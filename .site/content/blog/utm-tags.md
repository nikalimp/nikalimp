**[UTM-метки](/glossary/utm-parameters/) — это параметры в конце ссылки, которые сообщают аналитике, откуда пришёл посетитель: из какой рекламы, рассылки или соцсети.** Если передать их в скрытые поля формы, у каждой заявки будет источник, и вы перестанете гадать, какой канал приносит деньги. Ниже — как составить ссылку, готовый скрипт для Webflow, Next.js и любого HTML-сайта и как в 2026 году отличить клиентов из ChatGPT от клиентов из поиска.

Заявка без источника — как письмо без обратного адреса: прочитать можно, ответить «спасибо, рекламщик» — нельзя.

## Откуда взялось название

UTM — Urchin Tracking Module. Метки придумали в компании Urchin Software, которую в 2005 году купил Google. Из Urchin потом вырос Google Analytics, а метки стали общим стандартом: их понимают и Google Analytics, и [Яндекс Метрика](/glossary/yandex-metrica/).

## Как составить ссылку

Метки добавляют к ссылке конкретного объявления. Блок меток начинается со знака `?`, метки разделяются знаком `&`:

```
https://nikalimp.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=geo_audit
```

## Какие бывают метки

| Метка | Что означает | Примеры значений |
|---|---|---|
| `utm_source` | Площадка-источник | yandex, google, vk, telegram |
| `utm_medium` | Тип трафика | cpc, email, social, banner |
| `utm_campaign` | Название кампании | geo_audit, black_friday |
| `utm_content` | Вариант объявления | banner_1, video_15s |
| `utm_term` | Ключевое слово | geo_prodvizhenie |

Названия можно придумывать свои: например, `utm_device`, чтобы отличать мобильный трафик от десктопного.

Правила для значений:

1. Только латиница.
2. Только строчные буквы — `Yandex` и `yandex` аналитика посчитает разными источниками.
3. Слова разделяются нижним подчёркиванием или дефисом, без пробелов.

В версии статьи 2024 года во втором пункте стояли «прописные» буквы — это была опечатка, правильно строчные. Признаю ошибку, как Шелдон Купер признаёт чужую правоту: неохотно, но публично.

## Как передать метки в форму заявки

### Tilda

Тильда сама добавляет UTM-метки к данным заявки. Отправьте тестовую заявку по ссылке с метками и проверьте, что они доходят до почты или CRM, — и готово.

### Webflow, Next.js и любой HTML-сайт

В 2024 году я давал скрипт на jQuery, который читал метки только с текущей страницы. Проблема: посетитель пришёл на главную с метками, перешёл в «Услуги» — и метки потерялись. Новая версия запоминает метки на весь визит, сама создаёт скрытые поля в формах и работает без jQuery.

Вставьте код перед закрывающим тегом `</body>` на всех страницах. В Webflow это Site settings → Custom code → Footer code.

```html
<script>
(function () {
  var keys = ["utm_source", "utm_medium", "utm_campaign", "utm_content", "utm_term"];
  var params = new URLSearchParams(window.location.search);
  var saved = {};
  try { saved = JSON.parse(sessionStorage.getItem("utm") || "{}"); } catch (e) {}
  keys.forEach(function (k) { if (params.get(k)) saved[k] = params.get(k); });
  try { sessionStorage.setItem("utm", JSON.stringify(saved)); } catch (e) {}

  function fill() {
    document.querySelectorAll("form").forEach(function (form) {
      keys.forEach(function (k) {
        if (!saved[k]) return;
        var input = form.querySelector('input[name="' + k + '"]');
        if (!input) {
          input = document.createElement("input");
          input.type = "hidden";
          input.name = k;
          form.appendChild(input);
        }
        input.value = saved[k];
      });
    });
  }

  if (document.readyState === "loading") document.addEventListener("DOMContentLoaded", fill);
  else fill();
})();
</script>
```

Что делает скрипт:

1. Читает метки из адреса страницы.
2. Сохраняет их в `sessionStorage` — они живут, пока открыта вкладка.
3. Находит все формы и добавляет в каждую скрытые поля `utm_source`, `utm_medium` и остальные.

В Webflow скрытые поля уйдут вместе с заявкой в раздел Forms и в подключённые интеграции. В Next.js-проекте вынесите тот же код в компонент формы.

## Как отследить клиентов из нейросетей

В 2024 году эта глава была бы фантастикой уровня «Чёрного зеркала». В 2026-м — рутина.

- **ChatGPT** сам добавляет к ссылкам на сайты метку `utm_source=chatgpt.com`. Скрипт выше поймает её и запишет в заявку.
- **Perplexity, Алиса AI и другие** метки ставят не всегда. Их видно по источнику перехода в Яндекс Метрике: отчёт «Источники, сводка» → переходы с сайтов → perplexity.ai, alice.yandex.ru, gemini.google.com.
- **В Метрике** соберите сегмент из этих источников и следите за ним раз в месяц.

Так я замеряю результат [GEO-продвижения](/geo-audit/): не «нас вроде упоминают», а «из ChatGPT за месяц пришло столько-то заявок».

## Когда UTM-метки нужны

- Платная реклама в Яндекс Директе, VK Рекламе и у блогеров — у каждого блогера своя ссылка.
- Офлайн: QR-код на баннере, визитке или упаковке.
- Email-рассылки — чтобы сравнить письма между собой.
- Посевы в Telegram-каналах.

## Частые вопросы

**Влияют ли UTM-метки на SEO?** Нет, если на страницах стоит canonical без меток. Поисковики склеят адреса с метками и без.

**Можно ли ставить метки на внутренние ссылки сайта?** Не нужно: Метрика начнёт считать переход внутри сайта новым визитом и сотрёт настоящий источник.

**Почему в заявке нет меток?** Проверьте три вещи: метки в ссылке написаны без ошибок (`utm_source`, а не `utm_sourse`), скрипт стоит на странице с формой, форма отправляет скрытые поля в почту или CRM.

P. S. В версии 2024 года в примере ссылки была метка `utm_sourse`. Если вы скопировали её тогда — проверьте рекламу, она до сих пор пишет в пустоту.
