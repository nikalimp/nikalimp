# nikalimp.ru — правила для агента

Сайт Ника. С 12.11.2026 живёт в этом публичном репозитории (раньше — `.site` в vault NikitOS). Минуты GitHub Actions у публичного репозитория бесплатные.

## Перед работой
1. `.site/specs/STATUS.md` — где проект и что ждём; `.site/README.md` — устройство сайта.
2. Стандарты — в vault NikitOS (`Resources/Frameworks/`): «AI-Ready сайт — стандарт», «Публикация — стандарт». Вёрстка и тексты — скилл `web-dev`: shadcn/ui, Главред, Типограф.

## Git
- Код — ветка `claude/<задача>` и PR: `pr.yml` проверяет `npm run check`, сливает и выкладывает. Контент (`.site/content/`, `Library/`) задачи по расписанию коммитят прямо в `main` — push в `main` запускает `deploy.yml`.
- Справочники `Library/*` правятся здесь, в репозитории сайта. В vault NikitOS их больше нет.

## Команды
```bash
cd .site && npm ci
npm run dev     # локально
npm run check   # сборка + все проверки (перед выкладкой обязательно)
```

## Нельзя
- Google Fonts, внешние CDN и скрипты, которые блокируются в РФ.
- Текст за JavaScript: весь контент — в HTML.
- Выкладывать с проваленным `npm run check`.
- Класть сюда приватное: репозиторий публичный. Секреты — только в Settings → Secrets.
