Split-flap — стиль механического табло, где символы показаны на перекидных карточках. Каждая буква или цифра состоит из двух половинок, которые щёлкают и переворачиваются, пока не покажут нужный знак. Стиль узнаётся по тёмным плиткам, моноширинным буквам и движению «колоды» перед результатом.

## Откуда пришёл

Табло с перекидными карточками появились в середине XX века. Их ставили на вокзалах и в аэропортах: расписание рейсов менялось, и механика сама перекладывала символы. Известна итальянская фирма Solari di Udine, чьи табло знали многие города Европы. Отсюда и название «Solari board».

Когда электронные экраны вытеснили механику, табло стало ностальгией. В вебе стиль заметен как приём для часов, счётчиков, афиш и приветственных экранов. Фильмы, музеи транспорта и небольшие устройства с механическими табло сделали образ узнаваемым и среди тех, кто никогда не видел живой вокзал.

## Как узнать стиль

- Сетка одинаковых тёмных плиток с одним символом в каждой.
- Тонкая горизонтальная линия посередине плитки — шов между половинками.
- Моноширинный шрифт, только заглавные буквы и цифры.
- Движение: символы быстро перебираются, затем останавливаются на нужном.
- Контрастный светлый или жёлтый знак на почти чёрном фоне.
- Лёгкая рамка и тень у плитки создают объём.

Механика даёт и звук: сухой щелчок карточек. В вебе его воспроизводят короткой записью, но лучше оставить звук необязательным. Главное в стиле — ритм: символы меняются волной слева направо, а не все разом.

## Где уместно

Табло работает там, где есть что-то меняющееся: время, цена, статус, обратный отсчёт.

- Страницы мероприятий с отсчётом до начала.
- Блоки с цифрами и показателями.
- Сайты кафе, баров и студий с ретро-характером.
- Лендинги, где нужен запоминающийся заголовок.
- Приветственные экраны и пасхалки.

Не подходит для длинных текстов: плитки читаются медленно, а анимация отвлекает. Используйте его для одной фразы или одного числа, а не для абзаца. Хороший пример — блок «Следующий поток стартует через» с датой на плитках и обычным текстом под ним.

## Как сделать на сайте

Каждая плитка — блок с двумя половинками: верхней и нижней. При смене символа верхняя половинка поворачивается вокруг горизонтальной оси через `transform: rotateX()` и открывает новое значение. Эффект рисуют на CSS с `perspective`, а порядок символов задаёт небольшой скрипт.

```css
.flap { perspective: 400px; font: 700 48px "Roboto Mono"; }
.top, .bottom { backface-visibility: hidden; overflow: hidden; }
.top { transform-origin: bottom; }
.flip .top { animation: fold 0.18s ease-in forwards; }
@keyframes fold { to { transform: rotateX(-90deg); } }
```

Не создавайте сотни DOM-узлов под каждое слово. Для короткой фразы хватит 10–20 плиток. Анимируйте только `transform` и `opacity`, чтобы работала видеокарта. Для длинных блоков можно рисовать табло на canvas.

Чтобы не мешать читалкам экрана, добавьте скрытый текст с итоговым значением и поставьте `aria-label` на контейнер. Для `prefers-reduced-motion` показывайте результат сразу, без перебора символов. Звук щелчков включайте только по клику пользователя.

## Цвета и шрифты

Фон табло — угольный #111111, плитки чуть светлее: #1E1E1E. Знаки белые #F2F2F2 или жёлтые #F5C518, как на старых вокзалах. Серый #8A8A8A подойдёт для подписей, красный #D7263D — для предупреждений и отмен.

Нужен моноширинный шрифт: ширина символов одинакова, плитки не прыгают. Подойдут Roboto Mono, PT Mono и IBM Plex Mono. Для заголовков над табло возьмите узкий Oswald: он напоминает вывески на транспорте. Проверьте, что гарнитура содержит кириллицу, иначе русские буквы упадут в запасной шрифт.

## Типичные ошибки

- Слишком медленная анимация: пользователь ждёт слово несколько секунд.
- Пропорциональный шрифт: плитки разной ширины ломают сетку.
- Табло на весь экран с длинным текстом.
- Нет текстовой замены для скринридеров и поисковых систем.
- Бесконечный перебор символов, который не останавливается.
- Низкий контраст знака и плитки: тёмно-серое на чёрном не читается на солнце.

## Частые вопросы

### Чем табло split-flap отличается от обычного счётчика?
Счётчик просто меняет цифру. Split-flap показывает механику: карточки переворачиваются, перебирают символы и останавливаются. Именно движение даёт стилю характер.

### Можно ли набрать на табло русский текст?
Можно. Нужен моноширинный шрифт с кириллицей и набор символов, который включает русские буквы. В скрипте задайте алфавит в нужном порядке, чтобы перебор выглядел естественно.

### Как сделать табло для обратного отсчёта?
Считайте разницу между текущим временем и датой события раз в секунду. Меняйте плитку только у тех разрядов, где цифра действительно сменилась, и анимация останется лёгкой.

### Влияет ли табло на SEO?
Если слово существует только как картинка или canvas, поисковик его не увидит. Держите итоговый текст в HTML, а анимацию добавьте поверх.
