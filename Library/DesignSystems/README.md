# Дизайн-системы

Каталог дизайн-систем и библиотек к ним для будущей коллекции «Дизайн-системы» на сайте nikalimp.ru. Продукт описан в [[Сайт NikAlimp]]. Связанные инструменты — [[shadcn ui|shadcn/ui]], [[21st.dev]].

Идея коллекции: дизайн-система — это база (токены, компоненты, правила). Поверх базы ставятся библиотеки: компоненты, блоки секций, анимации, шаблоны, темы, иконки, Figma-киты. На странице системы показываем все подходящие ей библиотеки.

```
Дизайн-система (kind: system)
   └── библиотеки (kind: library, поле systems → слаги систем)
         ├── components   — компоненты
         ├── blocks       — готовые секции страниц
         ├── animations   — анимации и эффекты
         ├── templates    — целые сайты и дашборды
         ├── themes, icons, charts, figma
         └── tool, directory — генераторы, CLI, каталоги
```

## Файлы
- `designsystems.json` — данные: `{updated, items[]}`, по объекту на систему или библиотеку. Собрано 2026-11-07: 70 систем и 143 библиотеки. У систем есть поле `family` — группа на сайте (shadcn, tailwind, react, vue-svelte, ru, enterprise, css).
- `looks.json` — фирменные токены каждой системы для обложек: `primary`, `accent`, `radius`, `dark`.

## На сайте
- `/design-systems/` и `/design-systems/<slug>/` — системы: описание, факты, библиотеки по типам, лид-магнит, услуги, вопросы и ответы.
- `/ui-libraries/` и `/ui-libraries/<slug>/` — библиотеки: связь с системами, факты, лид-магнит, услуги.
- Код: `.site/src/lib/design-systems.ts` (данные, вопросы, выбор услуг), `components/ds-cover.tsx` (обложки SVG), `ds-parts.tsx`, `ds-filter.tsx`.
- Обложка системы — мини-интерфейс в её токенах из `looks.json`. Обложка библиотеки — сцена по главному типу (первый в `types`); у библиотек нейтральных систем цвет берётся из палитры по слагу.

## Поля записи
| Поле | Что значит |
|---|---|
| `slug`, `name` | Адрес и название |
| `kind` | `system` — база, `library` — набор поверх базы |
| `systems` | У библиотеки — слаги систем, к которым она подходит; `any` — к любой |
| `types` | components, blocks, animations, templates, themes, icons, charts, figma, primitives, tool, directory |
| `frameworks`, `styling`, `install` | Стек и способ установки (shadcn CLI, npm, копирование, Figma) |
| `size` | Объём по данным сайта |
| `pricing`, `price`, `license` | free / freemium / paid, цены, лицензия |
| `github`, `stars` | Репозиторий и звёзды на дату проверки |
| `status` | active, slow (почти не обновляется), moved (переехал), archived (закрыт) |
| `ru` | Доступность из России (оплата, открытость кода) |
| `ai` | MCP-сервер, llms.txt, скиллы для агентов |
| `best_for`, `short`, `about` | Для кого, суть до 60 символов, описание |
| `sources`, `checked` | Откуда факты и дата проверки |

## Что проверить перед публикацией
- Поле `ru` проверялось не из России: у платных Pro стоит общее правило «оплата только зарубежной картой».
- Тексты `short` и `about` пройти Главредом и Типографом (стандарт сайта).
- Записи со `status` moved и archived — решить, показывать ли их на сайте.
- Пересечения с `Library/Tools/` (shadcn/ui, 21st.dev, Magic UI и др.) — связать ссылками, а не дублировать.

## Обновление
Раз в квартал перепроверять цены, звёзды и статусы: в экосистеме shadcn библиотеки часто переезжают и меняют условия.
