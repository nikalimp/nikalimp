# Astro

**URL:** nikalimp.ru/glossary/astro
**См. также:** [[Astro]]

## Определение

Astro — это фреймворк для создания быстрых сайтов, ориентированных на контент: блогов, документации, лендингов и корпоративных страниц. Он собирает страницы в статический HTML и подключает JavaScript только там, где он нужен.

Ключевая идея Astro — «островная архитектура» (Islands). Страница в основном статична, а интерактивные участки (форма, калькулятор, слайдер) работают как отдельные «острова» со своим кодом. Остальное отправляется браузеру без JavaScript, поэтому страницы открываются быстро. Это помогает показателям [[Core Web Vitals]] и [[LCP]].

Astro поддерживает компоненты из [[React (термин)|React]], [[Vue]], [[Svelte (термин)|Svelte]] и других библиотек в одном проекте. Контент можно хранить в Markdown и отдавать как [[Статический сайт|статический сайт]] ([[SSG]]), а при необходимости включать серверный рендеринг ([[SSR]]).

### Пример
Блог на Astro: статьи лежат в файлах Markdown, страницы собираются при деплое, комментарии или поиск подключаются отдельными интерактивными компонентами.

### Когда Astro подходит
- Много текста, мало интерактива: блог, документация, сайт услуг.
- Важна скорость загрузки и SEO.
- Нужен простой хостинг статики и дешёвая поддержка.

### Когда лучше другой инструмент
Если сайт — это сложное приложение с кабинетом, состоянием и постоянной интерактивностью, удобнее [[Next.js (термин)|Next.js]] или похожие решения.

### Типичные ошибки
- Подключать тяжёлые библиотеки на всю страницу, хотя достаточно одного «острова».
- Забывать про [[Sitemap.xml]] и мета-теги: фреймворк их сам не заполнит.
- Хранить секреты в клиентском коде.

### Как проект на Astro устроен
Страницы лежат в папке `src/pages`, каждый файл становится адресом. Общие части (шапка, подвал, карточки) выносятся в компоненты. Данные и статьи можно держать в Markdown или подключать из [[Headless CMS|headless CMS]]. При сборке получается папка со статикой, которую можно выложить на любой хостинг или через [[CDN]]. Для обновлений сайта обычно настраивают [[CI-CD|CI/CD]]: изменения в репозитории автоматически собираются и публикуются.

### Частый вопрос
**Astro подходит для SEO?** Да. Страницы отдаются как готовый HTML, их легко индексируют и поисковики, и [[AI-краулер|AI-краулеры]], которые часто не выполняют JavaScript. Это одна из причин выбирать Astro для контентных сайтов.
