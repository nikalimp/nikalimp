# CSS Grid

**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/css-grid

## Определение

CSS Grid — это система раскладки в CSS, которая позволяет располагать элементы страницы по строкам и столбцам одновременно. Она подходит для сеток карточек, шаблонов страниц и сложных макетов.

Без Grid сетки делали на таблицах, плавающих блоках (`float`) и [[Flexbox]]. Grid появился в основных браузерах в 2017 году и упростил двумерную вёрстку: вы описываете, сколько колонок и строк нужно, а браузер расставляет элементы. Размеры задаются в пикселях, процентах, долях `fr` и функциях вроде `minmax()`.

### Чем отличается от Flexbox
Flexbox управляет раскладкой в одном направлении: в строку или в столбец. Grid работает сразу в двух направлениях. Часто их используют вместе: Grid для каркаса страницы, Flexbox для содержимого внутри карточки или меню.

### Пример
Сетка из трёх колонок с отступами:

`display: grid; grid-template-columns: repeat(3, 1fr); gap: 24px;`

Автоматическая адаптивная сетка без медиазапросов:

`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));`

Колонки сами перестроятся: на узком экране карточки встанут в один ряд.

### Основные свойства
1. `display: grid` включает режим сетки у контейнера.
2. `grid-template-columns` и `grid-template-rows` задают структуру.
3. `gap` задаёт расстояние между ячейками.
4. `grid-area` и `grid-column` позиционируют элемент в нужных ячейках.
5. `grid-template-areas` позволяет описать шаблон словами.

### Типичные ошибки
- Использовать Grid там, где достаточно Flexbox.
- Задавать фиксированные размеры колонок и ломать [[Адаптивная вёрстка|адаптивность]].
- Менять визуальный порядок элементов так, что он расходится с порядком для клавиатуры и скринридера ([[Доступность]]).
- Забывать про `min-width: 0`, из-за чего длинный текст растягивает колонку.

### Кому и когда это нужно
Всем, кто верстает современные сайты: от каталогов и портфолио до [[Bento grid|bento-сеток]]. Для простого ряда кнопок хватит Flexbox.

### Как Grid помогает адаптивности
Сетка умеет перестраиваться без отдельных правил для каждого устройства. Через `auto-fit` и `minmax()` карточки сами распределяются по доступной ширине, а через `grid-template-areas` на узком экране удобно переставить блоки. Это сокращает объём CSS и делает вёрстку предсказуемой. Всё равно проверяйте результат на реальных устройствах и при увеличении шрифта.

### Частый вопрос
**Нужно ли ещё учить Flexbox, если есть Grid?** Да. Это разные инструменты. Grid лучше для общей сетки страницы, Flexbox удобнее для выравнивания элементов в одну линию.
