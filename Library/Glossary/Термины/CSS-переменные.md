# CSS-переменные

**English:** CSS Custom Properties
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/css-custom-properties

## Определение

CSS-переменные (пользовательские свойства, CSS Custom Properties) — это значения, которые задаются один раз и используются в стилях много раз. Имя переменной начинается с двух дефисов, например `--color-primary`, а подставляется функцией `var()`.

Переменные помогают держать цвета, отступы, шрифты и радиусы в одном месте. Нужно сменить фирменный цвет — меняете одну строку, а не сотню. На этом строятся [[Дизайн-токены|дизайн-токены]] и [[Дизайн-система|дизайн-системы]] в коде.

В отличие от переменных [[SCSS]], CSS-переменные живут в браузере, а не исчезают после сборки. Поэтому их можно менять на лету: через [[JavaScript]] или в зависимости от условий, например при переключении [[Тёмная тема|тёмной темы]].

### Пример
```css
:root {
  --color-bg: #ffffff;
  --color-text: #1a1a1a;
  --space-4: 16px;
}
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #121212;
    --color-text: #f2f2f2;
  }
}
body {
  background: var(--color-bg);
  color: var(--color-text);
  padding: var(--space-4);
}
```
Блок `:root` задаёт значения для всей страницы. В тёмной теме подменяются только значения переменных, а сами правила остаются без изменений.

### Как организовать переменные
1. Выделите базовые значения: цвета, шрифты, отступы.
2. Добавьте смысловые имена по роли: `--color-text`, `--color-border`, а не `--gray-700` в компонентах.
3. Задавайте переменные на уровне `:root`, локальные — внутри компонента.
4. Для запасного значения используйте `var(--x, 16px)`.
5. Документируйте набор: список и назначение.

### Типичные ошибки
- Называть переменные по значению (`--red`), а не по роли.
- Создавать слишком много переменных «на всякий случай».
- Забывать про запасное значение: если переменной нет, свойство не сработает.
- Использовать переменные внутри медиазапросов как условие: подставить `var()` в само условие нельзя.

### Где переменные особенно полезны
В дизайн-системах, где десятки компонентов зависят от одних и тех же цветов и отступов; в многобрендовых проектах, где нужно быстро сменить палитру; в переключателях тем. Если вы используете [[shadcn-ui]] или [[Tailwind CSS (термин)|Tailwind CSS]], переменные уже лежат в основе токенов: достаточно менять их значения, и стиль всего интерфейса обновляется согласованно.

### Частый вопрос
**Чем CSS-переменные лучше переменных SCSS?** Они работают в браузере и умеют меняться динамически, например для тем и адаптивных значений. SCSS-переменные вычисляются при сборке и после неё недоступны. Современные проекты часто обходятся только CSS-переменными.
