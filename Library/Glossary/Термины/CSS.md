## Определение

CSS (каскадные таблицы стилей) — это язык, который описывает внешний вид веб-страницы: цвета, шрифты, отступы, расположение блоков и анимации. [[HTML]] задаёт структуру и смысл страницы, CSS — оформление.

Язык появился в середине 1990-х, чтобы отделить оформление от содержимого. Теперь можно менять дизайн всего сайта, не трогая HTML. Стили подключаются отдельным файлом, в теге `<style>` или прямо в элементе, хотя отдельный файл удобнее для поддержки и кэширования.

Слово «каскадные» означает, что при конфликте правил браузер выбирает главное по понятному порядку: учитывает специфичность селектора, порядок записи и важность. Именно поэтому правила иногда «не работают»: другое, более сильное правило перебивает ваше.

### Пример
```css
.button {
  background: #0a5cff;
  color: #fff;
  padding: 12px 20px;
  border-radius: 8px;
}
```
Правило применяется ко всем элементам с классом `button`.

### Как писать CSS, чтобы его можно было поддерживать
1. Используйте понятную систему имён, например [[БЭМ]].
2. Выносите цвета и размеры в переменные.
3. Избегайте глубокой вложенности селекторов.
4. Не злоупотребляйте `!important`.
5. Подумайте об утилитарных подходах вроде [[Tailwind CSS (термин)|Tailwind CSS]] или препроцессорах ([[SCSS]]).

### Типичные ошибки
- Фиксированные размеры, из-за которых ломается вёрстка на телефоне.
- Подключение огромных файлов стилей, которые тормозят загрузку ([[Минификация]]).
- Скрытие фокуса у ссылок и кнопок, что ухудшает [[Доступность]].
- Копирование чужих стилей без понимания каскада.

### Как CSS связан с производительностью и SEO
Стили блокируют отображение страницы, пока браузер не загрузит их, поэтому тяжёлые файлы замедляют первый экран. Уберите неиспользуемые правила, сожмите файлы и загружайте критичное в первую очередь. Аккуратный CSS также влияет на [[Core Web Vitals]]: заданные размеры блоков уменьшают сдвиги, а лёгкая вёрстка ускоряет появление главного контента.

### Частый вопрос
**CSS — это язык программирования?** Нет, это язык стилей. В нём нет полноценной логики вроде циклов и функций общего назначения, хотя современные возможности (переменные, `calc()`, условия в запросах) делают его гибким. Логика на странице пишется на [[JavaScript]].
