# Claude Code

**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/claude-code
**См. также:** [[Claude Code]]

## Определение

Claude Code — это агентный инструмент для программирования от Anthropic, который работает в терминале и редакторах кода. Он читает проект, пишет и правит файлы, запускает команды и тесты по вашему описанию задачи на обычном языке.

В отличие от чат-бота, Claude Code работает с вашей папкой проекта: ищет нужные файлы, вносит изменения в несколько мест, запускает проверку и исправляет ошибки. Это пример [[AI-агент|AI-агента]]. Он использует [[Языковая модель|языковые модели]] Claude и умеет вызывать инструменты ([[Tool use]]), в том числе внешние сервисы через [[MCP]].

Для настройки под проект используют файл с инструкциями (обычно `CLAUDE.md`), где описаны стек, правила кода и команды. Расширять возможности можно скиллами и плагинами: заготовленными инструкциями для типовых задач.

### Для чего применяют
- Создание сайтов и сервисов по описанию ([[AI-разработка]]).
- Рефакторинг и поиск ошибок.
- Написание тестов и документации.
- Подготовка коммитов и [[Pull request|pull request]].
- Автоматизация рутинных задач в репозитории.

### Как начать
1. Установите инструмент по актуальной инструкции на сайте Anthropic.
2. Откройте терминал в папке проекта и запустите Claude Code.
3. Опишите задачу: что нужно получить, какие ограничения.
4. Просмотрите предложенные изменения и подтвердите их.
5. Запустите тесты и проверьте результат сами.

### Типичные ошибки
- Давать расплывчатую задачу без критериев готовности.
- Разрешать любые действия без просмотра, особенно удаление файлов и отправку данных вовне.
- Не вести файл инструкций проекта: агент каждый раз начинает «с нуля».
- Выкладывать результат на сайт без проверки.

### Чем отличается от Cursor и чат-ботов
Cursor встроен в редактор и больше ориентирован на интерактивную правку кода; Claude Code ближе к исполнителю, которому поручают задачу целиком. Чат-бот видит только то, что вы ему вставили.

### Как безопасно работать с агентом
Давайте минимальные права: сначала режим, где каждое действие подтверждается. Храните секреты вне репозитория и не вставляйте их в запросы. Работайте в отдельной ветке, чтобы любые правки можно было откатить через [[Git]]. Просматривайте изменения перед слиянием и запускайте тесты. Такие меры снижают риск, что агент случайно сломает рабочий проект или раскроет данные.

### Частый вопрос
**Нужно ли уметь программировать, чтобы работать с Claude Code?** Для простых задач можно обойтись базовым пониманием, но результат всё равно нужно проверять. Чем лучше вы понимаете код и тестирование, тем безопаснее и полезнее инструмент.
