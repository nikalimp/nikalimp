# Custom GPT

**Категория:** [[Глоссарий — AI и LLM]]
**URL:** nikalimp.ru/glossary/custom-gpt

## Определение

Custom GPT — это настроенная версия ChatGPT с собственными инструкциями, загруженными файлами и подключёнными действиями, которую можно сохранить и использовать для одной задачи или поделиться ссылкой.

Обычный чат начинается с чистого листа: каждый раз приходится объяснять роль, стиль и правила. Custom GPT фиксирует это один раз. При создании вы описываете назначение, задаёте инструкции (как отвечать, чего избегать, какой формат), прикладываете файлы знаний (регламенты, прайс, примеры) и при необходимости подключаете внешние сервисы через вызов функций ([[Function calling]]). Получается узкий помощник: консультант по услугам, редактор по вашей редполитике, помощник отдела продаж.

Создают такие боты в конструкторе ChatGPT, доступность функции и способ публикации зависят от тарифа и региона. Опубликовать помощника можно для себя, по ссылке или в каталоге. Custom GPT удобен для небольших команд и экспертов: не нужно программировать, достаточно уметь чётко формулировать инструкции. Для сложных систем с собственной логикой и интеграциями лучше использовать [[API модели|API]]. Близкие по идее решения есть у других сервисов, например [[Проекты в Claude|проекты]] и [[Claude Skills|навыки]] в Claude.

### Что настраивается
- Название, описание и стартовые подсказки.
- Инструкции: роль, тон, правила, формат ответов.
- Файлы знаний: документы, к которым помощник обращается.
- Возможности: поиск в сети, работа с изображениями, код.
- Действия: вызов внешнего API.

### Как создать Custom GPT
1. Определите одну задачу и аудиторию: чем уже, тем лучше результат.
2. Напишите инструкции: роль, этапы работы, формат, запреты, что делать при нехватке данных.
3. Загрузите чистые, актуальные файлы знаний без лишнего.
4. Проверьте на 10–20 реальных вопросах и найдите слабые места.
5. Исправьте инструкции и повторите проверку.
6. Решите, кому и как будет доступен помощник.

### Пример
Студия делает помощника «Менеджер по первичному брифу»: он задаёт клиенту вопросы по списку, уточняет сроки и бюджет, а в конце формирует структурированный бриф для команды. Файл знаний содержит перечень услуг и этапов работы.

### Типичные ошибки
- Слишком общая задача: помощник отвечает на всё, но ни в чём не силён.
- Загрузка конфиденциальных данных в файлы знаний, которые могут быть доступны пользователям.
- Противоречивые инструкции.
- Отсутствие тестирования на реальных запросах.
- Ожидание, что файлы знаний гарантируют точность: модель всё равно может ошибиться.

### Частый вопрос
**Нужно ли уметь программировать для создания Custom GPT?** Нет. Для базового помощника достаточно написать инструкции и загрузить файлы. Программирование нужно только для подключения внешних сервисов через действия.
