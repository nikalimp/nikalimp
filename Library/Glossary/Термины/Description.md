# Description

**English:** Meta Description
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/description

## Определение

Description (мета-описание) — это HTML-тег `<meta name="description">`, в котором кратко описано содержимое страницы. Поисковики часто берут его текст для сниппета в выдаче.

Тег находится в `<head>`. Пользователь его не видит на странице, но читает в результатах поиска под заголовком. Хорошее описание повышает кликабельность ([[CTR]]), хотя прямым фактором ранжирования ([[Фактор ранжирования]]) не считается.

Поисковая система не обязана показывать ваш текст. Если описание не подходит под запрос, Google и Яндекс могут собрать сниппет из текста страницы сами.

### Пример
`<meta name="description" content="Разработка сайта-визитки на Tilda под ключ: срок 7 дней, адаптив, подключение формы заявок и аналитики.">`

В выдаче под заголовком появится этот текст, а слова из запроса поисковик выделит жирным.

### Как написать хорошее описание
1. Ответьте на вопрос пользователя: что он найдёт на странице и зачем туда идти.
2. Включите основной ключ естественно, один раз.
3. Добавьте конкретику: срок, формат, отличие, вместо общих слов.
4. Уложитесь примерно в 120–160 символов: длинный текст обрежется.
5. Сделайте описание уникальным для каждой страницы.

### Типичные ошибки
- Одинаковое описание на всех страницах сайта.
- Перечень ключевых слов вместо связного текста.
- Пустой тег: поисковик подставит случайный кусок текста.
- Обещания, которых нет на странице: рост отказов и потеря доверия.
- Дублирование [[Title]] слово в слово.

### Чем отличается от Title
[[Title]] — заголовок сниппета, он влияет на ранжирование сильнее и должен точно называть тему. Description — пояснение под ним, его задача убедить кликнуть.

### Кому и когда это нужно
Мета-описания нужны любому сайту, который хочет получать переходы из поиска. Для интернет-магазина и каталога их составляют по шаблону с подстановкой названия и ключевой характеристики. Для статей, лендингов и услуг лучше писать вручную: это пара предложений, которые продают клик. Начните с самых посещаемых страниц, которые видны в Google Search Console и Вебмастере.

### Частый вопрос
**Нужно ли заполнять description, если поисковик всё равно может его заменить?** Да. В большинстве случаев он берёт именно ваш текст, особенно если тот точно отвечает на запрос. Для важных страниц это один из самых дешёвых способов поднять CTR без изменения позиций.
