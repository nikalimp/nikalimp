# Function calling

**English:** Function Calling
**Категория:** [[Глоссарий — AI и LLM]]
**URL:** nikalimp.ru/glossary/function-calling

## Определение

Function calling («вызов функций») — это возможность языковой модели вместо текста вернуть структурированный запрос на вызов функции: название и аргументы. Ваш код выполняет функцию и возвращает результат модели, которая формулирует ответ.

Сама модель не умеет узнавать курс валют, проверять наличие товара или создавать заявку в CRM: у неё только текст. Function calling соединяет её с внешним миром. Вы описываете доступные функции в [[API модели|запросе к API]]: имя, назначение, параметры. Если пользователь пишет «сколько стоит доставка в Казань», модель решает, что нужна функция расчёта доставки, и возвращает её имя с аргументами в формате [[JSON]]. Ваш код вызывает реальную службу, получает результат и передаёт его модели, а она отвечает человеку по-человечески.

Это основа [[AI-агент|AI-агентов]] и умных чат-ботов. Для стандартизации подключения инструментов к моделям появился протокол [[MCP]]. Важно помнить: модель только предлагает вызов, а решение выполнить его и проверку аргументов принимает ваш код. Так вы контролируете безопасность.

### Как это работает по шагам
1. Вы описываете функции: название, описание, схема параметров.
2. Пользователь задаёт вопрос.
3. Модель решает, нужна ли функция, и возвращает вызов с аргументами.
4. Ваш код проверяет аргументы и выполняет функцию.
5. Результат отправляется обратно модели.
6. Модель формирует итоговый ответ пользователю.

### Пример
Бот записи в салон. Описана функция «получить свободные слоты(дата, услуга)». Клиент пишет: «Хочу на маникюр в пятницу». Модель вызывает функцию с датой и услугой, код возвращает свободное время, а модель предлагает варианты. После выбора вызывается функция «создать запись».

### Как писать описание функций
- Давайте функции понятные имена и краткие описания: по ним модель решает, когда вызывать.
- Описывайте параметры и допустимые значения.
- Не делайте функции слишком универсальными: лучше несколько простых.
- Указывайте, какие параметры обязательны.

### Типичные ошибки
- Выполнять вызов без проверки аргументов: возможны ошибки и злоупотребления.
- Давать модели функции с опасными действиями (удаление, оплата) без подтверждения человеком.
- Расплывчатые описания: модель вызывает не ту функцию.
- Не обрабатывать ошибки внешней службы.
- Забывать про [[Prompt injection|prompt injection]]: данные из внешних источников могут содержать вредные инструкции.

### Частый вопрос
**Модель сама выполняет функцию?** Нет. Она лишь формирует запрос на вызов. Выполняет его ваш код, и именно он решает, разрешать ли действие. Это даёт контроль над тем, что модель может делать.
