## Определение

GitHub — это сервис для хранения кода в репозиториях [[Git]], совместной работы над проектами и автоматизации выкладки. Сейчас он принадлежит Microsoft и остаётся самой популярной площадкой для разработчиков.

Git хранит историю изменений на вашем компьютере, а GitHub делает её доступной в интернете: команда видит одну и ту же версию проекта, предлагает правки, обсуждает их и принимает. Вокруг репозитория выросла целая инфраструктура: задачи, обзор кода, автоматические проверки, хостинг статических страниц.

Для сайтов GitHub часто служит связующим звеном. Вы отправляете изменения в репозиторий, а [[Vercel (термин)]], [[Netlify (термин)]] или собственный сервер получают сигнал и обновляют сайт.

Платформа основана в 2008 году, а в 2018-м её купила Microsoft. Помимо кода, на ней живёт огромное число открытых проектов: любой может изучить чужие решения, предложить исправление или взять библиотеку для своего сайта. В России сервис доступен, но разработчики сообщают об отдельных ограничениях на оплату платных функций. Отечественные и самостоятельные варианты, например GitLab на своём сервере, пользуются теми же командами Git.

### Что умеет
- Repositories: публичные и приватные хранилища кода.
- [[Pull request]]: предложение изменений с обсуждением и проверкой.
- Issues: задачи и баги.
- Actions: автоматические сценарии, например тесты и выкладка при каждом изменении, подробнее в [[CI-CD]].
- Pages: бесплатный хостинг статических сайтов.
- Organizations: общий доступ для команды.

### Как выложить проект
1. Зарегистрируйтесь и создайте новый репозиторий.
2. В папке проекта выполните `git remote add origin <адрес>`.
3. Отправьте код командой `git push -u origin main`.
4. Подключите репозиторий к хостингу или настройте сценарий в Actions.
5. Включите защиту основной ветки и двухфакторную аутентификацию.

### Типичные ошибки
- Сделать репозиторий публичным и оставить в нём ключи доступа.
- Хранить всё в одной ветке без обзора изменений.
- Не добавить файл `.gitignore` и залить в репозиторий лишние папки.
- Отдать доступ всем участникам с правами администратора.

### Чем отличается от Git
Git — программа для версий, GitHub — онлайн-платформа на её основе. Без GitHub можно работать с Git. Но без Git GitHub бесполезен.

### Частый вопрос
**Безопасно ли держать клиентский код на GitHub?** Да, если репозиторий приватный, включена двухфакторная аутентификация, а секреты хранятся в настройках сервиса, а не в коде. Для проектов с требованием хранить данные в России проверьте условия договора с клиентом: исходный код и персональные данные — разные вещи.
