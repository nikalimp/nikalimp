# Image SEO

**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/image-seo

## Определение



Image SEO — оптимизация изображений, чтобы их находили в поиске по картинкам и визуальном поиске (Google Lens, «Поиск по картинке» в Яндексе) и чтобы они не тормозили сайт.

Сюда входят понятные имена файлов, атрибут alt с описанием, подписи к картинкам, современные форматы (WebP, AVIF), сжатие и ленивая загрузка, разметка ImageObject. Мультимодальные нейросети тоже «видят» картинки через alt и окружающий текст.

### История поиска по картинкам
Google запустил поиск по изображениям в 2001 году. Поводом, по воспоминаниям сотрудников компании, стал всплеск запросов о зелёном платье Дженнифер Лопес на церемонии «Грэмми». Яндекс открыл свой поиск по картинкам в 2002 году. Долгое время поисковики понимали картинку только по тексту вокруг неё: имени файла, alt и подписи. В 2010-х появился поиск по изображению, в 2017 году — Google Lens, а Яндекс развивал «Умную камеру». Мультимодальные модели теперь сами распознают объекты на фото, но текстовые сигналы остаются главными.

### Что даёт Image SEO
- Трафик из поиска по картинкам — особенно для товаров, интерьеров, рецептов, дизайна.
- Скорость сайта: изображения часто занимают большую часть веса страницы.
- Понятность для нейросетей: модель знает, что изображено, и может сослаться на страницу.
- Доступность: alt читают экранные дикторы для незрячих пользователей.

### Чек-лист оптимизации
1. Называйте файлы по содержанию: remont-kuhni-loft.webp вместо IMG_4521.jpg.
2. Пишите alt одним предложением о том, что на картинке, без перечня ключевых слов.
3. Используйте WebP или AVIF и сжимайте изображения.
4. Указывайте width и height, чтобы страница не прыгала при загрузке.
5. Включайте ленивую загрузку для картинок ниже первого экрана.
6. Добавляйте подписи под важными изображениями.
7. Размечайте ключевые изображения через ImageObject и указывайте их в Open Graph.

Для портфолио и интернет-магазинов Image SEO — одна из самых окупаемых технических задач.
