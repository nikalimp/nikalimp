# JSON

**URL:** nikalimp.ru/glossary/json

## Определение

JSON (JavaScript Object Notation) — это текстовый формат для хранения и передачи данных в виде пар «ключ — значение», который одинаково легко читают и человек, и программа.

Формат вырос из синтаксиса [[JavaScript]], но сегодня его понимает любой язык программирования. Именно JSON чаще всего возвращают [[API]]: сайт запрашивает данные у сервера, а тот отвечает JSON-текстом. Он вытеснил более громоздкий XML благодаря компактности и простоте.

Формат придумал Дуглас Крокфорд в начале 2000-х, а затем он стал международным стандартом. Главная причина успеха — простота: описание формата умещается на одну страницу, и нет нужды в сложных библиотеках, чтобы начать им пользоваться. Размер JSON-ответа влияет на скорость: лишние поля увеличивают объём данных, которые придётся скачать и разобрать. Хорошие API отдают только то, что нужно клиенту.

### Как выглядит
Данные заключены в фигурные скобки, ключи и строки в двойных кавычках, значения разделены запятыми:
`{"name": "Анна", "age": 30, "tags": ["дизайн", "сайты"], "active": true}`

### Какие значения допустимы
- Строка в двойных кавычках.
- Число.
- Логическое значение: true или false.
- Пустое значение: null.
- Массив: список в квадратных скобках.
- Объект: набор пар «ключ — значение» в фигурных скобках, который можно вкладывать друг в друга.

В JSON нет комментариев, дат и функций. Дату обычно записывают строкой, например `"2026-11-01"`.

### Где встречается
- Ответы и запросы [[REST API]] и [[GraphQL]].
- Файлы настроек проекта, например package.json.
- Структурированные данные для поисковиков: [[JSON-LD (термин)]].
- Данные из [[Webhook]], когда сервис сообщает о событии.
- Хранение в [[Local Storage]].

### Как проверить JSON
1. Вставьте текст в любой валидатор JSON.
2. Убедитесь, что все ключи и строки в двойных кавычках.
3. Проверьте запятые: после последнего элемента лишней запятой быть не должно.
4. Проверьте, что скобки закрыты.

### Типичные ошибки
- Одинарные кавычки вместо двойных.
- Лишняя запятая в конце списка.
- Комментарии внутри файла.
- Кодировка не UTF-8: русские буквы превращаются в набор символов.

### Частый вопрос
**Чем JSON отличается от объекта JavaScript?** Объект в JavaScript — структура в памяти программы, где допустимы функции и ключи без кавычек. JSON — текст, в котором всё строго: только данные, ключи в двойных кавычках. Чтобы передать объект по сети, его превращают в JSON-строку, а на приёме разбирают обратно.
