## Определение

JavaScript — это язык программирования, который делает веб-страницы живыми: меню раскрываются, формы проверяются, данные подгружаются без перезагрузки. Он работает прямо в браузере и входит в тройку базовых технологий сайта вместе с [[HTML]] и [[CSS]].

Язык создал Брендан Эйх в 1995 году. Несмотря на похожее название, к Java он отношения не имеет. Со временем JavaScript вышел за пределы браузера: на нём пишут серверы (Node.js), мобильные приложения и десктопные программы. Стандарт языка называется ECMAScript, новые версии выходят ежегодно.

Скрипт работает с [[DOM]]: находит элементы страницы, меняет их, реагирует на клики и ввод. Для запросов к серверу он использует [[API]] и обменивается данными в формате [[JSON]].

Сегодня это самый распространённый язык веба. Браузеры исполняют его во встроенных движках, например V8 у Chrome. Поэтому ваш код запускается у посетителя на его устройстве, и его скорость зависит от мощности телефона, а не только от сервера. Для больших проектов чаще используют TypeScript: он добавляет проверку типов и ловит ошибки ещё при написании кода, а затем превращается в обычный JavaScript.

### Зачем знать не только программисту
- От JavaScript зависит скорость сайта: тяжёлые скрипты тормозят загрузку и ухудшают [[INP]] и [[LCP]].
- Если текст страницы создаётся скриптом, поисковый робот и [[AI-краулер]] могут его не увидеть. Многие AI-краулеры не выполняют JavaScript.
- Вокруг языка выросла экосистема: [[React (термин)]], [[Next.js (термин)]], а также TypeScript, надстройка с типами.

### Пример
Кнопка «Показать телефон»: скрипт ждёт клика, находит блок с номером и убирает у него класс `hidden`. Номер появляется, страница не перезагружается.

### Как начать изучать
1. Освойте основы HTML и CSS: без них JavaScript нечем управлять.
2. Выучите переменные, условия, циклы и функции.
3. Потренируйтесь работать с DOM: события, поиск элементов, изменение текста.
4. Научитесь запрашивать данные у API через `fetch`.
5. Затем переходите к фреймворку, например React.

### Типичные ошибки
- Подключать большие библиотеки ради одной мелочи.
- Показывать важный контент только после выполнения скрипта.
- Забывать о людях с отключённым JavaScript и медленными телефонами.
- Не проверять ошибки в консоли браузера.

### Частый вопрос
**JavaScript и Java — это одно и то же?** Нет. Это два разных языка с разным назначением. Название похоже по историческим причинам: в 1990-х его выбрали из маркетинговых соображений. Java чаще применяют в крупных серверных системах и Android, JavaScript — в вебе.
