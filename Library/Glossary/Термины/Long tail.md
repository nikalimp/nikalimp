# Long tail

**English:** Long-tail Keywords
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/long-tail

## Определение

Long tail («длинный хвост») — это множество узких, редких и конкретных поисковых запросов из трёх и более слов, у каждого из которых мало показов, но суммарно они дают значительную часть трафика.

Идею «длинного хвоста» в экономике популяризировал журналист Крис Андерсон. В SEO она означает: в поисковой статистике есть небольшое число популярных запросов («диван») и огромное число редких, но точных («угловой диван с ящиком для белья до 2 метров»). В русскоязычном SEO такие запросы называют низкочастотными ([[НЧ запросы]]) и [[Микро-НЧ]].

Для продвижения хвост выгоден по трём причинам. Конкуренция ниже, поэтому выйти в топ проще. Запрос конкретнее, поэтому пользователь лучше понимает, что ищет. Конверсия обычно выше, чем у общих запросов.

### Пример
«Ремонт квартир» — высокочастотный запрос с огромной конкуренцией. «Ремонт двухкомнатной хрущёвки под ключ с дизайн-проектом» — хвост. Показов мало, но человек уже определился с задачей.

### Как работать с длинным хвостом
1. Соберите запросы в [[Wordstat]], в подсказках поисковика и в блоке [[People Also Ask]].
2. Просмотрите отчёт по запросам в Google Search Console и Яндекс Вебмастере: там видно, по каким фразам уже есть показы.
3. Сгруппируйте запросы по смыслу ([[Кластеризация запросов]]).
4. Для каждой группы создайте страницу или раздел статьи, отвечающий именно на этот вопрос.
5. Добавьте блок FAQ и подразделы для разных формулировок.

### Типичные ошибки
- Делать отдельную страницу на каждую мелкую формулировку. Это создаёт дубли и каннибализацию.
- Писать общий текст, который не отвечает на конкретный вопрос.
- Игнорировать хвост, потому что у каждого запроса «мало трафика».
- Не проверять намерение пользователя.

### Чем отличается от обычных запросов
Основной (head) запрос — короткий и общий, у него высокий спрос, но размытый интент. Хвостовой запрос — длинный и точный. Лучший результат даёт сочетание: страницы под главные запросы и содержательные материалы под хвост.

### Кому и когда это нужно
Работа с длинным хвостом особенно полезна новым сайтам, блогам, малому бизнесу и нишевым услугам. Там, где конкуренция по общим запросам слишком высока, хвост даёт первый трафик и заявки. Он также удобен для проверки гипотез: по редким запросам быстро видно, какие темы интересны аудитории. Внимательно относитесь к структуре, чтобы не плодить похожие страницы.

### Частый вопрос
**Стоит ли продвигаться только по длинному хвосту?** Для нового сайта и небольшого бизнеса это хорошая стартовая стратегия: первые результаты приходят быстрее. Позже добавляйте более конкурентные запросы, опираясь на накопленный авторитет.
