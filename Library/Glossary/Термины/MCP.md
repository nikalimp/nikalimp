# MCP

**English:** Model Context Protocol
**Категория:** [[Глоссарий — GEO и AI-поиск]]
**URL:** nikalimp.ru/glossary/mcp

## Определение

MCP (Model Context Protocol) — открытый протокол, через который языковые модели и AI-агенты подключаются к внешним данным и сервисам: базам данных, CRM, файлам, API сайтов.

Протокол представила Anthropic в 2024 году, затем его поддержали другие крупные разработчики AI. Для бизнеса MCP-сервер — способ дать нейросетям прямой и точный доступ к своим данным, например к каталогу или расписанию, вместо того чтобы они угадывали по страницам сайта.

### История протокола
Anthropic опубликовала MCP в ноябре 2024 года как открытый стандарт с документацией и примерами серверов. Задача была практической: каждая интеграция модели с внешним сервисом писалась заново, и разработчикам приходилось повторять одну и ту же работу. MCP предложил единый способ описать инструменты и данные. В марте 2025 года поддержку протокола объявила OpenAI, затем Google, Microsoft и разработчики инструментов для программирования. К концу 2025 года вокруг протокола выросли тысячи открытых серверов: для баз данных, CRM, таблиц, дизайн-инструментов, браузеров. Позже Anthropic передала MCP в Agentic AI Foundation под управлением Linux Foundation.

### Как устроен MCP
- **Клиент** — приложение с моделью: Claude, ChatGPT, Cursor, Claude Code.
- **Сервер** — программа, которая даёт доступ к данным или действиям сервиса.
- **Инструменты** — функции, которые модель может вызвать: найти товар, создать заявку, получить расписание.
- **Ресурсы** — данные, которые модель может прочитать: документы, записи, файлы.

Модель видит описание инструментов и сама решает, какой вызвать для ответа пользователю.

### Зачем MCP бизнесу
- Нейросети получают точные данные из первоисточника, а не угадывают по сайту.
- AI-агенты клиентов могут проверить наличие, записаться или оформить заказ.
- Сотрудники подключают CRM, таблицы и базы знаний к рабочим ассистентам.

### С чего начать
Для большинства компаний первый шаг — не свой MCP-сервер, а машиночитаемый сайт: микроразметка, фиды, llms.txt. MCP-сервер имеет смысл, когда есть каталог, расписание или личный кабинет, с которыми агенты должны работать напрямую.
