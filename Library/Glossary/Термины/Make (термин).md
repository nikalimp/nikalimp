## Определение

Make — это сервис визуальной автоматизации, в котором из блоков-модулей собирают сценарии: «когда произошло событие в одном приложении, выполни действия в других». Раньше сервис назывался Integromat, с 2022 года работает под именем Make.

Сценарий выглядит как схема на холсте: слева триггер, например «новая строка в таблице», дальше цепочка модулей — создать сделку, отправить сообщение, записать данные. Между модулями данные передаются с помощью переменных, а ветвления, фильтры и циклы позволяют строить условную логику. Для связи с сервисами без готового модуля используют HTTP-запросы и [[Webhook]], то есть подключение через [[API]].

Главная особенность Make — визуальность. Весь сценарий виден на одном холсте, а у каждого модуля можно посмотреть, какие данные он получил и что отдал на выходе. Это сильно ускоряет поиск ошибок: сразу видно, на каком шаге данные пропали. Сценарии запускаются по расписанию, по событию или вручную, а историю запусков можно открыть и повторить неудавшиеся выполнения без потери данных.

### Пример
Новая оплата в платёжной системе запускает сценарий. Он создаёт запись в таблице, отправляет клиенту письмо с доступом, а бухгалтеру пишет в чат. Если оплата отклонена, сценарий идёт по другой ветке и уведомляет менеджера.

### Как собрать сценарий
1. Определите триггер: что запускает сценарий.
2. Добавьте модуль-триггер и подключите сервис.
3. Добавьте нужные действия и настройте соответствие полей.
4. Добавьте фильтры и обработку ошибок.
5. Запустите тест на реальных данных и только потом включайте расписание.

### Типичные ошибки
- Не настроить обработку ошибок — при сбое сценарий останавливается, а заявки теряются.
- Не следить за лимитом операций: каждый шаг сценария расходует операцию из тарифа.
- Передавать персональные данные россиян через зарубежный сервис без оценки рисков по 152-ФЗ.
- Строить гигантские сценарии вместо нескольких небольших.

### Чем отличается от Zapier и n8n
[[Zapier (термин)|Zapier]] проще для линейных цепочек, Make нагляднее и сильнее в ветвлениях и обработке данных. [[n8n (термин)|n8n]] можно развернуть на своём сервере и держать данные у себя. У всех трёх один принцип, различаются удобство, цена и ограничения.

### Частый вопрос
**Make работает с российскими сервисами?** Частично. Для многих популярных систем есть готовые модули, а для остальных подключаются через HTTP-запросы и вебхуки. Если основной набор инструментов российский, стоит сравнить с [[Albato (термин)|Albato]].
