# Mistral

**Категория:** [[Глоссарий — AI и LLM]]
**URL:** nikalimp.ru/glossary/mistral

## Определение

Mistral — это семейство языковых моделей французской компании Mistral AI, часть из которых опубликована с открытыми весами, а часть доступна только через API и в чат-приложении.

Mistral AI основана в 2023 году в Париже выходцами из крупных исследовательских команд. Первой заметной моделью стала Mistral 7B: она была небольшой, но по качеству превосходила более крупные модели прошлого поколения, а лицензия Apache 2.0 разрешила свободно использовать её, в том числе в коммерческих проектах. Позже вышли модели на архитектуре «смесь экспертов» (Mixtral): в ней для каждого запроса включается лишь часть параметров, поэтому модель работает быстрее при высоком качестве.

Компания работает по двум направлениям. Одни модели публикуют с открытыми весами ([[Open weights]]), и их можно скачать и запустить у себя. Другие, самые мощные, предоставляют только через платформу и API. У Mistral есть и собственный чат-ассистент Le Chat.

### Чем интересна Mistral
- Компактные модели с хорошим качеством, которые можно запустить на сравнительно скромном оборудовании.
- Свободные лицензии у части моделей, что удобно для коммерческих проектов.
- Европейская юрисдикция компании: для некоторых заказчиков это важно с точки зрения правил обработки данных.
- Хорошая работа с несколькими европейскими языками и с кодом.

### Пример
Небольшая студия хочет сделать внутреннего помощника для сотрудников и не отправлять документы во внешние облака. Разработчик скачивает открытую версию Mistral, запускает через [[Ollama (термин)|Ollama]] на сервере и подключает базу знаний. Получается свой ассистент без передачи данных третьим сторонам.

### Чем отличается от Llama
Обе линейки популярны в сообществе и подходят для запуска у себя. Главное отличие — условия: у части моделей Mistral лицензия Apache 2.0, которая считается свободной, а [[Llama]] выходит по собственной лицензии Meta с условиями. Конкретные версии нужно проверять по странице модели, так как лицензии на разные релизы могут отличаться.

### Как проверить, подходит ли модель
1. Определите задачу: чат, классификация, извлечение данных, код.
2. Возьмите 20–30 типовых запросов из своей работы.
3. Прогоните их через несколько моделей, включая Mistral.
4. Сравните качество, скорость и стоимость запуска.
5. Проверьте лицензию выбранной версии.

Ещё одно практическое замечание: компактные модели подходят для задач, где важна скорость и низкая цена запроса, например классификации обращений или извлечения данных из текста. Для длинных рассуждений и сложного анализа выбирайте более крупные версии и сравнивайте результаты.

### Частый вопрос
**Mistral — это open-source?** Частично. Некоторые модели опубликованы с открытыми весами и свободной лицензией, но самые мощные доступны только по API. Поэтому для каждой конкретной модели смотрите, под какой лицензией она выходит.
