## Определение

NLWeb — открытый проект Microsoft, который позволяет добавить на сайт диалоговый интерфейс на естественном языке и открыть контент сайта для AI-агентов.

NLWeb опирается на данные, которые у сайтов уже есть, — микроразметку Schema.org и RSS, и работает как MCP-сервер. Проект показывает, куда движется веб: сайты становятся источниками структурированных ответов для агентов.

### История проекта
Microsoft анонсировала NLWeb в мае 2025 года на конференции Build. Автор проекта — Раманатан Гуха, один из создателей RSS, RDF и Schema.org. Он предложил сделать для диалоговых интерфейсов то же, что HTML сделал для документов: общий открытый стандарт. Код проекта выложили на GitHub. В числе первых партнёров были издатели, интернет-магазины и сервисы с большими каталогами.

### Как работает NLWeb
- Берёт структурированные данные, которые на сайте уже есть: Schema.org, RSS, товарные фиды.
- Загружает их в векторную базу и подключает выбранную языковую модель.
- Отвечает на вопросы посетителей обычным языком: «какие кроссовки есть до 8000 рублей?».
- Каждый экземпляр NLWeb работает как MCP-сервер, поэтому AI-агенты могут обращаться к сайту напрямую.
- Ответы возвращаются в формате Schema.org, то есть остаются машиночитаемыми.

### Кому это нужно
NLWeb подходит сайтам с большим объёмом структурированного контента: каталогам, медиа, базам знаний, сайтам с рецептами или событиями. Для небольшого сайта услуг выгоднее начать с основы — качественной микроразметки и llms.txt. Если эта основа есть, подключить NLWeb позже будет проще.

### Как подготовиться уже сейчас
1. Проверьте полноту микроразметки: товары, услуги, статьи, события, FAQ.
2. Поддерживайте RSS или фид с актуальными данными.
3. Убедитесь, что данные в разметке совпадают с текстом страниц.

### Что важно понимать
Проект молодой, и стандарт продолжает меняться. Но направление показательное: сайты превращаются из набора страниц в источник ответов для людей и агентов. Микроразметка, которая раньше нужна была только для сниппетов, становится интерфейсом сайта для AI.
