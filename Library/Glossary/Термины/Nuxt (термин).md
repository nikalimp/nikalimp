## Определение

Nuxt — это фреймворк на основе [[Vue]], который добавляет к библиотеке серверный рендеринг, маршрутизацию по файлам и генерацию статических страниц. Это то же самое для Vue, чем [[Next.js (термин)|Next.js]] является для React.

Vue сам по себе собирает интерфейс в браузере. Nuxt берёт на себя инфраструктуру: страницы создаются как файлы в папке `pages`, адреса строятся автоматически, а данные можно загружать на сервере до отправки страницы в браузер. Поэтому поисковые роботы получают готовый HTML с текстом, а пользователь видит контент быстрее, чем в обычном [[SPA]].

Nuxt поддерживает несколько режимов. Можно рендерить страницу на сервере при каждом запросе ([[SSR]]), заранее собрать статические страницы ([[SSG]]) или смешать подходы: главная страница статическая, личный кабинет рендерится в браузере. Фреймворк с открытым кодом работает на Node.js, а также умеет собираться для облачных платформ и serverless-окружений.

Nuxt давно развивается как открытый проект с большим сообществом. Он особенно популярен в России и странах СНГ среди команд, которые выбрали Vue как основной инструмент. Для заказчика важны два следствия: сайт индексируется как обычный, а разработчиков на Vue и Nuxt найти проще, чем кажется, и это снижает риск остаться без поддержки.

### Как выбрать между Nuxt и Next.js
1. Посмотрите, на чём пишет команда. Vue — Nuxt, React — Next.js.
2. Оцените, какие библиотеки интерфейса нужны. Экосистема React больше, у Vue проще порог входа.
3. Проверьте требования к хостингу: оба фреймворка запускаются на Node.js.
4. Если сайт контентный и должен хорошо индексироваться, подойдут оба, а выбор определяет привычка команды.

### Что даёт Nuxt из коробки
- Автоматическая маршрутизация по структуре папок.
- Автоимпорт компонентов и функций.
- Серверный рендеринг и генерация статики.
- Модули для SEO, изображений, шрифтов и аналитики.
- Серверные маршруты для собственного API.

### Типичные ошибки
- Включён только клиентский рендеринг, и SEO-преимущество теряется.
- Обращение к браузерным объектам (`window`, `document`) в коде, который выполняется на сервере.
- Слишком много модулей замедляют сборку и увеличивают размер страниц.

### Частый вопрос
**Подходит ли Nuxt для сайта компании?** Да. Он хорошо справляется с лендингами, блогами и каталогами: страницы индексируются, быстро загружаются и легко масштабируются. Если команда уже работает с Vue, Nuxt логичный выбор.
