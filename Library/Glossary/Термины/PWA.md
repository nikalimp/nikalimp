# PWA

**English:** Progressive Web App
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/pwa

## Определение

PWA (Progressive Web App, прогрессивное веб-приложение) — это сайт, который ведёт себя как мобильное приложение: устанавливается на экран телефона, открывается без адресной строки, умеет работать без интернета и отправлять уведомления.

Технически PWA — обычный сайт с тремя добавками: HTTPS, файл манифеста и service worker. Манифест — небольшой [[JSON]]-файл с названием, иконками и цветами приложения. Service worker — скрипт, который работает в фоне, перехватывает сетевые запросы, хранит нужные файлы в кэше и принимает push-уведомления. Благодаря этому сайт открывается мгновенно и после первой загрузки может работать офлайн.

Главное преимущество: не нужно публиковаться в магазинах приложений и писать отдельный код под iOS и Android. Один сайт работает везде, а пользователь ставит его в два нажатия. Для бизнеса это дешёвый способ получить значок на экране смартфона. Правда, возможности зависят от браузера и системы: на iPhone часть функций, например push-уведомления, поддерживается с ограничениями.

Установить PWA можно прямо из браузера: Chrome и Edge показывают кнопку «Установить», а в Safari на iPhone нужно выбрать «На экран Домой». После установки на экране появляется значок с названием и иконкой сайта. Для пользователя это выглядит как обычное приложение, при этом обновления приходят автоматически вместе с сайтом.

### Что нужно для PWA
1. Сайт отдаётся по [[HTTPS]].
2. Есть файл манифеста с названием, иконками разных размеров и режимом отображения.
3. Подключён service worker с логикой кэширования.
4. Сайт адаптивен под смартфон, см. [[Адаптивная вёрстка]].
5. Проверка в Lighthouse: инструмент оценивает соответствие критериям PWA.

### Кому и когда это нужно
PWA подходит сервисам, которыми пользуются регулярно: личные кабинеты, трекеры, магазины, внутренние инструменты. Для разового лендинга или визитки она избыточна.

### Типичные ошибки
- Кэшируют всё подряд, и пользователь видит устаревшие данные.
- Нет страницы для офлайн-режима, и вместо неё браузерная ошибка.
- Иконки только одного размера, из-за чего значок выглядит размыто.
- Просят разрешение на уведомления сразу при заходе, не объяснив зачем.

### Частый вопрос
**Заменит ли PWA нативное приложение?** Для многих задач да: каталог, личный кабинет, заказ, уведомления. Но если нужен глубокий доступ к функциям устройства или обязательно присутствие в App Store и RuStore, понадобится полноценное приложение.
