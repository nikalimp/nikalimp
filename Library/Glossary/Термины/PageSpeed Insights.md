# PageSpeed Insights

**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/pagespeed-insights

## Определение

PageSpeed Insights (PSI) — это бесплатный сервис Google, который измеряет скорость загрузки страницы и даёт рекомендации по её ускорению. Он показывает отдельные результаты для мобильных устройств и компьютеров.

Сервис объединяет два источника данных. Первый — полевые данные: реальные замеры пользователей Chrome за последние 28 дней из отчёта Chrome UX Report. Они есть, только если у страницы достаточно посещений. Второй — лабораторные данные: тест, который запускает [[Lighthouse (термин)|Lighthouse]] в искусственных условиях. Он работает для любой страницы, но его результаты отличаются от реальных.

Основу составляют показатели [[Core Web Vitals]]: [[LCP]] — скорость появления главного контента, [[INP]] — отклик на действия, [[CLS]] — стабильность макета. Также отображаются TTFB и общая оценка по шкале от 0 до 100. Ниже идёт список проблем: тяжёлые изображения, блокирующие скрипты, неиспользуемый код.

У сервиса есть ограничения. Лабораторный тест запускается на одном условном устройстве с заданной скоростью сети, поэтому он не повторяет всё многообразие реальных телефонов. Сайты с большим трафиком получают данные по реальным пользователям, и именно им стоит доверять в первую очередь. Лабораторные цифры нужны, чтобы найти причину проблемы и проверить исправление.

### Как проверить страницу
1. Откройте сервис и вставьте адрес страницы.
2. Дождитесь результата и сначала посмотрите вкладку «Мобильные».
3. Изучите блок с полевыми данными, если он есть: это то, что видят реальные люди.
4. Пройдитесь по списку рекомендаций и начните с тех, что дают больше всего экономии.
5. После исправлений проверьте страницу ещё раз и сравните результат.

### Как читать оценку
Цвета: зелёный — хорошо, оранжевый — нужно улучшить, красный — плохо. Не гонитесь за 100 баллов любой ценой. Для бизнеса важнее, чтобы реальные пользователи видели показатели в зелёной зоне.

### Типичные ошибки
- Проверяют только главную, хотя тормозить могут карточки и статьи.
- Ориентируются на один замер: результат колеблется от запуска к запуску.
- Смотрят на десктоп, когда основная аудитория на смартфонах.
- Жертвуют контентом и дизайном ради лишних баллов.

### Частый вопрос
**Влияет ли оценка PageSpeed Insights на позиции в поиске?** Не сама оценка, а скорость и удобство страниц. Google использует Core Web Vitals как один из сигналов, но он не главный: релевантность контента важнее. Для Яндекса скорость тоже имеет значение, его инструменты показывают похожие метрики в Вебмастере.
