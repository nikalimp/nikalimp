# Pantone

**Категория:** [[Глоссарий — Графический дизайн и бренд]]
**URL:** nikalimp.ru/glossary/pantone

## Определение

Pantone — это система стандартизации цвета, созданная американской компанией Pantone: каждому оттенку присвоен номер, по которому печатник и дизайнер получают один и тот же цвет в разных типографиях.

Основная система называется Pantone Matching System (PMS). Цвета в ней — это готовые смешанные краски, которые называют плашечными. Типография не смешивает их из голубой, пурпурной, жёлтой и чёрной ([[CMYK]]), а берёт готовую краску или замешивает её по рецепту. Поэтому цвет получается точнее и стабильнее, особенно для яркого, металлизированного или флуоресцентного оттенка, которого CMYK передать не может.

Номер записывают с буквой. «Pantone 185 C» означает красный на мелованной бумаге (coated), «U» — на немелованной (uncoated). Один и тот же оттенок на разной бумаге выглядит по-разному, поэтому буква важна. Пользуются системой с веерами образцов: по нему сверяют цвет вживую, а не по экрану.

### Пример
У компании фирменный красный. В брендбуке указан Pantone 185 C, рядом приведены значения для экрана ([[HEX]] и [[RGB]]) и для обычной печати (CMYK). Визитки печатают плашечной краской, баннер на сайте использует HEX, листовки на офсете идут в CMYK, и цвет везде узнаваем.

### Как использовать Pantone
1. Выберите оттенок по образцам, а не на мониторе: экран искажает цвет.
2. Запишите номер с буквой покрытия в [[Брендбук|брендбуке]].
3. Для сайта и презентаций возьмите ближайшие значения в RGB и HEX из каталога.
4. Для обычной печати уточните эквивалент в CMYK; он будет приближённым.
5. Обсудите с типографией, можно ли печатать плашечной краской и сколько это добавит к стоимости.

### Типичные ошибки
- Считать, что цвет на экране совпадёт с эталоном: мониторы по-разному показывают оттенки.
- Не указывать тип покрытия, C или U.
- Требовать от полноцветной печати точного совпадения с плашкой: цвета из CMYK передаются приближённо.
- Заказывать плашечную краску для маленького тиража, когда достаточно CMYK.
- Забывать, что у каждой типографии свои возможности и профили.

### Чем отличается от CMYK
CMYK смешивает цвет из четырёх красок и подходит для фото и сложных изображений. Pantone даёт точный отдельный цвет, поэтому его выбирают для логотипов и фирменных оттенков. Часто используют оба: CMYK для общей печати, Pantone для главного цвета бренда.

### Частый вопрос
**Что такое «цвет года» Pantone?** Это оттенок, который компания ежегодно объявляет трендовым. Он задаёт настроение сезона в моде и дизайне, но для бренда не обязателен: фирменный цвет выбирают исходя из позиционирования, а не из тренда одного года.
