# Query fan-out

**English:** Query Fan-out
**Категория:** [[Глоссарий — GEO и AI-поиск]]
**URL:** nikalimp.ru/glossary/query-fan-out

## Определение

Query fan-out — техника генеративного поиска, при которой система разбивает вопрос пользователя на множество подзапросов, ищет по каждому отдельно и объединяет найденное в один ответ.

Например, вопрос «как выбрать CRM для агентства» может превратиться в подзапросы о ценах, интеграциях, отзывах и сравнении конкретных систем. Google прямо описывает этот подход в AI Mode. Для GEO вывод простой: тему нужно покрывать широко, отвечая на подвопросы, а не только на главный запрос.

### Откуда взялся термин
Слово fan-out пришло из инженерии: так называют один сигнал, который расходится на много выходов, как веер. Google использовал термин публично на конференции I/O в мае 2025 года, когда описывал, как устроен AI Mode. Похожим образом работают Perplexity, ChatGPT с поиском и режимы глубокого исследования, хотя каждая компания называет механизм по-своему.

### Как работает fan-out
1. Система получает вопрос и определяет, из каких частей он состоит.
2. Генерирует подзапросы: уточнения, синонимы, сравнения, связанные темы. Пользователь их не видит.
3. Ищет по каждому подзапросу параллельно, иногда по десяткам сразу.
4. Отбирает лучшие фрагменты из результатов.
5. Собирает итоговый ответ и указывает источники.

### Пример
Запрос: «Где сделать сайт для стоматологии в Казани с записью онлайн?». Подзапросы: «стоимость сайта для клиники», «онлайн-запись на сайт стоматологии», «требования к медицинским сайтам», «веб-студии Казань отзывы», «сайт на Tilda или на коде для клиники». Источники для ответа приходят из разных подзапросов.

### Что это значит для контента
- Одна страница под главный запрос не закрывает тему.
- Нужны разделы и страницы под подвопросы: цена, сроки, сравнение, требования, ошибки.
- Каждый раздел должен быть понятен отдельно.
- Внешние упоминания тоже важны: подзапрос «отзывы» приведёт на агрегаторы, а не на сайт компании.

Подвопросы удобно собирать в ходе промпт-исследования и закрывать кластером страниц.
