# Radix UI

**См. также:** [[Radix UI]]

## Определение

Radix UI — это библиотека готовых «безголовых» (headless) компонентов для React: выпадающих меню, диалогов, вкладок, переключателей и других элементов интерфейса. Она отвечает за поведение и доступность, а внешний вид оставляет вам.

Сложные элементы интерфейса только кажутся простыми. Выпадающий список должен открываться с клавиатуры, возвращать фокус, закрываться по Esc, правильно читаться экранными программами. Radix реализует всё это внутри компонентов, но не навязывает стили: компонент выглядит так, как вы его оформите с помощью [[CSS]] или [[Tailwind CSS (термин)|Tailwind CSS]]. Отсюда название «безголовый»: есть логика без готового оформления.

Библиотека построена на [[React (термин)|React]] и состоит из отдельных пакетов: можно подключить только нужный компонент, и остальной код не попадёт на страницу. Radix поддерживает управление с клавиатуры и атрибуты ARIA, которые нужны для [[WCAG]].

На Radix построен популярный набор [[shadcn-ui]]: его компоненты — это оформленные Radix-примитивы, которые копируются в проект и правятся под себя.

Компоненты Radix устроены как набор мелких частей: у диалога есть корневой элемент, триггер, содержимое, заголовок и кнопка закрытия. Их можно комбинировать и оформлять независимо. Такой подход называют составными компонентами, он даёт гибкость без потери предсказуемого поведения.

### Пример
Диалоговое окно из Radix само ловит фокус внутри себя, закрывается по клавише Esc и блокирует прокрутку страницы за собой. Разработчику остаётся задать цвета, отступы и анимацию.

### Чем отличается от готовых UI-китов
Готовые наборы (Material UI, Ant Design) дают и логику, и фиксированный дизайн, который трудно изменить. Radix даёт только логику и доступность, а дизайн вы делаете сами. Это удобно, когда у проекта собственная дизайн-система.

### Типичные ошибки
- Стилизуют компонент так, что пропадает видимый фокус.
- Заменяют внутренние части своими, нарушая доступность.
- Подключают много компонентов, не используя их.
- Забывают подписи (label) и текстовые описания у кнопок-иконок.

### Частый вопрос
**Нужно ли знать Radix, если вы используете shadcn/ui?** Для старта нет: shadcn/ui скрывает детали. Но когда нужно поменять поведение компонента или разобраться с ошибкой, знание Radix пригодится, потому что именно он работает внутри.
