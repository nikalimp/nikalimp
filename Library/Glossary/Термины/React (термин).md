## Определение

React — это JavaScript-библиотека для создания пользовательских интерфейсов из независимых компонентов. Её разработала компания Facebook (ныне Meta), открытый код вышел в 2013 году.

Основная идея: интерфейс собирается из [[Компонент|компонентов]] — небольших кусков кода, каждый из которых отвечает за свою часть страницы. Кнопка, карточка товара, форма, шапка сайта — всё это компоненты, которые можно переиспользовать. Разработчик описывает, как должен выглядеть интерфейс при определённых данных, а React сам обновляет только изменившиеся элементы. Для этого используется виртуальный DOM: библиотека сравнивает старую и новую версии и вносит минимальные изменения.

Код компонентов пишут на [[JavaScript]] или [[TypeScript (термин)|TypeScript]] с разметкой JSX, которая похожа на HTML. Состояние компонента хранится в хуках, например `useState`.

React сам по себе рисует интерфейс в браузере. Для готового сайта к нему добавляют фреймворки: [[Next.js (термин)|Next.js]] обеспечивает маршрутизацию и серверный рендеринг. Это важно для SEO, потому что чистое React-приложение отдаёт браузеру почти пустой HTML.

React — самая распространённая библиотека для интерфейсов, вокруг неё сложилась огромная экосистема: библиотеки маршрутизации, форм, анимаций, наборы готовых компонентов. Благодаря этому разработчиков найти проще, а для типовых задач есть готовые решения. Обратная сторона — нужно самому выбирать подходящие инструменты и следить за их совместимостью.

### Пример
Интернет-магазин: компонент `ProductCard` получает название, цену и фото и рисует карточку. Каталог просто вызывает его для каждого товара в списке. Изменили `ProductCard` — карточки обновились везде.

### Кому и когда нужен React
- Веб-сервисам и личным кабинетам с богатой интерактивностью.
- Проектам, где интерфейс много раз используется и меняется.
- Командам, которым нужна большая экосистема готовых библиотек.

Для лендинга из пяти блоков React чаще избыточен: хватит статического HTML и немного скриптов.

### Типичные ошибки
- Рендерят всё в браузере и теряют SEO.
- Лишние перерисовки из-за неправильной работы с состоянием.
- Тяжёлые зависимости на каждую мелочь, из-за чего растёт размер страницы.
- Игнорируют доступность: кликабельные блоки без кнопок и ссылок.

### Частый вопрос
**React — это фреймворк?** Формально нет, это библиотека: она отвечает только за интерфейс. Маршрутизацию, сборку и серверную часть вы подключаете отдельно или берёте готовый фреймворк, например Next.js.
