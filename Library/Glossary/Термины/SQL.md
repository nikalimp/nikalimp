# SQL

## Определение

SQL (Structured Query Language, язык структурированных запросов) — это язык для работы с реляционными [[База данных|базами данных]]: он позволяет выбирать, добавлять, изменять и удалять данные в таблицах.

Язык появился в 1970-х в компании IBM и стал международным стандартом. Его используют [[MySQL (термин)|MySQL]], [[PostgreSQL (термин)|PostgreSQL]], SQLite, Microsoft SQL Server, Oracle и другие системы. Диалекты немного отличаются, но базовые команды везде похожи.

SQL декларативен: вы описываете, какие данные нужны, а не то, как их искать. База сама выбирает способ выполнения. Запросы читаются почти как английские фразы, поэтому язык осваивают не только разработчики, но и аналитики и маркетологи, которые выгружают данные для отчётов.

Даже если вы не пишете код, навык простых запросов пригодится. Многие сервисы аналитики и BI-системы позволяют использовать SQL для выгрузок: сколько клиентов пришло за месяц, какой средний чек, какие товары покупают вместе. Это быстрее, чем просить разработчика делать выгрузку под каждый вопрос.

### Основные команды
- `SELECT` — выбрать данные.
- `INSERT` — добавить строку.
- `UPDATE` — изменить существующие строки.
- `DELETE` — удалить строки.
- `JOIN` — соединить данные из разных таблиц.
- `WHERE`, `GROUP BY`, `ORDER BY` — условия, группировка и сортировка.

### Пример
Запрос `SELECT city, COUNT(*) FROM orders GROUP BY city ORDER BY COUNT(*) DESC` покажет, из каких городов поступает больше всего заказов. Для маркетолога это быстрый способ понять географию продаж.

### Как начать учить SQL
1. Поставьте SQLite или откройте онлайн-песочницу.
2. Создайте таблицу и добавьте в неё несколько строк.
3. Потренируйтесь в `SELECT` с условием `WHERE`.
4. Освойте `JOIN` на двух связанных таблицах.
5. Затем перейдите к группировкам и подзапросам.

### Типичные ошибки
- `UPDATE` или `DELETE` без `WHERE`: меняются или удаляются все строки.
- Подстановка пользовательского ввода прямо в запрос: уязвимость SQL-инъекции.
- `SELECT *` в рабочем коде вместо нужных полей.
- Отсутствие индексов на колонках, по которым ищут.

### Частый вопрос
**SQL — это база данных?** Нет, это язык. База данных, например PostgreSQL, хранит информацию, а SQL — способ с ней общаться. Если нужен не табличный подход, посмотрите на [[NoSQL]].
