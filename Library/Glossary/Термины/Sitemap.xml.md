# Sitemap.xml

**English:** XML Sitemap
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/sitemap-xml

## Определение

Sitemap.xml — это файл со списком адресов страниц сайта в формате XML, который помогает поисковым роботам быстрее находить и индексировать нужные страницы.

Файл лежит в корне сайта, например `https://site.ru/sitemap.xml`. Он не гарантирует, что страницы попадут в индекс, но сообщает роботу: «Вот страницы, которые важны, и вот когда они менялись». Особенно полезен для новых сайтов, больших проектов и сайтов с плохой внутренней перелинковкой.

Один файл может содержать до 50 000 адресов и весить до 50 МБ без сжатия. Если страниц больше, создают несколько файлов и общий индексный файл со ссылками на них.

### Пример
```
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://site.ru/uslugi/</loc>
    <lastmod>2026-10-15</lastmod>
  </url>
</urlset>
```
Поле `loc` обязательно, `lastmod` — дата последнего изменения, её указывают, если она точная.

### Как подключить
1. Сгенерируйте файл средствами CMS, плагином или скриптом сборки сайта.
2. Включите в него только страницы, которые нужны в поиске: с кодом 200, без [[Noindex]], без редиректов и с адресом по [[Canonical]].
3. Положите файл в корень сайта и проверьте, что он открывается в браузере.
4. Добавьте строку `Sitemap: https://site.ru/sitemap.xml` в [[robots.txt (термин)|robots.txt]].
5. Отправьте файл в [[Яндекс Вебмастер (термин)|Яндекс Вебмастер]] и [[Google Search Console (термин)|Google Search Console]] и следите за отчётом об ошибках.

### Типичные ошибки
- В файле остаются удалённые, закрытые и перенаправляемые адреса.
- Указаны адреса с http вместо https или без www, когда сайт работает иначе.
- Файл не обновляется после добавления страниц.
- В файл попали служебные страницы, фильтры и дубли.

### Чем отличается от HTML-карты сайта
[[Карта сайта]] в HTML — страница для людей, помогающая ориентироваться. Sitemap.xml предназначен для роботов, пользователь его обычно не видит. На сайте могут быть обе.

### Кому и когда это нужно
Файл особенно полезен новым сайтам, у которых мало внешних ссылок, интернет-магазинам с тысячами карточек, сайтам с большой вложенностью и проектам, где страницы часто добавляются. После запуска или переезда отправьте sitemap в Вебмастер и Search Console, чтобы поисковики быстрее обошли новые адреса и показали отчёт о найденных проблемах.

### Частый вопрос
**Обязателен ли sitemap.xml?** Нет, но он рекомендован. Небольшой сайт с хорошей перелинковкой индексируется и без него, а для новых и крупных сайтов файл заметно ускоряет обнаружение страниц.
