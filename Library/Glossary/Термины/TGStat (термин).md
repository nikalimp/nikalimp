## Определение

TGStat — это российский сервис аналитики и каталог Telegram-каналов: он собирает данные о публичных каналах, показывает динамику подписчиков, охваты, вовлечённость и помогает искать площадки для рекламы.

Сервис ведёт открытую базу публичных каналов и чатов, раскладывает их по тематикам и странам и формирует рейтинги. Для каждого канала доступны график роста аудитории, средний охват публикации, показатель [[ER]], цитируемость, частота публикаций и история рекламных постов. Есть поиск по каналам, по упоминаниям и по тексту публикаций, а также инструменты для владельцев каналов и платные тарифы с расширенной статистикой.

Основные пользователи — рекламодатели и агентства, которые подбирают каналы для закупа, и администраторы, которые анализируют собственный рост. Сервис помогает быстро отсеять слабые площадки: резкие скачки подписчиков, низкий охват при большой аудитории, подозрительные источники роста. При этом данные сервиса — внешняя оценка. Точные цифры видит только владелец канала в статистике самого Telegram, поэтому перед покупкой рекламы запрашивайте скриншоты внутренней статистики.

### Как проверять канал перед закупом
1. Откройте карточку канала и посмотрите график подписчиков: рост должен быть плавным, без внезапных скачков.
2. Сравните охват публикации с числом подписчиков: у живого канала охват составляет заметную долю аудитории.
3. Проверьте ER и динамику реакций.
4. Посмотрите историю рекламных постов: частоту, соседние рекламодатели, эффект на охват.
5. Запросите у владельца подтверждение статистики из самого Telegram.
6. Сверьте данные с другим сервисом, например [[Telemetr (термин)]].

### Чем отличается от Telemetr
Оба сервиса собирают публичные данные и ведут каталоги. Различаются набором метрик, оформлением и алгоритмами оценки. Многие специалисты проверяют каналы сразу в нескольких сервисах и сравнивают результаты.

### Типичные ошибки
- Верить одному показателю, например числу подписчиков.
- Игнорировать вовлечённость при выборе канала.
- Покупать рекламу без запроса внутренней статистики.
- Считать, что высокое место в рейтинге гарантирует продажи.
- Не учитывать тематику и аудиторию, подходящую вашему продукту.

### Какие данные недоступны
Сервис не видит закрытые каналы и не знает точных цифр внутренней статистики: источники переходов, реальный охват по часам, точный состав аудитории. Эти данные есть только у администратора. Поэтому для серьёзного бюджета полагайтесь на комбинацию внешних сервисов, скриншотов и пробной публикации.

### Частый вопрос
**Можно ли доверять статистике TGStat полностью?** Нет. Это оценка по открытым данным, она хорошо показывает тенденции, но не заменяет внутреннюю статистику канала. Для решения о закупе сочетайте внешний сервис, скриншоты из Telegram и пробное размещение небольшого бюджета.
