## Определение

Tailwind CSS — это CSS-фреймворк, в котором оформление собирают прямо в HTML из готовых коротких классов: `flex`, `p-4`, `text-lg`, `bg-white`. Вместо отдельного файла стилей с придуманными названиями вы описываете вид элемента набором мелких классов.

Фреймворк появился в 2017 году, его автор — Адам Уотан. Подход называют utility-first: каждый класс отвечает за одно свойство — отступ, цвет, размер шрифта. Из таких «кирпичиков» собирается любой интерфейс. Лишние классы при сборке удаляются, поэтому итоговый [[CSS]]-файл получается небольшим.

Tailwind не даёт готовых компонентов вроде красивой кнопки или карточки. Он даёт систему значений: шкалу отступов, палитру, размеры шрифтов, точки [[Брейкпоинт|перелома]] для адаптива. Значения можно менять под фирменный стиль в файле настроек. Поэтому он хорошо сочетается с [[Дизайн-система|дизайн-системами]] и библиотеками компонентов вроде [[shadcn-ui]].

### Пример
Кнопка в Tailwind:

`<button class="rounded-lg bg-blue-600 px-4 py-2 text-white hover:bg-blue-700">Отправить</button>`

Здесь скругление, фон, отступы, цвет текста и состояние при наведении заданы классами. Адаптив делают префиксами: `md:flex` включает flex-раскладку от ширины планшета.

### Чем отличается от Bootstrap
Bootstrap даёт готовые компоненты с узнаваемым видом: `btn`, `card`, `navbar`. Tailwind даёт только низкоуровневые классы, а внешний вид вы определяете сами. Сайты на Tailwind меньше похожи друг на друга, но требуют больше решений от разработчика.

### Типичные ошибки
- Длинные цепочки классов копируют по страницам вместо вынесения в [[Компонент]].
- Придумывают произвольные значения (`mt-[13px]`) вместо шкалы, и интерфейс теряет ритм.
- Не настраивают палитру и шрифты под бренд, и сайт выглядит «шаблонно».
- Ждут, что фреймворк сам сделает дизайн: он ускоряет вёрстку, но не заменяет макет.

### Кому и когда это нужно
Tailwind удобен командам, которые строят интерфейсы из компонентов на [[React (термин)|React]], Vue или [[Next.js (термин)|Next.js]]. Для сайта-визитки на конструкторе он не нужен.

### Частый вопрос
**Tailwind CSS — это замена CSS?** Нет. Tailwind генерирует обычный CSS, просто вы пишете его в виде классов в разметке. Знание CSS нужно всё равно: без понимания flex, grid и позиционирования с Tailwind быстро запутаешься.
