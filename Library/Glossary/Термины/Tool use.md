# Tool use

**English:** Tool Use
**Категория:** [[Глоссарий — AI и LLM]]
**URL:** nikalimp.ru/glossary/tool-use

## Определение

Tool use (использование инструментов) — это способность языковой модели вызывать внешние инструменты: поиск, калькулятор, базу данных, календарь, API сервисов, чтобы получить данные или выполнить действие, которых нет у неё самой.

Сама по себе модель умеет только работать с текстом. Она не знает сегодняшних новостей, плохо считает большие числа и не может отправить письмо. Инструменты закрывают эти пробелы. Разработчик описывает модели список доступных функций: название, назначение и параметры. Когда модель понимает, что для ответа нужен инструмент, она не отвечает сразу, а формирует вызов: «запусти поиск с таким запросом». Приложение выполняет вызов и возвращает результат модели. Та читает его и формулирует итоговый ответ или делает следующий вызов.

Технически этот механизм часто называют [[Function calling]]. Tool use — более широкое понятие: оно описывает общую идею, а function calling — конкретный способ её реализации в API. Для стандартизации подключения инструментов появился протокол [[MCP]], через который ассистенты работают с внешними сервисами одним способом.

### Пример
Вы спрашиваете ассистента: «Какие у меня встречи завтра и сколько между ними свободного времени?» Модель вызывает инструмент календаря, получает список встреч, считает промежутки и отвечает. Без инструмента она могла бы только выдумать ответ.

### Какие бывают инструменты
- Веб-поиск и чтение страниц.
- Запросы к базам данных и CRM.
- Выполнение кода и расчёты.
- Работа с файлами и документами.
- Отправка писем, создание задач, запись в календарь.

### Зачем это нужно
Tool use превращает чат-бот в рабочего помощника: он не только советует, но и делает. Это основа [[AI-агент|AI-агентов]], которые решают задачи из нескольких шагов, сами выбирая, что вызвать и в каком порядке.

### Риски и меры защиты
1. Давайте модели только нужные инструменты и минимальные права.
2. Для необратимых действий (платёж, удаление, отправка) требуйте подтверждения человека.
3. Проверяйте входные данные: вредный текст на странице способен подсказать модели опасное действие ([[Prompt injection]]).
4. Ведите журнал вызовов, чтобы разбирать ошибки.

### Типичные ошибки
- Описывать инструмент расплывчато, поэтому модель вызывает его невпопад.
- Давать слишком много инструментов сразу.
- Не обрабатывать ошибки сервиса, и модель продолжает работу с пустым результатом.

### Частый вопрос
**Tool use и function calling — это одно и то же?** Почти. Tool use — общая идея того, что модель пользуется внешними инструментами. Function calling — конкретный механизм в API, при котором модель возвращает структурированный вызов функции. На практике термины часто употребляют как синонимы.
