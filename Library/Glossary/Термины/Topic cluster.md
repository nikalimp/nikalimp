# Topic cluster

**English:** Topic Cluster
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/topic-cluster

## Определение

Topic cluster (тематический кластер) — это группа связанных страниц сайта, где одна опорная страница раскрывает широкую тему, а несколько дочерних разбирают её частные вопросы, и все они связаны внутренними ссылками.

Подход помогает поисковикам понять, что сайт глубоко разбирает тему, а читателям — удобно переходить от общего к частному. Он родился из того, что поиск стал оценивать не отдельные ключевые слова, а смысл и полноту тематики. Вместо десятка разрозненных статей сайт получает структуру, в которой каждый материал усиливает остальные.

### Из чего состоит кластер
- **Опорная страница.** Широкий обзор темы, см. [[Pillar page]].
- **Дочерние страницы.** Подробные статьи по подтемам: «как», «что такое», «сравнение», «ошибки».
- **Внутренние ссылки.** Опорная ссылается на каждую дочернюю, а каждая дочерняя — на опорную и на соседние по смыслу.

### Пример
Кластер «SEO для сайта услуг». Опорная страница описывает всё направление. Дочерние: «как собрать семантическое ядро», «как написать Title», «что такое sitemap», «как провести аудит». Читатель идёт от общей картины к деталям и обратно.

### Как построить кластер
1. Выберите тему, важную для бизнеса, с достаточным объёмом запросов.
2. Составьте список вопросов, которые задают люди по теме, на основе [[Семантическое ядро|семантического ядра]], подсказок и выдачи.
3. Сгруппируйте вопросы: какие входят в одну страницу, а какие нужны отдельно.
4. Создайте опорную страницу и дочерние материалы.
5. Настройте [[Внутренняя перелинковка|внутренние ссылки]] между ними.
6. Через несколько месяцев проверьте, какие страницы растут, и дополните слабые места.

### Типичные ошибки
- Писать дочерние статьи без ссылок на опорную страницу.
- Создавать несколько страниц под один и тот же запрос: они конкурируют между собой.
- Брать тему слишком широкую для сайта или без связи с бизнесом.
- Оставлять кластер недописанным: опорная страница ссылается на статьи, которых нет.

### Чем отличается от семантического ядра
[[Семантическое ядро]] — список запросов. Topic cluster — структура страниц и ссылок, построенная на этих запросах. Ядро отвечает на вопрос «о чём писать», кластер — «как это организовать».

### Кому и когда это нужно
Кластеры нужны блогам и сайтам услуг, которые строят контент вокруг нескольких важных тем. Они полезны, когда у сайта уже есть набор разрозненных статей и нужно их объединить, а также при планировании контента на несколько месяцев вперёд. Для визитки из трёх страниц такая структура лишняя, а для контентного проекта она становится основой плана.

### Частый вопрос
**Сколько страниц в тематическом кластере?** Обычно опорная страница и от 5 до 15 дочерних, но число определяется темой. Важно, чтобы каждая страница отвечала на отдельный вопрос и ссылалась на остальные.
