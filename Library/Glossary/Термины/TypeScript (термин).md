## Определение

TypeScript — это язык программирования, надстройка над [[JavaScript]], которая добавляет описание типов данных. Код на TypeScript перед запуском превращается в обычный JavaScript, поэтому работает везде, где работает JS.

Язык создала Microsoft, первая версия вышла в 2012 году. Идея простая: вы заранее говорите, что переменная — строка, а функция принимает число и возвращает объект с такими-то полями. Редактор и компилятор проверяют это до запуска и подсвечивают ошибки: опечатку в названии поля, передачу строки вместо числа, обращение к значению, которого может не быть.

Проверка типов работает только при разработке. В браузер или на сервер уходит обычный JavaScript, типов там уже нет. Поэтому TypeScript не защищает от неверных данных, пришедших извне, например из [[API]]: их всё равно нужно проверять отдельно.

### Пример
`function price(total: number, discount: number): number { return total - discount }`

Если вызвать `price("100", 10)`, TypeScript сообщит об ошибке сразу в редакторе. В обычном JavaScript такой вызов дал бы странный результат уже на странице у пользователя.

### Чем отличается от JavaScript
JavaScript проверяет типы во время выполнения и допускает почти любые операции. TypeScript проверяет их при написании кода. Любой корректный JavaScript — это почти всегда допустимый TypeScript, поэтому проект можно переводить постепенно, файл за файлом.

### Типичные ошибки
- Везде ставят тип `any`, и проверка перестаёт что-либо давать.
- Думают, что типы защищают данные из формы или API во время работы сайта.
- Выключают строгий режим, чтобы «не мешали ошибки».

### Кому и когда это нужно
TypeScript окупается в проектах, где код живёт долго и его правят несколько человек: [[Веб-приложение|веб-приложения]], админки, [[SaaS]]. [[Next.js (термин)|Next.js]] и [[React (термин)|React]]-проекты сегодня чаще всего пишут на нём. Для одностраничного лендинга он избыточен.

### Частый вопрос
**Нужно ли учить JavaScript перед TypeScript?** Да. TypeScript строится поверх JavaScript и не отменяет его правил. Сначала освойте основы JS, потом добавляйте типы.
