# Vue

**English:** Vue.js
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/vue

## Определение

Vue (Vue.js) — это JavaScript-фреймворк для создания интерфейсов, который обновляет страницу автоматически при изменении данных. Его выпустил в 2014 году Эван Ю, бывший разработчик Google.

Основная идея — реактивность. Вы описываете данные и шаблон, а Vue следит, чтобы они совпадали: изменили значение в переменной — нужный кусок страницы перерисовался сам, без ручной правки [[HTML]]. Интерфейс собирается из [[Компонент|компонентов]]: каждый хранит свою разметку, логику и стили, часто в одном файле с расширением `.vue`.

Vue можно подключить к готовой странице одним скриптом и оживить отдельный блок. Можно собрать на нём целое одностраничное приложение ([[SPA]]), а с фреймворком Nuxt — сайт с серверным рендерингом ([[SSR]]). Порог входа считается невысоким: шаблоны похожи на обычный HTML.

### Чем отличается от React
Оба решают одну задачу — строят интерфейс из компонентов. [[React (термин)|React]] — библиотека, вокруг которой вы сами выбираете остальные инструменты, и разметка пишется на JSX внутри JavaScript. Vue ближе к «всё в комплекте»: официальные решения для маршрутов и состояния, шаблоны в привычном синтаксисе HTML. Выбор чаще определяется командой и экосистемой, а не техническим превосходством.

### Типичные ошибки
- Берут Vue для простого лендинга, где хватило бы статичной вёрстки.
- Смешивают старый и новый стиль API и получают разнобой в проекте.
- Складывают всё состояние в один компонент вместо общего хранилища.

### Кому и когда это нужно
Vue подходит для личных кабинетов, админок и интерактивных сервисов. В России его используют довольно широко, среди прочего потому что по нему много документации и курсов на русском.

### Частый вопрос
**Что выбрать для нового проекта: Vue или React?** Если команда уже знает один из них, берите его. Если выбор свободный, ориентируйтесь на нужную экосистему: для [[Next.js (термин)|Next.js]] и готовых библиотек компонентов проще React, для быстрого старта с понятными шаблонами подойдёт Vue.
