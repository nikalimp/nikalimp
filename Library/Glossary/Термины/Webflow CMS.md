# Webflow CMS

**Категория:** [[Глоссарий — No-code и CMS]]
**URL:** nikalimp.ru/glossary/webflow-cms

## Определение

Webflow CMS — встроенная в [[Webflow (термин)|Webflow]] система управления контентом: коллекции записей (статьи, кейсы, товары), из которых автоматически собираются страницы по шаблону.

Редактор заполняет поля записи, а дизайн страницы задаётся один раз в шаблоне коллекции. Новая статья появляется на сайте в нужном оформлении без участия дизайнера.

### Как работает
Основа CMS — коллекция, по сути таблица. Каждая запись — строка, каждое поле — столбец. Поля бывают разных типов: текст, форматированный текст, изображение, видео, дата, число, переключатель, ссылка, а также ссылки на записи других коллекций. Через такие ссылки можно связать статью с автором, а кейс — с услугой.

Контент выводится двумя способами:
- шаблон коллекции — у каждой записи своя страница со своим адресом;
- список коллекции — блок на любой странице, который показывает записи с фильтром и сортировкой: «три последних кейса», «статьи по теме».

Записи можно создавать вручную, загружать из CSV или через API. Контентом управляют в Editor, не заходя в редактор дизайна.

### Где применяется
- Блог и база знаний.
- Кейсы и портфолио.
- Каталог услуг, команды, вакансий.
- Глоссарии и справочники — серии похожих страниц по одному шаблону.

Шаблонные страницы удобны для SEO и GEO: у каждой записи свой адрес, заголовок, описание и текст, который читают поисковики и нейросети.

### Ограничения
- Лимиты на число записей, коллекций и полей зависят от тарифа.
- Сложные связи и фильтры собрать трудно.
- При экспорте кода CMS не переносится: остаётся только вёрстка, записи нужно выгружать отдельно.
- Работа зависит от тарифов и доступности Webflow.

### Частый вопрос
Чем Webflow CMS отличается от [[Headless CMS]]? В Webflow контент и дизайн живут на одной платформе. Headless CMS хранит только контент и отдаёт его по API любому фронтенду — например, сайту на [[Next.js (термин)|Next.js]]. Это гибче и не привязывает к одной платформе.

Если коллекции упёрлись в лимиты, контент переносят в собственную админку. Такую систему делают в услуге [админка и дашборд](/services/web-service-development/).
