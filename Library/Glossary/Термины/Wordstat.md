# Wordstat

**English:** Yandex Wordstat
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/wordstat

## Определение

Wordstat (Яндекс Вордстат) — бесплатный сервис Яндекса, который показывает, сколько раз в месяц люди ищут слово или фразу и какие похожие запросы задают.

Сервис работает по адресу wordstat.yandex.ru и требует только аккаунт Яндекса. Это базовый инструмент для оценки спроса в Рунете.

### Как работает
Вводите фразу — Wordstat показывает число показов по ней за последний месяц. Число включает все запросы, в которых есть эта фраза: по «сайт» в статистику попадут и «заказать сайт», и «сайт погоды». Рядом сервис показывает похожие запросы — что ещё ищут люди с той же задачей.

Чтобы получить точную цифру, используют операторы:
- кавычки `"заказать сайт"` — только эта фраза без дополнительных слов;
- восклицательный знак `!сайт` — точная форма слова;
- плюс `+` — учесть служебные слова вроде «на» и «для»;
- минус `-` — исключить слово из подсчёта;
- квадратные скобки — зафиксировать порядок слов.

Отдельно можно посмотреть спрос по регионам, динамику по месяцам и разбивку по устройствам.

### Где применяется
- Сбор [[Семантическое ядро|семантического ядра]] для сайта.
- Выбор тем статей и страниц услуг.
- Оценка спроса на услугу в разных городах.
- Поиск формулировок: какими словами клиенты описывают задачу.
- Сезонность: когда спрос растёт и когда запускать рекламу.

Данные показывают поиск в Яндексе, но хорошо отражают и то, что люди спрашивают у нейросетей. Формулировки из Wordstat помогают составить пул вопросов для проверки видимости бренда в ChatGPT, Алисе и Perplexity.

### Где ошибаются
- Смотрят общую цифру без кавычек и переоценивают спрос в разы.
- Выбирают только частотные запросы и пропускают длинный хвост, где выше доля заявок.
- Не учитывают регион и сезон.

### Что сделать на своём сайте
1. Проверьте основные услуги в кавычках и по своему региону.
2. Выпишите похожие запросы с понятным намерением.
3. Сгруппируйте их по страницам: одна группа — одна страница.
4. Для массовой выгрузки используйте [[Key Collector (термин)|Key Collector]] или похожие инструменты.

Запросы из Wordstat становятся основой и для SEO, и для пула вопросов в [GEO-аудите](/geo-audit/).
