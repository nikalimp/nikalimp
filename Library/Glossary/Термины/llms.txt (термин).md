## Определение

llms.txt — текстовый файл в корне сайта (site.ru/llms.txt) в формате Markdown, который кратко описывает сайт для языковых моделей и даёт ссылки на ключевые страницы.

Формат предложил Джереми Ховард (Answer.AI) в 2024 году по аналогии с robots.txt и sitemap.xml. Структура простая: заголовок с названием, короткое описание в цитате и разделы со списками ссылок и пояснениями.

Важно понимать статус файла: это открытая инициатива, а не стандарт поисковых систем. Крупные AI-сервисы официально не обещают его использовать, но файл недорог в поддержке и помогает AI-агентам и инструментам разработчиков быстро понять структуру сайта. Пример — nikalimp.ru/llms.txt.

### Пример структуры
- Первая строка — заголовок с названием: `# Название компании`.
- Затем цитата с описанием: `> Чем занимается, для кого, где работает`.
- Дальше разделы второго уровня, например `## Услуги` и `## Статьи`.
- В каждом разделе — список ссылок: `- [Разработка лендинга](https://site.ru/services/personal-website/): сроки, цены, состав`.
- В конце может быть раздел `## Optional` со второстепенными страницами, которые модель может пропустить.

### Как сделать файл
1. Опишите компанию в одном-двух предложениях с фактами.
2. Перечислите ключевые страницы по разделам с пояснением в одну строку.
3. Положите файл в корень сайта и проверьте, что он открывается по адресу /llms.txt.
4. Генерируйте файл при сборке сайта из тех же данных, что и страницы, чтобы он не устаревал.
5. Для полного текста страниц добавьте llms-full.txt.

### Типичные ошибки
- Файл не обновляют после изменения цен и услуг.
- В файле есть то, чего нет на сайте.
- Ссылки ведут на редиректы или закрытые страницы.
- Файл отдаётся с неправильной кодировкой, и кириллица превращается в набор символов.

### Кому нужен llms.txt
Сайтам документации и SaaS он помогает в первую очередь: разработчики загружают его в AI-ассистентов. Для сайтов услуг это недорогой элемент AI-ready базы, который входит в стандарт сайтов NikAlimp и генерируется автоматически.

### Частый вопрос
**Заменяет ли llms.txt файл sitemap.xml?** Нет. Sitemap нужен поисковым роботам: в нём все адреса сайта для индексации. llms.txt — короткое описание для языковых моделей с отбором главных страниц и пояснениями. Сайту нужны оба файла.
