# Атрибуция

**English:** Attribution
**Категория:** [[Глоссарий — Маркетинг и аналитика]]
**URL:** nikalimp.ru/glossary/attribution

## Определение

Атрибуция — это определение того, какие рекламные каналы и касания привели клиента к покупке или заявке, и распределение между ними «заслуги» за результат. Она отвечает на вопрос: кому из каналов засчитать продажу.

Путь клиента редко короткий. Человек может увидеть рекламу в Telegram, через неделю найти сайт в поиске, потом вернуться по ссылке из рассылки и оставить заявку. Если всю заслугу отдать последнему касанию, первые два канала окажутся «бесполезными», хотя они привели человека. Правила распределения заслуги называют моделями атрибуции.

Данные для атрибуции собирают через счётчики вроде Яндекс Метрики и Google Analytics 4, UTM-метки и [[CRM]]. Чем точнее эти данные, тем точнее вывод.

### Основные модели
- Первый клик: всё получает канал, с которого человек впервые пришёл.
- Последний клик ([[Last click]]): всё получает последний канал перед конверсией.
- Линейная: заслуга делится поровну между всеми касаниями.
- С учётом давности: ближние ко дню покупки касания получают больше.
- По позиции: больше всего получают первое и последнее касание.
- На основе данных: алгоритм сам оценивает вклад каждого касания по статистике.

### Пример
Клиент увидел пост в Telegram-канале (1-е касание), позже перешёл из поиска (2-е), затем кликнул по письму из рассылки (3-е) и купил. По модели последнего клика рассылка получает 100%. По линейной модели каждый канал получит по трети.

### Как выбрать модель
1. Оцените длину цикла: чем он длиннее, тем менее подходит последний клик.
2. Сравните отчёты по нескольким моделям в аналитике.
3. Ищите каналы, которые сильно выигрывают при смене модели: обычно это верх воронки.
4. Принимайте решения по бюджету, учитывая разные модели, а не одну.

### Типичные ошибки
- Всегда смотрят только последний клик.
- Не размечают ссылки, и трафик попадает в «прямые заходы».
- Не передают данные офлайн-продаж из CRM.
- Игнорируют, что часть касаний (например, посты в соцсетях) невозможно отследить.

### Кому и когда это нужно
Вопрос атрибуции становится важным, когда у компании больше двух рекламных каналов и длинный путь клиента. Без неё легко отключить канал, который готовил покупку, но не получил «заслугу». Начните с корректных меток и целей, а затем переходите к [[Сквозная аналитика]].

### Частый вопрос
**Какая модель атрибуции лучше?** Универсальной нет. Для короткого цикла хватает последнего клика, для длинного лучше смотреть несколько моделей и сквозную аналитику. Главное — понимать ограничения выбранной модели и не принимать по ней резких решений.
