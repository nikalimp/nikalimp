# База данных

**English:** Database
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/database

## Определение

База данных — это организованное хранилище информации, из которого программа быстро достаёт, добавляет и меняет данные. На сайтах в базах хранят пользователей, заказы, товары, заявки, статьи.

Данные в базе упорядочены по заданной схеме, а доступ к ним идёт через специальную программу — систему управления базами данных (СУБД). Самый распространённый тип — реляционные базы: данные лежат в таблицах со строками и столбцами, а таблицы связаны между собой. Запросы к ним пишут на языке [[SQL]]. Примеры: [[PostgreSQL (термин)|PostgreSQL]], MySQL. Есть и нереляционные базы, например MongoDB и Redis, где данные хранятся как документы или пары «ключ — значение».

Сайт общается с базой через [[Бэкенд|бэкенд]]: браузер никогда не обращается к ней напрямую. Бэкенд принимает запрос пользователя, проверяет права, достаёт нужные записи и возвращает ответ.

### Пример
В интернет-магазине есть таблица `products` (товары), `customers` (покупатели) и `orders` (заказы). В заказе хранятся номер покупателя и номера товаров. Чтобы показать историю покупок, система соединяет таблицы запросом.

### Кому и когда это нужно
Для статичного сайта из нескольких страниц база не нужна. Она нужна там, где есть данные, которые меняются без участия разработчика: кабинеты, каталоги, формы с историей, [[SaaS]]. Готовые решения вроде [[Supabase (термин)|Supabase]] дают базу сразу с API.

### Типичные ошибки
- Не делают резервные копии и не проверяют восстановление.
- Хранят пароли в открытом виде.
- Не создают индексы таблиц, и запросы замедляются при росте данных.
- Открывают базу в интернет без защиты.
- Хранят персональные данные россиян вне России, нарушая требования 152-ФЗ.

### Частый вопрос
**Чем база данных отличается от таблицы Excel?** База рассчитана на одновременную работу множества пользователей, на большие объёмы и строгие связи между данными. Excel удобен для ручной аналитики, но плохо подходит как основа сайта.
