# Блог

**English:** Blog
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/blog

## Определение

Блог — это раздел сайта или отдельный сайт с регулярно публикуемыми материалами, которые идут в обратном хронологическом порядке: новые записи сверху. Для бизнеса блог — способ привлекать посетителей из поиска и доказывать экспертность.

Слово пришло от английского weblog, «сетевой журнал». Раньше блоги были личными дневниками, сегодня это основной формат контент-маркетинга. Компания пишет статьи, отвечающие на вопросы клиентов, и получает трафик из Яндекса, Google и нейросетей, которые подбирают источники для ответов.

Технически блог — это набор страниц одного шаблона с рубриками, датами, автором и перелинковкой. Его ведут через [[CMS]] или файлы в репозитории. Для поиска у каждой статьи должны быть свой адрес, заголовок, описание и разметка, а сам блог — быть в [[Sitemap.xml|sitemap.xml]] и открыт для индексации.

### Зачем бизнесу блог
- Статьи закрывают информационные запросы, по которым не продают услугу напрямую.
- Они ведут на коммерческие страницы через внутренние ссылки.
- На них ссылаются другие сайты, и растёт авторитет домена.
- Из них нейросети берут факты для ответов, если материал структурирован и точен.

### Как запустить блог
1. Определите темы по запросам клиентов и по сезонности.
2. Составьте контент-план на 1–2 месяца.
3. Задайте единый шаблон статьи: заголовок, ответ в начале, подзаголовки, автор, дата.
4. Публикуйте регулярно, лучше реже, но стабильно.
5. Раз в квартал обновляйте старые статьи, которые приносят трафик.

### Типичные ошибки
- Пишут «для галочки» без привязки к запросам.
- Бросают блог после трёх записей.
- Публикуют тексты, сгенерированные нейросетью, без проверки фактов.
- Не связывают статьи ссылками с услугами.

### Частый вопрос
**Нужен ли блог сайту услуг?** Если вы хотите получать клиентов из поиска, да. Первые результаты обычно появляются не сразу, а через несколько месяцев регулярной работы. Если трафик берёте из рекламы или рекомендаций, можно обойтись и без блога.
