# Веб-приложение

**English:** Web Application
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/web-application

## Определение

Веб-приложение — это программа, которая работает в браузере и не требует установки: пользователь открывает адрес и сразу пользуется сервисом. Примеры: онлайн-банк, CRM, таск-трекер, конструктор презентаций, личный кабинет.

В отличие от обычного сайта, где человек в основном читает, в веб-приложении он действует: создаёт записи, загружает файлы, настраивает, получает персональные данные. У страницы есть состояние, учётные записи и логика. Для этого нужны [[Фронтенд|фронтенд]] (интерфейс), [[Бэкенд|бэкенд]] (логика и данные) и [[База данных|база данных]].

Веб-приложения строят на фреймворках: [[React (термин)|React]], [[Vue]], [[Next.js (термин)|Next.js]]. Бывают одностраничные ([[SPA]]), когда интерфейс обновляется без перезагрузки, и многостраничные с серверным рендерингом. Современные приложения с поддержкой установки на экран телефона называют [[PWA]].

Главные преимущества: работают на любом устройстве, обновляются у всех сразу, не требуют публикации в магазинах приложений. Из минусов: нужен интернет (если нет офлайн-режима), доступ к функциям устройства ограничен.

### Пример
Личный кабинет рекламодателя: вход по паролю, список кампаний, график расходов, выгрузка отчёта. Это не набор статичных страниц, а программа с данными.

### Чем отличается от сайта
Сайт в основном передаёт информацию, веб-приложение выполняет задачи. Граница размыта: у интернет-магазина есть страницы-витрины и приложение-корзина. Разработка приложения дороже, поскольку нужна проработка ролей, данных и безопасности.

### Типичные ошибки
- Делают приложение там, где хватило бы сайта.
- Не продумывают роли и права доступа.
- Не учитывают нагрузку и резервное копирование.
- Не проверяют работу на мобильных устройствах.

### Частый вопрос
**Чем веб-приложение отличается от мобильного приложения?** Веб-приложение открывается в браузере и работает везде, мобильное устанавливается из магазина и лучше использует возможности телефона: камеру, уведомления, датчики. Если эти возможности не критичны, веб-приложение дешевле и быстрее запускается.
