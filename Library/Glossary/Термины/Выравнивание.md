# Выравнивание

**English:** Alignment
**Категория:** [[Глоссарий — UI-UX дизайн]]
**URL:** nikalimp.ru/glossary/alignment

## Определение

Выравнивание — это расположение элементов по общим линиям: левому или правому краю, центру, верху или низу. Оно создаёт порядок и показывает, что элементы связаны, потому что глаз легко прослеживает общую границу.

Ровная опорная линия делает страницу собранной. Когда заголовок, текст и кнопка начинаются с одного левого края, читатель идёт по прямой. Когда каждый элемент «плавает» на своём месте, возникает ощущение небрежности, даже если пользователь не понимает причину. Поэтому выравнивание считают одним из главных признаков аккуратного дизайна.

Основные виды. По левому краю: самый удобный для чтения текста на русском и других языках с письмом слева направо. По правому краю: годится для цифр и коротких подписей. По центру: подходит для коротких заголовков и торжественных блоков, но длинный центрированный текст читается плохо. По ширине: даёт ровные края, но создаёт неравные пробелы и «реки» в тексте без переносов. Вертикальное выравнивание: по верхнему краю, центру или базовой линии текста.

### Пример
В карточках услуг иконка, заголовок, описание и кнопка выровнены по левому краю, а кнопки у всех карточек стоят на одной нижней линии, хотя тексты разной длины. Страница выглядит собранной. Если кнопки расположены на разной высоте, строка карточек выглядит рваной.

### Как проверить выравнивание
1. Включите направляющие или [[Модульная сетка|сетку]] и привяжите к ним элементы.
2. Проведите мысленно вертикальные линии вдоль краёв блоков: их должно быть немного.
3. Выравнивайте текст в строке по базовой линии, а иконки с текстом — по оптическому центру.
4. Используйте автоматическую раскладку ([[Auto Layout]]) в Figma или Flexbox и Grid в коде, чтобы выравнивание не разъезжалось.
5. Проверьте экран на разных ширинах: при перестроении колонок линии должны сохраняться.
6. Для арабского, иврита и других языков справа налево используйте логические свойства вместо «левого» и «правого».

### Типичные ошибки
- Смесь центрированного и левого выравнивания в одном блоке.
- Длинный текст по центру.
- Выравнивание по ширине без переносов слов, из-за чего появляются дырки между словами.
- Выравнивание по математическому, а не оптическому центру: круглые иконки и треугольники кажутся смещёнными.
- Число в таблицах выровнено по левому краю, и разряды не совпадают.

### Чем отличается от близости
[[Близость]] группирует элементы расстоянием. Выравнивание связывает их общей линией. Вместе они дают структуру: блок воспринимается цельным и отдельным от соседних.

### Частый вопрос
**Какое выравнивание текста лучше для сайта?** Для основного текста — по левому краю: он удобнее читается и не создаёт неровных пробелов. По центру выравнивают короткие заголовки и подписи. Числа в таблицах лучше выравнивать по правому краю или по разряду.
