# Вёрстка

**English:** Front-end Markup
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/front-end-markup

## Определение

Вёрстка — это превращение макета сайта в работающие страницы с помощью [[HTML]] и [[CSS]], которые браузер умеет показывать. Дизайнер рисует, как должно выглядеть, а верстальщик создаёт код, который выглядит так же и работает на разных экранах.

HTML задаёт структуру: заголовки, абзацы, кнопки, формы, изображения. CSS отвечает за внешний вид: цвета, шрифты, отступы, сетку, анимации. [[JavaScript]] добавляет поведение: меню, слайдеры, проверку форм. Вместе они образуют [[Фронтенд|фронтенд]] сайта.

Хорошая вёрстка — не только красивая, но и корректная. Семантичные теги (`header`, `nav`, `main`, `article`) помогают поисковикам и нейросетям понять структуру страницы, а экранным читалкам — прочитать её для людей с нарушениями зрения. Быстрая вёрстка без лишнего кода улучшает загрузку и показатели [[Core Web Vitals]].

Верстают по-разному: вручную на HTML и CSS, на фреймворках вроде [[Tailwind CSS (термин)|Tailwind]], в компонентном подходе с [[React (термин)|React]] или в визуальных редакторах Tilda и Webflow.

### Пример
Макет главной страницы в Figma: шапка, заголовок, три карточки, форма. Верстальщик создаёт HTML с этими блоками, оформляет их стилями, делает так, чтобы на телефоне карточки шли друг под другом, и добавляет проверку формы.

### Виды вёрстки
- Адаптивная: страница перестраивается под ширину экрана ([[Адаптивная вёрстка]]).
- Резиновая: блоки растягиваются пропорционально.
- Фиксированная: ширина жёсткая, сегодня почти не используется.

### Что проверять в готовой вёрстке
1. Совпадение с макетом на разных размерах экрана.
2. Корректность HTML по валидатору.
3. Работу в основных браузерах.
4. Доступность: клавиатура, контраст, подписи у полей.
5. Скорость загрузки.

### Типичные ошибки
- Разметка из одних `div` без смысла.
- Фиксированные размеры в пикселях.
- Дублирование стилей вместо повторного использования.
- Тексты в картинках вместо живого текста.

### Частый вопрос
**Вёрстка и программирование — это одно и то же?** Нет. Вёрстка занимается структурой и внешним видом страницы, а программирование — логикой: данные, расчёты, работа с сервером. Но современный фронтенд-разработчик обычно умеет и то, и другое.
