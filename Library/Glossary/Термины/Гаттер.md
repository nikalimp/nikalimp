# Гаттер

**English:** Gutter
**Категория:** [[Глоссарий — UI-UX дизайн]]
**URL:** nikalimp.ru/glossary/gutter

## Определение

Гаттер — это промежуток между соседними колонками модульной сетки. Он отделяет колонки друг от друга и задаёт расстояние между блоками контента, которые стоят в одном ряду. Название от английского gutter, дословно «желоб».

Сетка из колонок без гаттеров заставляет блоки слипаться, текст соседних колонок сливается, а картинки упираются друг в друга. Гаттер даёт воздух и позволяет глазу различать блоки. Его ширина обычно фиксирована для каждого диапазона экранов и берётся из шкалы отступов. Например, на десктопе гаттер крупнее, на телефоне компактнее, чтобы не тратить драгоценную ширину.

Не путайте гаттер с внешними полями страницы. Поля ([[Отступы|отступы]] от краёв экрана) определяют расстояние между содержимым и краем окна, а гаттеры действуют только между колонками. Вместе поля, колонки и гаттеры образуют каркас [[Модульная сетка|модульной сетки]]. В вёрстке гаттер реализуют свойством gap в CSS Grid и Flexbox либо внутренними отступами колонок.

### Пример
Сетка из 12 колонок для десктопа, гаттер между колонками 24 пикселя, поля страницы 80 пикселей. Карточка занимает четыре колонки и три гаттера внутри, три карточки образуют ряд. На телефоне сетка превращается в четыре колонки с гаттером 16 пикселей и полями 16 пикселей, карточки идут по одной в ряд, а вертикальное расстояние между ними берётся тем же значением.

### Как выбрать гаттер
1. Определите шкалу отступов проекта, например кратную 8 пикселям ([[8pt grid]]).
2. Выберите гаттер из этой шкалы для каждого диапазона ширины.
3. Сделайте вертикальные промежутки между рядами карточек согласованными с горизонтальными.
4. Проверьте плотность: при слишком маленьком гаттере блоки слипаются, при слишком большом разваливается группировка.
5. Зафиксируйте значения в [[Дизайн-токены|токенах]] и используйте gap в коде.
6. Проверьте поведение на границах [[Брейкпоинт|брейкпоинтов]].

### Типичные ошибки
- Гаттер, не совпадающий со значениями шкалы отступов, и «лишние» числа в макете.
- Разные гаттеры в соседних блоках одной страницы.
- Вертикальные промежутки между рядами не совпадают с горизонтальными без причины.
- Гаттер путают с внутренним отступом карточки и получают двойные отступы.
- Слишком большая ширина гаттера на мобильном: контент становится узким.

### Чем отличается от padding
[[Padding]] — внутренний отступ внутри элемента между его краем и содержимым. Гаттер — внешний промежуток между соседними колонками или элементами сетки. Padding принадлежит элементу, а гаттер принадлежит сетке.

### Частый вопрос
**Какой ширины делать гаттер?** Чаще всего берут значение из шкалы отступов: на десктопе крупнее, на мобильном меньше, например 16–32 пикселя. Главное — единообразие по всему сайту и согласованность с внешними полями страницы.
