# Граф знаний

**English:** Knowledge Graph
**Категория:** [[Глоссарий — GEO и AI-поиск]]
**URL:** nikalimp.ru/glossary/knowledge-graph

## Определение

Граф знаний — база данных, в которой поисковая система хранит факты о сущностях и связи между ними: «компания — основатель — город — продукты».

Самый известный пример — Knowledge Graph Google, у Яндекса есть собственная база объектов. Из графа знаний берутся карточки в выдаче и часть фактов для AI-ответов.

### История
Идея баз знаний старше поисковиков: экспертные системы 1970–1980-х хранили факты в виде правил и связей. В 2007 году появилась открытая база Freebase. В 2010 году Google купил её разработчика, компанию Metaweb, а в мае 2012 года запустил Knowledge Graph со слоганом «вещи, а не строки». В 2012 году стартовал и проект Wikidata — открытая база фактов Википедии. Яндекс развивает собственную базу объектов, на которой строятся карточки в выдаче.

### Как устроен граф
Граф состоит из узлов и связей. Узел — сущность: компания, человек, город, продукт. Связь — отношение: «основана в», «руководитель», «производит», «находится в». У каждого узла есть атрибуты: дата основания, адрес, сайт, логотип. Поисковик собирает эти данные из Википедии, Wikidata, микроразметки сайтов, справочников и других источников.

### Зачем граф знаний нейросетям
- Генеративный поиск использует граф для проверки фактов и подстановки точных данных.
- Граф помогает различать сущности с похожими названиями.
- Карточки из графа показываются рядом с AI-ответами.

### Как попасть в граф знаний
1. Разметьте сайт через Organization или Person с полными данными.
2. Укажите в sameAs официальные профили: соцсети, справочники, Википедию, если есть.
3. Используйте одно и то же название и описание на всех площадках.
4. Добейтесь упоминаний в авторитетных источниках.
5. Для известных компаний — создайте запись в Wikidata по её правилам.

### Частый вопрос
**Нужна ли статья в Википедии, чтобы попасть в граф знаний?** Нет. Википедия помогает, но её правила значимости строгие, и для большинства компаний статья недоступна. Граф знаний собирает данные и из других источников: микроразметки, справочников, СМИ, карт. Согласованные данные на этих площадках — реальный путь для малого и среднего бизнеса.
