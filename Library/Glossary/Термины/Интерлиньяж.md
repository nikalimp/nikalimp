# Интерлиньяж

**English:** Line Height
**Категория:** [[Глоссарий — Графический дизайн и бренд]]
**URL:** nikalimp.ru/glossary/line-height

## Определение

Интерлиньяж — это расстояние между строками текста, а точнее между их базовыми линиями. В вебе его задают свойством `line-height` и часто называют межстрочным интервалом. Английский термин — leading.

Название пришло из типографии, где между строками металлического набора вставляли свинцовые пластинки (в английском это lead, откуда и leading). Сегодня принцип тот же, только вместо свинца — число в макете или CSS.

Интерлиньяж сильно влияет на читаемость. При слишком плотных строках глаз «спотыкается» и путает верхнюю и нижнюю строку. При слишком больших зазорах текст рассыпается на отдельные полоски, и абзац теряет целостность. Правильное значение зависит от гарнитуры, кегля, длины строки и назначения текста.

### Какие значения использовать
- Основной текст: обычно 1,4–1,6 от размера шрифта, то есть при 16 px интерлиньяж около 24 px.
- Заголовки: плотнее, около 1,1–1,3, потому что строк мало, а размер большой.
- Мелкий текст: чуть свободнее, 1,5 и выше.
- Длинная строка требует большего интерлиньяжа, короткая обходится меньшим.
- Шрифты с большой высотой строчных букв нуждаются в большем зазоре.

### Как задать интерлиньяж в CSS
1. Указывайте значение без единиц: `line-height: 1.5`. Тогда оно считается от размера шрифта элемента и корректно наследуется.
2. Для заголовков переопределите значение: `h1 { line-height: 1.2 }`.
3. Проверьте текст в нескольких ширинах окна: на узком экране строк больше, а на широком строки длиннее.
4. Сверьте результат с рекомендациями по доступности: для основного текста принято брать не меньше 1,5.
5. Если тексты стыкуются в одном блоке, выдерживайте вертикальный ритм: отступы кратны базовому значению.

### Типичные ошибки
- Одно значение интерлиньяжа на весь сайт, включая заголовки и подписи.
- Задавать `line-height` в пикселях: при смене размера шрифта значение «ломается».
- Слишком узкий интерлиньяж у заголовков в несколько строк, когда выносные элементы букв касаются друг друга.
- Слишком большой интерлиньяж, из-за чего абзац выглядит рыхло.

### Чем отличается от кернинга и трекинга
[[Кернинг]] регулирует расстояние между конкретной парой букв, [[Трекинг]] — равномерное расстояние между всеми буквами. Интерлиньяж работает по вертикали и определяет расстояние между строками. Вместе они образуют «воздух» текста.


### Как проверить глазами
Откройте абзац текста на реальном устройстве и прочитайте его целиком. Если глаз легко находит начало следующей строки и текст не слипается, значение подобрано хорошо. Для проверки удобно сравнить два варианта рядом, например 1,4 и 1,6.

### Частый вопрос
**Какой интерлиньяж лучше для сайта?** Для основного текста возьмите 1,5 от размера шрифта и уменьшите до 1,2–1,3 для крупных заголовков. Затем проверьте на реальном тексте и подправьте под конкретную гарнитуру: единой формулы для всех шрифтов нет.
