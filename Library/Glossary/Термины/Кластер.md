# Кластер

**English:** Keyword Cluster
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/keyword-cluster

## Определение

Кластер (keyword cluster) в SEO — это группа поисковых запросов со схожим смыслом, которые можно продвигать на одной странице. Например, «купить диван», «диван недорого» и «заказать диван» относятся к одному кластеру: людям нужна одна и та же страница с каталогом диванов.

Идея в том, что одна страница отвечает сразу на много формулировок одного [[Интент|интента]]. Если под каждый запрос делать отдельную страницу, получатся почти одинаковые тексты, возникнет [[Каннибализация|каннибализация]] и сайт будет выглядеть набором дублей. А если, наоборот, свалить разные интенты на одну страницу, она не попадёт ни в один из них.

Кластер получают в результате [[Кластеризация запросов|кластеризации]]. У кластера есть главный запрос (с высокой частотностью и понятным интентом) и поддерживающие запросы, которые используют в заголовках, подзаголовках и тексте.

### Пример
Запросы: «заказать сайт-визитку», «сайт-визитка цена», «разработка сайта визитки». Это один кластер, и ему нужна одна страница услуги. А запрос «как сделать сайт-визитку самому» — другой кластер: информационный, под него пишут статью.

### Как работать с кластером
1. Определите главный запрос и интент.
2. Проверьте выдачу: какие страницы там стоят и какого они типа.
3. Закрепите кластер за одной страницей, записав это в таблице соответствия «кластер → адрес».
4. Используйте запросы кластера в `title`, заголовке H1, подзаголовках и тексте, не вставляя их подряд.
5. Раз в квартал проверяйте, не появились ли новые запросы.

### Не путайте
Тематический кластер (topic cluster) — это другое понятие: группа статей, связанных ссылками вокруг одной страницы-хаба. Про него есть отдельная статья — [[Topic cluster]]. Кластер запросов — про распределение запросов по страницам, тематический — про структуру контента.

### Типичные ошибки
- Делать кластеры по похожести слов, а не по выдаче.
- Закреплять один кластер за несколькими страницами.
- Оставлять запросы без страницы, потому что «они мелкие».

### Зачем нужны кластеры
Они превращают список запросов в план страниц. Видно, какие страницы нужно создать, какие уже есть, а какие можно объединить. Для бюджета это тоже полезно: вы платите за страницу, а не за каждую фразу, и точно знаете, какие запросы она должна закрыть.

### Частый вопрос
**Сколько запросов должно быть в кластере?** Однозначного числа нет: бывают кластеры из двух запросов и из пятидесяти. Главное — чтобы все запросы действительно отвечали на один интент и могли быть закрыты одной страницей.
