# Когортный анализ

**English:** Cohort Analysis
**Категория:** [[Глоссарий — Маркетинг и аналитика]]
**URL:** nikalimp.ru/glossary/cohort-analysis

## Определение

Когортный анализ — это метод аналитики, при котором пользователей делят на группы (когорты) по общему признаку, чаще всего по дате первого действия, и отслеживают, как ведёт себя каждая группа со временем.

Пример когорты: все, кто впервые купил в январе. Через месяц смотрим, сколько из них купили снова, через два — сколько осталось. Так видно, как меняется удержание и выручка, не смешивая старых клиентов и новых. Средний показатель по всей базе такой картины не даёт, потому что скрывает различия между группами.

Метод нужен продуктам и бизнесам с повторными покупками или подпиской: приложениям, интернет-магазинам, SaaS, онлайн-школам. Для единичных разовых услуг он менее полезен.

Результат обычно рисуют в виде таблицы-«лесенки» с цветовой шкалой: тёмные ячейки означают высокое удержание, светлые — низкое. По диагонали и вертикальным полосам видно влияние внешних событий, например сезона или акции, которые затронули сразу несколько когорт.

### Пример
Онлайн-школа сравнивает когорты по месяцу первой покупки. Из когорты марта через 3 месяца учится 40% студентов, из когорты июня — 55%. Значит, после изменения программы или онбординга удержание улучшилось. Без разделения на когорты общий процент ничего бы не показал.

### Как провести
1. Выберите признак группировки: месяц первой покупки, источник трафика, тариф.
2. Выберите метрику: активность, повторная покупка, выручка на клиента, отток.
3. Постройте таблицу: строки — когорты, столбцы — периоды после старта (неделя 1, 2, 3 или месяц 1, 2, 3).
4. Сравните строки между собой и найдите, где удержание лучше или хуже.
5. Свяжите различия с событиями: изменением цены, продукта, рекламы.

### Типичные ошибки
- Брать когорты из нескольких десятков человек: значения скачут случайно.
- Сравнивать когорты разной давности без учёта сезона.
- Смотреть только общее [[Retention]] и не делить по каналам.
- Не связывать выводы с [[LTV]]: когорта с лучшим удержанием обычно приносит больше денег за время жизни клиента.

### Чем отличается от сегментации
[[Сегментация]] делит клиентов по свойствам (город, возраст, канал) на конкретный момент. Когортный анализ делит по времени входа и смотрит развитие во времени. Часто их комбинируют: когорты внутри сегментов.

### Частый вопрос
**Какие инструменты подходят для когортного анализа?** Для начала хватит таблицы с выгрузкой из CRM или Метрики: когорты можно построить сводной таблицей. В Яндекс Метрике есть отчёт «Когортный анализ», а в продуктовой аналитике — готовые инструменты.
