# Многостраничный сайт

**English:** Multi-page Website
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/multi-page-website

## Определение

Многостраничный сайт — это сайт из нескольких или многих отдельных страниц, у каждой из которых свой адрес, тема и содержание. Между страницами человек переходит по меню и ссылкам.

Типичный пример — [[Корпоративный сайт]]: главная, о компании, страницы услуг, кейсы, блог, контакты. Крупные сайты, например [[Интернет-магазин|магазины]] и порталы, содержат тысячи страниц. Каждая страница отвечает на свой вопрос или запрос, и в этом главное преимущество для поиска: можно занять позиции по многим запросам, а не по одному.

Для нейросетей и поисковиков многостраничная структура тоже удобнее: каждая услуга или вопрос имеет отдельный адрес, на который можно сослаться.

### Пример
Стоматология: отдельная страница для каждой услуги (имплантация, лечение, отбеливание), страницы врачей, цены, отзывы, блог. Человек, который ищет «имплантация зубов цена», попадает сразу на нужную страницу, а не листает общую.

### Как спроектировать структуру
1. Соберите запросы аудитории и сгруппируйте их по темам.
2. Для каждой услуги или темы заведите отдельную страницу.
3. Постройте понятную иерархию: не глубже 3–4 уровней.
4. Настройте меню, хлебные крошки и перелинковку между связанными страницами.
5. Подготовьте файл sitemap.xml и понятные адреса (URL).

### Типичные ошибки
- Много страниц с одинаковым или пустым текстом.
- Запутанное меню: нужную страницу сложно найти.
- Страницы без внутренних ссылок, до которых не добраться.
- Дублирование: одна тема описана на нескольких страницах.

### Чем отличается от одностраничника
[[Одностраничник]] выводит всё на одной странице, это удобно для простого предложения. Многостраничный сайт лучше для SEO, для сложного бизнеса и для случаев, когда нужно показать много информации.

### Кому и когда это нужно
Многостраничная структура нужна, когда у бизнеса несколько услуг или товарных направлений, когда вы хотите привлекать клиентов из поиска и когда нужно много информации: цены, документы, кейсы, статьи. Если предложение простое, а трафик платный, хватит лендинга. Можно начать с небольшого сайта и добавлять страницы по мере появления услуг и статей.

### Частый вопрос
**Сколько страниц должно быть на сайте?** Столько, сколько нужно, чтобы ответить на запросы клиентов. Для небольшой компании это обычно 5–15 страниц, а потом сайт растёт за счёт статей и разделов. Важна не цифра, а польза каждой страницы.
