# Промпт-трекинг

**English:** Prompt Tracking
**Категория:** [[Глоссарий — GEO и AI-поиск]]
**URL:** nikalimp.ru/glossary/prompt-tracking

## Определение

Промпт-трекинг — регулярная проверка ответов нейросетей по фиксированному набору запросов, чтобы отслеживать упоминания бренда, его позиции и ссылки на сайт. Аналог съёма позиций в SEO.

Ответы моделей меняются от запуска к запуску, поэтому один и тот же запрос проверяют несколько раз и смотрят на долю ответов с упоминанием. Трекинг делают вручную или через специализированные сервисы.

### Откуда метод
Съём позиций — одна из первых автоматизаций SEO. Сервисы проверяли, на каком месте сайт стоит по ключевым словам, и строили графики. Когда нейросети стали источником клиентов, бизнесу понадобился аналог для AI-ответов. В 2024–2025 годах появились специализированные сервисы промпт-трекинга, а крупные SEO-платформы добавили модули для отслеживания AI-видимости.

### Что отслеживают
- Упомянут ли бренд в ответе.
- На какой позиции в списке.
- Есть ли ссылка на сайт.
- Какие конкуренты названы рядом.
- В каком тоне модель говорит о бренде.
- Какие источники модель цитирует.

### Как организовать трекинг
1. Возьмите пул промптов из промпт-исследования.
2. Выберите модели: для России — Алиса AI, GigaChat, ChatGPT, DeepSeek, Perplexity.
3. Проверяйте каждый промпт 3–5 раз за сессию: ответы различаются от запуска к запуску.
4. Проводите замер в одни и те же дни месяца.
5. Сохраняйте полные ответы, а не только отметки «да» и «нет».

### Ручной или автоматический
Для 20–30 промптов можно вести трекинг вручную в таблице. Для сотни промптов и нескольких моделей нужен сервис или скрипт через API моделей. Учтите, что ответы через API и в веб-интерфейсе могут отличаться: интерфейс добавляет поиск и персонализацию.

### Как читать результаты
Смотрите на долю ответов с упоминанием по месяцам и сравнивайте с конкурентами. Связывайте изменения с действиями: публикацией статьи, обновлением страницы, новыми отзывами. Так видно, что именно влияет на ответы.

### Частый вопрос
**Какие сервисы использовать?** Для старта хватает таблицы и ручных проверок. Специализированные сервисы окупаются, когда в пуле больше 50 запросов и несколько моделей.
