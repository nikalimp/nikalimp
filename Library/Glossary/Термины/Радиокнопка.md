# Радиокнопка

**English:** Radio Button
**Категория:** [[Глоссарий — UI-UX дизайн]]
**URL:** nikalimp.ru/glossary/radio-button

## Определение

Радиокнопка — это элемент формы в виде небольшого кружка, позволяющий выбрать ровно один вариант из нескольких. Когда пользователь выбирает один пункт, остальные автоматически снимаются.

Название происходит от переключателей настроек частот в старых радиоприёмниках: нажатие одной кнопки отжимало остальные. В HTML радиокнопка задаётся тегом `<input type="radio">`; все кнопки группы получают одинаковое имя (name), по нему браузер понимает, что выбрать можно только одну. Выбранная кнопка обозначается точкой внутри кружка.

Радиокнопки подходят, когда вариантов мало, и пользователь должен видеть их все сразу, чтобы сравнить. Типичные случаи: выбор способа доставки, тарифа, пола, периода оплаты. Если вариантов много, лучше [[Дропдаун|выпадающий список]]. Если можно выбрать несколько, нужны [[Чекбокс|чекбоксы]]. А для включения и выключения одной настройки подходит [[Свитч]].


Иногда вместо классических кружков делают крупные карточки с выбором: тарифы, способы доставки, варианты оплаты. Технически это те же радиокнопки, только с другой подачей. Такой вид лучше работает на телефоне, потому что область нажатия большая, а в карточку можно добавить цену и пояснение. Главное, чтобы выбранная карточка была чётко выделена.
### Чем отличается от чекбокса
Радиокнопка: выбирается один вариант из группы, снять выбор нельзя, пока не выбран другой. Чекбокс: каждый пункт независим, можно выбрать несколько или ни одного. Форма также отличается: кнопка круглая, чекбокс квадратный. Не смешивайте эти формы, иначе пользователь ошибётся в ожиданиях.

### Как сделать радиокнопки удобными
1. Выберите значение по умолчанию, если есть самый частый вариант. Если выбор принципиален, оставьте пустым и сделайте поле обязательным.
2. Сделайте кликабельной не только кружок, но и подпись ([[Лейбл|лейбл]]), это увеличивает область нажатия.
3. Выровняйте варианты в столбик: так проще сравнивать. В одну строку ставьте их, только если вариантов два-три и тексты короткие.
4. Добавьте видимое состояние фокуса, чтобы можно было выбирать с клавиатуры стрелками.
5. Сгруппируйте кнопки в `<fieldset>` с `<legend>`, чтобы скринридер озвучивал вопрос вместе с вариантами.
6. Порядок вариантов должен быть логичным: по частоте, по возрастанию цены или по алфавиту.

### Типичные ошибки
- Использование радиокнопок там, где нужен множественный выбор.
- Слишком много вариантов, и список превращается в длинную простыню.
- Мелкий кружок без кликабельной подписи.
- Нет значения по умолчанию там, где оно очевидно.
- Пользователь не может отменить выбор, хотя поле необязательное: добавьте вариант «Не выбрано» или кнопку сброса.

### Частый вопрос
**Когда использовать радиокнопки, а когда выпадающий список?** Если вариантов от двух до пяти, берите радиокнопки: все варианты видны сразу, и выбор делается одним кликом. Если больше пяти-семи, выпадающий список экономит место. Для двух вариантов «да» и «нет» подойдёт чекбокс или свитч.
