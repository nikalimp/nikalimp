# СЧ запросы

**English:** Mid-frequency Keywords
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/mid-frequency-keywords

## Определение

СЧ запросы (среднечастотные запросы) — это поисковые запросы со средним спросом: их вводят заметно реже самых популярных, но чаще редких. Обычно это фразы из двух-трёх слов вроде «ремонт квартир Москва» или «купить ноутбук для учёбы».

Деление на высокочастотные ([[ВЧ запросы]]), среднечастотные и низкочастотные ([[НЧ запросы]]) условное. Границы зависят от тематики: для узкой ниши 500 показов в месяц — много, для массового рынка — мало. Поэтому ориентируйтесь на сравнение внутри своей темы, а не на универсальные цифры. Частоту показывают [[Wordstat]] и аналогичные сервисы.

СЧ запросы — компромисс. Спрос у них заметный, конкуренция ниже, чем у ВЧ, а намерение пользователя обычно понятнее. Поэтому на них строят основную часть структуры сайта: разделы, категории и страницы услуг.

### Пример
Для студии, продающей окна: «пластиковые окна» — ВЧ, «пластиковые окна Москва цена» — СЧ, «пластиковые окна в хрущёвку с шумоизоляцией» — НЧ. Для страницы услуги подойдёт СЧ запрос с привязкой к региону.

### Как работать со среднечастотными запросами
1. Соберите запросы по теме в Wordstat и других сервисах.
2. Разделите их на ВЧ, СЧ и НЧ относительно вашей ниши.
3. Проверьте выдачу: какие страницы занимают топ по СЧ запросам.
4. Сгруппируйте похожие запросы в кластеры и назначьте каждому свою страницу.
5. Оптимизируйте страницы, а потом добавляйте НЧ запросы в подзаголовки и текст.

### Типичные ошибки
- Продвигать один СЧ запрос на нескольких страницах: возникает каннибализация.
- Выбирать запросы по частоте, не глядя на коммерческое намерение.
- Ожидать быстрых результатов: по СЧ запросам обычно уже есть сильные конкуренты.

### Как найти золотую середину
Лучший СЧ запрос — тот, по которому спрос уже есть, топ не закрыт гигантами, а ваш сайт может дать лучший ответ. Проверяйте выдачу вручную: если в топе только крупные агрегаторы, пробиться сложнее, а если встречаются небольшие сайты, шансы выше.

### Кому и когда это нужно
Среднечастотные запросы подходят основным разделам сайта: категориям, услугам, ключевым статьям. Для тематических страниц низкой конкуренции берите НЧ, для главных страниц и каталогов — ВЧ и СЧ.

### Частый вопрос
**С каких запросов лучше начинать продвижение?** Новому сайту проще начать с низкочастотных запросов, а по мере роста переходить к среднечастотным. Для сайта с историей СЧ запросы — основной источник трафика: они дают спрос без огромной конкуренции ВЧ.
