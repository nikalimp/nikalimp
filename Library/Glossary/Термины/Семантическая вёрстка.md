# Семантическая вёрстка

**English:** Semantic HTML
**Категория:** [[Глоссарий — Веб-разработка]]
**URL:** nikalimp.ru/glossary/semantic-html

## Определение

Семантическая вёрстка — это способ писать [[HTML]] так, чтобы теги описывали смысл содержимого, а не только внешний вид. Заголовок размечают как заголовок, навигацию как навигацию, список как список.

В HTML есть теги со смыслом: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`, `<h1>`–`<h6>`, `<ul>`, `<button>`. Если вместо них использовать одни `<div>` с классами, страница для глаз будет выглядеть так же, но программы, которые читают код, не поймут её структуру. Эти программы — поисковые роботы, [[Скринридер]] для незрячих, браузеры и [[AI-краулер]].

Польза практическая: поисковики лучше разбирают страницу, людям с ограниченными возможностями легче ориентироваться ([[Доступность]]), код становится понятнее разработчикам, а нейросети проще извлекать из страницы ответы.

Семантика особенно важна сейчас, когда сайты читают не только люди, но и нейросети. Языковые модели и AI-поиск разбирают страницу по структуре: заголовок, список, таблица, абзац. Чем яснее разметка, тем проще извлечь точный ответ и процитировать его. Поэтому семантическая вёрстка входит в базовые требования к [[AI-ready сайт]] и совпадает с тем, что нужно для доступности: один и тот же аккуратный код помогает и незрячим пользователям, и поисковым роботам. 

### Пример
Вместо `<div class="title">Услуги</div>` пишут `<h2>Услуги</h2>`. Вместо `<div class="menu">` — `<nav>`. Вместо `<div onclick="...">Отправить</div>` — `<button>Отправить</button>`: кнопка сразу доступна с клавиатуры и распознаётся как кнопка.

### Как проверить
1. Откройте страницу и отключите стили: структура должна оставаться логичной.
2. Пройдите по странице клавишей Tab: все интерактивные элементы должны получать [[Focus]] по порядку.
3. Проверьте заголовки: на странице один `<h1>`, уровни идут без пропусков ([[Заголовки H1–H6]]).
4. Запустите [[Lighthouse (термин)]] и посмотрите раздел доступности.

### Типичные ошибки
- Всё делают `<div>`-ами и `<span>`-ами.
- Выбирают заголовки по размеру шрифта, а не по смыслу.
- Кнопки делают ссылками и наоборот.
- Не заполняют `alt` у изображений ([[Alt-текст]]).

### Частый вопрос
**Влияет ли семантическая вёрстка на SEO?** Косвенно да. Поисковые системы понимают структуру страницы лучше, а правильные заголовки помогают определить главную тему. Сама по себе вёрстка позиции не гарантирует, но без неё остальные усилия менее эффективны.
