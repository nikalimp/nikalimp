# Семантическое ядро

**English:** Semantic Core
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/semantic-core

## Определение

Семантическое ядро — это структурированный список поисковых запросов, по которым сайт должен показываться в выдаче, сгруппированный по страницам. Это основа SEO: по нему решают, какие страницы нужны сайту и о чём на них писать.

Ядро собирают из реальных запросов людей. Источники: [[Wordstat]], подсказки поисковиков, данные Яндекс Метрики и Search Console, сайты конкурентов, инструменты вроде [[Serpstat (термин)]] и [[Ahrefs (термин)]]. Запросы очищают от лишних, группируют по смыслу и распределяют по страницам: один смысловой кластер — одна страница.

Хорошее ядро охватывает разные типы запросов: [[Информационный запрос|информационные]], [[Коммерческий запрос|коммерческие]], [[Транзакционный запрос|транзакционные]] и [[Навигационный запрос|навигационные]]. Для каждого кластера определяют частотность, конкуренцию и намерение пользователя.


На практике ядро служит не списком для хранения, а рабочим документом. Из него вытекают структура сайта, заголовки и темы статей, задания копирайтерам и план [[Внутренняя перелинковка|внутренней перелинковки]]. Если ядро собрано без привязки к реальным страницам, оно быстро превращается в таблицу, которой никто не пользуется. Поэтому полезно хранить рядом с запросом адрес страницы, статус работ и дату последней проверки.
### Как собрать семантическое ядро
1. Составьте базовые маркеры: названия услуг, товаров, проблем клиента.
2. Расширьте их через Wordstat, подсказки поиска и анализ конкурентов.
3. Удалите нецелевые запросы: не про ваш регион, продукт или аудиторию.
4. Сгруппируйте запросы по смыслу ([[Кластеризация запросов]]) и по типу страницы.
5. Привяжите каждый кластер к существующей или новой странице.
6. Раз в квартал обновляйте ядро: спрос и конкуренты меняются.

### Типичные ошибки
- Собрать огромный список и не привязать его к страницам.
- Оставить в ядре нецелевые запросы только из-за высокой частотности.
- Продвигать несколько страниц под один смысл, из-за чего возникает [[Каннибализация]].
- Игнорировать низкочастотные запросы, которые приносят заявки точнее.

### Кому нужно
Любому сайту, который хочет получать трафик из поиска: перед запуском, при переработке структуры и при планировании блога. Для небольшой визитки ядро может состоять из нескольких десятков запросов, для интернет-магазина — из тысяч.

### Частый вопрос
**Сколько запросов должно быть в семантическом ядре?** Столько, сколько нужно, чтобы описать все страницы сайта и покрыть спрос в вашей нише. Для небольшого сайта услуг это обычно десятки или сотни запросов, для каталога — тысячи. Важнее не число, а то, что у каждого запроса есть страница, а у каждой страницы — свой смысл.
