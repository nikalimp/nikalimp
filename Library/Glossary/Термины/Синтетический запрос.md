# Синтетический запрос

**English:** Synthetic Query
**Категория:** [[Глоссарий — GEO и AI-поиск]]
**URL:** nikalimp.ru/glossary/synthetic-query

## Определение

Синтетический запрос — запрос, который генерирует сама поисковая система или нейросеть, а не пользователь: например, переформулировка вопроса или подзапрос при query fan-out.

Пользователь их не видит, но именно по ним система находит страницы для ответа.

### Откуда понятие
Поисковики переформулировали запросы задолго до нейросетей: исправляли опечатки, добавляли синонимы, расширяли запрос близкими словами. Языковые модели сделали это масштабным. В генеративном поиске один вопрос пользователя может превратиться в десятки синтетических запросов. Google описывает это как query fan-out, а патенты поисковиков упоминают генерацию синтетических запросов для поиска и обучения систем ранжирования.

### Виды синтетических запросов
- **Переформулировки:** тот же вопрос другими словами.
- **Уточнения:** добавление города, года, типа пользователя.
- **Подвопросы:** части сложного вопроса по отдельности.
- **Сравнения:** «X против Y», «альтернативы X».
- **Связанные темы:** вопросы, которые обычно задают следом.
- **Проверочные запросы:** поиск подтверждения конкретного факта.

### Пример
Пользователь спрашивает: «Нужен ли малому бизнесу сайт, если есть Telegram-канал?». Система может искать: «сайт или Telegram для бизнеса», «плюсы сайта для малого бизнеса», «индексируется ли Telegram в поиске», «стоимость лендинга», «Telegram-канал вместо сайта отзывы». Ответ соберут из источников, найденных по разным запросам.

### Что это значит для GEO
1. Страница может попасть в ответ по синтетическому запросу, которого нет ни в одном сервисе статистики.
2. Покрывать нужно не только главный вопрос, но и подвопросы, сравнения, проверки.
3. Полезно спрашивать у самой нейросети: «на какие подвопросы ты бы разбил этот вопрос?» — и закрывать их на сайте.
4. Раздел, который точно отвечает на узкий подвопрос, — самый вероятный кандидат в источники.

### Частый вопрос
**Где посмотреть синтетические запросы своей ниши?** Напрямую — нигде: поисковики их не публикуют. Но их можно смоделировать. Попросите нейросеть разбить вопрос клиента на подвопросы, посмотрите блок «Похожие вопросы» и подсказки поисковиков. Совпадения в этих списках — самые вероятные синтетические запросы.
