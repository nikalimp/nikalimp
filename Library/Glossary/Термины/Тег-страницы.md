# Тег-страницы

**English:** Tag Pages
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/tag-pages

## Определение

Тег-страницы — это страницы-подборки на сайте, которые собирают материалы по одной метке (тегу). В блоге тег «seo» открывает список всех статей с этой меткой, в интернет-магазине тег может объединять товары по свойству.

Теги нужны для навигации: человек находит материалы по теме, а поисковый робот получает дополнительные пути к страницам. При аккуратном использовании тег-страница может стать посадочной для запросов вида «статьи про SEO». Но на практике теги часто работают плохо: в них нет собственного текста, они дублируют категории и множатся без контроля.

Главный риск — создание множества слабых страниц с одним и тем же набором заголовков. Они [[Каннибализация|каннибализируют]] основные страницы, тратят [[Краулинговый бюджет|краулинговый бюджет]] и попадают в категорию «малоценных» страниц, которые поисковик может не включить в индекс.


Многие CMS, включая WordPress, создают страницы тегов автоматически, и владелец сайта может не заметить, как их стали сотни. Поэтому после запуска блога стоит проверить, сколько тег-страниц попало в индекс. В Яндекс Вебмастере и Search Console видно, какие адреса проиндексированы. Если рядом с полезными статьями в индексе оказались сотни тонких страниц-подборок, пора навести порядок.
### Как использовать теги
1. Заведите ограниченный список тегов, связанных с реальными темами сайта.
2. Не создавайте тег, под которым меньше 3–5 материалов.
3. Добавьте на тег-страницу уникальный заголовок и короткое вводное описание.
4. Решите, нужна ли страница в поиске: если нет, закройте её тегом [[Noindex]].
5. Проверяйте, не дублируют ли теги категории и друг друга.

### Типичные ошибки
- Создавать десятки одноразовых тегов к каждой статье.
- Оставлять на тег-страницах только список ссылок без текста.
- Использовать теги и категории с одинаковыми названиями.
- Открывать для индексации страницы пагинации тегов без необходимости.

### Чем отличается от категории
Категория — часть структуры сайта: иерархичная, обычно одна на материал. Тег — свободная метка: у материала может быть несколько тегов, и они не образуют иерархии. Категории обычно продвигают, теги чаще нужны для навигации.

### Частый вопрос
**Нужно ли закрывать теги от индексации?** Если у тегов нет собственной ценности и они повторяют содержимое категорий, их лучше закрыть через noindex. Если тег оформлен как полноценная тематическая подборка с текстом и приводит трафик, оставьте его в индексе.
