# Фасетная навигация

**English:** Faceted Navigation
**Категория:** [[Глоссарий — SEO]]
**URL:** nikalimp.ru/glossary/faceted-navigation

## Определение

Фасетная навигация — это система фильтров в каталоге, которая позволяет выбирать товары или материалы по нескольким признакам одновременно: цене, бренду, цвету, размеру, наличию. Каждый признак называется фасетом.

Для пользователя это удобно: он быстро сужает выбор. Для SEO у фасетной навигации две стороны. С одной стороны, страницы с фильтрами могут отвечать на реальные запросы вроде «чёрные кроссовки 42 размера». С другой, комбинации фильтров порождают огромное число адресов с почти одинаковым содержимым. Поисковый робот тратит [[Краулинговый бюджет|краулинговый бюджет]] на них, возникают [[Дубли страниц|дубли]] и [[Каннибализация|каннибализация]].

Поэтому задача — решить, какие комбинации оставить для индексации, а какие закрыть. Оставляют те, у которых есть реальный спрос в поиске и достаточно товаров. Остальные закрывают от индексации или от обхода.


Проблема особенно заметна на больших каталогах. Если в категории пять фильтров по десять значений, количество возможных комбинаций исчисляется сотнями тысяч, и даже небольшая доля из них, открытая для индексации, создаёт огромный пласт слабых страниц. Поэтому правила работы с фильтрами закладывают на старте разработки каталога, а не после того, как индекс сайта разросся.
### Как настроить фасетную навигацию для SEO
1. Выгрузите запросы и найдите комбинации фильтров, по которым ищут люди.
2. Для таких комбинаций сделайте постоянные чистые адреса с уникальными заголовком, описанием и текстом.
3. Остальные комбинации закройте через [[Noindex]], [[Canonical]] на основную категорию или правила в robots.txt.
4. Стандартизируйте порядок параметров в адресе, чтобы одна и та же выборка не имела нескольких URL.
5. Следите за числом проиндексированных страниц каталога в Вебмастере.

### Типичные ошибки
- Открыть к индексации все комбинации фильтров.
- Закрыть все фильтры, потеряв запросы с реальным спросом.
- Использовать одновременно noindex и запрет в robots.txt: робот не увидит noindex на закрытой странице.
- Выводить пустые страницы фильтров без товаров.

### Чем отличается от пагинации
[[Пагинация]] делит один длинный список на страницы. Фасетная навигация меняет выборку по признакам. Первая работает с объёмом, вторая со смыслом, и настройки для них разные.

### Частый вопрос
**Нужно ли индексировать страницы фильтров?** Только те, под которые есть поисковый спрос и достаточно товаров, например бренд плюс категория. Остальные комбинации лучше закрыть, чтобы не плодить дубли и не тратить краулинговый бюджет.
