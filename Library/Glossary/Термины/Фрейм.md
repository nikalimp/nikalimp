# Фрейм

**English:** Frame
**Категория:** [[Глоссарий — UI-UX дизайн]]
**URL:** nikalimp.ru/glossary/frame

## Определение

Фрейм (frame) — это контейнер в графическом редакторе, например в Figma, который задаёт область экрана или блока и вмещает в себя вложенные элементы.

В дизайне интерфейсов фрейм заменяет холст и артборд. Один фрейм соответствует экрану: например, 1440 на 900 пикселей для десктопа или 390 на 844 для смартфона. Внутри фреймов лежат другие фреймы, текст, фигуры и [[Компонент|компоненты]]. Вложенность позволяет собирать интерфейс по частям: страница, секция, карточка, кнопка. Так же устроены и вёрстка, и [[Атомарный дизайн|атомарный дизайн]].

Фрейм умеет больше обычной группы. Он обрезает содержимое по границам, задаёт [[Адаптив|адаптивное]] поведение через ограничения (constraints), поддерживает сетки, цвет заливки, скругления и [[Auto Layout]]. Благодаря этому макет можно растягивать и проверять на разных размерах экрана. Группа же просто объединяет элементы без собственных свойств.

### Пример
Дизайнер создаёт фрейм «Главная, десктоп» шириной 1440 пикселей. Внутри лежат фреймы секций: «Хедер», «Первый экран», «Услуги», «Футер». В секции «Услуги» три фрейма-карточки с Auto Layout. Если изменить текст в одной карточке, остальные подстроятся по высоте.

### Как работать с фреймами
1. Создавайте отдельный фрейм под каждый экран и называйте его понятно: «Главная, десктоп», «Корзина, мобильный».
2. Включайте Auto Layout там, где содержимое должно подстраиваться под размер.
3. Настройте сетку: колонки, отступы, [[Гаттер]].
4. Задайте ограничения, чтобы элементы правильно вели себя при изменении размера.
5. Группируйте логику вложенными фреймами с осмысленными именами, а не «Frame 1284».
6. Размещайте фреймы разных брейкпоинтов рядом, чтобы сравнивать их по [[Брейкпоинт|брейкпоинтам]].

### Типичные ошибки
- Хаотичные имена слоёв.
- Использование групп вместо фреймов.
- Фиксированные размеры там, где нужна адаптация.
- Элементы за границей фрейма.

### Кому и когда это нужно
Фреймы нужны дизайнерам интерфейсов, веб-дизайнерам и всем, кто делает макеты в Figma и подобных редакторах. Для разработчика правильная вложенность фреймов — подсказка, как верстать: блок становится контейнером, Auto Layout превращается в flex, а ограничения — в правила адаптива. Чем аккуратнее структура макета, тем меньше вопросов на этапе [[Хэндофф|передачи в разработку]].
### Не путайте с iframe
В вёрстке есть похожее слово — iframe, встроенный документ внутри страницы, например карта или видео. К фреймам в Figma он отношения не имеет. Это просто совпадение названий.

### Частый вопрос
**Чем фрейм отличается от группы в Figma?** Фрейм сам является контейнером: у него есть размер, заливка, сетка, обрезка и Auto Layout. Группа лишь объединяет слои и подстраивается под них. Для экранов и компонентов берите фреймы.
