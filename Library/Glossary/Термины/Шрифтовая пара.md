# Шрифтовая пара

**English:** Font Pairing
**Категория:** [[Глоссарий — Графический дизайн и бренд]]
**URL:** nikalimp.ru/glossary/font-pairing

## Определение

Шрифтовая пара — это сочетание двух шрифтов, которые используются вместе в проекте: обычно один для заголовков и один для основного текста. Хорошая пара выглядит цельно, но шрифты чётко различаются по роли.

Пара нужна, чтобы создать [[Визуальная иерархия|иерархию]] и характер. Заголовок задаёт тон, основной текст отвечает за читаемость. Если шрифты слишком похожи, но не одинаковы, возникает ощущение ошибки. Если слишком разные, композиция разваливается. Поэтому подбор строится на контрасте с общей логикой.

### Принципы подбора
- Контраст по роли: например, антиква для заголовков и гротеск для текста.
- Общие пропорции: высота строчных букв и ширина знаков должны быть соразмерны.
- Один акцент: выразительный только один шрифт, второй нейтральный.
- Одно семейство: можно использовать разные начертания одной гарнитуры, это самый безопасный вариант.
- Настроение: оба шрифта подчёркивают характер бренда.

### Как подобрать пару
1. Определите главный шрифт: тот, который задаёт характер.
2. Подберите к нему нейтральный партнёр с хорошей читаемостью.
3. Проверьте обе гарнитуры на кириллицу, начертания и цифры.
4. Соберите пример макета с заголовком, подзаголовком, текстом и кнопкой.
5. Посмотрите на разных размерах и экранах.
6. Зафиксируйте в стилях и [[Дизайн-система|дизайн-системе]].

### Примеры сочетаний
Классическая схема: заголовок антиквой, основной текст гротеском. Современная схема: геометрический гротеск для заголовков и нейтральный гуманистический для текста. Самая простая схема: одна гарнитура, но заголовки жирным начертанием, а текст обычным.

### Типичные ошибки
- Брать два похожих шрифта: разница выглядит случайной.
- Использовать три и больше семейства в одном проекте.
- Сочетать два выразительных шрифта: они спорят за внимание.
- Не проверить кириллицу: латинская пара красиво выглядит, а русская версия нет.
- Подбирать пару только по картинкам, не проверив на реальном тексте.

### Чем отличается от гарнитуры
[[Гарнитура]] — семейство шрифтов с общим рисунком. Пара — сочетание двух разных гарнитур в одном проекте.

### Пример
Для сайта юридической компании подойдёт антиква с характерным рисунком для заголовков и спокойный гротеск для текста. Заголовки выглядят солидно, основной текст легко читается на экране. Для приложения доставки возьмите один современный гротеск: заголовки сделайте жирными, а подписи обычными. Результат аккуратный и современный.

### Кому и когда нужно
Шрифтовую пару выбирают при разработке фирменного стиля, сайта, презентации или упаковки. Решение закрепляют в брендбуке, чтобы все материалы выглядели одинаково, даже если с ними работают разные люди. Пока пара не выбрана, макеты приходится переделывать при каждой смене шрифта.

### Частый вопрос
**Сколько шрифтов лучше использовать на сайте?** Достаточно двух, а в простых проектах хватит одного с разными начертаниями. Каждый новый шрифт увеличивает вес страницы и риск стилистического разнобоя.
