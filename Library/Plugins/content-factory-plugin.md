Content Factory (Контент-завод) — это плагин и набор шаблонов для ИИ-агента, который превращает ведение блога в предсказуемый еженедельный цикл: от анализа поисковых запросов до готовых статей, обложек, постов в Telegram и отчётов по трафику.

## Зачем нужен этот плагин

Когда нейросеть просят просто «напиши статью про SEO», она выдаёт общий текст без фактов, не в тоне компании и без привязки к реальному спросу. Content Factory задаёт жёсткую базу: голос бренда, проверенные факты, анти-ИИ стоп-лист и разделение этапов (отчёт → копирайтинг → публикация).

## Структура файлов в проекте

- `content/factory/config.json` — параметры сайта, частота выхода, каналы и стек.
- `content/factory/voice.md` — правила тона, словарь бренда и анти-ИИ стоп-лист.
- `content/factory/facts.md` — проверенные цифры, цены, кейсы и реквизиты (агент не имеет права выдумывать факты вне этого файла).
- `content/factory/plan.md` — очередь тем с целевыми запросами и статусами (`planned`, `ready`, `published`).

## Инструкция по установке

1. Создайте структуру папок контент-завода внутри сайта:

```bash
mkdir -p content/factory/reports content/factory/queue
touch content/factory/config.json content/factory/voice.md content/factory/facts.md content/factory/plan.md
```

2. Заполните `voice.md` примерами реальных текстов автора и списком запрещённых штампов, а в `facts.md` выпишите реальные цифры, услуги и кейсы компании.
3. Подключите проверки Главреда (`glavred.mjs`) и Типографа (`typograf.mjs`), чтобы каждая новая статья автоматически проверялась до коммита.
4. Настройте две задачи по расписанию: субботний цикл (отчёт недели + написание новых статей в очередь `ready`) и публикацию по будням (перенос готовой статьи в `content/blog/` и push в `main`).

## Частые ошибки

- Запускают конвейер без заполненного `facts.md` — статьи получаются общими и не продают услуги компании.
- Публикуют статьи сразу без очереди `ready` и без проверки Главредом.
- Не сверяют темы плана с реальными запросами из Search Console и Вебмастера.

## Частые вопросы

### Подходит ли Content Factory для сайтов не на Next.js?

Да. Плагин использует адаптеры стеков: статьи в Markdown можно выгружать в Next.js, Astro, Hugo или публиковать через API в WordPress и Ghost.

### Нужно ли человеку вычитывать каждую статью?

На старте — да, чтобы откалибровать `voice.md` и `facts.md` за первые 1–2 недели. После настройки достаточно просматривать еженедельный отчёт и план тем.

### Как контент-завод помогает попадать в ответы нейросетей?

Каждая статья строится по правилам GEO: прямой ответ на вопрос в первом абзаце, конкретные таблицы, списки, проверяемые цифры и блок FAQ с разметкой `FAQPage`.
