Главред CLI — локальный скрипт проверки русских текстов по принципам информационного стиля Максима Ильяхова. Он работает без внешнего API, прямо в терминале и в GitHub Actions, оценивает каждую страницу сайта по шкале от 0 до 10 и показывает конкретные стоп-слова.

## Зачем нужен этот плагин

ИИ-модели склонны писать гладкий, но пустой текст с канцеляритом («осуществляется», «является», «данный»), неподтверждёнными оценками («уникальный», «высококачественный») и вводными конструкциями. Локальная проверка Главреда автоматически ловит такой мусор на этапе сборки сайта и не пускает слабые тексты в релиз.

## Что проверяет скрипт

- Канцеляризмы и отглагольные существительные (замена на сильный глагол).
- Оценочные слова без фактов и цифр («лучший», «эффективный», «профессиональный»).
- Усилители, штампы, неопределённости («различные», «некоторые») и лишние вводные слова.
- Среднюю длину предложений и плотность стоп-слов на 100 слов текста.

## Инструкция по установке

1. Положите модуль `scripts/glavred.mjs` со словарём стоп-слов и правилами подсчёта в папку `scripts/` вашего проекта.
2. Подключите проверку в общий скрипт сборки `scripts/check.mjs`, чтобы проверять весь видимый текст внутри `<main>` на каждой странице из `sitemap.xml`:

```js
import { glavred } from "./glavred.mjs";

const res = glavred(mainText);
if (res.score < 6.5) throw new Error(`Главред ниже 6.5 (${res.score})`);
```

3. Для точечной проверки новой статьи запускайте команду из терминала:

```bash
node scripts/glavred.mjs content/blog/my-article.md
```

4. Юридические документы (`privacy-policy`, `consent`, `terms`) добавьте в массив `glavredSkip` в `scripts/check.local.mjs`, чтобы не искажать обязательные формулировки закона.

## Частые ошибки

- Пытаются довести оценку до 10 из 10 любой ценой, удаляя нужные профессиональные термины.
- Не разделяют пороги: для экспертных статей цель — 8.0+, для продающих лендингов и карточек — 7.5+.
- Проверяют сырой Markdown вместе с блоками кода и frontmatter вместо чистого видимого текста.

## Частые вопросы

### Заменяет ли локальный скрипт сайт glvrd.ru?

Локальный скрипт закрывает 90 % рутинной чистки и работает автоматически в CI/CD без ограничений и сети. Для тонкой редактуры главного лендинга текст можно дополнительно прогнать на сайте `glvrd.ru`.

### Почему оценка ниже 6.5 блокирует сборку?

Оценка ниже 6.5 почти всегда означает тяжёлый канцелярит или сырой неотредактированный текст от нейросети. Жёсткий порог защищает качество сайта при автоматических публикациях.

### Работает ли скрипт с английскими текстами?

Нет. Словарь правил рассчитан только на русский язык; для англоязычных страниц проверку отключают через `glavredSkip`.
