Google Search Console MCP подключает официальный Search Analytics API прямо к ИИ-агенту. Агент сам запрашивает статистику по запросам и страницам за любой период, находит падения позиций и предлагает конкретные правки заголовков для роста CTR.

## Зачем нужен этот плагин

Выгружать CSV-таблицы из интерфейса Search Console вручную и копировать их в чат долго и неудобно — теряется контекст и ограничивается число строк. Через MCP агент напрямую читает до тысяч строк статистики, группирует страницы по разделам и сразу сверяет их с кодом сайта.

## Инструкция по установке

1. В **Google Cloud Console** создайте проект, включите `Google Search Console API` и создайте сервисный аккаунт (Service Account).
2. Скачайте JSON-ключ сервисного аккаунта и сохраните его вне репозитория, например в `~/.secrets/gsc-key.json`.
3. В интерфейсе **Google Search Console** откройте нужный сайт → «Настройки» → «Пользователи и разрешения» и добавьте email сервисного аккаунта с правами «Полный» или «Ограниченный» (для чтения хватает ограниченного).
4. Добавьте MCP-сервер в конфиг `.mcp.json` (Claude Code) или `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "gsc": {
      "command": "npx",
      "args": ["-y", "mcp-server-gsc"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/Users/USER/.secrets/gsc-key.json"
      }
    }
  }
}
```

5. Перезапустите агента и запросите сводку по кликам за последние 28 дней.

## Как проверить, что всё работает

Напишите агенту: «Покажи топ-10 страниц `sc-domain:example.ru` по показам за последние 28 дней с CTR ниже 2 %». Если права выданы верно, агент вернёт таблицу с реальными адресами, показами, кликами и средней позицией.

## Частые ошибки

- Забывают добавить email сервисного аккаунта в пользователи ресурса в Search Console — API возвращает ошибку `403 Forbidden`.
- Путают формат адреса ресурса: для доменного ресурса нужно указывать `sc-domain:example.ru`, а для URL-префикса — `https://example.ru/`.
- Кладут JSON-файл с ключом внутрь папки Git-репозитория.

## Частые вопросы

### Безопасно ли давать ИИ-агенту доступ к Search Console?

Да, если выдать сервисному аккаунту права только на чтение («Ограниченный»). Агент сможет анализировать статистику, но не сможет менять настройки сайта.

### За какой период доступны данные через API?

Search Console API отдаёт ежедневную статистику за последние 16 месяцев с задержкой 2–3 дня от текущей даты.

### Работает ли этот MCP для нескольких сайтов сразу?

Да. Добавьте один и тот же email сервисного аккаунта во все нужные ресурсы в Search Console — агент сможет сравнивать все проекты из одной сессии.
