Obsidian и LLM Wiki — это архитектура долговременной памяти для ИИ-агентов на базе обычных Markdown-файлов и JSON-паспортов. Вместо того чтобы каждый раз заново объяснять контекст проекта, агент читает структурированную базу знаний за секунду.

## Зачем нужен этот плагин

Контекстное окно любой нейросети конечно и обнуляется в новом чате. Когда стандарты работы, паспорта сайтов, история решений и заметки по клиентам лежат в единой системе Markdown-файлов с перекрёстными ссылками, любой агент сразу знает все правила и не повторяет старых ошибок.

## Как устроена база знаний

- **Паспорта проектов (`.projects/<имя>.json`)** — сайт, репозиторий, ресурсы SEO, секция Todoist, пороги сигналов.
- **Статус проекта (`STATUS.md`)** — текущий этап, последние обновления и открытые долги.
- **Стандарты (`Resources/Frameworks/`)** — проверенные гайды: AI-Ready сайт, публикация, дизайн-предпочтения.
- **Справочники и вики** — короткие атомарные заметки, связанные ссылками `[[Имя заметки]]`.

## Инструкция по установке

1. Установите бесплатное приложение **Obsidian** и откройте в нём рабочую папку базы знаний (vault).
2. Создайте структуру папок для проектов, стандартов и паспортов:

```bash
mkdir -p .projects Resources/Frameworks Projects
```

3. Добавьте в корень каждого проекта файл `AGENTS.md` со ссылкой на `STATUS.md` и нужные стандарты, чтобы ИИ-агент читал их первым шагом.
4. Для программного чтения паспортов и сводок подключите локальный MCP-сервер (например, `obsidian-mcp` или собственный лёгкий Node-скрипт поверх папки vault).

## Как проверить, что всё работает

Откройте чистый чат с агентом и спросите: «Какой сейчас статус проекта и какие есть открытые долги?». Агент должен прочитать `STATUS.md` и паспорт и ответить точными фактами без наводящих вопросов.

## Частые ошибки

- Превращают базу в свалку длинных полотен без структуры — агент тратит контекст впустую.
- Хранят секреты и пароли прямо в заметках внутри публичного репозитория (приватный vault и публичный код всегда должны быть разделены).
- Забывают обновлять `STATUS.md` в конце задачи, из-за чего память быстро устаревает.

## Частые вопросы

### Чем подход LLM Wiki лучше обычного векторного поиска (RAG)?

Для рабочей базы из десятков и сотен документов явная структура (паспорта, оглавления, ссылки) работает точнее векторного поиска: агент всегда читает полный актуальный документ, а не случайные обрывки абзацев.

### Работает ли Obsidian без интернета и в России?

Да. Все файлы хранятся локально на вашем компьютере в открытом формате Markdown — без привязки к облаку и риска блокировок.

### Нужно ли покупать платную подписку Obsidian?

Нет. Для локальной работы с ИИ-агентами достаточно бесплатной версии Obsidian; синхронизацию можно настроить через обычный Git или iCloud.
