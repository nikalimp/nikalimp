Playwright MCP — официальный MCP-сервер от Microsoft, который даёт ИИ-агенту «глаза и руки» в настоящем браузере. Агент сам открывает локальный или живой сайт, снимает скриншоты, проверяет мобильную ширину 360 px, кликает по формам и читает ошибки в консоли.

## Зачем нужен этот плагин

Без доступа к браузеру ИИ-агент оценивает вёрстку вслепую — только по коду. Из-за этого он не видит наехавших заголовков, горизонтального скролла на телефоне, обрезанных кнопок или ошибок JavaScript. Playwright MCP закрывает этот разрыв и превращает агента в полноценного QA-инженера.

## Инструкция по установке

1. Убедитесь, что установлен Node.js версии 18 или выше.
2. Подключите сервер одной командой в **Claude Code**:

```bash
claude mcp add playwright -- npx @playwright/mcp@latest
```

3. Или добавьте конфиг вручную в `.mcp.json` (Claude Code) / `.cursor/mcp.json` (Cursor):

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

4. При первом запуске Playwright при необходимости установит браузер Chromium:

```bash
npx playwright install chromium
```

## Как проверить, что всё работает

Запустите локальный сервер (`npm run dev`) и попросите агента: «Открой `http://localhost:3010` на ширине 360 px, проверь консоль на ошибки и сделай скриншот первого экрана». Агент откроет страницу, проверит логи и пришлёт снимок.

## Частые ошибки

- Забывают закрыть фоновый браузер или запускают десятки вкладок без очистки сессии.
- Тестируют только десктоп 1440 px и пропускают узкий мобильный экран 360 px.
- Используют Playwright для обхода защит и капч — сервер предназначен для тестирования своих сайтов и легальной автоматизации.

## Частые вопросы

### Чем Playwright MCP отличается от обычного Playwright?

Обычный Playwright требует заранее написанных тестовых сценариев на TypeScript. Playwright MCP позволяет ИИ-агенту исследовать страницу в реальном времени через дерево доступности (accessibility snapshot) и действовать по ситуации.

### Требует ли Playwright MCP платной подписки?

Нет. Пакет `@playwright/mcp` полностью бесплатный и распространяется с открытым исходным кодом.

### Можно ли использовать его для GEO-замеров?

Да. Агент открывает чистую неавторизованную сессию браузера, чтобы история поиска не искажала ответы нейросетей.
