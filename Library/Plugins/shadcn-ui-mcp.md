shadcn/ui MCP — официальный MCP-сервер, который даёт ИИ-агенту прямой доступ к актуальному реестру компонентов, блоков, примеров кода и команд установки `shadcn/ui`. Агент перестаёт галлюцинировать устаревшие пропсы и ставит проверенные компоненты напрямую в проект.

## Зачем нужен этот плагин

Без MCP-сервера нейросети часто генерируют компоненты по памяти из старых версий библиотек: путают классы Tailwind v3 и v4, забывают про доступность клавиатуры и придумывают несуществующие импорты. Через MCP агент сам читает актуальную документацию реестра и собирает интерфейс в единой системе.

## Инструкция по установке

1. Инициализируйте `shadcn/ui` в вашем Next.js-проекте, если ещё не сделали этого:

```bash
npx shadcn@latest init
```

2. Подключите MCP-сервер одной командой (она автоматически определит Claude Code или Cursor и запишет конфиг):

```bash
npx shadcn@latest mcp init
```

3. Если вы настраиваете MCP вручную, добавьте блок в `.mcp.json` в корне проекта (для Claude Code) или в `.cursor/mcp.json` (для Cursor):

```json
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

4. Перезапустите сессию ИИ-агента, чтобы он подхватил новые инструменты реестра.

## Как проверить, что всё работает

Попросите агента: «Найди в реестре shadcn блок навигации и карточку с формой, покажи доступные варианты». Агент вызовет инструменты MCP `search_items_in_registries` и `view_items_in_registries` и вернёт реальные компоненты с точными командами установки.

## Частые ошибки

- Забывают настроить токены в `globals.css` и оставляют стандартную серую тему shadcn без характера бренда.
- Оборачивают компоненты из `src/components/ui` в лишние обёртки вместо того, чтобы править их исходный код.
- Устанавливают тяжёлые сторонние блоки из внешних реестров с `framer-motion` на контентный сайт, замедляя загрузку.

## Частые вопросы

### Работает ли shadcn/ui MCP с Tailwind CSS v4?

Да. Официальный реестр поддерживает Tailwind CSS v4, CSS-переменные и React 19 в новых версиях Next.js.

### Можно ли подключать через этот MCP свои приватные реестры?

Да. В файле `components.json` проекта можно указать дополнительные реестры (включая внутренние библиотеки компании), и MCP-сервер автоматически сделает их доступными агенту.

### Нужен ли API-ключ для базового реестра shadcn/ui?

Нет. Официальный реестр `ui.shadcn.com` полностью бесплатный и открытый, ключ не требуется.
