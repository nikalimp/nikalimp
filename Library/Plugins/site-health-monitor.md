Модуль мониторинга и еженедельных снимков собирает ключевые показатели всех сайтов в один JSON-слепок по расписанию: доступность HTTP, скорость PageSpeed Insights, трафик из Вебмастера и GSC, выход статей и количество заявок. При выходе за порог система сразу шлёт сигнал в Telegram.

## Зачем нужен этот плагин

Вручную заходить в десяток панелей аналитики и проверять скорость каждого сайта раз в неделю невозможно. Автоматический снимок копит честную недельную историю в репозитории и мгновенно подсвечивает аномалии: падение трафика, просадку Core Web Vitals или сорванную публикацию.

## Инструкция по установке

1. Получите бесплатный ключ **PageSpeed Insights API** в Google Cloud Console и сохраните его в секретах (`PSI_API_KEY`).
2. Задайте пороги сигналов в паспорте каждого проекта (например, минимальный PageSpeed 85, допустимое падение кликов не более 20 %).
3. Настройте запуск скрипта сбора данных в `.github/workflows/data.yml` по cron-расписанию раз в неделю:

```yaml
name: Weekly Data
on:
  schedule:
    - cron: "0 5 * * 6"
jobs:
  snapshot:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: node scripts/health-snapshot.mjs
        env:
          PSI_API_KEY: ${{ secrets.PSI_API_KEY }}
          TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
```

4. Сохраняйте результаты снимков в историю (`.json` или `.md`), чтобы Дежурный монитор мог сравнивать текущую неделю с прошлым месяцем.

## Как проверить, что всё работает

Запустите скрипт вручную через вкладку **Actions → Run workflow** или локально из терминала. В папке отчётов должен появиться свежий снимок с цифрами по каждому проекту, а при тестовом занижении порога — прийти уведомление в Telegram.

## Частые ошибки

- Запускают замеры PageSpeed без API-ключа — Google быстро ограничивает анонимные запросы ошибкой `429 Too Many Requests`.
- Настраивают слишком чувствительные алерты, из-за которых команда начинает игнорировать уведомления.
- Не сохраняют историю снимков — без прошлых точек невозможно увидеть тренд роста или падения.

## Частые вопросы

### Сколько стоит PageSpeed Insights API?

API полностью бесплатен при лимите до 25 000 запросов в день — этого с запасом хватает на десятки сайтов.

### Как мониторинг проверяет работу сайта из России?

Помимо глобальных проверок GitHub Actions, доступность и редиректы проверяются прямыми HTTP-запросами к российскому хостингу и сверкой с визитами в Яндекс Метрике.

### Можно ли присылать клиенту готовый отчёт на основе этих снимков?

Да. Раз в месяц накопленные снимки автоматически собираются в аккуратный PDF-отчёт в стиле бренда клиента.
