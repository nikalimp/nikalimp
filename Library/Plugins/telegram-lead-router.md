LeadForm и Telegram-роутер — лёгкая система приёма заявок для статических сайтов без платных CRM, сторонних виджетов и тяжёлых капч. Форма на фронтенде отправляет данные в простой `public/api/lead.php`, который сохраняет лид в журнал и мгновенно шлёт уведомление в Telegram.

## Зачем нужен этот плагин

Статические сайты на Next.js (`output: "export"`) не имеют Node.js-сервера на обычном PHP-хостинге. Вместо подключения платных конструкторов форм или зарубежных сервисов, один небольшой PHP-файл в `public/api/lead.php` закрывает приём заявок, защиту от ботов и резервное копирование.

## Инструкция по установке

1. Создайте бота в `@BotFather`, получите `bot_token` и узнайте свой `chat_id`.
2. Положите конфиг **вне публичной папки сайта** (например, `/var/www/user/data/leads/config.php`), чтобы к нему нельзя было обратиться по HTTP:

```php
<?php
return [
  'bot_token' => '123456:ABC-DEF...',
  'chat_id'   => '123456789',
  'email'     => 'hello@example.ru',
];
```

3. Разместите обработчик `public/api/lead.php`: он проверяет скрытое поле-ловушку `company` (если заполнено — молча отбрасывает спам), дописывает строку в `leads.jsonl`, отправляет сообщение через Telegram Bot API и дублирует на почту.
4. На стороне Next.js подключите компонент `LeadForm`: при отправке он делает `fetch("/api/lead.php", { method: "POST", ... })` и передаёт цель `lead` с параметрами `offer` и `page` в Яндекс Метрику.

## Как проверить, что всё работает

Отправьте тестовую заявку с любой страницы сайта. В течение 2 секунд должно прийти сообщение в Telegram с именем, контактом, адресом страницы и названием оффера, а на сервере появится новая запись в `leads.jsonl`.

## Частые ошибки

- Кладут `config.php` с токеном бота прямо в `public/api/` — так файл рискует попасть в Git или открыться снаружи.
- Забывают чекбокс согласия на обработку персональных данных по 152-ФЗ со ссылкой на `/consent/`.
- Не проверяют работу формы при отключённом JavaScript (стандартный `action="/api/lead.php" method="post"` подстраховывает сбои скриптов).

## Частые вопросы

### Надёжно ли работает защита от спама без капчи?

Скрытое поле-ловушка (honeypot) плюс проверка времени заполнения и лимита запросов с одного IP отсекают больше 95 % автоматического спама, не мешая живым клиентам.

### Что будет, если Telegram API временно не ответит?

Обработчик сначала записывает заявку в `leads.jsonl` и отправляет письмо на почту. Лид не потеряется даже при сбое мессенджера.

### Можно ли подключить форму к CRM позже?

Да. В тот же `lead.php` добавляется один POST-запрос на вебхук AmoCRM, Bitrix24 или Notion без изменения кода фронтенда.
