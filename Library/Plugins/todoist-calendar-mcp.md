Связка MCP-серверов Todoist и Google Календаря превращает ИИ-агента в надёжного планировщика: он видит актуальные задачи по каждому проекту, сверяет свободные окна в расписании, ставит встречи и напоминает о регулярных отчётах.

## Зачем нужен этот плагин

Договорённости с клиентами часто рождаются в коде, отчётах или чате, а переносить их вручную в трекер и календарь постоянно некогда. Когда у агента есть прямой доступ к Todoist и Календарю, он сам раскладывает найденные проблемы из аудита по задачам и держит ритм всех проектов.

## Инструкция по установке

1. Получите **API-токен Todoist** в настройках аккаунта: `Настройки → Интеграции → Для разработчиков → Копировать API-токен`.
2. Подключите Todoist MCP в `.mcp.json` (Claude Code) или `.cursor/mcp.json` (в имени переменной укажите название сервиса в верхнем регистре и `_API_TOKEN`, как в документации пакета):

```json
{
  "mcpServers": {
    "todoist": {
      "command": "npx",
      "args": ["-y", "@abhiz123/todoist-mcp-server"],
      "env": {
        "API_TOKEN": "ВАШ_ТОКЕН"
      }
    }
  }
}
```

3. Для **Google Календаря** создайте OAuth-клиент в Google Cloud Console (включите `Google Calendar API`), пройдите разовую авторизацию и укажите путь к токену в конфиге календарного MCP-сервера.
4. Закрепите в паспорте каждого проекта название его секции в Todoist — тогда агент сразу знает, куда складывать задачи по конкретному сайту.

## Как проверить, что всё работает

Спросите агента: «Что у меня запланировано на завтра в календаре и какие просроченные задачи висят в Todoist?». Агент опросит оба сервиса и выдаст объединённую сводку.

## Частые ошибки

- Хранят все проекты в одном общем списке «Входящие» без секций — агент не может отфильтровать задачи конкретного клиента.
- Не указывают часовой пояс при создании встреч в Google Календаре.
- Разрешают агенту автоматически удалять задачи без подтверждения (лучше ограничиваться созданием, чтением и переносом срока).

## Частые вопросы

### Работает ли Todoist API на бесплатном тарифе?

Да. Бесплатного тарифа Todoist полностью хватает для подключения MCP, работы с проектами, секциями и дедлайнами.

### Может ли агент ставить повторяющиеся задачи на отчёты?

Да. Todoist понимает естественные формулировки повторения вроде `every 1st` (первого числа каждого месяца) или `every Saturday`.

### Как защитить API-токен от утечки?

Передавайте токен через переменные окружения операционной системы или локальный файл вне Git-репозитория, никогда не коммитьте `.mcp.json` с ключами.
