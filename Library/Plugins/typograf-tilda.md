Типограф CLI — локальный скрипт для автоматической расстановки русской типографики как в Tilda. Он прогоняет исходники и Markdown-статьи перед сборкой Next.js, не трогая код, URL, email и frontmatter.

## Зачем нужен этот плагин

Вручную расставлять «ёлочки», длинное тире и неразрывные пробелы после каждого предлога в сотнях страниц и статей невозможно. Без типографа в конце строк остаются висячие союзы, прямые кавычки `"..."` и дефисы вместо тире. Автоматический шаг в `prebuild` решает задачу раз и навсегда.

## Что исправляет скрипт

- Заменяет прямые кавычки на «ёлочки» и вложенные „лапки“.
- Ставит длинное тире `—` в предложениях и короткое `–` в числовых диапазонах (`5–10`).
- Добавляет неразрывный пробел (`U+00A0`) после предлогов, союзов, частиц и между числом и единицей измерения (`40 000 ₽`, `5 дней`).
- Меняет три точки `...` на многоточие `…` и аккуратно отбивает инициалы.
- Полностью пропускает блоки кода в Markdown, HTML-теги, адреса ссылок и параметры.

## Инструкция по установке

1. Скопируйте модуль `src/lib/typograf.mjs` и CLI-обёртку `scripts/typograf.mjs` в ваш проект Next.js.
2. Добавьте команды в `package.json`:

```json
{
  "scripts": {
    "typograf": "node scripts/typograf.mjs",
    "typograf:check": "node scripts/typograf.mjs --check",
    "prebuild": "node scripts/typograf.mjs"
  }
}
```

3. Для динамических текстов из Markdown или CSV импортируйте функцию `typograf()` прямо в парсере данных (`src/lib/`):

```ts
import { typograf } from "./typograf.mjs";

const cleanTitle = typograf(rawTitle);
```

4. Запустите `npm run typograf` — повторный запуск не внесёт ни одного лишнего изменения (скрипт идемпотентен).

## Частые ошибки

- Прогоняют через типограф блоки кода с промптами или CSS — копируемый код ломается из-за «ёлочек». Всегда разделяйте текст и ```` ```...``` ```` перед обработкой.
- Используют строковые литералы с предлогами как жёсткие ключи TypeScript-типов: после прогона пробел внутри литерала становится неразрывным, поэтому ключи лучше нормализовать.

## Частые вопросы

### Нужен ли интернет или внешний API для работы Типографа?

Нет. Скрипт работает локально на чистом JavaScript без внешних зависимостей и занимает доли секунды.

### Не ломает ли неразрывный пробел поиск по сайту?

При сборке поискового индекса (`search-index.ts`) символы `U+00A0` автоматически заменяются на обычные пробелы, поэтому поиск находит любые фразы без проблем.

### Подходит ли этот Типограф для английских сайтов?

Нет. Правила кавычек «ёлочек» и отбивки тире специфичны для русского языка. Для английских страниц используют типографские правила `en` (кавычки “ ” и em-dash без пробелов).
