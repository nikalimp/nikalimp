Подключение Яндекс Метрики через MCP и API даёт ИИ-агенту доступ к реальным визитам, источникам переходов (включая реферальный трафик из ChatGPT, Perplexity и Алисы), глубине просмотра и достижению целей заявок.

## Зачем нужен этот плагин

Поиск показывает только клики, но не отвечает на главный вопрос бизнеса: какие страницы реально приносят заявки. Связка Яндекс Метрики с ИИ-агентом позволяет видеть конверсию каждого раздела, сравнивать офферы форм и отслеживать переходы из нейросетей в еженедельных отчётах.

## Инструкция по установке

1. Создайте OAuth-приложение на `oauth.yandex.ru` с правом `metrika:read` и получите OAuth-токен.
2. Узнайте номер счётчика сайта (например, `12345678`) и сохраните токен в локальном `.env` или в GitHub Secrets (`YANDEX_METRIKA_TOKEN`).
3. Настройте на сайте отправку целей при заявке и кликах по мессенджерам (`lead`, `click_telegram`, `click_booking`):

```ts
window.ym?.(METRIKA_ID, "reachGoal", "lead", {
  offer: offerId,
  page: window.location.pathname,
});
```

4. Подключите MCP-сервер Метрики в конфиг агента (или используйте локальный CLI-скрипт запросов к `https://api-metrika.yandex.net/stat/v1/data`):

```json
{
  "mcpServers": {
    "yandex-metrica": {
      "command": "npx",
      "args": ["-y", "yandex-metrica-mcp"],
      "env": {
        "YANDEX_METRIKA_TOKEN": "ВАШ_ТОКЕН"
      }
    }
  }
}
```

## Как проверить, что всё работает

Попросите агента выгрузить визиты и конверсии по цели `lead` за последние 28 дней с разбивкой по странице входа. Агент обратится к API Метрики и вернёт сводку по самым конверсионным разделам сайта.

## Частые ошибки

- Забывают завести JavaScript-цели (`lead`, `click_telegram`) в интерфейсе самой Метрики — события уходят из браузера, но не попадают в отчёт по целям.
- Подключают токен без прав `metrika:read` или от аккаунта без гостевого доступа к счётчику.
- Не фильтруют переходы по `utm_source` и реферерам нейросетей (`chatgpt.com`, `perplexity.ai`, `alice.yandex.ru`).

## Частые вопросы

### Можно ли отслеживать переходы из ChatGPT и Perplexity в Яндекс Метрике?

Да. В отчёте «Источники → Сайты» и через API по параметру `ym:s:referer` видны переходы с доменов `chatgpt.com`, `perplexity.ai`, `claude.ai` и `deepseek.com`.

### Работает ли API Яндекс Метрики на бесплатном тарифе?

Да. API отчётов и передача JavaScript-целей полностью бесплатны для всех счётчиков Яндекс Метрики.

### Как часто обновляются данные в API?

Базовые визиты и цели появляются в отчётах в течение 5–15 минут после действия пользователя на сайте.
