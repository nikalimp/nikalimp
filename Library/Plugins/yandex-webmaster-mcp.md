Связка Яндекс Вебмастер + IndexNow решает две главные задачи SEO в Рунете: даёт ИИ-агенту доступ к реальным кликам, показам и ошибкам индексации в Яндексе, а после каждой выкладки сайта мгновенно отправляет новые и обновлённые URL на переобход.

## Зачем нужен этот плагин

Обычно робот Яндекса узнаёт о новой статье или каталоге через несколько дней или недель. Протокол IndexNow сокращает это время до часов. А подключение API Вебмастера к ИИ-агенту позволяет сравнивать периоды 28 к 28 дням и ловить вылетевшие страницы автоматически.

## Инструкция по установке

1. **Настройте IndexNow** для мгновенного переобхода: сгенерируйте 32-символьный hex-ключ и положите его в корень сайта `public/<ключ>.txt` (внутри файла — сам ключ).
2. Добавьте скрипт `scripts/indexnow.mjs`, который после деплоя отправляет изменённые URL на `https://yandex.com/indexnow`:

```bash
curl -X POST "https://yandex.com/indexnow" \
  -H "Content-Type: application/json" \
  -d '{"host":"example.ru","key":"ВАШ_КЛЮЧ","urlList":["https://example.ru/new-page/"]}'
```

3. **Подключите API Яндекс Вебмастера** к ИИ-агенту: создайте OAuth-приложение на `oauth.yandex.ru` с правами `webmaster:hostinfo` и `webmaster:verify`, получите токен и сохраните его в переменных окружения (`YANDEX_WEBMASTER_TOKEN`) или в GitHub Secrets.
4. Передайте токен в MCP-сервер аналитики или скрипт выгрузки, чтобы агент мог запрашивать список хостов, популярные запросы и статусы индексации.

## Как проверить, что всё работает

Откройте `https://ваш-домен/<ключ>.txt` в браузере — должен вернуться чистый ключ с кодом `200 OK`. После тестовой отправки одного URL через `indexnow.mjs` сервер Яндекса вернёт статус `200` или `202 Accepted`.

## Частые ошибки

- Отправляют в IndexNow адреса, которые ещё не успели выложиться на хостинг (нужно вызывать скрипт строго после шага деплоя).
- Отправляют в IndexNow редиректы или страницы с `noindex` — поисковик снижает доверие к таким уведомлениям.
- Коммитят OAuth-токен в открытый репозиторий вместо `.env` и GitHub Secrets.

## Частые вопросы

### Работает ли IndexNow для Google?

Нет. IndexNow поддерживают Яндекс, Bing, Seznam и Naver. Для Google индексация ускоряется через секционный `sitemap.xml` и Google Search Console.

### Есть ли лимит на количество URL в одном запросе IndexNow?

В одном POST-запросе можно передать до 10 000 адресов, но на практике лучше отправлять только реально добавленные или изменённые страницы.

### Зачем нужен доступ к Вебмастеру, если уже есть Яндекс Метрика?

Метрика показывает поведение людей уже на сайте, а Вебмастер — показы в выдаче, средние позиции, CTR, ошибки краулера и исключённые из индекса страницы.
