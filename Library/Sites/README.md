# Коллекция сайтов

Каталог для страницы [nikalimp.ru/sites/](https://nikalimp.ru/sites/): красивые сайты по категориям и нишам. Продукт описан в [[Сайт NikAlimp]]. На сайте источник виден только на странице примера (строка «Источник»).

- `sites.json` — данные сайта: сайты, категории, ниши, справочник источников `sources`. Руками не правится, собирается скриптом `.site/scripts/sites-import.mjs`.
- `rollout.json` — сколько самых свежих сайтов опубликовано (`published`). Страницы выпускаем партиями: чтобы открыть следующую партию, увеличьте число.
- `source/` — выгрузка источника Made on Tilda (`src: "madeontilda"`): `crawl.py` (список галереи через API `mot.tildacdn.com` → `state.json`), `sites.py` (разбор главной каждого сайта → `sites.jsonl`), `niche.csv` (ниша каждого сайта, `uid,slug`). Файлы `cls*.tsv` — временные, их можно удалить.

## Новый источник
Добавьте выгрузку в `source/<источник>/`, ключ и название — в `sources` скрипта импорта, поле `src` — каждому сайту. Категории и ниши — те же.

## Что берём
Название и обложку как в источнике, категорию, дату публикации (для порядка, на сайте не показываем), лайки. С главной сайта — meta description, число блоков, сколько свёрстано вручную, и признаки: форма, квиз, корзина, видео, карта, лента статей. Обложки и скриншоты грузятся с CDN источника, к себе не копируем. Автора и дату на сайте не показываем.

Категории — как в галерее Made on Tilda: Бизнес, Интернет-магазины, Мероприятия, Медиа, Портфолио, Образование, Персональные, Другое. Подкатегории — 28 ниш (список NICHES в скрипте импорта); страница подкатегории появляется от 6 сайтов.

## Обновление (1-е число каждого месяца, задача по расписанию)
1. `cd source && rm state.json && python3 crawl.py` — повторять, пока в выводе не будет `done`.
2. `python3 sites.py` — повторять, пока строк в `sites.jsonl` не станет столько же, сколько сайтов.
3. Новым сайтам — ниша в `niche.csv` (агент классифицирует по заголовку и описанию).
4. В `.site`: `node scripts/sites-import.mjs`; в `rollout.json` прибавить число новых сайтов, чтобы старые страницы не выпали.
5. Сборка и `npm run check`, коммит в main, выкладка `gh workflow run deploy.yml`.
