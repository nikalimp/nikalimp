Aiesa.ru — российский разработчик и провайдер ИИ для обработки речи. Через единый API сервис даёт распознавание речи (STT), синтез (TTS) и LLM-аналитику. Данные остаются в России, а решение соответствует 152-ФЗ. Доступен пробный период.

## Для кого
- Разработчики и ИИ-стартапы.
- Интеграторы.
- Крупный бизнес, которому нужна обработка речи и LLM-аналитика на современных моделях без нарушения 152-ФЗ.

## Какую задачу решает
Почти каждый продукт сегодня использует ИИ, но в России возникает тупик. Зарубежные API создают риски по 152-ФЗ. Собственная инфраструктура стоит дорого. Локальные проприетарные решения заметно отстают от мирового рынка.

Aiesa.ru закрывает весь путь обработки речи одним API, а данные хранятся в России. Распознавание умеет работать со смешанной речью и разделять говорящих. Рассуждающие модели LLM обрабатывают результат расшифровки.

## Возможности
- Единый API для всего пайплайна обработки речи.
- STT: библиотека терминов, нормализация, диаризация, обработка смешанной речи.
- Поддержка ссылок на аудио и два режима обработки.
- Рассуждающие LLM-модели для анализа расшифровок.
- Бесшовная передача результата распознавания в LLM.
- Локализация данных в РФ.
