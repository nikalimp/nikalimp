Аквинт — приложение для простого учёта денег малого бизнеса. Приход и расход записываются в три касания прямо в телефоне. Все данные хранятся только у пользователя.

## Для кого
Приложение создано для владельцев малого бизнеса и небольших команд:
- сферы услуг;
- торговли;
- общепита;
- мастерских.

Оно нужно тем, кому важен понятный учёт без сложных бухгалтерских систем.

## Какую задачу решает
Деньги есть, но непонятно, куда они уходят. В заметках данные теряются, Excel нужно долго настраивать, а сложные сервисы стоят дорого.

В Аквинте приход и расход вносятся быстро. Приложение показывает остатки по счетам и прибыль. Оно строит прогноз: хватит ли денег до конца месяца и когда возможен кассовый разрыв. Данные хранятся только на телефоне, работа возможна без интернета и регистрации.

Хранение только на устройстве подходит тем, кто не хочет отправлять финансовые данные на чужие серверы. Для команды можно подключить несколько телефонов.

## Возможности
- Запись прихода и расхода в три касания
- Остатки по счетам и прибыль
- Прогноз кассового разрыва
- Работа без интернета и регистрации
- Несколько устройств для команды
- Выписки из банка
- Резервная копия и выгрузка в Excel

## Частые вопросы

Владельцам небольших компаний, мастерских и точек, которым нужен простой учёт денег.
