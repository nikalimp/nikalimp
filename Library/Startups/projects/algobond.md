AlgoBond автоматизирует исполнение стратегии управления облигационным портфелем. Вы задаёте правила, а сервис выполняет операции через API брокера. Инвестиционные решения остаются за вами. Есть версии для Windows, Android и Linux.

## Для кого
- Частные инвесторы.
- Финансовые консультанты и советники.
- Семейные офисы.
- Владельцы капитала.

## Какую задачу решает
По мере роста облигационного портфеля растёт объём ручной работы: купоны, погашения, реинвестирование, подбор новых выпусков, заявки и контроль соблюдения стратегии. Всё это отнимает время и требует внимания.

AlgoBond переносит эту рутину в автоматику. Пользователь описывает правила стратегии, а сервис сам подбирает облигации, совершает сделки и реинвестирует поступления. Работа идёт через API брокера, а стратегию определяет пользователь.

Сервис не принимает инвестиционных решений за пользователя. Он исполняет заданную стратегию и берёт на себя рутину: заявки, реинвестирование и контроль выполнения правил. Так владелец капитала тратит время на выбор подхода, а не на ручные операции.

## Возможности
- Исполнение вашей стратегии по заданным правилам.
- Подбор облигаций.
- Сделки через API брокера.
- Реинвестирование купонов и погашений.
- Поддержка брокеров Финам, Алор, Т-Инвестиции и БКС.
- Версии для Windows, Android и Linux.
