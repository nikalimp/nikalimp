Assistant Go — сервис заказа проверенных специалистов в пару кликов. Команда называет его «такси для услуг»: вы описываете задачу, а система за 60 секунд находит ближайших мастеров нужной специализации. Команда из Орла.

## Для кого
- Жители городов, которым нужен мастер быстро и без долгих согласований.
- Мастера, которые хотят платить только за результат.

## Какую задачу решает
Рынок бытовых услуг застрял в формате досок объявлений. Заказчикам сложно найти мастера, а мастера теряют деньги на откликах «в пустоту».

Assistant Go работает иначе. Заказчик описывает задачу, и ему не нужно выбирать специализацию. Система находит ближайших мастеров по специализации и району. Мастера получают только релевантные заявки, а комиссию платят после выполнения заказа.

## Возможности
- Заказ мастера за 60 секунд.
- Описание задачи без выбора специализации.
- Подбор ближайших мастеров по району.
- Только релевантные заявки для мастеров.
- Комиссия взимается за выполненный заказ.
- Проверенные специалисты.

## Частые вопросы

### Что такое Assistant Go?
Это сервис заказа мастеров по модели такси: описываете задачу и получаете ближайших специалистов.

### Кому подойдёт Assistant Go?
Жителям города, которым нужен мастер. А также мастерам, которым нужны заявки без оплаты откликов.

### Как работает Assistant Go?
Вы описываете задачу. Система подбирает ближайших мастеров нужной специализации в вашем районе. Мастер платит комиссию, только когда заказ выполнен.
