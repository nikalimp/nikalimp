Aura Companion — бесплатный AI-компаньон с открытым исходным кодом. Он помогает управлять Claude Code и Codex с оркестрацией. Код опубликован на GitHub под лицензией MIT, его можно запустить у себя.

## Для кого
- Разработчикам, которые хотят развернуть собственного AI-компаньона.
- Вайбкодерам, которые работают с Claude Code и Codex.
- AI-энтузиастам, которые изучают код, форкают проект и дорабатывают его под себя.

## Какую задачу решает
Мощные AI-инструменты для кода закрыты и стоят денег. Из России и СНГ к ним сложно подобраться: нужен VPN, иностранная карта и непростая настройка. К тому же такие сервисы работают как чёрный ящик.

Aura Companion даёт другой путь. Проект открыт целиком: его можно клонировать с GitHub, запустить локально, форкнуть и развивать. Привязки к закрытому сервису нет, платить за развёртывание не нужно.

## Возможности
- Управление Claude Code и Codex с оркестрацией.
- 29 навыков в составе проекта.
- Council Mode.
- Полный исходный код на GitHub под лицензией MIT.
- Бесплатное развёртывание у себя.
- Локальный запуск и возможность форкнуть проект.
