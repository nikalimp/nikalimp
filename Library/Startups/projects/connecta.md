Connecta — приложение в Telegram только для женщин, которое подбирает подруг в вашем городе. Оно учитывает особенности характера и ищет тех, с кем у вас есть шанс на настоящую дружбу.

## Для кого
- Женщинам, которым сложно найти «своих» людей.
- Тем, кто переехал в другой город или страну.
- Интровертам.
- Всем, кому трудно заводить новых друзей.

## Какую задачу решает
Привычные способы найти друзей, такие как университет и офис, исчезли, а новые не появились. Сложно знакомиться, вливаться в компании и переводить общение в настоящую дружбу.

Connecta подбирает собеседниц по психотипу, а не случайно. Приложение учитывает предикторы дружеских отношений и ищет совпадения рядом с вами. Так поиск общения перестаёт быть тяжёлым трудом, когда одиноко. Верификация по полу помогает сохранить закрытое пространство только для женщин. Поиск ограничен вашим городом, чтобы знакомство могло перейти в живую встречу. Приложение работает прямо в Telegram.

## Возможности
- Подбор подруг по психотипу.
- Учёт предикторов дружбы при поиске совпадений.
- Только женщины, пол проверяется при верификации.
- Поиск в вашем городе.
- Работа внутри Telegram.

## Частые вопросы

### Что такое Connecta?
Connecta — Telegram-приложение для знакомств в формате дружбы. Оно доступно только женщинам.

### Кому подойдёт Connecta?
Приложение подойдёт женщинам, которым трудно находить подруг: после переезда, интровертам и тем, кому одиноко.

Да, у приложения есть бесплатные опции. Подробности уточняйте на сайте.
