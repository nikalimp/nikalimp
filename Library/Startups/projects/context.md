Context — сервис для изучения английского через чтение и прослушивание книг. В нём есть отобранные книги по уровням, адаптации для начинающих, аудио вместе с текстом и перевод слов с учётом контекста.

## Для кого
- Тем, кто хочет улучшить понимание английского через книги.
- Тем, кто теряется в сложных текстах.
- Начинающим, которым нужны адаптированные сюжеты.

## Какую задачу решает
В книге на английском слишком много незнакомых слов. Переводчик отвлекает от сюжета. Огромная библиотека не помогает, если непонятно, с чего начать. В итоге книгу быстро бросают.

Context убирает эти барьеры. Книги подобраны для комфортного обучения и разделены по уровням. Незнакомое слово переводится с учётом конкретного предложения, поэтому смысл не теряется. Интерфейс остаётся простым. Так чтение превращается в практику, а не в борьбу со словарём. Начинающим помогают адаптированные сюжеты, а тем, кто уже читает свободно, подойдут книги посложнее.

## Возможности
- Книги, отобранные для обучения.
- Распределение по уровням сложности.
- Адаптированные сюжеты для начинающих.
- Аудио вместе с текстом.
- Перевод слов с учётом контекста.
- Тренинг и словарь, как называет их команда.
