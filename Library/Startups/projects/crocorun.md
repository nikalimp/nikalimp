CrocoRun — сервис экспресс-аудита конверсии посадочной страницы. Он анализирует страницу за несколько минут и выдаёт гипотезы для роста. Отчёт можно оформить в формате white-label PDF с вашим логотипом.

## Для кого
- Владельцы сайтов.
- Разработчики сайтов.
- Агентства, которые используют аудит для пресейла и апсейла.
- Те, кто хочет быстро получить гипотезы роста конверсии.

## Какую задачу решает
Ручной анализ занимает много времени и стоит дорого. Обычные ИИ-модели, по словам команды, в 90% случаев выдумывают детали при анализе сайта.

CrocoRun собирает много данных о странице. Сервис разбирает каждый элемент, его назначение, структуру, код и дизайн и анализирует всё с помощью ИИ. Результат приходит в стандартном формате: гипотезы и оценка влияния и затрат (impact/effort). Можно запустить десятки страниц в день, причём сразу несколько. Это удобно агентствам, которым нужно проверить сайты нескольких клиентов.

## Возможности
- Экспресс-отчёт за минуты.
- Анализ структуры, кода и дизайна страницы.
- Гипотезы по росту конверсии.
- Оценка impact/effort.
- Стандартизированный формат отчёта.
- White-label PDF с логотипом.
- Массовый запуск: десятки страниц в день.

## Частые вопросы

### Что такое CrocoRun?
Это сервис для экспресс-аудита конверсии посадочных страниц. Он выдаёт отчёт с гипотезами роста.

### Кому подойдёт CrocoRun?
Владельцам сайтов, разработчикам и агентствам. Подойдёт тем, кто хочет использовать аудит для пресейла и апсейла.

### Есть ли бесплатная версия CrocoRun?
Нет, сервис платный. Условия и стоимость уточняйте на сайте проекта.
