DevNullifier — бесплатное кроссплатформенное приложение с открытым кодом. Оно очищает кэш разработки, временные файлы и ненужные данные. Работает на Windows, Mac и Linux. Команда из Самары открыла его исходный код.

## Для кого
Разработчикам на Windows, Mac и Linux, у которых накапливаются временные файлы проектов.

## Какую задачу решает
Во время разработки создаются временные файлы, которые не удаляются сами. Они занимают место на диске, а вручную искать их по папкам долго.

DevNullifier знает, где лежат такие файлы. В нём есть шаблоны для большинства популярных фреймворков. Приложение находит лишнее, а вы выбираете, что удалить. Приложение запоминает результаты поиска, поэтому повторная проверка идёт быстрее. Удаление настраивается выборочно, а автообновление держит шаблоны актуальными. Так вы освобождаете место на диске и не трогаете нужные файлы.

## Возможности
- Шаблоны временных файлов для популярных фреймворков.
- Поиск ненужных файлов и данных.
- Выборочная настройка удаления.
- Кэширование результатов для быстрого повторного поиска.
- Автообновление.
- Полностью открытый код.

## Частые вопросы

### Что такое DevNullifier?
DevNullifier — приложение для очистки кэша и временных файлов, которые остаются после разработки. Исходный код открыт, работает на трёх платформах.  Приложение обновляется само.

### Кому подойдёт DevNullifier?
Оно подойдёт разработчикам на Windows, Mac и Linux, которым нужно освободить место на диске без ручного поиска.  Подойдёт и тем, кто любит инструменты с открытым кодом.

### Есть ли бесплатная версия DevNullifier?
Приложение бесплатное, код открытый.
