Ecommetriya — ERP-система для маркетплейсов. Она собирает в одном рабочем пространстве инструменты, которыми селлер пользуется каждый день. Основной функционал сейчас адаптирован под Wildberries.

## Для кого
Платформа создана для селлеров на маркетплейсах. Подходит тем, кто использует больше трёх сервисов для работы с площадкой. В планах команды из Перми поддержка Ozon и Яндекс Маркета.

## Какую задачу решает
Селлеры решают задачи на маркетплейсе через четыре–пять сервисов, а некоторые используют больше семи. Приходится переключать внимание и заполнять одинаковые данные в разных местах.

Ecommetriya объединяет нужный функционал в единственном месте. Команда сравнивает это со зрелыми сферами: у продавцов есть amoCRM, у маркетологов eЛама, у бухгалтеров 1С. Для молодой сферы маркетплейсов Ecommetriya создаёт такое же рабочее пространство.

Главная идея проста: меньше переключений между окнами, меньше ручного переноса данных, меньше ошибок. Команда считает, что платформа будет полезна любому селлеру, который пользуется больше чем тремя сервисами.

## Возможности
- Единое рабочее пространство для селлера
- Функционал для работы на Wildberries
- Управление проектами и CRM
- Меньше сервисов и дублирования данных
- Ozon и Яндекс Маркет — в планах

## Частые вопросы

### Что такое Ecommetriya?
Ecommetriya — ERP-система для продавцов на маркетплейсах. Она заменяет набор разрозненных сервисов единым рабочим пространством.

### Кому подойдёт Ecommetriya?
Селлерам Wildberries, а в перспективе Ozon и Яндекс Маркета, которые работают с несколькими сервисами сразу.

### Есть ли бесплатная версия Ecommetriya?
Да, у Ecommetriya есть бесплатные опции. Состав платных функций смотрите на сайте проекта.
