FastDeploy — консольная утилита для деплоя приложений на Docker Compose на собственный VPS. Хватает трёх команд. HTTPS, git и секреты уже встроены. Проект бесплатный, с открытым кодом под лицензией MIT.

## Для кого
- Инди-разработчикам.
- Фрилансерам.
- Небольшим командам, которые выкатывают пет-проект или MVP на недорогой VPS без DevOps-инженера, Kubernetes и CI.

## Какую задачу решает
Развернуть простое приложение на своём сервере — это вечер возни с Docker, nginx, сертификатами, секретами и обновлениями. Зарубежные PaaS вроде Heroku и Render дороги и плохо доступны из России.

FastDeploy сводит это к трём командам. fd server init готовит сервер: ставит Docker и Traefik и настраивает HTTPS. fd env push загружает секреты. fd deploy подтягивает код по Git и запускает compose. С компьютера ничего не собирается. Инструмент не требует отдельного демона на сервере: подключение идёт только по SSH.

## Возможности
- Подготовка сервера одной командой: Docker, Traefik, HTTPS.
- Автоматический HTTPS через Let's Encrypt.
- Загрузка секретов отдельной командой, секреты не хранятся в Git.
- Деплой по Git.
- Несколько приложений на одном VPS.
- Работа без демона, только по SSH.
- Совместимость с любым docker-compose.yml.

## Частые вопросы

### Что такое FastDeploy?
FastDeploy — CLI-утилита, которая разворачивает Docker Compose приложения на ваш сервер.

Утилита подойдёт инди-разработчикам, фрилансерам и небольшим командам, у которых нет DevOps-инженера.

FastDeploy бесплатный и открытый, лицензия MIT.
