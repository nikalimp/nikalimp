FireWire — сервис независимой аналитики инвестиционных портфелей. Он собирает счета у разных брокеров, считает TWR, XIRR и доходность за вычетом инфляции. Также сервис строит календарь купонов и дивидендов.

## Для кого
- Частным инвесторам со счетами у нескольких брокеров.
- Тем, кто хочет знать реальную доходность портфеля.
- Финансовым блогерам и инвест-клубам, которые публикуют свои портфели.

## Какую задачу решает
Приложения брокеров показывают номинальную доходность по каждому счёту отдельно и без учёта инфляции. Общую картину инвесторы собирают вручную в Excel. Это долго, и в таблицах легко ошибиться.

FireWire подключается к счетам по Read-Only API или берёт данные из отчётов брокеров. Вы видите всё в одном дашборде. Формулы открыты, а поправка идёт на ИПЦ ЦБ РФ.

## Возможности
- Подключение счетов по Read-Only API или из отчётов брокеров.
- Больше 10 брокеров РФ в одном дашборде, по словам команды.
- Расчёт TWR и XIRR.
- Доходность с поправкой на инфляцию по ИПЦ ЦБ РФ.
- Календарь купонов и дивидендов.
- Шифрование ключей в браузере.
- Шеринг портфеля без указания сумм.

## Частые вопросы

### Что такое FireWire?
FireWire — сервис аналитики портфелей, который собирает счета у разных брокеров и считает реальную доходность.

### Кому подойдёт FireWire?
Сервис подойдёт частным инвесторам с несколькими брокерскими счетами, а также финансовым блогерам и инвест-клубам.

### Есть ли бесплатная версия FireWire?
Да, у сервиса есть бесплатный тариф.
