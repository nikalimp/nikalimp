ФМайлер — сервис отправки транзакционных писем: кодов входа, чеков, подтверждений заказов и уведомлений. Письма уходят из приложения по SMTP или REST API, а журнал показывает путь каждого сообщения. Команда из Саранска.

## Для кого
- Разработчики.
- Команды SaaS-продуктов.
- Интернет-магазины и онлайн-сервисы, которые отправляют письма из своего продукта.

## Какую задачу решает
Пользователь не получил код или чек. Письмо не отправилось, его отклонили или оно задержалось? Пока команда ищет ответ в логах и проверяет настройки домена, клиент уходит.

ФМайлер показывает путь каждого письма: этапы обработки, ответ сервера получателя и причину отказа. Письма подписываются вашим доменом. Перейти на новый SMTP-сервер можно без переписывания логики, либо подключить API.

## Возможности
- Отправка по SMTP и REST API.
- Подпись письма вашим доменом.
- Журнал доставки: этапы, ответ сервера получателя, причина отказа.
- Поддержка DKIM, SPF и DMARC после делегирования поддомена.
- Шаблоны писем.
- Вебхуки.
- Приём входящих писем.

## Частые вопросы

### Что такое ФМайлер?
Это сервис транзакционной почты с подробным журналом доставки. Он отправляет письма из приложения через SMTP или API.

### Кому подойдёт ФМайлер?
Разработчикам и командам SaaS, интернет-магазинов и онлайн-сервисов, которым нужно понимать, дошло ли письмо до пользователя.

### Есть ли бесплатная версия ФМайлера?
Сервис платный, но есть пробный период.
