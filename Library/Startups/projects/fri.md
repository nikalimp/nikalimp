FRI — универсальный индекс репутации футболистов. Платформа считает рейтинг по формуле, используя официальную статистику матчей, достижения, дисциплину, медийный фон и поддержку фанатов.

## Для кого
Платформа ориентирована на три аудитории:
- компании, которым нужна объективная оценка репутации игрока для партнёрств;
- футболисты, которые хотят видеть показатель своей ценности и влияния;
- болельщики, которым нужен понятный рейтинг на основе статистики.

## Какую задачу решает
Сейчас нет единого способа оценить репутацию футболиста. Статистика матчей, популярность в соцсетях и медийный образ существуют отдельно друг от друга. Сравнить игроков по всем параметрам сразу трудно.

FRI объединяет эти данные в один рейтинг. В расчёт попадают игровые показатели, достижения, соцсети, дисциплина, медийный фон и мнение фанатов. Формула одинакова для всех игроков, поэтому оценка остаётся объективной.

Такой рейтинг помогает сравнивать игроков не по одному показателю, а по целой картине. Для партнёров это основа для выбора, для болельщиков — понятный ориентир, а для игроков — возможность видеть свой вес в футболе. Формула открывает рейтинг для всех участников рынка и снижает долю субъективных оценок.

## Возможности
- Единый рейтинг репутации игрока
- Официальная статистика матчей
- Достижения и дисциплина
- Соцсети и медийный фон
- Мнение и поддержка фанатов
- Расчёт по единой формуле

## Частые вопросы

### Что такое FRI?
FRI — платформа аналитики, которая оценивает репутацию футболистов единым числом на основе данных.

### Кому подойдёт FRI?
Компаниям, выбирающим партнёров среди игроков, самим футболистам и болельщикам, которым интересны объективные рейтинги.

### Есть ли бесплатная версия FRI?
Да, платформа бесплатная.
