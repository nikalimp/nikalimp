Gradius — сервис, который встраивает нативную контекстную рекламу в ответы нейросетей. Рекламодатели получают целевые переходы из диалогов с ИИ, а владельцы AI-сервисов зарабатывают на трафике. Сервис платный.

## Для кого
- Рекламодатели, которые устали переплачивать в стандартных performance-каналах.
- Владельцы GenAI-сервисов, которые ищут устойчивую монетизацию проекта.

## Какую задачу решает
По данным команды, стоимость лида в классических каналах растёт на 18–25% в год, и они становятся дороже и хуже окупаются. У AI-сервисов другая проблема: каждый запрос бесплатного пользователя приносит убыток до 2 рублей.

Gradius соединяет две стороны. Реклама появляется прямо в ответах нейросети, поэтому рекламодатель получает переходы из диалога. AI-сервис монетизирует бесплатную аудиторию. Команда называет доход до 4 рублей в месяц на одного бесплатного пользователя.

Реклама появляется внутри ответа нейросети, там, где пользователь уже получает рекомендации. Аукциона между рекламодателями при этом нет, отмечает команда.

## Возможности
- Нативная контекстная реклама в ответах нейросетей.
- Работа без аукционной конкуренции.
- Целевые переходы из диалогов с нейросетями.
- Для рекламодателей: CTR 2–4%, конверсия в целевое действие 5–10% (данные команды).
- Для AI-сервисов: монетизация бесплатной аудитории.
