HADL — сервис для частных инвесторов, который собирает все брокерские счета и криптобиржи в один портфель. В нём видны реальная доходность, календарь выплат и рекомендации по ребалансировке.

## Для кого
- Частные инвесторы со счетами у нескольких брокеров.
- Те, кто держит криптовалюту на биржах.

## Какую задачу решает
Приложение брокера показывает только его счёт. Общую картину инвесторы собирают в Excel: сводят сделки, считают доходность и ведут календарь выплат. Удобного инструмента для ребалансировки обычно нет.

HADL забирает сделки у 11 российских брокеров и трёх криптобирж через API или загрузку отчёта и сводит их в общий портфель. Если брокера нет в списке, сделки заводит ИИ-ассистент по отчёту или скриншоту. Инвестор видит общий результат по всем счетам и принимает решения о покупках по полной картине.

## Возможности
- Загрузка сделок по API или из отчёта.
- Реальная доходность портфеля.
- Календарь выплат на год.
- Подсказки, что докупить для баланса.
- Скринер облигаций с сортировкой по доходности после налогов.
- Учёт по FIFO, LIFO или вручную.

## Частые вопросы

### Что такое HADL?
HADL — трекер инвестиционного портфеля. Он собирает данные из разных источников и показывает общую картину. Для брокеров вне списка сделки добавляет ИИ-ассистент.

### Кому подойдёт HADL?
Частным инвесторам, которые держат активы у нескольких брокеров и на криптобиржах. Подойдёт и начинающим инвесторам, у которых один-два счёта.
