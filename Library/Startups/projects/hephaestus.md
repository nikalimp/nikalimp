Hephaestus — open-source фреймворк для автоматизации API-тестов в Postman. Общий движок хранится в Git и подгружается в Postman одним запросом. В каждом запросе остаётся только небольшой конфиг.

## Для кого
- QA-инженеры и команды, которые тестируют REST- и XML-API в Postman.
- Те, у кого большие коллекции с десятками запросов и дублирующимися скриптами.
- Те, кому нужна snapshot-регрессия без настройки CI.

## Какую задачу решает
В Postman у каждого запроса свои скрипты. Когда методов больше 50, возникает хаос: код дублируется, логика разная, а ревью невозможно. Нет snapshot-регрессии, маскирования секретов и единого стандарта.

Hephaestus выносит общую логику в движок. Каждый метод задаётся override-конфигом. Движок сам занимается авторизацией, проверками, snapshot-регрессией, JSON Schema и маскированием секретов. Движок обновляется из Git одной кнопкой, а тесты можно запускать через Newman и Docker. Отчёты сохраняются в форматах JUnit и HTML.

## Возможности
- Работает в Postman без зависимостей.
- Более 20 модулей: snapshot, auth, schema, assertions.
- Совместим с Apidog.
- Обновление движка из Git одной кнопкой.
- Поддержка Docker, Newman, JUnit и HTML-отчётов.
- Лицензия MIT.

## Частые вопросы

### Что такое Hephaestus?
Hephaestus — открытый фреймворк для API-тестов в Postman. Он убирает дублирующиеся скрипты из запросов и заменяет их общим движком.  Подходит для REST и XML API.

### Кому подойдёт Hephaestus?
Фреймворк подойдёт QA-инженерам и командам с большими коллекциями Postman, которым нужны единый стандарт и snapshot-регрессия.

### Есть ли бесплатная версия Hephaestus?
Фреймворк бесплатный и распространяется с открытым кодом по лицензии MIT.
