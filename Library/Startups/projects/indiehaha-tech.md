Indiehaha.tech — тренажёр код-ревью. Вы оставляете комментарии к настоящим pull request из опенсорс-проектов и к задачам с собеседований. ИИ оценивает каждый комментарий по смыслу. Команда проекта работает из Тбилиси.

## Для кого
- Начинающие разработчики.
- Опытные программисты.
- Те, кто готовится к собеседованию.
- Все, кто хочет понимать чужой код в эпоху AI-разработки.

## Какую задачу решает
Новичкам тяжело даётся код-ревью. Когда код пишет ИИ, умение читать и проверять его становится главным навыком. На собеседованиях всё чаще дают задачи на ревью, но тренажёра вроде LeetCode для этого не было.

В Indiehaha.tech вы практикуетесь на реальных задачах. AI-тьютор оценивает суть замечания, а не совпадение ключевых слов. Для подготовки к конкретному собеседованию можно отфильтровать задачи по компании. Профиль с результатами можно показать работодателю как подтверждение навыка.

## Возможности
- Более 450 задач на 15+ языках программирования.
- Реальные PR из опенсорс-проектов.
- Задачи с собеседований.
- AI-тьютор, который оценивает смысл комментариев.
- Фильтр по компаниям, например Plata, Avito, Ozon.
- Профиль, который можно добавить в резюме.

Это платформа для тренировки код-ревью. Вы комментируете реальный код, а система оценивает качество ваших замечаний.

Платформа подойдёт разработчикам любого уровня и тем, кто готовится к собеседованиям с ревью-задачами.
