Infokly CodeBoard — онлайн-редактор кода для занятий по программированию. Преподаватель и ученик работают в одном окне браузера, вместе правят код и сразу запускают его. Ничего устанавливать не нужно.

## Для кого
- Преподаватели и репетиторы по программированию.
- Онлайн-школы.
- Образовательные платформы, которые проводят занятия дистанционно.

## Какую задачу решает
На онлайн-уроках по программированию много времени уходит на подготовку: установить программы, настроить среду, передать друг другу код. Из-за этого занятия идут медленнее, а расширять школу сложнее.

CodeBoard убирает эту подготовку. Ученик и преподаватель открывают один редактор в браузере, видят правки друг друга и запускают программу на месте.

Для школ это ещё и вопрос масштаба. Когда преподавателей и учеников много, каждая лишняя настройка на уроке умножается на число занятий.

Оба участника работают в одном редакторе, поэтому преподаватель видит код ученика и помогает с ним по ходу урока.

## Возможности
- Совместное редактирование кода в реальном времени.
- Мгновенный запуск программ прямо в браузере.
- Работа без установки программ.
- Подходит для любого устройства.
- Один редактор для преподавателя и ученика.
