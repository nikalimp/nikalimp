Koddo — онлайн-платформа, где прикладные задачи по Python, JavaScript и SQL решают прямо в браузере. Тесты сразу проверяют код. ИИ-ассистент подсказывает, но не выдаёт готовый ответ.

## Для кого
- Те, кто изучает Python, JavaScript или SQL.
- Те, кто хочет перейти от теории к практике.
- Те, кто закрывает пробелы после курсов.
- Те, кто готовится к собеседованию.

## Какую задачу решает
После курсов часто не хватает практики. Непонятно, что решать дальше, почему код не проходит тесты и как получить помощь, не списав чужой ответ.

Koddo даёт задачи из реальной разработки, учебные пути и редактор прямо в браузере. Устанавливать ничего не нужно. Автопроверка отвечает сразу, а подсказки ИИ помогают найти ошибку без спойлеров. Прогресс сохраняется. Skill Tests показывают текущий уровень, а мок-собеседования помогают привыкнуть к формату интервью.

## Возможности
- Прикладные задачи по Python, JavaScript и SQL.
- Учебные пути.
- Редактор кода в браузере.
- Мгновенная автопроверка тестами.
- ИИ-ассистент с подсказками без готового решения.
- Skill Tests.
- Мок-собеседования.
