НейроМиша — тренажёр для подготовки к ЕГЭ. Искусственный интеллект проверяет развёрнутые ответы по критериям ФИПИ за секунды и объясняет, какой пункт не закрыт. Команда из Краснодара.

## Для кого
- Одиннадцатиклассники, которые готовятся к ЕГЭ самостоятельно
- Десятиклассники, которые начинают заранее
- Репетиторы и школы, которым нужен инструмент проверки работ

## Какую задачу решает
Развёрнутую часть экзамена нельзя проверить самому. Школьник пишет ответ и не знает, засчитают ли его. В задании 25 незачёт по одному критерию обнуляет все шесть баллов. Репетитор проверяет работу раз в неделю.

НейроМиша проверяет ответ сразу и показывает, где ошибка. Тренажёр ведёт прогресс по каждому номеру КИМ и подбирает следующее задание. Карточки возвращаются по расписанию. Для репетиторов и школ тренажёр служит инструментом проверки работ. Школьник занимается самостоятельно и получает обратную связь сразу, а не через неделю. Начать можно без регистрации: сервис даёт 20 заданий, пробник и проверку ответа.
