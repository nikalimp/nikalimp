«Отправка в MAX по номеру» — шлюз для отправки сообщений с сайта в мессенджер MAX по номеру телефона. Он работает через API. Через него можно отправлять статусы, акции, скидки и другие уведомления. Команда из Санкт-Петербурга.

## Для кого
- Разработчики
- Владельцы сайтов
- Основатели стартапов, которым нужно отправлять транзакционные и информационные уведомления пользователям

## Какую задачу решает
Сайтам нужно уведомлять клиентов, но почти все популярные каналы связи стали недоступны. Нужен рабочий способ отправлять сообщения с сайта пользователям.

Сервис принимает запрос по API и доставляет сообщение в MAX по номеру телефона. Подписчики могут отказаться от отдельных групп уведомлений: гибкая отписка работает на стороне бота. Подключение рассчитано на разработчиков: сообщения отправляются запросом по API. Пользователь сам решает, на какие группы уведомлений он подписан.

## Возможности
