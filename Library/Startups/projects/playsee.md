PlaySee — сервис для создания видеовиджетов на сайте. Вы загружаете ролик, настраиваете внешний вид и показ, а сервис хранит видео и быстро отдаёт его посетителям.

## Для кого
- Маркетологи.
- Студии дизайна.
- Видеокреаторы и дизайнеры.
- Все, кто делает видеоконтент и хочет использовать его на сайте.

## Какую задачу решает
Видео на сайте помогает привлечь внимание и рассказать о продукте. Но нужно где-то хранить ролики, быстро их загружать и проверять, какие креативы работают. PlaySee собирает это в одном месте.

Команда называет типовые сценарии: видеообращение основателя, демонстрация сервиса, креативы из соцсетей, представление команды, объяснение условий и гарантий, UGC-контент. Виджет можно настроить под сайт, а показ ограничить правилами. Виджет легко настроить под страницу: выбрать, кому и когда его показывать, и протестировать разные креативы. Для сложных сценариев есть JS API, а видео загружается быстро благодаря CDN. Сервис пригодится, когда нужно быстро показать посетителю суть продукта: ролик встроен в страницу и не мешает загрузке сайта. Маркетолог сам решает, кому и когда показывать видео.

## Возможности
- Видеовиджет с кастомизацией.
- Хостинг видео.
- Встроенный CDN для быстрой загрузки по всему миру.
- Таргетирование по UTM-меткам.
- Настройки показа.
- JS API для сложных сценариев.
- Админ-панель.
- Расширенные лимиты для компаний.
