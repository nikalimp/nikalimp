RunHouse — self-hosted маркетплейс приложений. В каталоге есть GitLab, Grafana и десятки других сервисов, которые ставятся на ваш сервер в один клик.

## Для кого
- Команды и компании, которым нужен собственный стек без облачной подписки.
- Те, кому нужен devops, но нет ресурсов погружаться в него.

Команда также предлагает отдельную подписку на devops-сопровождение платформы.

## Какую задачу решает
Self-hosted сервисы долго устанавливать, настраивать и сопровождать. Для этого приходится разбираться в devops и вручную писать конфигурации.

RunHouse заменяет ручную настройку каталогом приложений. Вы выбираете сервис, а платформа устанавливает его, показывает состояние и выдаёт адрес. Резервные копии тоже настраиваются из панели. Данные остаются у вас.

Для запуска не нужно писать конфигурации и разбираться в контейнерах. Вы выбираете приложение в каталоге и получаете рабочий сервис с адресом и защищённым соединением. Если требуется помощь, команда готова взять поддержку и обслуживание платформы на себя.

## Возможности
- Каталог приложений для установки.
- Установка в один клик вместо docker compose.
- Проверка состояния (health) сервисов.
- Адрес для каждого приложения.
- Бэкапы из панели.
- Несколько инстансов.
- HTTPS из коробки.

## Частые вопросы

### Что такое RunHouse?
Это платформа, которая устанавливает и обслуживает self-hosted приложения на вашем сервере через единую панель.

### Кому подойдёт RunHouse?
Командам и компаниям, которым нужны свои сервисы без облачной подписки и без глубокого погружения в devops.

### Есть ли бесплатная версия RunHouse?
Да, у платформы есть бесплатные опции. Условия тарифов смотрите на сайте.
