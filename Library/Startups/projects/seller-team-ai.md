Seller Team AI — сервис с восемью ИИ-агентами для продавцов Wildberries. Агенты читают данные магазина по официальному API и считают прибыль, окупаемость рекламы и остатки. На выходе вы получаете план на неделю с эффектом в рублях.

## Для кого
- Продавцы на Wildberries с оборотом 1–10 млн ₽ в месяц.
- Магазины, где нет штата из финансиста, маркетолога и снабженца.
- Те, кому мало графиков в обычной аналитике и нужны конкретные действия.

## Какую задачу решает
В кабинете продавец видит выручку и выплаты. Прибыль по каждому товару после комиссии, логистики, отказов и налога там не видна. Непонятно и то, окупается ли реклама.

Seller Team AI считает всё это за один–три минуты. Расчёты делает код, а нейросеть объясняет результат. По словам команды, цифры совпадают с отчётами Wildberries один к одному. Доступ к магазину только на чтение, поэтому сервис ничего не меняет сам.

## Возможности
- Восемь ИИ-агентов для разных задач магазина.
- Чтение данных через официальный API Wildberries.
- Прибыль по каждому товару.
- Окупаемость рекламы.
- Контроль остатков.
- План на неделю с эффектом в рублях.

## Частые вопросы

### Что такое Seller Team AI?
Это команда ИИ-агентов, которая анализирует магазин на Wildberries и подсказывает, что делать.

### Кому подойдёт Seller Team AI?
Продавцам Wildberries с оборотом 1–10 млн ₽ в месяц, у которых нет своих аналитиков.

### Как работает Seller Team AI?
Сервис подключается к магазину по API с доступом только на чтение. Код считает показатели, а нейросеть объясняет их и составляет план.
