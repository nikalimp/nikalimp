Сигнал — сервис поиска B2B-клиентов. Он находит момент, когда компании нужен ваш продукт или услуга. Каждый день система проверяет 40+ источников данных и показывает компании с признаками спроса.

## Для кого
Сервис подходит B2B-компаниям, которые ищут клиентов вхолодную:
- руководителям отделов продаж;
- менеджерам по продажам;
- фаундерам, которые продают сами.

## Какую задачу решает
Холодные продажи почти всегда слепые. Менеджер не знает, у кого прямо сейчас есть повод купить. Признаки спроса разбросаны по десяткам источников, и следить за ними вручную трудно.

Сигнал делает эту работу ежедневно. Он смотрит вакансии, Telegram, технологический стек, отзывы, маркетплейсы и другие места, от HH до GitHub. В итоге менеджер получает не просто список компаний, а причину написать именно им и именно сейчас.

Вместо случайной рассылки команда продаж работает по горячему списку. Менеджер заранее знает, почему компания может заинтересоваться, и пишет по делу. Это повышает шанс ответа на холодное письмо.

## Возможности
- Ежедневный мониторинг 40+ источников
- Данные от HH до GitHub
- Поиск компаний по признакам спроса
- Контакты в каждой карточке: сайт, почта, телефон
- Полная цепочка формирования сигнала

## Частые вопросы

### Что такое Сигнал?
Сигнал — платформа, которая ищет компании с активным спросом на ваш продукт. Команда из Твери развивает его для B2B-продаж.

### Кому подойдёт Сигнал?
B2B-компаниям, отделам продаж и фаундерам, которым нужны горячие поводы для первого контакта.

### Есть ли бесплатная версия Сигнала?
Сервис платный, но есть пробный период (триал). Условия смотрите на сайте проекта.
