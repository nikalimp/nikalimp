Solpuga — локальный кроссплатформенный HTTP(S) прокси. С его помощью можно смотреть и подменять сетевые запросы. Интерфейс русскоязычный, приложение работает на macOS, Windows и Linux.

## Для кого
- Разработчики API и приложений, которые отлаживают работу с сетью.
- QA-инженеры.
- Команды безопасности, которые ищут неожиданные сюрпризы в трафике.

## Какую задачу решает
Существующих решений мало, и почти все зарубежные. Командам из России их трудно оплачивать, а бесплатный функционал ограничен. Самый популярный аналог команда считает тяжёлым и устаревшим по UX.

Solpuga предлагает минималистичное современное приложение со всем необходимым. Оно ориентировано на русскоязычных пользователей и поддерживает работу с мобильными устройствами на iOS и Android. Инструмент простой, интерфейс понятный. Так разработчик быстро видит, какие запросы уходят из приложения, и может изменить их на лету, чтобы проверить поведение сервера или клиента. QA-инженеры воспроизводят ошибки, а специалисты по безопасности находят слабые места. Команда делает приоритет на простоте: установил, запустил и сразу видишь трафик. Для тех, кому нужна отладка мобильных приложений, есть работа с устройствами на iOS и Android.

## Возможности
- Просмотр HTTP(S)-запросов.
- Подмена сетевых запросов.
- Работа на macOS, Windows и Linux.
- Поддержка iOS и Android.
- Русский язык интерфейса.
- Минималистичный современный интерфейс.
