«Сородители» — бесплатная платформа знакомств для тех, кто ищет партнёра для рождения ребёнка и создания семьи. Здесь каждый настроен на серьёзные намерения. Поиск идёт по анкетам с ценностями, целями и параметрами партнёра.

## Для кого
- Одинокие мужчины и женщины, которые хотят семью и детей.
- Те, кто не находит серьёзного партнёра на обычных сайтах знакомств.
- Люди, разделяющие традиционные семейные ценности.

## Какую задачу решает
Бывает, что пара годами живёт вместе, но партнёр не готов к детям, и отношения заканчиваются. Время уходит. Обычные сайты знакомств часто рассчитаны на случайные встречи, а не на семью.

«Сородители» собирают на одной платформе людей с общей целью. Анкеты показывают ценности и цели поиска, поэтому легче найти единомышленника и не тратить время на пустые встречи. Платформа подходит для поиска партнёра для традиционной семьи и для сородительства.

## Возможности
- Анкеты с семейными ценностями.
- Указание целей поиска.
- Параметры желаемого партнёра.
- Поиск партнёра для традиционной семьи.
- Поиск партнёра для сородительства.
- Аудитория с серьёзными намерениями.
- Бесплатное использование.
