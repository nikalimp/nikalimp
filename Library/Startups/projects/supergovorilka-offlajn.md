СуперГоворилка — программа для диктовки текста, которая работает без интернета на Mac и Windows. Зажимаете горячую клавишу, говорите, а текст появляется в активном поле. Подписка не нужна. Команда из Калининграда.

## Для кого
Для тех, кто много печатает: письма, заметки, код, сообщения. И для тех, кому удобнее проговорить мысль вслух, чем набирать её руками. Поддерживаются русский и английский.

## Какую задачу решает
Много печатать утомительно. Облачная диктовка отправляет голос на чужие серверы и просит подписку. Нормального офлайн-решения для Windows за разумные деньги не было.

СуперГоворилка распознаёт речь прямо на вашем устройстве. Текст попадает в письмо, чат, заметку, код или браузер. Всё занимает пару секунд. Голос никуда не уходит: облака, аккаунта и интернета для работы не требуется.
