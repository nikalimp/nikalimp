T-Bank MCP — открытый MCP-сервер, который связывает ИИ-агентов с аккаунтом в Т-Банке. Ассистент в чате видит счета и траты, делает переводы и оплачивает счета, но только после вашего подтверждения.

## Для кого
- Пользователи Claude Code, Cursor и других ИИ-агентов, у которых есть счёт в Т-Банке.
- Разработчики.
- Те, кто хочет управлять деньгами и покупками из чата с ассистентом.

## Какую задачу решает
У банков нет интерфейса для ИИ-агентов. Ассистент не видит счета и траты. Доверить ему платежи страшно: нет гарантии, что деньги не уйдут без ведома владельца.

T-Bank MCP работает поверх мобильного API банка и предоставляет агенту 90 инструментов. Каждый платёж подтверждается кнопкой с суммой, без неё перевод невозможен. Пароль и PIN не попадают в контекст модели.

Проект открыт на GitHub, поэтому код можно проверить самостоятельно и убедиться, как устроена защита платежей.

## Возможности
- Баланс и траты.
- Переводы по телефону и реквизитам.
- Оплата ЖКХ и штрафов.
- Продукты, билеты и поездки.
- 90 инструментов для агента.
- Подтверждение платежа кнопкой с суммой.
- Закреплённые сертификаты TLS в пакете.
- Открытый код под лицензией MIT.

## Частые вопросы

### Что такое T-Bank MCP?
Это открытый сервер по протоколу MCP, который даёт ИИ-агентам доступ к функциям Т-Банка.

### Кому подойдёт T-Bank MCP?
Тем, кто работает с Claude Code, Cursor или Goose и хочет управлять банковскими операциями из чата.

### Есть ли бесплатная версия T-Bank MCP?
Да, сервис бесплатный. Установка одной командой: pip install tbank-mcp.
