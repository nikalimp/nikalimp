Табрика — русскоязычная платформа для совместной работы с данными. В ней есть таблицы, представления и API, и всё это работает без программирования. Инфраструктура находится в России.

## Для кого
Платформа рассчитана на тех, кому нужна гибкая база данных без кода:
- малый и средний бизнес;
- агентства разработки;
- AI-разработчики;
- стартапы;
- ноукодеры и лоукодеры.

## Какую задачу решает
В готовых CRM сложно менять процессы. В каждом новом проекте приходится заново писать слой CRUD-кода. Airtable, NocoDB и похожие сервисы либо не дают нужной гибкости, либо стоят дорого.

В Табрике все данные лежат в таблицах и представлениях. Для любой таблицы автоматически появляется готовый REST API. Пользователи работают вместе в реальном времени. Данные хранятся в российской юрисдикции с соблюдением 152-ФЗ, а бесплатный тариф доступен без ограничения по сроку.

Для разработчика это экономия времени: backend для прототипа появляется без отдельного кода. Для бизнеса это таблицы, которые можно подстроить под свой процесс.

## Возможности
- Таблицы и гибкие представления данных
- Мгновенный REST API для любой таблицы
- Совместная работа в реальном времени
- Хранение данных в российской юрисдикции (152-ФЗ)
- Бесплатный тариф навсегда
- Работа без строчки кода

## Частые вопросы

### Что такое Табрика?
Табрика — no-code платформа для работы с данными. Она заменяет самописные базы и гибкие CRM таблицами с готовым API.

### Кому подойдёт Табрика?
Малому и среднему бизнесу, агентствам разработки, стартапам, AI-разработчикам и ноукодерам.

### Есть ли бесплатная версия Табрики?
Да. Команда сообщает о бесплатном тарифе без ограничения по сроку.
