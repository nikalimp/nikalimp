TrustNode — мобильное приложение для Android, которое в реальном времени распознаёт признаки мошенничества. Проверка идёт на самом телефоне: локальный ИИ-классификатор анализирует звонки, СМС и ссылки без сервера. Команда работает из Челябинска.

## Для кого
Для обычных пользователей Android, которых утомили звонки мошенников и спам-СМС. Разбираться в информационной безопасности не нужно.

## Какую задачу решает
Мошенники и спамеры атакуют каждый день, а встроенная защита телефона их часто не ловит. Пользователь остаётся один на один с подозрительным звонком или ссылкой.

TrustNode проверяет входящие звонки, СМС и ссылки с помощью модели ruBERT, которая работает на устройстве. Данные не покидают телефон, приложению не нужен интернет для анализа. Результат подсказывает, насколько сообщение или звонок похожи на мошенничество. В версии 1.2.0 команда обновила интерфейс и добавила новый фильтр, который заметно снизил число ложных срабатываний.

## Возможности
- Анализ звонков, СМС и ссылок на признаки мошенничества.
- Локальный ИИ-классификатор ruBERT.
- Работа офлайн без передачи данных на сервер.
- Высокая точность на русском языке, по словам команды.
- Обновлённый интерфейс и фильтр против ложных срабатываний в версии 1.2.0.
- Security-аудит по OWASP MASVS без критичных находок.
