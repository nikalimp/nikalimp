Try Clew — no-code сервис для онбординга пользователей. С ним можно создавать туры, подсказки, попапы и чеклисты прямо в интерфейсе продукта. Разработчик для этого не нужен.

## Для кого
- Продакт-менеджеры.
- Маркетологи.
- CS-команды в SaaS, e-commerce, банках и веб-сервисах.
- Команды, у которых нет времени разработчиков на онбординг.

## Какую задачу решает
Каждая подсказка, попап или тур превращаются в задачу разработчику и ожидание релиза. Пользователи тем временем теряются в интерфейсе и уходят, не дойдя до ключевого действия.

Установите один тег, затем в визуальном редакторе кликайте по элементам страницы и пишите тексты шагов. Эксперимент можно публиковать сразу и сравнивать варианты в A/B-тесте.

## Возможности
- Туры, подсказки, попапы, чеклисты и рейтинги.
- Визуальный редактор: клик по элементу на странице.
- A/B-тесты с плановой выборкой.
- Победителя можно сделать основным в один клик.
- Сломанные шаги видны сразу.
- Данные хранятся обезличенно в России.
- Вход через Яндекс ID или почту.
- Установка на свои серверы.

## Частые вопросы

### Что такое Try Clew?
Try Clew — сервис для создания туров, подсказок и попапов внутри продукта без участия разработчиков. Подключается одним тегом.

### Кому подойдёт Try Clew?
Сервис подойдёт продактам, маркетологам и CS-командам, которые хотят вести новых пользователей к первой пользе.

### Есть ли бесплатная версия Try Clew?
Да, есть бесплатный тариф. Также доступна версия для установки на свои серверы.
