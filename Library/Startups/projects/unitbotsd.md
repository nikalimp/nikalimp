UnitBotSD — сервис расчёта юнит-экономики для продавцов на маркетплейсах. Он показывает реальную прибыль по товарам для Wildberries, Ozon, Яндекс Маркета и Магнит Маркета и учитывает налоги.

## Для кого
- Продавцы-новички.
- Действующие селлеры на маркетплейсах.
- Менеджеры по маркетплейсам.

## Какую задачу решает
Рынок сервисов для расчёта юнит-экономики пока раздроблен. Многие продукты слишком упрощены или заточены под одну площадку и не учитывают реальные налоговые условия.

UnitBotSD собирает все четыре маркетплейса в одном тарифе. В сервисе есть актуальные шаблоны расчёта для каждой площадки. Налоги считаются для разных режимов. Наглядные расчёты показывают, где проседает маржинальность. Для новичков есть видеогайды, а аналитики сервиса отвечают на вопросы.

Сервис помогает принять решение о цене и ассортименте до закупки, а не после. Вы видите, как налоговый режим меняет итоговую прибыль, и находите товары, которые тянут маржу вниз. Для новичков есть видеогайды, а аналитики сервиса отвечают на вопросы.

Сервис помогает сравнить площадки между собой и оценить, где выгоднее продавать конкретный товар.

## Возможности
- Расчёт юнит-экономики для Wildberries, Ozon, Яндекс Маркета и Магнит Маркета.
- Актуальные шаблоны для каждой площадки.
- Расчёт налогов для разных режимов.
- Визуальный анализ маржинальности.
- Видеогайды.
