# Accessibility Insights

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Доступность (a11y) · Global
Буква: A · Страница на сайте: `/tools/accessibility-insights`

## Описание

Accessibility Insights — бесплатный набор инструментов Microsoft для проверки доступности сайтов и приложений Windows по WCAG. Есть расширение для Chrome и Edge и десктопная версия для Windows.

Главное отличие — сочетание автоматической проверки на движке axe-core и пошагового ручного аудита: инструмент ведёт по всем критериям WCAG и подсказывает, что проверить руками.

### Возможности
- **FastPass** за пару минут находит типовые ошибки: контраст, подписи, ARIA, порядок табуляции.
- **Assessment** — пошаговый аудит по критериям WCAG 2.1 AA с отметками и отчётом.
- **Визуализация** заголовков, ориентиров и порядка фокуса прямо на странице.
- **Tab stops:** показывает путь фокуса с клавиатуры и пропущенные элементы.
- **Экспорт отчёта** в HTML и создание задач в GitHub или Azure Boards.

### Кому подходит
Фронтенд-разработчикам, дизайнерам и QA, которые проверяют сайт на доступность перед запуском и хотят пройти аудит по чек-листу WCAG.

### Как пользоваться
Установите расширение, откройте страницу и запустите FastPass. Исправьте найденное, затем пройдите Assessment для ключевых шаблонов: главная, каталог, форма.

### Совет
Автопроверка ловит лишь часть проблем. После FastPass пройдите страницу клавиатурой и экранной читалкой [[NVDA]] или [[VoiceOver]] — так всплывают ошибки, которых не видит ни один сканер.

### Ограничения
Расширение работает только в Chromium-браузерах. Ручной аудит требует времени и знания WCAG. Для быстрых проверок в браузере есть [[axe DevTools]] и [[WAVE]].

## Частые вопросы
### Accessibility Insights бесплатный?
Да, полностью: это открытый проект Microsoft без платных функций.

### Работает ли Accessibility Insights в России?
Да, расширение ставится из магазина Chrome или Edge без VPN и оплаты.

### Accessibility Insights или axe DevTools?
Оба используют движок axe-core. Accessibility Insights бесплатно даёт пошаговый ручной аудит, у [[axe DevTools]] часть сценариев платная, но удобнее интеграция в процесс разработки.

### Хватит ли автоматической проверки для соответствия WCAG?
Нет. Автоматика находит около трети проблем, остальное проверяют вручную: клавиатура, читалка, смысл подписей.
