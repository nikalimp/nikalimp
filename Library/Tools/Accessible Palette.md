# Accessible Palette

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Цвет и контраст · Global
Буква: A · Страница на сайте: `/tools/accessible-palette`

## Описание

Accessible Palette — бесплатный веб-инструмент для построения цветовых шкал с предсказуемым контрастом. Каждая ступень шкалы имеет одинаковую воспринимаемую светлоту во всех цветах палитры.

Главное отличие — шкалы строятся в цветовом пространстве CIELAB, а не HSL: синий-500 и жёлтый-500 получаются одинаково светлыми, поэтому пары «текст — фон» проходят контраст WCAG сразу для всех цветов.

### Возможности
- **Шкалы по светлоте:** задайте базовые цвета, инструмент выровняет ступени по L* в CIELAB.
- **Проверка контраста** WCAG для каждой ступени относительно белого и чёрного.
- **Настройка кривых** насыщенности и оттенка по ступеням.
- **Экспорт** в CSS-переменные и формат для Tailwind.
- **Несколько цветов сразу:** основной, нейтральный, статусные — в одной системе.

### Кому подходит
Дизайнерам интерфейсов и дизайн-систем, которым нужна палитра с гарантированным контрастом для текстов, кнопок и состояний.

### Как пользоваться
Введите основной цвет бренда и нейтральный, задайте число ступеней, проверьте контраст, затем экспортируйте токены в CSS или конфиг [[Tailwind CSS]].

### Совет
Закрепите правило: текст на фоне берётся минимум через 5 ступеней шкалы. Тогда контраст 4,5:1 выполняется автоматически, и в [[Figma]] не нужно проверять каждую пару вручную. Для финальной проверки используйте [[Stark]] или [[WebAIM Contrast Checker]].

### Ограничения
Нет сохранения проектов и совместной работы. Инструмент строит шкалы, но не подбирает гармоничные сочетания цветов. Для готовых шкал есть [[Radix Colors]], для продвинутой генерации — [[Leonardo Color]].

## Вердикт
- Кому подходит: Дизайнерам дизайн-систем, которым нужны шкалы цветов с предсказуемым контрастом.
- Кому не подходит: Тем, кто ищет вдохновение и готовые сочетания цветов для бренда.

## Частые вопросы
### Accessible Palette бесплатный?
Да, все функции бесплатны и не требуют регистрации.

### Работает ли Accessible Palette в России?
Да, сайт открывается без VPN, оплата не нужна.

### Accessible Palette или Leonardo Color?
Accessible Palette проще: выравнивает светлоту шкалы для нескольких цветов. [[Leonardo Color]] строит палитру от целевого коэффициента контраста и подходит для сложных тем со светлым и тёмным режимом.

### Зачем выравнивать светлоту шкалы?
Чтобы правило контраста работало для всех цветов одинаково: если серый-600 на белом читается, то и синий-600, и красный-600 тоже.
