## Описание

Aider — бесплатный AI-ассистент для программирования в терминале. Он правит файлы вашего проекта по запросу на естественном языке и сразу коммитит изменения в git.

Главное отличие — работа с любой моделью и глубокая связка с git: каждое изменение — отдельный коммит с понятным сообщением, его легко откатить.

### Возможности
- **Любая LLM:** Claude, GPT, Gemini, [[DeepSeek]], модели через [[OpenRouter]] и локальные модели.
- **Карта репозитория:** Aider строит сжатое описание кода и передаёт модели нужный контекст.
- **Автокоммиты** с осмысленными сообщениями.
- **Запуск тестов и линтера** после правки и автоисправление ошибок.
- **Голосовой ввод** и режим работы из IDE через комментарии.

### Кому подходит
Разработчикам, которые живут в терминале, хотят выбирать модель сами и платить только за API без подписки.

### Как начать
Установите Aider через pip, задайте API-ключ провайдера, перейдите в папку репозитория и запустите aider с нужными файлами. Опишите задачу обычными словами.

### Совет
Добавляйте в чат только файлы, которые нужно менять, и держите правила проекта в файле соглашений или [[Agents.md]]. Так модель тратит меньше токенов и реже ошибается.

### Ограничения
Нет графического интерфейса, порог входа выше, чем у [[Cursor]] или [[Cline]] в [[VS Code]]. Расходы на API зависят от модели и размера контекста.

## Частые вопросы
### Aider бесплатный?
Да, сам инструмент бесплатный. Платите только провайдеру модели за запросы или используете локальную модель бесплатно.

### Работает ли Aider в России?
Aider работает локально без ограничений. Для API OpenAI и Anthropic нужны VPN и зарубежная карта; DeepSeek и OpenRouter доступнее.

### Aider или Cursor?
[[Cursor]] — редактор с интерфейсом и подпиской. Aider — терминальный инструмент без подписки, где вы сами выбираете модель.

### Какая модель лучше для Aider?
Разработчики публикуют рейтинг моделей на собственном бенчмарке. Обычно лучшие результаты дают топовые модели Anthropic, OpenAI и Google.
