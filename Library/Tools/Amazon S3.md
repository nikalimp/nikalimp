# Amazon S3

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · Хранение файлов и облака · Global
Буква: A · Страница на сайте: `/tools/amazon-s3`

## Описание

Amazon S3 — объектное хранилище Amazon Web Services: хранит файлы любого объёма, от картинок сайта до резервных копий и датасетов, и отдаёт их по API.

Главное отличие — S3 стал отраслевым стандартом: его API поддерживают почти все хранилища, библиотеки и сервисы бэкапов.

### Возможности
- **Классы хранения:** Standard, Intelligent-Tiering, Glacier для архивов.
- **Версионирование** и защита объектов от удаления.
- **Политики доступа** и подписанные ссылки на файлы.
- **Статический хостинг сайтов** и связка с CloudFront.
- **Жизненный цикл:** автоматический перевод старых файлов в дешёвый класс.

### Кому подходит
Разработчикам и компаниям, которые строят продукт на [[AWS]] и работают с зарубежной аудиторией.

### Как начать
Создайте аккаунт AWS, бакет в нужном регионе и пользователя IAM с ограниченными правами. Загружайте файлы через консоль, CLI или SDK.

### Совет
Сразу закройте публичный доступ к бакету и настройте правила жизненного цикла. Самая частая неожиданная статья расходов — исходящий трафик, поэтому раздавайте файлы через CDN.

### Ограничения
Тарификация сложная: хранение, запросы и трафик считаются отдельно. Для российских проектов из-за оплаты и 152-ФЗ лучше [[Yandex Object Storage]] или [[Selectel S3]]. Без платы за трафик — [[Cloudflare R2]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: пробный период
- Платформы: Веб, API

## Вердикт
- Кому подходит: Разработчикам продуктов на AWS с зарубежной аудиторией.
- Кому не подходит: Российским проектам с персональными данными и оплатой в рублях.
- Итог: Эталонное объектное хранилище, но из России недоступное без зарубежных реквизитов.

## Плюсы
- Стандартный API, который поддерживают все
- Классы хранения под любые задачи
- Высокая надёжность и версионирование
- Интеграция со всеми сервисами AWS

## Минусы
- Сложная тарификация и дорогой трафик
- Нет регистрации и оплаты из России
- Требования 152-ФЗ к данным россиян

## Частые вопросы
### Amazon S3 бесплатный?
Нет, но новые аккаунты AWS получают до $200 кредитов на 6 месяцев, их можно тратить на S3.

### Работает ли Amazon S3 в России?
AWS не регистрирует новых клиентов из России и не принимает российские карты.

### Чем заменить Amazon S3 в России?
[[Yandex Object Storage]] и [[Selectel S3]] поддерживают S3-совместимый API: код и библиотеки менять почти не придётся.

### Amazon S3 или Cloudflare R2?
[[Cloudflare R2]] не берёт плату за исходящий трафик и выгоднее для раздачи файлов. S3 богаче по функциям и классам хранения.

## Цена

Оплата по факту: хранение в классе Standard — около $0,023 за ГБ в месяц, плюс запросы и исходящий трафик. Новым аккаунтам AWS даёт до $200 кредитов на 6 месяцев.


## Доступность из России

AWS не регистрирует новых клиентов из России и не принимает российские карты: нужны зарубежная карта и адрес. Российские аналоги с S3-совместимым API — [[Yandex Object Storage]] и [[Selectel S3]].
