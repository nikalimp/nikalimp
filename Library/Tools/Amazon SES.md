# Amazon SES

## Описание

Amazon SES (Simple Email Service) — сервис отправки писем от Amazon Web Services: транзакционные письма, уведомления и массовые рассылки через API или SMTP.

Главное отличие — цена: $0,10 за тысячу писем, это в разы дешевле маркетинговых платформ вроде [[Mailchimp]].

### Возможности
- **Отправка через API и SMTP** из любого языка и фреймворка.
- **Настройка домена:** SPF, DKIM, DMARC и свой MAIL FROM.
- **Выделенные IP** и управляемые пулы IP.
- **Virtual Deliverability Manager:** аналитика доставляемости и советы.
- **Входящая почта:** приём писем и передача в Lambda или S3.

### Кому подходит
Разработчикам SaaS и интернет-магазинов, которые отправляют много транзакционных писем и готовы сами собрать шаблоны и логику.

### Как начать
Создайте аккаунт AWS, подтвердите домен через DNS и запросите выход из sandbox: без этого письма уходят только на подтверждённые адреса.

### Совет
Следите за процентом жалоб и отказов: при превышении порогов AWS ограничивает отправку. Обрабатывайте bounce и complaint через SNS и удаляйте такие адреса из базы.

### Ограничения
Нет визуального конструктора писем и удобной работы с базой: это инфраструктура, а не маркетинговый сервис. Для разработчиков удобнее API у [[Resend]] или [[SendGrid]].

## Вердикт
- Кому подходит: Разработчикам, которым нужна дешёвая отправка больших объёмов писем.
- Кому не подходит: Маркетологам без разработчика и российским компаниям.
- Итог: Самая дешёвая надёжная инфраструктура для писем, но без интерфейса маркетолога и без доступа из России.

## Частые вопросы
### Сколько стоит Amazon SES?
$0,10 за 1 000 писем плюс $0,12 за ГБ вложений. Новые аккаунты могут оплатить первые месяцы кредитами Free Tier.

### Работает ли Amazon SES в России?
Нет: AWS не регистрирует новых клиентов из России и не принимает российские карты.

### Amazon SES или Resend?
[[Resend]] удобнее для разработчиков: простой API, шаблоны на React и понятная панель. SES дешевле на больших объёмах.

### Что такое sandbox в SES?
Это стартовый режим, в котором можно отправлять письма только на подтверждённые адреса. Выход из него запрашивают через поддержку AWS.
