## Описание

Anima — сервис и плагин для Figma, который превращает макеты в код на React, Vue, HTML и Tailwind, а также собирает прототипы по текстовому описанию в AI Playground.

Главное отличие от ручной вёрстки — скорость первого результата: код всей страницы или компонента получается за минуты, а разработчик его дорабатывает.

### Возможности
- **Плагин для [[Figma]]:** экспорт фреймов в React, Vue, HTML, CSS и Tailwind.
- **AI Playground:** правки сгенерированного кода по текстовым запросам.
- **Клонирование сайтов:** импорт страницы по адресу в редактируемый код.
- **Inspect для разработчиков** с размерами, стилями и ассетами.
- **Связь с дизайн-системой:** использование своих компонентов при генерации.

### Кому подходит
Дизайнерам, которые хотят показать рабочий прототип, и фронтенд-разработчикам, которым нужен стартовый код по макету.

### Как начать
Установите плагин Anima в Figma, выделите фрейм и выберите фреймворк. Откройте результат в Playground, поправьте запросами и скачайте код.

### Совет
Готовьте макет к экспорту: Auto Layout на всех блоках, понятные имена слоёв, компоненты вместо копий. Чем чище макет, тем меньше абсолютного позиционирования в коде.

### Ограничения
Код требует доработки: семантика, доступность и логика остаются на разработчике. Бесплатных генераций мало. Похожую задачу решает [[Builder.io]], а для обратного пути, из сайта в Figma, есть отдельные плагины.

## Частые вопросы
### Anima бесплатная?
Есть бесплатный план с пятью генерациями кода и пятью импортами из Figma. Для регулярной работы нужен Pro.

### Работает ли Anima в России?
Плагин и сайт работают без VPN, но подписку можно оплатить только зарубежной картой.

### Anima или Builder.io?
[[Builder.io]] сильнее в связке с существующей кодовой базой и CMS. Anima проще для быстрого экспорта макета в код.

### Можно ли использовать код Anima в продакшене?
Да, но после проверки: поправьте семантику, адаптив и доступность, замените абсолютные отступы на сетку.
