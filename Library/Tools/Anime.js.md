## Описание

Anime.js — лёгкая JavaScript-библиотека для анимации на сайтах. Она анимирует CSS-свойства, SVG, DOM-атрибуты и объекты JavaScript через один простой API.

Главное отличие — компактность и простой синтаксис при богатых возможностях: в четвёртой версии библиотека стала модульной, и в сборку попадает только то, что вы используете.

### Возможности
- **Анимация** CSS, трансформаций, SVG-атрибутов и любых JS-объектов.
- **Таймлайны** для последовательных и параллельных анимаций.
- **SVG:** морфинг фигур, отрисовка линий и движение по пути.
- **Scroll Observer:** запуск и привязка анимации к прокрутке.
- **Draggable, stagger и пружинные easing** для интерактивных эффектов.

### Кому подходит
Фронтенд-разработчикам и дизайнерам, которые оживляют лендинги, иллюстрации и интерфейсы без тяжёлых зависимостей.

### Как начать
Установите пакет animejs через npm, импортируйте функцию animate и передайте ей селектор и параметры. Сложные сцены собирайте в таймлайн.

### Совет
Анимируйте transform и opacity: они не вызывают перерасчёт раскладки и не тормозят на слабых телефонах. Учитывайте настройку prefers-reduced-motion.

### Ограничения
Для сложных скролл-сцен и экосистемы плагинов чаще берут [[GSAP]], для анимации в React — [[Motion (motion.dev)]]. Плавную прокрутку отдельно даёт [[Lenis]], векторные анимации из After Effects — [[Lottie]].

## Частые вопросы
### Anime.js бесплатный?
Да, библиотека распространяется под лицензией MIT и бесплатна для любых проектов.

### Работает ли Anime.js в России?
Да, пакет ставится из npm или подключается с CDN без ограничений.

### Anime.js или GSAP?
[[GSAP]] мощнее для сложных скролл-сцен и тоже стал бесплатным. Anime.js легче и проще для типовых анимаций интерфейса.

### Можно ли использовать Anime.js в React?
Да, создавайте анимацию в useEffect и очищайте её при размонтировании компонента.
