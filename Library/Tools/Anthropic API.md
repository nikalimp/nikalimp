## Описание

Anthropic API — программный доступ к моделям Claude. Разработчики используют его для чат-ботов, анализа документов, генерации кода, AI-агентов и автоматизации работы с текстом.

Модели Claude ценят за качество текстов, работу с длинным контекстом и надёжное следование инструкциям, что особенно важно в агентах и сложных сценариях.

### Возможности
- **Модели Claude** разных уровней: быстрые и недорогие, сбалансированные и самые мощные.
- **Длинный контекст** — анализ больших документов и кодовых баз за один запрос.
- **Вызов инструментов** — модель обращается к вашим функциям и API.
- **Работа с изображениями и PDF.**
- **Кэширование промптов** для снижения стоимости повторяющегося контекста.
- **Batch API** для массовой обработки.
- **Claude Agent SDK** для создания агентов.
- **Протокол MCP** для подключения внешних сервисов.

### Кому подходит
Разработчикам AI-продуктов, компаниям, которые автоматизируют работу с документами и поддержкой, командам, которые строят AI-агентов для программирования и аналитики.

### Как начать
Зарегистрируйтесь в консоли Anthropic, пополните баланс и получите ключ. Попробуйте запросы в песочнице Workbench, затем перенесите их в код.

### Совет
Выносите неизменную часть промпта — инструкции, примеры, документы — в начало запроса и включайте кэширование. Для чат-ботов с длинной базой знаний это заметно снижает расходы.

### Ограничения
Модели не генерируют изображения. Для картинок понадобится отдельный сервис.

### Где особенно полезен
В обработке договоров, отчётов и переписки, где важно точно следовать инструкциям и не терять детали длинного документа.

### Частый вопрос
**Anthropic API или OpenAI API?** Выбирают по качеству на конкретной задаче: протестируйте обе модели на 20–30 реальных примерах. Один ключ для обеих — через [[OpenRouter]]. Готовое приложение — [[Claude]], сравните также [[OpenAI API]].

## Вердикт
- Кому подходит: Разработчикам и командам, которым нужен доступ к моделям Claude для своих приложений, агентов и автоматизаций.
- Кому не подходит: Тем, кому нужен готовый чат без кода: для этого есть приложение Claude, а API требует подключения и оплаты по токенам.
- Итог: Anthropic API — доступ к моделям Claude с оплатой за токены, из России нужен зарубежный аккаунт и карта.

## Плюсы
- Оплата только за использованные токены, без абонентской платы
- Кэширование запросов и пакетная обработка снижают стоимость
- Несколько моделей разного размера под разные задачи
- Подходит для агентов, кода и работы с длинными документами

## Минусы
- Россия официально не поддерживается
- Интерфейс консоли и документация на английском
- Стоимость растёт с объёмом, нужно следить за расходом токенов

## Частые вопросы
### Сколько стоит Anthropic API?
Оплата идёт за входные и выходные токены, цена зависит от модели. Например, Claude Sonnet 5.5 стоит $2 за 1 млн входных и $10 за 1 млн выходных токенов, Opus 5.5 — $4 и $20. Актуальную таблицу смотрите на странице цен Anthropic.

### Работает ли Anthropic API в России?
Нет, Anthropic официально не поддерживает Россию. Нужен зарубежный аккаунт, зарубежная карта и обычно VPN.

### Что лучше: Anthropic API или OpenAI API?
Оба дают доступ к сильным моделям с оплатой за токены. Anthropic часто берут для кода и агентов, OpenAI — за широкий набор модальностей; лучше проверить обе на своей задаче.

### Есть ли у Anthropic API бесплатный тариф?
Постоянного бесплатного плана нет, работа идёт по предоплате за токены. Чат в приложении Claude устроен отдельно.
