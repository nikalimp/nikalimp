## Описание

Apify — платформа для парсинга сайтов и автоматизации работы в браузере. В её каталоге тысячи готовых «акторов» — парсеров для Google Maps, Instagram, TikTok, Amazon, сайтов вакансий и других источников, — а также инструменты для создания своих.

Apify основан в Чехии и стал одной из главных платформ веб-скрапинга, в том числе для сбора данных под AI-приложения.

### Возможности
- **Каталог готовых парсеров** для популярных сайтов.
- **Свои парсеры** на JavaScript и Python с библиотекой Crawlee.
- **Прокси** для обхода ограничений.
- **Расписание** запусков.
- **Хранилища** результатов и выгрузка в JSON, CSV, Excel.
- **Интеграции** с Make, n8n, Zapier и AI-агентами через MCP.
- **API** для своих приложений.

### Кому подходит
Маркетологам и аналитикам — для сбора данных о конкурентах и рынке. Разработчикам — для парсинга в продуктах. Специалистам по AI — для наполнения баз знаний.

### Как начать
Найдите готовый актор — например, для сбора компаний из Google Maps, — задайте параметры и запустите. Результат скачайте в таблицу.

### Как использовать в работе
Собирайте базу потенциальных клиентов: компании из карт в нужном городе и нише с сайтами и контактами — готовая база для аутрича.

### Где особенно полезен
В исследованиях рынка: цены конкурентов, отзывы, ассортимент — регулярно и без ручной работы.

### Совет
Соблюдайте правила сайтов и законы о персональных данных: не собирайте личные данные без законных оснований.

### Партнёрская программа
У Apify есть партнёрская программа с рекуррентным вознаграждением.

### Частый вопрос
**Apify или Firecrawl?** [[Firecrawl]] превращает сайты в чистый текст для AI, Apify — универсальная платформа парсинга. Связать результаты с другими сервисами помогут [[n8n]] и [[Make]].

## Частые вопросы
### Сколько стоит Apify?
Есть бесплатный тариф с $5 использования в месяц. Платные: Starter — $19, Scale — $199, Business — $999 в месяц, при оплате за год скидка 10%.

### Работает ли Apify в России?
Сайт открывается, но оплата российскими картами недоступна. Для платных тарифов нужна зарубежная карта.

### Что лучше: Apify или Bright Data?
Apify удобнее, если нужны готовые парсеры и свои скрипты в облаке, Bright Data сильнее в прокси и больших объёмах. Выбирайте по задаче.

### Для чего нужен Apify?
Это платформа для запуска парсеров и автоматизаций в облаке. Можно взять готовый актор из каталога или написать свой.
