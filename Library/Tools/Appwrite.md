## Описание

Appwrite — это open-source бэкенд для веб- и мобильных приложений: база данных, авторизация, хранилище файлов, серверные функции и realtime в одном сервисе.

Главное отличие от Supabase и Firebase — выбор: ту же платформу можно развернуть у себя через Docker или взять готовое облако Appwrite Cloud.

### Возможности
- **Базы данных** с коллекциями, правами доступа и индексами; в облаке есть выделенные инстансы.
- **Авторизация:** email, телефон, magic link, OAuth-провайдеры, команды и роли.
- **Storage** для файлов с превью изображений и антивирусом.
- **Functions** на Node.js, Python, PHP, Dart и других языках, с запуском по событиям и расписанию.
- **Sites** для хостинга фронтенда и **Realtime** для подписки на изменения.
- **SDK** для веба, Flutter, React Native, iOS и Android.

### Кому подходит
Разработчикам MVP и небольших продуктов, которым нужен готовый бэкенд, а также командам, которым важно хранить данные на своём сервере.

### Как начать
Создайте проект в Appwrite Cloud или поднимите Docker-контейнер на VPS. Подключите SDK, настройте коллекцию и права, затем авторизацию.

### Совет
Для проектов с персональными данными россиян ставьте self-hosted Appwrite на российский сервер: так проще выполнить требования о локализации данных.

### Ограничения
Документная модель данных менее гибкая, чем чистый SQL. Для сложных связей и отчётов удобнее Postgres-решения или ORM вроде [[Prisma]]. Если нужна только авторизация, проще взять [[Clerk]] или [[Auth.js]].

## Вердикт
- Кому подходит: Разработчикам MVP и мобильных приложений, которым нужен бэкенд «из коробки» с возможностью self-hosting.
- Кому не подходит: Проектам со сложной реляционной моделью данных и тяжёлой аналитикой.
- Итог: Гибкий open-source бэкенд, который одинаково работает в облаке и на своём сервере.

## Плюсы
- Open-source и бесплатный self-hosting
- База, авторизация, файлы, функции и хостинг в одном месте
- SDK для веба, Flutter и мобильных платформ
- Pro-тариф считается за проект, а не за участника команды

## Минусы
- Облако не оплатить российской картой
- Документная модель уступает SQL в сложных запросах
- Self-hosting требует администрирования и бэкапов

## Частые вопросы
### Appwrite бесплатный?
Да, self-hosted версия бесплатна полностью, а в облаке есть бесплатный план с квотами. Pro стоит от $25 в месяц за проект.

### Работает ли Appwrite в России?
Self-hosted версию можно развернуть на российском сервере без ограничений. Облако работает, но оплатить Pro можно только зарубежной картой.

### Appwrite или Supabase?
Supabase построен на Postgres и лучше для реляционных данных. Appwrite проще в старте, поддерживает больше языков для функций и удобнее для self-hosting.

### Можно ли перенести проект из облака на свой сервер?
Да, у Appwrite есть инструмент миграции между облаком и self-hosted версией.
