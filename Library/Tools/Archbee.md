## Описание

Archbee — платформа для технической документации и базы знаний: справка продукта, документация API и внутренние инструкции команды.

Главное отличие — редактор для команды и публичный сайт документации в одном продукте: тексты пишут в визуальном редакторе, а читатели получают быстрый сайт со своим доменом и поиском.

### Возможности
- **Блочный редактор** с вкладками, схемами, кодом и встраиваемыми видео.
- **Документация API** из OpenAPI с интерактивной проверкой запросов.
- **Публичный сайт** документации со своим доменом и брендингом.
- **Синхронизация с GitHub** и версии документации.
- **AI-поиск** с ответами по содержимому базы.

### Кому подходит
SaaS-компаниям и продуктовым командам, которым нужны публичная справка, документация API и внутренняя база знаний без своей разработки.

### Как начать
Возьмите пробный период, импортируйте существующие документы из Markdown или [[Confluence]], настройте структуру разделов и подключите свой домен.

### Совет
Пишите статьи справки по задачам пользователя: «как подключить оплату», а не «раздел Настройки». Такие статьи чаще находят в поиске и цитируют AI-ассистенты.

### Ограничения
Цена выше, чем у open-source генераторов. Похожие сервисы — [[GitBook]], [[Mintlify]] и [[ReadMe (инструмент)|ReadMe]], бесплатные с кодом — [[Docusaurus]] и [[Fumadocs]].

## Вердикт
- Кому подходит: SaaS-командам, которым нужна публичная справка и документация API без разработки.
- Кому не подходит: Командам с ограниченным бюджетом и разработчикам, готовым собрать документацию из кода.
- Итог: Удобная платформа документации с визуальным редактором и публичным сайтом, но с оплатой зарубежной картой.

## Частые вопросы
### Сколько стоит Archbee?
Младший тариф стоит несколько десятков долларов в месяц за команду, старшие — дороже. Первые 14 дней бесплатно.

### Работает ли Archbee в России?
Сайт открывается, но подписку оплачивают только зарубежной картой.

### Archbee или GitBook?
Оба дают визуальный редактор и публичный сайт документации. [[GitBook]] популярнее у open-source проектов и имеет бесплатный план, Archbee гибче в блоках и документации API.

### Можно ли сделать в Archbee внутреннюю базу знаний?
Да, можно закрыть пространство для сотрудников и разграничить доступ.
