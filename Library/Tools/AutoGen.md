## Описание

AutoGen — открытый фреймворк Microsoft для создания многоагентных систем на Python и .NET. В нём несколько ИИ-агентов общаются друг с другом, распределяют роли и вместе решают задачу.

С октября 2025 года AutoGen находится в режиме поддержки: Microsoft исправляет ошибки, но новые функции развивает в преемнике — Microsoft Agent Framework. Существующие проекты продолжают работать.

### Возможности
- **AgentChat** — готовые шаблоны команд агентов: ассистент, критик, исполнитель кода.
- **Core** — событийная модель для сложных распределённых систем.
- **Extensions** — подключение моделей разных провайдеров, инструментов и выполнения кода.
- **AutoGen Studio** — визуальный интерфейс для сборки и тестирования агентов без кода.

### Кому подходит
Разработчикам и исследователям, которые экспериментируют с многоагентными сценариями: генерация и проверка кода, исследования, обработка документов.

### Как начать
Установите `autogen-agentchat` через pip, подключите ключ [[OpenAI API]] или локальную модель и запустите пример с двумя агентами. Затем добавляйте инструменты и роли.

### Совет
Для нового продакшен-проекта сравните AutoGen с Microsoft Agent Framework, [[LangGraph]] и [[CrewAI]]: у них активная разработка. AutoGen хорош для прототипов и изучения идеи многоагентности.

### Ограничения
Новых функций больше не будет. Многоагентные диалоги расходуют много токенов, а их поведение сложно отлаживать.

## Частые вопросы
### AutoGen бесплатный?
Да, фреймворк открыт и бесплатен. Деньги уходят только на API моделей, которые вы подключаете.

### Работает ли AutoGen в России?
Библиотека устанавливается без ограничений. Для API OpenAI и Anthropic нужны VPN и зарубежная карта, поэтому часто используют локальные модели через [[LM Studio]].

### AutoGen или CrewAI?
[[CrewAI]] проще для команд агентов с ролями и активно развивается. AutoGen гибче на низком уровне, но уже в режиме поддержки.

### AutoGen больше не развивается?
Microsoft перевела AutoGen в режим поддержки и развивает Microsoft Agent Framework. Ошибки исправляют, старые проекты работают.
