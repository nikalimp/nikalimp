## Описание

Axure RP — профессиональный инструмент для создания сложных интерактивных прототипов. В отличие от Figma, в Axure можно задать настоящую логику: условия, переменные, вычисления, динамические панели, повторители данных.

Axure появился в 2002 году и до сих пор используется UX-специалистами, аналитиками и проектировщиками для прототипов корпоративных систем, где поведение интерфейса важнее визуального стиля.

### Возможности
- **Условная логика** и переменные в прототипах.
- **Динамические панели** — состояния элементов.
- **Повторители** для таблиц и списков с данными.
- **Формы** с валидацией.
- **Адаптивные представления.**
- **Документация** и спецификации прямо в прототипе.
- **Публикация** прототипа для тестирования.

### Кому подходит
UX-архитекторам, бизнес-аналитикам и проектировщикам сложных систем: банковских интерфейсов, CRM, админок, ERP.

### Как начать
Соберите один сценарий с реальной логикой — например, фильтрацию таблицы — и опубликуйте прототип для команды.

### Как использовать в работе
Используйте прототипы Axure как живую спецификацию: разработчики видят поведение интерфейса во всех состояниях вместо длинного текстового ТЗ.

### Где особенно полезен
В проектах со сложными формами, фильтрами и таблицами, где статичные макеты не передают поведение.

### Совет
Не делайте в Axure финальный визуальный дизайн: инструмент силён в логике, а не в оформлении.

### Ограничения
Высокий порог входа и устаревший по сравнению с Figma интерфейс.

### Кому не подойдёт
Для маркетинговых сайтов и простых приложений достаточно прототипов Figma.

### Связка
Визуальный дизайн экранов делайте в Figma.

### Частый вопрос
**Axure или Figma?** [[Figma]] — для визуального дизайна и простых прототипов, Axure — для сложной логики. Живые прототипы с кодом можно собрать в [[Figma Make]] или [[ProtoPie]].

## Частые вопросы
### Сколько стоит Axure RP?
Axure RP работает по подписке за пользователя: на странице цен Pro стоит $29 в месяц, Team — $49 в месяц. Для крупных компаний есть Enterprise по запросу.

### Есть ли бесплатная версия Axure RP?
Бесплатного тарифа нет, но есть полнофункциональный пробный период на 30 дней для Windows и macOS.

### Что лучше: Axure RP или Figma?
Axure сильнее в прототипах со сложной логикой, Figma — в совместном дизайне интерфейсов и библиотеках компонентов. Для визуального дизайна чаще берут Figma, для детальных сценариев — Axure.

### Для чего нужен Axure RP?
Для прототипов интерфейсов с интерактивной логикой и документацией: условия, переменные, переходы между состояниями.
