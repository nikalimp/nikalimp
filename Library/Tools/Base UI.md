# Base UI

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · UI-библиотеки и компоненты · Global
Буква: B · Страница на сайте: `/tools/base-ui`

## Описание

Base UI — библиотека нестилизованных React-компонентов с правильной доступностью: меню, диалоги, поповеры, селекты, слайдеры. Её делают авторы [[Material UI]], Radix и Floating UI.

Главное отличие от готовых UI-китов — в компонентах нет стилей. Вы получаете поведение, клавиатурную навигацию и ARIA, а внешний вид задаёте сами, например через [[Tailwind CSS]].

### Возможности
- **Десятки компонентов** — диалоги, меню, табы, комбобоксы, тултипы, формы.
- **Доступность из коробки** — фокус, клавиатура и атрибуты ARIA.
- **Без стилей** — подходит под любую дизайн-систему.
- **Композиция** — компоненты собираются из частей, можно заменить рендер любой части.
- **Поддержка в [[shadcn ui|shadcn/ui]]** — Base UI можно выбрать основой компонентов.

### Кому подходит
Фронтенд-разработчикам и командам, которые строят свою дизайн-систему на React и не хотят писать доступные выпадающие меню и диалоги с нуля.

### Как начать
Установите пакет Base UI из npm и соберите первый компонент по примеру из документации. Стилизуйте части через классы или data-атрибуты состояния.

### Совет
Если нужна готовая визуальная основа, начните с shadcn/ui на Base UI и правьте компоненты в своём репозитории. Писать всё с чистого листа имеет смысл только для собственной дизайн-системы.

### Ограничения
Только React. Стили, темы и визуальные шаблоны придётся делать самостоятельно. Экосистема примеров пока меньше, чем у Radix и [[React Aria]].

## Частые вопросы
### Base UI бесплатный?
Да, библиотека полностью бесплатная и открытая.

### Работает ли Base UI в России?
Да, пакет устанавливается из npm без VPN.

### Base UI или Radix?
Обе библиотеки дают нестилизованные доступные компоненты. Base UI делают в том числе бывшие авторы Radix, она активно развивается и поддерживается в shadcn/ui.

### Можно ли использовать Base UI с Tailwind?
Да, это частая связка: классы Tailwind вешаются на части компонентов, а состояния берутся из data-атрибутов.
