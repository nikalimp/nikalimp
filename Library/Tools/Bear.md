## Описание

Bear — приложение для заметок на Markdown для iPhone, iPad и Mac. Его ценят за аккуратную типографику, быстрый поиск и систему вложенных тегов вместо папок.

Главное отличие от [[Obsidian]] и [[Notion]] — минимум настроек: Bear работает сразу после установки и выглядит красиво без плагинов.

### Возможности
- **Markdown-редактор** — заголовки, списки, задачи, код, таблицы.
- **Вложенные теги** — `#работа/клиенты` вместо папок.
- **Связи между заметками** — ссылки на другие заметки и разделы.
- **Экспорт** — PDF, HTML, DOCX, Markdown (в Pro).
- **Синхронизация через iCloud, шифрование заметок, поиск по тексту на картинках** — в Pro.

### Кому подходит
Пользователям техники Apple, которые пишут черновики, заметки и статьи и хотят простой красивый инструмент без сложной настройки.

### Как начать
Скачайте Bear из App Store, заведите 3–5 тегов верхнего уровня и пишите. Если пользуетесь несколькими устройствами, оформите Pro для синхронизации.

### Совет
Используйте теги как контексты, а не как ярлыки к каждой мысли: «Проекты», «Идеи», «Чтение». Для сохранения статей из сети держите рядом [[Readwise]] или [[Raindrop.io]].

### Ограничения
Работает только на устройствах Apple, версии для Windows и Android нет. Синхронизация между устройствами — только в Pro, а оплатить её российской картой нельзя.

## Частые вопросы
### Bear бесплатный?
Базовая версия бесплатна. Синхронизация между устройствами, шифрование и расширенный экспорт доступны в Bear Pro за $2,99 в месяц.

### Работает ли Bear в России?
Приложение работает, но Bear Pro оформляется через App Store, который не принимает российские карты.

### Bear или Obsidian?
Bear проще и красивее из коробки, но только для Apple. [[Obsidian]] бесплатен, работает везде и подходит для большой базы знаний с плагинами.

### Есть ли Bear для Windows?
Нет, Bear работает только на macOS, iPhone и iPad.
