## Описание

Better Stack — это платформа мониторинга: проверка доступности сайтов, статус-страницы, дежурства, сбор логов, ошибок и метрик в одном сервисе.

Главное отличие — удобство: красивые статус-страницы, звонки дежурному при падении сайта и логи с SQL-запросами без настройки собственного стека.

### Возможности
- **Uptime-мониторинг** сайтов, API, SSL-сертификатов и cron-задач.
- **Статус-страницы** на своём домене для клиентов.
- **Дежурства:** расписания, эскалации, звонки и SMS ответственному.
- **Логи и трейсы** с поиском и SQL-запросами.
- **Отслеживание ошибок** и записи сессий для фронтенда.

### Кому подходит
Разработчикам, студиям и SaaS-командам, которые хотят узнавать о падении сайта раньше клиентов.

### Как начать
Добавьте монитор с адресом сайта, укажите email или [[Slack]] для уведомлений и создайте статус-страницу. Позже подключите логи через готовые интеграции.

### Совет
Мониторьте не только главную, а ключевое действие: форму заявки или API оплаты. Сайт может отвечать, а заявки при этом не уходить. Для ночных cron-задач используйте heartbeat-мониторы: они сообщат, если задача не отработала.

### Ограничения
Объёмы логов на бесплатном плане хватает только на маленькие проекты. Для простого мониторинга доступности хватит [[UptimeRobot]], для глубокой аналитики ошибок — [[Sentry]], для своих дашбордов — [[Grafana]].

## Частые вопросы
### Better Stack бесплатный?
Да, бесплатный план включает 10 мониторов, статус-страницу и небольшие объёмы логов и ошибок.

### Работает ли Better Stack в России?
Бесплатный план работает без VPN. Платные функции можно оплатить только зарубежной картой.

### Better Stack или UptimeRobot?
[[UptimeRobot]] проще и дешевле для мониторинга доступности. Better Stack добавляет дежурства, логи и ошибки.

### Можно ли получать уведомления о падении в Telegram?
Да, например через вебхук, который пересылает уведомление боту в [[Telegram (инструмент)|Telegram]].
