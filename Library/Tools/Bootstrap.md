## Описание

Bootstrap — бесплатный CSS-фреймворк с готовой сеткой, компонентами и утилитами для быстрой адаптивной вёрстки сайтов и интерфейсов.

Главное отличие: Bootstrap даёт готовые компоненты — кнопки, формы, модальные окна, меню — которые одинаково выглядят во всех браузерах и работают из коробки без своего CSS.

### Возможности
- **12-колоночная сетка** на флексбоксах с брейкпоинтами для адаптива.
- **Компоненты:** навигация, карточки, формы, модальные окна, выпадающие меню, карусели.
- **Утилиты** для отступов, цветов, типографики и выравнивания.
- **Кастомизация через Sass** и CSS-переменные.
- **Тёмная тема** через цветовые режимы.
- **JavaScript без jQuery** начиная с пятой версии.

### Кому подходит
Разработчикам админок, внутренних сервисов и прототипов. Бэкенд-разработчикам, которым нужна аккуратная вёрстка без дизайнера.

### Как начать
Подключите CSS и JS через CDN или установите пакет `npm install bootstrap`. Возьмите шаблон страницы из документации и собирайте её из готовых компонентов.

### Совет
Не переопределяйте стили поверх готового CSS — меняйте переменные Sass и собирайте свою версию. Так файл станет меньше, а сайт не будет выглядеть как «очередной Bootstrap».

### Ограничения
Сайты на стандартных стилях узнаваемы и выглядят шаблонно. Для дизайна с нуля и современных стеков чаще берут [[Tailwind CSS]] или библиотеки вроде [[shadcn ui|shadcn/ui]] для [[React]].

## Вердикт
- Кому подходит: Разработчикам админок, прототипов и внутренних сервисов, которым нужна быстрая адаптивная вёрстка.

## Частые вопросы
### Bootstrap бесплатный?
Да, фреймворк распространяется бесплатно под лицензией MIT, в том числе для коммерческих проектов.

### Работает ли Bootstrap в России?
Да, его можно установить через npm, подключить через CDN или скачать с GitHub без VPN.

### Bootstrap или Tailwind CSS?
Bootstrap даёт готовые компоненты, [[Tailwind CSS]] — утилитарные классы для своего дизайна. Для быстрой админки подходит Bootstrap, для дизайна по макету из [[Figma]] — Tailwind.

### Нужен ли jQuery для Bootstrap?
Нет, начиная с Bootstrap 5 скрипты компонентов написаны на чистом JavaScript.
