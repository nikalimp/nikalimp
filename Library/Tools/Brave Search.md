# Brave Search

[[Инструменты — GEO и AI-поиск|GEO и AI-поиск]] · AI-поисковики и ответные движки · Global
Буква: B · Страница на сайте: `/tools/brave-search`

## Описание

Brave Search — поисковая система компании Brave с собственным независимым индексом. В отличие от большинства альтернативных поисковиков, она не перепродаёт выдачу Google или Bing, а сканирует интернет сама.

Brave Search встроен в браузер Brave и известен вниманием к приватности: поисковик не собирает профили пользователей. AI-функция Answer with AI даёт краткий ответ со ссылками над результатами.

### Возможности
- **Собственный индекс** веба.
- **AI-ответы** со ссылками на источники.
- **Goggles** — пользовательские правила ранжирования.
- **Поиск без профилирования** пользователя.
- **Brave Search API** — данные поиска для приложений и AI-агентов.

### Почему это важно для GEO
Brave Search API используют многие AI-сервисы и агенты как источник веб-данных. Значит, сайт, который хорошо индексируется Brave, может чаще попадать в ответы AI-инструментов, даже если пользователи не заходят в сам поисковик.

### Кому подходит
Пользователям, которым важна приватность. Разработчикам AI-приложений, которым нужен поисковый API с собственным индексом. SEO- и GEO-специалистам — для проверки, видит ли независимый индекс их сайт.

### Как начать
Проверьте свой сайт поиском с оператором site: — так вы увидите, какие страницы есть в индексе Brave. Задайте несколько вопросов из вашей ниши и посмотрите, на какие сайты ссылается AI-ответ.

### Совет
Не блокируйте краулер Brave в robots.txt без причины. Чем больше независимых индексов знает ваш сайт, тем шире его присутствие в AI-инструментах.

### Ограничения
Индекс меньше, чем у Google, особенно по русскоязычным и локальным запросам.

### Частый вопрос
**Нужно ли оптимизировать сайт под Brave Search?** Отдельной оптимизации не требуется: работают те же принципы, что и для Google. Достаточно открыть сайт для индексации. Похожие альтернативные поисковики — [[Kagi]] и [[You.com]].

## Частые вопросы
### Brave Search бесплатный?
Да, поиск бесплатный и работает в любом браузере на search.brave.com. Платная подписка Search Premium убирает рекламу, а API для разработчиков оплачивается по числу запросов.

### Работает ли Brave Search в России?
Да, поиск открывается без VPN. Оплатить Premium или API российской картой нельзя.

### Что лучше: Brave Search или Google?
Google точнее и полнее, особенно на русском. Brave Search выбирают за приватность и независимый индекс, а разработчики — за API, который можно встроить в AI-агента.

### Где используют Brave Search API?
В AI-ассистентах и агентах, которым нужен свежий веб-поиск: API отдаёт результаты в виде данных, а Answers API — готовый ответ со ссылками. Для Claude и других агентов есть MCP-сервер Brave Search.
