## Описание

Bright Data — платформа для сбора веб-данных: прокси-сети, API для парсинга сайтов и поисковой выдачи, готовые датасеты. Сервис обходит капчи и блокировки, а возвращает чистые данные в JSON или CSV.

Главное отличие — масштаб: одна из крупнейших сетей резидентных прокси и готовые скраперы для сотен популярных сайтов.

### Возможности
- **Прокси:** резидентные, мобильные, серверные и ISP-прокси с геотаргетингом.
- **Web Scraper API** с готовыми сборщиками для маркетплейсов, соцсетей и карт.
- **Unlocker API** — получает страницу в обход капч и антибот-защиты.
- **SERP API** для выдачи Google, Bing и других поисковиков.
- **Датасеты** — готовые выгрузки данных от $250 за 100 000 записей.

### Кому подходит
Аналитикам, разработчикам и командам данных, которые собирают цены, отзывы и выдачу в больших объёмах. Командам AI-агентов, которым нужен доступ к вебу.

### Как начать
Зарегистрируйтесь, пройдите проверку и выберите продукт. Для разовой задачи начните с готового скрапера, для своего кода подключите Unlocker API по примеру из документации.

### Совет
Не берите прокси, если есть готовый скрапер под нужный сайт: платить за записи обычно дешевле, чем за гигабайты трафика и свою поддержку парсера.

### Ограничения
Строгая проверка клиентов и сложное ценообразование. Для no-code задач проще [[Browse AI]] или [[Octoparse]], для своих сценариев — [[Apify]] и [[Firecrawl]].

## Частые вопросы
### Сколько стоит Bright Data?
Оплата зависит от продукта: прокси от $2,50 за гигабайт, API от $0,75–1 за 1 000 записей или запросов. У API есть бесплатные лимиты.

### Работает ли Bright Data в России?
Нет: российские карты не принимаются, а проверка клиента отсекает пользователей из России.

### Bright Data или Apify?
[[Apify]] удобнее для своих сценариев и готовых акторов, Bright Data сильнее в прокси и обходе защит.

### Законно ли парсить сайты через Bright Data?
Сбор публичных данных в большинстве стран законен, но стоит соблюдать условия сайтов и законы о персональных данных. Bright Data требует описать цель сбора при регистрации.
