## Описание

Bruno — это бесплатный API-клиент с открытым кодом для отправки и тестирования HTTP-запросов, который хранит коллекции в обычных файлах прямо в репозитории проекта.

Главное отличие от [[Postman]] — нет облака и обязательного аккаунта: запросы лежат в текстовых файлах формата .bru, поэтому их версионируют в Git и ревьюят как код.

### Возможности
- **Коллекции в Git:** каждый запрос — отдельный файл рядом с кодом проекта.
- **Окружения и переменные** для локальной, тестовой и боевой среды.
- **Скрипты и тесты** на JavaScript до и после запроса.
- **REST, GraphQL и gRPC** в одном приложении.
- **CLI** для запуска коллекций в CI, например в [[GitHub Actions]].

### Кому подходит
Разработчикам и командам, которые хотят держать API-запросы рядом с кодом, не платить за облако и не хранить секреты на чужих серверах.

### Как начать
Скачайте приложение для своей системы, откройте папку проекта и создайте коллекцию. Коллекции из [[Postman]] и [[Insomnia]] импортируются за пару кликов.

### Совет
Секреты храните в файле .env и добавьте его в .gitignore, а в Bruno ссылайтесь на переменные. Так коллекцию можно смело коммитить.

### Ограничения
Совместная работа идёт через Git, без облачной синхронизации в реальном времени. Часть функций, например визуальный редактор тестов, доступна только в платных версиях.

## Вердикт
- Кому подходит: Разработчикам, которые хранят всё в Git и не хотят облачных аккаунтов.
- Кому не подходит: Командам, которым нужна облачная совместная работа и общие рабочие пространства.
- Итог: Лёгкая офлайн-замена Postman с коллекциями в репозитории и бесплатной основой.

## Плюсы

- Импорт из Postman и Insomnia

## Частые вопросы
### Bruno бесплатный?
Да, основная версия бесплатная и с открытым кодом. Платные тарифы добавляют продвинутые функции.

### Работает ли Bruno в России?
Да, приложение скачивается и работает без VPN. Платную лицензию оплачивают зарубежной картой.

### Bruno или Postman?
[[Postman]] удобнее для облачной совместной работы и публичной документации API. Bruno лучше, если коллекции должны жить в Git и не уходить в чужое облако.

### Можно ли запускать коллекции Bruno в CI?
Да, через Bruno CLI: команда прогоняет коллекцию и возвращает результат тестов.
