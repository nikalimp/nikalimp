## Описание

Builder.io — визуальная платформа для разработки, в которой дизайнеры, маркетологи и разработчики собирают интерфейсы и страницы поверх реального кода и компонентов проекта. Состоит из двух продуктов: Code — визуальная AI-среда разработки, и Content — визуальная headless CMS.

Главное отличие — работа с вашим репозиторием и компонентами: правки превращаются в код и pull request, а не живут в закрытом конструкторе.

### Возможности
- **Визуальная AI-среда:** правки интерфейса мышкой и промптом прямо в репозитории.
- **Импорт из [[Figma]]** в код на компонентах вашей дизайн-системы.
- **Headless CMS:** маркетинг собирает страницы из компонентов сайта на [[Next.js]] или [[React]].
- **Подключение GitHub, GitLab и Bitbucket** с pull request на каждую правку.
- **A/B-тесты и персонализация** контента.

### Кому подходит
Продуктовым командам, где дизайнеры и маркетологи хотят менять интерфейс без очереди к разработчикам, и стартапам на React и Next.js.

### Как начать
Создайте пространство, подключите репозиторий и разрешите доступ к компонентам. Попросите AI изменить экран или импортируйте макет из Figma, затем проверьте и смержите pull request.

### Совет
Зарегистрируйте свои компоненты в Builder.io. Без этого AI и редактор генерируют разметку с нуля, и вы теряете смысл дизайн-системы.

### Ограничения
Кредиты на AI быстро заканчиваются, а для простого лендинга платформа избыточна. Для no-code сайтов проще [[Webflow]], для внутренних инструментов — [[Retool]] или [[WeWeb]].

## Частые вопросы
### Builder.io бесплатный?
Да, есть бесплатный план на 60 AI-кредитов в месяц и одного пользователя. Платные тарифы — от $24 в месяц за пользователя.

### Работает ли Builder.io в России?
Сайт работает, но для оплаты нужна зарубежная карта.

### Builder.io или Webflow?
[[Webflow]] — конструктор сайтов со своим хостингом. Builder.io встраивается в ваш код на React или Next.js и подходит, когда у проекта уже есть разработчики.

### Что такое headless CMS в Builder.io?
Это редактор, в котором маркетолог собирает страницы из компонентов сайта, а сайт получает контент через API и рендерит его своим кодом.
