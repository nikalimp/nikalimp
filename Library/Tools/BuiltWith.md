# BuiltWith

[[Инструменты — SEO|SEO]] · Анализ сайтов и конкурентов · Global
Буква: B · Страница на сайте: `/tools/builtwith`

## Описание

BuiltWith — сервис, который определяет, на каких технологиях построен сайт: CMS, конструктор, хостинг, аналитика, рекламные пиксели, платёжные системы, фреймворки и десятки других категорий.

Помимо проверки одного сайта, BuiltWith собирает базы всех сайтов, использующих определённую технологию. Поэтому сервис популярен у продажников B2B: можно найти все магазины на Shopify в стране или все сайты с конкретной CRM.

### Возможности
- **Профиль технологий сайта:** CMS, аналитика, реклама, виджеты, хостинг.
- **История технологий:** что сайт использовал раньше.
- **Списки сайтов** по технологии, стране и трафику.
- **Анализ рынка** — доля технологий в нише.
- **Расширение для браузера.**
- **API** для интеграций.

### Кому подходит
Маркетологам и продажникам B2B — для поиска клиентов по технологиям. Разработчикам и SEO-специалистам — для анализа конкурентов. Веб-студиям — для оценки рынка.

### Как начать
Введите адрес сайта конкурента и посмотрите его стек: аналитика, рекламные системы, чат, CMS. Это подскажет, какими инструментами он пользуется.

### Как использовать в работе
Ищите потенциальных клиентов: например, сайты на устаревшей CMS или без аналитики — им можно предложить редизайн или настройку.

### Где особенно полезен
В B2B-продажах SaaS и услуг: список компаний с нужной технологией — готовая база для аутрича.

### Совет
Проверяйте данные вручную: сервис определяет технологии по признакам в коде и иногда ошибается или показывает устаревшие данные.

### Ограничения
Для российских сайтов база неполная, а платные тарифы дорогие.

### Частый вопрос
**BuiltWith или Wappalyzer?** [[Wappalyzer]] удобнее для быстрой проверки в браузере, BuiltWith — для больших баз и истории. Для анализа трафика используют [[Similarweb]].

## Частые вопросы
### Сколько стоит BuiltWith?
Проверка отдельного сайта бесплатна. Платные тарифы — Basic $295, Pro $495 и Team $995 в месяц; при оплате за год выходит дешевле ($2950, $4950 и $9950).

### Работает ли BuiltWith в России?
Сайт открывается и бесплатная проверка работает. Оплатить тариф российской картой нельзя, нужна зарубежная карта.

### BuiltWith или Wappalyzer — что лучше?
Для быстрой проверки одного сайта удобнее [[Wappalyzer]] с расширением. BuiltWith берут, когда нужны списки сайтов по технологии, история и выгрузки для продаж.

### Как узнать, на чём сделан сайт?
Введите адрес сайта на builtwith.com — сервис покажет CMS, хостинг, аналитику, рекламные пиксели и другие технологии. Данные берутся из кода страницы, поэтому проверьте важное вручную.
