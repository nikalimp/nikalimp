## Описание

Bun — это быстрая среда выполнения JavaScript и TypeScript, которая в одном файле объединяет рантайм, пакетный менеджер, сборщик и тест-раннер. Её разрабатывают как замену Node.js, совместимую с большинством npm-пакетов.

Главное отличие — скорость: установка зависимостей и запуск скриптов в разы быстрее привычного стека. В 2025 году команда Bun присоединилась к Anthropic.

### Возможности
- **Рантайм** с нативной поддержкой TypeScript и JSX без настройки.
- **Пакетный менеджер** bun install, совместимый с package.json.
- **Тест-раннер** bun test с API в стиле Jest.
- **Сборщик** для фронтенда и серверного кода.
- **Встроенные API:** HTTP-сервер, SQLite, работа с файлами и S3.

### Кому подходит
Разработчикам на JavaScript и TypeScript, которые хотят ускорить установку пакетов, тесты и локальную разработку, и тем, кто пишет скрипты и небольшие серверы.

### Как начать
Установите Bun одной командой из документации, затем в существующем проекте замените npm install на bun install. Скрипты запускайте через bun run, тесты — через bun test.

### Совет
Начните с bun install в существующем проекте: это безопасный шаг, который даёт выигрыш сразу. Рантайм в продакшене включайте после прогона тестов.

### Ограничения
Часть нативных модулей Node.js и редких пакетов работает с особенностями. Для фронтенда на [[Next.js]] и [[Vite]] Bun обычно используют как пакетный менеджер. Альтернативный рантайм — [[Deno]].

## Вердикт
- Кому подходит: JavaScript- и TypeScript-разработчикам, которым важна скорость установки пакетов, тестов и запуска скриптов.
- Кому не подходит: Проектам с редкими нативными модулями Node.js, где важна полная совместимость.
- Итог: Быстрый всё-в-одном инструмент для JavaScript, который можно внедрять по частям.

## Плюсы
- Рантайм, пакетный менеджер, сборщик и тесты в одном файле
- TypeScript работает без настройки
- Совместим с npm и package.json
- Бесплатный и с открытым кодом

## Минусы
- Совместимость с Node.js неполная для редких модулей
- Меньше опыта эксплуатации в продакшене, чем у Node.js
- Документация только на английском

## Частые вопросы
### Bun бесплатный?
Да, Bun бесплатный и с открытым исходным кодом, платных версий нет.

### Работает ли Bun в России?
Да, Bun устанавливается и работает без VPN, пакеты из npm загружаются без ограничений.

### Bun или Deno?
Оба поддерживают TypeScript из коробки. Bun делает ставку на совместимость с npm и скорость, [[Deno]] — на безопасность по умолчанию и веб-стандарты.

### Можно ли использовать Bun с Next.js?
Да, чаще всего как пакетный менеджер и для запуска скриптов. Проект на [[Next.js]] работает с bun install без изменений.
