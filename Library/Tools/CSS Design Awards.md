# CSS Design Awards

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Насмотренность и референсы · Global
Буква: C · Страница на сайте: `/tools/css-design-awards`

## Описание

CSS Design Awards — это международная премия и галерея веб-дизайна, где жюри из 200+ дизайнеров и разработчиков оценивает сайты и выбирает «Сайт дня».

В отличие от [[Awwwards]], оценки здесь разбиты на три понятные шкалы — UI, UX и Innovation, а галерея обновляется каждый день.

### Возможности
- **Website of the Day:** ежедневный выбор лучшего сайта.
- **Оценки UI, UX и Innovation** у каждой работы.
- **Сайт месяца и года** — подборки лучших работ за период.
- **Фильтры** по цвету, категории и технологии.
- **Профили студий и жюри** с их работами.

### Кому подходит
Веб-дизайнерам и студиям для насмотренности и поиска свежих приёмов анимации и типографики. Студиям — для статуса и портфолио после награды.

### Как пользоваться
Откройте раздел победителей, отфильтруйте по нужной категории и сохраняйте удачные решения в [[Pinterest]] с пометками, что именно понравилось.

### Совет
Смотрите на оценку UX, а не только на эффектность: сайты с высоким UI и низким UX — хороший пример того, чего не стоит повторять в коммерческом проекте.

### Ограничения
Большинство победителей — промосайты агентств с тяжёлой анимацией. Для референсов обычных лендингов и интерфейсов полезнее [[Land-book]], [[Refero]] и [[Mobbin]].

## Частые вопросы
### CSS Design Awards бесплатный?
Смотреть галерею можно бесплатно. Платно только отправить свой сайт на оценку жюри.

### Работает ли CSS Design Awards в России?
Да, сайт открывается без VPN. Оплатить участие можно только зарубежной картой.

### CSS Design Awards или Awwwards?
[[Awwwards]] известнее и престижнее, CSS Design Awards дешевле для участия и показывает оценки по трём шкалам. Для насмотренности полезно смотреть обе галереи.

### Стоит ли отправлять сайт на конкурс?
Да, если это промосайт с сильной анимацией и дизайном. Обычному корпоративному сайту шансов на награду мало.
