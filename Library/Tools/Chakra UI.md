## Описание

Chakra UI — библиотека готовых React-компонентов с доступностью и темами из коробки: кнопки, формы, модальные окна, меню, таблицы и другие элементы интерфейса. Стили задаются через пропсы и токены дизайн-системы.

Главное отличие — система токенов и рецептов: цвета, отступы и варианты компонентов настраиваются в одной теме, а не переписываются в каждом файле.

### Возможности
- **Десятки компонентов** с поддержкой клавиатуры и экранных читалок.
- **Темы и семантические токены**, светлая и тёмная тема.
- **Рецепты** для вариантов компонентов: размеры, стили, состояния.
- **Поддержка [[Next.js]]** и серверных компонентов React.
- **Chakra UI Pro** — платные блоки и шаблоны страниц.

### Кому подходит
React-разработчикам, которые собирают админки, личные кабинеты и внутренние сервисы и хотят быстро получить аккуратный и доступный интерфейс.

### Как начать
Установите пакет через npm, оберните приложение в провайдер и начните с готовых компонентов из документации. Затем вынесите цвета и шрифты бренда в тему.

### Совет
Сразу настройте семантические токены: «фон», «текст», «акцент». Тогда тёмная тема и ребрендинг сводятся к правке одного файла.

### Ограничения
Стили через пропсы добавляют вес в рантайме и спорят с подходом [[Tailwind CSS]]. Если проект на Tailwind, удобнее [[shadcn ui|shadcn/ui]]; для корпоративных интерфейсов есть [[Ant Design]] и [[Material UI]].

## Вердикт
- Кому подходит: React-разработчикам, которым нужны доступные компоненты с удобной системой тем.
- Кому не подходит: Проектам на Tailwind CSS и тем, кто хочет полный контроль над кодом компонентов.
- Итог: Зрелая бесплатная библиотека React-компонентов с сильной системой токенов.

## Частые вопросы
### Chakra UI бесплатный?
Да, библиотека бесплатная и с открытым кодом. Платные только готовые блоки и шаблоны Chakra UI Pro.

### Работает ли Chakra UI в России?
Да, пакеты устанавливаются из npm без VPN, ограничений для российских разработчиков нет.

### Chakra UI или shadcn/ui?
[[shadcn ui|shadcn/ui]] копирует код компонентов в проект и работает на Tailwind. Chakra UI подключается пакетом и даёт систему тем через токены.

### Подходит ли Chakra UI для дизайн-системы?
Да, токены, рецепты и семантические цвета позволяют описать дизайн-систему бренда в одной теме.
