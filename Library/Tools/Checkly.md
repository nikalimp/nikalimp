## Описание

Checkly — это сервис синтетического мониторинга: он регулярно проверяет API и пользовательские сценарии сайта браузерными тестами на [[Playwright]] и сообщает о сбоях.

Главное отличие — подход «мониторинг как код». Проверки пишут в репозитории на TypeScript или JavaScript, прогоняют в CI и разворачивают вместе с приложением.

### Возможности
- **API-проверки** с проверкой ответа, статуса и времени.
- **Браузерные проверки** на Playwright: вход, корзина, оплата.
- **Проверки из разных регионов** мира по расписанию.
- **Checkly CLI и Terraform** для описания мониторинга в коде.
- **Уведомления и страницы статуса:** Slack, почта, вебхуки, PagerDuty.

### Кому подходит
Командам разработки, которые хотят знать о поломке ключевого сценария раньше пользователей и держат тесты в одном месте с кодом.

### Как начать
Зарегистрируйтесь, создайте API-проверку главной страницы и браузерную проверку формы входа. Затем перенесите проверки в репозиторий через Checkly CLI.

### Совет
Используйте одни и те же тесты Playwright и для CI, и для мониторинга. Так не придётся поддерживать два набора сценариев.

### Ограничения
Для простой проверки доступности сайта Checkly избыточен, хватит [[UptimeRobot]]. Точек проверки в России нет, лимиты бесплатного тарифа небольшие.

## Вердикт
- Кому подходит: Разработчикам, которые проверяют API и сценарии сайта тестами Playwright.
- Кому не подходит: Владельцам простых сайтов, которым нужна только проверка доступности.
- Итог: Сильный мониторинг сценариев как код, с бесплатным стартом и оплатой только из-за рубежа.

## Частые вопросы
### Checkly бесплатный?
Да, есть бесплатный тариф Hobby с ограниченным числом проверок. Его хватает для небольшого проекта.

### Работает ли Checkly в России?
Да, сервис открывается без VPN, но платные тарифы оплачивают зарубежной картой. Точек проверки в России нет.

### Checkly или UptimeRobot?
[[UptimeRobot]] проверяет, открывается ли сайт. Checkly проверяет, работает ли сценарий целиком: вход, форма, оплата.

### Можно ли запускать проверки Checkly в CI?
Да, через Checkly CLI проверки запускают перед деплоем, например в [[GitHub Actions]].
