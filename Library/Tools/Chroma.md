## Описание

Chroma — это векторная база данных с открытым кодом для AI-приложений: она хранит эмбеддинги текстов и находит похожие по смыслу фрагменты для поиска и RAG.

Главное отличие — простота старта. Chroma запускается одной командой в Python или JavaScript, работает прямо в памяти приложения и не требует отдельной инфраструктуры для прототипа.

### Возможности
- **Хранение эмбеддингов** с метаданными и фильтрами.
- **Семантический и гибридный поиск** по смыслу и ключевым словам.
- **Встроенные функции эмбеддингов** для популярных моделей.
- **Режимы работы:** в памяти, на диске, на сервере или в облаке.
- **Интеграции** с [[LangChain]], LlamaIndex и другими фреймворками.

### Кому подходит
Разработчикам, которые собирают чат-бот по документам, поиск по базе знаний или RAG-прототип и хотят начать без лишней настройки.

### Как начать
Установите пакет chromadb, создайте коллекцию, добавьте документы и выполните первый запрос. Для продакшена разверните сервер в Docker или подключите Chroma Cloud.

### Совет
Сразу сохраняйте в метаданных источник и дату документа: фильтры по ним сильно повышают точность ответов RAG.

### Ограничения
На очень больших объёмах и при высокой нагрузке управляемые сервисы вроде [[Pinecone]] или [[Qdrant]] настраивать проще. Облако недоступно для оплаты российской картой.

## Частые вопросы
### Chroma бесплатная?
Да, версия с открытым кодом бесплатна. Платить нужно только за облако Chroma Cloud.

### Работает ли Chroma в России?
Да, открытую версию ставят на российский сервер без VPN. Облако оплачивают зарубежной картой.

### Chroma или Pinecone?
[[Pinecone]] — управляемый облачный сервис для больших нагрузок. Chroma проще для старта и работает на своём сервере.

### Подходит ли Chroma для продакшена?
Да, в серверном режиме или через Chroma Cloud. Для прототипа хватает встроенного режима в памяти.
