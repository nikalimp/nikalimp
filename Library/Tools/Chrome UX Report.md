# Chrome UX Report

[[Инструменты — SEO|SEO]] · Скорость и Core Web Vitals · Global
Буква: C · Страница на сайте: `/tools/chrome-ux-report`

## Описание

Chrome UX Report (CrUX) — это открытый набор данных Google о том, как реальные пользователи Chrome видят скорость сайтов: LCP, INP, CLS и другие метрики Core Web Vitals.

Главное отличие от лабораторных тестов вроде [[Google PageSpeed Insights]] в режиме Lighthouse или [[WebPageTest]]: CrUX показывает полевые данные, собранные у живых посетителей за последние 28 дней. Именно их Google учитывает в оценке качества страниц.

### Возможности
- **Полевые метрики** LCP, INP, CLS, FCP и TTFB по страницам и доменам.
- **Разрез по устройствам** — телефоны, компьютеры, планшеты — и по типу соединения.
- **CrUX API** для автоматических проверок и дашбордов.
- **CrUX History API** с историей метрик по неделям.
- **Набор данных в [[Google BigQuery]]** с ежемесячными выгрузками по странам.

### Кому подходит
SEO-специалистам, фронтенд-разработчикам и владельцам сайтов, которым важно знать, как сайт работает у посетителей, а не на тестовом сервере.

### Как начать
Откройте CrUX Vis или вставьте адрес в PageSpeed Insights: блок «Что видят ваши пользователи» — это и есть CrUX. Для регулярного мониторинга получите API-ключ в Google Cloud и подключите API к таблице или [[Looker Studio]].

### Совет
Сравнивайте CrUX с отчётом «Основные интернет-показатели» в [[Google Search Console]]: он строится на тех же данных, но группирует похожие страницы.

### Ограничения
Данные есть только у страниц и доменов с достаточным трафиком из Chrome. Пользователи Яндекс Браузера и Safari в выборку не попадают, а изменения видны с задержкой до 28 дней.

## Карточка
- Россия: работает
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, API

## Вердикт
- Кому подходит: SEO-специалистам и разработчикам, которые следят за Core Web Vitals по реальным посетителям.
- Кому не подходит: Небольшим сайтам с низким трафиком: данных по ним в CrUX просто не будет.
- Итог: Бесплатный эталон полевых данных о скорости, на который ориентируется сам Google.

## Плюсы
- Полностью бесплатный, включая API
- Реальные данные посетителей, а не синтетический тест
- Те же метрики, что учитывает Google в поиске
- История по неделям через History API

## Минусы
- Нет данных по сайтам с маленьким трафиком
- Учитывает только Chrome, без Яндекс Браузера и Safari
- Результат правок виден не сразу, окно — 28 дней

## Частые вопросы
### Chrome UX Report бесплатный?
Да. API, CrUX Vis и данные в PageSpeed Insights бесплатные. Платить приходится только за большие SQL-запросы в BigQuery сверх бесплатной квоты.

### Работает ли Chrome UX Report в России?
Да, API и PageSpeed Insights открываются без VPN. Учтите, что в выборку попадают только пользователи Chrome, поэтому для российской аудитории картина неполная.

### Chrome UX Report или PageSpeed Insights?
Это не конкуренты: [[Google PageSpeed Insights]] показывает данные CrUX в верхнем блоке и добавляет к ним лабораторный тест. Для разовой проверки хватит PSI, для мониторинга удобнее CrUX API.

### Почему по моему сайту нет данных CrUX?
У страницы или домена слишком мало посещений из Chrome за 28 дней. В этом случае ориентируйтесь на лабораторные тесты, например [[GTmetrix]] или [[WebPageTest]].

## Цена

Бесплатно. Данные доступны через CrUX API, CrUX Vis и PageSpeed Insights; запросы к BigQuery укладываются в бесплатную квоту Google Cloud, сверх неё оплачиваются по тарифам BigQuery.


## Доступность из России

Сайт документации, API и PageSpeed Insights открываются из России без VPN. Для платного использования BigQuery нужна зарубежная карта; российского аналога с полевыми данными Chrome нет.
