# Claude Agent SDK

## Описание

Claude Agent SDK — это библиотека Anthropic для Python и TypeScript, на которой собирают собственных AI-агентов с тем же устройством, что у Claude Code: инструменты, файлы, команды и долгие задачи.

Главное отличие от обычного вызова [[Anthropic API]] — готовый агентный цикл. SDK сам управляет вызовами инструментов, правами, контекстом и подагентами, а вы описываете задачу и подключаете нужные инструменты.

### Возможности
- **Встроенные инструменты:** чтение и правка файлов, команды в терминале, веб-поиск.
- **Подключение MCP-серверов** и собственных инструментов.
- **Подагенты** для параллельных и узких задач.
- **Права и хуки:** контроль, что агенту можно делать без подтверждения.
- **Управление контекстом:** автоматическое сжатие истории в долгих сессиях.

### Кому подходит
Разработчикам, которые строят агентов для кода, поддержки, исследований и автоматизации процессов на моделях [[Claude (инструмент)|Claude]].

### Как начать
Установите пакет для Python или TypeScript, получите ключ API в консоли Anthropic и запустите пример агента из документации. Затем ограничьте набор инструментов под свою задачу.

### Совет
Давайте агенту минимум прав и включайте подтверждение для опасных действий: записи файлов, команд в терминале, отправки данных наружу.

### Ограничения
Работает только с моделями Claude. Из России нужен VPN или зарубежный сервер и зарубежная карта. Долгие агентные задачи расходуют много токенов.

- Кому подходит: Разработчикам агентов на моделях Claude, которым нужен готовый агентный цикл.
- Кому не подходит: Тем, кто хочет свободно переключаться между моделями разных компаний.
- Итог: Самый короткий путь к агенту уровня Claude Code в собственном продукте.

## Частые вопросы
### Claude Agent SDK бесплатный?
Библиотека бесплатная, но работа агента оплачивается: вы платите за токены моделей Claude через API.

### Работает ли Claude Agent SDK в России?
Только через VPN или зарубежный сервер: Anthropic не обслуживает Россию. Для оплаты API нужна зарубежная карта.

### Claude Agent SDK или OpenAI Agents SDK?
[[OpenAI Agents SDK]] привязан к моделям OpenAI, Claude Agent SDK — к Claude. Если нужны разные модели в одном коде, посмотрите [[Vercel AI SDK]] или [[LangChain]].

### Чем Claude Agent SDK отличается от Claude Code?
Claude Code — готовый агент для разработчика. Agent SDK — его основа в виде библиотеки, на которой собирают своих агентов.

## Доступность из России

Anthropic не обслуживает пользователей из России: нужен VPN или сервер за рубежом и зарубежная карта для оплаты API. Российские альтернативы для агентов — модели GigaChat и YandexGPT со своими SDK.
