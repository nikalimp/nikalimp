## Описание

CleanShot X — это приложение для скриншотов и записи экрана на macOS: снимок, аннотации, запись видео и GIF, распознавание текста и загрузка в облако в одном инструменте.

Главное отличие от стандартных скриншотов macOS — скорость работы со снимком: после захвата появляется плавающее превью, из которого картинку можно сразу отредактировать, перетащить в чат или загрузить и получить ссылку.

### Возможности
- **Скриншоты** области, окна, экрана и с прокруткой длинных страниц.
- **Аннотации:** стрелки, подписи, размытие, нумерованные шаги, выделение.
- **Запись экрана** в MP4 или GIF с кликами, нажатиями клавиш и камерой.
- **OCR** — копирование текста с любой части экрана.
- **CleanShot Cloud** — ссылка на снимок или видео сразу после захвата.
- **Скрытие иконок рабочего стола** и красивый фон для снимков.

### Кому подходит
Дизайнерам, разработчикам, менеджерам и техподдержке на Mac, которые каждый день делают скриншоты для задач, баг-репортов и инструкций.

### Как начать
Купите лицензию, назначьте в настройках привычные сочетания клавиш вместо системных Cmd+Shift+4 и включите автокопирование в буфер.

### Совет
Для коротких демо интерфейса записывайте GIF с подсветкой кликов: в задаче или чате такой ролик понятнее длинного текста. Для красивых промо-роликов лучше подходит [[Screen Studio]].

### Ограничения
Работает только на macOS. Видеоредактор простой: для монтажа понадобится [[DaVinci Resolve]] или [[Descript]].

## Частые вопросы
### Сколько стоит CleanShot X?
Лицензия стоит $35 разово и включает год обновлений. После этого приложение продолжает работать, а обновления можно продлить за $19 в год.

### Работает ли CleanShot X в России?
Само приложение работает без ограничений и без VPN. Оплатить лицензию российской картой нельзя.

### CleanShot X или Screen Studio?
CleanShot X — для ежедневных скриншотов и быстрых записей. [[Screen Studio]] делает отполированные промо-видео с автоматическим зумом и подходит для демо продукта.

### Есть ли CleanShot X для Windows?
Нет, приложение есть только для macOS. На Windows похожие задачи решают ShareX и встроенная «Ножницы».
