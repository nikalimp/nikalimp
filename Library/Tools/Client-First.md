# Client-First

Буква: C · Страница на сайте: `/tools/client-first`

## Описание

Client-First — это бесплатная система стилей и правил именования классов для [[Webflow]] от студии Finsweet, по которой собирают масштабируемые сайты, понятные любому разработчику.

Главное отличие — строгие и понятные правила. Классы называются так, что по имени ясно назначение элемента, а сайт легко передать клиенту или другой команде.

### Возможности
- **Правила именования классов:** утилитарные классы и классы компонентов с подчёркиванием.
- **Стартовый проект** для клонирования с готовой структурой и стилями.
- **Структура страницы:** page-wrapper, section, padding-global, container.
- **Размеры в rem** для доступности и масштабирования.
- **Совместимость** с [[Finsweet Attributes]] и [[Relume Library]].

### Кому подходит
Webflow-разработчикам и студиям, которые делают сайты для клиентов и хотят, чтобы проект через полгода могла поддерживать другая команда.

### Как начать
Клонируйте стартовый проект Client-First, прочитайте документацию по именованию и соберите первую страницу из секций на базовой структуре.

### Совет
Не создавайте новый класс на каждый случай. Сначала проверьте, решит ли задачу утилитарный класс, иначе через месяц в проекте будут сотни дублей.

### Ограничения
Система требует дисциплины и времени на изучение. Для одностраничного лендинга она может быть избыточной, а вне Webflow её правила применить сложнее.

## Частые вопросы
### Client-First бесплатный?
Да, система, документация и стартовый проект бесплатные. Платить нужно только за Webflow.

### Работает ли Client-First в России?
Да, документация и стартовый проект доступны без VPN. Сложности только с оплатой самого Webflow.

### Client-First или своя система классов?
Своя система подходит соло-разработчику. Client-First выигрывает, когда над сайтом работает команда или проект передают клиенту: правила общие и хорошо описаны.

### Можно ли использовать Client-First с Relume?
Да, [[Relume Library]] выдаёт компоненты по правилам Client-First, их можно вставлять в проект без переименования классов.
