## Описание

Cline — это бесплатный AI-агент для программирования с открытым кодом, который работает внутри VS Code и других редакторов: читает проект, пишет и правит файлы, запускает команды в терминале.

Главное отличие — модель на ваш выбор и прозрачная оплата. Cline не продаёт подписку: вы подключаете любой API или локальную модель и платите только за токены.

### Возможности
- **Режимы Plan и Act:** сначала агент составляет план, потом выполняет его по вашему подтверждению.
- **Правка файлов и терминал:** каждое изменение показывается диффом до применения.
- **Любые модели:** Claude, GPT, Gemini, [[DeepSeek]], модели через [[OpenRouter]] и локальные через [[LM Studio]].
- **MCP-серверы:** подключение внешних инструментов и данных.
- **Чекпоинты:** откат проекта к любому шагу агента.
- **Браузер:** агент открывает приложение и проверяет результат.

### Кому подходит
Разработчикам, которые хотят агента уровня [[Cursor]], но без подписки и с контролем над моделью и расходами.

### Как начать
Установите Cline из маркетплейса расширений [[VS Code]], добавьте API-ключ провайдера и опишите задачу в чате. Начните с режима Plan.

### Совет
Создайте в корне проекта файл с правилами: стек, стиль кода, запреты. Агент читает его при каждой задаче, и правок становится меньше.

### Ограничения
На больших задачах токены дорожают быстро — следите за счётчиком стоимости. Качество целиком зависит от выбранной модели.

## Частые вопросы
### Cline бесплатный?
Да, само расширение бесплатное и с открытым кодом. Платить нужно за запросы к моделям — напрямую провайдеру или через Cline по себестоимости.

### Работает ли Cline в России?
Расширение работает. API Anthropic и OpenAI из России недоступны, поэтому используют [[DeepSeek]], [[OpenRouter]] или локальные модели.

### Cline или Cursor?
[[Cursor]] — отдельный редактор с подпиской и встроенными лимитами. Cline встраивается в привычный VS Code и не ограничивает выбор модели, но счёт за токены зависит от вас.

### Чем Cline отличается от Roo Code?
Roo Code — форк Cline с дополнительными режимами и настройками. Базовая механика у них общая.

## Цена

Расширение с открытым кодом бесплатно для разработчиков. Платите только за запросы к моделям: своим API-ключом у провайдера или через встроенный провайдер Cline по себестоимости; для компаний есть Enterprise по запросу.


## Доступность из России

Расширение ставится и работает из России. Ограничения зависят от модели: API Anthropic и OpenAI из России недоступны, а DeepSeek, OpenRouter и локальные модели через LM Studio работают.
