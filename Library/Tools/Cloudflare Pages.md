# Cloudflare Pages

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · Хостинг и деплой · Global
Буква: C · Страница на сайте: `/tools/cloudflare-pages`

## Описание

Cloudflare Pages — бесплатный хостинг статических сайтов и фронтенда на сети Cloudflare. Сайт собирается из Git-репозитория и раздаётся через CDN по всему миру.

Главное отличие — нет лимита на трафик даже на бесплатном плане, а функции на Workers добавляют серверную логику.

### Возможности
- **Деплой из Git:** каждый пуш в [[GitHub]] или [[GitLab]] запускает сборку.
- **Превью-ссылки** на каждую ветку и pull request.
- **Фреймворки:** [[Next.js]], [[Vite]], Astro, Hugo и чистый HTML.
- **Pages Functions** для форм, API и редиректов без отдельного сервера.
- **Свои домены** и бесплатный SSL, до 100 доменов на проект.

### Кому подходит
Фрилансерам и разработчикам лендингов, документации и портфолио с аудиторией за пределами России.

### Как начать
Создайте аккаунт [[Cloudflare]], выберите Workers & Pages, подключите репозиторий и укажите команду сборки. Через минуту сайт доступен на адресе pages.dev.

### Совет
Перед запуском проверьте, как сайт открывается из России через несколько провайдеров. Если основная аудитория российская, разместите сайт у российского хостера.

### Ограничения
Сборка дольше 20 минут прерывается, в проекте до 20 000 файлов на бесплатном плане. Cloudflare переносит развитие в Workers, новые функции появляются там раньше. Альтернативы — [[Vercel]] и [[GitHub Pages]].

## Вердикт
- Кому подходит: Тем, кто делает статические сайты и фронтенд для зарубежной аудитории и хочет бесплатный хостинг без лимита трафика.
- Кому не подходит: Владельцам сайтов, где основная аудитория в России: трафик Cloudflare там замедляют.
- Итог: Один из самых щедрых бесплатных хостингов для статики, но для российской аудитории рискованный.

## Частые вопросы
### Cloudflare Pages бесплатный?
Да, бесплатного плана хватает для большинства лендингов и портфолио: 500 сборок в месяц и трафик без ограничений.

### Работает ли Cloudflare Pages в России?
Сервисом можно пользоваться, но с 2025 года российские провайдеры замедляют трафик Cloudflare. Посетители из России могут видеть сайт не полностью или с задержкой.

### Cloudflare Pages или Vercel?
[[Vercel]] удобнее для [[Next.js]] с серверным рендерингом, Cloudflare Pages выгоднее по трафику на бесплатном плане.

### Можно ли подключить свой домен?
Да, домен добавляется в настройках проекта. Проще всего, если DNS домена уже обслуживает [[Cloudflare]].
