# Cloudflare R2

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · Хранение файлов и облака · Global
Буква: C · Страница на сайте: `/tools/cloudflare-r2`

## Описание

Cloudflare R2 — это объектное хранилище файлов, совместимое с API [[Amazon S3]], без платы за исходящий трафик. В нём хранят картинки, видео, бэкапы, сборки и файлы пользователей.

Главное отличие от S3 — нулевая стоимость отдачи данных: вы платите только за объём и операции, а не за каждый скачанный гигабайт. Для сайтов с тяжёлыми медиа это заметная экономия.

### Возможности
- **S3-совместимый API**: работают привычные SDK, rclone и Cyberduck.
- **Бесплатный исходящий трафик** при любом объёме.
- **Публичный доступ** через свой домен с кэшем Cloudflare.
- **Связка с [[Cloudflare Workers]]** для обработки файлов на лету.
- **Класс Infrequent Access** для редко используемых данных за $0,01 за ГБ.
- **Event notifications** и миграция данных из других S3-хранилищ.

### Кому подходит
Разработчикам и небольшим командам, которые раздают много файлов международной аудитории и хотят предсказуемый счёт.

### Как начать
Создайте бакет в панели Cloudflare, выпустите API-токен и подключите его как S3 с эндпоинтом вашего аккаунта. Для публичных файлов привяжите поддомен.

### Совет
Держите медиа сайта в R2 и отдавайте через свой домен: кэш Cloudflare снимет нагрузку, а счёт за трафик останется нулевым.

### Ограничения
С 2025 года в России Cloudflare работает с замедлением, крупные файлы могут не загружаться у посетителей. Для российской аудитории выбирайте [[Yandex Object Storage]] или [[Selectel S3]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, API
- Проверено: 2026-11-09

## Вердикт
- Кому подходит: Проектам с международной аудиторией и большим объёмом отдаваемых файлов.
- Кому не подходит: Сайтам для посетителей из России и проектам с требованиями 152-ФЗ.
- Итог: Самое выгодное S3-хранилище для раздачи файлов, если аудитория не в России.

## Плюсы
- Исходящий трафик бесплатный
- Щедрый бесплатный лимит 10 ГБ
- Совместимость с API S3
- Связка с Workers и CDN Cloudflare

## Минусы
- Замедление Cloudflare в России с 2025 года
- Оплата только зарубежной картой
- Меньше функций, чем у S3, например нет полноценных классов хранения уровня Glacier

## Частые вопросы
### Cloudflare R2 бесплатный?
Да, до 10 ГБ хранения и нескольких миллионов операций в месяц. Сверх лимита платите за объём и операции, исходящий трафик всегда бесплатный.

### Работает ли Cloudflare R2 в России?
Сервис доступен, но российские провайдеры с июня 2025 года замедляют Cloudflare, и тяжёлые файлы у посетителей из России могут не загружаться. Оплата — только зарубежной картой.

### Cloudflare R2 или Amazon S3?
R2 выгоднее, когда файлы много скачивают: у него нет платы за трафик. [[Amazon S3]] богаче по функциям и классам хранения, но счёт за отдачу данных выше.

### Чем заменить R2 для российской аудитории?
[[Yandex Object Storage]] и [[Selectel S3]] совместимы с API S3, принимают российские карты и хранят данные в России.
