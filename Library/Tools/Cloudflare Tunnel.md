## Описание

Cloudflare Tunnel — это способ открыть доступ к локальному серверу или внутреннему сервису из интернета без белого IP и проброса портов. Программа cloudflared на вашей машине сама устанавливает исходящее соединение с Cloudflare.

Главное отличие от [[ngrok]] — постоянные адреса на вашем домене бесплатно и защита через Cloudflare Access: можно пустить к сервису только сотрудников с почтой компании.

### Возможности
- **Публикация локального сервера** на своём домене с HTTPS.
- **Быстрые туннели** trycloudflare.com без аккаунта и домена.
- **Доступ по SSH, RDP и к приватным сетям** без открытия портов.
- **Cloudflare Access** — вход по почте, Google или SSO перед сервисом.
- **Защита от DDoS** и скрытие реального IP сервера.

### Кому подходит
Разработчикам, которые показывают локальную сборку клиенту, тестируют вебхуки или держат домашний сервер. Командам — для безопасного доступа к внутренним панелям.

### Как начать
Установите cloudflared через [[Homebrew]] или пакетный менеджер и выполните cloudflared tunnel --url http://localhost:3000: вы сразу получите временный адрес. Для постоянного туннеля добавьте домен в Cloudflare и создайте туннель в панели Zero Trust.

### Совет
Закрывайте туннели к админкам и staging-окружениям через Cloudflare Access: даже если адрес утечёт, без входа по почте никто не попадёт внутрь.

### Ограничения
Для постоянных адресов домен должен быть на DNS Cloudflare. В России Cloudflare работает с замедлением, поэтому для показа клиентам из РФ туннель может грузиться медленно.

## Частые вопросы
### Cloudflare Tunnel бесплатный?
Да, туннели бесплатные и не ограничены по трафику для обычных сайтов. Платные тарифы Zero Trust нужны только командам с расширенными требованиями.

### Работает ли Cloudflare Tunnel в России?
Да, регистрация и туннели работают. Но с 2025 года российские провайдеры замедляют Cloudflare, и у посетителей из России сайт через туннель может открываться медленно.

### Cloudflare Tunnel или ngrok?
[[ngrok]] быстрее настроить и удобнее для разовой отладки вебхуков. Cloudflare Tunnel выигрывает, когда нужен постоянный адрес на своём домене бесплатно.

### Нужен ли домен для Cloudflare Tunnel?
Для быстрых туннелей на trycloudflare.com — нет. Для постоянного адреса нужен домен, подключённый к DNS Cloudflare.
