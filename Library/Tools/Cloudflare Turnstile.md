# Cloudflare Turnstile

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · CDN, безопасность и SSL · Global
Буква: C · Страница на сайте: `/tools/cloudflare-turnstile`

## Описание

Cloudflare Turnstile — это бесплатная замена капче от [[Cloudflare]], которая проверяет, что форму отправляет человек, без картинок со светофорами и почти без действий со стороны посетителя.

Главное отличие от [[reCAPTCHA]] — приватность и удобство. Turnstile не следит за пользователем ради рекламы, а проверку проходит в фоне за счёт браузерных тестов.

### Возможности
- **Невидимая проверка** или флажок без головоломок.
- **Работа на любом сайте,** даже если он не подключён к Cloudflare.
- **Простая замена reCAPTCHA:** похожий API и миграция за несколько строк.
- **Аналитика** прохождения проверок в панели Cloudflare.
- **Плагины** для WordPress, популярных фреймворков и конструкторов.

### Кому подходит
Разработчикам и владельцам сайтов с зарубежной аудиторией, которые защищают формы регистрации, входа и заявок от спама.

### Как начать
Создайте виджет в панели Cloudflare, получите ключи, вставьте скрипт и элемент виджета в форму. На сервере проверьте токен через API.

### Совет
Всегда проверяйте токен на сервере. Проверка только в браузере не защищает: бот может отправить форму напрямую.

### Ограничения
В России сервисы Cloudflare замедляются, и проверка может не загрузиться — это прямые потери заявок. Для сайта на российскую аудиторию надёжнее Яндекс SmartCaptcha.

## Вердикт
- Кому подходит: Сайтам с зарубежной аудиторией, которым нужна бесплатная и незаметная защита форм.
- Кому не подходит: Сайтам на российскую аудиторию: из-за замедления Cloudflare часть посетителей не пройдёт проверку.
- Итог: Лучшая бесплатная замена reCAPTCHA для международных сайтов, но рискованная для Рунета.

## Частые вопросы
### Cloudflare Turnstile бесплатный?
Да, Turnstile бесплатен для любых сайтов, без лимита на число проверок.

### Работает ли Cloudflare Turnstile в России?
Подключить его можно, но российские провайдеры замедляют Cloudflare, и у части посетителей проверка не загружается.

### Turnstile или Яндекс SmartCaptcha?
Для зарубежной аудитории удобнее Turnstile. Для российской — [[Яндекс SmartCaptcha]], которая стабильно работает в России. Ещё одна альтернатива — [[hCaptcha]].

### Нужно ли подключать сайт к Cloudflare для Turnstile?
Нет, Turnstile работает на любом хостинге: достаточно аккаунта Cloudflare и ключей виджета.
