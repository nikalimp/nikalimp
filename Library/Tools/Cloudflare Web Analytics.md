# Cloudflare Web Analytics

[[Инструменты — Маркетинг и аналитика|Маркетинг и аналитика]] · Веб-аналитика · Global
Буква: C · Страница на сайте: `/tools/cloudflare-web-analytics`

## Описание

Cloudflare Web Analytics — это бесплатная веб-аналитика без cookies: она показывает посещаемость, популярные страницы, источники трафика и скорость загрузки у реальных посетителей.

Главное отличие от [[Google Analytics 4]] — приватность и простота. Сервис не использует cookies и не собирает отпечатки браузера, поэтому баннер согласия для него обычно не нужен, а отчёт помещается на одном экране.

### Возможности
- **Посещения и просмотры** по страницам, странам, устройствам и источникам.
- **Core Web Vitals** реальных посетителей: LCP, INP, CLS.
- **Два способа установки**: JS-маячок или данные с серверов Cloudflare для проксированных сайтов.
- **Фильтры и зум по времени** для разбора всплесков трафика.
- **Без cookies и fingerprinting**.

### Кому подходит
Владельцам блогов, лендингов и портфолио, которым нужна простая статистика без тяжёлых счётчиков. Разработчикам — как бесплатный мониторинг скорости.

### Как начать
В панели Cloudflare откройте раздел Web Analytics, добавьте сайт и вставьте выданный скрипт перед закрывающим тегом body. Для сайтов на [[Cloudflare Pages]] аналитика включается одной кнопкой.

### Совет
Используйте его как второй счётчик рядом с [[Яндекс Метрика]]: Метрика даёт Вебвизор и цели, а Cloudflare — чистые данные о скорости без cookies.

### Ограничения
Нет целей, воронок, сегментов и данных о пользователях. Для аудитории из России данные неполные из-за замедления Cloudflare; для продуктовой аналитики выбирайте [[Plausible]] или [[Umami]].

## Вердикт
- Кому подходит: Небольшим сайтам и блогам, которым нужна простая статистика без cookies.
- Кому не подходит: Маркетологам, которым нужны цели, воронки и сквозная аналитика.
- Итог: Бесплатная и лёгкая аналитика с данными о скорости, но слишком простая для маркетинга.

## Частые вопросы
### Cloudflare Web Analytics бесплатный?
Да, сервис полностью бесплатный и не требует платного тарифа Cloudflare или переноса DNS.

### Работает ли Cloudflare Web Analytics в России?
Панель работает, но из-за замедления Cloudflare у части посетителей из России скрипт может не загрузиться. Для российского трафика ставьте рядом [[Яндекс Метрика]].

### Cloudflare Web Analytics или Plausible?
[[Plausible]] тоже работает без cookies, но умеет цели, события и UTM-отчёты и стоит денег. Cloudflare бесплатный и проще, но без целей.

### Нужен ли баннер cookies для Cloudflare Web Analytics?
Сервис не ставит cookies и не собирает отпечатки, поэтому для него самого баннер обычно не нужен. Если на сайте есть другие счётчики, требования определяют они.

## Доступность из России

Регистрация и панель работают без зарубежной карты. С 2025 года российские провайдеры замедляют Cloudflare, поэтому часть визитов из России может не учитываться; для российской аудитории основной счётчик — Яндекс Метрика.
