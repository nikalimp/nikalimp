## Описание

Cloudflare Workers — это бессерверная платформа для запуска JavaScript, TypeScript, Python и WebAssembly на сотнях дата-центров Cloudflare по всему миру. Код выполняется рядом с пользователем, без серверов и холодного старта.

Главное отличие от [[Vercel]] и AWS Lambda — модель изолятов V8: функции стартуют за миллисекунды, а бесплатного лимита хватает для большинства небольших проектов.

### Возможности
- **Функции на краю сети** без холодного старта.
- **Хранилища:** KV, D1 (SQLite), Durable Objects, очереди и [[Cloudflare R2]].
- **Workers AI** — запуск открытых нейросетей рядом с кодом.
- **Полноценные сайты**: Next.js, Astro, Remix и другие фреймворки.
- **Cron-триггеры** для задач по расписанию.

### Кому подходит
Разработчикам API, прокси, вебхуков, Telegram-ботов и лёгких сайтов, которым нужна глобальная скорость без администрирования серверов.

### Как начать
Установите CLI Wrangler через npm, выполните npm create cloudflare и задеплойте шаблон командой wrangler deploy. Через минуту код будет доступен на адресе workers.dev.

### Совет
Используйте Workers как прослойку перед внешними API: так ключи не попадут в браузер, а ответы можно кэшировать и снижать расходы.

### Ограничения
Это не Node.js: часть библиотек не работает, а время CPU на бесплатном плане ограничено 10 мс на запрос. В России сервис работает с замедлением, для аудитории из РФ выбирайте [[Yandex Cloud]] или [[Timeweb Cloud]].

## Частые вопросы
### Cloudflare Workers бесплатный?
Да, бесплатный план даёт 100 000 запросов в сутки. Платный стоит от $5 в месяц и снимает основные ограничения.

### Работает ли Cloudflare Workers в России?
Аккаунт и бесплатный план работают. Но российские провайдеры с 2025 года замедляют Cloudflare, а оплатить платный план можно только зарубежной картой.

### Cloudflare Workers или Vercel?
[[Vercel]] удобнее для проектов на Next.js с превью каждой ветки. Workers дешевле на больших объёмах и быстрее стартует, но требует учитывать ограничения среды.

### Можно ли запустить Telegram-бота на Cloudflare Workers?
Да, бот на вебхуках хорошо подходит для Workers. Учтите, что из-за замедления Cloudflare в России ответы могут приходить с задержкой.
