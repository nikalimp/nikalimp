## Описание

CodePen — это онлайн-редактор и сообщество фронтенд-разработчиков, где HTML, CSS и JavaScript пишут в браузере и сразу видят результат. Отдельный пример на CodePen называют «пеном».

Главное отличие от [[CodeSandbox]] и [[StackBlitz]] — фокус на визуальных экспериментах и сообществе: здесь публикуют анимации, эффекты и компоненты, а лучшие работы попадают в подборки и получают тысячи просмотров.

### Возможности
- **Редактор HTML, CSS и JS** с мгновенным превью.
- **Препроцессоры:** Sass, Less, TypeScript, Pug, Markdown.
- **Подключение библиотек** из npm и CDN в пару кликов.
- **Встраивание** работ в статьи и документацию.
- **Коллекции и подборки** лучших работ сообщества.
- **PRO:** приватные пены, загрузка файлов, Collab Mode и Professor Mode.

### Кому подходит
Фронтенд-разработчикам и веб-дизайнерам, которые прототипируют эффекты, собирают портфолио и ищут идеи. Преподавателям — для живых демонстраций.

### Как начать
Нажмите Create → Pen, напишите разметку и стили, а нужную библиотеку подключите в настройках JS. Сохраните работу — у неё появится постоянная ссылка.

### Совет
Перед тем как писать анимацию с нуля, поищите на CodePen готовый пример по запросу вроде «GSAP scroll» или «CSS marquee»: почти всегда найдётся рабочая основа, которую можно разобрать.

### Ограничения
CodePen не подходит для многостраничных проектов с бэкендом. В бесплатном плане все работы публичные, а для приложений целиком удобнее [[StackBlitz]] или [[CodeSandbox]].

## Частые вопросы
### CodePen бесплатный?
Да, создавать и публиковать работы можно бесплатно и без ограничений по количеству. PRO нужен для приватности, загрузки файлов и совместной работы.

### Работает ли CodePen в России?
Да, сайт работает без VPN. Для оплаты PRO нужна зарубежная карта.

### CodePen или JSFiddle?
[[JSFiddle]] проще и подходит для быстрых тестов кода. На CodePen больше сообщество, удобнее встраивание и есть подборки работ для вдохновения.

### Можно ли использовать код с CodePen в коммерческом проекте?
Публичные пены по умолчанию распространяются по лицензии MIT, если автор не указал другую. Перед использованием проверьте лицензию в описании работы.
