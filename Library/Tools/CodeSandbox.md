## Описание

CodeSandbox — это облачная среда разработки в браузере: можно открыть проект на React, Vue, Next.js или Node.js, запустить его и поделиться ссылкой без установки чего-либо на компьютер.

Главное отличие от [[CodePen]] — полноценные проекты: в CodeSandbox работают npm-зависимости, бэкенд, терминал и импорт репозиториев с [[GitHub]]. С декабря 2024 года сервис принадлежит компании Together AI и развивает SDK для запуска кода от AI-агентов.

### Возможности
- **Шаблоны** React, Vue, Svelte, Next.js, Node.js и других стеков.
- **Облачные виртуальные машины** с терминалом и Docker.
- **Импорт репозиториев** GitHub и работа с ветками.
- **Совместное редактирование** в реальном времени.
- **SDK** для запуска изолированных песочниц из своего кода.

### Кому подходит
Разработчикам для демо, воспроизведения багов и code review, преподавателям и авторам библиотек. Командам AI-продуктов — для безопасного запуска сгенерированного кода.

### Как начать
Откройте codesandbox.io, выберите шаблон, например React + Vite, и начните писать код. Чтобы показать коллеге, скопируйте ссылку на песочницу.

### Совет
Когда сообщаете о баге в открытой библиотеке, прикладывайте минимальный пример в CodeSandbox: мейнтейнеры отвечают на такие задачи заметно быстрее.

### Ограничения
Облачные машины на бесплатном плане медленнее локальной сборки. Для повседневной работы удобнее [[VS Code]] на своём компьютере, а для быстрых фронтенд-демо — [[StackBlitz]].

## Частые вопросы
### CodeSandbox бесплатный?
Да, публичные песочницы бесплатные. Pro за $12 в месяц нужен для приватных проектов и более мощных машин.

### Работает ли CodeSandbox в России?
Да, сайт и бесплатный план работают без VPN. Оплатить Pro можно только зарубежной картой.

### CodeSandbox или StackBlitz?
[[StackBlitz]] запускает Node.js прямо в браузере и стартует быстрее. CodeSandbox использует облачные машины, поэтому поддерживает больше стеков, включая Docker и бэкенды на других языках.

### Кому принадлежит CodeSandbox?
С декабря 2024 года CodeSandbox входит в Together AI. Сервис продолжает работать, а команда развивает SDK песочниц для AI-агентов.
