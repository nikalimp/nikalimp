## Описание

Cohere — канадская платформа языковых моделей для бизнеса: генерация текста (семейство Command), эмбеддинги (Embed) и переранжирование результатов поиска (Rerank) через API.

Главное отличие — фокус на корпоративном поиске и RAG, а не на чат-боте для всех. Rerank и Embed часто берут в связке с чужой LLM, чтобы точнее находить нужные документы.

### Возможности
- **Command A и Command R** — модели для ответов по документам, вызова инструментов и агентов, с поддержкой многих языков, включая русский.
- **Embed** — векторные представления текста и изображений для семантического поиска.
- **Rerank** — пересортировка найденных фрагментов по смыслу запроса, поднимает точность RAG.
- **Цитирование источников** — модель указывает, из какого фрагмента взят ответ.
- **Развёртывание** — облако Cohere, AWS, Azure, Oracle или собственная инфраструктура заказчика.

### Кому подходит
Разработчикам корпоративного поиска, баз знаний и ассистентов по документам. Командам, которым нужен качественный Rerank поверх уже готового стека.

### Как начать
Зарегистрируйтесь, получите пробный ключ и попробуйте Rerank на своих данных в Playground. Для продакшена подключите оплату и смените ключ на боевой.

### Совет
Не меняйте всю LLM ради Cohere. Добавьте Rerank между векторным поиском и генерацией — это дешёвый способ поднять качество ответов в существующем RAG.

### Ограничения
По общим задачам Command уступает топовым моделям [[OpenAI API]] и [[Anthropic API]]. Из России нужен обход блокировок, что неудобно для продакшена. Для локального запуска открытых моделей удобнее [[Hugging Face]].

## Карточка
- Россия: VPN и зарубежная карта
- Русский язык: нет
- Бесплатный план: пробный период
- Платформы: Веб, API

## Вердикт
- Кому подходит: Разработчикам RAG и корпоративного поиска, которым нужны сильные Embed и Rerank.
- Кому не подходит: Тем, кто ищет универсальный чат-бот или сервис с оплатой российской картой.
- Итог: Профильная платформа для поиска по документам, ценная в первую очередь моделями Rerank и Embed.

## Плюсы
- Rerank заметно повышает точность поиска в RAG
- Многоязычные Embed-модели, включая русский
- Модели доступны в AWS, Azure и для установки у себя
- Бесплатный ключ для тестов без привязки карты

## Минусы
- Нет официальной работы с Россией
- Command слабее лидеров рынка в общих задачах
- Пробный ключ нельзя использовать в коммерческом продукте

## Частые вопросы
### Cohere бесплатный?
Для тестов да: пробный ключ бесплатный, но с лимитами и запретом на коммерческое использование. В продакшене оплата за токены.

### Работает ли Cohere в России?
Официально нет: нужен VPN и зарубежная карта. Без ограничений работают российские [[GigaChat]] и [[Yandex AI Studio]].

### Cohere или OpenAI API?
Для генерации текста и агентов сильнее [[OpenAI API]]. Cohere выбирают за Rerank и Embed, их можно использовать вместе с любой другой моделью.

### Зачем нужен Rerank?
Векторный поиск находит похожие фрагменты, но не всегда самые полезные. Rerank пересортирует их по смыслу запроса, и в модель попадает меньше мусора.

## Цена

Пробный API-ключ бесплатный, но с жёсткими лимитами и только для тестов. Боевое использование оплачивается за токены: у флагманской Command A — около $2,5 за миллион входных и $10 за миллион выходных токенов, у Embed и Rerank — свои тарифы.


## Доступность из России

Официально Cohere не обслуживает Россию: для регистрации и запросов нужен VPN, оплата — только зарубежной картой. Российские аналоги — [[GigaChat]] и [[Yandex AI Studio]].
