# Color Hunt

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Цвет и контраст · Global
Буква: C · Страница на сайте: `/tools/color-hunt`

## Описание

Color Hunt — это бесплатная коллекция цветовых палитр из четырёх цветов, которые отбирают вручную и оценивают лайками сообщества. Палитру можно скопировать в HEX одним кликом.

Главное отличие от генераторов вроде [[Coolors]] — кураторство: вместо случайных сочетаний вы смотрите готовые палитры, которые уже понравились тысячам дизайнеров.

### Возможности
- **Тысячи палитр** по 4 цвета с HEX-кодами.
- **Фильтры** по цвету, настроению и теме: пастель, винтаж, неон, свадьба, зима.
- **Сортировка** по новизне и популярности за месяц, год и всё время.
- **Создание своей палитры** и отправка в коллекцию.
- **Расширение для Chrome** с новой палитрой в каждой вкладке.

### Кому подходит
Дизайнерам, иллюстраторам, SMM-специалистам и разработчикам, которым нужна быстрая идея для цветовой схемы сайта, презентации или поста.

### Как пользоваться
Выберите тег, например «Pastel» или «Dark», откройте понравившуюся палитру и нажмите на цвет — HEX скопируется в буфер. Сохраняйте находки лайком, чтобы вернуться к ним позже.

### Совет
Палитра из Color Hunt — это отправная точка, а не готовая система. Перенесите цвета в [[Figma]], постройте шкалы оттенков и проверьте контраст текста в [[WebAIM Contrast Checker]].

### Ограничения
Нет шкал оттенков, ролей цветов и проверки доступности. Для полноценной дизайн-системы нужны [[Adobe Color]], [[Coolors]] или ручная настройка токенов.

## Частые вопросы
### Color Hunt бесплатный?
Да, сайт полностью бесплатный. Регистрация не нужна даже для копирования цветов.

### Работает ли Color Hunt в России?
Да, работает без VPN и ограничений.

### Color Hunt или Coolors?
[[Coolors]] генерирует палитры, умеет блокировать цвета и экспортировать их в разные форматы. Color Hunt показывает готовые палитры, отобранные людьми, и лучше подходит для поиска настроения.

### Как применить палитру из Color Hunt на сайте?
Назначьте цветам роли: фон, текст, акцент, вспомогательный. Затем проверьте контраст текста и фона, чтобы сайт оставался читаемым.
