# Content Reel

## Описание

Content Reel — бесплатный плагин для [[Figma]] от Microsoft, который заполняет макеты реалистичным контентом: имена, адреса, даты, тексты, аватары и иконки.

Главное отличие — общие библиотеки контента. Команда собирает свои наборы данных, например названия товаров или реальные цены, и подставляет их в любые макеты.

### Возможности
- **Текстовые строки** — имена, e-mail, телефоны, даты, адреса, суммы.
- **Аватары и изображения** — заливка фигур фотографиями и иллюстрациями.
- **Иконки** — вставка иконок из встроенных наборов.
- **Свои библиотеки** — наборы данных, которыми можно поделиться с командой.
- **Массовая подстановка** — заполнение сразу всех выделенных слоёв разными значениями.

### Кому подходит
UI-дизайнерам, которые рисуют списки, таблицы, карточки пользователей и хотят видеть макет с правдоподобными данными вместо «Lorem ipsum».

### Как пользоваться
Установите плагин из сообщества Figma, выделите текстовые слои или фигуры и выберите тип контента. Плагин заполнит каждый слой своим значением.

### Совет
Соберите библиотеку с данными своего продукта: реальные длинные названия, большие суммы, пустые значения. Так вы увидите, как интерфейс ломается на крайних случаях, ещё до вёрстки.

### Ограничения
Встроенные данные в основном англоязычные, для русских имён и адресов придётся собрать свою библиотеку. Для фото удобнее [[Unsplash for Figma]], для иконок — [[Iconify for Figma]].

## Вердикт
- Кому подходит: UI-дизайнерам, которые заполняют макеты списков, таблиц и профилей.
- Кому не подходит: Тем, кому нужны готовые русские данные из коробки.
- Итог: Простой бесплатный плагин, который убирает «рыбу» из макетов и помогает ловить крайние случаи.

## Частые вопросы
### Content Reel бесплатный?
Да, плагин полностью бесплатный и не требует регистрации вне Figma.

### Работает ли Content Reel в России?
Да, если у вас работает Figma. Сам плагин оплаты не требует.

### Чем заменить Content Reel?
Для фото — [[Unsplash for Figma]], для иконок — [[Iconify for Figma]]. Для данных на русском проще собрать свою библиотеку внутри Content Reel.

### Как добавить русские имена?
Создайте свою библиотеку в плагине и вставьте списком нужные строки: имена, города, названия товаров.
