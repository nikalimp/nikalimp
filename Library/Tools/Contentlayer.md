# Contentlayer

## Описание

Contentlayer — библиотека с открытым кодом, которая превращает Markdown и MDX-файлы в типизированные JSON-данные для сайта на [[Next.js]] и других фреймворках.

Главное отличие — контент живёт в репозитории как обычные файлы, а Contentlayer проверяет их по схеме и генерирует типы TypeScript. Ошибка в поле статьи всплывает на этапе сборки, а не на живом сайте.

### Возможности
- **Схема документов** — поля, типы и обязательность для статей, страниц, авторов.
- **Типы TypeScript** — автоматическая генерация типов по схеме.
- **MDX** — компиляция MDX с плагинами remark и rehype.
- **Вычисляемые поля** — slug, время чтения, оглавление.
- **Горячая перезагрузка** — правка Markdown сразу видна в режиме разработки.

### Кому подходит
Разработчикам блогов, документации и сайтов-портфолио, которые хранят тексты в Git и не хотят отдельную CMS.

### Как начать
Установите пакет, опишите схему документа в `contentlayer.config.ts` и подключите плагин к конфигурации Next.js. Импортируйте сгенерированные данные на страницах.

### Совет
Для нового проекта сначала посмотрите на [[Velite]]: он решает ту же задачу и развивается. Contentlayer оставьте для поддержки старых проектов.

### Ограничения
Основная разработка остановилась в 2023 году, после ухода спонсора. Новые версии Next.js поддерживаются только через неофициальный форк contentlayer2. Если нужен визуальный редактор для авторов, берите [[Keystatic]] или [[TinaCMS]].

## Вердикт
- Кому подходит: Разработчикам, которые поддерживают существующий сайт на Contentlayer.
- Кому не подходит: Новым проектам и командам, где тексты правят не разработчики.
- Итог: Удобная, но заброшенная библиотека для контента в Git: для новых сайтов лучше взять Velite.

## Плюсы
- Бесплатная, с открытым кодом
- Типизация контента и проверка на сборке
- Хорошая поддержка MDX
- Контент хранится в репозитории

## Минусы
- Проект не развивается с 2023 года
- Проблемы совместимости с новыми версиями Next.js
- Нет интерфейса для редакторов

## Частые вопросы
### Contentlayer бесплатный?
Да, это библиотека с открытым кодом под лицензией MIT, платных версий нет.

### Работает ли Contentlayer в России?
Да, пакет устанавливается из npm без ограничений и работает локально при сборке.

### Contentlayer или Velite?
Для нового проекта — [[Velite]]: схема и подход похожи, но он поддерживается. Contentlayer имеет смысл только в уже работающих проектах.

### Жив ли Contentlayer?
Основной репозиторий почти не обновляется. Сообщество поддерживает форк contentlayer2, но для долгой жизни проекта надёжнее перейти на Velite.
