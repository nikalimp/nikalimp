## Описание

Convex — бэкенд для веб-приложений: база данных, серверные функции на TypeScript, файлы, планировщик и обновления в реальном времени в одном сервисе.

Главное отличие — данные синхронизируются с интерфейсом автоматически. Вы пишете запрос на TypeScript, а компоненты [[React]] обновляются сами при каждом изменении в базе, без WebSocket и кеша вручную.

### Возможности
- **Реактивная база** — документы с транзакциями и подписка интерфейса на изменения.
- **Функции на TypeScript** — запросы, мутации и действия со сквозной типизацией.
- **Планировщик и cron** — отложенные и регулярные задачи.
- **Файлы и поиск** — хранилище, полнотекстовый и векторный поиск.
- **Компоненты** — готовые модули: лимиты запросов, очереди, агенты.

### Кому подходит
Разработчикам приложений с живыми данными: чаты, совместное редактирование, дашборды, AI-продукты. Хорошо работает в связке с AI-кодингом.

### Как начать
Выполните `npm create convex`, опишите схему и первую функцию запроса. Подключите клиент в React и вызывайте функции через хуки.

### Совет
Держите тяжёлые вызовы внешних API в действиях (actions), а логику с базой — в мутациях. Так транзакции остаются быстрыми.

### Ограничения
Это не SQL: перейти на PostgreSQL потом непросто. Для привычной реляционной модели посмотрите [[Neon]] или [[Appwrite]], для простого бэкенда в одном файле — [[PocketBase]]. Авторизацию часто берут из [[Clerk]].

## Частые вопросы
### Convex бесплатный?
Да, есть бесплатный план для небольших проектов. Для продакшена с нагрузкой нужен Professional или собственный хостинг.

### Работает ли Convex в России?
Бесплатный облачный план доступен, платные тарифы — только с зарубежной картой. Открытую версию можно развернуть на российском сервере.

### Convex или Neon?
[[Neon]] — это PostgreSQL в облаке, к нему нужен свой бэкенд. Convex даёт базу и серверные функции сразу, но без SQL.

### Подходит ли Convex для AI-приложений?
Да: есть векторный поиск, фоновые задачи и готовый компонент для агентов, а живые обновления удобны для чатов.
