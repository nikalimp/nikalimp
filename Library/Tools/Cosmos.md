# Cosmos

## Описание

Cosmos — визуальная платформа для сбора референсов: картинки, видео и ссылки складываются в коллекции, а AI-поиск находит похожие изображения по смыслу и цвету.

Главное отличие — спокойная лента без рекламы, лайков и счётчиков подписчиков. Cosmos задумывали как замену [[Pinterest]] для дизайнеров, которым мешает визуальный шум.

### Возможности
- **Коллекции** — подборки картинок, видео и ссылок для проектов и мудбордов.
- **Сохранение откуда угодно** — расширение для браузера и мобильное приложение.
- **AI-поиск** — по описанию, цвету и визуальному сходству.
- **Импорт** — перенос досок из Pinterest и [[Are.na]].
- **Публичные коллекции** — ими можно делиться с клиентом или командой.

### Кому подходит
Дизайнерам, арт-директорам и фотографам, которые собирают насмотренность и мудборды для проектов.

### Как начать
Создайте аккаунт, установите расширение и импортируйте старые доски из Pinterest. Заведите коллекцию на каждый проект.

### Совет
Подписывайтесь на коллекции дизайнеров, чей вкус вам близок. Лента станет полезнее, чем поиск по ключевым словам.

### Ограничения
Ленты по темам меньше, чем в Pinterest: популярные стили здесь представлены беднее. Для UI-паттернов полезнее [[Mobbin]] и [[Refero]], для подборок лучших сайтов — [[Godly]].

## Частые вопросы
### Cosmos бесплатный?
Да, основные функции бесплатные: сохранение, коллекции, поиск и импорт.

### Работает ли Cosmos в России?
Да, сайт и приложение открываются без VPN.

### Cosmos или Pinterest?
[[Pinterest]] больше по объёму контента, Cosmos — чище: без рекламы и рекомендаций товаров. Для работы дизайнера Cosmos удобнее.

### Как собрать мудборд в Cosmos?
Создайте коллекцию, сохраняйте в неё картинки через расширение и поделитесь ссылкой с клиентом.
