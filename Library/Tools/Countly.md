## Описание

Countly — платформа продуктовой аналитики для мобильных приложений, сайтов и устройств, которую можно установить на свой сервер и хранить все данные у себя.

Главное отличие — полный контроль над данными. Countly можно развернуть в закрытом контуре, поэтому его выбирают банки, госсектор и компании со строгими требованиями к хранению персональных данных.

### Возможности
- **События и воронки** — пользовательские действия, конверсии и удержание.
- **Сбой-отчёты** — ошибки и падения мобильных приложений.
- **Пуш-уведомления** — рассылки по сегментам из той же системы.
- **Опросы и NPS** — обратная связь внутри приложения.
- **SDK** — для iOS, Android, веба, Flutter, React Native и десктопа.

### Кому подходит
Командам мобильных приложений, которым нужна аналитика с хранением данных в своей инфраструктуре. Российским компаниям с требованиями 152-ФЗ.

### Как начать
Разверните Countly Lite через Docker на своём сервере, подключите SDK и отправьте первые события. Затем соберите воронку ключевого сценария.

### Совет
Сначала опишите план событий: название, параметры, где срабатывает. Без плана в базе быстро накопятся дубли вроде «click_button» и «button_click».

### Ограничения
Часть функций (когорты, A/B-тесты, расширенные воронки) есть только в платной версии. Интерфейс беднее, чем у облачных лидеров. Для веб-аналитики в России обычно хватает [[Яндекс Метрика]].

## Вердикт
- Кому подходит: Командам приложений, которым важно хранить аналитику на своих серверах.
- Кому не подходит: Небольшим сайтам, где хватает бесплатной Метрики.
- Итог: Зрелая продуктовая аналитика с открытым кодом, удобная для закрытого контура.

## Плюсы
- Бесплатная версия для своего сервера
- Данные не покидают вашу инфраструктуру
- Аналитика, сбои, пуши и опросы в одной системе
- SDK для всех основных платформ

## Минусы
- Расширенные функции только в платной версии
- Нужна своя поддержка сервера
- Интерфейс без русского языка

## Частые вопросы
### Countly бесплатный?
Версия Lite с открытым кодом бесплатная для установки на свой сервер. Облако и Enterprise платные.

### Работает ли Countly в России?
Да, самостоятельную установку можно развернуть на российском хостинге. Облачные тарифы требуют зарубежной карты.

### Countly или Яндекс Метрика?
[[Яндекс Метрика]] бесплатна и удобна для сайтов. Countly нужен для мобильных приложений и продуктовой аналитики с хранением данных у себя.

### Подходит ли Countly под 152-ФЗ?
Да, если развернуть его на сервере в России: данные пользователей не уходят третьим лицам.
