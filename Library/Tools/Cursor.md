## Описание

Cursor — редактор кода со встроенным AI. Он основан на VS Code, поэтому привычен разработчикам, но добавляет агента, который сам пишет и правит код в проекте, автодополнение целыми блоками и чат с пониманием всей кодовой базы.

Cursor делает компания Anysphere. Редактор стал одним из главных инструментов «вайб-кодинга» — разработки, когда человек описывает задачу словами, а AI пишет код.

### Возможности
- **Агент:** выполняет задачу целиком — меняет несколько файлов, запускает команды, исправляет ошибки.
- **Tab:** предсказывает следующие правки и дописывает код.
- **Чат по проекту:** ответы с учётом всей кодовой базы.
- **Выбор моделей** от разных разработчиков.
- **Правила проекта** — инструкции, которые агент учитывает всегда.
- **Совместимость** с расширениями и настройками VS Code.

### Кому подходит
Разработчикам любого уровня, дизайнерам и продуктовым менеджерам, которые сами собирают прототипы. Фрилансерам, которые делают сайты и сервисы на Next.js, React и других фреймворках.

### Как начать
Установите Cursor, импортируйте настройки VS Code и откройте проект. Начните с небольших задач: «добавь страницу контактов» или «найди, почему форма не отправляется». Проверяйте каждое изменение перед коммитом.

### Совет
Опишите в правилах проекта стек, стиль кода и запреты. Например: «используй shadcn/ui, не добавляй новые библиотеки без запроса». Так агент меньше ошибается.

### Ограничения
Агент может уверенно сломать то, что работало. Работайте через Git и делайте коммит перед большими изменениями.

### Частый вопрос
**Cursor или GitHub Copilot?** [[GitHub Copilot]] работает внутри привычного редактора, Cursor — отдельный редактор с более глубокой интеграцией агента. Для сборки приложения без кода подойдёт [[Lovable]], для работы в терминале — Claude Code от [[Claude]].

## Частые вопросы
### Cursor бесплатный?
Да, у Cursor есть бесплатный план с ограниченным числом запросов. Платные тарифы стоят от $8 в месяц, а модели Claude и GPT доступны с Premium за $30 и оплачиваются отдельно по ценам API.

### Работает ли Cursor в России?
Сам редактор запускается, но часть AI-функций без VPN не работает: разработчики моделей закрыли доступ из России. Оплатить подписку российской картой нельзя.

### Что лучше: Cursor или Claude Code?
Cursor — визуальный редактор с агентом внутри, [[Claude Code]] — агент в терминале. Cursor удобнее, если хочется видеть код и правки в интерфейсе, Claude Code — если задачи удобнее ставить словами и запускать в консоли.

### Что изменилось в тарифах Cursor в 2026 году?
12 октября 2026 года xAI объединила Cursor, Grok и X Premium в одну подписку с общим недельным лимитом. Старые тарифы Cursor пока работают, переход на новую подписку необязателен.
