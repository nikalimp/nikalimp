Буква: C · Страница на сайте: `/tools/customer-io`

## Описание

Customer.io — платформа автоматических сообщений для продуктов: e-mail, пуши, SMS и сообщения в приложении отправляются по действиям пользователя, а не по расписанию.

Главное отличие — работа с событиями продукта. Вы передаёте в Customer.io данные о действиях (регистрация, оплата, брошенная корзина), и сценарии сами реагируют на них нужным сообщением.

### Возможности
- **Сценарии** — визуальный конструктор цепочек с условиями, задержками и ветками.
- **Каналы** — e-mail, пуши, SMS, сообщения в приложении и вебхуки.
- **Сегменты** — по атрибутам и событиям в реальном времени.
- **Data Pipelines** — сбор событий и передача в другие сервисы, как [[Segment]].
- **Транзакционные письма** — подтверждения, чеки, сброс пароля по API.

### Кому подходит
SaaS-продуктам и приложениям, которым нужны онбординг, реактивация и сообщения по поведению пользователей.

### Как начать
Подключите SDK или API, передайте события регистрации и ключевого действия. Затем соберите цепочку из 3–4 писем онбординга.

### Совет
Сначала опишите 5–10 ключевых событий продукта и их параметры. Без чистых данных сценарии будут срабатывать не вовремя.

### Ограничения
Дорого для небольших проектов. Для простых рассылок по базе хватит [[Brevo]] или [[Mailchimp]], для транзакционных писем — [[Postmark]] или [[Resend]].

## Вердикт
- Кому подходит: SaaS и мобильным приложениям, которым нужны сообщения по действиям пользователей.
- Кому не подходит: Небольшим сайтам с редкими рассылками и российским проектам без зарубежной карты.
- Итог: Сильная платформа продуктовых коммуникаций, но с высоким входным ценником.

## Плюсы
- Сценарии по событиям продукта в реальном времени
- E-mail, пуши, SMS и in-app в одной системе
- Сбор и передача данных через Data Pipelines
- Гибкий API для разработчиков

## Частые вопросы
### Сколько стоит Customer.io?
От $100 в месяц на тарифе Essentials. Бесплатного плана нет, есть пробный период на 14 дней.

### Работает ли Customer.io в России?
Сайт работает, но оплатить подписку можно только зарубежной картой. Для российских проектов надёжнее [[Mindbox]] или [[Unisender]].

### Customer.io или Brevo?
[[Brevo]] дешевле и подходит для рассылок по базе. Customer.io сильнее в сценариях по событиям продукта.

### Можно ли отправлять транзакционные письма?
Да, через API Customer.io отправляет подтверждения, чеки и уведомления вместе с маркетинговыми сценариями.
