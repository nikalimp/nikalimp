## Описание

Cypress — это фреймворк для end-to-end и компонентного тестирования веб-приложений: тесты пишутся на JavaScript или TypeScript и запускаются в настоящем браузере.

Главное отличие — интерактивный раннер: вы видите каждый шаг теста, снимки DOM и можете «отмотать» выполнение назад.

### Возможности
- **E2E-тесты** пользовательских сценариев: вход, корзина, оплата.
- **Компонентные тесты** для [[React]], Vue, Angular и Svelte.
- **Перехват сетевых запросов** и подмена ответов API.
- **Автоматические ожидания:** не нужно расставлять паузы вручную.
- **Cypress Cloud:** параллельный запуск, история прогонов, поиск нестабильных тестов.

### Кому подходит
Фронтенд-разработчикам и QA-инженерам, которые тестируют веб-приложения и хотят наглядную отладку тестов.

### Как начать
Установите пакет командой npm install cypress --save-dev и запустите npx cypress open. Мастер создаст структуру папок и примеры тестов. В CI тесты запускаются командой cypress run, например в [[GitHub Actions]].

### Совет
Обращайтесь к элементам через атрибуты data-cy, а не через классы: тесты перестанут ломаться после правок вёрстки.

### Ограничения
Нет поддержки Safari — только экспериментальный WebKit. Несколько вкладок и доменов в одном тесте поддерживаются хуже, чем в [[Playwright]]. Для юнит-тестов быстрее [[Vitest]] или [[Jest]].

## Вердикт
- Кому подходит: Фронтенд-командам, которым нужны наглядные E2E- и компонентные тесты.
- Кому не подходит: Проектам, где важны Safari, мобильные браузеры и сценарии с несколькими вкладками.
- Итог: Удобный бесплатный фреймворк для тестов в браузере с лучшей в классе отладкой.

## Частые вопросы
### Cypress бесплатный?
Да, фреймворк бесплатный и открытый. Платный только облачный сервис Cypress Cloud сверх 500 результатов тестов в месяц.

### Работает ли Cypress в России?
Да, фреймворк ставится через npm без VPN. Оплатить Cypress Cloud можно только зарубежной картой.

### Cypress или Playwright?
[[Playwright]] быстрее, поддерживает Safari и несколько вкладок. Cypress проще для старта и удобнее в отладке.

### Подходит ли Cypress для тестирования API?
Да, команда cy.request отправляет запросы к API, но для ручной работы с API удобнее [[Postman]].
