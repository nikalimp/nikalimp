## Описание

DBeaver — это универсальный клиент для баз данных: в одной программе можно подключиться к PostgreSQL, MySQL, SQLite, ClickHouse, Oracle и десяткам других СУБД, писать SQL-запросы и редактировать таблицы.

Главное отличие от [[TablePlus]] — бесплатная версия с открытым кодом и поддержка почти любых баз через JDBC-драйверы.

### Возможности
- **80+ баз данных:** реляционные, аналитические, а в платных версиях — NoSQL.
- **SQL-редактор** с автодополнением, форматированием и планом выполнения запроса.
- **ER-диаграммы** структуры базы.
- **Импорт и экспорт** данных в CSV, Excel, JSON и SQL.
- **SSH-туннели** для подключения к базам на удалённых серверах.

### Кому подходит
Бэкенд-разработчикам, аналитикам и администраторам, которые работают с несколькими базами и не хотят держать отдельный клиент для каждой.

### Как начать
Скачайте Community Edition, нажмите «Новое соединение», выберите тип базы и укажите хост, порт и учётные данные. Нужный драйвер DBeaver скачает сам.

### Совет
Для боевых баз включите в настройках соединения режим «только чтение» и подтверждение транзакций: случайный UPDATE без WHERE обойдётся дорого.

### Ограничения
Интерфейс на Java тяжелее и медленнее нативных клиентов. MongoDB, Redis и облачные хранилища доступны только в платных версиях. Для простых запросов из редактора кода хватает SQL-расширений для [[VS Code]].

## Частые вопросы
### DBeaver бесплатный?
Да, версия Community бесплатная и с открытым кодом. Платные версии добавляют NoSQL-базы, облака и поддержку.

### Работает ли DBeaver в России?
Да, Community Edition скачивается и работает без VPN. Платные версии оплачиваются зарубежной картой.

### DBeaver или TablePlus?
[[TablePlus]] быстрее и легче, особенно на Mac, но платный. DBeaver бесплатен и поддерживает больше баз данных.

### Можно ли подключиться к базе через SSH в DBeaver?
Да, в настройках соединения есть вкладка SSH: укажите сервер, пользователя и ключ.
