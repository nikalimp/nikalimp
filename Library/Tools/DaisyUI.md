# DaisyUI

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · UI-библиотеки и компоненты · Global
Буква: D · Страница на сайте: `/tools/daisyui`

## Описание

DaisyUI — это бесплатный плагин для [[Tailwind CSS]] с готовыми компонентами: кнопки, карточки, модальные окна и формы подключаются короткими классами вроде btn или card.

Главное отличие от [[shadcn ui|shadcn/ui]] — DaisyUI работает на чистом CSS без JavaScript и не привязан к React, поэтому подходит для любого фреймворка и даже статического HTML.

### Возможности
- **68 компонентов** — от кнопок и меню до таблиц, таймлайнов и чатов.
- **35 готовых тем** со светлой и тёмной версией, переключение одним атрибутом.
- **Свои темы** через CSS-переменные и генератор тем на сайте.
- **Любой стек:** HTML, [[React]], [[Vue.js]], Svelte, Laravel, Django.
- **Версия 5** для Tailwind CSS 4, без зависимостей.

### Кому подходит
Разработчикам на Tailwind, которые хотят собрать интерфейс быстро и не писать длинные цепочки утилитарных классов. Хорошо подходит для прототипов, админок и pet-проектов.

### Как начать
Установите пакет командой npm i -D daisyui, добавьте @plugin "daisyui" в CSS-файл после импорта Tailwind и используйте классы компонентов в разметке.

### Совет
Сразу настройте свою тему через переменные цветов и скруглений: без этого сайт на DaisyUI легко узнаётся по стандартной палитре.

### Ограничения
Сложные интерактивные компоненты — выпадающие списки с поиском, датапикеры — придётся писать самим или брать из [[Headless UI]]. Доступность клавиатурой нужно проверять вручную.

## Частые вопросы
### DaisyUI бесплатный?
Да, библиотека бесплатная и с открытым кодом. Платные только отдельные готовые шаблоны.

### Работает ли DaisyUI в России?
Да, пакет ставится через npm, а документация открывается без VPN.

### DaisyUI или shadcn/ui?
[[shadcn ui|shadcn/ui]] даёт React-компоненты с логикой и доступностью, которые вы копируете в проект. DaisyUI проще и работает без React, но интерактивность приходится дописывать.

### Совместим ли DaisyUI с Tailwind CSS 4?
Да, DaisyUI 5 сделан под Tailwind CSS 4 и подключается одной строкой @plugin в CSS.
