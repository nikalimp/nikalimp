## Описание

DataForSEO — это набор API с SEO-данными: выдача поисковых систем, ключевые слова, ссылки, данные о доменах и страницах. Сервис продаёт данные по запросу, без интерфейса для конечного пользователя.

Главное отличие — модель «плати за запрос». Вы не покупаете подписку на SEO-платформу, а берёте только те данные, которые нужны вашему скрипту, сервису или дашборду.

### Возможности
- **SERP API:** выдача Google, Bing и других систем по запросу, региону и языку.
- **Keywords Data API:** частотность, CPC и конкуренция по ключевым словам.
- **Backlinks API:** ссылочный профиль домена, доноры, анкоры.
- **On-Page API:** краулинг сайта и технические ошибки.
- **Labs API:** готовые срезы по видимости доменов и конкурентам.

### Кому подходит
Разработчикам SEO-инструментов, агентствам со своими дашбордами и тем, кто строит мониторинг позиций или GEO-отчёты на собственном коде.

### Как пользоваться
Зарегистрируйтесь, получите логин и пароль API в кабинете и отправьте первый запрос из Playground. Затем подключите API к своему скрипту, [[n8n]] или [[Make]].

### Совет
Используйте очередь Standard вместо Live, если результат не нужен мгновенно: задачи в очереди стоят в несколько раз дешевле. Для массового мониторинга позиций это главная статья экономии.

### Ограничения
Нужен разработчик или хотя бы no-code сценарий: готовых отчётов для клиента нет. Для выдачи Яндекса удобнее российские сервисы. Если нужен готовый интерфейс, посмотрите [[SerpApi]] или [[SE Ranking]].

## Частые вопросы
### Сколько стоит DataForSEO?
Подписки нет: вы пополняете баланс и платите за запросы. Цена одной выдачи в очереди Standard — доли цента, Live дороже.

### Работает ли DataForSEO в России?
Российские карты сервис не принимает, для оплаты нужна зарубежная. Для задач по Яндексу проще взять российские сервисы.

### DataForSEO или SerpApi?
[[SerpApi]] проще для разработчика и даёт данные выдачи в удобном JSON. DataForSEO дешевле на больших объёмах и кроме выдачи отдаёт ключи, ссылки и аудит.

### Можно ли собрать на DataForSEO мониторинг позиций?
Да, это типовая задача: список запросов уходит в SERP API, результаты сохраняются в таблицу или базу и выводятся в дашборд.
