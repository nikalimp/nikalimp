## Описание

Deno Deploy — это облачный хостинг от создателей [[Deno]] для серверного JavaScript и TypeScript. Код запускается на серверах по всему миру, ближе к пользователю, и разворачивается из GitHub за секунды.

Главное отличие — нет настройки серверов и сборки. Вы пушите код в репозиторий, а Deploy сам собирает проект и выдаёт адрес с HTTPS.

### Возможности
- **Деплой из GitHub:** каждый пуш создаёт превью, основная ветка уходит в продакшен.
- **TypeScript без сборки** и поддержка npm-пакетов.
- **Deno KV** — встроенное хранилище «ключ — значение».
- **Очереди и задачи по расписанию** (cron) без отдельного сервиса.
- **Фреймворки:** Fresh, [[Hono]], Astro, Next.js и другие.

### Кому подходит
Разработчикам API, ботов, вебхуков и небольших веб-сервисов, которым нужен быстрый деплой без своего сервера.

### Как начать
Подключите GitHub-репозиторий в панели Deno Deploy, укажите точку входа и переменные окружения. Первый деплой займёт меньше минуты.

### Совет
Держите тяжёлые задачи вне Deploy: у бессерверных функций есть лимиты по времени и памяти. Обработку видео или долгие расчёты выносите на VPS.

### Ограничения
Deno Deploy переходит на новую версию платформы, старая версия (Deploy Classic) постепенно отключается, проверьте сроки в документации. Для долгоживущих процессов и баз данных лучше [[Fly.io]] или свой сервер с [[Coolify]].

## Частые вопросы
### Deno Deploy бесплатный?
Да, бесплатный план есть и подходит для ботов, API и небольших сайтов. За большие объёмы трафика нужен Pro.

### Работает ли Deno Deploy в России?
Бесплатный план работает без VPN. Платный тариф оплачивается только зарубежной картой.

### Deno Deploy или Cloudflare Workers?
[[Cloudflare Workers]] дешевле на больших объёмах и даёт больше сопутствующих сервисов. Deno Deploy проще для проектов на Deno и TypeScript.

### Можно ли запустить Telegram-бота на Deno Deploy?
Да, через вебхуки: бот получает обновления по HTTPS, а Deploy запускает обработчик только на время запроса.
