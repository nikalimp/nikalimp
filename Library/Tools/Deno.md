## Описание

Deno — это среда выполнения JavaScript и TypeScript от создателя Node.js Райана Даля: код на TypeScript запускается без настройки сборки, а доступ к сети и файлам выдаётся явными разрешениями.

Главное отличие — безопасность и встроенные инструменты: форматтер, линтер, тесты и сборка в один файл идут из коробки, а с версии 2 поддерживаются пакеты npm.

### Возможности
- **TypeScript без настройки** и проверка типов одной командой.
- **Разрешения:** скрипт не получит доступ к сети, диску и переменным окружения без флагов.
- **Встроенные инструменты:** deno fmt, deno lint, deno test, deno compile.
- **Совместимость с npm** и Node.js API.
- **Deno Deploy:** хостинг серверных функций на edge с KV-хранилищем.

### Кому подходит
Разработчикам, которые пишут скрипты, API и серверные функции на TypeScript и хотят меньше конфигурации, чем в Node.js. Фронтенд можно собирать через [[Vite]] или фреймворк Fresh от команды Deno.

### Как начать
Установите Deno одной командой из документации, создайте файл main.ts и запустите deno run main.ts. Для веб-сервера достаточно функции Deno.serve.

### Совет
Используйте deno compile, чтобы собрать скрипт в один исполняемый файл: его можно отдать коллеге или клиенту без установки среды.

### Ограничения
Экосистема меньше, чем у Node.js, часть npm-пакетов с нативными модулями работает с оговорками. По скорости установки и запуска конкуренцию составляет [[Bun]].

## Частые вопросы
### Deno бесплатный?
Да, Deno бесплатный и открытый. Платный только хостинг Deno Deploy сверх бесплатного лимита в 1 млн запросов в месяц.

### Работает ли Deno в России?
Да, установка и запуск работают без VPN. Для платного Deno Deploy нужна зарубежная карта.

### Deno или Bun?
[[Bun]] быстрее и ближе к Node.js по совместимости. Deno безопаснее за счёт разрешений и даёт больше встроенных инструментов.

### Можно ли использовать npm-пакеты в Deno?
Да, с версии 2 пакеты подключаются через префикс npm: и файл package.json.
