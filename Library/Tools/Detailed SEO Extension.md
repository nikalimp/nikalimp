## Описание

Detailed SEO Extension — это бесплатное расширение для Chrome и Firefox, которое за один клик показывает SEO-данные страницы: title, description, заголовки, canonical, robots, разметку и ссылки.

Главное отличие от [[SeoQuake]] — чистый интерфейс без рекламы и лишних метрик: только то, что нужно для быстрого технического аудита страницы.

### Возможности
- **Мета-данные:** title, description, canonical, robots и X-Robots-Tag.
- **Структура заголовков** H1–H6 с отступами по вложенности.
- **Микроразметка Schema.org** без отдельного валидатора.
- **Ссылки и изображения:** экспорт списков, подсветка nofollow, hreflang.
- **Быстрые переходы** в Ahrefs, Semrush, SimilarWeb и Wayback Machine из контекстного меню.

### Кому подходит
SEO-специалистам, контент-менеджерам и веб-разработчикам, которые проверяют страницы перед публикацией или анализируют конкурентов.

### Как пользоваться
Установите расширение, откройте любую страницу и нажмите на иконку. Вкладки Overview, Headings, Links, Images и Schema покажут данные страницы.

### Совет
Перед запуском сайта пройдитесь расширением по ключевым шаблонам страниц: одинаковые title и пропущенный H1 видны сразу, без запуска краулера.

### Ограничения
Проверяет только открытую страницу. Для аудита всего сайта нужен краулер — [[Screaming Frog SEO Spider]] или [[Netpeak Spider]]. Данных о позициях и трафике нет.

## Частые вопросы
### Detailed SEO Extension бесплатное?
Да, расширение полностью бесплатное, без платных функций и рекламы.

### Работает ли Detailed SEO Extension в России?
Да, расширение ставится из магазинов Chrome и Firefox и работает без VPN.

### Detailed SEO Extension или SeoQuake?
[[SeoQuake]] показывает больше внешних метрик, но перегружает выдачу. Detailed SEO Extension удобнее для чистой проверки содержимого страницы.

### Работает ли расширение в Яндекс Браузере?
Да, Яндекс Браузер ставит расширения из Chrome Web Store.
