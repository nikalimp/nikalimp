## Описание

DevUtils — это приложение для macOS с набором офлайн-утилит разработчика: форматирование JSON, декодирование JWT, Base64, проверка регулярных выражений, генерация UUID и десятки других мелочей в одном окне.

Главное отличие — всё работает локально. Вы не вставляете токены, ключи и данные клиентов на случайные сайты-конвертеры, а обрабатываете их у себя на компьютере.

### Возможности
- **Форматтеры:** JSON, SQL, HTML, CSS, XML с подсветкой.
- **Декодеры:** JWT, Base64, URL, HTML-сущности.
- **Генераторы:** UUID, хеши, Lorem Ipsum, пароли.
- **Конвертеры:** JSON в YAML и CSV, время Unix, цвета, системы счисления.
- **Умный буфер:** приложение само определяет, что вы скопировали, и открывает нужный инструмент.

### Кому подходит
Веб-разработчикам и тестировщикам на Mac, которые много раз в день разбирают JSON, токены и строки и не хотят держать десяток вкладок с онлайн-утилитами.

### Как пользоваться
Скопируйте строку и откройте DevUtils горячей клавишей: приложение подскажет подходящий инструмент. Удобно вызывать его через [[Raycast]].

### Совет
Настройте глобальную горячую клавишу и автоопределение буфера: так DevUtils заменит поиск онлайн-конвертеров и сэкономит минуты каждый день.

### Ограничения
Только macOS: для Windows и Linux ищите аналоги. Часть функций дублируют бесплатные утилиты командной строки, которые ставятся через [[Homebrew]].

## Частые вопросы
### DevUtils бесплатный?
Нет, это платное приложение с пробным периодом. Исходный код опубликован, но готовую сборку покупают.

### Работает ли DevUtils в России?
Приложение работает офлайн без ограничений. Купить лицензию можно только зарубежной картой.

### Чем заменить DevUtils?
Онлайн-утилитами вроде CyberChef или командами в терминале. Для быстрых действий на Mac подходит [[Raycast]] с расширениями.

### Безопасно ли вставлять токены в DevUtils?
Да, обработка идёт локально на компьютере, без отправки данных на сервер.
