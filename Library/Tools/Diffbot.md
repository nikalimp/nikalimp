## Описание

Diffbot — это сервис, который с помощью машинного обучения превращает веб-страницы в структурированные данные: статьи, товары, обсуждения, организации и людей. Кроме API парсинга, у него есть собственный граф знаний о компаниях и людях.

Главное отличие — не нужно писать селекторы. Вы передаёте адрес страницы, а Diffbot сам определяет тип страницы и возвращает заголовок, текст, цену, автора и другие поля в JSON.

### Возможности
- **Extract API:** статьи, товары, видео, обсуждения без настройки шаблонов.
- **Crawlbot:** обход целого сайта с извлечением данных.
- **Knowledge Graph:** база компаний, людей и событий с поиском по атрибутам.
- **Natural Language API:** сущности, связи и тональность в тексте.
- **Интеграции** с Google Sheets и через API.

### Кому подходит
Аналитикам, исследовательским и data-командам, которым нужны данные с тысяч разных сайтов без поддержки парсера под каждый.

### Как пользоваться
Получите токен в кабинете и отправьте адрес страницы в Extract API. Для обхода сайта создайте задачу в Crawlbot и выгрузите результат в JSON или CSV.

### Совет
Проверьте качество извлечения на 20–30 страницах ваших источников до покупки тарифа: на нестандартной вёрстке автоматика ошибается.

### Ограничения
Дорого для небольших задач. Для разового парсинга одного сайта дешевле [[Apify]] или [[Firecrawl]], а для подготовки текста под LLM — [[Exa]] или [[Tavily]].

## Вердикт
- Кому подходит: Data-командам, которым нужны структурированные данные с множества разных сайтов и граф знаний о компаниях.
- Кому не подходит: Фрилансерам и небольшим проектам с разовым парсингом одного сайта.
- Итог: Мощный автоматический парсинг и граф знаний, но дорогой и только для зарубежной карты.

## Частые вопросы
### Diffbot бесплатный?
Есть бесплатный план с ограниченным числом кредитов, его хватает для тестов. Рабочие объёмы требуют подписки.

### Работает ли Diffbot в России?
API доступен без VPN, но оплатить подписку российской картой нельзя.

### Diffbot или Firecrawl?
[[Firecrawl]] дешевле и удобен для подготовки страниц в Markdown под нейросети. Diffbot сильнее в извлечении структурированных полей и даёт граф знаний.

### Что такое Knowledge Graph Diffbot?
База из миллиардов сущностей — компаний, людей, статей, — которую Diffbot собирает с открытых сайтов. По ней ищут компании и контакты по атрибутам.
