## Описание

Docusaurus — это бесплатный генератор сайтов документации от Meta: вы пишете страницы в Markdown или MDX, а он собирает быстрый статический сайт с навигацией, поиском и версиями.

Главное отличие от [[GitBook]] и [[Mintlify]] — полный контроль и отсутствие подписки: сайт живёт в вашем репозитории и разворачивается на любом хостинге.

### Возможности
- **Markdown и MDX:** в тексте можно использовать компоненты [[React]].
- **Версии документации** для разных релизов продукта.
- **Мультиязычность** с отдельными папками переводов.
- **Блог** и произвольные страницы рядом с документацией.
- **Поиск** через Algolia DocSearch или локальные плагины.

### Кому подходит
Командам открытых проектов, SaaS и разработчикам API, которым нужна документация или база знаний, которая хранится в git.

### Как начать
Выполните npx create-docusaurus@latest my-docs classic, отредактируйте файлы в папке docs и запустите npm start. Для публикации соберите сайт командой npm run build и выложите на [[GitHub Pages]] или [[Vercel]].

### Совет
Включите поле last_update и ссылку «Редактировать страницу» в настройках: пользователи увидят свежесть документации, а правки будут приходить через pull request.

### Ограничения
Нужен базовый опыт с Node.js и git: визуального редактора нет. Для команды без разработчиков удобнее облачные базы знаний вроде [[Notion]] или [[GitBook]].

## Частые вопросы
### Docusaurus бесплатный?
Да, Docusaurus бесплатный и с открытым кодом. Платить нужно только за хостинг, если не использовать бесплатные варианты.

### Работает ли Docusaurus в России?
Да, пакет ставится через npm без VPN, а готовый сайт можно разместить на российском хостинге.

### Docusaurus или GitBook?
[[GitBook]] удобнее для команд без разработчиков, но платный для команд. Docusaurus бесплатный и гибкий, но требует работы с кодом.

### Поддерживает ли Docusaurus русский язык?
Да, интерфейс сайта переводится на русский, а документацию можно вести на нескольких языках.
