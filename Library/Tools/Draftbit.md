## Описание

Draftbit — это визуальный конструктор мобильных приложений на React Native. Вы собираете экраны из компонентов, подключаете API и получаете приложение для iOS и Android с настоящим кодом, который можно выгрузить.

Главное отличие — код не заперт в платформе. В отличие от многих no-code сервисов, Draftbit генерирует проект на [[React Native]] и [[Expo]], который разработчик может доработать вручную.

### Возможности
- **Визуальный редактор экранов** с компонентами и стилями.
- **Подключение REST API** и бэкендов вроде Supabase или [[Xano]].
- **Свой код:** вставки на JavaScript и собственные компоненты.
- **Превью на телефоне** через приложение Expo.
- **Экспорт исходников** и публикация в сторы.

### Кому подходит
Стартапам и фрилансерам, которые делают MVP мобильного приложения, и разработчикам, которым нужен быстрый старт интерфейса с возможностью уйти в код.

### Как начать
Создайте проект из шаблона, подключите API с данными и соберите 2–3 ключевых экрана. Проверьте приложение на телефоне через Expo Go до покупки тарифа.

### Совет
Заранее спроектируйте API и данные: Draftbit отвечает за интерфейс, а логика и база живут на бэкенде. Так приложение будет проще переносить и поддерживать.

### Ограничения
Нужен базовый опыт разработки: без понимания API и React Native сложные экраны собрать трудно. Для полностью no-code подхода посмотрите [[Adalo]] или [[FlutterFlow]].

## Частые вопросы
### Draftbit бесплатный?
Начать можно бесплатно, но экспорт кода и публикация приложения доступны на платных тарифах.

### Работает ли Draftbit в России?
Сервис открывается без VPN, оплатить его российской картой нельзя.

### Draftbit или FlutterFlow?
[[FlutterFlow]] строит приложения на Flutter и сильнее в готовой интеграции с Firebase. Draftbit выбирают, если команда работает с React Native и JavaScript.

### Можно ли продолжить проект без Draftbit?
Да, на платном тарифе можно выгрузить исходный код на React Native и Expo и вести его в обычной среде разработки.
