## Описание

Drizzle ORM — это лёгкая ORM для TypeScript, которая описывает таблицы кодом и строит запросы с синтаксисом, близким к SQL. Типы результатов выводятся автоматически, без отдельной генерации клиента.

Главное отличие — «если знаете SQL, знаете Drizzle». Запросы читаются как SQL, библиотека весит мало и работает в бессерверных и edge-средах, где тяжёлые ORM запускаются медленно.

### Возможности
- **Схема на TypeScript:** таблицы, связи и индексы описываются кодом.
- **Два API:** SQL-подобный конструктор запросов и реляционные запросы со вложенными данными.
- **Drizzle Kit:** генерация и применение миграций.
- **Drizzle Studio:** просмотр и правка данных в браузере.
- **Базы:** PostgreSQL, MySQL, SQLite и облачные [[Neon]], [[Turso]], PlanetScale.

### Кому подходит
TypeScript-разработчикам, которые пишут бэкенд на Next.js, [[Hono]] или Node.js и хотят строгие типы без потери контроля над SQL.

### Как начать
Установите `drizzle-orm` и `drizzle-kit`, опишите схему в `schema.ts`, настройте `drizzle.config.ts` и выполните `drizzle-kit generate` для первой миграции.

### Совет
Храните схему в одном файле или папке и генерируйте миграции, а не правьте базу руками. Так история структуры базы живёт в git вместе с кодом.

### Ограничения
Для сложных связей и привычного декларативного API некоторым удобнее [[Prisma]]. Документация местами отстаёт от новых версий, а API между мажорными релизами меняется.

## Частые вопросы
### Drizzle ORM бесплатный?
Да, библиотека с открытым кодом и без платных тарифов.

### Работает ли Drizzle ORM в России?
Да, пакет ставится из npm без VPN и аккаунта.

### Drizzle или Prisma?
[[Prisma]] проще для новичка и даёт декларативную схему. Drizzle легче, быстрее стартует в бессерверных функциях и ближе к SQL.

### С какими базами работает Drizzle?
С PostgreSQL, MySQL и SQLite, а также с облачными сервисами вроде [[Neon]], [[Turso]] и Supabase.
