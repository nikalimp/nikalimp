## Описание

Electron — это фреймворк для создания десктопных приложений на JavaScript, HTML и CSS. Одна кодовая база собирается под Windows, macOS и Linux.

Главное отличие — внутри приложения работают Chromium и Node.js, поэтому веб-разработчик пишет десктопную программу теми же инструментами, что и сайт. На Electron сделаны [[VS Code]], [[Slack]], [[Discord]] и [[Obsidian]].

### Возможности
- **Кроссплатформенность:** одна сборка под три системы.
- **Доступ к системе** через Node.js: файлы, меню, уведомления, трей.
- **Любой фронтенд:** [[React]], [[Vue.js]] или чистый HTML.
- **Автообновления** и упаковка установщиков через Electron Forge.
- **Нативные модули** для задач, где не хватает JavaScript.

### Кому подходит
Веб-разработчикам, которым нужно десктопное приложение: внутренний инструмент, клиент для сервиса, редактор.

### Как начать
Создайте проект командой `npx create-electron-app my-app`, запустите `npm start`, затем перенесите в окно свой веб-интерфейс. Сборку установщиков делает Electron Forge.

### Совет
Отделяйте интерфейс от системной логики с самого начала: всё, что работает с файлами и ОС, держите в главном процессе и передавайте через preload-скрипт. Так приложение безопаснее и его проще поддерживать.

### Ограничения
Приложения тяжёлые: каждое тащит свой Chromium, установщик весит от 80–100 МБ, а память расходуется заметно. Если важен размер, посмотрите на Tauri или [[Flutter]].

## Вердикт
- Кому подходит: Веб-разработчикам, которые хотят выпустить десктопное приложение на знакомом стеке.
- Кому не подходит: Тем, кому важны маленький размер приложения и низкое потребление памяти.
- Итог: Самый проверенный способ сделать десктопное приложение из веб-интерфейса, ценой веса и памяти.

## Плюсы
- Один код для Windows, macOS и Linux
- Огромное сообщество и проверка временем: на нём работают VS Code и Slack
- Подходит любой фронтенд-фреймворк
- Бесплатный, лицензия MIT

## Минусы
- Большой размер установщика
- Высокое потребление памяти
- Нужно следить за безопасностью: Node.js в связке с веб-страницей открывает лишние доступы

## Частые вопросы
### Electron бесплатный?
Да, это открытый проект под лицензией MIT. Деньги понадобятся только на сертификаты подписи и аккаунты разработчика для магазинов приложений.

### Работает ли Electron в России?
Да, фреймворк скачивается из npm и GitHub без VPN, а готовые приложения работают на любых компьютерах.

### Electron или Tauri?
Tauri использует системный веб-движок и даёт приложения в разы легче, но требует Rust для системной логики. Electron тяжелее, зато проще для JavaScript-разработчика и стабильнее на всех системах.

### Можно ли сделать на Electron мобильное приложение?
Нет, Electron только для десктопа. Для мобильных приложений на JavaScript берут [[React Native]] с [[Expo]].
