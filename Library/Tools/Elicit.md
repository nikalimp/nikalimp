## Описание

Elicit — это AI-ассистент для работы с научными статьями: он ищет исследования по вопросу, вытаскивает из них данные в таблицу и пишет обзор с цитатами.

Главное отличие от [[Perplexity]] и [[ChatGPT]] — Elicit ищет только по научной базе из 138 млн статей и показывает, из какого фрагмента взят каждый факт.

### Возможности
- **Поиск по смыслу:** вопрос на естественном языке вместо ключевых слов.
- **Таблицы извлечения:** размер выборки, методы и результаты из десятков статей в колонках.
- **Отчёты** с выводами и ссылками на источники.
- **Систематические обзоры:** отбор тысяч статей по критериям.
- **Импорт из Zotero** и экспорт в CSV, BIB, DOCX.

### Кому подходит
Исследователям, аспирантам, аналитикам и продуктовым командам, которым нужно опереться на научные данные, а не на мнения.

### Как начать
Зарегистрируйтесь, задайте вопрос по-английски, например «does remote work affect productivity», отметьте релевантные статьи и добавьте колонки с нужными данными.

### Совет
Используйте Elicit для отбора и черновой таблицы, а ключевые цифры всегда сверяйте с текстом статьи: извлечение ошибается на сложных таблицах и в исследованиях с несколькими группами.

### Ограничения
Работает в основном с англоязычными статьями, полный текст доступен не всегда. Для быстрого ответа с источниками проще [[Consensus]], для работы со своими PDF — [[NotebookLM]] или [[ChatPDF]].

## Вердикт
- Кому подходит: Исследователям и аналитикам, которые разбирают десятки научных статей по одному вопросу.
- Кому не подходит: Тем, кому нужен поиск по русскоязычным источникам или обычный чат-бот.
- Итог: Сильный AI-инструмент для научных обзоров, который экономит дни ручного чтения.

## Плюсы
- Поиск по научной базе, а не по всему интернету
- Каждый факт привязан к цитате из статьи
- Таблицы извлечения данных из десятков исследований
- Бесплатный план для знакомства

## Минусы
- Только англоязычный интерфейс и в основном англоязычные статьи
- Ошибки извлечения на сложных таблицах
- Оплата только зарубежной картой

## Частые вопросы
### Elicit бесплатный?
Да, план Basic бесплатный: поиск без ограничений и несколько отчётов. Для регулярной работы понадобится платный тариф.

### Работает ли Elicit в России?
Сайт работает без VPN, но оплатить подписку можно только зарубежной картой.

### Elicit или Consensus?
[[Consensus]] быстрее отвечает на вопрос «да или нет» по науке. Elicit глубже: таблицы данных, систематические обзоры, отчёты.

### Можно ли спрашивать Elicit на русском?
Вопрос на русском он поймёт, но база статей в основном англоязычная, поэтому точнее работают запросы на английском.
