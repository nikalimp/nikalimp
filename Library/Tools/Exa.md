## Описание

Exa — это поисковый API для AI-приложений и агентов: он ищет страницы по смыслу запроса и сразу отдаёт их чистый текст, готовый для подачи в языковую модель.

Главное отличие от [[SerpApi]] — Exa не пересказывает выдачу Google, а использует свой индекс и нейросетевой поиск. Запрос «стартапы, которые делают AI для юристов» вернёт сайты таких компаний, а не статьи со словами из запроса.

### Возможности
- **Search API** в режимах Lite, Auto и Deep.
- **Contents:** полный текст, выдержки и краткое содержание страницы.
- **Answer:** ответ на вопрос с источниками.
- **Research API:** агент сам проводит многошаговое исследование.
- **Websets и мониторы** для сбора списков компаний и отслеживания новых страниц.

### Кому подходит
Разработчикам AI-агентов, RAG-систем и сервисов, которым нужен свежий веб в ответах модели.

### Как начать
Зарегистрируйтесь, получите API-ключ и бесплатные кредиты, сделайте первый запрос через Python- или JS-SDK. Exa подключается к [[LangChain]], [[Vercel AI SDK]] и через MCP к [[Claude (инструмент)|Claude]].

### Совет
Включайте в запрос описание страницы, которую ищете, а не ключевые слова: Exa лучше понимает «блог разработчика о миграции на Postgres», чем «postgres миграция».

### Ограничения
Русскоязычный веб покрыт слабее англоязычного. Оплата только зарубежной картой. Для поиска с готовым ответом в агентах есть [[Tavily]], для выгрузки страниц сайта — [[Firecrawl]].

## Частые вопросы
### Exa бесплатный?
Частично: на тарифе Starter дают $10 кредитов каждый месяц без привязки карты. Дальше оплата по факту использования.

### Работает ли Exa в России?
API отвечает из России без VPN, но пополнить баланс можно только зарубежной картой.

### Exa или Tavily?
[[Tavily]] проще подключить как поиск для агента с готовой выжимкой. Exa сильнее в смысловом поиске и сборе списков компаний и страниц.

### Можно ли подключить Exa к Claude?
Да, у Exa есть MCP-сервер: [[Claude (инструмент)|Claude]] и [[Cursor]] получают веб-поиск через него.
