## Описание

Express — это минималистичный веб-фреймворк для Node.js: он принимает HTTP-запросы, разбирает маршруты и отдаёт ответы. На нём пишут API, бэкенды сайтов и серверную часть приложений.

Главное отличие — минимум правил. Express не диктует структуру проекта: вы сами выбираете базу данных, шаблоны и авторизацию. Поэтому на нём построено множество других инструментов, включая [[NestJS]].

### Возможности
- **Маршрутизация:** обработчики для GET, POST и других методов по адресам.
- **Middleware:** цепочки функций для логирования, авторизации, парсинга JSON.
- **Тысячи пакетов** из npm: CORS, сессии, загрузка файлов, rate limit.
- **Шаблонизаторы** для серверного рендеринга страниц.
- **Express 5** с поддержкой async-функций и ошибок в промисах.

### Кому подходит
Разработчикам на JavaScript, которым нужен простой бэкенд: API для фронтенда, вебхуки ботов, прокси к сторонним сервисам.

### Как начать
Выполните `npm install express`, создайте файл с тремя строками: импорт, маршрут `app.get('/')` и `app.listen(3000)`. Запустите через `node` — сервер готов.

### Совет
С первого дня подключите валидацию входящих данных и обработчик ошибок: Express ничего не проверяет за вас, и большинство уязвимостей появляются из-за непроверенного ввода.

### Ограничения
Express не даёт архитектуры: в большом проекте без договорённостей в команде код быстро запутывается. Для крупного бэкенда со структурой берут [[NestJS]], для API на Python — [[FastAPI]].

## Частые вопросы
### Express бесплатный?
Да, это открытый проект под лицензией MIT. Платите только за сервер, где работает приложение.

### Работает ли Express в России?
Да, пакет ставится из npm без VPN, а сервер можно разместить на любом российском хостинге.

### Express или NestJS?
Express проще и подходит для небольших API. [[NestJS]] построен поверх Express и добавляет архитектуру с модулями и TypeScript для больших проектов.

### Подходит ли Express для Telegram-бота?
Да, на нём удобно принимать вебхуки от [[Telegram (инструмент)|Telegram]] и отвечать пользователю.
