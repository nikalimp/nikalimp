## Описание

FastAPI — это веб-фреймворк на Python для создания API: он строит маршруты по аннотациям типов, проверяет входящие данные и сам генерирует документацию.

Главное отличие от [[Django]] и Flask — скорость разработки и работы. Вы описываете модель данных один раз, а FastAPI проверяет запросы, сериализует ответы и показывает интерактивную документацию в [[Swagger]].

### Возможности
- **Валидация через Pydantic:** ошибка в запросе возвращается с понятным описанием.
- **Автодокументация** Swagger UI и ReDoc по адресу `/docs`.
- **Асинхронность:** async и await для быстрых запросов к базам и внешним API.
- **Внедрение зависимостей** для авторизации и подключения к базе.
- **Подсказки редактора** благодаря аннотациям типов.

### Кому подходит
Python-разработчикам, которые пишут API для сайтов, мобильных приложений и AI-сервисов. Фреймворк популярен у ML-инженеров, которые оборачивают модели в API.

### Как начать
Установите `pip install "fastapi[standard]"`, опишите маршрут в файле `main.py` и запустите `fastapi dev main.py`. Документация откроется по адресу `/docs`.

### Совет
Описывайте схемы ответов так же тщательно, как схемы запросов: фронтенд-разработчик получит точную документацию, а лишние поля из базы не утекут в API.

### Ограничения
FastAPI — только API: админки, шаблонов и ORM из коробки нет, их собирают из отдельных библиотек. Для сайта с админкой быстрее [[Django]], для API на JavaScript — [[Express]].

- Большой проект нужно структурировать самому

## Частые вопросы
### FastAPI бесплатный?
Да, это открытый проект под лицензией MIT. Платите только за хостинг API.

### Работает ли FastAPI в России?
Да, пакет ставится из PyPI без VPN, а API можно разместить на российском VPS.

### FastAPI или Django?
[[Django]] — полный фреймворк с админкой и ORM для сайтов. FastAPI — для быстрых API, особенно когда фронтенд отдельный или нужно отдать модель машинного обучения.

### Подходит ли FastAPI для AI-сервисов?
Да, это частый выбор: на FastAPI оборачивают модели и запросы к [[OpenAI API]] или [[Anthropic API]], а потоковые ответы работают через асинхронность.
