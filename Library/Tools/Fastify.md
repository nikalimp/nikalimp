## Описание

Fastify — это веб-фреймворк для Node.js, рассчитанный на высокую скорость и низкие накладные расходы. На нём пишут REST API, бэкенды сайтов и микросервисы.

Главное отличие — производительность и схемы. Fastify обрабатывает заметно больше запросов в секунду, чем [[Express]], а JSON-схемы маршрутов проверяют входящие данные и ускоряют сериализацию ответов.

### Возможности
- **Высокая скорость** обработки запросов и сериализации JSON.
- **JSON Schema** для валидации запросов и ответов.
- **Система плагинов** с изоляцией контекста: авторизация, CORS, загрузка файлов, Swagger.
- **Встроенный логгер Pino** с минимальными накладными расходами.
- **Поддержка TypeScript** и async/await из коробки.

### Кому подходит
Бэкенд-разработчикам на Node.js, которые пишут API с высокой нагрузкой, и командам, которые хотят строгую валидацию и документацию API по схемам.

### Как начать
Установите пакет `fastify`, создайте сервер, опишите первый маршрут со схемой ответа и запустите `listen`. Для генерации проекта есть `fastify-cli`.

### Совет
Описывайте схему ответа для каждого маршрута: Fastify использует её для быстрой сериализации и не отдаст клиенту лишние поля, например хеш пароля.

### Ограничения
Экосистема меньше, чем у Express, а часть middleware для Express требует адаптера. Для edge-сред и Cloudflare Workers удобнее [[Hono]], для крупных приложений с архитектурой из коробки — [[NestJS]], который может работать поверх Fastify.

## Вердикт
- Кому подходит: Бэкенд-разработчикам на Node.js, которым нужен быстрый API со строгой валидацией.
- Кому не подходит: Тем, кто пишет под edge-среды или хочет самую большую экосистему готовых middleware.
- Итог: Быстрый и строгий фреймворк для API на Node.js, современная замена Express.

## Частые вопросы
### Fastify бесплатный?
Да, это фреймворк с открытым кодом под лицензией MIT.

### Работает ли Fastify в России?
Да, пакет ставится из npm без VPN и аккаунта.

### Fastify или Express?
[[Express]] проще и имеет огромную экосистему. Fastify быстрее, проверяет данные по схемам и лучше подходит для новых проектов с нагрузкой.

### Можно ли использовать Fastify с NestJS?
Да, [[NestJS]] поддерживает Fastify как HTTP-движок вместо Express, это даёт прирост скорости без смены архитектуры.
