# Feather Icons

Буква: F · Страница на сайте: `/tools/feather-icons`

## Описание

Feather Icons — это бесплатный набор из 287 линейных иконок в стиле «тонкая обводка»: сетка 24×24, обводка 2 пикселя, скруглённые концы линий.

Главное отличие — минимализм и единый стиль: иконки рисовали под одну сетку, поэтому интерфейс выглядит аккуратно без доработки. Набор не обновляется с 2021 года, его развитие продолжил форк [[Lucide]].

### Возможности
- **287 иконок** для интерфейсов: стрелки, файлы, медиа, соцсети.
- **SVG-формат:** иконки меняют цвет и толщину линии через CSS.
- **npm-пакет** и готовые обёртки для [[React]] и [[Vue.js]].
- **Плагин для [[Figma]]** и скачивание отдельных иконок с сайта.
- **Лицензия MIT** без указания авторства.

### Кому подходит
Дизайнерам и разработчикам минималистичных интерфейсов, лендингов и прототипов, где хватает базового набора иконок.

### Как начать
Найдите иконку на feathericons.com и скачайте SVG или установите `npm install feather-icons`. В React удобнее пакет `react-feather`.

### Совет
Если иконок не хватает, переходите на [[Lucide]]: стиль тот же, а иконок больше 1500, так что интерфейс не придётся перерисовывать.

### Ограничения
Набор заморожен: новых иконок нет, современных логотипов и пиктограмм тоже. Для больших проектов берут [[Lucide]], [[Phosphor Icons]] или [[Tabler Icons]].

## Частые вопросы
### Feather Icons бесплатный?
Да, все иконки бесплатные под лицензией MIT, их можно использовать в коммерческих проектах без указания автора.

### Работает ли Feather Icons в России?
Да, сайт, GitHub и npm доступны без VPN.

### Feather Icons или Lucide?
[[Lucide]] — форк Feather с тем же стилем и в пять раз большим набором иконок, который активно обновляется. Для нового проекта лучше Lucide.

### Как поменять цвет иконки Feather?
Иконки используют `stroke="currentColor"`, поэтому цвет задаётся через CSS-свойство `color` у родительского элемента.
