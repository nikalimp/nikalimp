# Figma Code Connect

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Handoff и дизайн-системы · Global
Буква: F · Страница на сайте: `/tools/figma-code-connect`

## Описание

Figma Code Connect — это инструмент Figma, который связывает компоненты дизайн-системы в макете с реальными компонентами в коде, чтобы разработчик видел в Dev Mode готовый фрагмент из вашей библиотеки.

Главное отличие от обычного Dev Mode — вместо автоматически сгенерированного CSS разработчик видит код вашего компонента с правильными свойствами: `<Button variant="primary">`, а не набор стилей.

### Возможности
- **Связка компонентов:** вариант и свойства компонента в [[Figma]] сопоставляются с пропсами в коде.
- **Поддержка платформ:** React и React Native, HTML и веб-компоненты, SwiftUI, Jetpack Compose.
- **Два способа настройки:** CLI с файлами конфигурации в репозитории и визуальная настройка прямо в Figma.
- **Ссылки на исходники** компонентов в GitHub прямо из Dev Mode.
- **Контекст для ИИ:** MCP-сервер Figma передаёт связки агентам, и те генерируют код на ваших компонентах.

### Кому подходит
Командам с собственной дизайн-системой, где дизайнеры и разработчики используют одну библиотеку компонентов, например на [[shadcn ui|shadcn/ui]].

### Как начать
Установите CLI, авторизуйтесь токеном Figma, создайте файлы связок для ключевых компонентов и опубликуйте их командой `figma connect publish`.

### Совет
Начните с 10–15 самых частых компонентов: кнопка, поле, карточка, модальное окно. Это закрывает большую часть экранов, а связки для редких компонентов добавляйте по мере необходимости.

### Ограничения
Доступно только на дорогих тарифах. Связки нужно поддерживать при каждом изменении API компонентов. Для документации компонентов всё равно нужен [[Storybook]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: нет
- Платформы: Веб, Windows, macOS, API

## Вердикт
- Кому подходит: Продуктовым командам с дизайн-системой в коде и тарифом Figma Organization или Enterprise.
- Кому не подходит: Фрилансерам и небольшим студиям на бесплатном или Professional тарифе Figma.
- Итог: Мост между библиотекой в Figma и кодом, который сокращает ручной перенос макетов и помогает ИИ-агентам писать код на ваших компонентах.

## Плюсы
- Разработчик видит код вашей библиотеки, а не сгенерированный CSS
- Поддержка React, SwiftUI, Jetpack Compose и HTML
- Связки хранятся в репозитории рядом с компонентами
- Связки используются MCP-сервером Figma для ИИ-агентов

## Минусы
- Только на тарифах Organization и Enterprise
- Связки требуют поддержки при изменении компонентов
- Оплата Figma из России только через зарубежную карту

## Частые вопросы
### Code Connect бесплатный?
Нет, отдельного тарифа нет. Code Connect работает в Dev Mode на тарифах Figma Organization и Enterprise.

### Работает ли Figma Code Connect в России?
Figma открывается без VPN, но нужные тарифы оплачиваются только зарубежной картой.

### Code Connect или Storybook?
Это разные задачи. [[Storybook]] документирует и тестирует компоненты в коде, Code Connect показывает эти компоненты разработчику прямо в макете. Их используют вместе.

### Зачем Code Connect для ИИ-агентов?
MCP-сервер Figma передаёт агенту не только макет, но и связки с компонентами. Агент собирает экран из вашей библиотеки, а не пишет новую вёрстку с нуля.
