# Finsweet Attributes

## Описание

Finsweet Attributes — это бесплатная библиотека скриптов для [[Webflow]], которая добавляет фильтры, сортировку, подгрузку и другие функции через атрибуты элементов, без написания кода.

Главное отличие от платного [[Jetboost]] — библиотека открытая и бесплатная, работает на вашем сайте без внешнего сервиса и без лимитов по числу элементов.

### Возможности
- **Фильтры и поиск** по CMS-коллекциям с несколькими условиями.
- **Подгрузка:** «показать ещё», бесконечная прокрутка, пагинация без перезагрузки.
- **Вложенные коллекции:** вывод связанных элементов CMS внутри карточки.
- **Сортировка и объединение** нескольких коллекций в один список.
- **Интерфейсные решения:** аккордеоны, копирование в буфер, оглавление статьи, слайдеры.

### Кому подходит
Дизайнерам и разработчикам на Webflow, которым не хватает стандартных возможностей CMS для каталогов, блогов и порталов.

### Как начать
Подключите скрипт библиотеки в настройках сайта, добавьте нужным элементам атрибуты по документации и проверьте работу на опубликованной версии.

### Совет
Используйте вместе с методологией классов [[Client-First]] от той же команды: структура страницы будет понятна и атрибуты легче поддерживать.

### Ограничения
Фильтрация работает в браузере, поэтому на больших коллекциях падает скорость. Атрибуты работают только на опубликованном сайте, в редакторе Webflow результат не виден. Для сложной логики и данных из API лучше [[Wized]].

## Частые вопросы
### Finsweet Attributes бесплатный?
Да, библиотека бесплатная и открытая. Платить нужно только за сам Webflow.

### Работает ли Finsweet Attributes в России?
Да, скрипты подключаются с CDN и работают для посетителей из России без VPN.

### Finsweet Attributes или Jetboost?
[[Jetboost]] настраивается через интерфейс и работает как облачный сервис по подписке. Finsweet Attributes бесплатен, но требует аккуратной расстановки атрибутов.

### Влияет ли Finsweet Attributes на SEO?
Подгружаемые скриптом элементы поисковики видят хуже. Важные страницы держите доступными по прямым ссылкам и в карте сайта.
