## Описание

Firecrawl — сервис для превращения сайтов в чистые данные для AI. Он обходит страницы, выполняет JavaScript, убирает меню и рекламу и возвращает текст в Markdown или структурированный JSON, готовый для языковых моделей.

Firecrawl стал популярным инструментом разработчиков AI-агентов и RAG-систем, а также генераторов llms.txt.

### Возможности
- **Scrape** — одна страница в Markdown, HTML или JSON.
- **Crawl** — обход всего сайта.
- **Map** — список всех URL сайта.
- **Extract** — извлечение структурированных данных по схеме.
- **Search** — поиск в интернете с содержимым страниц.
- **Генерация llms.txt** для сайта.
- **Интеграции** с LangChain, n8n и MCP-сервер для AI-агентов.

### Кому подходит
Разработчикам AI-приложений и агентов, специалистам по автоматизации, GEO-специалистам, которые анализируют, как сайт выглядит для нейросетей.

### Как начать
Получите ключ, вставьте адрес своего сайта в песочницу и посмотрите результат в Markdown. Так видно, какой текст получает нейросеть со страницы.

### Как использовать в работе
Проверяйте сайт глазами AI: если после очистки Firecrawl на странице почти не осталось текста, нейросетям трудно использовать её как источник.

### Где особенно полезен
В GEO-аудитах и наполнении баз знаний для AI-ботов по сайтам компании.

### Совет
Соблюдайте правила сайтов и robots.txt при обходе чужих ресурсов.

### Ограничения
Кредиты быстро расходуются при обходе больших сайтов.

### Связка
Результат удобно передавать в n8n.

### Частый вопрос
**Firecrawl или Apify?** Firecrawl специализируется на данных для AI, [[Apify]] — на универсальном парсинге популярных площадок. Автоматизации собирают в [[n8n]] и [[LangChain]].

## Частые вопросы
### Firecrawl бесплатный?
Да, есть тариф Free: 1 000 кредитов в месяц без карты. Этого хватает примерно на 1 000 страниц. Платные тарифы начинаются с $19 в месяц.

### Можно ли использовать Firecrawl в России?
Облачную версию оплачивают зарубежной картой, открытую версию можно развернуть на своём сервере.

### Что лучше, Firecrawl или Apify?
Firecrawl проще, если нужен чистый текст для нейросетей. Apify подходит для сложных сценариев с готовыми парсерами.

### Что делает Firecrawl?
Превращает страницы сайтов в Markdown или структурированные данные через API.
