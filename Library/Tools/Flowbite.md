## Описание

Flowbite — это библиотека готовых UI-компонентов на [[Tailwind CSS]]: кнопки, формы, модальные окна, навигация, таблицы и целые секции страниц с минимальным JavaScript для интерактива.

Главное отличие от [[shadcn ui|shadcn/ui]] — независимость от фреймворка. Компоненты Flowbite работают в чистом HTML, а для [[React]], [[Vue.js]], Svelte и Angular есть отдельные версии.

### Возможности
- **Сотни компонентов** на классах Tailwind CSS.
- **Интерактив без зависимостей:** выпадающие меню, вкладки, модалки на небольшом скрипте.
- **Версии для фреймворков:** React, Vue, Svelte, Angular, Laravel.
- **Дизайн-система в [[Figma]]** с теми же компонентами.
- **Тёмная тема** во всех компонентах.

### Кому подходит
Разработчикам на Tailwind CSS, которым нужен готовый интерфейс для админки, лендинга или прототипа без проектирования каждого элемента.

### Как начать
Установите `npm install flowbite`, подключите плагин в конфиг Tailwind CSS и скопируйте разметку нужного компонента из документации.

### Совет
Берите разметку Flowbite как основу и сразу переносите цвета и отступы в токены своего проекта: так интерфейс не будет выглядеть шаблонно.

### Ограничения
Компоненты узнаваемы, без доработки сайт выглядит типовым. Доступность у части интерактивных элементов слабее, чем у [[Headless UI]] или [[shadcn ui|shadcn/ui]] на Radix.

## Частые вопросы
### Flowbite бесплатный?
Да, базовая библиотека бесплатная под лицензией MIT. Расширенные блоки и Figma-файлы продаются в Pro разовой покупкой.

### Работает ли Flowbite в России?
Да, бесплатная версия ставится из npm без VPN. Для покупки Pro нужна зарубежная карта.

### Flowbite или shadcn/ui?
[[shadcn ui|shadcn/ui]] — компоненты для React, которые копируются в проект и правятся как свой код. Flowbite подходит, если проект не на React или нужен чистый HTML.

### Flowbite или DaisyUI?
[[DaisyUI]] даёт короткие классы вроде `btn` поверх Tailwind CSS. Flowbite предлагает готовую разметку компонентов и секций со скриптами для интерактива.
