# Font Awesome

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Иконки · Global
Буква: F · Страница на сайте: `/tools/font-awesome`

## Описание

Font Awesome — библиотека иконок для сайтов и интерфейсов: тысячи значков в виде шрифта, SVG и компонентов для React, Vue и Angular.

Главное отличие — популярность и простота подключения. Иконки ставятся одной строкой через CDN-кит, а бесплатный набор знаком почти каждому разработчику.

### Возможности
- **Бесплатный набор** — около двух тысяч иконок и логотипов брендов.
- **Pro-стили** — тонкие, лёгкие, дуотон, резкие варианты.
- **Киты** — подключение только нужных иконок через CDN.
- **Пакеты для [[React]], [[Vue.js]]**, Angular и npm.
- **Загрузка собственных иконок** в кит на платных тарифах.

### Кому подходит
Разработчикам сайтов и админок, которым нужны понятные иконки без поиска по разным источникам, и пользователям [[Bootstrap]] и [[WordPress (инструмент)|WordPress]].

### Как начать
Создайте бесплатный кит на сайте, подключите скрипт в шаблон и вставляйте иконки тегом i с нужным классом. В React используйте пакет @fortawesome/react-fontawesome.

### Совет
Подключайте иконки как SVG и только нужные, а не весь шрифт целиком. Так страница загружается быстрее, а иконки остаются чёткими.

### Ограничения
Стиль бесплатного набора узнаваем и встречается на тысячах сайтов. Для современного интерфейса многие выбирают более лёгкие наборы, например в [[shadcn ui|shadcn/ui]] по умолчанию идут иконки Lucide.

## Частые вопросы
### Font Awesome бесплатный?
Да, бесплатный набор можно использовать в коммерческих проектах. Pro-иконки и дополнительные стили — по годовой подписке.

### Работает ли Font Awesome в России?
Да, сайт и CDN работают без VPN. Для оплаты Pro нужна зарубежная карта.

### Чем заменить Font Awesome?
Бесплатные альтернативы — Lucide, Heroicons и Tabler Icons. Большие коммерческие библиотеки — [[Icons8]] и [[Flaticon]].

### Нужно ли указывать авторство Font Awesome?
Для бесплатного набора авторство указывается в лицензии внутри файлов. Ссылка на сайте не требуется.
