# Font Squirrel

Буква: F · Страница на сайте: `/tools/font-squirrel`

## Описание

Font Squirrel — каталог бесплатных шрифтов с лицензией на коммерческое использование: их можно ставить в макеты, логотипы, на сайты и в печать.

Главное отличие от случайных «бесплатных» сайтов: команда проверяет лицензию каждого шрифта и указывает в карточке, где его можно использовать.

### Возможности
- **Каталог с фильтрами** по классификации, тегам и языкам, включая кириллицу.
- **Карточка лицензии:** отметки для десктопа, веба, электронных книг и приложений.
- **Webfont Generator** превращает TTF/OTF в WOFF и WOFF2 с CSS для подключения на сайт.
- **Matcherator** определяет шрифт по картинке.
- **Скачивание пакетом** со всеми начертаниями.

### Кому подходит
Дизайнерам и верстальщикам, которым нужен шрифт без юридических рисков: для лендинга, презентации, упаковки или брендинга небольшой компании.

### Как пользоваться
Откройте раздел Find Fonts, включите фильтр по языку Cyrillic, выберите шрифт и проверьте вкладку License. Затем скачайте OTF или прогоните файлы через Webfont Generator.

### Совет
Перед загрузкой шрифта в генератор убедитесь, что лицензия разрешает веб-встраивание: генератор просит это подтвердить. Для сайта подключайте только нужные начертания, чтобы не тормозить загрузку.

### Ограничения
Кириллических шрифтов меньше, чем латинских. Каталог обновляется медленно, а часть результатов ведёт на платные шрифты MyFonts. Для подбора пар удобнее [[Google Fonts]] или [[Fontshare]].

## Частые вопросы
### Font Squirrel бесплатный?
Да. Шрифты из основного каталога бесплатны и разрешены для коммерческих проектов, регистрация не нужна.

### Работает ли Font Squirrel в России?
Да, сайт открывается без VPN, скачивание не требует оплаты.

### Font Squirrel или Google Fonts?
[[Google Fonts]] удобнее для веба: шрифты подключаются одной строкой и в каталоге больше кириллицы. Font Squirrel полезен лицензиями для печати и генератором веб-шрифтов.

### Можно ли использовать шрифты Font Squirrel в логотипе?
В большинстве случаев да, но проверьте вкладку License у конкретного шрифта: у некоторых есть оговорки.
