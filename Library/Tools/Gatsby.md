## Описание

Gatsby — фреймворк на [[React]] для статических сайтов: собирает страницы заранее из Markdown, CMS и API и отдаёт быстрый HTML.

Главное: Gatsby был одним из первых популярных генераторов на React, но после покупки компанией Netlify в 2023 году развивается медленно. Для новых проектов чаще выбирают [[Next.js]] или Astro.

### Возможности
- **Сборка статики** с предзагрузкой страниц и оптимизацией картинок.
- **GraphQL-слой данных:** один запрос к Markdown, [[Contentful]], WordPress и другим источникам.
- **Тысячи плагинов** для SEO, изображений, аналитики и CMS.
- **Стартеры** для блогов, документации и портфолио.

### Кому подходит
Командам, которые поддерживают существующий сайт на Gatsby, и разработчикам, которым нужен статический сайт на React с готовыми плагинами для headless CMS.

### Как пользоваться
Выполните `npm init gatsby`, выберите CMS и плагины, запустите `gatsby develop`. Для продакшена соберите `gatsby build` и выложите папку `public` на хостинг.

### Совет
Если сайт на Gatsby уже работает, не спешите переписывать его, но новые проекты начинайте на Next.js или [[Eleventy]]: у них активнее разработка и экосистема.

### Ограничения
Долгие сборки на больших сайтах, сложная связка плагинов и редкие обновления. Часть плагинов перестала поддерживаться, а Gatsby Cloud закрыт.

## Вердикт
- Кому подходит: Разработчикам, которые поддерживают сайт на Gatsby или любят GraphQL-слой данных для контентных сайтов.
- Кому не подходит: Тем, кто начинает новый проект и хочет активную экосистему и серверный рендеринг.
- Итог: Бесплатный и рабочий генератор статики на React, который уступил место Next.js и Astro.

## Частые вопросы
### Gatsby бесплатный?
Да, фреймворк открытый и бесплатный. Платите только за хостинг, на котором размещаете готовый сайт.

### Работает ли Gatsby в России?
Да, установка через npm и сборка работают без VPN, а сайт размещается на любом российском хостинге.

### Gatsby или Next.js?
[[Next.js]] активнее развивается и умеет серверный рендеринг, Gatsby проще для чисто статических сайтов на GraphQL, но новых функций почти не получает.

### Жив ли Gatsby в 2026 году?
Фреймворк доступен и работает, но обновляется редко, а Gatsby Cloud закрыт. Для новых проектов его выбирают всё реже.

## Цена

## Доступность из России

Работает из России: пакеты ставятся через npm без VPN, готовый сайт можно разместить на российском хостинге как обычную статику.
