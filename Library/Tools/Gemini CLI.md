# Gemini CLI

Буква: G · Страница на сайте: `/tools/gemini-cli`

## Описание

Gemini CLI — открытый ИИ-агент от Google для терминала: читает проект, пишет и правит код, запускает команды и работает с файлами на моделях Gemini.

Главное, что важно знать в 2026 году: Google переводит пользователей на новый Antigravity CLI. С 18 июня 2026 года Gemini CLI перестал обслуживать бесплатных пользователей и подписчиков Google AI Pro и Ultra, но работает с платными ключами API и в корпоративных тарифах.

### Возможности
- **Агент в терминале:** план, правки в нескольких файлах, запуск тестов и команд.
- **Большой контекст** моделей Gemini для работы с крупными репозиториями.
- **MCP-серверы** для подключения внешних инструментов и данных.
- **Файл GEMINI.md** с правилами проекта.
- **Открытый код** под Apache 2.0.

### Кому подходит
Командам на Google Cloud с корпоративным Gemini Code Assist и разработчикам с платным ключом API, у которых уже настроены скрипты и CI вокруг Gemini CLI.

### Как начать
Установите `npm install -g @google/gemini-cli`, задайте переменную `GEMINI_API_KEY` с платным ключом и запустите `gemini` в папке проекта.

### Совет
Если вы начинаете с нуля, сразу выбирайте Antigravity CLI или альтернативы вроде [[OpenAI Codex]] и [[Cursor]]: новые модели Gemini Google оптимизирует уже под Antigravity.

### Ограничения
Бесплатного доступа больше нет, развитие сместилось в Antigravity, из России нужны VPN и зарубежная карта.

## Вердикт
- Кому подходит: Командам с корпоративным Gemini Code Assist и тем, кто уже встроил Gemini CLI в свои процессы.
- Кому не подходит: Новым пользователям и тем, кто рассчитывал на бесплатный лимит через Google-аккаунт.
- Итог: Открытый терминальный агент Google, который уступает место Antigravity CLI и больше не бесплатен для частных пользователей.

## Частые вопросы
### Gemini CLI бесплатный?
Сам инструмент открытый, но бесплатный доступ к моделям через Google-аккаунт отключили 18 июня 2026 года. Теперь нужен платный ключ API или корпоративный тариф.

### Работает ли Gemini CLI в России?
Только через VPN, а платный ключ API требует зарубежную карту.

### Gemini CLI или Claude Code?
Claude Code активно развивается и работает по подписке Claude, а Gemini CLI Google заменяет на Antigravity CLI. Для новых проектов разумнее выбирать активно поддерживаемый агент, например [[OpenAI Codex]] или [[Cursor]].

### Чем заменить Gemini CLI?
Google рекомендует Antigravity CLI. Среди альтернатив — [[OpenAI Codex]], [[Cursor]] и [[GitHub Copilot]].

## Цена

Сам инструмент открытый и бесплатный, но с 18 июня 2026 года бесплатный вход через Google-аккаунт и подписки Google AI Pro и Ultra больше не обслуживаются. Работать можно через платный ключ Gemini API с оплатой за токены или корпоративный Gemini Code Assist.


## Доступность из России

Сервисы Gemini недоступны из России без VPN, а платный API-ключ требует зарубежную карту. Российская альтернатива для кода — GigaCode от Сбера.
