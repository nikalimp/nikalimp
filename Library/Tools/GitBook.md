## Описание

GitBook — платформа для технической и продуктовой документации. В ней пишут справочные центры, документацию API, внутренние базы знаний и руководства, а публикуют как аккуратный сайт с поиском.

GitBook связывает документацию с Git: тексты можно синхронизировать с репозиторием на GitHub и редактировать как код.

### Возможности
- **Блочный редактор** с поддержкой кода, таблиц и вкладок.
- **Синхронизация с GitHub и GitLab.**
- **Опубликованная документация** на своём домене.
- **Поиск и AI-ответы** по документации.
- **Документация API** из OpenAPI.
- **Версии и ветки** изменений.
- **Аналитика** просмотров.

### Кому подходит
SaaS-компаниям и разработчикам, которые ведут документацию продукта и API, командам, которым нужна аккуратная база знаний.

### Как начать
Создайте пространство, импортируйте существующие документы или подключите репозиторий. Организуйте структуру по сценариям пользователя, а не по устройству продукта.

### Как использовать в работе
Включите AI-поиск по документации: пользователи получают ответ на вопрос сразу, а не листают десяток страниц.

### Где особенно полезен
В продуктах для разработчиков и B2B-сервисах: хорошая документация снижает нагрузку на поддержку.

### Документация и GEO
Нейросети активно используют документацию как источник ответов о продуктах. Структурированные справочные страницы с понятными заголовками повышают шанс, что AI-ассистент правильно расскажет о вашем сервисе.

### Совет
Обновляйте документацию вместе с релизом: устаревшая справка вредит больше, чем её отсутствие.

### Кому не подойдёт
Небольшим проектам без документации продукта.

### Частый вопрос
**GitBook или Notion для документации?** [[Notion]] проще для внутренних заметок, GitBook — для публичной документации и связки с кодом. Схемы для документации рисуют в [[draw.io]] и [[Excalidraw]].

## Частые вопросы
### Сколько стоит GitBook?
Есть бесплатный план для одного человека, Essential стоит $65 в месяц за сайт, Ultimate — $249 (при оплате за год), плюс $12 за каждого участника.

### Работает ли GitBook в России?
Оплата российскими картами недоступна, поэтому для платного тарифа нужна зарубежная карта.

### Что лучше: GitBook или Docusaurus?
GitBook удобнее для команд без разработчиков, Docusaurus бесплатен и даёт полный контроль над кодом. Выбирайте по тому, кто пишет документацию.

### Для чего нужен GitBook?
Для публикации документации, базы знаний и справки к продукту. Контент можно хранить в GitHub и править в визуальном редакторе.
