## Описание

GitFlic — российский сервис для хранения кода на git с CI/CD, реестром пакетов и инструментами командной работы, в облаке и для установки на своих серверах.

Главное отличие: GitFlic — отечественная замена [[GitHub]] и [[GitLab]] из реестра российского ПО, поэтому его выбирают госкомпании и бизнес, которому важна российская юрисдикция кода.

### Возможности
- **Git-репозитории** с ветками, мерж-реквестами и код-ревью.
- **CI/CD:** конвейеры сборки, тестов и деплоя.
- **Реестр пакетов** и контейнеров для npm, Maven, Docker и других форматов.
- **Задачи и вики** для ведения проекта.
- **Импорт** репозиториев с GitHub и GitLab.
- **Self-hosted версии** для установки в закрытом контуре компании.

### Кому подходит
Компаниям с требованиями импортозамещения, госсектору, командам, которые хотят держать код на российских серверах, и разработчикам, которые ищут запасную площадку для репозиториев.

### Как начать
Зарегистрируйтесь на gitflic.ru, импортируйте репозиторий с GitHub или GitLab и добавьте SSH-ключ. Для CI создайте конфигурационный файл конвейера в корне проекта.

### Совет
Настройте зеркалирование важных репозиториев с GitHub на GitFlic: если доступ к зарубежному сервису ограничат, код и история останутся под рукой.

### Ограничения
Сообщество и выбор интеграций меньше, чем у GitHub. Open source-проектов на площадке мало. Для публичных проектов с международной аудиторией по-прежнему удобнее GitHub.

## Частые вопросы
### GitFlic бесплатный?
Облачная версия бесплатна для разработчиков. Версии для установки на своих серверах продаются по запросу.

### Работает ли GitFlic в России?
Да, это российский сервис: работает без VPN и входит в реестр российского ПО.

### GitFlic или GitHub?
[[GitHub]] даёт огромное сообщество и экосистему, GitFlic — российскую юрисдикцию и соответствие требованиям импортозамещения. Многие команды держат зеркала на обеих площадках.

### Можно ли перенести репозиторий с GitHub на GitFlic?
Да, в GitFlic есть импорт репозиториев с GitHub и GitLab с сохранением истории коммитов.
