## Описание

GitHub Actions — встроенная в [[GitHub]] система CI/CD: она автоматически запускает тесты, сборку и деплой при пуше, пул-реквесте или по расписанию.

Главное отличие: Actions живёт прямо в репозитории — сценарии описываются в YAML-файлах рядом с кодом, а для типовых задач есть тысячи готовых действий в Marketplace.

### Возможности
- **Триггеры:** пуш, пул-реквест, релиз, расписание или ручной запуск.
- **Раннеры GitHub** на Linux, Windows и macOS или собственные серверы.
- **Marketplace:** готовые действия для деплоя на [[Vercel]], хостинги, Docker и облака.
- **Матрица сборок:** тест на нескольких версиях языка и ОС одновременно.
- **Секреты и окружения** для ключей и паролей.
- **Кэш и артефакты** для ускорения сборок и хранения результатов.

### Кому подходит
Разработчикам и командам, которые хранят код на GitHub и хотят автоматизировать тесты, сборку и выкладку без отдельного CI-сервиса.

### Как начать
Создайте в репозитории папку `.github/workflows` и добавьте YAML-файл из шаблонов на вкладке Actions. Ключи доступа к хостингу сохраните в секретах репозитория.

### Совет
Включите кэширование зависимостей и запускайте тяжёлые задачи только при изменении нужных папок через фильтр `paths`. Это экономит минуты и ускоряет проверку пул-реквестов.

### Ограничения
Приватные проекты быстро расходуют бесплатный лимит, особенно на macOS-раннерах. Из России оплатить сверхлимит сложно. Российская альтернатива с CI/CD — [[GitFlic]], зарубежная — [[GitLab]].

## Частые вопросы
### GitHub Actions бесплатный?
Для публичных репозиториев — да. Для приватных в бесплатный план GitHub входит около 2 000 минут Linux в месяц, а собственные раннеры не расходуют лимит.

### Работает ли GitHub Actions в России?
Да, в рамках бесплатного лимита работает без VPN. Платные минуты и тарифы оплачиваются только зарубежной картой.

### GitHub Actions или GitLab CI?
Actions удобнее, если код уже на GitHub, и выигрывает за счёт Marketplace. [[GitLab]] CI сильнее в self-hosted установках и встроенных инструментах DevOps.

### Как задеплоить сайт через GitHub Actions?
Добавьте workflow, который собирает проект и выкладывает файлы на хостинг по SSH или FTP, либо используйте готовое действие для [[Vercel]] или [[Cloudflare Pages]].
