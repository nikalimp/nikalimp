## Описание

GitHub Desktop — бесплатный графический клиент Git от GitHub для Windows и macOS: коммиты, ветки и пул-реквесты без командной строки.

Главное отличие от [[GitKraken]] и [[Sourcetree]]: GitHub Desktop проще и сделан для ежедневной рутины — изменения, коммит, пуш — с тесной связкой с [[GitHub]].

### Возможности
- **Наглядный дифф** изменений по строкам с выбором, что включить в коммит.
- **Ветки и слияния** в пару кликов.
- **Перетаскивание коммитов** для cherry-pick, squash и смены порядка.
- **Stash** незавершённых изменений.
- **Пул-реквесты:** создание и просмотр статуса проверок.

### Кому подходит
Дизайнерам, верстальщикам, контент-менеджерам и начинающим разработчикам, которым нужно работать с репозиторием сайта без изучения команд Git.

### Как начать
Скачайте приложение, войдите в аккаунт GitHub, клонируйте репозиторий и откройте его в редакторе кнопкой Open in Visual Studio Code.

### Совет
Перед каждым коммитом смотрите дифф и снимайте галочки с лишних файлов: так в репозиторий не попадут временные файлы и секреты.

### Ограничения
Нет визуального графа веток, интерактивного rebase и работы с несколькими репозиториями сразу. Версии для Linux нет, есть только неофициальные сборки.

## Частые вопросы
### GitHub Desktop бесплатный?
Да, полностью бесплатный и с открытым кодом.

### Работает ли GitHub Desktop в России?
Да, приложение скачивается и работает без VPN.

### GitHub Desktop или GitKraken?
[[GitKraken]] показывает граф веток и умеет больше, но приватные репозитории в нём платные. GitHub Desktop проще и бесплатен полностью.

### Работает ли GitHub Desktop с GitLab?
Да, приложение работает с любым Git-репозиторием, но функции пул-реквестов доступны только для GitHub.
