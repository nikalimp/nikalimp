## Описание

GitHub Pages — бесплатный хостинг статических сайтов прямо из репозитория [[GitHub]]. Подходит для портфолио, документации и простых лендингов.

Главное отличие — сайт живёт рядом с кодом: вы пушите изменения в ветку, и через минуту они на сайте.

### Возможности
- **Сайт из репозитория:** публикация из ветки или через [[GitHub Actions]].
- **Свой домен** и бесплатный HTTPS.
- **Jekyll из коробки,** а через Actions — любой генератор: [[Vite]], Astro, Hugo.
- **Сайт пользователя** на адресе имя.github.io и отдельные сайты проектов.

### Кому подходит
Разработчикам и дизайнерам для портфолио, документации к проектам и простых лендингов без серверной логики. Сервис удобен и для учебных проектов: сайт обновляется вместе с кодом, отдельный хостинг не нужен.

### Как начать
Создайте репозиторий, положите index.html, откройте Settings → Pages и выберите ветку. Сайт появится на адресе имя.github.io.

### Совет
Собирайте сайт через GitHub Actions, а не встроенный Jekyll: так нет лимита в 10 сборок в час и можно использовать любой фреймворк.

### Ограничения
Только статика: нет серверных функций и форм без сторонних сервисов. Размер сайта — до 1 ГБ, мягкий лимит трафика — 100 ГБ в месяц. Коммерческие магазины размещать запрещено. Для серверной логики выбирайте [[Vercel]] или [[Cloudflare Pages]].

## Вердикт
- Кому подходит: Тем, кто держит код на GitHub и хочет бесплатно опубликовать портфолио или документацию.
- Кому не подходит: Проектам с формами, авторизацией и серверной логикой, интернет-магазинам.
- Итог: Самый простой бесплатный способ опубликовать статический сайт, если код уже на GitHub.

## Плюсы
- Бесплатно для публичных репозиториев
- Свой домен и HTTPS без доплат
- Работает из России без VPN
- Любой генератор через GitHub Actions

## Частые вопросы
### GitHub Pages бесплатный?
Да, для публичных репозиториев. Для сайта из приватного репозитория нужен платный тариф GitHub.

### Работает ли GitHub Pages в России?
Да, GitHub и сайты на github.io открываются из России без VPN.

### GitHub Pages или Cloudflare Pages?
GitHub Pages проще, если код уже на [[GitHub]]. [[Cloudflare Pages]] даёт серверные функции и больше сборок, но в России его трафик замедляют.

### Какие лимиты у GitHub Pages?
Сайт до 1 ГБ, мягкий лимит трафика 100 ГБ в месяц и 10 сборок в час, если не использовать GitHub Actions.
