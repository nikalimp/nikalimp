## Описание

GitHub — крупнейшая платформа для хранения кода и совместной разработки. Она построена на системе контроля версий Git и добавляет к ней удобный интерфейс, задачи, обсуждения, автоматизацию и AI-инструменты.

GitHub запустили в 2008 году, в 2018 году его купила Microsoft. На платформе хранятся миллионы проектов с открытым кодом и приватные репозитории компаний по всему миру.

### Возможности
- **Репозитории** с историей изменений.
- **Пулл-реквесты** и ревью кода.
- **Issues и Projects** — задачи и доски.
- **GitHub Actions** — автоматическая сборка, тесты и деплой.
- **GitHub Pages** — бесплатный хостинг статических сайтов.
- **Codespaces** — среда разработки в браузере.
- **Copilot** — AI-помощник для кода.

### Кому подходит
Разработчикам, командам и всем, кто работает с кодом или текстами в Git. Дизайнерам и маркетологам GitHub тоже пригодится: в нём удобно хранить сайт, документацию и даже базу знаний.

### Как начать
Создайте аккаунт, установите GitHub Desktop, если не хотите работать в терминале, и создайте первый репозиторий. Сохраняйте изменения небольшими коммитами с понятными сообщениями.

### Автоматический деплой
Связка «репозиторий + Actions» позволяет выкладывать сайт при каждом изменении. Так работает nikalimp.ru: правка текста в заметке попадает в GitHub, Actions собирает сайт и отправляет его на хостинг.

### Совет
Не храните в репозитории пароли, токены и ключи. Для них есть Secrets в настройках репозитория. Если секрет попал в историю, считайте его скомпрометированным и замените.

### Российские альтернативы
Для компаний, которым важно хранить код в России, есть GitVerse от Сбера и GitFlic.

### Частый вопрос
**GitHub или GitLab?** GitHub популярнее и сильнее в open source и AI-инструментах, GitLab чаще выбирают для самостоятельной установки в компании. AI для кода — в обзорах [[GitHub Copilot]] и [[Cursor]], редактор — [[VS Code]].

## Вердикт
- Кому подходит: Всем, кто хранит код и работает над ним с другими: от одиночек до больших команд.
- Кому не подходит: Тем, кому нужен российский сервис с оплатой в рублях и без риска блокировок.
- Итог: GitHub — стандарт для хранения кода и совместной работы; для большинства задач хватает бесплатного тарифа.

## Плюсы
- Бесплатные публичные и приватные репозитории без лимита по числу
- 2 000 минут CI/CD в месяц на бесплатном тарифе
- Issues, Projects, Pull Requests и Actions в одном месте
- Огромное сообщество и открытые проекты

## Частые вопросы
### Сколько стоит GitHub и есть ли бесплатный тариф?
Бесплатный тариф есть и включает неограниченные публичные и приватные репозитории. Team стоит $4 за пользователя в месяц, Enterprise — $21.

### Работает ли GitHub в России?
Бесплатные аккаунты работают, но оплатить платный тариф российской картой нельзя. Для компаний под санкциями доступ может быть ограничен.

### Что лучше: GitHub или GitLab?
GitHub популярнее и лучше подходит для открытых проектов и сообщества. GitLab сильнее, когда нужен полный DevOps-набор и установка на свой сервер.

### Что такое GitHub простыми словами?
Это сайт, где хранят код и историю его изменений. В нём команда обсуждает правки, проверяет их и выкладывает проект.
