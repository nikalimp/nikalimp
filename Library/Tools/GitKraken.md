## Описание

GitKraken — кроссплатформенный графический клиент Git с наглядным графом веток, редактором конфликтов и интеграцией с GitHub, GitLab, Bitbucket и Azure DevOps.

Главное отличие от [[GitHub Desktop]]: GitKraken показывает всю историю репозитория в виде цветного графа и умеет сложные операции — интерактивный rebase, worktrees, работу с несколькими репозиториями.

### Возможности
- **Граф коммитов и веток** с перетаскиванием для merge и rebase.
- **Редактор конфликтов** слияния с выбором строк из обеих версий.
- **Пул-реквесты и задачи** из [[GitHub]], [[GitLab]] и Jira прямо в клиенте.
- **Рабочие пространства** для группы репозиториев.
- **GitLens** для [[VS Code]] и CLI в одной подписке.

### Кому подходит
Разработчикам и командам, которые работают с несколькими ветками и репозиториями одновременно и хотят видеть историю, а не держать её в голове.

### Как начать
Скачайте клиент для Windows, macOS или Linux, войдите через аккаунт GitHub или GitLab, откройте репозиторий и изучите граф: все операции доступны из контекстного меню.

### Совет
Для разбора конфликтов используйте встроенный редактор слияния: он показывает обе версии и результат рядом, а это быстрее, чем править маркеры конфликтов вручную.

### Ограничения
На бесплатном плане приватные репозитории недоступны. Приложение на Electron тяжелее нативных клиентов вроде [[Sourcetree]], а цены на сайте видны не во всех регионах.

## Частые вопросы
### GitKraken бесплатный?
Да, но бесплатный план работает только с локальными и публичными репозиториями. Для приватных нужна подписка.

### Работает ли GitKraken в России?
Приложение работает без VPN, но платную подписку можно оплатить только зарубежной картой.

### GitKraken или Sourcetree?
[[Sourcetree]] бесплатный, в том числе для приватных репозиториев, но без Linux-версии. GitKraken удобнее и красивее, но платный.

## Цена

Бесплатный план работает только с локальными и публичными репозиториями. Для приватных репозиториев нужны платные тарифы Pro, Advanced или Business — ориентировочно от $5 за пользователя в месяц при оплате за год, есть пробный период 14 дней.


## Доступность из России

Приложение скачивается и работает из России, но платные тарифы оплачиваются только зарубежной картой. Бесплатные аналоги для приватных репозиториев — GitHub Desktop и Sourcetree.
