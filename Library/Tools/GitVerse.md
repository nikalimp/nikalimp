# GitVerse

[[Инструменты — Веб-разработка|Веб-разработка]] · Git и командная разработка · Россия и СНГ
Буква: G · Страница на сайте: `/tools/gitverse`

## Описание

GitVerse — российская платформа для хостинга Git-репозиториев и совместной разработки от Сбера с ИИ-помощником GigaCode, CI/CD и облачной средой разработки.

Главное отличие от [[GitHub]]: данные хранятся в России, нет риска блокировки аккаунта из-за санкций, а ИИ-помощник и облачная IDE встроены в платформу.

### Возможности
- **Публичные и приватные репозитории** с импортом и зеркалированием с GitHub и [[GitLab]].
- **GigaCode** — ИИ-автодополнение кода для десятков языков.
- **CI/CD** с готовыми сценариями сборки и деплоя.
- **GigaIDE:** десктопная на базе IntelliJ и облачная на базе VS Code.
- **Трекер задач, вики и реестр артефактов** для npm, Maven и Docker с зеркалами внешних реестров.

### Кому подходит
Российским командам и компаниям, которым важно хранить код в России, а также разработчикам, которые хотят резервную копию репозиториев на случай ограничений GitHub.

### Как начать
Войдите через Сбер ID, импортируйте репозиторий с GitHub по ссылке и включите зеркалирование, чтобы изменения подтягивались автоматически.

### Совет
Настройте зеркало ключевых репозиториев с GitHub даже если основная работа идёт там: при блокировке доступа код и история останутся под рукой.

### Ограничения
Сообщество и каталог открытых проектов намного меньше, чем у GitHub. Сторонних интеграций мало, а вход завязан на Сбер ID. Альтернатива — [[GitFlic]].

## Вердикт
- Кому подходит: Российским командам, которым нужно хранить код в РФ и иметь встроенный ИИ-помощник.
- Кому не подходит: Open-source проектам, которым важны сообщество и интеграции GitHub.
- Итог: Российская замена GitHub с ИИ, CI/CD и облачной IDE, но с маленьким сообществом.

## Плюсы
- Бесплатный хостинг публичных и приватных репозиториев
- Данные в России, без санкционных рисков
- Встроенный ИИ-помощник GigaCode
- Импорт и зеркалирование с GitHub и GitLab

## Минусы
- Маленькое сообщество и мало открытых проектов
- Вход только через Сбер ID
- Меньше интеграций, чем у GitHub

## Частые вопросы
### GitVerse бесплатный?
Да, хостинг репозиториев бесплатный. Платить нужно за облачные ресурсы для сборки и деплоя, если они нужны.

### Работает ли GitVerse в России?
Да, это российская платформа Сбера: работает без VPN, данные хранятся в России.

### GitVerse или GitFlic?
Обе платформы российские. [[GitFlic]] появился раньше и ориентирован на компании, GitVerse даёт ИИ-помощник GigaCode и облачную IDE от Сбера.

### Можно ли перенести репозиторий с GitHub в GitVerse?
Да, через импорт по ссылке. Можно включить зеркалирование, чтобы изменения подтягивались автоматически.
