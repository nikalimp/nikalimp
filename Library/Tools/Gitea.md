## Описание

Gitea — это лёгкий сервер Git с открытым исходным кодом, который ставят на свой сервер, чтобы хранить репозитории, вести задачи и ревью кода без [[GitHub]].

Главное отличие — минимальные требования. Gitea написана на Go, запускается одним бинарным файлом и работает даже на дешёвом VPS или Raspberry Pi.

### Возможности
- **Репозитории и ревью:** pull request, ревью кода, защита веток.
- **Задачи и проекты:** issues, метки, вехи, канбан-доски.
- **Gitea Actions:** CI/CD, совместимый с синтаксисом [[GitHub Actions]].
- **Реестр пакетов:** npm, Docker, Maven и другие форматы.
- **Зеркала** репозиториев с GitHub и [[GitLab]].

### Кому подходит
Небольшим командам и студиям, которым нужен свой Git-сервер на российском VPS или в закрытом контуре.

### Как начать
Запустите Gitea в Docker или бинарным файлом, подключите базу данных и создайте организацию. Настройте раннер Actions, если нужен CI.

### Совет
Настройте зеркалирование важных репозиториев с GitHub в Gitea. Так у вас будет резервная копия кода на своём сервере.

### Ограничения
Обновления, бэкапы и безопасность сервера — ваша забота. Экосистема Actions меньше, чем у GitHub. В 2022 году часть сообщества ушла в форк Forgejo из-за смены модели управления.

## Частые вопросы
### Gitea бесплатная?
Да, версия для своего сервера бесплатная. Платные — только облачный хостинг и Enterprise.

### Работает ли Gitea в России?
Да, если ставить на свой сервер: зарубежные платежи и VPN не нужны. Облачные российские варианты — [[GitFlic]] и [[GitVerse]].

### Gitea или GitLab?
[[GitLab]] мощнее, но требует много памяти. Gitea работает на дешёвом VPS и проще в обслуживании.

### Можно ли перенести репозитории с GitHub в Gitea?
Да, встроенная миграция переносит код, задачи, pull request и вики.

Self-hosted версия работает в России без ограничений и не зависит от зарубежных платежей. Российские облачные аналоги — GitFlic и GitVerse.
