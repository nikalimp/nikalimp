# Google Cloud

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · Хостинг и деплой · Global
Буква: G · Страница на сайте: `/tools/google-cloud`

## Описание

Google Cloud — облачная платформа Google: серверы, базы данных, хранилище, аналитика и ИИ-модели Gemini с оплатой по факту использования.

Главное отличие — сильная аналитика и ИИ: [[Google BigQuery]] для больших данных и Vertex AI для работы с моделями [[Google Gemini]].

### Возможности
- **Compute Engine** — виртуальные машины, одна e2-micro бесплатно каждый месяц.
- **Cloud Run** — контейнеры без управления серверами, 2 млн запросов в месяц бесплатно.
- **BigQuery** — хранилище данных, 1 ТБ запросов в месяц бесплатно.
- **Cloud Storage** — объектное хранилище для файлов и бэкапов.
- **Vertex AI** — модели Gemini и сторонние модели по API.

### Кому подходит
Командам, которые работают с данными и ИИ, и проектам, уже связанным с экосистемой Google.

### Как начать
Создайте аккаунт с зарубежной картой, активируйте $300 кредитов и разверните первый контейнер в Cloud Run. Бюджет и оповещения настройте в Billing.

### Совет
Для небольших API и ботов берите Cloud Run: бесплатного лимита часто хватает, а сервер не простаивает за ваш счёт.

### Ограничения
Новых клиентов из России не принимают. Тарификация сложная, без бюджета легко переплатить. Для простого сайта удобнее [[Vercel]] или [[Railway]], в России — [[Yandex Cloud]] и [[Cloud.ru]].

## Частые вопросы
### Google Cloud бесплатный?
Новые клиенты получают $300 кредитов, а 20+ продуктов бесплатны в пределах месячных лимитов. Лимиты Free Tier не сгорают, но Google может их менять.

### Работает ли Google Cloud в России?
Нет. С 2022 года Google Cloud не принимает новых клиентов из России.

### Google Cloud или AWS?
[[AWS]] даёт больше сервисов и регионов, Google Cloud сильнее в аналитике и ИИ. Для России оба недоступны, альтернатива — [[Yandex Cloud]].

### Где в Google Cloud запустить бота или API?
В Cloud Run: он запускает контейнер по запросу, и в пределах бесплатного лимита небольшой бот ничего не стоит.
