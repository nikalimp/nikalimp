## Описание

Google Docs — бесплатный онлайн-редактор текстов от Google для совместной работы в браузере и на телефоне, с комментариями и историей версий.

Главное отличие — совместное редактирование в реальном времени, которое стало стандартом: несколько человек правят текст одновременно и видят курсоры друг друга.

### Возможности
- **Совместная работа:** правки в реальном времени, комментарии, упоминания.
- **Режим предложений:** правки видны как рецензия и принимаются по одной.
- **История версий** с откатом и именованными версиями.
- **Вкладки и шаблоны** для длинных документов.
- **Голосовой ввод**, перевод документа и AI-функции Gemini в платных планах.
- **Экспорт** в DOCX, PDF, ODT, Markdown.

### Кому подходит
Всем, кто пишет тексты вместе: копирайтерам, редакторам, менеджерам, студентам и командам без корпоративной вики.

### Как начать
Откройте docs.google.com, создайте документ и выдайте доступ по ссылке с ролью «Комментатор» или «Редактор». Храните документы в общих папках [[Google Drive]].

### Совет
Отдавайте текст клиенту в режиме «Комментатор»: он оставит замечания, а основной текст останется под вашим контролем.

### Ограничения
Для структурированной базы знаний удобнее [[Notion]] или [[Яндекс Wiki]]. Сложная вёрстка лучше получается в Word.

## Вердикт
- Кому подходит: Всем, кто пишет и согласовывает тексты вместе с коллегами и клиентами.
- Кому не подходит: Командам, которым нужна структурированная база знаний с навигацией и правами по разделам.
- Итог: Бесплатный стандарт совместного редактирования текстов.

## Плюсы
- Бесплатно и без установки
- Удобное совместное редактирование и комментарии
- Режим предложений для правок
- Работает в России без VPN

## Минусы
- Нет удобной структуры для большой базы знаний
- Workspace не оплатить российской картой
- Ограниченные возможности вёрстки

## Частые вопросы
### Google Docs бесплатный?
Да, для личного аккаунта Google бесплатно. Платный Google Workspace нужен для корпоративной почты и большего хранилища.

### Работает ли Google Docs в России?
Да, бесплатная версия работает без VPN. Оплатить Workspace российской картой нельзя.

### Google Docs или Яндекс Документы?
Google Docs удобнее в совместной работе и экспорте. [[Яндекс 360]] выбирают компании, которым важна оплата в рублях и хранение данных в России.

### Как отдать документ клиенту на согласование?
Включите доступ по ссылке с ролью «Комментатор» или попросите вносить правки в режиме предложений.
