# Google PageSpeed Insights

[[Инструменты — SEO|SEO]] · Скорость и Core Web Vitals · Global
Буква: G · Страница на сайте: `/tools/google-pagespeed-insights`

## Описание

Google PageSpeed Insights — бесплатный сервис Google для проверки скорости загрузки страницы на мобильных и компьютерах. Он показывает оценку от 0 до 100 и список конкретных причин медленной загрузки.

Отчёт строится из двух источников: лабораторной проверки Lighthouse и реальных данных пользователей Chrome за последние 28 дней.

### Что показывает
- **Core Web Vitals** — ключевые метрики опыта пользователя: LCP (загрузка главного контента), INP (отклик на действия) и CLS (сдвиги вёрстки).
- **Оценку производительности** по данным Lighthouse.
- **Рекомендации:** сжать изображения, убрать неиспользуемый JavaScript, отложить загрузку сторонних скриптов, включить кеширование.
- **Диагностику** доступности, SEO и лучших практик.

### Кому подходит
Владельцам сайтов, разработчикам и SEO-специалистам. Скорость влияет на поведение посетителей и конверсию, а Core Web Vitals входят в сигналы ранжирования Google.

### Как проверить сайт
Вставьте адрес страницы и дождитесь отчёта. Смотрите в первую очередь мобильную версию: она почти всегда медленнее, а большая часть трафика сегодня мобильная. Проверьте не только главную, но и шаблоны страниц: карточку товара, статью, страницу услуги.

### Типичные причины низкой оценки
- Тяжёлые изображения без современных форматов WebP и AVIF.
- Виджеты чатов, квизов и счётчиков, которые грузятся сразу.
- Шрифты, подключённые с внешних серверов.
- Большие библиотеки JavaScript на конструкторах сайтов.

### Совет
Если реальных данных пользователей нет, сайт пока мало посещаемый. Ориентируйтесь на лабораторную проверку и повторяйте её после каждого крупного изменения: новых виджетов, шрифтов или блоков.

### Частый вопрос
**Нужно ли добиваться 100 баллов?** Нет. Важнее, чтобы реальные данные Core Web Vitals были в зелёной зоне. Оценка Lighthouse колеблется от проверки к проверке. Для глубокого анализа используют Lighthouse в Chrome DevTools, GTmetrix и WebPageTest.

## Вердикт
- Кому подходит: Владельцам сайтов и разработчикам, которым нужно быстро проверить скорость страницы на телефоне и компьютере.
- Кому не подходит: Тем, кому нужна история замеров и мониторинг по расписанию: сервис показывает только текущий результат.
- Итог: PageSpeed Insights — бесплатная проверка скорости: показывает данные реальных пользователей и тест Lighthouse.

## Плюсы
- Бесплатный и без регистрации
- Данные реальных пользователей Chrome (CrUX) за 28 дней
- Тест Lighthouse с оценкой скорости, доступности, SEO и лучших практик
- Подсказки, что исправить в первую очередь
- Есть API для автоматических проверок

## Минусы
- Показывает один замер, истории нет
- Тест имитирует среднее устройство, поэтому результат отличается от реального
- Для страниц с малым трафиком данных реальных пользователей нет

## Частые вопросы
### Сколько стоит PageSpeed Insights?
Сервис бесплатный: достаточно вставить адрес страницы. Регистрация не нужна.

### Работает ли PageSpeed Insights в России?
Да, сайт pagespeed.web.dev открывается из России без VPN.

### Что лучше: PageSpeed Insights или GTmetrix?
PageSpeed Insights показывает данные реальных пользователей Chrome и оценку Lighthouse. [[GTmetrix]] хранит историю замеров и строит водопад загрузки, но часть функций платная.

### Что показывает PageSpeed Insights?
Два набора данных: метрики реальных пользователей за 28 дней и тест загрузки в [[Lighthouse]]. Среди метрик — LCP, INP, CLS и FCP.
