# Google Tag Manager

[[Инструменты — Маркетинг и аналитика|Маркетинг и аналитика]] · Веб-аналитика · Global
Буква: G · Страница на сайте: `/tools/google-tag-manager`

## Описание

Google Tag Manager (GTM) — бесплатная система управления тегами. Через неё на сайт ставят счётчики аналитики, пиксели рекламы, чаты и другие скрипты без правки кода сайта.

Разработчик один раз устанавливает контейнер GTM, а дальше маркетолог сам добавляет и настраивает теги через интерфейс.

### Как устроен GTM
- **Теги** — фрагменты кода: Яндекс Метрика, Google Analytics, пиксель VK, коллтрекинг.
- **Триггеры** — условия срабатывания: просмотр страницы, клик, отправка формы, прокрутка.
- **Переменные** — данные, которые передаются в теги: URL, текст кнопки, сумма заказа.
- **Уровень данных (dataLayer)** — объект на странице, через который сайт передаёт события и параметры.

### Возможности
- Режим предпросмотра для проверки тегов перед публикацией.
- Версии контейнера и откат изменений.
- Рабочие области для командной работы.
- Шаблоны тегов из галереи сообщества.
- Серверный контейнер для передачи данных через свой сервер.

### Кому подходит
Маркетологам и аналитикам, которые часто меняют набор счётчиков и событий. Сайтам с большим числом рекламных систем. Командам, где маркетинг не хочет ждать разработчика ради каждого пикселя.

### Как начать
Создайте аккаунт и контейнер, установите два фрагмента кода на все страницы. Добавьте первый тег — например, Метрику — и проверьте его в режиме предпросмотра. Затем настройте цели на клики и отправку форм.

### Совет
Называйте теги, триггеры и переменные по единой схеме: «Метрика — цель — заявка». Через год в контейнере будет сотня элементов, и без системы в нём сложно разобраться.

### Частый вопрос
**Замедляет ли GTM сайт?** Сам контейнер лёгкий, но каждый тег добавляет скрипты. Удаляйте неиспользуемые теги и проверяйте скорость в [[Google PageSpeed Insights]]. Данные удобно смотреть в [[Яндекс Метрика|Метрике]] и [[Google Analytics 4]].

## Вердикт
- Кому подходит: Маркетологам и разработчикам, которым нужно подключать счётчики, пиксели и события на сайте без правки кода каждый раз.
- Кому не подходит: Тем, у кого один счётчик на сайте: проще вставить его код напрямую.
- Итог: Google Tag Manager — бесплатный контейнер для тегов, который экономит время, когда на сайте больше двух-трёх счётчиков.

## Плюсы
- Бесплатный
- Теги, триггеры и переменные настраиваются без разработчика
- Предпросмотр и версии контейнера перед публикацией
- Работает с Google Analytics 4, Google Ads и сторонними тегами
- Один контейнер для нескольких сервисов

## Минусы
- Нужно разобраться в тегах, триггерах и переменных
- Ошибка в контейнере может сломать сбор данных на всём сайте
- Серверный вариант требует оплаты своего сервера

## Частые вопросы
### Сколько стоит Google Tag Manager?
Стандартная версия бесплатна. Серверный вариант тоже бесплатен, но нужно оплачивать свой сервер.

### Работает ли Google Tag Manager в России?
Да, сервис открывается из России без VPN. Если передаёте данные посетителей в зарубежные сервисы, учитывайте закон о персональных данных.

### Чем Google Tag Manager отличается от Google Analytics?
[[Google Analytics 4]] собирает и показывает статистику, а Google Tag Manager только подключает к сайту теги, в том числе счётчик аналитики. Он нужен, чтобы не править код сайта.

### Можно ли подключить через GTM Яндекс Метрику?
Да, [[Яндекс Метрика|Яндекс Метрику]] можно поставить через свой HTML-тег. Цели и события тоже удобно настраивать в контейнере.
