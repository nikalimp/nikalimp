## Описание

Grist — это таблица с возможностями базы данных: колонки с типами, связи между таблицами, формулы на Python и наглядные виджеты для просмотра данных.

Главное отличие от [[Google Sheets]] — строгая структура. В Grist каждая колонка имеет тип, таблицы связаны ссылками, а формулы пишутся на Python и применяются ко всей колонке.

### Возможности
- **Связанные таблицы:** ссылки между записями, как в базе данных.
- **Формулы на Python** с доступом к связанным записям.
- **Виджеты:** карточки, графики, календарь, связанные представления на одной странице.
- **Права доступа** на уровне строк и колонок.
- **Открытый код:** grist-core можно поставить на свой сервер.

### Кому подходит
Небольшим командам и аналитикам, которым нужна база данных без программиста: CRM, учёт заказов, каталог, реестр клиентов.

### Как начать
Импортируйте таблицу из CSV или Excel, задайте типы колонок и свяжите таблицы ссылками. Затем соберите страницу с карточкой записи и списком связанных строк.

### Совет
Если данные чувствительные, разверните Grist на своём сервере — бесплатная версия поддерживает все основные функции.

### Ограничения
Меньше готовых интеграций, чем у облачных конкурентов. Для автоматизаций понадобится [[n8n]] или API. Интерфейс непривычен тем, кто знает только формулы Excel.

## Частые вопросы
### Grist бесплатный?
Да, есть бесплатный облачный план и бесплатная версия для своего сервера. Платный Pro снимает лимиты.

### Работает ли Grist в России?
Облако открывается, но оплатить Pro российской картой нельзя. Версию grist-core можно развернуть на российском VPS.

### Grist или NocoDB?
[[NocoDB]] делает интерфейс поверх существующей SQL-базы. Grist — самостоятельная таблица-база с Python-формулами.

### Можно ли связать Grist с другими сервисами?
Да, через API и вебхуки, удобнее всего — через [[n8n]].
