# Headless UI

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · UI-библиотеки и компоненты · Global
Буква: H · Страница на сайте: `/tools/headless-ui`

## Описание

Headless UI — это бесплатная библиотека компонентов без стилей от создателей [[Tailwind CSS]]: она даёт готовую логику, доступность и клавиатурное управление, а внешний вид вы задаёте сами.

Главное отличие — компоненты не навязывают дизайн. Вы получаете рабочие меню, диалоги и списки, а оформление пишете классами Tailwind.

### Возможности
- **Набор компонентов:** Dialog, Menu, Listbox, Combobox, Popover, Tabs, Disclosure, Switch, Radio Group и поля форм.
- **Доступность из коробки:** ARIA-атрибуты, фокус, управление с клавиатуры.
- **Анимации** через компонент Transition и data-атрибуты состояний.
- **Плавающие элементы:** позиционирование выпадающих списков и поповеров с учётом края экрана.
- **React и Vue:** актуальная вторая версия — для React, Vue поддерживается в первой.

### Кому подходит
Фронтенд-разработчикам на React и Tailwind, которые хотят свой дизайн без борьбы со стилями готовых UI-китов.

### Как начать
Установите пакет командой `npm install @headlessui/react`, импортируйте нужный компонент и добавьте классы Tailwind. Готовые примеры оформления есть в [[Tailwind UI]].

### Совет
Используйте data-атрибуты состояний вроде `data-focus` и `data-open` вместо условных классов в JSX. Код станет короче, а стили — нагляднее.

### Ограничения
Компонентов меньше, чем в Radix: нет тостов, тултипов, слайдеров и таблиц. Для Vue новые функции не выходят. Если нужен готовый дизайн, быстрее взять [[shadcn ui|shadcn/ui]] или [[DaisyUI]].

- Кому подходит: Разработчикам на React и Tailwind, которым нужна доступная логика компонентов без чужого дизайна.
- Кому не подходит: Тем, кому нужен большой набор готовых оформленных компонентов или свежие версии для Vue.
- Итог: Лёгкая бесплатная основа для своих интерфейсов на Tailwind.

## Частые вопросы
### Headless UI бесплатный?
Да, библиотека с открытым кодом под лицензией MIT. Платные только готовые шаблоны [[Tailwind UI]], но они не обязательны.

### Работает ли Headless UI в России?
Да, пакет устанавливается из npm без VPN, а библиотека работает в браузере пользователя без внешних сервисов.

### Headless UI или shadcn/ui?
[[shadcn ui|shadcn/ui]] даёт готовые оформленные компоненты, которые вы копируете в проект, и покрывает больше сценариев. Headless UI проще и легче, но дизайн придётся делать самому. Для сложных форм и дат посмотрите [[React Aria]].

### Что значит «headless» в названии?
Компонент отвечает за поведение и доступность, но не содержит стилей. Внешний вид полностью определяет разработчик.
