# Hemingway Editor

[[Инструменты — Контент и копирайтинг|Контент и копирайтинг]] · Проверка и редактура текста · Global
Буква: H · Страница на сайте: `/tools/hemingway-editor`

## Описание

Hemingway Editor — это редактор, который подсвечивает в английском тексте длинные предложения, наречия, пассивный залог и сложные слова, чтобы текст читался проще.

Главное отличие — он не правит за вас, а показывает проблемные места цветом и оценивает уровень читаемости по школьной шкале. Его русский аналог по идее — [[Главред]].

### Возможности
- **Подсветка сложных предложений:** жёлтым — трудные, красным — очень трудные.
- **Наречия, пассив и сложные слова** с подсказками более простых вариантов.
- **Оценка читаемости** по шкале Grade level.
- **Hemingway Editor Plus:** AI исправляет грамматику, тон и сокращает предложения.
- **Экспорт** в HTML, Markdown, Word и публикация в WordPress из приложения.

### Кому подходит
Копирайтерам, маркетологам и продактам, которые пишут на английском для зарубежной аудитории: лендинги, письма, статьи, интерфейсы.

### Как пользоваться
Откройте hemingwayapp.com, вставьте текст и упрощайте фразы, пока подсветки не станет мало. Цель для маркетинговых текстов — уровень Grade 6–8.

### Совет
Не гонитесь за нулём подсветок. Используйте редактор как второй взгляд после черновика, а грамматику проверяйте в [[Grammarly]] или [[LanguageTool]].

### Ограничения
Работает только с английским языком. Бесплатная версия не проверяет орфографию и грамматику. Правила механические: иногда помечает точные термины и нужный пассив. Для русских текстов используйте [[Главред]] и [[Тургенев]].

## Частые вопросы
### Hemingway Editor бесплатный?
Да, веб-версия на hemingwayapp.com бесплатна и работает без регистрации. AI-функции и приложение для компьютера платные.

### Работает ли Hemingway Editor в России?
Веб-версия открывается без VPN. Оплатить Plus или приложение российской картой нельзя.

### Hemingway Editor или Главред?
Для английского — Hemingway, для русского — [[Главред]]: он ищет штампы, канцелярит и слова-паразиты. Для проверки грамматики английского добавьте [[Grammarly]].

### Подходит ли Hemingway для русского текста?
Нет, правила работают только для английского. Русский текст редактор оценит неверно.
