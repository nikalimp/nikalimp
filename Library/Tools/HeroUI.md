## Описание

HeroUI — это библиотека React-компонентов на Tailwind CSS и React Aria с готовым дизайном, анимациями и тёмной темой. До января 2025 года она называлась NextUI.

Главное отличие от [[shadcn ui|shadcn/ui]]: компоненты ставятся пакетом из npm и обновляются вместе с библиотекой, а не копируются в проект. Внешний вид при этом настраивается через темы и классы [[Tailwind CSS]].

### Возможности
- **Больше 50 компонентов:** кнопки, формы, таблицы, модальные окна, календари, выпадающие списки, тосты.
- **Доступность из коробки:** логика клавиатуры, фокуса и ARIA построена на [[React Aria]].
- **Темы:** светлая и тёмная схемы, свои цвета, скругления и шрифты через плагин Tailwind.
- **Версия 3:** переписана под Tailwind CSS v4, компоненты собираются по принципу композиции.
- **HeroUI Native:** отдельный набор для React Native.
- **Pro:** готовые блоки, шаблоны дашбордов, дизайн-системы и MCP-сервер для AI-редакторов.

### Кому подходит
Разработчикам на [[React]] и [[Next.js]], которым нужен красивый интерфейс без своей дизайн-системы: админки, дашборды, SaaS, MVP.

### Как начать
Создайте проект через CLI HeroUI или подключите пакет в готовый проект на Tailwind. Возьмите тему по умолчанию, затем поменяйте основные цвета и радиусы в конфиге.

### Совет
Для новых проектов берите третью версию: вторая и третья заметно различаются по API, и переезд позже отнимет время.

### Ограничения
Узнаваемый стиль: без настройки темы сайт выглядит как демо HeroUI. Только React, для Vue и Svelte библиотеки нет. Переход между мажорными версиями требует переписывать часть кода.

## Частые вопросы
### HeroUI бесплатный?
Да, основная библиотека бесплатная и распространяется под лицензией MIT. Платная только версия Pro с блоками и шаблонами.

### Работает ли HeroUI в России?
Да, пакеты ставятся из npm без ограничений. Для покупки Pro понадобится зарубежная карта.

### HeroUI или shadcn/ui?
HeroUI даёт готовый стиль и обновления пакетом. [[shadcn ui|shadcn/ui]] копирует код компонентов в проект, его проще перекроить под свой дизайн.

### Чем HeroUI отличается от NextUI?
Это та же библиотека: в 2025 году NextUI переименовали в HeroUI, а пакеты перенесли в новое пространство имён.
