## Описание

Homebrew — это бесплатный менеджер пакетов для macOS и Linux: он устанавливает консольные утилиты и программы одной командой в терминале.

Главное отличие — вместо скачивания установщиков с сайтов вы пишете `brew install` и получаете нужную версию, а потом обновляете всё разом.

### Возможности
- **Формулы:** тысячи консольных утилит — Node.js, Python, git, [[FFmpeg]], PostgreSQL.
- **Casks:** обычные приложения вроде [[VS Code]], [[Figma]] или [[Raycast]] через `brew install --cask`.
- **Обновление всего сразу** командой `brew upgrade`.
- **Brewfile:** список программ в одном файле, чтобы настроить новый Mac за минуты.
- **Сервисы:** запуск баз данных и серверов в фоне через `brew services`.

### Кому подходит
Разработчикам, дизайнерам и всем, кто работает в терминале на Mac или Linux и не хочет вручную искать и обновлять программы.

### Как начать
Скопируйте команду установки с brew.sh в Терминал и следуйте подсказкам. Затем установите первые пакеты, например `brew install git node`.

### Совет
Выполните `brew bundle dump` и храните получившийся Brewfile в git. При переезде на новый Mac команда `brew bundle` восстановит весь набор программ.

### Ограничения
Новые версии macOS поддерживаются, старые — постепенно перестают. На Windows работает только через WSL. Глобальные зависимости могут конфликтовать: версии Node.js и Python для проектов удобнее держать в отдельных менеджерах версий или пакетов вроде [[pnpm]].

## Частые вопросы
### Homebrew бесплатный?
Да, это open-source проект. Он живёт на пожертвования и не продаёт платных версий.

### Работает ли Homebrew в России?
Да, установка и пакеты загружаются с GitHub без VPN. Если загрузка идёт медленно, настройте зеркало через переменные окружения.

### Чем Homebrew отличается от App Store?
App Store ставит только приложения из каталога Apple. Homebrew ставит и программы, и консольные утилиты для разработки, которых в App Store нет.

### Как обновить все программы через Homebrew?
Выполните `brew update`, а затем `brew upgrade`. Для приложений из casks добавьте `brew upgrade --cask`.
