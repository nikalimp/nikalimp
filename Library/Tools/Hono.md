# Hono

## Описание

Hono — это лёгкий веб-фреймворк на TypeScript для API и серверных приложений, который работает на любом JavaScript-рантайме: [[Cloudflare Workers]], [[Bun]], [[Deno]], Node.js и AWS Lambda.

Главное отличие от [[Express]]: Hono построен на веб-стандартах Request и Response, поэтому один и тот же код запускается и на edge-платформах, и на обычном сервере. Ядро весит около 14 КБ.

### Возможности
- **Быстрый роутер** с параметрами, группами маршрутов и типизацией.
- **Middleware из коробки:** CORS, JWT, кеш, сжатие, логирование, Basic Auth.
- **Валидация** запросов через Zod и другие схемы.
- **RPC-клиент:** фронтенд получает типы API без генерации кода.
- **JSX на сервере** для HTML-страниц без React.
- **Адаптеры** для Vercel, Netlify, Fastly и AWS.

### Кому подходит
Разработчикам, которые пишут API, вебхуки, прокси и бэкенд для сайтов и хотят запускать их на edge или в serverless-функциях.

### Как начать
Выполните `npm create hono@latest`, выберите шаблон под нужную платформу и опишите первый маршрут. Деплой на Cloudflare Workers занимает пару минут.

### Совет
Используйте RPC-режим, если фронтенд на TypeScript: типы ответа подтягиваются автоматически, и ошибки в контракте API видно ещё в редакторе.

### Ограничения
Экосистема меньше, чем у [[Express]] и [[NestJS]]: готовых плагинов меньше, сложную архитектуру придётся собирать самостоятельно. Документация только на английском и японском.

## Вердикт
- Кому подходит: Разработчикам API и серверных функций, которым важны скорость, типизация и переносимость между платформами.
- Кому не подходит: Командам, которым нужен «тяжёлый» фреймворк с готовой архитектурой, ORM и модулями.
- Итог: Быстрый и лёгкий фреймворк на веб-стандартах, который запускается почти где угодно.

## Частые вопросы
### Hono бесплатный?
Да, это открытый фреймворк под лицензией MIT. Платите только за хостинг, где запускаете приложение.

### Работает ли Hono в России?
Да, фреймворк ставится из npm без ограничений. Доступность зависит от выбранного хостинга: например, Cloudflare Workers работает, а оплата части зарубежных платформ требует зарубежную карту.

### Hono или Express?
[[Express]] привычнее и богаче плагинами, но привязан к Node.js. Hono быстрее, типизирован и работает на edge-платформах. Для нового API на TypeScript чаще выбирают Hono.

### На чём запускать Hono?
Чаще всего на [[Cloudflare Workers]], [[Bun]] или [[Deno Deploy]]. Для обычного сервера подойдёт Node.js через адаптер.
