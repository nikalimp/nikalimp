## Описание

Hugging Face — крупнейшая платформа для моделей машинного обучения с открытым кодом. На ней хранятся сотни тысяч моделей, датасетов и демо-приложений: от языковых моделей до генераторов изображений и распознавания речи.

Hugging Face называют «GitHub для AI»: разработчики публикуют модели, а другие скачивают и используют их в своих проектах.

### Возможности
- **Hub моделей:** открытые LLM, модели изображений, речи, перевода и другие.
- **Датасеты** для обучения и тестирования.
- **Spaces** — бесплатный хостинг демо-приложений на Gradio и Streamlit.
- **Библиотека Transformers** и другие инструменты для разработчиков.
- **Inference API** — запуск моделей без своего сервера.
- **Рейтинги моделей** и сообщество.

### Кому подходит
Разработчикам и исследователям AI, стартапам, которые строят продукты на открытых моделях, и техническим специалистам, которые хотят попробовать модели без установки.

### Как начать
Найдите модель под задачу — например, распознавание речи на русском, — и откройте её Space для пробы в браузере. Если подходит, скачайте модель и запустите локально.

### Hugging Face и бизнес
Открытые модели позволяют обрабатывать данные на своих серверах. Для российских компаний это способ использовать AI без зависимости от зарубежных облачных сервисов.

### Совет
Читайте карточку модели: лицензия может запрещать коммерческое использование, а требования к памяти — не подходить вашему серверу.

### Ограничения
Новичку сложно разобраться в тысячах моделей без технического опыта. Для простого чата лучше готовые ассистенты.

### Частый вопрос
**Hugging Face или OpenRouter?** Hugging Face — для скачивания и запуска моделей, [[OpenRouter]] — для доступа к множеству моделей через один API без своего сервера. Популярные открытые модели — [[Qwen]] и [[DeepSeek]].

## Частые вопросы
### Hugging Face бесплатный?
Да, публичные модели, датасеты и Spaces на базовом железе бесплатны. Платить нужно за PRO ($9 в месяц), команду, приватные ресурсы и мощные GPU.

### Работает ли Hugging Face из России?
Мы не смогли подтвердить стабильный доступ и оплату из России. Платные функции принимают только банковскую карту через Stripe, детали уточняйте у поддержки.

### Hugging Face или Replicate: что выбрать?
Hugging Face — каталог и сообщество открытых моделей, Replicate — готовый API для запуска моделей с оплатой за использование. Для экспериментов берите Hugging Face, для быстрой интеграции — Replicate.

### Что такое Hugging Face?
Это платформа, где хранят и публикуют открытые модели, датасеты и демо-приложения. Модели можно скачать или запустить в Spaces и через API.
