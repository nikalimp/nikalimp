## Описание

Hygraph — это headless CMS с GraphQL API: контент хранится в облаке, а сайт или приложение забирают его запросами. До 2022 года сервис назывался GraphCMS.

Главное отличие от [[Contentful]] и [[Sanity]]: Hygraph изначально построен вокруг GraphQL и умеет объединять в одном API свой контент и данные из внешних систем — каталога товаров, CRM или другого API.

### Возможности
- **GraphQL API** для чтения и записи контента, с фильтрами и пагинацией.
- **Content Federation:** подключение внешних API в общую схему.
- **Визуальный конструктор моделей** контента без кода.
- **Локализация** и варианты контента для разных рынков.
- **Роли и этапы публикации** для редакций.
- **CDN и вебхуки** для пересборки сайта после правок.

### Кому подходит
Командам разработки, которые делают многоязычные сайты, интернет-магазины и приложения на [[Next.js]] и хотят один API для контента и внешних данных.

### Как начать
Создайте проект на тарифе Hobby, опишите модели контента и попробуйте запросы в API Playground. Подключите сайт через GraphQL-клиент и настройте вебхук на пересборку.

### Совет
Сразу продумайте модели и связи: менять схему с живым контентом сложнее, чем в начале. Для маркетинговых страниц заведите модульные блоки, а не одно большое поле.

### Ограничения
Бесплатный тариф ограничен по объёму и пользователям, а следующий шаг сразу дорогой. Из России работать сложно. Открытые альтернативы для своего сервера — [[Strapi]], [[Directus]] и [[Payload CMS]].

## Вердикт
- Кому подходит: Командам, которым нужна headless CMS на GraphQL с объединением внешних данных.
- Кому не подходит: Небольшим проектам из России и тем, кому нужен недорогой платный тариф.
- Итог: Мощная GraphQL CMS для сложных проектов, но дорогая и малодоступная из России.

## Плюсы

## Частые вопросы
### Hygraph бесплатный?
Есть бесплатный тариф Hobby для личных и тестовых проектов. Коммерческие тарифы начинаются примерно с $199 в месяц.

### Работает ли Hygraph в России?
Работа из России нестабильна: может понадобиться VPN, а оплата проходит только зарубежной картой. Надёжнее развернуть открытую CMS на своём сервере.

### Hygraph или Strapi?
Hygraph — облачный сервис с GraphQL и объединением данных. [[Strapi]] — открытая CMS, которую можно бесплатно поставить на свой сервер, в том числе в России.

### Что такое Content Federation?
Это подключение внешних API в схему Hygraph: сайт одним запросом получает и статьи, и, например, цены из каталога.
