# Iconify

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Иконки · Global
Буква: I · Страница на сайте: `/tools/iconify`

## Описание

Iconify — это открытый фреймворк, который собирает больше 200 000 иконок из 150+ наборов в один каталог и даёт единый способ подключить любую из них в код.

Главное отличие от отдельных наборов вроде [[Lucide]] или [[Material Symbols]]: в Iconify вы не выбираете одну библиотеку. Любая иконка из любого набора подключается одной строкой с префиксом, например `mdi:home` или `lucide:search`.

### Возможности
- **Каталог 150+ наборов:** Material, Lucide, Tabler, Phosphor, Font Awesome и другие.
- **Компоненты** для React, Vue, Svelte и веб-компонент.
- **Плагин для Tailwind CSS:** иконки как классы.
- **Unplugin Icons:** иконки встраиваются в бандл при сборке.
- **API** для загрузки иконок по запросу.
- **Плагин для Figma** и поиск на icon-sets.iconify.design.

### Кому подходит
Разработчикам и дизайнерам, которым нужны иконки из разных наборов в одном проекте или которые хотят быстро переключаться между стилями.

### Как начать
Найдите иконку на сайте Iconify, скопируйте её имя и подключите через `@iconify/react` или плагин Tailwind. Для продакшна встраивайте иконки при сборке.

### Совет
Не смешивайте в одном интерфейсе иконки из разных наборов: выберите один основной и берите из других только недостающие, со сходной толщиной линии.

### Ограничения
У каждого набора своя лицензия, проверяйте её перед коммерческим использованием. Подгрузка по API добавляет внешний запрос: в продакшне лучше встраивать иконки в сборку.

## Частые вопросы
### Iconify бесплатный?
Да, фреймворк, API и плагины бесплатные. Лицензия конкретной иконки зависит от её набора.

### Работает ли Iconify в России?
Да, сайт, API и пакеты npm работают без VPN.

### Iconify или Lucide?
[[Lucide]] — один набор в одном стиле. Iconify — каталог, в котором есть и Lucide, и ещё 150 наборов.

### Как подключить иконки Iconify в Tailwind?
Поставьте плагин `@iconify/tailwind4` и используйте классы вида `icon-[mdi--home]`. Иконка встроится как CSS-маска.
