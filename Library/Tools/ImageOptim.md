## Описание

ImageOptim — это бесплатное приложение для Mac, которое сжимает JPEG, PNG, GIF и SVG без видимой потери качества: файлы перетаскивают в окно, и они становятся легче.

Главное отличие — простота. Нет настроек на каждом шаге: приложение прогоняет картинку через несколько оптимизаторов и выбирает лучший результат, удаляя лишние метаданные.

### Возможности
- **Сжатие без потерь** и с потерями для JPEG, PNG, GIF и SVG.
- **Удаление метаданных:** EXIF, геолокация, профиль камеры.
- **Пакетная обработка:** перетащите папку целиком.
- **Несколько движков** сжатия, включая MozJPEG и pngquant.
- **Веб-API** для автоматической оптимизации на сервере.

### Кому подходит
Веб-дизайнерам и разработчикам на Mac, которые готовят картинки для сайтов, а также всем, кто отправляет фото и хочет убрать из них геолокацию.

### Как пользоваться
Скачайте приложение с сайта, перетащите в окно файлы или папку. Сжатые файлы заменяют исходники, поэтому работайте с копиями.

### Совет
Включите режим сжатия с потерями и качество 80–85% — экономия для JPEG и PNG вырастет в разы без заметной разницы. Для WebP и AVIF используйте [[Squoosh]].

### Ограничения
Работает только на macOS. Не конвертирует в WebP и AVIF. Заменяет исходные файлы. На Windows и в браузере его заменят [[Squoosh]] и [[TinyPNG]], для векторной графики — [[SVGOMG]].

## Частые вопросы
### ImageOptim бесплатный?
Да, приложение для Mac бесплатное и с открытым кодом под лицензией GPL. Платный только веб-API для серверной оптимизации.

### Работает ли ImageOptim в России?
Да, приложение работает офлайн и не требует регистрации или оплаты.

### ImageOptim или TinyPNG?
[[TinyPNG]] работает в браузере на любой системе, но ограничивает число и размер файлов бесплатно. ImageOptim работает на Mac локально и без лимитов.

### Есть ли ImageOptim для Windows?
Нет, только для macOS. На Windows используйте [[Squoosh]] в браузере или похожие open-source утилиты.
