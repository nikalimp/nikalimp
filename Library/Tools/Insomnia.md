## Описание

Insomnia — это десктопный клиент для отправки и отладки запросов к API: REST, GraphQL, gRPC, WebSocket и SSE. Разработчик — компания Kong.

Главное отличие от [[Postman]] — лёгкий интерфейс и локальное хранилище: коллекции можно держать на своём компьютере или в Git, без облака.

### Возможности
- **Запросы любых типов:** REST, GraphQL, gRPC, WebSocket, SSE, с переменными окружения.
- **Дизайн API:** редактор спецификаций OpenAPI с подсветкой ошибок, совместим со [[Swagger]].
- **Хранение на выбор:** локальный vault, Git Sync или облако Kong.
- **Мок-серверы:** до 1000 запросов в месяц на бесплатном плане.
- **Тесты и скрипты:** проверки ответов, коллекции и запуск из CLI Inso в CI.

### Кому подходит
Фронтенд- и бэкенд-разработчикам, которые проверяют API во время разработки. Небольшим командам, которым хватает синхронизации через Git.

### Как начать
Скачайте приложение для Windows, macOS или Linux, создайте коллекцию и импортируйте запросы из cURL, OpenAPI или файла Postman. Для работы без облака выберите локальное хранилище.

### Совет
Выносите адреса, токены и ключи в окружения, а не в тела запросов. Так одну коллекцию можно запускать против локального, тестового и боевого сервера.

### Ограничения
Командная работа и облачная синхронизация для больших команд — только на платных планах. Экосистема плагинов и публичных коллекций меньше, чем у Postman.

## Вердикт
- Кому подходит: Разработчикам, которым нужен быстрый клиент API с локальным хранением и Git.
- Кому не подходит: Командам, которые строят всю работу с API вокруг облачного воркспейса и публичных коллекций.
- Итог: Лёгкая альтернатива Postman с бесплатным планом и хранением коллекций в Git.

## Плюсы
- Бесплатный план покрывает индивидуальную работу
- Поддержка REST, GraphQL, gRPC и WebSocket в одном окне
- Локальное хранилище и Git Sync без обязательного облака
- Редактор OpenAPI и CLI для запуска в CI

## Минусы
- Оплата только зарубежной картой
- Интерфейс только на английском
- Меньше интеграций и готовых коллекций, чем у Postman

## Частые вопросы
### Insomnia бесплатный?
Да, план Essentials бесплатный и подходит для индивидуальной работы. Платные планы добавляют командные функции.

### Работает ли Insomnia в России?
Приложение скачивается и работает без VPN. Платные планы можно оплатить только зарубежной картой.

### Insomnia или Postman?
Insomnia легче и удобнее для локальной работы с хранением в Git. [[Postman]] сильнее в командной работе, документации и готовых коллекциях.

### Можно ли пользоваться Insomnia без аккаунта?
Да, для локального хранилища аккаунт не нужен. Облачная синхронизация и командные функции требуют входа.
