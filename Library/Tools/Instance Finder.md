# Instance Finder

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Плагины Figma · Global
Буква: I · Страница на сайте: `/tools/instance-finder`

## Описание

Instance Finder — это плагин для Figma, который находит все экземпляры выбранного компонента в файле и выделяет их одним кликом.

Главное отличие от встроенного поиска Figma — плагин собирает инстансы со всех фреймов и страниц в один список, по которому удобно переходить.

### Возможности
- **Поиск инстансов** выбранного мастер-компонента на текущей странице или во всём файле.
- **Список результатов** с переходом к каждому экземпляру на холсте.
- **Массовое выделение**, чтобы поменять свойство, вариант или слой сразу у всех найденных копий.
- **Проверка перед удалением**: видно, используется ли компонент где-то ещё.

### Кому подходит
Дизайнерам, которые ведут дизайн-систему в [[Figma]] и регулярно чистят файлы. Командам, которые передают макеты в разработку и хотят знать, где живёт каждый компонент.

### Как пользоваться
Установите плагин из сообщества Figma, выделите компонент или инстанс и запустите плагин из меню Plugins. Выберите область поиска и кликните по нужному результату.

### Совет
Перед рефакторингом дизайн-системы прогоните ключевые компоненты через плагин и запишите, на каких экранах они стоят. Так проще оценить объём правок и не сломать макеты, которые уже ушли в работу.

### Ограничения
Плагин ищет только в открытом файле: инстансы в других файлах команды он не видит, для этого нужна аналитика библиотек в платных тарифах Figma. На больших файлах поиск по всем страницам идёт заметно дольше. Похожие задачи частично закрывают [[Batch Styler]] и встроенные функции Figma.

## Вердикт
- Кому подходит: Дизайнерам и командам, которые ведут компоненты в Figma и наводят порядок в больших файлах.
- Кому не подходит: Тем, кому нужна статистика использования компонентов по всем файлам команды.
- Итог: Простой бесплатный плагин, который экономит время на поиске копий компонента внутри файла.

## Плюсы
- Бесплатный, без регистрации и лимитов
- Находит инстансы по всем страницам файла
- Позволяет выделить все копии и править их пакетно
- Помогает безопасно удалять неиспользуемые компоненты

## Минусы

- На тяжёлых файлах поиск медленный

## Частые вопросы
### Instance Finder бесплатный?
Да, плагин бесплатный и ставится из сообщества Figma. Платить нужно только за саму Figma, если вам нужны её платные функции.

### Работает ли Instance Finder в России?
Да, плагин работает везде, где открывается Figma. Отдельного аккаунта и оплаты он не требует.

### Чем заменить Instance Finder?
Для пакетной правки стилей подойдёт [[Batch Styler]]. Статистику по библиотекам во всех файлах показывает аналитика библиотек в платных тарифах [[Figma]].

### Зачем искать инстансы, если есть мастер-компонент?
Мастер-компонент показывает, как выглядит элемент, но не где он стоит. Плагин отвечает на второй вопрос: на каких экранах компонент используется и что сломается при правке.
