## Описание

JSFiddle — это онлайн-песочница для HTML, CSS и JavaScript: пишете код в трёх панелях и сразу видите результат в окне предпросмотра.

Главное отличие — простота и возраст: JSFiddle работает с 2010 года, и ссылки на фиддлы до сих пор служат стандартным способом показать баг на Stack Overflow и в issue на [[GitHub]].

### Возможности
- **Четыре панели:** HTML, CSS, JavaScript и результат в одном окне.
- **Подключение библиотек** и фреймворков из списка или по ссылке на CDN.
- **Препроцессоры:** SCSS, TypeScript, CoffeeScript, Babel.
- **Встраивание** фиддла на сайт или в документацию через iframe.
- **Версии:** каждое сохранение получает свой адрес.

### Кому подходит
Разработчикам, которым нужно быстро проверить идею, воспроизвести баг или поделиться примером кода. Подходит преподавателям и авторам туториалов.

### Как начать
Откройте jsfiddle.net, вставьте код в панели и нажмите Run. Чтобы сохранить и поделиться, нажмите Save и отправьте ссылку.

### Совет
Перед вопросом на форуме сократите пример до минимального: только код, который воспроизводит проблему. Так вам ответят быстрее.

### Ограничения
Нет полноценного проекта с файлами, npm и сборкой — для этого используйте [[CodeSandbox]] или [[StackBlitz]]. Бесплатные фиддлы публичные, интерфейс устарел по сравнению с [[CodePen]].

## Частые вопросы
### JSFiddle бесплатный?
Да, основные функции бесплатны и доступны даже без регистрации. PRO убирает рекламу и добавляет приватные фиддлы.

### Работает ли JSFiddle в России?
Да, сайт открывается без VPN. Только оплата PRO требует зарубежной карты.

### JSFiddle или CodePen?
[[CodePen]] удобнее для демонстрации дизайна и поиска вдохновения, у него большое сообщество. JSFiddle проще и привычнее для воспроизведения багов.

### Можно ли использовать React в JSFiddle?
Да, подключите React из списка библиотек и включите Babel для JSX в панели JavaScript.
