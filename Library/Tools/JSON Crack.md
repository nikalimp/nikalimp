## Описание

JSON Crack — это бесплатный визуализатор JSON: превращает вложенные данные в интерактивную схему из связанных узлов, по которой видно структуру с первого взгляда.

Главное отличие — граф вместо дерева. Вложенные объекты и массивы раскладываются на холсте, и сложный ответ API читается быстрее, чем текст из тысячи строк.

### Возможности
- **Визуализация** JSON, YAML, CSV, XML и TOML в виде графа.
- **Конвертация** между форматами и генерация типов TypeScript.
- **Поиск по узлам** и раскрытие нужных веток.
- **Экспорт схемы** в PNG, JPEG или SVG.
- **Расширение для [[VS Code]]** и открытый код для запуска у себя.

### Кому подходит
Разработчикам, тестировщикам и аналитикам, которые разбирают ответы API, конфиги и выгрузки данных.

### Как пользоваться
Откройте редактор на сайте, вставьте JSON слева и смотрите схему справа. Кликайте по узлам, чтобы увидеть путь к значению, и выгружайте схему картинкой для документации.

### Совет
Используйте JSON Crack, чтобы показать структуру API менеджеру или дизайнеру: схема понятнее сырого JSON. Для чувствительных данных запустите проект локально из исходников.

### Ограничения
Большие файлы в бесплатной версии тормозят или не открываются. Редактировать данные на схеме удобнее в платном ToDiagram. Для запросов к API нужен отдельный клиент вроде [[Postman]] или [[Hoppscotch]].
