## Описание

Jekyll — это бесплатный генератор статических сайтов на Ruby: превращает Markdown-файлы и шаблоны Liquid в готовый HTML-сайт.

Главное отличие — родная поддержка в [[GitHub Pages]]: сайт на Jekyll собирается и публикуется прямо из репозитория, без отдельного сервера и настройки CI.

### Возможности
- **Markdown и front matter:** страницы и посты пишутся в текстовых файлах с метаданными.
- **Шаблоны Liquid:** макеты, инклюды, циклы по постам и коллекциям.
- **Блог из коробки:** посты по датам, категории, теги, RSS через плагин.
- **Коллекции и data-файлы** в YAML, JSON и CSV для каталогов и справочников.
- **Плагины и темы:** SEO-теги, sitemap, пагинация, готовые темы.

### Кому подходит
Разработчикам и авторам документации, которым нужен простой блог или сайт проекта на GitHub Pages. Подходит для портфолио и личных страниц.

### Как начать
Установите Ruby, затем выполните `gem install jekyll bundler`, создайте проект командой `jekyll new site` и запустите `bundle exec jekyll serve`. Для публикации отправьте репозиторий на GitHub и включите Pages.

### Совет
Для нового проекта сравните Jekyll с [[Hugo]] и [[Eleventy]]: они быстрее собирают большие сайты и не требуют Ruby. Jekyll выбирайте, если важна публикация на GitHub Pages без настройки.

### Ограничения
Сборка замедляется на сайтах с тысячами страниц. Установка Ruby на Windows неудобна. Проект развивается медленнее конкурентов, а GitHub Pages поддерживает только ограниченный список плагинов.

## Частые вопросы
### Jekyll бесплатный?
Да, это открытый проект под лицензией MIT. Хостинг на GitHub Pages для публичных репозиториев тоже бесплатный.

### Работает ли Jekyll в России?
Да, Jekyll работает локально и устанавливается без VPN. GitHub Pages из России тоже доступен.

### Jekyll или Hugo?
[[Hugo]] собирает сайт за секунды и ставится одним файлом. Jekyll проще для GitHub Pages и привычнее тем, кто знает Ruby.

### Нужно ли знать Ruby для Jekyll?
Нет, для обычного сайта достаточно Markdown, YAML и шаблонов Liquid. Ruby нужен только для своих плагинов.
