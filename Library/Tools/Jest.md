## Описание

Jest — это бесплатный фреймворк для тестирования JavaScript и TypeScript: запускает юнит- и интеграционные тесты, делает моки и снапшоты.

Главное отличие — всё в одном пакете: раннер, проверки, моки, покрытие кода и снапшоты работают без дополнительных библиотек. Проект создали в Meta, сейчас им управляет OpenJS Foundation.

### Возможности
- **Тесты без настройки:** находит файлы `*.test.js` и запускает их параллельно.
- **Моки:** подмена модулей, функций, таймеров и сетевых запросов.
- **Снапшоты:** сохранение вывода компонента и сравнение при следующих запусках.
- **Покрытие кода** встроено, без отдельного инструмента.
- **Watch-режим:** перезапуск только затронутых тестов при сохранении файла.

### Кому подходит
JavaScript- и TypeScript-разработчикам, особенно в проектах на [[React]], [[React Native]] и Node.js, где Jest давно стал стандартом.

### Как начать
Установите пакет `npm install --save-dev jest`, добавьте скрипт `"test": "jest"` и напишите первый файл `sum.test.js`. Для TypeScript подключите ts-jest или Babel.

### Совет
Для новых проектов на [[Vite]] сравните Jest с [[Vitest]]: у него тот же API, но он быстрее и не требует отдельной настройки трансформации. Для старых проектов на Jest переход редко оправдан.

### Ограничения
Поддержка ES-модулей до сих пор требует настройки. На больших проектах Jest медленнее Vitest. Для тестов в настоящем браузере нужны [[Playwright]] или [[Cypress]].

## Вердикт
- Кому подходит: Командам на React, React Native и Node.js, которым нужен проверенный фреймворк для юнит-тестов.
- Кому не подходит: Новым проектам на Vite и ES-модулях: там удобнее Vitest.
- Итог: Самый распространённый фреймворк тестирования JavaScript с моками и снапшотами из коробки.

## Частые вопросы
### Jest бесплатный?
Да, Jest распространяется бесплатно под лицензией MIT.

### Работает ли Jest в России?
Да, пакет ставится из npm и работает локально без VPN.

### Jest или Vitest?
[[Vitest]] быстрее и лучше дружит с Vite и ES-модулями. Jest надёжнее для существующих проектов и React Native, где он встроен по умолчанию.

### Можно ли тестировать React-компоненты в Jest?
Да, вместе с React Testing Library и окружением jsdom. Для проверки в настоящем браузере используйте [[Playwright]].
