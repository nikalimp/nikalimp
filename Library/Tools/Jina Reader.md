## Описание

Jina Reader — это API, который превращает любую веб-страницу в чистый Markdown для языковых моделей: достаточно добавить `r.jina.ai/` перед адресом страницы.

Главное отличие — нулевой порог входа. Не нужно ставить парсер, браузер или библиотеку: один HTTP-запрос возвращает текст без меню, рекламы и скриптов.

### Возможности
- **Чтение страниц** в Markdown, HTML или текст через `r.jina.ai`.
- **Поиск** через `s.jina.ai`: выдача с содержимым страниц для RAG.
- **Рендеринг JavaScript** для динамических сайтов.
- **Описание картинок** и чтение PDF.
- **Заголовки запроса** для выбора формата, CSS-селектора и таймаута.

### Кому подходит
Разработчикам ИИ-агентов, чат-ботов и RAG-систем, которым нужно быстро скормить модели содержимое страниц.

### Как начать
Откройте в браузере `https://r.jina.ai/https://example.com` и посмотрите результат. Для работы в коде получите API-ключ на jina.ai и передавайте его в заголовке Authorization, чтобы поднять лимиты.

### Совет
Проверьте, как ваш собственный сайт выглядит через Jina Reader: примерно так его видят ИИ-агенты. Если текст обрезан или перемешан с меню, это повод поправить вёрстку для GEO.

### Ограничения
Без ключа лимиты низкие, для продакшена нужен ключ и пополнение. Сайты с защитой от ботов часто отдают пустой ответ. В 2025 году Jina AI купила Elastic, условия могут меняться. Для обхода целых сайтов удобнее [[Firecrawl]] или [[Apify]].

- Кому не подходит: Тем, кто парсит защищённые сайты или обходит тысячи страниц одного домена.
- Итог: Самый простой способ превратить страницу в Markdown для ИИ: один запрос и никакой инфраструктуры.

## Плюсы
- Работает без установки: достаточно добавить префикс к адресу
- Бесплатный старт и 10 млн токенов на новый ключ
- Рендерит JavaScript и читает PDF
- Есть поиск с содержимым страниц

## Минусы

- Защищённые сайты часто не читаются
- Пополнение токенов только зарубежной картой

## Частые вопросы
### Jina Reader бесплатный?
Да, базовые запросы работают без ключа и бесплатно. Новый ключ получает 10 млн токенов, после них токены докупаются.

### Работает ли Jina Reader в России?
API отвечает из России без VPN. Для пополнения токенов нужна зарубежная карта.

### Jina Reader или Firecrawl?
Jina Reader проще для разового чтения страниц. [[Firecrawl]] удобнее для обхода целого сайта, карт сайта и структурированного извлечения данных.

### Как Jina Reader помогает в GEO?
Он показывает страницу так, как её прочитает языковая модель. Если в Markdown нет ключевых фактов, ИИ-поиск их тоже не увидит.

## Цена

Базовое использование бесплатно, без ключа — с жёсткими лимитами. Новый API-ключ получает разовый пакет из 10 млн токенов, дальше токены докупаются.


## Доступность из России

Сервис отвечает из России без VPN. Пополнение токенов требует зарубежной карты. Российского аналога в виде готового API почти нет; бесплатная замена — [[Crawl4AI]] на своём сервере.
