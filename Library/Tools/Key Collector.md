# Key Collector

Буква: K · Страница на сайте: `/tools/key-collector`

## Описание

Key Collector — десктопная программа для сбора и обработки семантического ядра. Она массово собирает запросы и частотность из Яндекс Вордстата, Директа, Google и поисковых подсказок, а потом помогает очистить и сгруппировать их.

Программу делает российская компания Legat Software. Key Collector много лет остаётся стандартом для SEO-специалистов в Рунете, когда нужно работать с тысячами запросов.

### Возможности
- **Парсинг запросов** из Вордстата (левая и правая колонки), подсказок Яндекса и Google, статистики Директа.
- **Проверка частотности** базовой, «в кавычках» и «точной» сразу для тысяч фраз.
- **Чистка:** стоп-слова, неявные дубли, группы нецелевых запросов.
- **Кластеризация** по выдаче и составу фраз.
- **Оценка конкуренции и релевантных страниц** сайта для каждого запроса.
- **Мультигруппы и проекты** для больших ядер.

### Кому подходит
SEO-специалистам и агентствам, которые собирают семантику для интернет-магазинов, сервисов и больших контентных сайтов. Для пары десятков запросов программа избыточна: хватит [[Яндекс Вордстат|Вордстата]] в браузере.

### Как начать
Купите лицензию, подключите несколько Яндекс-аккаунтов, прокси и сервис распознавания капчи — без них сбор быстро упрётся в ограничения. Начните с маркерных запросов, соберите их расширения, затем очистите список стоп-словами.

### Особенности
Программа работает только на Windows. На Mac её запускают через виртуальную машину. Есть облачные альтернативы: [[Rush Analytics]], [[Топвизор]], [[Букварикс]].

### Совет
Сохраняйте шаблоны стоп-слов и настройки сбора между проектами. Для однотипных сайтов, например нескольких клиник или магазинов одной ниши, это экономит часы ручной чистки.

### Частый вопрос
**Нужен ли Key Collector, если есть онлайн-сервисы?** Онлайн-сервисы проще, но платятся за объём. Key Collector окупается при регулярной работе с большими ядрами: лицензия разовая.

## Частые вопросы
### Сколько стоит Key Collector?
Первая лицензия стоит 2 200 ₽ для физлиц и 2 300 ₽ для юрлиц и ИП, платёж разовый. Дополнительные лицензии дешевле, от 1 300 ₽.

### Есть ли у Key Collector бесплатная версия?
Нет, демо-версии нет, программа работает только после оплаты. Разработчик советует покупать, только если вы уверены, что она нужна.

### Работает ли Key Collector в России?
Да, это российская программа, оплата возможна картами Мир, Visa, Mastercard, через ЮMoney и по счёту. Сбор статистики из Вордстата разработчик не гарантирует.

### Что лучше: Key Collector или Букварикс?
Key Collector — программа для постоянной работы с большими ядрами, Букварикс проще и бесплатен. Для старта хватает Букваркса, для постоянной работы с семантикой берут Key Collector.
