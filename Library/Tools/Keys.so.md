## Описание

Keys.so — сервис конкурентного анализа по базам запросов Яндекса и Google. По домену конкурента он показывает, по каким запросам тот в топе, сколько у него видимости и какие страницы приносят трафик.

Главная ценность сервиса — большие базы ключевых слов по Рунету. Семантику можно собрать не с нуля, а «подсмотреть» у сайтов, которые уже успешно продвигаются.

### Возможности
- **Анализ домена:** видимость, число запросов в топ-10 и топ-50, динамика.
- **Запросы и страницы конкурента:** что приносит ему трафик.
- **Сравнение сайтов:** общие и уникальные запросы у нескольких конкурентов.
- **Поиск конкурентов** по пересечению семантики.
- **Контекстная реклама:** объявления и запросы конкурентов в Директе.
- **Подбор запросов** из базы по маске.
- **Парсер Вордстата и кластеризация:** массовая частотность и группировка запросов по страницам.
- **Анализ ссылок** и история изменений robots.txt у конкурентов.
- **Трекер ИИ:** видимость сайта в ответах нейросетей, без подписки доступен демо-проект.

### Кому подходит
SEO-специалистам на старте проекта, маркетологам при анализе рынка и владельцам бизнеса, которые хотят понять, откуда конкуренты берут клиентов. Особенно полезен в нишах с большим числом сайтов: интернет-магазины, услуги, медицина.

### Как начать
Введите домен главного конкурента, посмотрите его топовые страницы и выгрузите запросы. Затем сравните 3⁠–⁠5 конкурентов между собой: общие запросы — обязательный минимум для вашего сайта, уникальные — точки роста.

### Совет
При выгрузке запросов конкурента фильтруйте их по позиции и частотности: запросы из топ-10 с заметным спросом — основа семантики, а длинный хвост добирайте позже.

### Как работать: пошагово
1. Зарегистрируйтесь. Без подписки откроется демодоступ к отчётам и 1 000 проверок позиций в месяц.
2. Введите домен своего сайта и выберите базу: Яндекс или Google, Москва или нужный регион.
3. Найдите конкурентов в отчёте по пересечению запросов. Берите сайты своего масштаба, а не маркетплейсы и агрегаторы.
4. Откройте сравнение 3⁠–⁠5 конкурентов. Общие запросы — это минимум, без которого не обойтись. Запросы, которые есть у конкурентов, но нет у вас, — список новых страниц.
5. Посмотрите топовые страницы каждого конкурента: какие разделы и статьи приносят им больше всего запросов в топ-10.
6. Выгрузите запросы и проверьте частотность через парсер Вордстата. Затем сгруппируйте их кластеризацией.
7. Поставьте ключевые запросы на мониторинг позиций и смотрите динамику раз в неделю.
