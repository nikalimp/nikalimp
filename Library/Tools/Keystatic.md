## Описание

Keystatic — это бесплатная CMS для сайтов на Next.js, Astro и Remix, которая хранит контент в файлах Markdown, YAML и JSON прямо в git-репозитории.

Главное отличие — нет базы данных и отдельного сервера. Редактор правит контент в удобной админке, а Keystatic сохраняет изменения коммитами в репозиторий.

### Возможности
- **Админка внутри сайта** по адресу `/keystatic` с полями, формами и предпросмотром.
- **Схема контента в коде**: коллекции и синглтоны на TypeScript.
- **Хранение в git**: локально при разработке или в [[GitHub]] на продакшене.
- **Редактор Markdoc и MDX** с вашими компонентами.
- **Keystatic Cloud**: вход для редакторов без аккаунта GitHub и хранилище картинок.

### Кому подходит
Разработчикам статических и гибридных сайтов на [[Next.js]], которые хотят дать клиенту удобную админку, но не хотят поднимать базу данных.

### Как начать
Добавьте пакеты Keystatic в проект, опишите схему коллекций в `keystatic.config.ts` и откройте `/keystatic` локально. Для продакшена переключите хранилище на GitHub или Keystatic Cloud.

### Совет
Держите схему контента близко к структуре страниц: одно поле — один смысловой блок. Тогда клиент не сломает вёрстку, а сайт останется AI-Ready: весь текст лежит в репозитории и попадает в HTML при сборке.

### Ограничения
Подходит для сайтов с сотнями, а не сотнями тысяч записей. Каждое изменение запускает сборку сайта. Нет ролей и согласований как в [[Sanity]] или [[Payload CMS]]. Похожие git-CMS — [[TinaCMS]] и [[Decap CMS]].

## Частые вопросы
### Keystatic бесплатный?
Да, сама CMS бесплатная и с открытым кодом. Платный только Keystatic Cloud Pro — от $10 в месяц для команд больше трёх человек и хранилища картинок.

### Работает ли Keystatic в России?
Да, пакет ставится через npm, а контент лежит в вашем репозитории. Режим GitHub требует доступа к GitHub, Cloud Pro — зарубежной карты.

### Keystatic или TinaCMS?
Обе CMS хранят контент в git. [[TinaCMS]] даёт визуальное редактирование на странице и свой облачный бэкенд, Keystatic проще в настройке и бесплатнее для небольших команд.

### Можно ли дать клиенту правки без GitHub?
Да, через Keystatic Cloud: клиент входит по email, а изменения всё равно сохраняются в репозиторий.
