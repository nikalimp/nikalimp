# Keyword Insights

Буква: K · Страница на сайте: `/tools/keyword-insights`

## Описание

Keyword Insights — это SEO-сервис для кластеризации ключевых слов по выдаче Google: группирует тысячи запросов по пересечению результатов и определяет интент каждой группы.

Главное отличие — кластеры строятся по реальной выдаче, а не по похожести слов. Если две фразы приводят к одним и тем же страницам, они попадают в одну группу и закрываются одной страницей.

### Возможности
- **Кластеризация** по пересечению выдачи с настройкой порога.
- **Определение интента**: информационный, коммерческий, транзакционный, навигационный.
- **Контент-брифы** по топу выдачи: заголовки, вопросы, объём.
- **ИИ-помощник и агент** для написания статей по брифу.
- **Карта тем** для планирования топикальной экспертности.

### Кому подходит
SEO-специалистам, контент-маркетологам и агентствам, которые продвигают англоязычные и европейские сайты в Google.

### Как начать
Возьмите пробный период за $1, загрузите список ключей из [[Semrush]] или [[Ahrefs]] и запустите кластеризацию. По результату постройте структуру разделов и контент-план.

### Совет
Сначала кластеризуйте, потом пишите. Две статьи на запросы из одного кластера будут конкурировать друг с другом в выдаче, а одна сильная страница заберёт весь кластер.

### Ограничения
Только Google, без Яндекса. Кредиты быстро тратятся на большие списки и ИИ-тексты: статья ИИ-агентом стоит 1 200 кредитов. Для Рунета нужны другие инструменты.

От $58 в месяц за 10 000 кредитов, при оплате за год на 20% дешевле. Кластеризация стоит 1 кредит за ключ, бриф — 100 кредитов.

### Работает ли Keyword Insights в России?
Сайт открывается без VPN, но оплатить можно только зарубежной картой. Для Яндекса сервис не подходит.

### Keyword Insights или Key Collector?
Для Google и англоязычных рынков — Keyword Insights. Для Яндекса и Рунета — [[Key Collector]] или [[Rush Analytics]] с кластеризацией по выдаче Яндекса.

### Что такое кластеризация ключевых слов?
Это группировка запросов, которые можно продвигать одной страницей. Она помогает не плодить дубли и спланировать структуру сайта.
