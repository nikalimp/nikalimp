# Keyword Surfer

Буква: K · Страница на сайте: `/tools/keyword-surfer`

## Описание

Keyword Surfer — это бесплатное расширение для Chrome, которое показывает частотность запроса и похожие ключевые слова прямо в выдаче Google.

Главное отличие — не нужно открывать отдельный сервис. Вы вводите запрос в Google, а частотность, идеи и оценка трафика страниц появляются рядом с результатами.

### Возможности
- **Частотность запроса** по выбранной стране прямо в выдаче.
- **Похожие ключевые слова** с частотностью и степенью схожести.
- **Оценка трафика** для страниц в результатах.
- **Количество слов** на страницах из топа.
- **Генерация черновика** статьи с переходом в [[Surfer SEO]].

### Кому подходит
Копирайтерам, блогерам и SEO-специалистам, которые быстро проверяют спрос на тему перед написанием статьи для Google.

### Как пользоваться
Установите расширение из Chrome Web Store, выберите страну и вводите запросы в Google как обычно. Справа и под строкой поиска появятся частотность и идеи.

### Совет
Используйте расширение для быстрой проверки «есть ли спрос», а не для полноценного семантического ядра. Для ядра выгрузите идеи и проверьте их в [[Google Keyword Planner]] или [[Keywords Everywhere]].

### Ограничения
Только Google и только браузеры на Chromium. Данные о частотности приблизительные. Для Яндекса не подходит, для серьёзной аналитики нужны [[Semrush]] или [[Ahrefs]].

## Частые вопросы
### Keyword Surfer бесплатный?
Да, расширение бесплатное. Платный только основной сервис [[Surfer SEO]], который не обязателен для работы расширения.

### Работает ли Keyword Surfer в России?
Да, расширение работает в Chrome без VPN и показывает данные по выдаче Google. Для Яндекса оно бесполезно.

### Keyword Surfer или Keywords Everywhere?
Keyword Surfer бесплатный. [[Keywords Everywhere]] показывает больше данных и работает на других площадках, но за кредиты.

### Насколько точна частотность?
Это оценка, а не точные данные Google. Для решений о бюджете проверяйте цифры в [[Google Keyword Planner]] и [[Google Search Console]].
