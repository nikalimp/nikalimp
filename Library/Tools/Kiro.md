## Описание

Kiro — это AI-среда разработки от AWS, которая пишет код по спецификациям: сначала требования и план, потом задачи и реализация. Есть IDE на базе VS Code, CLI и веб-версия.

Главное отличие от [[Cursor]] и [[Windsurf]] — спецификационный подход: агент формирует документы требований, дизайна и список задач, и только потом меняет код.

### Возможности
- **Specs:** из описания фичи Kiro собирает требования, технический дизайн и план задач.
- **Hooks:** агент запускается по событиям — сохранению файла, коммиту, созданию компонента.
- **Steering:** правила проекта в Markdown, которые агент учитывает в каждом запросе.
- **Модели:** Claude Sonnet и открытые модели, режим Auto выбирает модель под задачу.
- **MCP:** подключение внешних инструментов и документации.

### Кому подходит
Разработчикам и командам, которые хотят, чтобы AI работал по плану, а не правил код наугад. Тем, кто уже знаком со spec-driven подходом.

### Как пользоваться
Установите IDE, войдите через GitHub, Google или AWS Builder ID и откройте проект. Опишите фичу в чате, выберите режим Spec и проверьте требования перед запуском задач.

### Совет
Перед первой задачей заполните steering-файлы: стек, структура папок, стиль кода. Агент будет меньше ошибаться.

### Ограничения
Кредиты расходуются быстро на крупных задачах. Бесплатного лимита хватает только на знакомство. Аналоги без спецификаций — [[GitHub Copilot]] и [[Cline]].

## Частые вопросы
### Kiro бесплатный?
Да, есть бесплатный план на 50 кредитов в месяц. Для регулярной работы нужен Pro за $20 в месяц.

### Работает ли Kiro в России?
Без VPN нет. Для оплаты нужна зарубежная карта.

### Kiro или Cursor?
[[Cursor]] быстрее в повседневных правках и автокомплите. Kiro лучше для крупных фич, где важно сначала согласовать требования и план.

### Что такое спецификации в Kiro?
Это три документа: требования, дизайн и задачи. Агент выполняет задачи по очереди и показывает изменения.
