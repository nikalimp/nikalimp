## Описание

LangGraph — это открытый фреймворк для AI-агентов с управляемым состоянием: логика агента описывается графом из узлов и переходов. Библиотеку разрабатывает команда [[LangChain]], есть версии для Python и JavaScript.

Главное отличие — контроль: вы явно задаёте шаги, циклы и точки остановки, вместо того чтобы отдать всё решение модели.

### Возможности
- **Граф состояний:** узлы, условные переходы, циклы и параллельные ветки.
- **Память и чекпоинты:** состояние сохраняется, диалог продолжается с места остановки.
- **Человек в контуре:** пауза для подтверждения действия перед выполнением.
- **Мультиагентность:** несколько агентов с супервизором или передачей задач.
- **Стриминг:** вывод токенов и промежуточных шагов в интерфейс.

### Кому подходит
Разработчикам, которые делают агентов для продакшена: поддержку, исследование данных, автоматизацию с проверками. Тем, кому мало простых цепочек [[LangChain]] и чатов в [[Dify]].

### Как начать
Установите `pip install langgraph`, опишите состояние в TypedDict и добавьте узлы. Начните с готового шаблона ReAct-агента и постепенно заменяйте шаги своей логикой.

### Совет
Включайте чекпоинтер с первого дня, даже в памяти. Отладка агента с историей состояний занимает минуты, а не часы.

### Ограничения
Высокий порог входа: нужно понимать графы и асинхронный Python. Для простых сценариев быстрее [[CrewAI]] или [[OpenAI Agents SDK]].

## Частые вопросы
### LangGraph бесплатный?
Да, библиотека открыта и бесплатна. Платные только облачный мониторинг и деплой в LangSmith.

### Работает ли LangGraph в России?
Да, библиотека ставится без ограничений. Для облака LangSmith нужна зарубежная карта, для зарубежных моделей — VPN.

### LangGraph или CrewAI?
[[CrewAI]] быстрее для команд агентов с ролями. LangGraph даёт больше контроля над шагами и состоянием.

### Нужен ли LangChain для LangGraph?
Нет, LangGraph работает и без него, но легко подключает модели и инструменты [[LangChain]].

## Цена

Библиотека бесплатна и открыта под лицензией MIT. Платные только облачные сервисы LangChain: мониторинг и деплой в LangSmith с бесплатным стартовым планом и оплатой по объёму.


## Доступность из России

Библиотека ставится через pip или npm и работает в России. Облачный LangSmith оплачивается зарубежной картой, а для моделей OpenAI и Anthropic нужен VPN.
