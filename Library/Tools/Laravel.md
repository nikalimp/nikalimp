## Описание

Laravel — самый популярный PHP-фреймворк для веб-приложений. Он делает разработку на PHP удобной: понятная структура, мощная работа с базой данных, очереди, авторизация, тестирование — всё в едином стиле.

Laravel создал Тейлор Отвелл в 2011 году. Вокруг фреймворка выросла экосистема официальных инструментов для админок, деплоя и мониторинга.

### Возможности
- **Eloquent ORM** для работы с базой данных.
- **Маршрутизация, middleware, контроллеры.**
- **Шаблоны Blade.**
- **Очереди,** события и планировщик задач.
- **Авторизация** и стартовые наборы.
- **Livewire и Inertia** для интерактивных интерфейсов.
- **Тестирование** из коробки.

### Кому подходит
PHP-разработчикам и веб-студиям, которые делают сервисы, личные кабинеты, CRM, магазины и API. Laravel хорошо подходит для российского рынка, где PHP-хостинг доступен повсеместно.

### Как начать
Установите PHP и Composer, создайте проект, подключите базу данных и выполните миграции. Используйте стартовый набор для авторизации.

### Как использовать в работе
Используйте очереди для тяжёлых задач — отправки писем, обработки файлов, интеграций, — чтобы интерфейс оставался быстрым.

### Где особенно полезен
В веб-сервисах средней сложности: кабинеты клиентов, системы бронирования, внутренние CRM.

### Совет
Используйте официальные пакеты экосистемы вместо самописных решений: они поддерживаются и совместимы с новыми версиями.

### Ограничения
Для простых сайтов достаточно CMS или конструктора.

### Кому не подойдёт
Командам без PHP-разработчиков и маленьким сайтам-визиткам, которые проще и дешевле сделать на конструкторе.

### Частый вопрос
**Laravel или Django?** Выбирают по языку команды: Laravel — PHP, [[Django]] — Python. Для фронтенда используют [[Vue.js]] или [[React]], хостинг — [[Beget]] или [[Timeweb Cloud]].

## Вердикт
- Кому подходит: разработчикам на PHP, которым нужен фреймворк для сайтов, сервисов и API с готовой инфраструктурой.

- Итог: бесплатный PHP-фреймворк с мощной экосистемой, а хостинг от создателей стоит отдельно.

## Плюсы
- Бесплатный, с открытым кодом.
- Есть готовые решения для авторизации, очередей, кэша и базы данных.
- Большое сообщество и много пакетов.
- Выкладку можно отдать Laravel Cloud или Forge.

## Частые вопросы
### Сколько стоит Laravel?
Сам фреймворк бесплатен. Хостинг Laravel Cloud начинается с $5 в месяц плюс расход, Forge — с $12 в месяц.

### Работает ли Laravel в России?
Да, фреймворк ставится и работает без ограничений. Платные облачные сервисы Laravel российской картой не оплатить.

### Что лучше: Laravel или Django?
Laravel — для PHP, Django — для Python. Выбирайте по языку, на котором пишет команда.

### Чем отличаются Laravel Cloud и Forge?
Cloud сам запускает приложения и масштабирует их, платите за расход. Forge управляет вашими серверами за фиксированную цену.
