## Описание

LaunchDarkly — это платформа feature flags: она включает и выключает функции в продукте без нового релиза. Через флаги команды выкатывают обновления на часть пользователей, проводят эксперименты и мгновенно откатывают ошибки.

Главное отличие — промышленный масштаб: SDK для десятков языков, правила таргетинга, аудит изменений и эксперименты на тех же флагах.

### Возможности
- **Feature flags:** включение функций по пользователям, сегментам, странам и процентам трафика.
- **Постепенный релиз:** выкатка на 1%, 10%, 50% аудитории с автоматическим откатом при ошибках.
- **Эксперименты:** A/B-тесты на флагах со статистикой по метрикам.
- **SDK:** клиентские и серверные библиотеки для JavaScript, React, iOS, Android, Python, Go и других.
- **Аудит и согласование:** история изменений и подтверждение флагов в продакшене.

### Кому подходит
Продуктовым командам, которые релизят часто и хотят отделить деплой от включения функций. Компаниям, где ошибка в релизе стоит дорого.

### Как начать
Создайте проект, установите SDK в приложение и оберните новую функцию проверкой флага. Включите флаг для своей команды, затем постепенно расширяйте аудиторию.

### Совет
Удаляйте флаги после полного запуска функции. Старые флаги превращаются в технический долг и запутывают код.

### Ограничения
Цена быстро растёт с числом пользователей и сервисов. Для небольших проектов дешевле [[GrowthBook]] или [[Statsig]], для маркетинговых A/B-тестов на сайте — [[VWO]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, API, iOS, Android

## Вердикт
- Кому подходит: Продуктовым командам, которые часто релизят и управляют функциями через флаги и эксперименты.
- Кому не подходит: Небольшим проектам с ограниченным бюджетом и российским компаниям без зарубежной карты.
- Итог: Стандарт рынка для feature flags с экспериментами, но дорогой при росте.

## Плюсы

- Постепенный релиз с автоматическим откатом
- Эксперименты на тех же флагах
- Аудит и согласование изменений

## Частые вопросы
### LaunchDarkly бесплатный?
Есть бесплатный план Developer для небольших проектов. Командам с ростом трафика нужна платная подписка.

### Работает ли LaunchDarkly в России?
Сервис доступен, но оплатить его российской картой нельзя. Нужна зарубежная карта.

### Чем заменить LaunchDarkly?
[[GrowthBook]] — открытая альтернатива с флагами и экспериментами на своём сервере. [[Statsig]] даёт щедрый бесплатный лимит.

### Что такое feature flag?
Это переключатель в коде, который включает функцию для выбранных пользователей без нового деплоя.
