## Описание

Leonardo Color — это бесплатный инструмент Adobe для генерации доступных цветовых палитр по целевому контрасту. Вы задаёте фон и нужные коэффициенты контраста, а Leonardo подбирает оттенки, которые им соответствуют.

Главное отличие от [[Coolors]] и [[Adobe Color]] — палитра строится от требований доступности, а не от эстетики: каждый цвет гарантированно читается на фоне.

### Возможности
- **Цвета по контрасту:** оттенки рассчитываются под коэффициенты WCAG, например 4,5:1 и 3:1.
- **Темы:** светлая и тёмная тема из одной палитры через смену фона.
- **Шкалы:** построение шкал в разных цветовых пространствах, включая OKLCH и CAM02.
- **Экспорт:** CSS-переменные, JSON и токены для дизайн-системы.
- **Библиотека:** npm-пакет `@adobe/leonardo-contrast-colors` для генерации в коде.

### Кому подходит
Дизайнерам дизайн-систем и интерфейсов, которым нужны доступные цвета для текста, кнопок и графиков. Разработчикам, которые генерируют темы программно.

### Как пользоваться
Откройте редактор тем, задайте фоновый цвет и добавьте ключевые цвета бренда. Укажите нужные коэффициенты контраста и экспортируйте результат в CSS или JSON.

### Совет
Задавайте коэффициенты по ролям: 4,5:1 для текста, 3:1 для иконок и границ. Тогда тёмная тема получается автоматически сменой фона.

### Ограничения
Интерфейс сложнее обычных генераторов палитр. Для быстрой проверки одной пары цветов проще [[WebAIM Contrast Checker]], для готовых шкал — [[Radix Colors]].

## Частые вопросы
### Leonardo Color бесплатный?
Да, это бесплатный инструмент Adobe с открытым кодом.

### Работает ли Leonardo Color в России?
Да, сайт открывается без VPN и регистрации.

### Leonardo Color или Coolors?
[[Coolors]] — для быстрого подбора красивых сочетаний. Leonardo — для палитр интерфейса с нужным контрастом.

### Leonardo Color и Leonardo.ai — это одно и то же?
Нет. Leonardo Color — инструмент Adobe для цвета, а [[Leonardo.ai]] — генератор изображений.
