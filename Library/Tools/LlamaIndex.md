## Описание

LlamaIndex — это открытый фреймворк для RAG и AI-агентов, которые работают с документами: он загружает данные, разбивает их, строит индекс и отвечает на вопросы с опорой на источники. Есть версии для Python и TypeScript.

Главное отличие от [[LangChain]] — фокус на данных: сотни загрузчиков, продвинутые стратегии индексации и парсер сложных PDF.

### Возможности
- **Загрузчики данных:** PDF, Notion, Google Drive, базы данных, сайты и сотни других источников.
- **Индексы и поиск:** векторный, гибридный и иерархический поиск с переранжированием.
- **Агенты и Workflows:** агенты с инструментами и событийные сценарии из нескольких шагов.
- **LlamaParse:** облачный парсер таблиц, схем и сканов в PDF.
- **Векторные базы:** [[Qdrant]], [[Pinecone]], [[Weaviate]], [[Chroma]] и другие.

### Кому подходит
Разработчикам, которые делают чат-боты по документам, базы знаний и поиск по внутренним данным компании.

### Как начать
Установите `pip install llama-index`, положите документы в папку и соберите `VectorStoreIndex` из пяти строк кода. Задайте вопрос через query engine и проверьте источники ответа.

### Совет
Качество RAG зависит от парсинга больше, чем от модели. Для PDF с таблицами используйте LlamaParse или похожий парсер, а не простой извлекатель текста.

### Ограничения
API часто меняется, примеры из старых статей устаревают. Для сложных агентов с ветвлениями удобнее [[LangGraph]].

## Частые вопросы
### LlamaIndex бесплатный?
Да, фреймворк открыт и бесплатен. Облачные LlamaParse и LlamaCloud дают бесплатный лимит, дальше — подписка.

### Работает ли LlamaIndex в России?
Да, библиотека ставится без ограничений. VPN и зарубежная карта нужны только для облака и зарубежных моделей.

### LlamaIndex или LangChain?
LlamaIndex сильнее в загрузке, индексации и поиске по документам. [[LangChain]] шире по интеграциям и цепочкам, а для агентов у него есть [[LangGraph]].

### Можно ли использовать LlamaIndex с локальными моделями?
Да, фреймворк работает с локальными моделями и эмбеддингами, поэтому данные не уходят за пределы вашего сервера.
