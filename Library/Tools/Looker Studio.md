## Описание

Looker Studio (раньше Google Data Studio) — бесплатный сервис Google для создания дашбордов и отчётов. Он подключается к Google Analytics, Search Console, Google Ads, Таблицам, BigQuery и сотням других источников через коннекторы.

Сервис популярен у маркетологов и агентств для клиентских отчётов: дашборд обновляется автоматически, а клиент видит его по ссылке.

### Возможности
- **Коннекторы Google:** GA4, Search Console, Ads, YouTube, Таблицы, BigQuery.
- **Сторонние коннекторы** к рекламным системам и CRM.
- **Графики, таблицы, карты** и индикаторы.
- **Фильтры, параметры** и вычисляемые поля.
- **Шаблоны отчётов** и темы оформления.
- **Совместное редактирование** и публикация.
- **Рассылка отчётов** по расписанию.

### Кому подходит
Маркетологам, SEO-специалистам и агентствам, которые отчитываются по данным Google. Аналитикам — для быстрой визуализации без BI-систем.

### Как начать
Создайте отчёт из шаблона Search Console или GA4, подключите свой ресурс и настройте фильтры. Поделитесь ссылкой с клиентом с правом просмотра.

### Как использовать в работе
Сделайте шаблон SEO-отчёта с данными Search Console и копируйте его для каждого клиента. Так ежемесячная отчётность занимает минуты.

### Где особенно полезен
В SEO-отчётах для проектов на Google: клики, показы, CTR и позиции по страницам и запросам в наглядном виде.

### Совет
Используйте Google Таблицы как промежуточный источник для данных без коннекторов: выгрузили — подключили — отчёт обновляется.

### Ограничения
Большие отчёты с множеством источников работают медленно.

### Частый вопрос
**Looker Studio или DataLens?** Looker Studio удобнее для данных Google, [[Яндекс DataLens]] — для Яндекса и российских источников. Данные берутся из [[Google Analytics 4]] и [[Google Search Console]].

## Вердикт
- Кому подходит: Маркетологу и агентству, которым нужны бесплатные отчёты из Google Analytics, Search Console, Google Ads и таблиц.
- Кому не подходит: Тому, кто хранит данные только в российских сервисах: для Метрики и Директа удобнее DataLens.
- Итог: Бесплатный конструктор отчётов для данных Google, а для остальных источников часто нужны платные коннекторы.

## Плюсы
- Бесплатен для создателей и зрителей отчётов.
- Коннекторы к GA4, Search Console, Google Ads, Таблицам и BigQuery.
- Отчёты можно делиться ссылкой и отправлять по расписанию.
- Много готовых шаблонов.

## Минусы

- Тяжёлые отчёты работают медленно.

## Частые вопросы
### Сколько стоит Looker Studio и есть ли бесплатный тариф?
Looker Studio бесплатен. Платная версия Looker Studio Pro стоит около $9 в месяц за пользователя в проекте и нужна для командного управления.

### Работает ли Looker Studio в России?
Да, сервис открывается из России. Но часть коннекторов к рекламным системам Google для российских аккаунтов неактуальна.

### Что лучше: Looker Studio или Яндекс DataLens?
Для данных Google (GA4, Search Console) выбирайте Looker Studio, для данных Яндекса — DataLens. DataLens платный для команд, Looker Studio бесплатен.

### Для чего нужен Looker Studio?
Для отчётов и дашбордов: сервис подтягивает данные из таблиц, аналитики и рекламных кабинетов и показывает их в графиках.
