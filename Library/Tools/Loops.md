## Описание

Loops — это сервис email-рассылок для SaaS-компаний: маркетинговые кампании, автоматические цепочки и транзакционные письма в одном месте.

Главное отличие — фокус на продуктах. Loops получает события из приложения через API и запускает цепочки по действиям пользователя: регистрация, первый проект, окончание пробного периода.

### Возможности
- **Кампании:** разовые рассылки по сегментам базы.
- **Цепочки (Loops):** автоматические сценарии по событиям и свойствам контакта.
- **Транзакционные письма:** подтверждения, сброс пароля, счета через API.
- **Визуальный редактор** писем без HTML-вёрстки.
- **Интеграции** со Stripe, Supabase, Segment и SDK для популярных языков.

### Кому подходит
Стартапам и SaaS-командам, которым нужна одна система для онбординга, новостей и системных писем без сложного маркетингового комбайна.

### Как начать
Подключите домен отправки, импортируйте контакты и отправьте из приложения событие регистрации. На это событие соберите приветственную цепочку из 3–4 писем.

### Совет
Держите транзакционные и маркетинговые письма на разных поддоменах: проблемы с репутацией рассылок не заденут письма со сбросом пароля.

### Ограничения
Тариф считается по числу подписчиков, поэтому для больших баз с редкими рассылками дешевле [[Brevo]] или [[Unisender]]. Для чисто транзакционных писем хватает [[Resend]] или [[Postmark]].

## Частые вопросы
### Loops бесплатный?
Да, до 1000 подписчиков и 4000 писем в месяц. В письмах на бесплатном тарифе стоит брендинг Loops.

### Работает ли Loops в России?
Сайт открывается без VPN, но оплатить тариф можно только зарубежной картой. Для работы в рублях подойдут [[Unisender]] или [[DashaMail]].

### Loops или Resend?
[[Resend]] — API для транзакционных писем для разработчиков. Loops закрывает и маркетинг: кампании, цепочки и сегменты.

### Как Loops получает данные о пользователях?
Через API, SDK или интеграции: приложение отправляет контакт и события, а Loops запускает по ним цепочки.
