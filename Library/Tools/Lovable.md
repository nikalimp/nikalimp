## Описание

Lovable — сервис для создания веб-приложений по текстовому описанию. Вы пишете, что нужно сделать, а AI собирает интерфейс, логику и подключает базу данных. Результат — рабочий сайт или сервис, который можно опубликовать в один клик.

Lovable основан в Стокгольме и стал одним из самых быстрорастущих AI-стартапов в категории вайб-кодинга.

### Возможности
- **Генерация приложения** по описанию или скриншоту.
- **Правки в диалоге:** «добавь фильтр», «сделай тёмную тему».
- **Визуальное редактирование** элементов.
- **Подключение Supabase:** база данных, авторизация, хранение файлов.
- **Синхронизация с GitHub** — код принадлежит вам.
- **Публикация** на поддомене или своём домене.

### Стек
Lovable генерирует код на React, TypeScript и Tailwind CSS. Его можно продолжить в [[Cursor]] или любом редакторе.

### Кому подходит
Предпринимателям и продуктовым менеджерам — для MVP и прототипов. Дизайнерам — чтобы превратить макет в работающий интерфейс. Фрилансерам — для быстрых внутренних инструментов, лендингов и админок.

### Как начать
Опишите приложение в одном абзаце: для кого, какие экраны, какие данные. Начните с главного экрана, затем добавляйте функции по одной. Подключите GitHub сразу.

### Совет
Не пытайтесь описать всё приложение одним запросом. Небольшие шаги дают меньше ошибок и тратят меньше кредитов.

### Ограничения
Сложная бизнес-логика и большие проекты быстро упираются в ограничения генерации. На определённом этапе код лучше передать разработчику.

### Частый вопрос
**Lovable или Bolt?** Сервисы похожи: оба собирают приложения по описанию. Lovable сильнее в интерфейсах и интеграции с Supabase. Для лендингов без кода подойдут [[Tilda]] и [[Framer]], для разработки с контролем кода — [[Cursor]].

## Частые вопросы
### Lovable бесплатный?
Да, есть бесплатный тариф: 5 кредитов в день, но не больше 30 в месяц. Платные тарифы начинаются от $25 в месяц.

### Работает ли Lovable в России?
Оплатить Lovable российской картой нельзя. Опубликованные приложения могут открываться нестабильно, поэтому для продакшена выгрузите код и разместите у себя.

### Что лучше: Lovable или Bolt.new?
Lovable проще для новичков и тесно связан с Supabase и GitHub. Bolt.new даёт среду разработки с терминалом и больше свободы для тех, кто читает код.

### Нужно ли уметь программировать для Lovable?
Нет, для прототипа достаточно описать идею словами. Для сложных вещей, например платежей и прав доступа, понимание кода сильно помогает.
