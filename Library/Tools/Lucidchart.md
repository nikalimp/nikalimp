## Описание

Lucidchart — онлайн-редактор диаграмм компании Lucid для блок-схем, схем процессов, оргструктур, ER-диаграмм и схем облачной инфраструктуры.

Главное отличие — строгие технические диаграммы и автоматизация: схемы строятся из данных, SQL и облачных аккаунтов, а не только рисуются вручную.

### Возможности
- **Библиотеки фигур:** BPMN, UML, ER, AWS, Azure, Google Cloud, сети.
- **Импорт данных:** оргструктуры из CSV, схемы баз из SQL, инфраструктура из облака.
- **Совместная работа** с комментариями и курсорами в реальном времени.
- **Условное форматирование** и данные внутри фигур.
- **Интеграции:** Google Workspace, Microsoft 365, Confluence, Slack.

### Кому подходит
Аналитикам, архитекторам, DevOps и продакт-менеджерам, которым нужны аккуратные технические диаграммы.

### Как начать
Выберите шаблон нужного типа, например BPMN-процесс, и замените блоки своими шагами. Ссылку на диаграмму вставьте в документацию.

### Совет
Для схемы базы данных не рисуйте таблицы вручную: импортируйте структуру через SQL-запрос, тогда схема совпадёт с реальной базой.

### Ограничения
Бесплатный план сильно урезан. Для свободных схем и мозговых штурмов удобнее [[Miro]] или [[Excalidraw]], а бесплатная замена — [[draw.io]].

## Частые вопросы
### Lucidchart бесплатный?
Есть бесплатный план с лимитом документов и фигур. Для постоянной работы нужна подписка.

### Работает ли Lucidchart в России?
Сайт открывается без VPN, бесплатный план работает. Платный тариф оплачивается только зарубежной картой.

### Lucidchart или draw.io?
[[draw.io]] бесплатный и закрывает большинство задач. Lucidchart удобнее в совместной работе и импорте данных.

### Можно ли построить схему базы данных в Lucidchart?
Да, через импорт SQL: сервис строит ER-диаграмму по структуре базы.
