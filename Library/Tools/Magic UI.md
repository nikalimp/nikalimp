# Magic UI

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · UI-библиотеки и компоненты · Global
Буква: M · Страница на сайте: `/tools/magic-ui`

## Описание

Magic UI — бесплатная библиотека анимированных React-компонентов и эффектов для лендингов на [[Tailwind CSS]] и Motion, совместимая с [[shadcn ui|shadcn/ui]].

Главное отличие — фокус на маркетинговых страницах. Вместо базовых кнопок и форм здесь бегущие строки логотипов, анимированные счётчики, сетки «бенто», светящиеся рамки и фоновые эффекты.

### Возможности
- **150+ компонентов** — эффекты текста, фоны, карточки, маркизы, кнопки, устройства.
- **Подход shadcn** — код копируется в проект, его можно править.
- **Установка через CLI** — компонент ставится одной командой shadcn.
- **Стек** — React, TypeScript, Tailwind CSS, [[Motion (motion.dev)]].
- **Magic UI Pro** — платные блоки и готовые шаблоны лендингов.

### Кому подходит
Фронтенд-разработчикам и дизайнерам, которые собирают лендинги SaaS и стартапов на [[Next.js]] и хотят быстро добавить «живые» анимированные блоки.

### Как начать
Настройте shadcn/ui в проекте, выберите компонент на сайте и выполните команду установки из документации. Компонент появится в папке components, дальше правьте его как свой код.

### Совет
Используйте 2–3 эффекта на страницу, не больше. Анимированные фоны и маркизы на каждом блоке утомляют и замедляют страницу на телефонах.

### Ограничения
Только React и Tailwind: для Vue и других фреймворков нужны аналоги. Многие сайты уже используют те же эффекты, поэтому без доработки дизайн выглядит шаблонно. Похожая библиотека — [[Aceternity UI]].

## Частые вопросы
### Magic UI бесплатный?
Да, основная библиотека из 150+ компонентов бесплатная, исходники открыты на GitHub. Платный только Magic UI Pro с шаблонами.

### Работает ли Magic UI в России?
Да, документация и установка через CLI работают без VPN. Для покупки Pro понадобится зарубежная карта.

### Magic UI или Aceternity UI?
Обе библиотеки дают анимированные блоки для лендингов на React и Tailwind. [[Aceternity UI]] чаще выбирают за 3D-эффекты и яркие фоны, Magic UI — за аккуратные эффекты в стиле shadcn/ui.

### Как подключить Magic UI к shadcn/ui?
Установите shadcn/ui в проект и добавляйте компоненты Magic UI через ту же CLI-команду. Компоненты используют общие токены цвета и Tailwind-конфиг.
