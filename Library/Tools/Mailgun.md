# Mailgun

Буква: M · Страница на сайте: `/tools/mailgun`

## Описание

Mailgun — сервис отправки транзакционных и массовых писем через API и SMTP для разработчиков: подтверждения регистрации, сброс пароля, чеки, уведомления. Принадлежит компании Sinch.

Главное отличие — ориентация на разработчиков. Письма отправляются из кода, а Mailgun берёт на себя доставляемость, логи, обработку входящей почты и проверку адресов.

### Возможности
- **API и SMTP** — отправка писем из любого языка и фреймворка.
- **Логи и вебхуки** — статусы доставки, открытия, клики, отказы.
- **Входящая почта** — маршрутизация писем на ваш сервер или вебхук.
- **Проверка адресов** — валидация email перед отправкой.
- **Выделенные IP** — для больших объёмов и контроля репутации.
- **Шаблоны** — хранение шаблонов писем с переменными.

### Кому подходит
Разработчикам веб-сервисов и SaaS с зарубежной аудиторией, которым нужна надёжная отправка системных писем и данные о доставке.

### Как начать
Зарегистрируйтесь, добавьте домен и пропишите DNS-записи SPF, DKIM и MX. Получите API-ключ и отправьте тестовое письмо через SDK или SMTP.

### Совет
Отправляйте транзакционные и маркетинговые письма с разных поддоменов. Так жалобы на рассылку не испортят доставку писем сброса пароля.

### Ограничения
Короткое хранение логов на младших тарифах, выделенный IP — с 50 000 писем. Конструктора рассылок для маркетолога почти нет. Для разработчиков есть альтернативы — [[Resend]], [[SendGrid]] и [[Amazon SES]].

## Вердикт
- Кому подходит: Разработчикам SaaS и веб-сервисов, которым нужна отправка системных писем через API с подробными логами.
- Кому не подходит: Маркетологам без разработчика и российским компаниям, которым нужна оплата в рублях.
- Итог: Надёжный сервис транзакционной почты для разработчиков с понятными тарифами по объёму.

## Плюсы
- Простой API и SMTP, SDK для популярных языков
- Обработка входящей почты и проверка адресов
- Бесплатно до 100 писем в день
- Выделенные IP на больших объёмах

## Минусы

- Нет удобного конструктора рассылок
- Оплата только зарубежной картой

## Частые вопросы
### Mailgun бесплатный?
Да, есть бесплатный план на 100 писем в день. Платные тарифы — от $15 в месяц за 10 000 писем.

### Работает ли Mailgun в России?
Сайт открывается, но оплатить можно только зарубежной картой, а регистрация из России может не пройти проверку аккаунта.

### Mailgun или SendGrid?
Оба сервиса для отправки писем через API. [[SendGrid]] сильнее в маркетинговых рассылках, Mailgun — в логах, входящей почте и маршрутизации.

### Чем заменить Mailgun в России?
[[Unisender]] и [[Notisend]] отправляют транзакционные письма через API и принимают оплату в рублях.
