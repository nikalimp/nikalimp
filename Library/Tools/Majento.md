# Majento

Буква: M · Страница на сайте: `/tools/majento`

## Описание

Majento — российский набор из 70+ онлайн-инструментов для SEO: проверка позиций в Яндексе и Google, аудит страниц, анализ текста, кластеризация запросов и технические проверки сайта.

Главное отличие — много мелких утилит в одном месте. Вместо одного большого комбайна Majento даёт отдельный инструмент на каждую задачу, а рядом есть десктопная программа SiteAnalyzer для полного аудита.

### Возможности
- **Позиции** — WordChecker для съёма позиций в Яндексе и Google, бесплатная проверка в Яндексе.
- **Технический аудит** — ответы сервера, битые ссылки, цепочки редиректов, robots.txt, индексация.
- **Контент** — проверка Title, Description и H1, релевантность текста, плотность ключей, уникальность.
- **Семантика** — кластеризация, проверка коммерциализации и геозависимости, парсинг подсказок.
- **Утилиты** — генератор sitemap, WHOIS, возраст домена, Punycode.
- **Расширения** — SiteAnalyzer SEO Tools и расширение для [[Яндекс Вордстат]].

### Кому подходит
SEO-специалистам и владельцам сайтов в Рунете, которым нужны быстрые точечные проверки без подписки на большой сервис.

### Как пользоваться
Зарегистрируйтесь, выберите нужный инструмент в каталоге и вставьте адрес страницы или список запросов. Для регулярного аудита скачайте SiteAnalyzer и проверяйте сайт целиком.

### Совет
Сравнивайте заголовки H1–H6 своей страницы с топ-10 конкурентов через инструмент сбора заголовков — это быстрый способ найти пропущенные подтемы.

### Ограничения
Интерфейс разрозненный: каждый инструмент работает отдельно, общего проекта нет. Для регулярного мониторинга позиций удобнее [[Топвизор]], для семантики — [[Key Collector]] и [[Rush Analytics]].

## Частые вопросы
### Majento бесплатный?
Частично: регистрация и многие онлайн-проверки бесплатные. Расширенные лимиты и мониторинг позиций платные, тарифы указаны на сайте.

### Работает ли Majento в России?
Да, это российский сервис: работает без VPN и принимает оплату в рублях.

### Majento или PR-CY?
[[PR-CY]] сильнее в общем анализе сайта и мониторинге, Majento — в точечных проверках текста, заголовков и семантики.

### Что такое SiteAnalyzer от Majento?
Десктопная программа для Windows, которая обходит сайт и находит технические ошибки: битые ссылки, дубли, редиректы, проблемы с метатегами. Аналог — [[Screaming Frog SEO Spider]].
