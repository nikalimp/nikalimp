## Описание

Material UI — библиотека React-компонентов по гайдлайнам Google Material Design: кнопки, формы, таблицы, меню и диалоги, готовые к использованию.

Главное отличие — зрелость и охват. Библиотека развивается с 2014 года, а платные компоненты MUI X закрывают сложные задачи: таблицы данных, графики, календари.

### Возможности
- **Более 50 компонентов** с доступностью и поддержкой клавиатуры.
- **Темизация** — цвета, шрифты, скругления через единую тему.
- **MUI X** — Data Grid, Date Pickers, Charts, Tree View.
- **Шаблоны** дашбордов и страниц входа.
- **Figma-кит** для дизайнеров.

### Кому подходит
Командам, которые делают админки, дашборды и внутренние сервисы на [[React]] и хотят быстро собрать интерфейс без своей дизайн-системы.

### Как начать
Установите @mui/material и @emotion/react, оберните приложение в ThemeProvider и задайте свою тему. Компоненты импортируйте по одному.

### Совет
Сразу настройте тему под бренд: без неё продукт выглядит как типичный сервис Google. Для публичных сайтов с собственным дизайном удобнее [[shadcn ui|shadcn/ui]] и [[Tailwind CSS]].

### Ограничения
Узнаваемый «материальный» стиль сложно переделать полностью. Стили на Emotion добавляют вес. Мощные таблицы и графики MUI X с группировкой и экспортом — только в платных версиях.

## Частые вопросы
### Material UI бесплатный?
Да, основная библиотека бесплатна под лицензией MIT. Платные только расширенные компоненты MUI X Pro и Premium.

### Работает ли Material UI в России?
Да, библиотека устанавливается через npm без ограничений. Для покупки MUI X нужна зарубежная карта.

### Material UI или Ant Design?
Оба подходят для админок. [[Ant Design]] сильнее в корпоративных таблицах и формах, Material UI — в темизации и экосистеме MUI X.

### Есть ли Material UI для Figma?
Да, есть официальный Figma-кит, который повторяет компоненты библиотеки.
