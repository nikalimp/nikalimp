# Merkle Schema Markup Generator

## Описание

Merkle Schema Markup Generator — бесплатный онлайн-генератор разметки Schema.org в формате JSON-LD из набора TechnicalSEO.com: вы заполняете поля формы, а инструмент собирает готовый код для вставки на страницу.

Главное отличие — простота. Не нужно помнить синтаксис JSON-LD и обязательные свойства: генератор подставляет нужные поля для каждого типа, а код обновляется по мере заполнения.

### Возможности
- **Популярные типы** — Article, Breadcrumb, Event, FAQ Page, How-to, Local Business, Organization, Person, Product, Video, Website и другие.
- **JSON-LD** — формат, который рекомендует Google.
- **Живое превью кода** — разметка собирается по мере заполнения формы.
- **Копирование в один клик** — готовый код вставляется в head или body страницы.
- **Соседние инструменты** — другие бесплатные проверки на [[TechnicalSEO.com Tools]].

### Кому подходит
SEO-специалистам, контент-менеджерам и владельцам сайтов на конструкторах, которым нужно быстро добавить разметку организации, статьи, FAQ или товара без разработчика.

### Как пользоваться
Выберите тип разметки, заполните поля и скопируйте код. Вставьте его на страницу и проверьте в [[Google Rich Results Test]] и [[Schema Markup Validator]].

### Совет
Для сайта услуг начните с Organization или LocalBusiness на главной и FAQ Page на страницах услуг: эти типы помогают и поиску, и нейросетям понять, кто вы и что предлагаете.

### Ограничения
Генератор создаёт разметку для одной страницы вручную: для каталогов и блогов нужна автоматическая генерация в CMS, например через [[Yoast SEO]] или [[Rank Math]]. Редких типов и вложенных связей между сущностями в форме нет. Для больших проектов есть [[Schema App]].
