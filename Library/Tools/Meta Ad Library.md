# Meta Ad Library

[[Инструменты — Маркетинг и аналитика|Маркетинг и аналитика]] · Контекстная и таргетированная реклама · Global
Буква: M · Страница на сайте: `/tools/meta-ad-library`

## Описание

Meta Ad Library — это открытая база рекламы, которая сейчас крутится в Facebook, Instagram, Messenger, Threads и Audience Network. Смотреть её может любой, без аккаунта.

Главное отличие — прозрачность: видно все активные объявления любой страницы, дату запуска и площадки показа, а для ЕС и политической рекламы ещё охват и бюджет.

### Возможности
- **Поиск по рекламодателю или ключевому слову** в любой стране.
- **Фильтры** по платформе, языку, типу медиа и дате показа.
- **Карточка объявления:** креатив, текст, ссылка, дата старта и варианты A/B.
- **Архив политической рекламы** с расходами и демографией за 7 лет.
- **API** для выгрузки рекламы о политике и рекламы в ЕС.

### Кому подходит
Таргетологам, маркетологам и предпринимателям, которые изучают креативы конкурентов перед запуском своей кампании в [[Meta Ads Manager]].

### Как пользоваться
Выберите страну и категорию «Все объявления», введите название бренда. Отсортируйте по дате: объявления, которые крутятся месяцами, обычно окупаются.

### Совет
Собирайте «свайп-файл»: скриншоты долгоживущих креативов конкурентов по нише. Так быстрее найти рабочие офферы и форматы, чем придумывать с нуля.

### Ограничения
Цифр по бюджету и кликам для коммерческой рекламы вне ЕС нет. Неактивные коммерческие объявления вне ЕС не хранятся. Из России без VPN не открывается.

## Карточка
- Россия: VPN
- Русский язык: есть
- Бесплатный план: есть
- Платформы: Веб, API

## Вердикт
- Кому подходит: Таргетологам и маркетологам, которые работают на зарубежные рынки через рекламу Meta.
- Кому не подходит: Тем, кто рекламируется только в России: аудитории Instagram и Facebook там без VPN нет, а рекламный кабинет недоступен.
- Итог: Бесплатный и честный способ подсмотреть креативы конкурентов в соцсетях Meta.

## Плюсы
- Полностью бесплатно и без регистрации
- Видны все активные объявления любой страницы
- Данные об охвате и бюджете для ЕС и политической рекламы
- Есть API для выгрузки

## Частые вопросы
### Meta Ad Library бесплатная?
Да, библиотека бесплатна и открыта даже без аккаунта Facebook. API тоже бесплатный, но требует подтверждения личности.

### Работает ли Meta Ad Library в России?
Только через VPN: Facebook и Instagram заблокированы в России.

### Meta Ad Library или Google Ads Transparency Center?
Это одна идея для разных рекламных сетей. [[Google Ads Transparency Center]] показывает рекламу в поиске Google, YouTube и КМС, Meta Ad Library — в Facebook и Instagram.

### Как найти рекламу конкурента?
Введите название страницы бренда, выберите страну и «Все объявления». В карточке видно креатив, дату запуска и площадки.

## Доступность из России

Сервисы Meta заблокированы в России, поэтому библиотека открывается только через VPN. Публичной библиотеки у [[VK Реклама]] и [[Telegram Ads]] нет, чужую рекламу в Telegram отслеживают через [[TGStat]].
