## Описание

Metabase — это open source BI-система для дашбордов и отчётов: подключаете базу данных и строите графики без SQL или с ним.

Главное отличие — низкий порог входа: менеджеры собирают отчёты через конструктор вопросов, а аналитики пишут SQL в том же интерфейсе.

### Возможности
- **Конструктор вопросов** без кода: фильтры, группировки, сводные таблицы.
- **SQL-редактор** с переменными и сниппетами.
- **Дашборды** с фильтрами, автообновлением и рассылкой по почте и в Slack.
- **Встраивание** графиков в свой продукт или личный кабинет клиента.
- **20+ коннекторов:** PostgreSQL, MySQL, ClickHouse, [[Google BigQuery]] и другие.

### Кому подходит
Стартапам и продуктовым командам, которые хотят дашборды по своей базе без лицензий [[Tableau]] или [[Power BI]].

### Как начать
Запустите Metabase в Docker одной командой, подключите базу только на чтение и дайте команде доступ. Первые дашборды Metabase предложит сам через «X-ray».

### Совет
Подключайте отдельную реплику базы, а не продакшн: тяжёлые запросы аналитиков не должны тормозить сайт.

### Ограничения
Сложная модель данных и права на уровне строк — только в платных тарифах. Для маркетинговых источников вроде рекламных кабинетов удобнее [[Looker Studio]].

## Частые вопросы
### Metabase бесплатный?
Да, open source версия бесплатна и без лимита пользователей, если вы ставите её на свой сервер. Облако платное.

### Работает ли Metabase в России?
Self-hosted версия работает без ограничений. Облачные тарифы требуют зарубежной карты.

### Metabase или Яндекс DataLens?
[[Яндекс DataLens]] — облачный сервис с оплатой в рублях и коннекторами к Метрике. Metabase лучше для своей базы и встраивания отчётов в продукт.

### Нужен ли SQL для Metabase?
Нет, простые отчёты собираются в визуальном конструкторе. SQL нужен для сложных выборок.
