Буква: M · Страница на сайте: `/tools/microsoft-azure`

## Описание

Microsoft Azure — облачная платформа Microsoft: виртуальные машины, базы данных, хранилище, DevOps и ИИ-сервисы, включая модели OpenAI.

Главное отличие — глубокая связь с продуктами Microsoft: Active Directory, Microsoft 365, .NET и Windows Server. Для компаний на этом стеке переход в Azure проще всего.

### Возможности
- **Virtual Machines** с Windows и Linux, 750 часов B1s в месяц бесплатно первый год.
- **Azure OpenAI** — модели OpenAI в инфраструктуре Microsoft.
- **Azure Functions** — функции без сервера, 1 млн запросов в месяц бесплатно.
- **Azure DevOps** — репозитории и CI/CD, бесплатно до 5 пользователей.
- **Базы данных:** SQL Database, PostgreSQL, Cosmos DB.

### Кому подходит
Корпоративным командам на стеке Microsoft и компаниям, которым нужен доступ к моделям OpenAI в контролируемой инфраструктуре.

### Как начать
Создайте бесплатный аккаунт с зарубежной картой и телефоном, получите $200 кредитов и разверните первую машину или функцию из портала.

### Совет
Сразу создайте группу ресурсов под каждый проект: удалив группу, вы удалите все её ресурсы и не забудете платный сервис.

### Ограничения
Для пользователей из России сервис закрыт. Портал сложный, а кредиты сгорают через 30 дней. Похожие платформы — [[AWS]] и [[Google Cloud]], в России — [[Yandex Cloud]] и [[Cloud.ru]].

## Частые вопросы
### Microsoft Azure бесплатный?
Бесплатный аккаунт даёт $200 кредитов на 30 дней и набор сервисов на 12 месяцев. Часть сервисов бесплатна всегда в пределах лимитов.

### Работает ли Microsoft Azure в России?
Нет. Microsoft прекратила продажи в России, а в 2024 году отключила облачные сервисы российским компаниям.

### Azure или AWS?
Azure удобнее на стеке Microsoft и для моделей OpenAI, [[AWS]] — шире по набору сервисов. В России оба недоступны.

### Что такое Azure OpenAI?
Это доступ к моделям OpenAI через инфраструктуру Microsoft с корпоративными гарантиями хранения данных. Для личных проектов проще [[OpenAI API]].
