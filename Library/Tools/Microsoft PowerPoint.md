# Microsoft PowerPoint

Буква: M · Страница на сайте: `/tools/microsoft-powerpoint`

## Описание

Microsoft PowerPoint — это программа для создания презентаций из пакета Microsoft 365: слайды, анимации, переходы, режим докладчика и совместная работа в облаке.

Главное отличие от [[Google Slides]] — мощность настольной версии: сложные анимации, морфинг, работа без интернета и стандартный формат PPTX, который откроют где угодно.

### Возможности
- **Шаблоны и Конструктор:** автоматические варианты оформления слайда.
- **Переход «Трансформация»** для плавной анимации между слайдами.
- **Copilot:** генерация и правка слайдов по запросу, резюме презентации.
- **Тренер докладчика:** обратная связь по темпу, словам-паразитам и интонации.
- **Совместная работа** в реальном времени, комментарии и упоминания.
- **Режим докладчика** с заметками и таймером.

### Кому подходит
Корпоративным командам, консультантам, преподавателям и всем, кто сдаёт презентации в PPTX. Для быстрых красивых презентаций с AI попробуйте [[Gamma]], для совместной работы бесплатно — [[Google Slides]].

### Как начать
Откройте PowerPoint в браузере или приложении, выберите шаблон и включите Конструктор. Начните со структуры: один слайд — одна мысль.

### Совет
Настройте образец слайдов со шрифтами и цветами бренда до вёрстки. Тогда новые слайды сразу будут в фирменном стиле.

### Ограничения
Полная версия и Copilot — только по подписке. Веб-версия урезана по анимациям и функциям. Из России подписку официально не купить.

## Частые вопросы
### PowerPoint бесплатный?
Веб-версия бесплатна с аккаунтом Microsoft. Настольная версия и Copilot — в подписке Microsoft 365 от $9,99 в месяц.

### Работает ли PowerPoint в России?
Программа работает, но Microsoft не продаёт подписки в России. Оплатить можно только зарубежной картой.

### PowerPoint или Google Slides?
PowerPoint сильнее в анимациях и офлайн-работе. [[Google Slides]] бесплатен и удобнее для совместного редактирования.

### Можно ли сделать презентацию в PowerPoint с помощью AI?
Да, Copilot создаёт слайды по запросу в платной подписке. Бесплатно похожее умеет [[Gamma]].
