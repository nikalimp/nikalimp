## Описание

Mintlify — это платформа для документации разработчиков: тексты хранятся в Git-репозитории в MDX, а сервис собирает из них быстрый сайт документации.

Главное отличие — документация сразу готова для ИИ: Mintlify сам генерирует llms.txt, MCP-сервер и встроенного ИИ-ассистента по вашим страницам.

### Возможности
- **Docs-as-code:** MDX в Git, превью для каждого pull request.
- **Веб-редактор** для тех, кто не работает с Git.
- **API-справочник** из спецификации OpenAPI с песочницей запросов.
- **ИИ-ассистент** отвечает пользователям по вашей документации.
- **llms.txt и MCP** генерируются автоматически.

### Кому подходит
SaaS-компаниям и API-продуктам, которым нужна красивая документация без своей вёрстки. Стартапам — для бесплатного старта.

### Как начать
Подключите репозиторий на [[GitHub]], выберите шаблон и опубликуйте сайт на поддомене. Свой домен подключается в настройках.

### Совет
Держите в первых абзацах страниц прямые ответы и примеры кода: такие страницы чаще цитируют ИИ-поисковики, а llms.txt помогает агентам найти нужный раздел.

### Ограничения
Между бесплатным планом и Pro большой ценовой разрыв. Если нужен полный контроль и свой хостинг, берите [[Docusaurus]].

## Частые вопросы
### Mintlify бесплатный?
Да, план Starter бесплатный и включает свой домен. ИИ-ассистент и расширенные функции — в Pro от $450 в месяц.

### Работает ли Mintlify в России?
Сервис работает и бесплатный план доступен. Оплата Pro — только зарубежной картой.

### Mintlify или GitBook?
[[GitBook]] удобнее для нетехнических авторов и внутренних баз знаний. Mintlify сильнее в документации API и готовности к ИИ.

### Что такое llms.txt в Mintlify?
Это файл со списком страниц документации для языковых моделей. Mintlify создаёт его автоматически, чтобы ИИ-ассистенты быстрее находили ответы.
