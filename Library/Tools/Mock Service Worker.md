# Mock Service Worker

## Описание

Mock Service Worker (MSW) — это библиотека для имитации API в JavaScript: она перехватывает сетевые запросы в браузере и Node.js и возвращает заданные ответы.

Главное отличие от моков в самом коде — перехват на уровне сети. Приложение делает настоящие запросы через fetch или axios, а MSW отвечает за сервер, поэтому код не меняется ради тестов.

### Возможности
- **REST и GraphQL:** обработчики запросов с понятным синтаксисом.
- **Браузер:** перехват через Service Worker во время разработки.
- **Node.js:** перехват в тестах на [[Vitest]], [[Jest]] и [[Playwright]].
- **WebSocket** и потоковые ответы.
- **Одни обработчики** для разработки, тестов и [[Storybook]].

### Кому подходит
Фронтенд-разработчикам, которые пишут интерфейс раньше готового бэкенда или тестируют компоненты без реального сервера.

### Как начать
Установите пакет msw, опишите обработчики для 2–3 запросов и подключите их в тестах через setupServer. Для браузера сгенерируйте файл воркера командой из документации.

### Совет
Храните обработчики рядом с типами API и переиспользуйте их в тестах, Storybook и локальной разработке. Так моки не расходятся с реальными ответами.

### Ограничения
Моки нужно обновлять вслед за API, иначе тесты проходят на устаревших данных. Для ручной проверки настоящего API подходят [[Postman]] и [[Bruno]].

## Частые вопросы
### Mock Service Worker бесплатный?
Да, библиотека бесплатна и распространяется под лицензией MIT.

### Работает ли Mock Service Worker в России?
Да, пакет ставится из npm без VPN и работает локально.

### MSW или Postman?
[[Postman]] нужен для ручной проверки и документации настоящего API. MSW подменяет API внутри приложения и тестов.

### Работает ли MSW с Next.js?
Да, MSW работает в браузерной части и в тестах. Для серверных компонентов настройка сложнее, примеры есть в документации.
