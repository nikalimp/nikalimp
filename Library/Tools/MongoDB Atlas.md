## Описание

MongoDB Atlas — это облачная версия документной базы данных MongoDB: кластер разворачивается в AWS, Google Cloud или Azure за несколько минут, без своего сервера.

Главное отличие — помимо базы, Atlas включает полнотекстовый и векторный поиск, поэтому одна платформа закрывает и данные приложения, и поиск для ИИ.

### Возможности
- **Документная модель:** JSON-подобные документы без жёсткой схемы.
- **Atlas Search** для полнотекстового поиска на Lucene.
- **Vector Search** для RAG и семантического поиска, замена отдельной векторной базы вроде [[Pinecone]].
- **Автомасштабирование, бэкапы и репликация** из коробки.
- **Драйверы** для Node.js, Python, Go, Java и других языков.

### Кому подходит
Стартапам и разработчикам на JavaScript-стеке, которые хотят хранить данные как JSON и масштабироваться без DevOps. Часто используется с [[Express]] и [[NestJS]].

### Как начать
Создайте бесплатный кластер M0, добавьте IP в список доступа и подключитесь по строке подключения из панели. Для схем и запросов поставьте MongoDB Compass.

### Совет
Проектируйте документы под запросы приложения, а не под таблицы: данные, которые читаются вместе, храните в одном документе.

### Ограничения
Из России работать сложно. Сложные связи и транзакции между множеством сущностей удобнее в реляционной базе. Цена выделенных кластеров быстро растёт.

## Вердикт
- Кому подходит: Зарубежным стартапам и разработчикам, которым нужна документная база с поиском и векторами без администрирования.
- Кому не подходит: Проектам в России и тем, у кого данные сильно связаны и требуют SQL.
- Итог: Удобная управляемая MongoDB с векторным поиском, но для российских проектов недоступна.

## Плюсы
- Бесплатный кластер навсегда
- Полнотекстовый и векторный поиск в одной базе
- Разворачивается в трёх крупных облаках
- Бэкапы и масштабирование без DevOps

## Минусы
- Из России нужен VPN и зарубежная карта
- Выделенные кластеры дорожают быстро
- Сложные связи между данными хуже, чем в SQL

## Частые вопросы
### MongoDB Atlas бесплатный?
Да, кластер M0 на 512 МБ бесплатен без ограничения по времени. Для продакшена берут Flex или выделенный кластер.

### Работает ли MongoDB Atlas в России?
Официально нет: регистрация и оплата из России ограничены. Российские проекты ставят MongoDB Community на свой сервер или берут управляемую документную базу в [[Yandex Cloud]].

### MongoDB Atlas или Supabase?
Supabase построен на PostgreSQL и даёт SQL, авторизацию и хранилище. Atlas лучше, если данные удобно хранить как документы и нужен встроенный поиск.

### Можно ли использовать Atlas для RAG?
Да, Atlas Vector Search хранит эмбеддинги рядом с данными, отдельная векторная база не нужна.
