## Описание

Motion — это библиотека анимаций для React, JavaScript и Vue, бывший Framer Motion. Она анимирует элементы, жесты, скролл и переходы между состояниями.

Главное отличие — гибридный движок: простые анимации идут через браузерный Web Animations API на 120 кадрах, сложные — через JavaScript, а API остаётся декларативным.

### Возможности
- **Декларативные анимации:** `<motion.div animate={{...}} />` в [[React]].
- **Layout-анимации:** плавная перестройка интерфейса при смене вёрстки.
- **Жесты:** hover, tap, drag и pan.
- **Скролл-анимации** и привязка к позиции прокрутки.
- **AnimatePresence** для анимации исчезновения компонентов.

### Кому подходит
Фронтенд-разработчикам на React и [[Next.js]], которые делают живые интерфейсы, лендинги и продуктовые микровзаимодействия.

### Как начать
Установите пакет `motion`, импортируйте `motion` из `motion/react` и замените `div` на `motion.div` с пропом `animate`. Документация на motion.dev даёт готовые примеры.

### Совет
Анимируйте `transform` и `opacity`, а не ширину и отступы: так анимация идёт на GPU и не дёргает вёрстку. Уважайте `prefers-reduced-motion` через хук `useReducedMotion`.

### Ограничения
Для сложных таймлайнов и сцен на скролле многие выбирают [[GSAP]]. Для иллюстрированной анимации от дизайнеров удобнее [[Lottie]] или [[Rive]].

- Кому подходит: Разработчикам на React и Next.js, которым нужны анимации интерфейса без лишнего кода.

- Итог: Стандарт де-факто для анимаций в React с удобным API и быстрым движком.

## Частые вопросы
### Motion бесплатный?
Да, библиотека бесплатна и с открытым кодом. Платный только Motion+ с примерами и компонентами.

### Работает ли Motion в России?
Да, библиотека ставится из npm без VPN. Ограничения касаются только оплаты Motion+.

### Motion или GSAP?
Motion удобнее в React-компонентах и для анимаций интерфейса. [[GSAP]] сильнее в сложных таймлайнах и скролл-сценах, работает с любым фреймворком.

### Framer Motion и Motion — одно и то же?
Да, в 2024 году Framer Motion стал независимым проектом Motion. Импорт сменился на `motion/react`, API остался прежним.
