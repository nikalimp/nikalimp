# Name.com

Буква: N · Страница на сайте: `/tools/name-com`

## Описание

Name.com — это американский регистратор доменов: регистрация и перенос доменов в сотнях зон, управление DNS, а также хостинг, почта и SSL-сертификаты. Сервис входит в группу Identity Digital.

Главное отличие — удобное API и инструменты для разработчиков. Через API регистрируют домены и правят DNS из своих сервисов, поэтому Name.com выбирают реселлеры и платформы.

### Возможности
- **Регистрация доменов** в .com, .io, .ai и сотнях других зон.
- **DNS-управление** с шаблонами для популярных сервисов.
- **Защита данных WHOIS** без доплаты.
- **API** для регистрации, продления и правки DNS.
- **Хостинг, почта, SSL** как дополнительные услуги.

### Кому подходит
Разработчикам и компаниям за пределами России, которым нужен международный домен и API для автоматизации.

### Как начать
Проверьте свободность имени, сравните цену регистрации и продления, добавьте домен в корзину. После оплаты пропишите DNS-записи или укажите NS-серверы своего хостинга.

### Совет
Смотрите на цену продления, а не первого года: скидки на старте часто перекрываются дорогим продлением. DNS удобнее держать в [[Cloudflare]], а домен — у регистратора с честной ценой.

### Ограничения
Российские карты не принимаются, есть риск блокировки аккаунта из России. Зоны .ru и .рф здесь не зарегистрировать — для них нужен российский регистратор: [[REG.RU]] или [[RU-CENTER]]. Для международных доменов по себестоимости смотрите [[Cloudflare Registrar]] или [[Porkbun]].

## Частые вопросы
### Сколько стоит домен на Name.com?
Домен .com обходится примерно в $10–12 за первый год, продление дороже. Цены других зон — на сайте при поиске имени.

### Работает ли Name.com в России?
Сайт открывается, но российские карты не принимают, а аккаунты из России могут заблокировать по санкционным правилам США. Держать на нём важный домен рискованно.

### Name.com или Namecheap?
[[Namecheap]] обычно дешевле на старте и проще для новичков, Name.com удобнее для работы через API. Для минимальной цены продления посмотрите [[Cloudflare Registrar]].

### Чем заменить Name.com в России?
[[REG.RU]] и [[RU-CENTER]] регистрируют и .ru, и международные зоны с оплатой в рублях.
