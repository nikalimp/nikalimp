## Описание

Neon — это бессерверный PostgreSQL в облаке: база запускается за секунды, сама засыпает без нагрузки и масштабируется под запросы. С 2025 года Neon принадлежит Databricks.

Главное отличие — ветки базы данных. Копию базы со всеми данными можно создать за секунду, как ветку в Git: для превью-окружения, теста миграции или эксперимента.

### Возможности
- **Serverless Postgres:** вычисления отдельно от хранения, засыпание без нагрузки.
- **Ветки базы** для каждого превью-деплоя и пулл-реквеста.
- **Автомасштабирование** вычислений под нагрузку.
- **Восстановление на момент времени** в пределах окна истории.
- **Драйвер для edge-функций** и интеграции с [[Vercel]].
- **Расширения Postgres**, включая pgvector для поиска по векторам.

### Кому подходит
Разработчикам на Next.js и других фреймворках, которые деплоят на Vercel или аналогичные платформы и хотят базу без администрирования.

### Как начать
Создайте проект в консоли, скопируйте строку подключения и подключите базу через [[Prisma]] или [[Drizzle ORM]]. Для превью включите интеграцию с Vercel — каждая ветка кода получит свою ветку базы.

### Совет
Для продакшена отключите засыпание или задайте минимальный размер вычислений: первый запрос после сна выполняется заметно дольше.

### Ограничения
Холодный старт на бесплатном плане. Нет встроенной авторизации и хранилища файлов, как у Supabase. Для проектов с данными россиян по 152-ФЗ нужна база на серверах в России.

## Вердикт
- Кому подходит: Разработчикам на Next.js и Vercel, которым нужен Postgres без администрирования и с ветками для превью.
- Кому не подходит: Проектам с персональными данными россиян: по 152-ФЗ базу нужно держать в России.
- Итог: Удобный serverless Postgres с ветками базы — один из лучших вариантов для превью-окружений.

## Плюсы
- Бесплатный план для пет-проектов и прототипов
- Ветки базы создаются за секунду
- Обычный PostgreSQL с расширениями
- Интеграция с Vercel из коробки

- Не подходит для данных по 152-ФЗ

## Частые вопросы
### Neon бесплатный?
Да, бесплатный план подходит для прототипов и небольших проектов. Платные тарифы считают вычисления и хранение по факту.

### Работает ли Neon в России?
Сайт и консоль открываются, бесплатный план доступен. Платные тарифы оплачиваются только зарубежной картой.

### Neon или Supabase?
Neon — только база с ветками и масштабированием. Supabase добавляет авторизацию, хранилище файлов и realtime. Если нужна только база под [[Prisma]] или [[Drizzle ORM]], проще Neon.

### Что такое ветка базы в Neon?
Мгновенная копия базы с данными, которая не занимает место, пока её не меняют. Её используют для тестов миграций и превью-окружений.
