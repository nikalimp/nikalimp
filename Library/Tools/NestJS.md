## Описание

NestJS — это фреймворк для серверных приложений на Node.js и TypeScript с модульной архитектурой, внедрением зависимостей и декораторами в стиле Angular.

Главное отличие — строгая структура: модули, контроллеры и сервисы задают единый порядок в коде, поэтому большой бэкенд остаётся читаемым и в команде.

### Возможности
- **Модули, контроллеры и провайдеры** с внедрением зависимостей.
- **REST и GraphQL** из коробки, документация API через [[Swagger]].
- **Микросервисы:** транспорт через Redis, Kafka, RabbitMQ, gRPC.
- **WebSockets** для чатов и уведомлений.
- **Работает поверх [[Express]] или Fastify** и интегрируется с [[Prisma]] и TypeORM.

### Кому подходит
Командам, которые пишут бэкенд на TypeScript и хотят архитектуру уровня Java Spring без хаоса в коде. Хорошо ложится на фронтенд на [[Next.js]] или Angular.

### Как начать
Установите Nest CLI, выполните `nest new project`, и получите готовый проект с тестами. Новые модули и ресурсы генерируются командой `nest g resource`.

### Совет
Держите бизнес-логику в сервисах, а контроллеры делайте тонкими. Валидируйте входные данные через DTO с class-validator — это защищает API от мусора.

### Ограничения
Много шаблонного кода для маленьких проектов: простой API быстрее написать на Express или Hono. Порог входа выше из-за декораторов и DI.

## Частые вопросы
### NestJS бесплатный?
Да, NestJS бесплатный и с открытым кодом под лицензией MIT.

### Работает ли NestJS в России?
Да, фреймворк ставится из npm и работает без ограничений.

### NestJS или Express?
[[Express]] минималистичен и подходит для небольших API. NestJS построен поверх Express и добавляет архитектуру, DI и готовые модули для больших проектов.

### Нужно ли знать TypeScript для NestJS?
Желательно: фреймворк написан на TypeScript и опирается на декораторы и типы.
