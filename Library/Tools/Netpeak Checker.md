## Описание

Netpeak Checker — это десктопная программа для массового анализа сайтов и URL: она собирает SEO-показатели сотен доменов из десятков сервисов в одну таблицу.

Главное отличие — агрегатор: в одном окне вы получаете данные [[Ahrefs]], [[Semrush]], [[Serpstat]], [[Majestic]], Moz и других сервисов, плюс парсите выдачу Google.

### Возможности
- **Массовая проверка доменов** по сотням параметров: трафик, ссылки, авторитет, индексация.
- **Парсинг выдачи** Google по списку запросов.
- **Интеграции** с SEO-сервисами по вашим API-ключам.
- **Проверка on-page:** статусы, мета-теги, редиректы, скорость.
- **Выгрузка в таблицы** и фильтры по любым параметрам.

### Кому подходит
SEO-специалистам и линкбилдерам, которые оценивают доноры для ссылок, конкурентов и списки сайтов сотнями.

### Как начать
Установите программу на Windows, подключите API-ключи нужных сервисов, вставьте список доменов и выберите параметры. Результат выгрузите в Google Sheets.

### Совет
Для отбора доноров сначала отсейте сайты по трафику и индексу, а потом проверяйте платные метрики Ahrefs или Semrush: так тратится меньше API-лимитов.

### Ограничения
Работает только на Windows. Данные многих сервисов требуют их платных API-ключей. Из России официально недоступен.
