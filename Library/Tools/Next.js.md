## Описание

Next.js — фреймворк на React для создания сайтов и веб-приложений. Он добавляет к React маршрутизацию, серверный рендеринг, генерацию статических страниц, оптимизацию изображений и другие функции, которые нужны в продакшене.

Фреймворк разрабатывает компания Vercel с 2016 года. Сегодня это самый популярный способ делать сайты на React: на нём работают сайты крупных компаний, медиа и стартапов.

### Возможности
- **App Router** и серверные компоненты React.
- **Режимы рендеринга:** статическая генерация, серверный рендеринг, инкрементальное обновление.
- **Статический экспорт** — готовый сайт из HTML-файлов для любого хостинга.
- **Оптимизация** изображений, шрифтов и скриптов.
- **Метаданные и SEO:** заголовки, Open Graph, sitemap и robots из кода.
- **API-маршруты** и серверные действия.

### Кому подходит
Разработчикам и командам, которые делают контентные сайты, интернет-магазины, SaaS и дашборды. Next.js хорош там, где важны скорость, SEO и масштаб: сотни и тысячи страниц собираются из данных автоматически.

### Как начать
Создайте проект командой `npx create-next-app`, выберите TypeScript и Tailwind CSS. Для интерфейса удобно подключить [[shadcn ui|shadcn/ui]].

### Next.js и GEO
Фреймворк позволяет генерировать llms.txt, разметку Schema.org и карточки страниц из одного источника данных. Каталог инструментов и глоссарий на nikalimp.ru собираются так: тексты лежат в Markdown, а сайт строится при каждой выкладке.

### Совет
Для сайта без личных кабинетов и форм с сервером используйте статический экспорт: его можно разместить на любом хостинге, он быстрый и почти не ломается.

### Частый вопрос
**Next.js или конструктор?** Конструкторы вроде [[Tilda]] быстрее на старте. Next.js даёт полный контроль и масштаб, но требует разработчика. Ускорить разработку помогают [[Cursor]] и [[Vercel]] для деплоя.

## Вердикт
- Кому подходит: Разработчикам на React, которым нужны сайты и сервисы с серверным рендерингом, маршрутизацией и быстрой загрузкой.
- Кому не подходит: Тем, кому нужен простой статичный сайт без сборки, и тем, кто не хочет учить React.
- Итог: Next.js — бесплатный фреймворк на React для сайтов и веб-приложений, платить нужно только за хостинг.

## Плюсы
- Серверный рендеринг и статический экспорт в одном фреймворке
- Маршрутизация по папкам, без ручной настройки
- Хорошо подходит для SEO: страницы отдают готовый HTML
- Огромное сообщество и экосистема
- Можно выложить на любой хостинг, в том числе российский

## Минусы
- Нужно знать React и немного Node.js
- Фреймворк быстро меняется, обновления иногда ломают проект
- Часть функций работает лучше всего на Vercel

## Частые вопросы
### Next.js бесплатный?
Да, сам фреймворк бесплатный с открытым кодом. Платить придётся за хостинг: на Vercel есть бесплатный тариф Hobby для личных проектов и Pro за $20/мес.

### Работает ли Next.js в России?
Да, фреймворк ставится через npm и работает без ограничений. Сайт можно собрать в статику и разместить на российском хостинге.

### Что лучше: Next.js или Astro?
Для контентных сайтов с минимумом скриптов подойдёт [[Astro]], для сервисов с сложной логикой и кабинетом — Next.js. Next.js опирается на React, Astro работает с несколькими фреймворками.

### Чем Next.js отличается от React?
[[React]] — библиотека для интерфейсов, а Next.js — фреймворк на ней. Он добавляет маршрутизацию, серверный рендеринг и сборку.
