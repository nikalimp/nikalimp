## Описание

Nextra — это open-source фреймворк для сайтов документации и блогов на [[Next.js]]: вы пишете страницы в Markdown и MDX, а Nextra собирает из них сайт с навигацией, поиском и тёмной темой.

Главное отличие — минимум настройки. Структура папок сразу становится меню, а готовая тема документации выглядит аккуратно без дизайнера.

### Возможности
- **MDX:** Markdown с React-компонентами внутри страниц.
- **Тема документации** с боковым меню, оглавлением, переключателем темы.
- **Поиск** по сайту без внешних сервисов.
- **Подсветка кода**, вкладки, плашки, схемы.
- **Мультиязычность** и статическая сборка.
- **Тема блога** для простых сайтов со статьями.

### Кому подходит
Разработчикам и командам, которые ведут документацию к библиотеке, API или продукту и уже работают с Next.js.

### Как начать
Создайте проект Next.js, установите Nextra и тему документации, добавьте папку с MDX-страницами. Разместите сайт на [[Vercel]] или любом статическом хостинге.

### Совет
Держите документацию в одном репозитории с кодом: правки в API и в документации попадут в один пулл-реквест и не разъедутся.

### Ограничения
Нет визуального редактора — править страницы удобно только тем, кто работает с Git. Для команды без разработчиков проще [[GitBook]] или [[Mintlify]]. Если нужна гибкость и больше компонентов, посмотрите [[Fumadocs]], для крупных проектов — [[Docusaurus]].

## Частые вопросы
### Nextra бесплатный?
Да, Nextra распространяется под лицензией MIT. Платить нужно только за хостинг, если он платный.

### Работает ли Nextra в России?
Да, пакет ставится из npm без ограничений, а готовый сайт размещается на любом хостинге.

### Nextra или Docusaurus?
[[Docusaurus]] построен на React без Next.js и лучше подходит для больших проектов с версиями документации. Nextra проще, если проект уже на Next.js.

### Можно ли сделать на Nextra блог?
Да, у Nextra есть тема блога. Для сложного блога с категориями и SEO-настройками удобнее собрать сайт на Next.js самостоятельно.
