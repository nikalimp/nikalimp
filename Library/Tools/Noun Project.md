# Noun Project

Буква: N · Страница на сайте: `/tools/noun-project`

## Описание

Noun Project — это библиотека из примерно 10 млн иконок от дизайнеров со всего мира в форматах SVG и PNG, с плагинами для Figma, Google Docs и других программ.

Главное отличие — масштаб: почти на любое понятие, от «бюджета» до «онбординга», найдётся десяток вариантов в разных стилях и почти 200 тыс. согласованных наборов.

### Возможности
- **Поиск по смыслу:** иконки находятся по словам и понятиям, а не только по названиям.
- **Наборы иконок** в одном стиле для интерфейса или презентации.
- **Редактор:** смена цвета и фона перед загрузкой.
- **Плагины** для [[Figma]], Google Slides, PowerPoint и других программ.
- **API** для встраивания иконок в продукт.
- **Noun Studio** для генерации иконок в стиле выбранного набора за кредиты.

### Кому подходит
Дизайнерам презентаций, инфографики, обучающих материалов и маркетинга, где нужна иконка на редкое понятие.

### Как пользоваться
Найдите понятие на английском, отфильтруйте по стилю, откройте иконку и скачайте SVG. На бесплатном аккаунте укажите автора по шаблону с сайта.

### Совет
Для интерфейса продукта берите один набор или одну open-source библиотеку вроде [[Lucide]] или [[Phosphor Icons]]: иконки разных авторов из Noun Project отличаются толщиной линий.

### Ограничения
Без подписки нужна атрибуция автора. Стиль иконок неоднородный, поиск лучше работает на английском.

## Частые вопросы
### Noun Project бесплатный?
Да, скачивать иконки можно бесплатно, но с указанием автора и без коммерческой лицензии. Подписка Noun Pro снимает эти ограничения.

### Работает ли Noun Project в России?
Сайт открывается без VPN, бесплатные загрузки доступны. Подписку оплачивают только зарубежной картой.

### Noun Project или Flaticon?
Noun Project больше в монохромных иконках на абстрактные понятия. [[Flaticon]] сильнее в цветных иконках и наборах для веба и презентаций.

### Как указывать автора иконки?
Сайт показывает готовую строку атрибуции при загрузке: имя автора и ссылку на Noun Project. Её ставят в подписи, титрах или на странице с источниками.
