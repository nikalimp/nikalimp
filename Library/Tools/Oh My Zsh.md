## Описание

Oh My Zsh — это бесплатный фреймворк для настройки оболочки Zsh: темы приглашения, сотни плагинов и автодополнения для git, Docker, npm и других инструментов.

Главное отличие — порог входа: одна команда установки, и терминал сразу показывает ветку git, подсказывает команды и даёт удобные алиасы.

### Возможности
- **Более 300 плагинов:** git, docker, npm, kubectl, z для быстрых переходов по папкам.
- **Более 140 тем** приглашения командной строки.
- **Алиасы** для частых команд: например, gst вместо git status.
- **Автообновление** фреймворка и плагинов.
- **Подключение внешних плагинов** вроде zsh-autosuggestions и подсветки синтаксиса.

### Кому подходит
Разработчикам и дизайнерам, которые часто работают в терминале на macOS или Linux и хотят удобную оболочку без долгой ручной настройки.

### Как начать
Установите Zsh (на macOS он уже стоит), выполните команду установки с сайта ohmyz.sh. Затем откройте файл ~/.zshrc и перечислите нужные плагины в строке plugins.

### Совет
Не включайте десятки плагинов: каждый замедляет запуск терминала. Начните с git, z и автоподсказок, а тему держите простой. Хорошая пара — [[iTerm2]] или [[Warp]] и [[Homebrew]].

### Ограничения
При большом числе плагинов терминал запускается заметно медленнее. Для Windows нужен WSL. Тем, кто хочет максимальную скорость, иногда удобнее более лёгкие менеджеры плагинов.

## Частые вопросы
### Oh My Zsh бесплатный?
Да, это проект с открытым кодом под лицензией MIT, платных функций нет.

### Работает ли Oh My Zsh в России?
Да, установка идёт с GitHub без VPN, регистрация и оплата не нужны.

### Чем заменить Oh My Zsh?
Можно настроить Zsh вручную или взять терминал со встроенными подсказками вроде [[Warp]]. Для быстрых команд и поиска пригодится [[Raycast]].

### Как удалить Oh My Zsh?
Выполните команду uninstall_oh_my_zsh в терминале. Она вернёт прежний файл настроек оболочки.
