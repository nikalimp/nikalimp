## Описание

OneDrive — это облачное хранилище Microsoft для файлов и фото с синхронизацией между устройствами и совместным редактированием документов Word, Excel и PowerPoint в браузере.

Главное отличие — глубокая связка с Windows и Microsoft 365: папки «Рабочий стол» и «Документы» автоматически копируются в облако, а офисные файлы открываются для совместной работы без пересылки.

### Возможности
- **Синхронизация папок** Windows и macOS с файлами по требованию, без занятия места на диске.
- **Резервная копия** рабочего стола, документов и фото.
- **Совместное редактирование** файлов Office в браузере и приложениях.
- **Личное хранилище** с дополнительной проверкой входа для важных документов.
- **Журнал версий** и восстановление после удаления или шифровальщика.
- **Ссылки для доступа** со сроком и паролем на платных тарифах.

### Кому подходит
Тем, кто работает в Windows и Office и хочет держать документы в облаке с доступом с телефона и других компьютеров.

### Как начать
Войдите в учётную запись Microsoft в приложении OneDrive, выберите папки для резервного копирования и включите файлы по требованию.

### Совет
Если нужна оплата в рублях и стабильный доступ из России, держите рабочие файлы в [[Яндекс Диск]], а OneDrive используйте для совместной работы с зарубежными клиентами.

### Ограничения
5 ГБ бесплатно быстро заканчиваются. Новую подписку из России оформить сложно. Для обмена файлами с клиентами из СНГ привычнее [[Google Drive]] и [[Dropbox]].

## Вердикт
- Кому подходит: Пользователям Windows и Office, которым нужны синхронизация и совместная работа с документами.
- Кому не подходит: Тем, кто хочет оплачивать облако в рублях и хранить данные в России.
- Итог: Удобное облако для экосистемы Microsoft, но платные тарифы из России доступны только с зарубежной картой.

## Плюсы
- Встроен в Windows, резервное копирование папок в пару кликов
- Совместное редактирование документов Office
- 1 ТБ и приложения Office в тарифе Personal
- Русский интерфейс и журнал версий файлов

## Минусы

- Новую подписку из России оплатить нельзя без зарубежной карты
- Риск ограничений доступа из-за санкций

## Частые вопросы
### OneDrive бесплатный?
Да, бесплатно доступно 5 ГБ. Больше места дают подписки Microsoft 365 от $1,99 в месяц.

### Работает ли OneDrive в России?
Бесплатный аккаунт и синхронизация обычно работают без VPN. Купить подписку из России можно только зарубежной картой.

### Чем заменить OneDrive?
В России — [[Яндекс Диск]] с оплатой в рублях. Для работы с зарубежными командами — [[Google Drive]] или [[Dropbox]].

### Как освободить место на диске с OneDrive?
Включите «Файлы по требованию»: файлы останутся в облаке и скачаются только при открытии.

## Доступность из России

Бесплатный аккаунт и синхронизация обычно работают из России без VPN. Microsoft прекратил продажи в России, поэтому подписку оплачивают только зарубежной картой; российские аналоги — Яндекс Диск и Облако Mail.
