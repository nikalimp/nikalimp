## Описание

OpenAI API — программный доступ к моделям OpenAI: GPT для текста и рассуждений, моделям для изображений, распознавания и синтеза речи, эмбеддингам для поиска по смыслу. На этом API построены тысячи AI-продуктов, ботов и автоматизаций.

Разработчик отправляет запрос с текстом и получает ответ модели в своё приложение: чат-бот поддержки, генератор описаний товаров, анализатор отзывов.

### Возможности
- **Текстовые модели** разных размеров и цен.
- **Responses API** с поиском в интернете, работой с файлами и вызовом функций.
- **Структурированные ответы** в формате JSON по схеме.
- **Изображения:** генерация и редактирование.
- **Речь:** распознавание и синтез голоса.
- **Эмбеддинги** для семантического поиска и RAG.
- **Агенты** через Agents SDK.
- **Batch API** — обработка больших объёмов со скидкой.

### Кому подходит
Разработчикам и компаниям, которые встраивают AI в продукты. Автоматизаторам на n8n и Make — для обработки текстов, классификации заявок и генерации контента.

### Как начать
Создайте аккаунт на платформе, пополните баланс и получите ключ. Начните с недорогой модели и тестируйте качество на реальных примерах. Установите лимиты расходов в настройках.

### Совет
Для массовых задач — описаний товаров, классификации, перевода — используйте Batch API: он дешевле, а результат приходит в течение суток.

### Безопасность
Не публикуйте ключ API в коде на GitHub и в браузерной части сайта. Ключ хранится только на сервере.

### Частый вопрос
**OpenAI API или ChatGPT?** [[ChatGPT]] — готовое приложение для людей, API — сырьё для разработчиков. Альтернативы — [[Anthropic API]] и [[Google AI Studio]], доступ ко многим моделям через один ключ — [[OpenRouter]]. В России с оплатой в рублях доступны [[YandexGPT]] и [[GigaChat]].

## Вердикт
- Кому подходит: Разработчикам и командам, которые встраивают в продукты языковые модели, генерацию изображений и аудио.
- Кому не подходит: Тем, кто хочет готовый чат без кода: для этого есть ChatGPT, а не API.
- Итог: Основной API с самыми популярными моделями и оплатой за токены, но из России нужны VPN, зарубежный аккаунт и карта.

## Плюсы
- Широкий набор моделей: от дешёвых до флагманских
- Оплата только за использование
- Подробная документация и готовые SDK
- Скидки на кэшированные запросы и пакетную обработку

## Минусы
- Официально не работает с Россией
- Нужна зарубежная карта
- Стоимость трудно предсказать при больших объёмах

## Частые вопросы
### Сколько стоит OpenAI API и есть ли бесплатный тариф?
Бесплатного тарифа нет, платите за токены: от $0,10 за 1 млн входных токенов у самой лёгкой модели до $10 у флагманской. Бесплатные кредиты при регистрации официальная страница цен не упоминает.

### Работает ли OpenAI API в России?
Официально нет: нужен аккаунт в поддерживаемой стране, зарубежная карта и VPN. Запросы с российских адресов блокируются.

### Что лучше: OpenAI API или Anthropic API?
Зависит от задачи: у обоих сильные модели и похожая оплата за токены. Лучше протестировать обе на своих данных, а для переключения между ними удобен OpenRouter.

### Чем API отличается от ChatGPT?
ChatGPT — готовый чат по подписке, а API — доступ к моделям для своих приложений с оплатой за токены. Подписка ChatGPT и баланс API оплачиваются отдельно.

OpenAI официально не работает с Россией: для ключа API нужен зарубежный аккаунт и карта, запросы из России блокируются.
