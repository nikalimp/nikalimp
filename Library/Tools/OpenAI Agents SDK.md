## Описание

OpenAI Agents SDK — это open-source библиотека OpenAI для создания AI-агентов на Python и TypeScript: агент получает инструкции, инструменты и может передавать задачу другим агентам.

Главное отличие — минимум абстракций. Вместо сложных графов, как в [[LangGraph]], SDK даёт несколько простых примитивов: агент, инструмент, передача задачи, проверки и трассировка.

### Возможности
- **Агенты** с инструкциями, моделью и набором инструментов.
- **Handoffs** — передача диалога от одного агента другому.
- **Guardrails** — проверки входа и выхода, которые останавливают агента.
- **Сессии** с автоматической историей диалога.
- **Трассировка** каждого шага для отладки в панели OpenAI.
- **Голосовые агенты** и поддержка моделей других провайдеров.

### Кому подходит
Разработчикам, которые строят ассистентов, чат-ботов поддержки и агентов для внутренних задач и уже работают с [[OpenAI API]].

### Как начать
Установите пакет, задайте ключ API и создайте агента с инструкцией и одной функцией-инструментом. Запустите его и посмотрите шаги в трассировке.

### Совет
Начинайте с одного агента и добавляйте второго только тогда, когда задача явно делится на роли. Многоагентные схемы сложнее отлаживать и дороже в токенах.

### Ограничения
SDK заточен под модели OpenAI: другие провайдеры подключаются, но часть функций работает только с OpenAI. Из России API недоступен без VPN. Альтернативы — [[Claude Agent SDK]], [[Vercel AI SDK]] для TypeScript и [[CrewAI]].

## Вердикт
- Кому подходит: Разработчикам на Python и TypeScript, которые строят агентов на моделях OpenAI.
- Кому не подходит: Тем, кто работает только с российскими моделями или не может оплачивать зарубежный API.
- Итог: Простой и бесплатный фреймворк для агентов, но привязанный к экосистеме OpenAI.

## Частые вопросы
### OpenAI Agents SDK бесплатный?
Да, сама библиотека бесплатна. Платить нужно за вызовы моделей по тарифам OpenAI или другого провайдера.

### Работает ли OpenAI Agents SDK в России?
Библиотека ставится без ограничений, но OpenAI API блокирует запросы из России. Нужен сервер за рубежом и зарубежная карта для оплаты.

### OpenAI Agents SDK или LangGraph?
[[LangGraph]] подходит для сложных процессов с явным графом состояний. OpenAI Agents SDK проще и быстрее для типичных агентов с инструментами.

### Можно ли использовать с SDK модели не от OpenAI?
Да, SDK поддерживает другие модели через совместимые API и адаптеры, но трассировка и часть встроенных инструментов рассчитаны на OpenAI.

## Доступность из России

Библиотека ставится из PyPI и npm без ограничений, но OpenAI API не работает из России: нужен VPN или сервер за рубежом и оплата зарубежной картой. Можно подключить другие модели, доступные из России.
