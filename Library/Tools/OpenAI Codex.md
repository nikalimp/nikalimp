## Описание

OpenAI Codex — AI-агент для программирования от OpenAI. Он выполняет задачи в кодовой базе: пишет функции, исправляет ошибки, проводит ревью и готовит пулл-реквесты. Codex работает в облаке, в терминале через Codex CLI и в расширениях для редакторов.

Название Codex OpenAI использовала ещё в 2021 году для модели, на которой работал первый GitHub Copilot. Современный Codex — уже полноценный агент.

### Возможности
- **Облачные задачи:** агент работает в изолированной среде с копией репозитория.
- **Codex CLI** — агент в терминале на вашем компьютере.
- **Расширения** для VS Code и других редакторов.
- **Ревью пулл-реквестов** на GitHub.
- **Параллельные задачи** — несколько поручений одновременно.
- **Запуск тестов** и проверка изменений.

### Кому подходит
Разработчикам, которые хотят делегировать рутинные задачи: тесты, рефакторинг, исправление багов, обновление зависимостей. Командам, где агент берёт задачи из бэклога.

### Как начать
Подключите репозиторий GitHub в интерфейсе Codex и дайте небольшую задачу с понятным критерием готовности: «добавь тесты для модуля оплаты». Проверьте результат как обычный пулл-реквест.

### Совет
Добавьте в репозиторий файл AGENTS.md с описанием проекта, команд сборки и тестов. Агент читает его и реже ошибается.

### Ограничения
Агент может решить задачу формально, не поняв бизнес-логику. Ревью человека обязательно.

### Где особенно полезен
В проектах с хорошими тестами: агент сам проверяет изменения, и ревью занимает минуты. Без тестов результат приходится проверять вручную гораздо дольше.

### Частый вопрос
**Codex или Claude Code?** Оба — агенты для программирования с терминальным интерфейсом. Выбор зависит от подписки и моделей, которые лучше работают на вашем проекте. Похожие инструменты — [[Cursor]], [[Windsurf]] и [[GitHub Copilot]].

## Вердикт
- Кому подходит: Разработчикам, которые уже платят за ChatGPT и хотят агента для кода в терминале, редакторе и облаке.
- Кому не подходит: Тем, кто не готов к VPN и зарубежной оплате.
- Итог: Codex входит в подписки ChatGPT и работает как агент, которому можно поручить задачу целиком.

## Плюсы
- Входит в подписку ChatGPT, отдельно платить не нужно
- Работает в вебе, CLI, расширении для редакторов и на iOS
- Автоматическое ревью кода и интеграция со Slack на платных тарифах
- Можно подключить по API-ключу и платить за расход

## Минусы
- Сервисы OpenAI недоступны в России без VPN и зарубежной оплаты
- Лимиты зависят от модели и задачи и считаются общими с ChatGPT
- Интерфейс на английском

## Частые вопросы
### Сколько стоит OpenAI Codex?
Codex входит в тарифы ChatGPT: есть бесплатный, Go за $8 в месяц, Plus за $20 и Pro от $100. Через API-ключ можно платить за фактический расход.

### Работает ли Codex в России?
Нет, официально сервисы OpenAI в России недоступны. Нужны VPN, зарубежный аккаунт и зарубежная карта.

### Что лучше: Codex или Claude Code?
Оба — агенты для кода в терминале и редакторе. Выбирают обычно по подписке, которая уже есть, и по тому, какая модель лучше справляется с вашим проектом.

### Есть ли у Codex бесплатный доступ?
Да, в бесплатном тарифе ChatGPT доступны простые задачи по коду. Лимиты небольшие, для регулярной работы нужен Plus или выше.
