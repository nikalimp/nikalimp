# Oxygen Builder

## Описание

Oxygen Builder — визуальный конструктор для [[WordPress (инструмент)|WordPress]], который заменяет тему целиком: шапку, подвал, шаблоны записей и страниц вы собираете сами.

Отличие от конструкторов страниц — Oxygen не надстраивается над темой, а полностью управляет выводом сайта, поэтому код получается чище, а страницы — быстрее.

### Возможности
- **Шаблоны сайта:** шапка, подвал, архивы, записи, страницы 404 без отдельной темы.
- **Динамические данные** из полей записей и пользовательских полей.
- **Глобальные стили,** классы и переменные, как в [[Webflow]].
- **Поддержка [[WooCommerce]]:** шаблоны карточек товара, корзины и оформления заказа.
- **Вставка своего кода** PHP, CSS и JavaScript прямо в редакторе.

### Кому подходит
Веб-разработчикам и студиям, которые делают сайты на WordPress и хотят полный контроль над вёрсткой без написания темы с нуля.

### Как начать
Установите плагин, отключите тему (Oxygen её не использует), создайте главный шаблон с шапкой и подвалом, затем шаблоны для записей и страниц.

### Совет
Сразу заведите систему классов и глобальных цветов. Если стилизовать каждый элемент отдельно, через полгода сайт станет трудно поддерживать.

### Ограничения
Порог входа выше, чем у Elementor: нужно понимать блочную модель и CSS. Если отключить плагин, сайт теряет вёрстку. Редактор на английском.

## Частые вопросы
### Oxygen Builder бесплатный?
Нет, бесплатной версии нет. Можно купить лицензию и вернуть деньги в гарантийный срок, если не подошло.

### Работает ли Oxygen Builder в России?
Сам плагин работает на любом хостинге. Для покупки нужна зарубежная карта, российские карты не принимаются.

### Oxygen или Bricks Builder?
[[Bricks Builder]] развивается активнее и удобнее в работе с классами. Oxygen выбирают те, у кого уже есть сайты на нём и опыт работы с ним.

### Нужна ли тема для Oxygen?
Нет. Oxygen отключает вывод темы и строит сайт по своим шаблонам, поэтому тема влияет только на панель администратора.
