# Park UI

Буква: P · Страница на сайте: `/tools/park-ui`

## Описание

Park UI — бесплатная библиотека готовых компонентов интерфейса, построенная на headless-библиотеке Ark UI и CSS-движке Panda CSS. Компоненты копируются в проект, как в [[shadcn ui|shadcn/ui]].

Главное отличие — поддержка нескольких фреймворков: те же компоненты доступны для React, Vue и Solid, а с 2024 года проект развивается внутри организации [[Chakra UI]].

### Возможности
- **Десятки компонентов:** формы, диалоги, меню, таблицы, вкладки, календарь.
- **Доступность из коробки** благодаря Ark UI: клавиатура, фокус, ARIA.
- **Темы и токены:** цвета, скругления и шрифты настраиваются в одном месте.
- **CLI** для добавления компонентов прямо в проект.
- **Несколько фреймворков:** React, Vue, Solid.

### Кому подходит
Фронтенд-разработчикам, которым нужен shadcn-подход, но с Panda CSS вместо [[Tailwind CSS]] или не только для React.

### Как начать
Установите Panda CSS и пресет Park UI, затем добавьте нужные компоненты через CLI. Настройте акцентный цвет и скругления в конфиге темы.

### Совет
Заранее решите, нужен ли вам Panda CSS. Если проект уже на Tailwind, переход ради одной библиотеки редко окупается — проще взять shadcn/ui.

### Ограничения
Сообщество и экосистема заметно меньше, чем у shadcn/ui: меньше готовых блоков, примеров и ответов на вопросы. Документация только на английском.

## Вердикт
- Кому подходит: Разработчикам на React, Vue или Solid, которые используют Panda CSS и хотят владеть кодом компонентов.
- Кому не подходит: Проектам на Tailwind, где уже стоит shadcn/ui, и тем, кому важна большая экосистема готовых блоков.
- Итог: Аккуратная бесплатная библиотека компонентов для Panda CSS с хорошей доступностью, но с небольшим сообществом.

## Частые вопросы
### Park UI бесплатный?
Да, библиотека бесплатная и распространяется с открытым кодом под лицензией MIT.

### Работает ли Park UI в России?
Да, пакеты ставятся через npm, а компоненты работают в вашем проекте без внешних сервисов.

### Park UI или shadcn/ui?
[[shadcn ui|shadcn/ui]] популярнее, работает на Tailwind и Radix и имеет огромную экосистему. Park UI выбирают для Panda CSS или Vue и Solid.

### Связан ли Park UI с Chakra UI?
Да, проект перешёл в организацию [[Chakra UI]] и использует Ark UI — headless-библиотеку той же команды.
