## Описание

ParseHub — это десктопная программа для парсинга сайтов без кода: вы кликаете по элементам страницы, а она собирает данные в CSV, JSON или Excel, в том числе с сайтов на JavaScript.

Главное отличие — работа со сложными страницами: бесконечная прокрутка, выпадающие списки, формы входа и вкладки, которые простые парсеры не видят.

### Возможности
- **Визуальный выбор данных** кликом по элементам.
- **Сайты на JavaScript и AJAX:** React, Angular, бесконечная лента.
- **Вложенная логика:** переход по ссылкам, условия, вход в аккаунт.
- **Облачный запуск по расписанию** и ротация IP на платных тарифах.
- **API и вебхуки** для выгрузки в свои системы.
- **Клиенты для Windows, macOS и Linux.**

### Кому подходит
Аналитикам и маркетологам, которым нужно собирать данные со сложных сайтов без программиста, в том числе на Linux.

### Как начать
Скачайте программу, откройте нужный сайт внутри неё и выделите первый элемент списка: ParseHub предложит выбрать похожие. Добавьте переход по страницам и запустите тест.

### Совет
Используйте бесплатный план для проверки, справится ли ParseHub с вашим сайтом. Если сайт простой, дешевле взять [[Octoparse]], а для потоковых задач — [[Apify]].

### Ограничения
Платные тарифы дороже конкурентов. Бесплатные проекты видны другим пользователям. Большие задачи идут медленно из-за полного рендеринга страниц. Для подготовки данных к LLM удобнее [[Firecrawl]].

## Частые вопросы
### ParseHub бесплатный?
Да, есть бессрочный бесплатный план: 200 страниц за запуск и 5 публичных проектов. Расписание и API — на платных тарифах.

### Работает ли ParseHub в России?
Программа работает из России. Платные тарифы оплачивают только зарубежной картой.

### ParseHub или Octoparse?
[[Octoparse]] дешевле и даёт готовые шаблоны. ParseHub лучше для сложных JavaScript-сайтов и работает на Linux.

### Нужно ли уметь программировать?
Нет, задачи собираются кликами. Знание HTML и регулярных выражений помогает в сложных случаях.
