## Описание

Payload CMS — это headless CMS и бэкенд-фреймворк на TypeScript с открытым кодом, который встраивается прямо в приложение на Next.js: админка, API и база данных в одном проекте.

Главное отличие — подход «код как конфиг»: схема данных описывается в TypeScript, а Payload сам генерирует админку, REST и GraphQL API и типы. В 2025 году проект перешёл под крыло Figma и остался открытым.

### Возможности
- **Нативная интеграция с [[Next.js]]:** CMS и сайт в одном репозитории.
- **Коллекции и поля в коде** с автогенерацией типов TypeScript.
- **REST, GraphQL и Local API** без лишних сетевых запросов.
- **Авторизация, права доступа, версии и черновики** из коробки.
- **Живой предпросмотр** и визуальный редактор блоков.
- **PostgreSQL, MongoDB и SQLite** на выбор.

### Кому подходит
Разработчикам и студиям, которые делают сайты и сервисы на Next.js и хотят полный контроль над данными без облачной подписки.

### Как начать
Выполните npx create-payload-app, выберите шаблон и базу данных. Опишите коллекции в конфиге и откройте админку по адресу /admin.

### Совет
Держите Payload и фронтенд в одном проекте и используйте Local API в серверных компонентах: страницы отдаются быстрее, а схему данных проще поддерживать.

### Ограничения
Нужен разработчик: без кода коллекции не настроить. Для контент-команд без программистов проще [[Sanity]] или [[Contentful]], для готового API из базы — [[Directus]].

## Частые вопросы
### Payload CMS бесплатный?
Да, это open-source проект под лицензией MIT. Платить нужно только за свой хостинг и при желании за корпоративную поддержку.

### Работает ли Payload CMS в России?
Да, CMS ставится через npm на любой сервер, включая российские облака. Регистрация и оплата не нужны.

### Payload CMS или Strapi?
Обе CMS открытые и ставятся на свой сервер. Payload встраивается прямо в Next.js и сильнее в TypeScript, [[Strapi]] даёт больше настроек через интерфейс.

### Какую базу данных выбрать для Payload?
PostgreSQL — надёжный выбор для большинства проектов. MongoDB удобна для гибких схем, SQLite — для небольших сайтов и тестов.
