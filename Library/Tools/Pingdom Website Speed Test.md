# Pingdom Website Speed Test

## Описание

Pingdom Website Speed Test — бесплатный онлайн-тест скорости загрузки страницы от сервиса мониторинга Pingdom. Показывает время загрузки, вес страницы, число запросов и водопад загрузки ресурсов.

Главное отличие от [[Google PageSpeed Insights]]: Pingdom меряет реальную загрузку из выбранного города и показывает, какой файл тормозит, а не оценку Core Web Vitals.

### Возможности
- **Оценка производительности** по шкале от 0 до 100 с советами, что исправить.
- **Время загрузки, вес и число запросов** на одном экране.
- **Водопад запросов:** DNS, SSL, соединение, ожидание и получение для каждого файла.
- **Разбивка по типам контента** и доменам: видно, сколько весят скрипты, картинки и сторонние сервисы.
- **Выбор точки теста** в Европе, Азии, Северной и Южной Америке, Австралии.

### Кому подходит
Разработчикам и SEO-специалистам, которым нужно быстро найти тяжёлый файл, медленный сторонний скрипт или долгий ответ сервера.

### Как пользоваться
Вставьте адрес страницы, выберите ближайшую к аудитории точку, например Франкфурт для России, и запустите тест. Затем отсортируйте водопад по времени или весу.

### Совет
Запускайте тест 2–3 раза: первый прогон часто идёт без кэша CDN. Сверяйте результат с [[GTmetrix]] и [[WebPageTest]].

### Ограничения
Точек теста в России нет, мобильного профиля и Core Web Vitals тоже. Для оценки Google используйте [[Google PageSpeed Insights]] и [[Chrome UX Report]].

## Вердикт
- Кому подходит: Тем, кто ищет конкретную причину медленной загрузки: тяжёлые файлы, лишние запросы, медленный сервер.

- Итог: Простой бесплатный тест с понятным водопадом запросов, удобный для быстрой проверки страницы.

## Частые вопросы
### Pingdom Website Speed Test бесплатный?
Да, тест скорости бесплатный и не требует регистрации. Платят только за мониторинг Pingdom.

### Работает ли Pingdom Website Speed Test в России?
Тест обычно открывается без VPN. Оплатить платный мониторинг можно только зарубежной картой.

### Pingdom или Google PageSpeed Insights?
[[Google PageSpeed Insights]] оценивает Core Web Vitals и даёт рекомендации Google. Pingdom показывает фактическую загрузку и водопад запросов. Лучше использовать оба.

### Почему результаты отличаются от других тестов?
Сервисы меряют из разных городов, с разными каналами и кэшем. Сравнивайте результаты одного сервиса до и после правок.
