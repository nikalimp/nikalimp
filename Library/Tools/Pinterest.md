## Описание

Pinterest — визуальная поисковая система и социальная сеть для идей. Пользователи сохраняют картинки (пины) на тематические доски: интерьеры, рецепты, мода, дизайн, свадьбы, путешествия.

Pinterest запустили в 2010 году. В отличие от других соцсетей, им пользуются как поисковиком: люди ищут идеи и вдохновение и возвращаются к сохранённому через месяцы.

### Возможности
- **Доски** для сбора идей по темам.
- **Визуальный поиск:** найти похожие изображения по фрагменту картинки.
- **Пины со ссылками** на сайты-источники.
- **Видео-пины** и идеи из нескольких слайдов.
- **Бизнес-аккаунт** со статистикой.
- **Совместные доски** для команд и клиентов.

### Кому подходит
Дизайнерам — для мудбордов и насмотренности. Интерьерным студиям, свадебным агентствам, брендам одежды, кулинарным блогам — как источник трафика на сайт. Маркетологам — для поиска визуальных трендов.

### Pinterest как источник трафика
Пины живут долго и приводят переходы на сайт месяцами. Для этого изображения должны быть вертикальными, с понятным заголовком, а описание — с ключевыми словами, по которым ищут.

### Как собрать мудборд
Создайте секретную доску под проект, сохраните 30–50 изображений, затем оставьте 10–15 самых точных. Покажите доску клиенту до начала дизайна — так проще договориться о стиле.

### Совет
Используйте раздел «Похожие пины» под каждым изображением: так за несколько минут можно уйти глубоко в нужную стилистику, а не листать общую ленту.

### Ограничения
Многие пины ведут на источники без указания автора. Перед коммерческим использованием изображений найдите правообладателя.

### Частый вопрос
**Pinterest или Dribbble для насмотренности?** [[Dribbble]] — работы дизайнеров интерфейсов и брендинга, Pinterest — широкий визуальный поиск по любым темам. Для бесплатных фото с понятной лицензией подойдёт [[Unsplash]].

## Частые вопросы
### Pinterest бесплатный?
Да, для пользователей и бизнес-аккаунтов сервис бесплатный. Платные только рекламные кампании.

### Работает ли Pinterest в России?
Сайт и приложение открываются из России. Запустить рекламу российская компания не может.

### Что лучше: Pinterest или Behance?
Pinterest нужен для сбора референсов, Behance — для показа своих работ. Для поиска идей берите Pinterest, для портфолио — Behance.

### Для чего дизайнеру Pinterest?
Он нужен для сбора референсов: цвета, композиции, стили. Из досок удобно собирать мудборды для клиентов.
