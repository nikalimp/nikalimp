## Описание

Plasmic — это визуальный конструктор страниц и интерфейсов для React и Next.js: дизайнер собирает экраны мышкой, а разработчик подключает их к коду и данным.

Главное отличие от [[Webflow]] и [[Framer]] — Plasmic не держит сайт у себя. Страницы встраиваются в ваш проект как компоненты, а хостинг остаётся вашим: [[Vercel]], свой сервер или любая платформа.

### Возможности
- **Визуальный редактор** с сеткой, адаптивом, вариантами компонентов и состояниями.
- **Свои компоненты из кода:** разработчик регистрирует React-компоненты, и они появляются в панели редактора.
- **Два способа интеграции:** загрузка страниц через API или генерация кода прямо в репозиторий.
- **Данные:** подключение к REST, GraphQL, базам и headless CMS.
- **Импорт из [[Figma]]** через плагин.

### Кому подходит
Командам на React и Next.js, где маркетологи и дизайнеры хотят менять лендинги без участия разработчика. Агентствам, которые отдают клиенту визуальный редактор вместо CMS.

### Как начать
Создайте проект в браузере, соберите страницу из готовых блоков, затем подключите её к Next.js по инструкции из документации: это несколько строк кода и ключ проекта.

### Совет
Зарегистрируйте в Plasmic базовые компоненты дизайн-системы, например кнопки и карточки на [[shadcn ui|shadcn/ui]]. Тогда редакторы будут собирать страницы из ваших деталей, и вёрстка не разъедется.

### Ограничения
Без разработчика Plasmic раскрывается наполовину: подключение к проекту, данные и свои компоненты требуют кода. Для простого сайта-визитки проще взять [[Tilda (инструмент)|Tilda]].

## Вердикт
- Кому подходит: Командам на React и Next.js, где нетехнические сотрудники должны сами править страницы.
- Кому не подходит: Тем, кому нужен конструктор «всё в одном» с хостингом и без программиста.
- Итог: Визуальный редактор, который встраивается в ваш код, а не заменяет его.

## Плюсы
- Страницы живут в вашем проекте и на вашем хостинге
- Можно использовать собственные React-компоненты
- Бесплатный план подходит для пробы и небольших проектов
- Открытый исходный код редактора

## Частые вопросы
### Plasmic бесплатный?
Да, есть бесплатный план для небольших проектов. Командные тарифы платные, от $39 в месяц.

### Работает ли Plasmic в России?
Редактор работает без VPN. Оплатить платный тариф российской картой не получится, понадобится зарубежная.

### Plasmic или Builder.io?
Оба встраивают визуальный редактор в код. [[Builder.io]] сильнее как headless CMS для контента и экспериментов, Plasmic удобнее для сборки сложных интерфейсов из своих компонентов.

### Можно ли собрать в Plasmic внутреннее приложение?
Да, в Plasmic есть режим приложений с данными и формами. Но для админок быстрее взять [[Retool]].
