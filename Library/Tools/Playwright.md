## Описание

Playwright — фреймворк Microsoft для автоматизации браузеров и сквозного тестирования веб-приложений. Он управляет Chromium, Firefox и WebKit: открывает страницы, кликает, заполняет формы, делает скриншоты и проверяет результат.

Playwright вышел в 2020 году и быстро стал одним из главных инструментов тестирования. Его также используют для парсинга и AI-агентов, которые работают в браузере.

### Возможности
- **Три движка браузеров** одним API.
- **Автоматическое ожидание** элементов — меньше нестабильных тестов.
- **Скриншоты и видео** выполнения.
- **Трассировка** — пошаговый разбор упавшего теста.
- **Эмуляция** мобильных устройств, геолокации, темы.
- **Генератор тестов** по записанным действиям.
- **JavaScript, TypeScript, Python, Java, .NET.**

### Кому подходит
Разработчикам и тестировщикам веб-приложений, специалистам по автоматизации, разработчикам AI-агентов для браузера.

### Как начать
Установите Playwright, запустите генератор тестов и пройдите ключевой сценарий сайта — например, отправку формы. Сохраните тест и запускайте его перед каждым релизом.

### Как использовать в работе
Делайте скриншоты страниц в разных размерах экрана автоматически: так легко проверить вёрстку сайта на десятке устройств после изменений.

### Где особенно полезен
В регрессионном тестировании: ключевые сценарии — регистрация, заказ, оплата — проверяются автоматически при каждом изменении кода.

### Совет
Тестируйте сценарии пользователя, а не детали вёрстки: такие тесты реже ломаются при редизайне.

### Ограничения
Тесты требуют поддержки при изменениях интерфейса.

### Кому не подойдёт
Сайтам-визиткам без сложной логики.

### Связка
Тесты запускают автоматически в GitHub Actions при каждом коммите и пулл-реквесте.

### Частый вопрос
**Playwright или Cypress?** Cypress удобен для фронтенд-разработчиков в Chrome, Playwright поддерживает больше браузеров и языков. Ошибки в продакшене ловит [[Sentry]], код хранится на [[GitHub]].

## Вердикт
- Кому подходит: разработчикам и тестировщикам, которым нужны автотесты сайтов сразу в трёх браузерах.
- Кому не подходит: тем, кто не пишет код: для ручной проверки лучше подойдут записывающие сервисы.
- Итог: Бесплатный фреймворк Microsoft для автотестов в браузере, сейчас один из главных выборов.

## Частые вопросы
### Сколько стоит Playwright?
Ничего: это бесплатный инструмент с открытым кодом под лицензией Apache 2.0.

### Работает ли Playwright в России?
Да, ставится из npm или PyPI без ограничений.

### Что лучше: Playwright или Cypress?
[[Playwright]] поддерживает три браузерных движка и несколько языков, [[Cypress]] проще для старта на JavaScript. Для новых проектов чаще берут Playwright.

### Для чего нужен Playwright?
Он управляет браузером из кода: открывает страницы, жмёт кнопки, проверяет результат. Им пишут автотесты и собирают данные с сайтов.
