## Описание

PostCSS — это инструмент для обработки CSS с помощью JavaScript-плагинов: он разбирает стили в дерево, плагины его меняют, а на выходе получается готовый CSS.

Главное отличие от [[Sass]] — PostCSS сам ничего не умеет. Всё делают плагины, поэтому вы подключаете только нужное: префиксы, современный синтаксис, минификацию.

### Возможности
- **Autoprefixer:** автоматические вендорные префиксы по списку браузеров.
- **postcss-preset-env:** современный CSS с переводом в совместимый вид.
- **Минификация** через cssnano.
- **Интеграция с [[Tailwind CSS]]** через официальный плагин.
- **Сотни плагинов** и возможность написать свой.

### Кому подходит
Фронтенд-разработчикам на любых сборщиках: [[Vite]], Webpack, [[Next.js]]. Во многих проектах PostCSS уже работает внутри сборки, даже если вы его не настраивали.

### Как пользоваться
Установите postcss и нужные плагины через npm, создайте postcss.config.js и перечислите плагины. Сборщик подхватит конфиг автоматически.

### Совет
Держите список плагинов коротким: каждый плагин замедляет сборку. Для большинства проектов хватает Autoprefixer и плагина Tailwind, а минификацию часто делает сам сборщик.

### Ограничения
Порядок плагинов влияет на результат, и ошибки в нём трудно отлаживать. Часть задач PostCSS уже забирают Lightning CSS и встроенные возможности сборщиков, в том числе Tailwind CSS 4.

## Частые вопросы
### PostCSS бесплатный?
Да, это открытый проект под лицензией MIT. Платить не нужно ни за ядро, ни за плагины.

### Работает ли PostCSS в России?
Да, без ограничений: он ставится через npm и работает локально.

### PostCSS или Sass?
[[Sass]] — препроцессор со своим синтаксисом: переменные, миксины, вложенность. PostCSS обрабатывает обычный CSS плагинами. Их часто используют вместе.

### Нужен ли PostCSS для Tailwind CSS?
В Tailwind CSS 3 он был обязателен. В Tailwind CSS 4 есть плагин для Vite без PostCSS, но плагин @tailwindcss/postcss по-прежнему поддерживается.
