## Описание

Postman — платформа для разработки и тестирования API. В ней отправляют запросы к API, сохраняют их в коллекции, пишут автотесты, генерируют документацию и делятся всем этим с командой.

Postman начинался в 2012 году как расширение для Chrome и стал стандартом работы с API: им пользуются десятки миллионов разработчиков.

### Возможности
- **Запросы** REST, GraphQL, WebSocket, gRPC.
- **Коллекции** запросов с папками и переменными.
- **Окружения:** разработка, тест, продакшен.
- **Тесты** ответов на JavaScript.
- **Мок-серверы** для фронтенда без готового бэкенда.
- **Документация API** из коллекций.
- **AI-помощник** для запросов и тестов.

### Кому подходит
Бэкенд- и фронтенд-разработчикам, тестировщикам, специалистам по интеграциям и автоматизации, которые работают с API сервисов.

### Как начать
Создайте коллекцию, добавьте запрос к API — например, к CRM, — и сохраните токен в переменной окружения.

### Как использовать в работе
Проверяйте API сервиса в Postman до настройки интеграции в n8n или Make: так проще понять формат данных и найти ошибки.

### Где особенно полезен
В интеграциях с CRM, платёжными системами и маркетплейсами, где нужно разобраться в документации и протестировать запросы.

### Совет
Храните токены в переменных окружения, а не в самих запросах: так коллекцию можно безопасно передать коллеге.

### Ограничения
Командные функции в бесплатной версии ограничены.

### Кому не подойдёт
Тем, кто не работает с API.

### Частый вопрос
**Postman или Bruno?** Bruno — бесплатная альтернатива с хранением коллекций в файлах репозитория, Postman — платформа с облаком и командной работой. Автоматизации с API собирают в [[n8n]] и [[Make]].

## Вердикт
- Кому подходит: разработчикам и тестировщикам, которые работают с API и хотят собрать запросы, тесты и документацию в одном месте.
- Кому не подходит: тем, кому нужен лёгкий клиент без облака и аккаунта: ближе [[Bruno]].
- Итог: Самый известный клиент для API с бесплатным тарифом, но платные планы российской картой не оплатить.

- Есть интеграция с Git и VS Code

## Частые вопросы
### Сколько стоит Postman?
Бесплатный тариф стоит $0 в месяц. Solo — $9 в месяц, Team — $19 за пользователя в месяц при оплате за год.

### Работает ли Postman в России?
Приложение работает, а платные планы российской картой не оплатить: нужна карта зарубежного банка. Об этом пишут российские гайды по оплате 2026 года.

### Чем заменить Postman?
Ближайшие аналоги — [[Bruno]], [[Insomnia]] и [[Hoppscotch]]. Bruno хранит запросы в файлах и работает без облака.

### Что можно делать в Postman?
Отправлять запросы к API, писать к ним тесты, запускать моки и вести документацию.
