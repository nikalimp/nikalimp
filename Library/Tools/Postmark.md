# Postmark

Буква: P · Страница на сайте: `/tools/postmark`

## Описание

Postmark — это сервис отправки транзакционных писем через API и SMTP: подтверждения регистрации, сброс пароля, чеки и уведомления.

Главное отличие от [[SendGrid]] и [[Mailgun]] — скорость и доставляемость. Postmark разделяет транзакционные и маркетинговые потоки и следит за качеством отправителей, поэтому письма реже попадают в спам.

### Возможности
- **API и SMTP** для отправки из любого приложения.
- **Раздельные потоки** для транзакционных писем и рассылок.
- **Шаблоны писем** с переменными и предпросмотром.
- **Статистика:** доставки, открытия, отказы, жалобы.
- **Входящие письма** с разбором в JSON через вебхук.

### Кому подходит
SaaS-проектам, интернет-магазинам и приложениям, где важно, чтобы письмо с кодом или чеком пришло за секунды.

### Как начать
Зарегистрируйтесь, подтвердите домен через записи DKIM и Return-Path, пройдите проверку аккаунта и отправьте первое письмо через API или SMTP.

### Совет
Не отправляйте через транзакционный поток рекламные рассылки. Для них в Postmark есть отдельный broadcast-поток, иначе пострадает доставляемость важных писем.

### Ограничения
Новые аккаунты проходят ручную проверку, без неё отправка ограничена. Для разработчиков на Next.js с простым API удобнее [[Resend]], а для дешёвых больших объёмов — [[Amazon SES]].

## Карточка
- Россия: зарубежная карта

## Вердикт
- Кому подходит: Приложениям и SaaS, которым важна быстрая и надёжная доставка служебных писем.
- Кому не подходит: Российским проектам без зарубежной карты и тем, кто ищет самый дешёвый массовый SMTP.
- Итог: Один из самых надёжных сервисов для транзакционных писем с акцентом на доставляемость.

## Плюсы
- Высокая доставляемость и скорость
- Раздельные потоки для служебных писем и рассылок
- Понятная статистика и логи писем
- Обработка входящих писем

## Минусы
- Дороже Amazon SES на больших объёмах
- Ручная проверка новых аккаунтов
- Оплата только зарубежной картой

## Частые вопросы
### Postmark бесплатный?
Только для тестов: бесплатный план даёт 100 писем в месяц. Для рабочего проекта нужен платный тариф.

### Работает ли Postmark в России?
Сайт доступен, но оплата возможна только зарубежной картой, а аккаунт проходит ручную проверку.

### Postmark или Resend?
[[Resend]] удобнее для разработчиков на React и Next.js и дешевле на старте. Postmark дольше на рынке и сильнее в доставляемости и аналитике.

### Чем заменить Postmark в России?
Для транзакционных писем с оплатой в рублях подойдут [[Unisender]] и [[Notisend]].

## Доступность из России

Сайт открывается, но российские карты не принимаются. Сервис проверяет новые аккаунты вручную и может отказать в подключении, поэтому для оплаты нужна зарубежная карта, а для российских проектов есть [[Unisender]] и [[Notisend]].
