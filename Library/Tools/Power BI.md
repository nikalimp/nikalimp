# Power BI

[[Инструменты — Маркетинг и аналитика|Маркетинг и аналитика]] · Дашборды и BI · Global
Буква: P · Страница на сайте: `/tools/power-bi`

## Описание

Power BI — BI-система Microsoft для отчётов и дашбордов: подключаете источники данных, строите модель и визуализации, публикуете отчёты для команды.

Главное отличие — связка с экосистемой Microsoft: Excel, Azure, Teams и SharePoint, плюс мощный язык формул DAX для сложных расчётов.

### Возможности
- **Power BI Desktop** — бесплатное приложение для Windows, где собирают модель данных и отчёты.
- **Power Query** — загрузка и очистка данных из Excel, баз, API и сотен коннекторов.
- **DAX** — формулы для мер, когорт, план-факта и расчётов по периодам.
- **Облачный сервис** — публикация, обновление по расписанию, доступ по ролям.
- **Встраивание отчётов** в сайты и приложения через Power BI Embedded.

### Кому подходит
Аналитикам и компаниям, которые живут в Excel и [[Microsoft Azure]] и собирают управленческую отчётность из нескольких систем.

### Как начать
Скачайте Power BI Desktop, подключите таблицу или базу, соберите модель «звезда» и первые визуализации. Публикация в облако нужна, когда отчёт смотрят другие люди.

### Совет
Сначала спроектируйте модель данных: таблицы фактов и справочники. Отчёт на плохой модели тормозит и считает неверно, сколько ни настраивай визуализации.

### Ограничения
Desktop работает только на Windows. Совместный доступ платный для каждого зрителя. В России легальная покупка недоступна, поэтому российские компании переходят на [[Яндекс DataLens]] или [[Looker Studio]].

- Россия: VPN и зарубежная карта
- Русский язык: есть
- Бесплатный план: есть
- Платформы: Веб, Windows, iOS, Android

## Вердикт
- Кому подходит: Аналитикам и компаниям в экосистеме Microsoft, которым нужны сложные расчёты и управленческие дашборды.
- Кому не подходит: Российским компаниям, которым нужна легальная оплата и данные в РФ, а также пользователям macOS.
- Итог: Один из самых мощных BI-инструментов, но для работы из России нужны обходные пути.

## Плюсы
- Desktop-версия бесплатная и полноценная для построения отчётов
- DAX и Power Query закрывают сложную аналитику без программирования
- Сотни коннекторов к базам, сервисам и файлам
- Большое сообщество и много обучающих материалов на русском

## Минусы
- Desktop только для Windows
- Pro-лицензия нужна каждому, кто смотрит отчёты в облаке
- Нет продаж в России, аккаунты российских компаний ограничены

## Частые вопросы
### Power BI бесплатный?
Power BI Desktop бесплатный: в нём можно строить модель и отчёты. Чтобы делиться отчётами через облако, нужна платная лицензия Pro или Premium Per User.

### Работает ли Power BI в России?
Desktop можно использовать, если удалось его установить. Облачный сервис требует аккаунта Microsoft вне РФ, VPN и зарубежной карты для оплаты.

### Power BI или Яндекс DataLens?
Power BI сильнее в моделировании данных и DAX. [[Яндекс DataLens]] бесплатен в базовом варианте, работает в России и хранит данные в российском облаке.

### Нужно ли знать программирование для Power BI?
Нет, базовые отчёты собираются мышкой. Для сложных расчётов понадобится DAX, а для подготовки данных — Power Query.

## Доступность из России

Microsoft не продаёт подписки в России: для облачного сервиса нужны VPN, зарубежная карта и аккаунт вне РФ. Российский аналог — Яндекс DataLens.
