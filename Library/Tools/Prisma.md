## Описание

Prisma — ORM для Node.js и TypeScript: инструмент, через который приложение работает с базой данных. Вы описываете модели данных в понятном файле схемы, а Prisma генерирует типизированный клиент и миграции для PostgreSQL, MySQL, SQLite и других баз.

Prisma популярна в проектах на Next.js и стала одним из стандартных выборов для работы с базой в TypeScript.

### Возможности
- **Схема данных** в отдельном читаемом файле.
- **Типизированный клиент:** редактор подсказывает поля и ловит ошибки.
- **Миграции** — изменения структуры базы под контролем версий.
- **Prisma Studio** — визуальный просмотр и редактирование данных.
- **Поддержка** PostgreSQL, MySQL, SQLite, SQL Server, MongoDB.
- **Облачная база** Prisma Postgres.

### Кому подходит
Разработчикам на TypeScript, командам, которые делают веб-сервисы на Next.js и Node.js, и тем, кто хочет безопасно работать с базой без ручного SQL.

### Как начать
Установите Prisma в проект, опишите модели в файле схемы, подключите базу и запустите миграцию. Используйте сгенерированный клиент в коде.

### Как использовать в работе
Храните схему в репозитории и применяйте миграции через CI: структура базы на всех окружениях всегда одинаковая.

### Где особенно полезен
В проектах, где AI-помощники пишут код: строгие типы Prisma помогают ловить ошибки сгенерированного кода на этапе разработки.

### Совет
Смотрите на генерируемые запросы при сложных выборках: иногда один запрос через ORM превращается в десятки обращений к базе.

### Ограничения
Для очень сложных аналитических запросов удобнее писать SQL напрямую.

### Кому не подойдёт
Проектам не на JavaScript и TypeScript.

### Частый вопрос
**Prisma или Drizzle?** Drizzle легче и ближе к SQL, Prisma — удобнее схемой и инструментами. Базы данных — PostgreSQL на своём сервере или Supabase, фреймворк — [[Next.js]].

## Частые вопросы
### Сколько стоит Prisma?
Prisma ORM бесплатна. Облачная база Prisma Postgres стоит от $0 в месяц, платные планы — $10, $49 и $129 в месяц.

### Работает ли Prisma в России?
ORM работает без ограничений, ставится из npm. За облачные сервисы российской картой не заплатить.

### Что лучше: Prisma или Drizzle?
[[Prisma]] проще для старта и показывает данные в Studio. [[Drizzle ORM]] ближе к SQL и легче по размеру.

### Что такое Prisma?
Это ORM: вы описываете таблицы в схеме, а Prisma создаёт типизированный клиент для запросов.
