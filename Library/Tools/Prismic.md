# Prismic

Буква: P · Страница на сайте: `/tools/prismic`

## Описание

Prismic — это облачная headless CMS, в которой разработчики описывают блоки страниц, а маркетологи собирают из них страницы в визуальном редакторе.

Главное отличие от [[Contentful]] и [[Sanity]] — подход «слайсов»: страница собирается из готовых секций сайта, которые разработчик создаёт в коде через Slice Machine.

### Возможности
- **Slice Machine:** создание блоков в коде с превью и автоматической синхронизацией.
- **Редактор страниц** с живым предпросмотром.
- **Интеграции** с [[Next.js]], Nuxt и SvelteKit.
- **Мультиязычность** и локали.
- **Планирование публикаций** и релизы.

### Кому подходит
Командам, которые делают маркетинговые сайты на Next.js или Nuxt и хотят отдать маркетологам сборку страниц без участия разработчика.

### Как начать
Создайте репозиторий в Prismic, запустите стартовый шаблон для своего фреймворка, опишите первые слайсы в Slice Machine и отправьте их в CMS.

### Совет
Делайте слайсы крупными и законченными: «Герой с формой», «Тарифы», «Отзывы». Мелкие блоки дают маркетологам слишком много свободы, и сайт теряет единый стиль.

### Ограничения
Схему контента задают в коде, и без разработчика новый тип блока не добавить. Для сложных структурированных данных и связей гибче [[Sanity]] или [[Payload CMS]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, API

## Вердикт
- Кому подходит: Командам маркетинговых сайтов на Next.js и Nuxt, где маркетологи собирают страницы из готовых блоков.
- Кому не подходит: Проектам со сложной структурой данных и тем, кому нужна CMS на своём сервере.
- Итог: Удобная headless CMS для лендингов и маркетинговых сайтов с подходом слайсов.

## Плюсы
- Сборка страниц из готовых секций
- Slice Machine связывает код и CMS
- Бесплатный план для одного пользователя
- Хорошие стартеры для Next.js и Nuxt

## Минусы
- Новые блоки требуют разработчика
- Оплата только зарубежной картой
- Меньше гибкости в моделировании данных, чем у Sanity

## Частые вопросы
### Prismic бесплатный?
Да, для одного пользователя есть бесплатный план. Для команды нужен платный тариф.

### Работает ли Prismic в России?
API и редактор работают без VPN, но оплатить подписку можно только зарубежной картой.

### Prismic или Sanity?
[[Sanity]] гибче в структуре данных и настройке редактора. Prismic проще для маркетинговых сайтов, где страницы собирают из готовых блоков.

### Чем заменить Prismic на своём сервере?
[[Payload CMS]], [[Strapi]] или [[Directus]]: их можно развернуть на российском хостинге.

## Доступность из России

Сервис открывается без VPN, контент отдаётся через API. Российские карты не принимаются, поэтому для платного тарифа нужна зарубежная карта.
