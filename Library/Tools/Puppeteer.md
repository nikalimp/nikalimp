## Описание

Puppeteer — библиотека для Node.js, которая управляет браузером Chrome или Firefox из кода. С её помощью автоматизируют действия на сайтах, делают скриншоты и PDF, парсят страницы и тестируют интерфейсы.

Главное отличие от [[Playwright]]: Puppeteer проще и ближе к Chrome, его развивает команда Chrome в Google. Playwright поддерживает больше браузеров и языков и сильнее в тестировании.

### Возможности
- **Управление браузером:** переходы, клики, ввод текста, ожидание элементов.
- **Скриншоты и PDF** страниц, в том числе для генерации документов.
- **Парсинг сайтов** с JavaScript-рендерингом.
- **Перехват сетевых запросов** и подмена ответов.
- **Замеры производительности** и трассировка через Chrome DevTools Protocol.

### Кому подходит
Разработчикам на JavaScript, которым нужно автоматизировать браузер: генерировать PDF, снимать скриншоты для превью, парсить динамические сайты.

### Как начать
Выполните `npm i puppeteer`: вместе с пакетом скачается Chrome for Testing. Напишите скрипт, который открывает страницу и вызывает `page.screenshot()`.

### Совет
Для серверного рендера PDF и скриншотов держите один запущенный браузер и открывайте новые вкладки: запуск браузера на каждый запрос съедает память и время.

### Ограничения
Только JavaScript и TypeScript. Для кроссбраузерных тестов удобнее [[Playwright]] или [[Cypress]]. Для массового парсинга с прокси проще готовые сервисы вроде [[Apify]].

## Вердикт
- Кому подходит: JS-разработчикам, которым нужны скриншоты, PDF, парсинг и автоматизация Chrome.
- Кому не подходит: Командам, которым нужны кроссбраузерные E2E-тесты или код на Python и Java.
- Итог: Простая и надёжная библиотека для управления Chrome из Node.js.

## Частые вопросы
### Puppeteer бесплатный?
Да, библиотека бесплатна и распространяется с открытым кодом под лицензией Apache 2.0.

### Работает ли Puppeteer в России?
Да, пакет ставится из npm, а браузер скачивается автоматически без VPN.

### Puppeteer или Playwright?
[[Playwright]] поддерживает Chromium, Firefox и WebKit и несколько языков, в нём удобнее писать тесты. Puppeteer проще для задач с Chrome: скриншоты, PDF, парсинг.

### Можно ли запускать Puppeteer на сервере?
Да, в headless-режиме на Linux и в Docker. Учитывайте, что каждой вкладке нужно 100–300 МБ памяти.
