## Описание

Qdrant — это открытая векторная база данных на Rust для семантического поиска, RAG и рекомендаций: она хранит эмбеддинги и быстро находит похожие объекты.

Главное отличие от [[Pinecone]] — Qdrant можно бесплатно развернуть у себя, а мощная фильтрация по полям работает вместе с векторным поиском без потери скорости.

### Возможности
- **Векторный поиск** с фильтрами по метаданным.
- **Гибридный поиск:** плотные и разреженные векторы, полнотекстовый поиск.
- **Квантизация** для экономии памяти на больших коллекциях.
- **Шардинг и репликация** для масштабирования.
- **Клиенты** для Python, JavaScript, Go, Rust и интеграции с [[LangChain]] и [[LlamaIndex]].

### Кому подходит
Разработчикам AI-ассистентов, поиска по документам, рекомендательных систем и чат-ботов с базой знаний, особенно тем, кто хочет держать данные на своём сервере.

### Как начать
Запустите Qdrant в Docker одной командой, создайте коллекцию с нужной размерностью векторов и загрузите эмбеддинги через клиент на Python или JavaScript.

### Совет
Сразу сохраняйте в payload поля для фильтрации: язык, дату, источник, права доступа. Фильтр по ним в Qdrant быстрее и точнее, чем отсев результатов после поиска.

### Ограничения
Для небольшого проекта отдельная векторная база избыточна: хватит pgvector в PostgreSQL. Самостоятельный кластер требует администрирования, а облако — зарубежной карты.

## Частые вопросы
### Qdrant бесплатный?
Да, открытую версию можно запускать бесплатно. В облаке есть бесплатный кластер на 1 ГБ.

### Работает ли Qdrant в России?
Да, если запускать его на своём сервере. Облачную версию можно оплатить только зарубежной картой.

### Qdrant или Pinecone?
[[Pinecone]] — только облако без администрирования. Qdrant можно держать у себя, и он гибче в фильтрации.

### Qdrant или Chroma?
[[Chroma]] проще для прототипов и локальной разработки. Qdrant лучше для продакшена с большими объёмами и фильтрами.
