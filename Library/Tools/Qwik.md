# Qwik

## Описание

Qwik — это JavaScript-фреймворк для сайтов и веб-приложений, который почти не загружает JavaScript при открытии страницы и подгружает код только при действии пользователя.

Главное отличие от [[React]] и [[Next.js]] — возобновляемость (resumability) вместо гидратации. Страница не пересобирает состояние в браузере, а продолжает с того места, где остановился сервер, поэтому сайт интерактивен сразу.

### Возможности
- **Возобновляемость:** нет гидратации, минимальный стартовый JavaScript.
- **Ленивая загрузка** кода на уровне отдельных обработчиков событий.
- **Qwik City** с файловой маршрутизацией, загрузкой данных и серверными действиями.
- **Синтаксис JSX**, привычный разработчикам на React.
- **Адаптеры** для Cloudflare, Vercel, Netlify, Node.js и статической генерации.

### Кому подходит
Командам, которым критична скорость загрузки: интернет-магазины, контентные сайты и лендинги с большим трафиком с телефонов.

### Как начать
Создайте проект командой npm create qwik@latest, выберите стартовый шаблон и адаптер хостинга. Структура страниц похожа на Next.js, поэтому привыкнуть легко.

### Совет
Проверьте, действительно ли вам мешает гидратация: замерьте сайт в PageSpeed. Если показатели и так хорошие, переход на Qwik не окупит обучение команды.

### Ограничения
Экосистема меньше, чем у React: многие библиотеки придётся адаптировать. Знаки доллара в коде и правила сериализации непривычны новичкам. Мейнстрим-альтернативы для быстрых сайтов — Astro и [[SolidJS]].

## Вердикт
- Кому подходит: Командам, которым нужна максимальная скорость загрузки при сложном интерактиве.
- Кому не подходит: Тем, кому важна большая экосистема библиотек и много разработчиков на рынке.
- Итог: Необычный быстрый фреймворк, который почти не грузит JavaScript при открытии страницы.

## Плюсы
- Мгновенная интерактивность без гидратации
- Минимальный стартовый JavaScript
- Привычный JSX-синтаксис
- Бесплатный и открытый

## Минусы

## Частые вопросы
### Qwik бесплатный?
Да, это открытый проект под лицензией MIT.

### Работает ли Qwik в России?
Да, без ограничений: он ставится через npm, а сайты размещаются на любом хостинге.

### Qwik или Next.js?
[[Next.js]] — стандарт рынка с огромной экосистемой. Qwik быстрее на старте страницы, но библиотек и разработчиков под него меньше.

### Чем Qwik отличается от Astro?
Astro отдаёт статический HTML и подгружает интерактивные «острова». Qwik делает интерактивной всю страницу, но грузит код по требованию.
