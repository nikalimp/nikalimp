# Radix Colors

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Цвет и контраст · Global
Буква: R · Страница на сайте: `/tools/radix-colors`

## Описание

Radix Colors — открытая цветовая система для интерфейсов из 12-ступенчатых шкал со светлой и тёмной версиями. Каждый шаг шкалы отвечает за свою роль: фон, рамку, текст.

Главное отличие от генераторов палитр: шкалы уже подобраны под доступный контраст, а назначение каждого шага описано в документации.

### Возможности
- **30 шкал**: серые, цветные и яркие, включая оттенки для кнопок на тёмном и светлом фоне.
- **Тёмная тема** для каждой шкалы, переключение без ручной подстройки.
- **Альфа-варианты** для полупрозрачных слоёв поверх любого фона.
- **Цвета P3** для широкоцветных экранов.
- **Генератор своей палитры** по брендовому цвету.

### Кому подходит
Дизайнерам и фронтенд-разработчикам, которые собирают дизайн-систему и не хотят подбирать оттенки вручную. Шкалы используют [[shadcn ui|shadcn/ui]] и другие библиотеки компонентов.

### Как начать
Установите пакет `@radix-ui/colors` или скопируйте CSS-переменные с сайта. Для фирменного цвета откройте генератор, введите акцент и фон, экспортируйте результат в CSS.

### Совет
Привязывайтесь к ролям шагов, а не к конкретным цветам: шаги 1–2 для фона, 3–5 для элементов, 6–8 для рамок, 9–10 для заливки, 11–12 для текста. Тогда смена бренда или темы не ломает интерфейс.

### Ограничения
Шкалы готовые, тонкой ручной настройки нет. Это не генератор вдохновения: для поиска сочетаний лучше [[Coolors]] или [[Realtime Colors]].

## Частые вопросы
### Radix Colors бесплатный?
Да, полностью бесплатный, код открыт под лицензией MIT. Использовать можно и в коммерческих проектах.

### Работает ли Radix Colors в России?
Да, сайт и npm-пакет доступны без VPN, регистрация и оплата не нужны.

### Radix Colors или Tailwind CSS?
У [[Tailwind CSS]] своя палитра из 11 шагов без описанных ролей. Radix Colors дают 12 шагов с назначением каждого и готовую тёмную тему; шкалы легко подключить в Tailwind через переменные.

### Как сделать палитру под свой бренд?
Откройте генератор на сайте, задайте акцентный цвет, серый и фон. Сервис построит шкалы для светлой и тёмной темы и выгрузит CSS.
