# Radix Icons

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Иконки · Global
Буква: R · Страница на сайте: `/tools/radix-icons`

## Описание

Radix Icons — бесплатный набор из 300+ иконок размером 15×15 пикселей для интерфейсов. Иконки выпускает команда Radix вместе с цветами и компонентами.

Главное отличие: иконки нарисованы под мелкий размер и чёткую пиксельную сетку, поэтому хорошо выглядят в плотных интерфейсах, таблицах и меню.

### Возможности
- **Около 300 иконок** для навигации, действий, форматирования текста и логотипов сервисов.
- **React-пакет** `@radix-ui/react-icons`: каждая иконка — отдельный компонент.
- **SVG** для любых других проектов.
- **Файл для Figma** в сообществе.
- **Единый стиль** с тонкой линией и строгой геометрией.

### Кому подходит
Разработчикам интерфейсов на React и дизайнерам SaaS-продуктов с плотной вёрсткой. Набор подходит для админок, дашбордов и редакторов.

### Как начать
Установите пакет через npm и импортируйте нужные иконки по имени. В Figma добавьте файл из сообщества и копируйте иконки как компоненты.

### Совет
Не смешивайте Radix Icons с крупными иконками другой толщины на одном экране. Если не хватает нужного знака, возьмите похожий набор с близкой линией, например [[Lucide]] или [[Heroicons]], и проверьте его на размере 15–16 пикселей.

### Ограничения
Набор небольшой: для сложных продуктов иконок не хватит. Размер 15×15 неудобен в крупных макетах. Для поиска по десяткам наборов удобнее [[Iconify]].

## Частые вопросы
### Radix Icons бесплатные?
Да, иконки бесплатные и распространяются по лицензии MIT, их можно использовать в коммерческих проектах.

### Работает ли Radix Icons в России?
Да, сайт и npm-пакет доступны из России без VPN.

### Radix Icons или Lucide?
В [[Lucide]] больше полутора тысяч иконок, и он стандарт в [[shadcn ui|shadcn/ui]]. Radix Icons меньше, зато нарисованы под размер 15 пикселей.

### Можно ли менять цвет и размер?
Да, иконки наследуют цвет текста через currentColor, размер задаётся атрибутами width и height.
