## Описание

RapidAPI — маркетплейс API, где разработчики находят, тестируют и подключают тысячи сторонних API по одному ключу. Владельцы API продают через него доступ по подписке.

Главное отличие от [[Postman]]: RapidAPI в первую очередь каталог готовых API с единой оплатой и ключом, а не инструмент для разработки и тестирования своих запросов. В 2024 году технологии Rapid купила Nokia.

### Возможности
- **Каталог API:** погода, перевод, парсинг соцсетей, финансы, AI, поиск.
- **Один ключ** для всех подключённых API.
- **Тестирование в браузере** и примеры кода на десятке языков.
- **Тарифы Basic, Pro, Ultra, Mega** у каждого API.
- **Для провайдеров:** публикация своего API, биллинг и аналитика.

### Кому подходит
Разработчикам и no-code специалистам, которым быстро нужен сторонний API для прототипа или небольшого продукта.

### Как начать
Зарегистрируйтесь, найдите API через поиск, откройте вкладку «Pricing» и подпишитесь на бесплатный план. Скопируйте пример запроса с вашим ключом.

### Совет
Перед продакшеном проверьте рейтинг, задержку и процент успешных ответов API. Многие API на маркетплейсе поддерживают одиночные авторы, они могут исчезнуть без предупреждения.

### Ограничения
Качество API сильно разное. Для критичных задач надёжнее подключаться к официальному API сервиса напрямую или к проверенным провайдерам вроде [[SerpApi]] и [[Apify]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, API

## Вердикт
- Кому подходит: Разработчикам, которым нужно быстро найти и попробовать сторонний API.
- Кому не подходит: Продуктам, где нужна гарантированная стабильность API и оплата из России.
- Итог: Большой каталог API с одним ключом, удобный для прототипов, но с неровным качеством.

## Плюсы
- Тысячи API в одном каталоге
- Один ключ и единая оплата
- Тестирование запросов прямо в браузере
- У многих API есть бесплатный план

## Минусы
- Качество и поддержка API разные
- API могут пропадать без предупреждения
- Оплата только зарубежной картой

## Тарифы
| Тариф | Цена | Что входит |
|---|---|---|
| Аккаунт | бесплатно | Каталог, ключ, тестирование |
| Basic у API | часто бесплатно | Ограниченное число запросов |
| Pro, Ultra, Mega | цену задаёт владелец API | Больше запросов и функций |

## Частые вопросы
### RapidAPI бесплатный?
Регистрация бесплатная, у многих API есть бесплатный план с лимитом запросов. Платные тарифы назначает владелец API.

### Работает ли RapidAPI в России?
Сайт открывается без VPN, но платные подписки можно оплатить только зарубежной картой.

### RapidAPI или Postman?
[[Postman]] нужен для разработки и тестирования запросов к любым API. RapidAPI — маркетплейс, где эти API ищут и покупают.

### Как выбрать надёжный API на RapidAPI?
Смотрите на рейтинг популярности, задержку, процент успешных ответов и дату последнего обновления. Протестируйте бесплатный план перед оплатой.
