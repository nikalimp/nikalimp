## Описание

Raycast — лаунчер для macOS, который заменяет Spotlight: запуск приложений, поиск файлов, история буфера обмена, управление окнами, сниппеты и тысячи расширений. В платной версии встроен AI-ассистент.

Главное отличие от Spotlight и Alfred: магазин расширений с интеграциями [[GitHub]], [[Notion]], [[Todoist]] и других сервисов, которые работают прямо из строки поиска.

### Возможности
- **Поиск и запуск** приложений, файлов, команд.
- **История буфера обмена** и сниппеты текста.
- **Управление окнами** горячими клавишами.
- **Магазин расширений** с открытым кодом на React и TypeScript.
- **AI-чат и AI-команды** на моделях OpenAI, Anthropic и других в тарифах Pro и выше.

### Кому подходит
Разработчикам, дизайнерам и всем, кто много работает на Mac и хочет управлять им с клавиатуры.

### Как начать
Скачайте Raycast, назначьте его на сочетание Cmd + Пробел вместо Spotlight. Включите историю буфера обмена и управление окнами, затем установите 3–5 расширений из магазина.

### Совет
Создайте Quicklinks на частые страницы: поиск в документации, Яндекс Метрику, панель хостинга. Открывать их с клавиатуры быстрее любых закладок.

### Ограничения
AI доступен только в платных тарифах. Основная версия — для Mac; версии для Windows и iOS моложе и умеют меньше. Синхронизация между устройствами — только в Pro.

## Частые вопросы
### Raycast бесплатный?
Да, основные функции бесплатны: запуск приложений, буфер обмена, окна, расширения. AI и синхронизация — с тарифа Pro за $10 в месяц.

### Работает ли Raycast в России?
Бесплатная версия работает без VPN. Подписку можно оплатить только зарубежной картой.

### Чем Raycast лучше Spotlight?
Spotlight только ищет. Raycast ещё хранит историю буфера, управляет окнами, вставляет сниппеты и работает с сервисами через расширения.

### Есть ли Raycast для Windows?
Да, версия для Windows вышла позже версии для Mac, и расширений для неё пока меньше.
