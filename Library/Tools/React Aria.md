# React Aria

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · UI-библиотеки и компоненты · Global
Буква: R · Страница на сайте: `/tools/react-aria`

## Описание

React Aria — библиотека доступных компонентов и хуков для React от Adobe. Даёт поведение, клавиатурную навигацию и ARIA-разметку для более чем 50 компонентов, а внешний вид вы задаёте сами.

Главное отличие от [[Material UI]] и [[Ant Design]]: компоненты поставляются без стилей. Вы полностью контролируете дизайн, а доступность и сложная логика уже реализованы.

### Возможности
- **React Aria Components:** готовые компоненты без стилей — меню, комбобоксы, календари, таблицы, drag and drop.
- **Хуки** для сборки своих компонентов с нуля.
- **Доступность:** клавиатура, фокус, экранные читалки на разных платформах.
- **Интернационализация** на 30+ языках, включая русский, даты и RTL.
- **Стилизация** через CSS, [[Tailwind CSS]] и data-атрибуты состояний.

### Кому подходит
Командам, которые строят свою дизайн-систему на React и хотят соблюдать WCAG без многомесячной разработки компонентов.

### Как начать
Установите `react-aria-components`, импортируйте, например, `Select` и стилизуйте его классами Tailwind по атрибутам `data-hovered` и `data-focused`. Стартеры есть в документации.

### Совет
Берите React Aria для сложных компонентов — дат, комбобоксов, таблиц, где самописный код почти всегда ломает доступность.


### Ограничения
Каждый компонент нужно оформить самостоятельно, а порог входа выше, чем у готовых наборов. Если нужны готовые стили, проще взять [[shadcn ui|shadcn/ui]] или [[Headless UI]] с [[Tailwind CSS]].

## Частые вопросы
### React Aria бесплатный?
Да, библиотека бесплатна и распространяется с открытым кодом под лицензией Apache 2.0.

### Работает ли React Aria в России?
Да, пакеты устанавливаются из npm без VPN, ограничений нет.

### React Aria или shadcn/ui?
[[shadcn ui|shadcn/ui]] даёт готовые стилизованные компоненты, которые копируются в проект. React Aria — основа без стилей с более глубокой доступностью. Их можно сочетать: есть варианты shadcn-компонентов на React Aria.

### Поддерживает ли React Aria русский язык?
Да, встроенные тексты, форматы дат и чисел переведены на русский и ещё 30 с лишним языков.
