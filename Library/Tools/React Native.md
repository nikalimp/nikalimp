## Описание

React Native — бесплатный фреймворк Meta для создания мобильных приложений под iOS и Android на JavaScript или TypeScript с использованием React.

Главное отличие: React Native использует настоящие нативные элементы интерфейса, а веб-разработчик, который знает [[React]], начинает писать мобильные приложения почти без переучивания.

### Возможности
- **Один код** для iOS и Android с общими компонентами.
- **Нативные элементы интерфейса** вместо веб-страницы внутри приложения.
- **Fast Refresh:** изменения видны сразу без перезапуска.
- **Новая архитектура** с прямым вызовом нативного кода и быстрым рендером.
- **Expo:** готовые модули, сборка в облаке и обновления без магазина.
- **Экосистема npm** и общие библиотеки с веб-проектами.

### Кому подходит
Командам с опытом в React и TypeScript, стартапам, которым нужно приложение и сайт на одном стеке, и тем, кто переносит веб-продукт в мобильный формат.

### Как начать
Создайте проект через Expo командой `npx create-expo-app`, запустите его и откройте на телефоне в приложении Expo Go. Код пишите в [[VS Code]] или [[Cursor]].

### Совет
Начинайте с Expo, а не с «голого» React Native: он закрывает сборку, иконки, пуш-уведомления и обновления. К нативному коду переходите, только когда упрётесь в ограничения.

### Ограничения
Сложная анимация и тяжёлая графика требуют нативных модулей. Обновления версий иногда ломают библиотеки. Для сборки под iOS нужен Mac с [[Xcode]], под Android — [[Android Studio]].

## Частые вопросы
### React Native бесплатный?
Да, фреймворк бесплатный и открытый. Платными бывают только облачные сервисы сборки и аккаунты разработчика в App Store и Google Play.

### Работает ли React Native в России?
Да, фреймворк ставится через npm без VPN. Ограничения касаются сервисов Google и Apple, которые нужны для сборки и публикации.

### React Native или Flutter?
React Native удобнее для команд на JavaScript и React, [[Flutter]] — для тех, кому важен одинаковый интерфейс на всех платформах и готовность учить Dart.

### Можно ли использовать один код для сайта и приложения?
Частично: логику, типы и запросы к API можно вынести в общий пакет, а интерфейс для сайта обычно пишут на [[React]] или [[Next.js]] отдельно.

## Цена

## Доступность из России

Работает в России без ограничений: устанавливается через npm. Для сборки под Android и iOS действуют те же ограничения, что у Android Studio и Xcode.
