## Описание

React Router — библиотека маршрутизации для [[React]]: связывает адреса страниц с компонентами. С версии 7 это ещё и полноценный фреймворк с серверным рендерингом, загрузкой данных и формами, в который влился [[Remix]].

Главное отличие от [[Next.js]]: React Router можно использовать как простую библиотеку в существующем SPA или как фреймворк, и он не привязан к конкретному хостингу.

### Возможности
- **Три режима:** декларативный для простых SPA, data mode и framework mode.
- **Вложенные маршруты** и общие макеты.
- **Loaders и actions:** загрузка данных и обработка форм на уровне маршрута.
- **Серверный рендеринг и пререндер** в режиме фреймворка на базе [[Vite]].
- **Типобезопасные маршруты** с автогенерацией типов.

### Кому подходит
React-разработчикам: от простого SPA до полноценного веб-приложения с SSR.

### Как начать
Для нового проекта выполните `npx create-react-router@latest`. Для существующего SPA установите `react-router` и оберните приложение в `BrowserRouter`.

### Совет
Если у вас SPA на шестой версии, обновляйтесь на седьмую: API почти не изменился, а framework mode можно включить позже, когда понадобится SSR.

### Ограничения
Частые смены API между мажорными версиями пугают команды. Для статических сайтов и блогов проще Astro или [[Next.js]]. Экосистема готовых шаблонов меньше, чем у Next.js.

## Вердикт
- Кому подходит: React-разработчикам, которым нужна маршрутизация в SPA или фреймворк без привязки к хостингу.
- Кому не подходит: Тем, кто делает контентный сайт и хочет готовые решения для SEO и картинок.
- Итог: Стандарт маршрутизации в React, который вырос в полноценный фреймворк.

## Плюсы
- Бесплатно, открытый код
- Работает и как библиотека, и как фреймворк
- Загрузка данных и формы на уровне маршрутов
- Деплой на любой хостинг с Node.js или в виде статики

## Минусы
- Ломающие изменения между мажорными версиями
- Меньше готовых шаблонов, чем у Next.js
- Документация только на английском

## Частые вопросы
### React Router бесплатный?
Да, библиотека бесплатна и распространяется с открытым кодом под лицензией MIT.

### Работает ли React Router в России?
Да, пакет устанавливается из npm без VPN, ограничений нет.

### React Router или Next.js?
[[Next.js]] даёт больше готового для SEO, картинок и деплоя на [[Vercel]]. React Router проще встроить в существующее SPA и легче разворачивать на любом сервере.

### Что стало с Remix?
Возможности Remix 2 перешли в React Router 7 в режиме фреймворка. Проекты на Remix обновляются на React Router почти без переписывания.
