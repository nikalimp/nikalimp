# React Three Fiber

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · 3D для веба · Global
Буква: R · Страница на сайте: `/tools/react-three-fiber`

## Описание

React Three Fiber — библиотека для создания 3D-сцен на [[Three.js]] в виде React-компонентов. Камеры, свет, модели и материалы описываются JSX-тегами, а состояние сцены управляется как обычное React-приложение.

Главное отличие от чистого [[Three.js]]: не нужно вручную создавать сцену и цикл рендера, а экосистема готовых помощников экономит недели работы.

### Возможности
- **Декларативная сцена:** `<mesh>`, `<ambientLight>`, `<perspectiveCamera>` в JSX.
- **Drei:** сотни готовых помощников — орбитальная камера, загрузка моделей, тексты, окружение.
- **Хуки** `useFrame` и `useThree` для анимации и доступа к сцене.
- **Физика и постобработка** через пакеты экосистемы pmndrs.
- **Совместимость** с [[Next.js]] и React Native.

### Кому подходит
Фронтенд-разработчикам на React, которые делают 3D-лендинги, конфигураторы товаров и интерактивные презентации. Дизайнер собирает сцену и модели, разработчик оживляет их кодом.

### Как начать
Установите `three`, `@react-three/fiber` и `@react-three/drei`. Добавьте `<Canvas>`, внутри — модель через `useGLTF` и `OrbitControls`.

### Совет
Готовьте модели в [[Blender]] и сжимайте их в формат GLB с Draco. Тяжёлые сцены грузите лениво, после основного контента, чтобы не портить скорость загрузки.

### Ограничения
Нужно знать и React, и основы 3D-графики. На слабых телефонах сложные сцены тормозят. Для 3D без кода проще [[Spline]].

## Частые вопросы
### React Three Fiber бесплатный?
Да, библиотека бесплатна и распространяется с открытым кодом под лицензией MIT.

### Работает ли React Three Fiber в России?
Да, пакеты устанавливаются из npm без VPN, ограничений нет.

### React Three Fiber или Three.js?
React Three Fiber работает поверх [[Three.js]] и не заменяет его. Если проект на React, удобнее R3F, если без фреймворка — чистый Three.js.

### React Three Fiber или Spline?
[[Spline]] позволяет собрать сцену визуально без кода. React Three Fiber даёт полный контроль, производительность и логику на JavaScript.
