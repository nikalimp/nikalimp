## Описание

React — JavaScript-библиотека для создания пользовательских интерфейсов. Интерфейс собирается из компонентов: кнопок, карточек, форм, страниц, которые можно переиспользовать и комбинировать.

React создали в Facebook (сейчас Meta) и открыли в 2013 году. Сегодня это самая популярная технология для веб-интерфейсов: на ней работают соцсети, банки, интернет-магазины и тысячи SaaS-продуктов.

### Ключевые идеи
- **Компоненты:** интерфейс разбит на независимые части со своей логикой.
- **JSX:** разметка пишется прямо в JavaScript.
- **Состояние и хуки:** компонент сам обновляется, когда меняются данные.
- **Однонаправленный поток данных:** проще понимать, что и почему изменилось.
- **Серверные компоненты:** часть интерфейса рендерится на сервере, чтобы страница загружалась быстрее.

### Экосистема
- [[Next.js]] — фреймворк для сайтов и приложений.
- [[Tailwind CSS]] и [[shadcn ui|shadcn/ui]] — стили и готовые компоненты.
- React Native — мобильные приложения на тех же принципах.
- Тысячи библиотек для форм, графиков, таблиц, анимаций.

### Кому подходит
Разработчикам интерфейсов и командам, которые делают веб-приложения, личные кабинеты, админки и дашборды. Также React — основа кода, который генерируют AI-инструменты вроде [[Lovable]] и v0.

### Как начать
Пройдите официальный учебник на react.dev — он бесплатный и с интерактивными примерами. Для реального проекта сразу берите фреймворк, например Next.js, а не настраивайте сборку вручную.

### React и SEO
Сайт, который рендерится только в браузере, хуже индексируется: поисковик и нейросети видят пустую страницу до выполнения JavaScript. Поэтому для публичных сайтов используют серверный рендеринг или статическую генерацию через Next.js.

### Совет
Держите компоненты маленькими и с одной задачей. Компонент на 500 строк сложно поддерживать, и AI-помощники в нём тоже чаще ошибаются.

### Частый вопрос
**React или Vue?** Обе технологии зрелые. React популярнее, у него больше вакансий, библиотек и примеров, поэтому AI-помощники пишут на нём особенно уверенно.

## Вердикт
- Кому подходит: Разработчикам, которые строят сложные интерфейсы из переиспользуемых компонентов, и командам с большим проектом.
- Кому не подходит: Тем, кому нужен простой лендинг: хватит конструктора или обычного HTML.
- Итог: React — бесплатная библиотека для интерфейсов, на которой стоит большая часть современных сайтов и сервисов.

## Плюсы
- Компонентный подход: интерфейс собирается из блоков
- Самая большая экосистема библиотек и готовых решений
- Работа найдётся почти везде
- На React строятся Next.js, React Native и другие инструменты
- Бесплатный и с открытым исходным кодом

## Минусы
- Нужно самому выбирать маршрутизацию, сборку и работу с данными
- Порог входа выше, чем у HTML и конструкторов

## Частые вопросы
### React бесплатный?
Да, React бесплатный и распространяется с открытым исходным кодом по лицензии MIT.

### Работает ли React в России?
Да, ограничений нет: библиотека ставится из npm и не зависит от страны.

### Что лучше: React или Vue?
Выбор зависит от команды. У React больше экосистема и вакансий, [[Vue.js]] проще на старте. Оба хорошо подходят для сложных интерфейсов.

### Чем React отличается от Next.js?
React отвечает за интерфейс, а [[Next.js]] добавляет к нему маршрутизацию, серверный рендеринг и сборку. Для сайта чаще берут Next.js.
