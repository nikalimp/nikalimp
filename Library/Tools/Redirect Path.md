# Redirect Path

Буква: R · Страница на сайте: `/tools/redirect-path`

## Описание

Redirect Path — бесплатное расширение для Chrome, которое показывает цепочку редиректов и HTTP-статус каждой открытой страницы: 301, 302, 404, 500, а также редиректы через JavaScript и meta refresh.

Главное отличие от краулеров вроде [[Screaming Frog SEO Spider]]: ничего не нужно запускать, статус видно сразу при обычном просмотре сайта.

### Возможности
- **Иконка статуса** в панели браузера: цвет и код ответа текущей страницы.
- **Цепочка редиректов** со всеми промежуточными адресами.
- **Заголовки ответа:** canonical, X-Robots-Tag, кэш, сервер.
- **IP-адрес и страна** сервера.
- **Копирование** цепочки для отчёта разработчику.

### Кому подходит
SEO-специалистам и разработчикам при переезде сайта, смене URL и настройке редиректов.

### Как пользоваться
Установите расширение и откройте старый адрес страницы. Нажмите на иконку: если в цепочке больше одного шага, редирект нужно сократить до прямого 301.

### Совет
После переезда сайта проверьте 10–20 главных старых URL. Цепочки из нескольких редиректов и 302 вместо 301 — частая причина потери позиций.

### Ограничения
Проверяет только открытые страницы по одной. Для массовой проверки нужен [[Screaming Frog SEO Spider]] или [[Netpeak Spider]], для мониторинга — [[Google Search Console]] и [[Яндекс Вебмастер]].

## Частые вопросы
### Redirect Path бесплатный?
Да, расширение бесплатное и не требует регистрации.

### Работает ли Redirect Path в России?
Да, расширение устанавливается из Chrome Web Store и работает без VPN.

### Redirect Path или Screaming Frog?
Redirect Path проверяет страницу, которую вы открыли. [[Screaming Frog SEO Spider]] обходит весь сайт и находит все редиректы и ошибки сразу.

### Как найти цепочку редиректов?
Откройте старый URL с установленным Redirect Path и нажмите на иконку. Если адресов в списке больше двух, настройте прямой 301-редирект на конечную страницу.
