## Описание

Redis — база данных в оперативной памяти, которую используют как кэш, хранилище сессий, очередь задач и брокер сообщений. Отвечает за доли миллисекунды.

Главное отличие от [[MongoDB Atlas]] или [[SQLite]] — данные лежат в памяти, поэтому Redis в разы быстрее дисковых баз и ставится рядом с основной базой, а не вместо неё.

### Возможности
- **Структуры данных:** строки, списки, хеши, множества, сортированные множества, потоки, JSON.
- **Кэш с TTL:** ключи удаляются сами через заданное время.
- **Pub/Sub и Streams** для очередей и обмена событиями между сервисами.
- **Векторный поиск** для RAG и семантического кэша LLM.
- **Репликация и кластер** для отказоустойчивости и роста нагрузки.

### Кому подходит
Бэкенд-разработчикам, которым нужен быстрый кэш, лимиты запросов, сессии или фоновые задачи. Фреймворки вроде [[Laravel]] и [[Ruby on Rails]] умеют работать с Redis из коробки.

### Как начать
Запустите Redis в Docker одной командой или создайте бесплатную базу в Redis Cloud. Подключитесь клиентом для своего языка и начните с кэша самых тяжёлых запросов.

### Совет
Всегда задавайте TTL для кэша и лимит памяти с политикой вытеснения. Иначе Redis заполнит всю память и начнёт отказывать в записи.

### Ограничения
Объём данных ограничен оперативной памятью, а она дороже диска. Redis не заменяет основную базу: при неправильной настройке сохранения часть данных теряется при перезапуске.

## Частые вопросы
### Redis бесплатный?
Да, open source-версию можно бесплатно поставить на свой сервер. В облаке Redis Cloud есть бесплатная база на 30 МБ, платные тарифы начинаются от $5 в месяц.

### Работает ли Redis в России?
Да, на своём сервере Redis работает без ограничений. Для облака Redis Cloud нужна зарубежная карта, поэтому в России чаще берут управляемую базу в [[Yandex Cloud]] или [[Selectel]].

### Redis или база данных вроде MongoDB?
Это разные задачи. Redis держит горячие данные в памяти для скорости, а [[MongoDB Atlas]] или PostgreSQL хранят основные данные на диске. Обычно их используют вместе.

### Для чего Redis в веб-проекте?
Для кэша страниц и запросов, хранения сессий, лимитов запросов к API, очередей фоновых задач и счётчиков в реальном времени.
