# Relume Library

Буква: R · Страница на сайте: `/tools/relume-library`

## Описание

Relume Library — библиотека из более чем 1000 готовых блоков сайта для [[Webflow]] и [[Figma]]: шапки, первые экраны, преимущества, отзывы, цены, футеры. Блоки копируются в проект в один клик.

Главное отличие: все блоки свёрстаны по системе классов [[Client-First]], поэтому сайт остаётся чистым и понятным для других разработчиков.

### Возможности
- **Более 1000 компонентов** с адаптивной вёрсткой.
- **Копирование в Webflow** и в Figma с теми же блоками.
- **Экспорт в React** для проектов на коде.
- **AI Site Builder:** карта сайта и вайрфреймы из короткого описания компании.
- **Стили и переменные** для быстрой смены шрифтов и цветов.

### Кому подходит
Веб-дизайнерам и студиям на Webflow, которые собирают сайты для клиентов и хотят сократить время на вёрстку структуры.

### Как начать
Сгенерируйте карту сайта и вайрфреймы в Site Builder, согласуйте их с клиентом. Затем экспортируйте страницы в Figma для дизайна или сразу в Webflow и настройте стили.

### Совет
Используйте Relume для структуры и вайрфреймов, а визуальный стиль делайте сами: иначе сайт будет похож на сотни других.

### Ограничения
Шаблонность: блоки узнаваемы. Полный доступ только по подписке. Для [[Tilda (инструмент)|Tilda]] библиотека не подходит.

## Частые вопросы
### Relume Library бесплатная?
Частично: бесплатно доступны часть компонентов и базовый AI Site Builder. Полная библиотека — по подписке.

### Работает ли Relume в России?
Сайт работает без VPN, но оплатить подписку российской картой нельзя.

### Relume или Finsweet?
Это разные инструменты. Relume даёт готовые блоки, а [[Finsweet Attributes]] добавляет функции: фильтры, сортировку, загрузку CMS-элементов. Их часто используют вместе.

### Можно ли использовать блоки Relume вне Webflow?
Да, есть экспорт в Figma и React. Для Tilda готового экспорта нет.
