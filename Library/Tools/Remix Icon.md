# Remix Icon

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Иконки · Global
Буква: R · Страница на сайте: `/tools/remix-icon`

## Описание

Remix Icon — бесплатная библиотека из более чем 3200 иконок в двух стилях: контурном и залитом. Все иконки нарисованы на сетке 24×24 и выдержаны в одном нейтральном стиле.

Главное отличие от [[Lucide]] или [[Heroicons]] — у каждой иконки есть пара «контур + заливка», поэтому активное и неактивное состояние решается без второй библиотеки.

### Возможности
- **3200+ иконок** в категориях: бизнес, связь, дизайн, разработка, финансы, медиа, логотипы.
- **Два стиля** для каждой иконки: Line и Fill.
- **Форматы:** SVG, PNG и иконочный шрифт с CSS-классами.
- **Пакеты** `@remixicon/react` и `@remixicon/vue` для фронтенда.
- **Плагин для [[Figma]]** в Figma Community.

### Кому подходит
Дизайнерам интерфейсов и разработчикам, которым нужен большой единый набор для приложения, админки или сайта, особенно с нижней навигацией и переключаемыми состояниями.

### Как начать
Найдите иконку поиском на сайте, скопируйте SVG или подключите шрифт через CDN. В React установите пакет и импортируйте только нужные компоненты.

### Совет
Используйте Line для обычного состояния и Fill для активного: например, в таб-баре мобильного приложения. Так навигация читается без смены цвета.

### Ограничения
С 2026 года набор распространяется по собственной лицензии Remix Icon License вместо Apache 2.0: перед использованием в коммерческом продукте прочитайте условия. Стиль нейтральный, но заметно отличается от [[Material Symbols]] и [[Phosphor Icons]], поэтому смешивать наборы не стоит.

## Частые вопросы
### Remix Icon бесплатный?
Да. Иконки можно бесплатно использовать в личных и коммерческих проектах. Упоминание автора приветствуется, но не обязательно.

### Работает ли Remix Icon в России?
Да, сайт, CDN, npm-пакеты и плагин для Figma доступны без VPN.

### Remix Icon или Lucide?
[[Lucide]] стандарт для проектов на [[shadcn ui|shadcn/ui]] и даёт только контурные иконки. Remix Icon больше по объёму и даёт залитую версию каждой иконки.

### Можно ли менять размер и цвет иконок?
Да. SVG и шрифт масштабируются без потери качества, а цвет наследуется от текста через `currentColor`.
