## Описание

Remix — фуллстек-фреймворк для веба от создателей React Router, который строится на веб-стандартах: Request, Response, формах и HTTP-кэше.

Главное: в 2024 году возможности Remix 2 перенесли в [[React Router]] 7, и для React-проектов команда рекомендует его. Под именем Remix 3 развивается новый фреймворк на Web API, уже без зависимости от React.

### Возможности
- **Загрузчики и действия:** данные грузятся и отправляются на сервере, рядом с маршрутом.
- **Вложенные маршруты** с параллельной загрузкой данных.
- **Формы без JavaScript:** прогрессивное улучшение из коробки.
- **Веб-стандарты:** Fetch API, работа на Node.js, Bun, Deno и edge-платформах.
- **Remix 3:** сервер, роутинг, сессии, авторизация и UI в одном пакете.

### Кому подходит
Разработчикам, которые любят веб-стандарты и серверный рендеринг без сложной магии. Проектам на Remix 2, которые переходят на React Router 7.

### Как начать
Для нового проекта на [[React]] создайте приложение на React Router 7 во фреймворк-режиме. Чтобы попробовать Remix 3, выполните `npx remix new my-app`.

### Совет
Если у вас проект на Remix 2, обновляйтесь на React Router 7: в большинстве случаев это замена импортов и пакетов, логика загрузчиков и действий остаётся.

### Ограничения
Смена курса запутала экосистему: материалы про Remix 2, React Router 7 и Remix 3 часто смешивают. Remix 3 моложе и беднее библиотеками, чем [[Next.js]].

## Вердикт
- Кому подходит: Разработчикам, которые ценят веб-стандарты, серверный рендеринг и формы без лишнего JavaScript.
- Кому не подходит: Командам, которым нужна стабильная экосистема и много готовых решений, как у Next.js.
- Итог: Идеи Remix живут в React Router 7, а Remix 3 — новый эксперимент на веб-стандартах.

## Плюсы
- Бесплатный, открытый код, поддержка Shopify
- Работает на веб-стандартах, а не на своей магии
- Формы и мутации без клиентского JavaScript
- Запуск на Node.js, Bun, Deno и edge

## Минусы
- Путаница между Remix 2, React Router 7 и Remix 3
- Меньше библиотек и примеров, чем у Next.js
- Remix 3 отходит от React, старые знания переносятся не полностью

## Частые вопросы
### Remix бесплатный?
Да, это открытый фреймворк под лицензией MIT. Платить нужно только за хостинг.

### Работает ли Remix в России?
Да, пакеты ставятся из npm без VPN, а приложение можно запустить на любом хостинге, включая [[Timeweb Cloud]] или [[Selectel]].

### Remix или Next.js?
[[Next.js]] даёт больше готовых решений и популярнее. Remix и React Router 7 проще по модели данных и ближе к веб-стандартам. Для нового React-проекта сравнивайте Next.js с React Router 7.

### Remix умер?
Нет. Remix 2 влился в React Router 7, а под именем Remix 3 команда развивает новый фреймворк на Web API.
