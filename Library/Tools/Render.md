## Описание

Render — облачная платформа для деплоя веб-сервисов, баз данных и фоновых задач из Git-репозитория. Вы подключаете репозиторий, а Render сам собирает и запускает приложение.

Главное отличие от [[Vercel]] — Render рассчитан на полноценные серверы: долгоживущие процессы, воркеры, cron-задачи и PostgreSQL, а не только фронтенд и функции.

### Возможности
- **Веб-сервисы** на Node.js, Python, Ruby, Go, Rust или в Docker-контейнере.
- **Управляемый PostgreSQL** и хранилище «ключ — значение» на базе Redis-совместимого движка.
- **Фоновые воркеры и cron-задачи** без отдельного сервера.
- **Автодеплой** из [[GitHub]] и превью для pull request.
- **Infrastructure as Code** через файл render.yaml.

### Кому подходит
Разработчикам и небольшим командам, которые хотят запустить бэкенд, API или бота без настройки серверов. Удобная замена [[Heroku]].

### Как начать
Зарегистрируйтесь через GitHub, создайте Web Service, выберите репозиторий и команду запуска. Через несколько минут сервис получит адрес на onrender.com и HTTPS.

### Совет
Бесплатные инстансы засыпают после простоя, и первый запрос после паузы идёт долго. Для продакшена сразу берите платный инстанс или держите на бесплатном только тестовые проекты.

### Ограничения
Дата-центры только за рубежом, оплата — зарубежной картой. Бесплатная база PostgreSQL удаляется через ограниченный срок. Цена растёт с ресурсами быстрее, чем у VPS на [[Hetzner]] или [[Timeweb Cloud]].

## Вердикт
- Кому подходит: Разработчикам, которым нужен простой деплой бэкенда, воркеров и базы без DevOps.
- Кому не подходит: Проектам с хранением персональных данных россиян и тем, кто не может платить зарубежной картой.
- Итог: Простая платформа для деплоя полноценных серверов с бесплатным стартом, но без серверов в России.

## Плюсы
- Деплой из Git за несколько минут
- Веб-сервисы, воркеры, cron и база в одном месте
- Бесплатный план для тестов и пет-проектов
- Превью для каждого pull request
- Конфигурация в коде через render.yaml

## Минусы
- Бесплатные инстансы засыпают
- Оплата только зарубежной картой
- Нет дата-центров в России, это важно для 152-ФЗ

## Частые вопросы
### Render бесплатный?
Есть бесплатный план: веб-сервис на 512 МБ, небольшая база PostgreSQL и хранилище «ключ — значение». Бесплатные сервисы засыпают при простое.

### Работает ли Render в России?
Сайт и задеплоенные приложения обычно открываются, но оплатить платные тарифы можно только зарубежной картой. Для проектов с данными россиян лучше российский хостинг.

### Render или Vercel?
[[Vercel]] лучше для фронтенда на [[Next.js]] и функций. Render — для долгоживущих серверов, ботов, воркеров и баз данных.

### Чем заменить Render в России?
[[Timeweb Cloud]] и [[Yandex Cloud]] дают облачные приложения и управляемые базы с оплатой в рублях. Для простого деплоя на свой VPS подойдёт [[Coolify]].
