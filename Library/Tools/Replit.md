## Описание

Replit — облачная платформа для разработки и запуска приложений в браузере. Её AI-агент создаёт приложение по описанию: пишет код, настраивает базу данных и публикует результат на хостинге Replit.

Replit начинался как онлайн-среда для обучения программированию и стал одной из главных платформ вайб-кодинга для людей без технического опыта.

### Возможности
- **Replit Agent** — создание приложений по описанию.
- **Онлайн-редактор** с поддержкой десятков языков.
- **Встроенная база данных** и хранилище.
- **Деплой** приложений с доменом.
- **Совместная работа** в реальном времени.
- **Мобильное приложение** для разработки с телефона.
- **Шаблоны** для ботов, сайтов и API.

### Кому подходит
Начинающим разработчикам и студентам, предпринимателям для внутренних инструментов и прототипов, преподавателям программирования.

### Как начать
Создайте аккаунт и опишите агенту приложение, например «трекер заявок с формой и таблицей». Посмотрите на план агента, уточните детали и запустите сборку.

### Совет
Сначала опишите данные: какие поля, какие связи. Агент лучше строит приложение, когда структура данных понятна с самого начала.

### Ограничения
Приложения работают на инфраструктуре Replit, поэтому для серьёзного продакшена код обычно переносят на свой хостинг.

### Где особенно полезен
Во внутренних инструментах компании: калькуляторы, формы, небольшие базы данных и Telegram-боты, которые не стоят найма разработчика. Готовое приложение сразу доступно по ссылке всей команде.

### Обучение
Replit остаётся популярной площадкой для обучения: задачи и проекты запускаются в браузере без установки.

### Частый вопрос
**Replit или Lovable?** Replit — полноценная среда для любых языков и бэкенда, [[Lovable]] — для веб-интерфейсов на React. Для быстрых прототипов в браузере есть [[Bolt.new]]. Код удобно хранить на [[GitHub]].

## Частые вопросы
### Replit бесплатный?
Да, бесплатный тариф есть, но с ограничениями. Для полноценной работы с ИИ-агентом нужен Core за $20 в месяц.

### Работает ли Replit в России?
Оплата российскими картами недоступна, поэтому для подписки нужна зарубежная карта. Доступ к платформе из России может быть ограничен, проверить это можно только на практике.

### Что лучше: Replit или Lovable?
Lovable сильнее в быстрой сборке интерфейсов, Replit даёт полноценную среду разработки с запуском и хостингом. Для кода и бэкенда обычно выбирают Replit.

### Нужно ли уметь программировать для Replit?
Не обязательно: агент пишет код по текстовому описанию. Но чтобы понимать результат и править ошибки, базовые знания пригодятся.
