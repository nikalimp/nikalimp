# Resend

Буква: R · Страница на сайте: `/tools/resend`

## Описание

Resend — сервис отправки транзакционных и маркетинговых писем через API для разработчиков. Письма для подтверждения входа, чеков и уведомлений отправляются одним запросом.

Главное отличие от [[SendGrid]] и [[Mailgun]] — простой API, удобная документация и React Email: шаблоны писем пишутся как React-компоненты, а не в старом табличном HTML.

### Возможности
- **API и SDK** для Node.js, Python, PHP, Ruby, Go и других языков, отправка через SMTP.
- **React Email:** шаблоны писем в виде компонентов с превью.
- **Домены и DNS:** пошаговая настройка SPF, DKIM и DMARC.
- **Broadcasts** для рассылок по списку контактов.
- **Вебхуки и журнал** доставки, открытий и ошибок.

### Кому подходит
Разработчикам SaaS, интернет-магазинов и сервисов на [[Next.js]], которым нужны надёжные системные письма без сложной настройки.

### Как начать
Зарегистрируйтесь, добавьте домен и пропишите DNS-записи у регистратора. Создайте API-ключ и отправьте первое письмо из примера кода.

### Совет
Отправляйте письма с поддомена, например mail.example.com. Так репутация маркетинговых рассылок не испортит доставку писем для входа и чеков.

### Ограничения
Бесплатный план ограничен 100 письмами в день. Оплата только зарубежной картой. Для писем с персональными данными россиян и массовых рассылок по российской базе лучше российские сервисы вроде [[Unisender]].

## Частые вопросы
### Resend бесплатный?
Да, бесплатно можно отправлять до 3000 писем в месяц, но не больше 100 в день. Pro стоит $20 в месяц за 50 000 писем.

### Работает ли Resend в России?
API доступен, но оплатить платный тариф можно только зарубежной картой. Для российских проектов с персональными данными надёжнее [[Unisender]] или [[Notisend]].

### Resend или SendGrid?
[[SendGrid]] старше и богаче маркетинговыми функциями. Resend проще в подключении и удобнее для разработчиков, особенно на React.

### Как не попасть в спам?
Настройте SPF, DKIM и DMARC, отправляйте с поддомена и не смешивайте системные письма с рассылками.
