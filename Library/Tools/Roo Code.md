## Описание

Roo Code — бесплатный AI-агент для программирования с открытым кодом, который работает как расширение [[VS Code]]. Он читает проект, правит файлы, запускает команды в терминале и проверяет результат.

Главное отличие от [[Cursor]]: Roo Code не привязан к своей подписке и моделям, вы подключаете любые модели через свои ключи и платите только за токены.

### Возможности
- **Режимы работы:** Code, Architect, Ask, Debug и Orchestrator для больших задач.
- **Свои режимы** с инструкциями и ограничениями доступа к файлам.
- **Любые модели:** Claude, GPT, Gemini, DeepSeek, локальные через Ollama, [[OpenRouter]].
- **Работа с терминалом и браузером** для запуска и проверки кода.
- **MCP-серверы** для подключения внешних инструментов.

### Кому подходит
Разработчикам, которые хотят гибкий агент в VS Code и контроль над расходами на модели.

### Как начать
Установите расширение из маркетплейса VS Code, добавьте ключ провайдера или OpenRouter. Начните с режима Architect: пусть агент составит план, затем переключитесь в Code.

### Совет
Создайте файл с правилами проекта: стек, стиль кода, команды тестов. Так агент реже ошибается и тратит меньше токенов на изучение кода.

### Ограничения
Расходы на токены при длинных задачах бывают высокими. Нужна настройка ключей и режимов. Похожий агент, от которого Roo Code ответвился, — [[Cline]].

## Частые вопросы
### Roo Code бесплатный?
Да, расширение бесплатное. Платить нужно только провайдеру моделей за использованные токены.

### Работает ли Roo Code в России?
Расширение работает. Для моделей Anthropic и OpenAI нужны VPN и зарубежная карта; проще подключить [[OpenRouter]] или локальные модели.

### Roo Code или Cline?
Roo Code появился как ответвление [[Cline]] и добавил режимы, своих агентов и оркестрацию. Cline проще, Roo Code гибче.

### Какую модель выбрать для Roo Code?
Для сложных задач — модели Claude или GPT старшего уровня, для простых правок — более дешёвые модели. Используйте разные модели для разных режимов.
