## Описание

SVGator — это онлайн-редактор SVG-анимации без кода: вы загружаете векторную графику, анимируете её на таймлайне и экспортируете в анимированный SVG, Lottie, GIF или видео.

Главное отличие — результат в виде лёгкого SVG с встроенной анимацией на CSS или JavaScript, который вставляется на сайт без библиотек.

### Возможности
- **Таймлайн с ключевыми кадрами** для положения, масштаба, цвета, прозрачности и формы.
- **Морфинг путей** и анимация обводки для эффекта рисования.
- **Интерактивность:** запуск по наведению, клику или прокрутке.
- **Экспорт** в SVG, [[Lottie]], GIF, MP4 и для мобильной разработки.
- **Импорт** из [[Figma]] через плагин и из [[Adobe Illustrator]].

### Кому подходит
Веб-дизайнерам и верстальщикам, которым нужны анимированные иконки, логотипы и иллюстрации без [[Adobe After Effects]] и без программирования.

### Как начать
Подготовьте графику в Figma или Illustrator со слоями, названными по смыслу. Импортируйте её в SVGator, расставьте ключевые кадры и проверьте экспорт на бесплатном плане.

### Совет
Перед импортом объедините лишние слои и упростите пути: чем меньше узлов, тем легче итоговый файл и плавнее анимация в браузере.

### Ограничения
Бесплатный план ограничивает экспорт и число проектов. Для сложной интерактивной анимации с логикой и состояниями лучше подходит [[Rive]]. Интерфейс только на английском.

## Частые вопросы
### SVGator бесплатный?
Есть бесплатный план с ограничением на экспорт. Для регулярной работы нужна подписка; актуальные цены — на сайте.

### Работает ли SVGator в России?
Редактор открывается без VPN. Оплатить подписку можно только зарубежной картой.

### SVGator или Rive?
SVGator проще и выдаёт обычный SVG для сайта. [[Rive]] сложнее, но поддерживает интерактивность, состояния и свой рантайм для веба и приложений.

### Можно ли экспортировать из SVGator в Lottie?
Да, SVGator экспортирует анимацию в Lottie JSON для сайтов и мобильных приложений.
