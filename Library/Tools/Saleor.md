## Описание

Saleor — это headless-платформа для интернет-магазинов с открытым кодом: бэкенд на Python и Django с GraphQL API, к которому подключается любая витрина.

Главное отличие от [[Shopify]] — полный контроль. Код открыт, магазин работает на вашем сервере, а фронтенд вы пишете сами, например на [[Next.js]].

### Возможности
- **GraphQL API** для каталога, корзины, заказов и клиентов.
- **Мультиканальность:** несколько витрин, валют и складов в одном магазине.
- **Панель управления** Saleor Dashboard для менеджеров.
- **Приложения и вебхуки** для платежей, доставки и интеграций.
- **Стартовая витрина** на Next.js.

### Кому подходит
Командам разработчиков, которые делают крупный магазин или маркетплейс с нестандартной логикой и не хотят зависеть от SaaS-платформы.

### Как начать
Запустите Saleor локально через Docker или создайте песочницу в Saleor Cloud. Подключите стартовую витрину, заведите товары и проверьте оформление заказа.

### Совет
Сравните Saleor с [[Medusa]] до выбора стека: Medusa написана на Node.js, и если команда пишет на JavaScript, поддерживать её проще.

### Ограничения
Без разработчика магазин не запустить. Российские платёжные системы вроде [[ЮKassa]] подключаются через собственные интеграции. Для небольшого каталога проще и дешевле взять готовую платформу вроде [[Shopify]] или [[Tilda (инструмент)|Tilda]].

## Частые вопросы
### Saleor бесплатный?
Да, открытый код бесплатен для любого использования. Платный только облачный хостинг Saleor Cloud.

### Работает ли Saleor в России?
Self-hosted версия работает на российском сервере без ограничений. Облако требует оплаты зарубежной картой.

### Saleor или Medusa?
Обе платформы headless и открытые. Saleor написан на Python с GraphQL, [[Medusa]] — на Node.js с REST API. Выбирайте по стеку команды.

### Нужен ли отдельный фронтенд?
Да. Saleor отдаёт данные через API, а витрину делают отдельно, обычно на Next.js.
