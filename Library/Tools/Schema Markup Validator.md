# Schema Markup Validator

Буква: S · Страница на сайте: `/tools/schema-markup-validator`

## Описание

Schema Markup Validator — бесплатный валидатор разметки Schema.org от проекта Schema.org. Проверяет JSON-LD, Microdata и RDFa по адресу страницы или вставленному коду.

Главное отличие от [[Google Rich Results Test]] — валидатор проверяет разметку по всему словарю Schema.org, а не только типы, которые дают расширенные результаты в Google. Он заменил старый Structured Data Testing Tool от Google.

### Возможности
- **Проверка по URL** или по фрагменту кода.
- **Три формата:** JSON-LD, Microdata, RDFa.
- **Дерево сущностей:** все найденные типы и свойства в структурированном виде.
- **Ошибки и предупреждения** по словарю Schema.org.
- **Без регистрации и лимитов** для ручных проверок.

### Кому подходит
SEO-специалистам, разработчикам и владельцам сайтов, которые добавляют разметку для поиска и AI-ответов и хотят убедиться, что она читается без ошибок.

### Как пользоваться
Вставьте адрес страницы или код и нажмите проверку. Посмотрите, какие сущности найдены, и исправьте ошибки в свойствах.

### Совет
Проверяйте страницу в двух инструментах: здесь — корректность по словарю, в Google Rich Results Test — право на расширенный сниппет. Для Яндекса дополнительно используйте валидатор микроразметки в [[Яндекс Вебмастер]].

### Ограничения
Валидатор не говорит, покажет ли поисковик расширенный сниппет. Не проверяет пакетно сотни страниц: для этого нужен краулер вроде [[Screaming Frog SEO Spider]]. Логические ошибки, например неверную цену, он не видит.

## Частые вопросы
### Schema Markup Validator бесплатный?
Да, валидатор полностью бесплатный и работает без регистрации.

### Работает ли Schema Markup Validator в России?
Да, сайт открывается без VPN и проверяет любые публичные страницы.

### Schema Markup Validator или Google Rich Results Test?
Используйте оба. Валидатор проверяет разметку по всему словарю Schema.org, а [[Google Rich Results Test]] — только типы, для которых Google показывает расширенные результаты.

### Как проверить разметку, созданную генератором?
Скопируйте JSON-LD из генератора вроде [[Merkle Schema Markup Generator]], вставьте во вкладку кода и запустите проверку до публикации.
