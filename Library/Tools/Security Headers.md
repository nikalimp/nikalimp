# Security Headers

[[Инструменты — SEO|SEO]] · Анализ сайтов и конкурентов · Global
Буква: S · Страница на сайте: `/tools/security-headers`

## Описание

Security Headers — бесплатный сканер HTTP-заголовков безопасности: вводите адрес сайта и за секунды получаете оценку от A+ до F и список недостающих заголовков.

Сервис создал Скотт Хелм, сейчас его поддерживает Snyk. Сканер не ищет уязвимости в коде, а проверяет только ответы сервера — быстро и без настройки.

### Возможности
- **Оценка от A+ до F** по набору заголовков безопасности.
- **Разбор каждого заголовка:** Content-Security-Policy, Strict-Transport-Security, X-Frame-Options, Referrer-Policy, Permissions-Policy и другие.
- **Подсказки** — что значит каждый заголовок и зачем он нужен.
- **Скрытие результата** — галочка «Hide results», чтобы проверка не попала в публичный список.
- **API** для автоматических проверок в CI и мониторинге.

### Кому подходит
Разработчикам и веб-студиям перед сдачей сайта, SEO-специалистам при техническом аудите, владельцам сайтов, которым нужна быстрая проверка без установки программ.

### Как пользоваться
Откройте securityheaders.com, вставьте адрес, нажмите Scan. Проверьте и главную, и внутренние страницы: заголовки иногда задаются по-разному.

### Совет
Не включайте Content-Security-Policy сразу в строгом режиме. Начните с Content-Security-Policy-Report-Only, соберите нарушения и только потом закрывайте лишнее, иначе сломаются счётчики вроде [[Яндекс Метрика]] и виджеты.

### Ограничения
Сканер оценивает только заголовки. Сертификат проверяйте в [[SSL Labs]], DNS — в [[DNS Checker]], а уязвимости приложения — отдельными инструментами.

## Частые вопросы
### Security Headers бесплатный?
Да, проверка на сайте бесплатная и без регистрации. Платный только API для автоматизации.

### Работает ли Security Headers в России?
Да, сайт открывается без VPN, и проверять можно любые сайты, включая российские.

### Security Headers или SSL Labs?
Они дополняют друг друга. Security Headers проверяет HTTP-заголовки, а [[SSL Labs]] — сертификат, протоколы и шифры TLS.

### Какую оценку считать нормальной?
Для обычного сайта достаточно A. A+ требует строгой Content-Security-Policy, которую на сайтах со сторонними скриптами настроить сложнее.
