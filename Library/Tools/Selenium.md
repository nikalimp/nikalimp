## Описание

Selenium — открытый фреймворк для автоматизации браузера: скрипт сам открывает страницы, кликает, заполняет формы и проверяет результат. Используют для тестов и парсинга.

Главное отличие — стандарт W3C WebDriver и поддержка многих языков: Java, Python, C#, JavaScript, Ruby. Selenium управляет Chrome, Firefox, Edge и Safari через их собственные драйверы.

### Возможности
- **WebDriver** — управление браузером из кода на привычном языке.
- **Selenium Grid** — параллельный запуск тестов на нескольких машинах и браузерах.
- **Selenium IDE** — расширение браузера, которое записывает действия и превращает их в тест.
- **Selenium Manager** сам скачивает нужный драйвер браузера.
- **Интеграции** с CI, например [[GitHub Actions]], и облачными фермами вроде [[BrowserStack]].

### Кому подходит
QA-инженерам с большим набором тестов, командам на Java и C#, разработчикам, которым нужна автоматизация браузера в существующем проекте.

### Как начать
Установите библиотеку (pip install selenium), напишите скрипт, который открывает страницу и ищет элемент, и запустите. Драйвер Selenium Manager подтянет сам.

### Совет
Не используйте фиксированные паузы вроде sleep. Ставьте явные ожидания (WebDriverWait) на нужный элемент — тесты станут быстрее и перестанут падать случайно.

### Ограничения
Selenium медленнее и капризнее современных инструментов: ожидания, нестабильные тесты и настройка Grid требуют опыта. Для нового проекта на JavaScript или Python часто проще [[Playwright]], для Chrome-автоматизации — [[Puppeteer]].

## Вердикт
- Кому подходит: QA-командам на Java, C# или Python и проектам, где тесты уже написаны на Selenium.
- Кому не подходит: Новым фронтенд-проектам, которым нужен быстрый старт и стабильные тесты из коробки.
- Итог: Проверенный стандарт автоматизации браузеров с огромной экосистемой, но более трудоёмкий, чем новые фреймворки.

## Плюсы
- Бесплатный и с открытым кодом
- Поддержка Java, Python, C#, JavaScript, Ruby
- Все основные браузеры через стандарт WebDriver
- Selenium Grid для параллельных запусков

## Минусы
- Тесты медленнее, чем в Playwright
- Без явных ожиданий тесты нестабильны
- Настройка Grid требует времени

## Частые вопросы
### Selenium бесплатный?
Да, это проект с открытым кодом. Платить приходится только за облачные фермы браузеров, если они нужны.

### Работает ли Selenium в России?
Да, библиотеки и драйверы скачиваются без VPN, а сам Selenium работает на вашем компьютере или сервере.

### Selenium или Playwright?
[[Playwright]] быстрее, сам ждёт элементы и проще в настройке. Selenium выбирают ради Java и C#, старых браузеров и уже написанных тестов.

### Можно ли парсить сайты через Selenium?
Можно, особенно если страница строится на JavaScript. Но для больших объёмов это медленно, и многие сайты распознают автоматизированный браузер.
