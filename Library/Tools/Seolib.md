## Описание

Seolib — российский сервис SEO-аналитики: съём позиций в Яндексе и Google, анализ видимости, проверка ссылок, подбор запросов и аудит сайта с оплатой за фактический объём.

Главное отличие — модель оплаты с баланса: вы платите за проверки, а не за месячный тариф. Для небольших проектов это дешевле подписки.

### Возможности
- **Позиции и топы** — съём позиций по регионам, видимость сайта, отчёты по конкурентам.
- **Анализ сайта** — проверка фильтров и оценка трафика.
- **Анализ ссылок** — показатели доноров и индексация ссылок.
- **Работа с запросами** — частотность, геозависимость, подбор релевантных страниц, анализ текстов конкурентов.
- **Генераторы** robots.txt и метатегов, API для разработчиков.

### Кому подходит
SEO-фрилансерам и небольшим агентствам с несколькими проектами, владельцам сайтов, которые проверяют позиции нерегулярно.

### Как начать
Зарегистрируйтесь, используйте приветственные 10 ₽ на тестовую проверку позиций, затем пополните баланс и настройте проект с запросами и регионом.

### Совет
Снимайте позиции раз в неделю, а не ежедневно: для большинства сайтов динамика видна и так, а расходы снижаются в несколько раз.

### Ограничения
Интерфейс выглядит старомодно, а модули разбросаны по разделам. Для ежедневного съёма позиций с удобными отчётами популярнее [[Топвизор]], для глубокой аналитики — [[Rush Analytics]] и [[Keys.so]].

## Частые вопросы
### Seolib бесплатный?
Нет, все модули платные, но при регистрации дают 10 ₽ на баланс для теста. Дальше платите только за проверки.

### Работает ли Seolib в России?
Да, это российский сервис: работает без VPN, принимает российские карты и выставляет счета юрлицам.

### Seolib или Топвизор?
Оба снимают позиции в Яндексе и Google. [[Топвизор]] удобнее для регулярной работы и отчётов клиентам, Seolib дешевле при редких проверках.

### Можно ли работать с Seolib через API?
Да, у сервиса есть API для разработчиков, через который можно забирать позиции и данные в свои отчёты.
