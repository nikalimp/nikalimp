## Описание

Shepherd.js — это JavaScript-библиотека для пошаговых туров по интерфейсу: подсказки привязываются к элементам страницы и ведут пользователя по шагам.

Главное отличие от SaaS-сервисов вроде [[Appcues]] и [[Userpilot]] — тур живёт в вашем коде. Нет внешнего кабинета и оплаты за пользователей, но и визуального редактора нет.

### Возможности
- **Шаги с привязкой** к любому элементу через CSS-селектор.
- **Позиционирование подсказок** на основе Floating UI.
- **Подсветка элемента** и затемнение остальной страницы.
- **Обёртки** для React, Vue, Angular и Ember.
- **Доступность:** управление с клавиатуры и фокус.
- **Свои стили** через CSS.

### Кому подходит
Разработчикам SaaS и веб-сервисов, которым нужен онбординг без внешнего сервиса и без ежемесячной оплаты за пользователей.

### Как начать
Установите пакет через npm, создайте тур и добавьте шаги с текстом и селекторами элементов. Запускайте тур при первом входе пользователя.

### Совет
Делайте тур из 3–5 шагов, которые ведут к первому полезному действию, а не показывают все кнопки. Длинные туры закрывают на втором шаге.

### Ограничения
Нет аналитики и редактора без кода. Для коммерческого проекта проверьте условия лицензии. Простая альтернатива — [[Intro.js]]. Тексты шагов хранятся в коде, и любая правка формулировки требует нового релиза продукта.

## Частые вопросы
### Shepherd.js бесплатный?
Код открыт и бесплатен для некоммерческих проектов. Для коммерческого продукта нужна платная лицензия.

### Работает ли Shepherd.js в России?
Да, библиотека ставится через npm и работает без ограничений. Ограничение одно: лицензию не оплатить российской картой.

### Shepherd.js или Intro.js?
[[Intro.js]] проще для быстрого старта. Shepherd.js гибче в позиционировании и стилизации и лучше работает с фреймворками.

### Можно ли использовать Shepherd.js с React?
Да, есть официальная обёртка для React, а также для Vue и Angular.
