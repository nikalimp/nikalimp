# Silktide

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Доступность (a11y) · Global
Буква: S · Страница на сайте: `/tools/silktide`

## Описание

Silktide — это платформа для проверки доступности и качества сайтов: сканирует страницы по WCAG, находит ошибки контента и SEO и показывает, как их исправить.

Главное отличие — бесплатное расширение для Chrome с симулятором. Оно не только находит ошибки, но и показывает страницу глазами человека с нарушением зрения или через экранную читалку.

### Возможности
- **Проверка WCAG 2.2** по всему сайту по расписанию.
- **Симулятор** дальтонизма, слабого зрения и экранной читалки.
- **Контроль контента:** орфография, битые ссылки, читаемость.
- **SEO-проверки** страниц.
- **Отчёты и приоритеты** для команды.
- **Бесплатное расширение** для проверки одной страницы.

### Кому подходит
Компаниям с большими сайтами, госсектору и вузам, которым нужно подтверждать соответствие стандартам доступности. Дизайнерам и разработчикам — бесплатное расширение.

### Как начать
Поставьте расширение Silktide Accessibility Checker, откройте страницу и запустите проверку. Начните с ошибок контраста, альтернативного текста и подписей полей форм.

### Совет
Включите симулятор экранной читалки и пройдите форму заявки только с клавиатуры. Так за пять минут видно, может ли человек без мыши оставить заявку.

### Ограничения
Цены платформы не опубликованы, она рассчитана на организации. Для разовой проверки хватит бесплатных [[WAVE]] и [[axe DevTools]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, Расширение браузера

## Вердикт
- Кому подходит: Организациям, которым нужен постоянный контроль доступности, и дизайнерам — бесплатное расширение.
- Кому не подходит: Малому бизнесу, которому нужна разовая проверка без бюджета.
- Итог: Сильная платформа доступности с бесплатным расширением, которое стоит поставить каждому веб-дизайнеру.

## Частые вопросы
### Silktide бесплатный?
Расширение для Chrome бесплатное. Платформа для проверки всего сайта продаётся по запросу.

### Работает ли Silktide в России?
Расширение работает без ограничений. Платную платформу российской компании оформить сложно.

### Silktide или Siteimprove?
Обе платформы корпоративные. [[Siteimprove]] шире по аналитике и маркетингу, Silktide проще и даёт удобное бесплатное расширение.

### Что проверять в первую очередь?
Контраст текста, альтернативный текст изображений, подписи полей форм и навигацию с клавиатуры.
