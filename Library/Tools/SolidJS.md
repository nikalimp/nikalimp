## Описание

SolidJS — это JavaScript-библиотека для интерфейсов с синтаксисом JSX, как у [[React]], но без виртуального DOM. Компоненты выполняются один раз, а обновления точечно меняют нужные узлы страницы.

Главное отличие — реактивность на сигналах. Solid не перерисовывает компонент целиком, поэтому он быстрее большинства фреймворков в бенчмарках и даёт маленький бандл.

### Возможности
- **Сигналы, мемо и эффекты** вместо хуков с массивами зависимостей.
- **JSX** и привычная для React-разработчика структура компонентов.
- **SolidStart** — метафреймворк с SSR, роутингом и серверными функциями.
- **Store** для вложенного состояния без иммутабельных копий.
- **Suspense и стриминг** для асинхронных данных.
- **Сборка через [[Vite]]** из коробки.

### Кому подходит
Фронтенд-разработчикам, которым важны скорость и размер бандла: виджеты, встраиваемые компоненты, дашборды с частыми обновлениями.

### Как начать
Создайте проект командой npm create solid, выберите шаблон и пройдите интерактивный учебник на сайте. Знание React сократит вход до пары дней.

### Совет
Не деструктурируйте props: в Solid это ломает реактивность. Обращайтесь к props.name напрямую или используйте splitProps.

### Ограничения
Экосистема меньше, чем у React и [[Vue.js]]: меньше готовых UI-библиотек и вакансий. Похожий подход к реактивности есть у Svelte и [[Qwik]].

## Вердикт
- Кому подходит: Разработчикам, которым нужна скорость и маленький бандл при знакомом JSX-синтаксисе.
- Кому не подходит: Командам, которым важны большая экосистема компонентов и простой найм.
- Итог: Быстрая реактивная библиотека для тех, кто знает React и хочет меньше перерисовок.

## Плюсы
- Высокая скорость без виртуального DOM
- Маленький размер бандла
- Знакомый JSX
- Бесплатно и с открытым кодом

## Минусы
- Небольшая экосистема UI-библиотек
- Мало вакансий и специалистов
- Другие правила реактивности: привычки из React ломают код

## Частые вопросы
### SolidJS бесплатный?
Да, это открытая библиотека под лицензией MIT. Её можно использовать в коммерческих проектах без оплаты.

### Работает ли SolidJS в России?
Да, пакеты ставятся из npm без VPN, документация открыта.

### SolidJS или React?
[[React]] выигрывает экосистемой и рынком труда. SolidJS быстрее и легче, но готовых компонентов меньше. Для лендингов с минимумом JS ещё подойдёт Astro с островами на Solid.

### Есть ли у SolidJS фреймворк для SSR?
Да, SolidStart: роутинг на файлах, серверный рендеринг и серверные функции, по роли аналог [[Next.js]].
