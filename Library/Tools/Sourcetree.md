## Описание

Sourcetree — бесплатный графический Git-клиент от Atlassian для Windows и macOS. Он показывает историю, ветки и изменения в виде наглядного дерева и выполняет команды Git кнопками.

Главное отличие — глубокая поддержка Git Flow и тесная связь с [[Bitbucket]], при этом программа работает и с [[GitHub]], [[GitLab]] и любым удалённым репозиторием.

### Возможности
- **Граф коммитов:** история веток и слияний в виде дерева.
- **Индексация по строкам:** в коммит можно добавить отдельные куски файла.
- **Git Flow и Hg Flow** встроены в интерфейс.
- **Интерактивный rebase,** cherry-pick, stash и работа с подмодулями.
- **Git LFS** для больших файлов.

### Кому подходит
Дизайнерам, верстальщикам и начинающим разработчикам, которым трудно держать в голове команды Git. Командам на Bitbucket, где Sourcetree стал стандартом.

### Как начать
Скачайте установщик, подключите аккаунт хостинга или вставьте ссылку на репозиторий и клонируйте его. Дальше коммиты, push и pull делаются кнопками на панели.

### Совет
Включите в настройках показ команд, которые Sourcetree выполняет. Так вы быстрее выучите сам Git и сможете работать в терминале, когда клиента нет под рукой.

### Ограничения
На больших репозиториях интерфейс бывает медленным. Версии для Linux нет. Альтернативы с более быстрым интерфейсом — [[GitKraken]] и [[GitHub Desktop]].

## Частые вопросы
### Sourcetree бесплатный?
Да, Sourcetree полностью бесплатный, в том числе для коммерческих проектов.

### Работает ли Sourcetree в России?
Сама программа работает и подключается к любым репозиториям, включая [[GitFlic]] и [[GitVerse]]. Скачивание с сайта Atlassian и вход в аккаунт Atlassian из России могут потребовать VPN.

### Sourcetree или GitHub Desktop?
[[GitHub Desktop]] проще и быстрее, но заточен под GitHub. Sourcetree сложнее, зато даёт rebase, Git Flow и работу с любым хостингом.

### Нужен ли аккаунт Atlassian для Sourcetree?
Установщик для Windows может предложить вход в аккаунт Atlassian или Bitbucket. Для работы с репозиториями на других хостингах достаточно ссылки и SSH-ключа.
