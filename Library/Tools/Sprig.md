# Sprig

Буква: S · Страница на сайте: `/tools/sprig`

## Описание

Sprig — это платформа продуктовых исследований: опросы внутри продукта, записи сессий, тепловые карты и анализ ответов с помощью AI. Сервис раньше назывался UserLeap.

Главное отличие — опросы показываются в момент действия пользователя: например, сразу после первого экспорта отчёта. Ответы связываются с поведением, а AI группирует открытые ответы по темам.

### Возможности
- **Опросы внутри продукта** с таргетингом по событиям и атрибутам.
- **Записи сессий** с фильтром по ответам на опрос.
- **Тепловые карты** кликов и прокрутки.
- **Опросы по ссылке** и сбор отзывов.
- **AI-анализ** открытых ответов и сводки по темам.
- **SDK** для веба, iOS и Android, интеграции с Segment и аналитикой.

### Кому подходит
Продуктовым менеджерам и UX-исследователям SaaS-продуктов, которым нужна постоянная обратная связь без отдельных интервью.

### Как начать
Подключите SDK, передайте ID пользователя и 2–3 ключевых события. Запустите короткий опрос из одного вопроса после целевого действия.

### Совет
Задавайте один вопрос за раз и ограничьте частоту показа на пользователя. Короткий опрос даёт в разы больше ответов, чем анкета на 10 пунктов.

### Ограничения
На бесплатном плане — 25 ответов на опросы в месяц, этого мало для выводов. Мобильная доставка на Starter стоит отдельно. Для интервью и тестов прототипов лучше [[Maze]] или [[Lyssna]].

## Карточка
- Россия: зарубежная карта
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, iOS, Android, API

## Вердикт
- Кому подходит: Продуктовым командам SaaS, которые хотят спрашивать пользователей прямо в момент действия.
- Кому не подходит: Небольшим сайтам и проектам без бюджета в валюте.
- Итог: Удобная платформа для опросов внутри продукта и записей сессий с AI-анализом, но платная для реальных объёмов.

## Плюсы
- Опросы по событиям в нужный момент
- Связь ответов с записями сессий
- AI-группировка открытых ответов
- SDK для веба и мобильных приложений

## Минусы
- Малые лимиты бесплатного плана
- Мобильная доставка на Starter стоит отдельно
- Оплата только зарубежной картой

## Частые вопросы
### Sprig бесплатный?
Да, бесплатный план есть, но с лимитами: 25 ответов на опросы внутри продукта и 50 записей сессий в месяц. Когда лимит исчерпан, сбор данных останавливается до следующего месяца.

### Работает ли Sprig в России?
Сайт работает, но оплатить платный тариф можно только зарубежной картой.

### Sprig или Maze?
[[Maze]] тестирует прототипы и сценарии до релиза. Sprig собирает обратную связь от реальных пользователей в работающем продукте.

### Чем заменить Sprig?
Для записей сессий — [[Hotjar]] или [[Microsoft Clarity]], для опросов — [[Userpilot]]. В России часть задач решает Вебвизор [[Яндекс Метрика|Яндекс Метрики]].
