## Описание

StackBlitz — онлайн-среда разработки, которая запускает Node.js прямо в браузере. Проекты на React, Vue, Angular, Next.js и Vite открываются за секунды без установки чего-либо на компьютер.

Главное отличие — технология WebContainers: сервер разработки, npm и терминал работают внутри вкладки, а не на удалённой машине. Поэтому всё быстро и работает даже без стабильной связи после загрузки. Та же команда сделала ИИ-конструктор [[Bolt.new]].

### Возможности
- **Node.js в браузере:** npm, терминал и сервер разработки без облачной виртуалки.
- **Шаблоны** для популярных фреймворков в один клик.
- **Открытие репозиториев GitHub** по ссылке.
- **Редактор на базе VS Code** с подсказками и горячими клавишами.
- **Встраивание** живых примеров в документацию и статьи.

### Кому подходит
Фронтенд-разработчикам для быстрых экспериментов, авторам библиотек для живых примеров, преподавателям и тем, кто воспроизводит баг для issue.

### Как начать
Откройте stackblitz.com, выберите шаблон или вставьте ссылку на репозиторий [[GitHub]]. Код можно сразу править и делиться ссылкой.

### Совет
Прикладывайте к баг-репортам ссылку на минимальный пример в StackBlitz: мейнтейнеры отвечают на такие issue заметно быстрее.

### Ограничения
Бэкенд на Python, PHP или с нативными модулями не запустится. Для этого берите [[Replit]] или [[CodeSandbox]]. Для больших проектов удобнее локальный [[VS Code]].

## Вердикт
- Кому подходит: Фронтенд-разработчикам, которым нужно быстро запустить проект на JavaScript без настройки окружения.
- Кому не подходит: Тем, кто пишет бэкенд не на Node.js или работает с тяжёлыми проектами.
- Итог: Самая быстрая песочница для JavaScript-проектов, которая работает целиком в браузере.

## Частые вопросы
### StackBlitz бесплатный?
Да, личный план бесплатный и не ограничивает число публичных проектов. Платить нужно за командную работу с приватными репозиториями организаций.

### Работает ли StackBlitz в России?
Да, сервис открывается без VPN. Оплатить тариф Teams российской картой не получится.

### StackBlitz или CodeSandbox?
StackBlitz запускает код в браузере и стартует быстрее. [[CodeSandbox]] использует облачные виртуальные машины и подходит для проектов, где нужен не только Node.js.

### Чем StackBlitz отличается от Bolt.new?
StackBlitz — редактор кода для разработчиков. [[Bolt.new]] построен на той же технологии, но код за вас пишет ИИ по текстовому описанию.
