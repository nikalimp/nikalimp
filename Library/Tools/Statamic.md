# Statamic

[[Инструменты — No-code и CMS|No-code и CMS]] · Классические CMS · Global
Буква: S · Страница на сайте: `/tools/statamic`

## Описание

Statamic — это CMS на [[Laravel]], которая по умолчанию хранит контент в файлах Markdown и YAML, а не в базе данных. Контент живёт в Git вместе с кодом, при желании базу данных можно подключить.

Главное отличие — удобная панель управления для редакторов при полном контроле разработчика: шаблоны на Antlers или Blade, любые пакеты Laravel и генерация статического сайта.

### Возможности
- **Файловое хранение контента** с версионированием в Git.
- **Конструктор полей** (Blueprints) и блочный редактор Bard.
- **Коллекции, таксономии и навигация** без кода.
- **Статическая генерация** через пакет SSG для деплоя на CDN.
- **GraphQL и REST API** в версии Pro для headless-сайтов.
- **Мультисайт, роли и ревизии** в Pro.

### Кому подходит
Разработчикам на Laravel и студиям, которые делают сайты для клиентов и хотят понятную админку без WordPress-плагинов.

### Как начать
Создайте проект через Statamic CLI или composer create-project, выберите стартовый набор и откройте панель по адресу /cp. Core бесплатен, Pro можно тестировать локально без лицензии.

### Совет
Храните контент в Git и деплойте через CI: так правки редакторов проходят тот же путь, что и код, а откат занимает одну команду.

### Ограничения
Нужен PHP-хостинг и знание Laravel. Для блога без разработчика проще [[Ghost]], для похожего файлового подхода на PHP есть [[Kirby]], для крупных баз — [[Craft CMS]].

## Частые вопросы
### Statamic бесплатный?
Да, версия Core бесплатна. Pro стоит $349 за сайт разово, обновления после первого года — $99 в год.

### Работает ли Statamic в России?
Да, это пакет для Laravel: он ставится через Composer и работает на любом российском хостинге с PHP. Ограничение только в оплате лицензии Pro.

### Statamic или WordPress?
[[WordPress (инструмент)|WordPress]] выигрывает числом тем, плагинов и подрядчиков. Statamic чище по коду, безопаснее из-за отсутствия десятков плагинов и удобнее для разработчиков на Laravel.

### Нужна ли Statamic база данных?
Нет, по умолчанию контент хранится в файлах. Базу данных подключают для больших объёмов или частых записей, например пользователей и заказов.
