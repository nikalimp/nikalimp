## Описание

Storybook Test — это набор инструментов тестирования внутри [[Storybook]]: каждая история компонента становится тестом рендеринга, взаимодействий и доступности. С версии 8.5 тесты запускаются через [[Vitest]] прямо из интерфейса Storybook.

Главное отличие — тесты пишутся на уже готовых историях. Не нужно заново описывать состояния компонента: история с пропсами и действиями в play-функции и есть тест.

### Возможности
- **Тесты рендеринга:** история упала с ошибкой, значит тест не прошёл.
- **Тесты взаимодействий** через play-функции: клики, ввод, проверки expect.
- **Проверки доступности** на axe-core для каждой истории.
- **Покрытие кода** отчётом прямо в Storybook.
- **Запуск в браузере** через Vitest и [[Playwright]], в режиме наблюдения и в CI.
- **Визуальные тесты** через облако [[Chromatic]].

### Кому подходит
Фронтенд-командам с дизайн-системой или библиотекой компонентов, которые уже пишут истории и хотят тестов без дублирования.

### Как начать
Выполните npx storybook add @storybook/addon-vitest в проекте со Storybook 8.5+ на Vite. В боковой панели появится кнопка запуска тестов.

### Совет
Добавляйте play-функцию в истории ключевых состояний: открытое меню, ошибка формы, пустой список. Эти состояния чаще всего ломаются при рефакторинге.

### Ограничения
Лучше всего работает с проектами на [[Vite]]. Сквозные сценарии через несколько страниц оставьте [[Playwright]] или [[Cypress]].

## Вердикт
- Кому подходит: Командам с библиотекой компонентов на Storybook, которые хотят тестировать истории без отдельного кода.
- Кому не подходит: Проектам без Storybook и тем, кому нужны только сквозные тесты страниц.
- Итог: Бесплатный способ превратить истории компонентов в тесты взаимодействий, доступности и покрытия.

- Бесплатно и с открытым кодом

## Частые вопросы
### Storybook Test бесплатный?
Да, тестирование входит в открытый Storybook. Платно только облако [[Chromatic]] для визуальных тестов, у него есть бесплатный лимит снимков.

### Работает ли Storybook Test в России?
Да, пакеты ставятся из npm, тесты запускаются на вашем компьютере и в CI без VPN.

### Storybook Test или Jest?
[[Jest]] тестирует логику и компоненты в эмуляции DOM. Storybook Test запускает компоненты в настоящем браузере и использует готовые истории.

### Можно ли запускать тесты Storybook в CI?
Да, команда vitest запускает тесты историй в CI, а отчёт о покрытии формируется там же.
