## Описание

Style Dictionary — это инструмент сборки дизайн-токенов: он берёт цвета, отступы, шрифты и тени из JSON и генерирует из них CSS-переменные, SCSS, JS, Swift, Kotlin и другие форматы.

Главное отличие — один источник правды для всех платформ. Дизайнер меняет цвет в токенах, а веб, iOS и Android получают одинаковое значение после сборки, без ручного копирования.

### Возможности
- **Токены в JSON** с поддержкой формата W3C Design Tokens (DTCG) с версии 4.
- **Ссылки между токенами:** семантические токены ссылаются на базовую палитру.
- **Трансформации:** перевод единиц, цветовых форматов, имён в нужный регистр.
- **Готовые форматы** для CSS, SCSS, JS, TypeScript, iOS и Android.
- **Свои трансформации и форматы** на JavaScript.
- **Темы и бренды** через несколько наборов исходников.

### Кому подходит
Командам дизайн-систем, которые поддерживают несколько платформ или брендов и хотят собирать токены автоматически.

### Как начать
Установите пакет из npm, создайте папку tokens с JSON-файлами и config.json с нужными платформами. Запустите сборку и подключите получившийся CSS-файл.

### Совет
Делите токены на три уровня: базовые (палитра), семантические (фон, текст, акцент) и компонентные. В интерфейсе используйте только семантические, тогда тёмная тема меняется одной подстановкой.

### Ограничения
Нет визуального интерфейса: настройка идёт через код. Чтобы дизайнеры правили токены в [[Figma]], используют [[Tokens Studio]] с синхронизацией в Git, а Style Dictionary собирает результат.

## Частые вопросы
### Style Dictionary бесплатный?
Да, это открытая библиотека от Amazon под лицензией Apache 2.0. Её можно использовать в коммерческих проектах.

### Работает ли Style Dictionary в России?
Да, пакет ставится из npm без VPN и работает локально и в CI.

### Style Dictionary или Tokens Studio?
Это не замена, а связка. [[Tokens Studio]] — плагин Figma для управления токенами, Style Dictionary превращает эти токены в код для платформ.

### Чем Style Dictionary помогает с тёмной темой?
Вы описываете семантические токены дважды, для светлой и тёмной темы, а сборка генерирует два набора CSS-переменных. Компоненты не меняются.
