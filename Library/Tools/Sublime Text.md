## Описание

Sublime Text — быстрый платный редактор кода для Windows, macOS и Linux с мультикурсорами, поиском по проекту и тысячами плагинов.

Главное отличие: Sublime Text открывается мгновенно и легко работает с огромными файлами, на которых тяжёлые IDE и [[VS Code]] начинают тормозить.

### Возможности
- **Мультикурсоры:** правка десятков строк одновременно.
- **Goto Anything:** переход к файлу, функции или строке по нескольким буквам.
- **Подсветка синтаксиса** для большинства языков.
- **Package Control:** тысячи плагинов и тем.
- **Разделение экрана** и работа с несколькими проектами.
- **Поддержка LSP** через плагины для автодополнения и подсказок.

### Кому подходит
Разработчикам, которым нужен лёгкий и быстрый редактор, а также тем, кто работает с большими логами, CSV и конфигами.

### Как начать
Скачайте редактор с официального сайта, установите Package Control через палитру команд и добавьте плагины для своего языка.

### Совет
Выучите три сочетания клавиш: выделение следующего вхождения, разделение выделения на строки и Goto Anything. Они дают основную часть скорости Sublime.

### Ограничения
AI-функций и встроенного отладчика нет, поэтому многие перешли на [[VS Code]] или [[Cursor]]. Для полноценной работы с большим проектом удобнее [[WebStorm]].

## Частые вопросы
### Sublime Text бесплатный?
Им можно пользоваться бесплатно без ограничения по сроку, но редактор будет напоминать о покупке. Личная лицензия стоит $99.

### Работает ли Sublime Text в России?
Да, редактор скачивается и работает без VPN. Купить лицензию можно только зарубежной картой.

### Sublime Text или VS Code?
Sublime быстрее и легче, [[VS Code]] бесплатный, с отладчиком, git и AI-расширениями. Для большинства задач сегодня выбирают VS Code.

### Что входит в лицензию Sublime Text?
Личная лицензия бессрочная и включает обновления на 3 года. После этого можно работать на последней доступной версии или оплатить обновление.
