# Supernova

Буква: S · Страница на сайте: `/tools/supernova`

## Описание

Supernova — это платформа для документации и поставки дизайн-систем: она забирает токены и компоненты из [[Figma]] и кода, собирает сайт документации и генерирует код токенов для платформ.

Главное отличие от [[Zeroheight]] — упор на автоматизацию: экспорт токенов в код через пайплайны, а с недавних пор MCP-серверы, через которые AI-агенты пишут код по вашей дизайн-системе.

### Возможности
- **Импорт токенов** из Figma Variables и [[Tokens Studio]].
- **Сайт документации** с живыми примерами компонентов из [[Storybook]].
- **Экспорт токенов в код** для веба, iOS и Android через пайплайны.
- **MCP-серверы** для Claude Code, Cursor и других агентов.
- **Отслеживание версий** дизайн-системы и изменений.
- **Права доступа** и приватные сайты документации на Pro.

### Кому подходит
Командам дизайн-систем в продуктовых компаниях, которые поддерживают несколько продуктов и хотят, чтобы дизайн, код и документация не расходились.

### Как начать
Подключите файл Figma с переменными, настройте структуру страниц документации и пригласите коллег. Бесплатного плана хватит, чтобы опубликовать публичные доки.

### Совет
Начните с токенов, а не с компонентов. Синхронизированные токены дают эффект сразу во всех продуктах, документация компонентов может подождать.

### Ограничения
Pro стоит $399 в месяц, это дорого для небольших команд. Бесплатный план ограничен 20 страницами и публичной документацией. Для генерации токенов без платформы хватает [[Style Dictionary]].

## Частые вопросы
### Supernova бесплатный?
Да, план Starter бесплатен: 3 редактора, 20 страниц публичной документации и одна дизайн-система. Приватные доки и свой домен — с тарифа Pro.

### Работает ли Supernova в России?
Сайт работает, но тариф Pro можно оплатить только зарубежной картой.

### Supernova или Zeroheight?
[[Zeroheight]] проще для написания документации. Supernova сильнее в автоматизации: экспорт токенов в код и MCP-серверы для AI-агентов.

### Зачем дизайн-системе MCP-сервер?
Через него AI-агент вроде [[Cursor]] получает ваши токены и компоненты и пишет код по дизайн-системе, а не по общим шаблонам.
