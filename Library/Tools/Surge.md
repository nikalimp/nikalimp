# Surge

Буква: S · Страница на сайте: `/tools/surge`

## Описание

Surge — это хостинг статических сайтов, который публикует папку с HTML, CSS и JS одной командой в терминале. Сайт получает адрес вида project.surge.sh за несколько секунд.

Главное отличие — минимализм: нет панели, сборки и настроек. Установили утилиту через npm, запустили `surge` в папке проекта — сайт в сети.

### Возможности
- **Публикация одной командой** из любой папки со статикой.
- **Свой домен** на бесплатном плане: достаточно настроить DNS.
- **Страница 404** и обработка маршрутов одностраничных приложений через файл 200.html.
- **Совместная работа:** можно добавить других людей к проекту.
- **Интеграция в CI:** публикация по токену из GitHub Actions и других сервисов.

### Кому подходит
Разработчикам и дизайнерам, которым нужно быстро показать прототип, макет в коде или собранный сайт на [[Vite]] или [[Eleventy]]. Удобно для временных демо для клиента.

### Как начать
Установите Node.js и выполните `npm install --global surge`. Перейдите в папку со сборкой и запустите `surge`: утилита попросит почту и пароль и предложит адрес.

### Совет
Для одностраничного приложения скопируйте index.html в 200.html — тогда прямые ссылки на внутренние страницы не будут отдавать 404.

### Ограничения
Только статика: серверного кода, функций и форм нет. Нет автоматической сборки из репозитория и превью для веток, как у [[Vercel]] и [[Cloudflare Pages]]. Сервис развивается медленно.

## Вердикт
- Кому подходит: Тем, кто хочет выложить статичный прототип или демо за минуту, без настройки репозитория и панели.
- Кому не подходит: Проектам с серверной логикой, формами, превью веток и автоматическими деплоями из Git.
- Итог: Самый быстрый способ опубликовать папку со статикой, но для рабочих сайтов есть более полные сервисы.

## Плюсы
- Публикация одной командой без регистрации в панели
- Свой домен бесплатно
- Подходит для одностраничных приложений

## Частые вопросы
### Surge бесплатный?
Да, основной функционал бесплатный: проекты без ограничений и свой домен. Платный Surge Plus добавляет SSL для своего домена, пароль и редиректы.

### Работает ли Surge в России?
Да, утилита и публикация работают без VPN. Платный тариф оплачивается только зарубежной картой.

### Surge или GitHub Pages?
Surge публикует папку с компьютера одной командой. [[GitHub Pages]] публикует сайт из репозитория и даёт бесплатный HTTPS для своего домена.

### Чем заменить Surge для рабочего сайта?
Для сайтов с автоматической сборкой и превью подойдут [[Vercel]] и [[Cloudflare Pages]].
