## Описание

SvelteKit — фреймворк для создания сайтов и веб-приложений на Svelte. Он отвечает за маршруты, серверный рендеринг, загрузку данных и сборку, а Svelte — за компоненты интерфейса.

Главное отличие от [[Next.js]] и [[React]] — компилятор. Svelte превращает компоненты в небольшой чистый JavaScript без виртуального DOM, поэтому страницы получаются лёгкими, а код компонентов короче.

### Возможности
- **Маршрутизация по файлам:** папка в `src/routes` превращается в страницу.
- **Рендеринг на выбор:** SSR, статическая генерация и SPA для отдельных страниц.
- **Загрузка данных и формы** через функции `load` и серверные actions.
- **Адаптеры** для Node.js, [[Vercel]], [[Cloudflare Pages]] и статического хостинга.
- **Сборка на [[Vite]]** с быстрым горячим обновлением.

### Кому подходит
Разработчикам, которые хотят быстрые сайты с минимумом JavaScript, и командам, уставшим от сложности экосистемы React. Хорош для лендингов, блогов и небольших сервисов.

### Как начать
Выполните `npx sv create my-app`, выберите шаблон и TypeScript, затем запустите `npm run dev`. Страницы создаются файлами `+page.svelte` в папке маршрутов.

### Совет
Для сайта-визитки или блога включите `adapter-static` и предрендеринг: получите набор HTML-файлов, который размещается на любом хостинге без Node.js.

### Ограничения
Экосистема меньше, чем у React: готовых UI-библиотек и вакансий меньше. Для работы с [[Tailwind CSS]] всё готово, а вот привычные React-компоненты вроде [[shadcn ui|shadcn/ui]] доступны только в неофициальных портах.

## Вердикт
- Кому подходит: Разработчикам, которым важны лёгкие страницы, короткий код и серверный рендеринг из коробки.
- Кому не подходит: Командам, которые зависят от экосистемы React и готовых библиотек компонентов.
- Итог: Быстрый и приятный фреймворк для сайтов и приложений, но с меньшей экосистемой, чем у Next.js.

## Плюсы
- Мало JavaScript в браузере и высокая скорость
- Короткий и понятный код компонентов
- SSR, статика и SPA в одном проекте
- Адаптеры для любого хостинга

## Минусы
- Меньше готовых библиотек и примеров, чем у React
- Меньше разработчиков на рынке
- Крупные изменения между версиями Svelte требуют миграции

## Частые вопросы
### SvelteKit бесплатный?
Да, SvelteKit и Svelte распространяются бесплатно под лицензией MIT, в том числе для коммерческих проектов.

### Работает ли SvelteKit в России?
Да, фреймворк устанавливается через npm и не зависит от облачных сервисов. Готовый сайт можно разместить на любом хостинге.

### SvelteKit или Next.js?
[[Next.js]] построен на React и имеет огромную экосистему. SvelteKit даёт более лёгкие страницы и короткий код, но готовых решений меньше.

### Можно ли сделать на SvelteKit статический сайт?
Да, с `adapter-static` SvelteKit собирает проект в HTML-файлы, которые работают на любом хостинге или [[GitHub Pages]].
