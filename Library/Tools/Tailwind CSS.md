## Описание

Tailwind CSS — CSS-фреймворк, в котором стили задаются короткими служебными классами прямо в разметке: `flex`, `p-4`, `text-lg`, `bg-white`. Вместо написания своих CSS-файлов разработчик собирает внешний вид из готовых «кирпичиков».

Фреймворк выпустил Адам Уотан в 2017 году. Подход сначала критиковали за «грязную» разметку, но сегодня Tailwind — стандарт в современной фронтенд-разработке.

### Возможности
- **Служебные классы** для отступов, цветов, сеток, типографики, анимаций.
- **Адаптивность** префиксами: `md:`, `lg:`.
- **Состояния:** `hover:`, `focus:`, `dark:` для тёмной темы.
- **Дизайн-токены:** цвета, шрифты и отступы настраиваются через CSS-переменные.
- **Минимальный итоговый CSS:** в сборку попадают только использованные классы.
- **Интеграции** с React, Next.js, Vue, Svelte и другими фреймворками.

### Кому подходит
Фронтенд-разработчикам и дизайнерам, которые верстают сами. Командам, которым нужна единая система отступов и цветов без разрастания CSS-файлов. AI-инструменты для кода генерируют интерфейсы в основном на Tailwind.

### Как начать
Установите Tailwind по инструкции для вашего фреймворка — в Next.js он подключается при создании проекта. Настройте цвета и шрифты бренда как переменные темы.

### Совет
Не копируйте одинаковые длинные наборы классов по всему проекту. Выносите повторяющиеся элементы в компоненты: кнопка, карточка, бейдж.

### Связь с дизайн-системой
Классы Tailwind напрямую отражают шкалы отступов и цветов. Если дизайнер в Figma использует те же шкалы, перенос макета в код идёт почти без расхождений.

### Ограничения
Длинные строки классов читаются тяжело. Помогают компоненты и автоматическая сортировка классов плагином Prettier.

### Частый вопрос
**Tailwind или Bootstrap?** Bootstrap даёт готовые компоненты с узнаваемым видом, Tailwind — инструменты для своего дизайна. Готовые компоненты на Tailwind берут из [[shadcn ui|shadcn/ui]]. Основа для проектов — [[React]] и [[Next.js]].

## Вердикт
- Кому подходит: Разработчикам и дизайнерам, которые верстают интерфейсы быстро и хотят держать стили рядом с разметкой.
- Кому не подходит: Тем, кто верстает без сборки и не хочет учить набор служебных классов.
- Итог: Tailwind CSS — бесплатный фреймворк с готовыми классами, а платными продаются только готовые компоненты и шаблоны Tailwind Plus.

## Плюсы
- Стили пишутся классами прямо в разметке, не нужно придумывать названия
- Бесплатный и с открытым кодом
- В итоговом файле остаются только используемые стили
- Работает с React, Next.js, Vue и другими, на нём построено много библиотек компонентов

## Минусы
- HTML заполняется длинными списками классов
- Нужна сборка и настройка проекта
- Готовые компоненты Tailwind Plus платные

## Частые вопросы
### Tailwind CSS бесплатный?
Да, фреймворк бесплатный и с открытым кодом. Платный только набор компонентов Tailwind Plus: $299 разово.

### Работает ли Tailwind CSS в России?
Да, он ставится из npm без ограничений.

### Что лучше: Tailwind CSS или Bootstrap?
[[Bootstrap]] даёт готовые компоненты, [[Tailwind CSS]] — гибкие классы для своего дизайна. Для уникального интерфейса чаще берут Tailwind.

### Что такое Tailwind CSS?
Это CSS-фреймворк, где стили собираются из коротких классов вроде flex или p-4 прямо в разметке.
