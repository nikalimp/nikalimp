# Tailwind UI

Буква: T · Страница на сайте: `/tools/tailwind-ui`

## Описание

Tailwind UI — коллекция готовых компонентов и шаблонов на [[Tailwind CSS]] от создателей фреймворка. В 2025 году продукт переименовали в Tailwind Plus: в него входят более 500 блоков интерфейса, шаблоны сайтов и UI-кит Catalyst.

Главное отличие — качество дизайна и кода от авторов самого Tailwind. Блоки сделаны в едином стиле, адаптивны и копируются в проект без лишних зависимостей.

### Возможности
- **Более 500 UI-блоков:** секции лендингов, интерфейсы приложений, магазинов.
- **Код на HTML, [[React]] и [[Vue.js]]** с интерактивом на [[Headless UI]].
- **Шаблоны сайтов** на [[Next.js]] для лендингов, блогов и документации.
- **Catalyst** — UI-кит для приложений на React.
- **Обновления** под новые версии Tailwind CSS без доплаты.

### Кому подходит
Разработчикам и фрилансерам, которые часто собирают лендинги и интерфейсы на Tailwind и хотят экономить время на типовых блоках.

### Как начать
Купите лицензию, войдите в аккаунт и выберите нужный блок. Переключите формат кода на HTML, React или Vue, скопируйте его в проект и замените тексты и картинки.

### Совет
Используйте блоки как основу, а не финальный дизайн: поменяйте шрифты, цвета и отступы под бренд, иначе сайт будет похож на тысячи других.

### Ограничения
Цена заметная для разового проекта. Бесплатные альтернативы — [[shadcn ui|shadcn/ui]], [[Flowbite]] и [[DaisyUI]], готовые блоки для Figma и кода — [[Untitled UI]].

## Частые вопросы
### Сколько стоит Tailwind UI?
Сейчас продукт называется Tailwind Plus. Личная лицензия стоит $299, командная до 25 человек — $979, оплата разовая с пожизненными обновлениями.

### Работает ли Tailwind UI в России?
Сайт открывается без VPN, но оплатить лицензию российской картой нельзя. Купленные компоненты работают в любом проекте без ограничений.

### Tailwind UI или shadcn/ui?
[[shadcn ui|shadcn/ui]] бесплатный и даёт базовые компоненты для React-приложений. Tailwind UI платный, но в нём больше готовых секций лендингов и шаблонов сайтов.

### Чем Tailwind UI отличается от Tailwind CSS?
[[Tailwind CSS]] — бесплатный CSS-фреймворк с утилитарными классами. Tailwind UI — платная коллекция готовых блоков и шаблонов, сделанных на этом фреймворке.
