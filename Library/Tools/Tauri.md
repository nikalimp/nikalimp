## Описание

Tauri — это открытый фреймворк для создания десктопных и мобильных приложений на веб-технологиях: интерфейс пишется на HTML, CSS и JS, а системная часть — на Rust.

Главное отличие от [[Electron]] — размер и память: Tauri не встраивает браузер, а использует системный WebView, поэтому установщик весит единицы мегабайт, а не сотни.

### Возможности
- **Любой фронтенд:** [[React]], Vue, Svelte, [[Vite]] или чистый HTML.
- **Windows, macOS, Linux, iOS и Android** из одного проекта начиная с версии 2.
- **Rust-бэкенд** для работы с файлами, системой и производительных задач.
- **Безопасность:** разрешения на системные API задаются явно.
- **Плагины** для уведомлений, автообновления, файловой системы и трея.

### Кому подходит
Веб-разработчикам, которые хотят упаковать сайт или сервис в лёгкое настольное приложение. Хорошо подходит для утилит, внутренних инструментов и офлайн-клиентов.

### Как начать
Установите Rust и Node.js, выполните `npm create tauri-app@latest` и выберите фронтенд-шаблон. Команда `npm run tauri dev` откроет приложение в окне.

### Совет
Держите тяжёлую логику на Rust, а интерфейс — на фронтенде: вызовы команд через IPC дешёвые, а производительность растёт заметно.

### Ограничения
Системный WebView отличается на разных ОС, поэтому вёрстку нужно проверять на каждой. Для серьёзной доработки придётся учить Rust. Мобильная поддержка моложе десктопной.

## Вердикт
- Кому подходит: Веб-разработчикам, которым нужно лёгкое десктопное приложение на знакомом фронтенд-стеке.
- Кому не подходит: Тем, кому нужен одинаковый рендеринг на всех ОС без проверки или кто не хочет трогать Rust.
- Итог: Лёгкая и безопасная альтернатива Electron для десктопа и мобильных платформ.

## Частые вопросы
### Tauri бесплатный?
Да, это открытый проект под лицензиями MIT и Apache 2.0, можно использовать в коммерческих продуктах.

### Работает ли Tauri в России?
Да, фреймворк, документация и пакеты доступны без VPN.

### Tauri или Electron?
[[Electron]] встраивает Chromium и рендерит одинаково везде, но весит больше. Tauri легче и быстрее, но зависит от системного WebView.

### Можно ли сделать мобильное приложение на Tauri?
Да, начиная с версии 2 Tauri собирает приложения для iOS и Android.
