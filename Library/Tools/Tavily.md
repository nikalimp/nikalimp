## Описание

Tavily — это поисковый API для ИИ-агентов и LLM-приложений: он ищет в интернете и возвращает очищенный текст страниц, готовый для подачи в модель.

Главное отличие от классических поисковых API — ответ заточен под RAG и агентов: вместо списка ссылок приходит выжимка контента, источники и при желании готовый короткий ответ. Сервис развивается под брендом Tavily by Nebius.

### Возможности
- **Search** — поиск по вебу с выдачей очищенного контента и ссылок на источники.
- **Extract** — извлечение текста с указанных страниц.
- **Crawl и Map** — обход сайта и карта его страниц.
- **Интеграции** с [[LangChain]], LlamaIndex, [[n8n]] и MCP-сервер для ассистентов.
- **SDK** для Python и JavaScript.

### Кому подходит
Разработчикам ИИ-агентов, чат-ботов с доступом к интернету и исследовательских пайплайнов. Тем, кто собирает RAG без собственного парсера.

### Как начать
Зарегистрируйтесь, получите API-ключ и сделайте первый запрос через SDK. Бесплатных 1 000 кредитов хватает на прототип.

### Совет
Для агентов включайте режим basic: он дешевле advanced. Глубокий режим и Extract оставляйте для задач, где важна полнота. Для сбора целых сайтов сравните с [[Firecrawl]], для семантического поиска — с [[Exa]].

### Ограничения
Кредиты расходуются быстро на глубоком поиске и обходе сайтов. Платные тарифы требуют зарубежной карты. Для массового парсинга конкретных сайтов лучше подходят [[Apify]] или собственные скрейперы.

## Частые вопросы
### Tavily бесплатный?
Да, бесплатный план даёт 1 000 кредитов в месяц без привязки карты. Студентам и стартапам предлагают дополнительные кредиты.

### Работает ли Tavily в России?
API открывается из России, бесплатный план доступен. Для оплаты платных тарифов нужна зарубежная карта.

### Tavily или Exa?
Tavily удобнее как универсальный поиск для агентов с готовой выжимкой. [[Exa]] сильнее в семантическом поиске похожих страниц и исследований.

### Сколько стоит один запрос?
Базовый поиск расходует 1 кредит, продвинутый — 2. При оплате по факту кредит стоит $0,008.
