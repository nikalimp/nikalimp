## Описание

The SEO Framework — это бесплатный SEO-плагин для [[WordPress (инструмент)|WordPress]], который автоматически заполняет мета-теги, разметку и карту сайта без долгой настройки.

Главное отличие — минимализм: нет рекламы в админке, лишних модулей и нагрузки на сайт. Плагин генерирует title и description из контента сам, а вы правите только нужное.

### Возможности
- **Автоматические мета-теги** title и description по контенту страницы.
- **Разметка Schema.org** для сайта, хлебных крошек и организации.
- **XML-карта сайта** и правила индексации для разделов.
- **Open Graph и Twitter Cards** для соцсетей.
- **Цветовой индикатор** качества мета-тегов при редактировании.

### Кому подходит
Владельцам и разработчикам сайтов на WordPress, которым нужен быстрый и чистый SEO-плагин без маркетинговых баннеров. Альтернатива [[Yoast SEO]] и [[Rank Math]].

### Как начать
Установите плагин из каталога WordPress, откройте настройки и проверьте название сайта, разделитель в title и правила индексации. Затем пройдите ключевые страницы и поправьте описания.

### Совет
Не переписывайте мета-описания для всех страниц: оставьте автоматические для второстепенных и вручную пишите только для страниц услуг и главных статей.

### Ограничения
Нет анализа текста по ключевому слову, как у Yoast. Редиректы, локальное SEO и мониторинг вынесены в платные расширения или другие плагины вроде [[Redirection]].

## Частые вопросы
### The SEO Framework бесплатный?
Да, основной плагин бесплатный. Платные только дополнительные расширения.

### Работает ли The SEO Framework в России?
Да, плагин устанавливается из каталога WordPress и работает без ограничений.

### The SEO Framework или Yoast SEO?
[[Yoast SEO]] даёт анализ текста и много подсказок, но тяжелее и с рекламой. The SEO Framework легче и быстрее, но без анализа текста.

### Можно ли перейти на The SEO Framework с Yoast?
Да, плагин умеет переносить SEO-данные из других популярных плагинов.
