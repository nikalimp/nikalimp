# Things 3

## Описание

Things 3 — это личный менеджер задач для Mac, iPhone, iPad, Apple Watch и Vision Pro от студии Cultured Code. Он помогает планировать день, вести проекты и разбирать входящие задачи.

Главное отличие — продуманный минималистичный дизайн и разовая покупка вместо подписки. Приложение дважды получало Apple Design Award.

### Возможности
- **Входящие, Сегодня, Планы, Когда-нибудь** — простая структура по методике GTD.
- **Проекты и области** с заголовками, чек-листами и сроками.
- **Быстрый ввод** задачи из любого приложения сочетанием клавиш.
- **Things Cloud** синхронизирует задачи между устройствами бесплатно.
- **Календарь** показывает встречи рядом с задачами дня.
- **Shortcuts и URL-схема** для автоматизации.

### Кому подходит
Тем, кто работает только на технике Apple и ведёт личные задачи и проекты: фрилансерам, дизайнерам, предпринимателям.

### Как начать
Скачайте пробную версию для Mac, разберите все задачи во Входящие и раскидайте их по областям жизни: работа, клиенты, дом.

### Совет
Каждое утро тратьте пять минут на список «Сегодня»: переносите туда только то, что реально сделать. Остальное оставляйте в «Планах» с датой начала.

### Ограничения
Нет версий для Windows, Android и веба. Совместной работы нет: для команды берите [[Todoist]] или [[Яндекс Трекер]]. Покупка для каждого устройства отдельная.

## Частые вопросы
### Things 3 бесплатный?
Нет, приложение покупается разово для каждого устройства. На Mac есть бесплатная пробная версия.

### Работает ли Things 3 в России?
Да, приложение и синхронизация работают без VPN. Купить его можно через российский Apple ID с оплатой со счёта телефона.

### Things 3 или TickTick?
[[TickTick]] кроссплатформенный, с подпиской, таймером и привычками. Things 3 проще и красивее, но работает только на Apple.

### Есть ли в Things 3 совместная работа?
Нет, это личный менеджер задач. Поделиться можно только текстом списка.
