## Описание

Timeweb Cloud — облачная платформа российской компании Timeweb. В ней можно арендовать виртуальные серверы, базы данных, хранилище файлов, Kubernetes и развернуть приложение из репозитория.

Timeweb работает на рынке хостинга с 2006 года. Облачное направление выросло в одну из самых популярных платформ у российских разработчиков и фрилансеров.

### Возможности
- **Облачные серверы (VPS)** с почасовой оплатой.
- **Управляемые базы данных:** PostgreSQL, MySQL, Redis и другие.
- **S3-хранилище** для файлов и бэкапов.
- **Apps** — деплой фронтенда и бэкенда прямо из GitHub.
- **Kubernetes** для сложных проектов.
- **Готовые образы:** WordPress, n8n, Docker и другие приложения в один клик.
- **Дата-центры** в России и других странах.

### Кому подходит
Разработчикам, фрилансерам и небольшим компаниям, которым нужен сервер для сайта, бота, n8n или веб-сервиса с оплатой в рублях. Удобно как замена зарубежным облакам для российских проектов.

### Как начать
Зарегистрируйтесь, пополните баланс и создайте сервер с нужной ОС или готовым приложением. Для статического сайта на Next.js можно использовать Apps или S3 с раздачей файлов.

### Совет
Включите автоматические бэкапы сервера. Они стоят недорого, а восстановление после ошибки или взлома занимает минуты вместо дней.

### Обычный хостинг
Для сайтов на WordPress, Битриксе или статических страниц у компании есть виртуальный хостинг Timeweb с панелью управления — проще, чем настраивать сервер самому.

### Партнёрская программа
Timeweb платит партнёрам процент с оплат приведённых клиентов — удобно для фрилансеров, которые размещают сайты клиентов.

### Частый вопрос
**Timeweb Cloud или Selectel?** [[Selectel]] ориентирован на средний и крупный бизнес, Timeweb Cloud проще и дешевле на старте. Также смотрите [[Beget]] и [[Yandex Cloud]].

## Частые вопросы
### Сколько стоит Timeweb Cloud?
Оплата почасовая, по фактическому использованию. Сервер Ultra с 1 ГБ памяти стоит от 1 920 ₽ в месяц, другие конфигурации и цены смотрите в калькуляторе на сайте.

### Работает ли Timeweb Cloud в России?
Да, это российский провайдер: оплата в рублях, дата-центры в России. Есть и зарубежные локации.

### Что лучше: Timeweb Cloud или Selectel?
Оба — российские облака с почасовой оплатой. Timeweb Cloud проще для новичков, Selectel — шире по набору услуг для крупных проектов.

### Чем Timeweb Cloud отличается от хостинга Timeweb?
Облако — это серверы под ваш контроль, где вы сами ставите ПО. Обычный хостинг проще: готовая панель и PHP, без администрирования сервера.
