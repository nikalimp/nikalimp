Буква: T · Страница на сайте: `/tools/treo`

## Описание

Treo — это сервис мониторинга скорости сайтов: собирает данные Core Web Vitals реальных пользователей из Chrome UX Report и регулярно прогоняет Lighthouse по выбранным страницам.

Главное отличие — Treo показывает и полевые данные Google, и лабораторные замеры на одной панели, по сотням сайтов сразу, с историей до пяти лет.

### Возможности
- **Site Speed Report** — бесплатный отчёт по любому домену на данных [[Chrome UX Report]]: LCP, INP, CLS по странам и устройствам.
- **Мониторинг Lighthouse** — регулярные проверки страниц из разных регионов с уведомлениями о просадках.
- **Сканирование sitemap** — проверка скорости всех страниц из карты сайта.
- **Сравнение с конкурентами** на тех же метриках.
- **API** на тарифах Pro и Scale.

### Кому подходит
SEO-специалистам, веб-студиям и командам интернет-магазинов, которые следят за Core Web Vitals десятков сайтов и хотят видеть регрессии до падения позиций.

### Как начать
Откройте treo.sh/sitespeed и введите домен — получите отчёт без регистрации. Для мониторинга заведите бесплатный аккаунт и добавьте до 5 сайтов.

### Совет
Сравнивайте полевые данные с лабораторными: если Lighthouse зелёный, а CrUX красный, проблема у реальных пользователей — медленные устройства или сторонние скрипты.

### Ограничения
CrUX есть только у сайтов с заметным трафиком из Chrome. Lighthouse-мониторинг доступен лишь на платных тарифах. Разовую проверку проще сделать в [[Google PageSpeed Insights]].

## Частые вопросы
### Treo бесплатный?
Да, есть бесплатный план на 5 сайтов с данными CrUX и бесплатный отчёт Site Speed по любому домену.

### Работает ли Treo в России?
Сайт работает без VPN. Оплатить платный тариф можно только зарубежной картой.

### Treo или DebugBear?
Оба мониторят Core Web Vitals. [[DebugBear]] глубже в отладке отдельных страниц, Treo удобнее для обзора сотен сайтов и бесплатного отчёта по CrUX.

### Откуда Treo берёт данные?
Полевые данные — из Chrome UX Report Google, лабораторные — из собственных прогонов Lighthouse.
