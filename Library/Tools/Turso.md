## Описание

Turso — это облачная база данных на основе [[SQLite]]: каждый проект получает быструю базу с репликами рядом с пользователями, а работают с ней обычным SQL.

Главное отличие — модель «база на пользователя»: можно создать тысячи маленьких баз, например отдельную для каждого клиента SaaS, и не платить за каждую отдельно.

### Возможности
- **libSQL** — открытый форк SQLite с сетевым доступом и репликацией.
- **Встроенные реплики** — копия базы прямо в приложении для чтения без задержек.
- **Тысячи баз** в одном аккаунте для изоляции данных клиентов.
- **Векторный поиск** в самой SQLite для AI-приложений.
- **SDK** для TypeScript, Python, Go, Rust и интеграция с [[Drizzle ORM]] и [[Prisma]].

### Кому подходит
Разработчикам веб-приложений и SaaS, которым нужна быстрая недорогая база без администрирования, особенно на edge-платформах вроде [[Cloudflare Workers]] и [[Vercel]].

### Как начать
Установите Turso CLI, выполните `turso db create` и получите строку подключения. Подключите базу через SDK или ORM.

### Совет
Для небольших проектов храните сессии и контент в Turso, а тяжёлую аналитику держите отдельно: SQLite хорошо читает и хуже справляется с массовой параллельной записью.

### Ограничения
На бесплатном плане при превышении лимитов базы блокируются до перехода на платный тариф. Сложные транзакционные нагрузки удобнее вести в Postgres, например в [[Neon]].

## Частые вопросы
### Turso бесплатный?
Да, бесплатный план даёт 5 ГБ и 500 млн чтений строк в месяц. Платные тарифы начинаются с $5,99.

### Работает ли Turso в России?
Сервис доступен, бесплатный план работает. Для платного тарифа нужна зарубежная карта.

### Turso или Supabase?
Supabase построен на Postgres и включает авторизацию и хранилище файлов. Turso — только база на SQLite, зато быстрее на чтение с edge и дешевле.

### Что такое libSQL?
Открытый форк SQLite, на котором работает Turso. Он добавляет сетевой доступ, репликацию и векторный поиск.
