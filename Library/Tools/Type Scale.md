## Описание

Type Scale — это бесплатный онлайн-калькулятор типографической шкалы: вы задаёте базовый размер шрифта и коэффициент, а сервис рассчитывает размеры заголовков и показывает их на живом примере.

Главное отличие — мгновенный визуальный предпросмотр: шкала сразу видна на тексте со шрифтом из [[Google Fonts]], а готовый CSS копируется одной кнопкой.

### Возможности
- **Модульные коэффициенты** — малая терция, большая терция, кварта, золотое сечение и другие.
- **Базовый размер** в пикселях с пересчётом в rem.
- **Предпросмотр** с любым шрифтом из Google Fonts и своим текстом.
- **Экспорт CSS** — готовые размеры для h1–h6 и body.

### Кому подходит
Веб-дизайнерам и верстальщикам, которые собирают дизайн-систему или стили для нового сайта и хотят выбрать размеры заголовков по правилу, а не на глаз.

### Как пользоваться
Укажите базовый размер, например 16 px, и выберите коэффициент. Посмотрите предпросмотр, подберите шрифт и скопируйте CSS в проект или перенесите размеры в стили [[Figma]].

### Совет
Для мобильной и десктопной версии берите разные коэффициенты: на маленьком экране 1,2, на большом 1,333. Плавный переход между ними удобно рассчитать в [[Utopia]].

### Ограничения
Сервис считает только размеры: межстрочный интервал, ширину строки и адаптивность придётся настроить самостоятельно. Кириллицы в предпросмотре может не быть, если выбранный шрифт её не поддерживает.

## Частые вопросы
### Type Scale бесплатный?
Да, сервис полностью бесплатный и работает без регистрации.

### Работает ли Type Scale в России?
Да, сайт открывается без VPN.

### Type Scale или Utopia?
Type Scale считает одну статичную шкалу. [[Utopia]] строит плавную шкалу, которая меняется между мобильным и десктопным размером через CSS clamp.

### Какой коэффициент выбрать для сайта?
Для текстовых сайтов и интерфейсов — 1,2–1,25, для лендингов с крупными заголовками — 1,333–1,5.
