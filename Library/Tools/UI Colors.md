# UI Colors

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Цвет и контраст · Global
Буква: U · Страница на сайте: `/tools/ui-colors`

## Описание

UI Colors — это генератор цветовых шкал для Tailwind CSS: из одного HEX-кода он строит палитру из 11 оттенков от 50 до 950 и отдаёт готовый конфиг.

Главное отличие — шкала собирается так, чтобы оттенки выглядели ровно и подходили для интерфейса, а не просто осветляли и затемняли исходный цвет.

### Возможности
- **Шкала 50–950** из одного цвета бренда.
- **Экспорт** в конфиг Tailwind, CSS-переменные, SCSS и другие форматы.
- **Ручная доводка** оттенка, насыщенности и светлоты отдельных шагов.
- **Предпросмотр** палитры на примерах интерфейса.
- **Плагин для Figma** — палитра сразу в стилях макета.

### Кому подходит
Дизайнерам и фронтенд-разработчикам, которые собирают дизайн-систему на Tailwind или [[shadcn ui|shadcn/ui]] и хотят получить брендовую шкалу за минуту.

### Как пользоваться
Вставьте HEX-код фирменного цвета, проверьте шкалу на примерах и скопируйте конфиг в `tailwind.config` или CSS-переменные.

### Совет
После генерации проверьте контраст пар «текст — фон» в [[WebAIM Contrast Checker]]: красивая шкала ещё не гарантирует читаемость кнопок и ссылок.

### Ограничения
Сервис строит шкалу для одного цвета, а полную систему с нейтральными и семантическими цветами придётся собрать вручную. Для доступных палитр с расчётом контраста посмотрите [[Radix Colors]] и [[Tints.dev]].

## Частые вопросы
### UI Colors бесплатный?
Да, генерация шкал и экспорт в код бесплатны.

### Работает ли UI Colors в России?
Да, сайт открывается без VPN.

### UI Colors или Tints.dev?
Оба строят шкалы для Tailwind. [[Tints.dev]] даёт больше ручного контроля по каждому шагу, UI Colors быстрее и нагляднее показывает палитру на интерфейсе.

### Как добавить палитру в shadcn/ui?
Скопируйте оттенки в CSS-переменные темы и назначьте их ролям: primary, accent, ring.
