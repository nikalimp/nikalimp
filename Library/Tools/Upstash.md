## Описание

Upstash — это бессерверные базы данных с оплатой за запросы: прежде всего Redis, а также векторная база, очереди QStash и инструменты для AI-приложений.

Главное отличие — модель без серверов: вы не платите за простаивающий инстанс, а подключаетесь по HTTP, поэтому Upstash работает даже там, где нет постоянных соединений, — на [[Vercel]] и [[Cloudflare Workers]].

### Возможности
- **Redis** — кэш, сессии, очереди и счётчики с REST API и глобальной репликацией.
- **Rate limiting** — готовая библиотека ограничения запросов для API.
- **QStash** — очередь сообщений и отложенные задачи через HTTP.
- **Vector** — векторная база для поиска и RAG.
- **Workflow** — долгие процессы с повторами поверх QStash.

### Кому подходит
Разработчикам на Next.js и edge-платформах, которым нужен кэш, ограничение запросов или очередь без собственного сервера.

### Как начать
Создайте базу Redis в консоли, скопируйте REST URL и токен и подключите SDK `@upstash/redis`. Первый запрос можно сделать за пять минут.

### Совет
Ограничьте частоту запросов к форме заявки и API через `@upstash/ratelimit`: это несколько строк кода, а спам и злоупотребления заметно сократятся.

### Ограничения
При постоянной высокой нагрузке оплата за команды обходится дороже своего [[Redis]]. Задержка по HTTP выше, чем у локального Redis. Хранилища в России нет.

## Частые вопросы
### Upstash бесплатный?
Да, бесплатный план даёт 500 тыс. команд Redis в месяц и 250 МБ данных.

### Работает ли Upstash в России?
Бесплатный план работает, платные тарифы оплачиваются зарубежной картой.

### Upstash или свой Redis?
Свой [[Redis]] дешевле при постоянной нагрузке, но его нужно администрировать. Upstash выгоден при неравномерной нагрузке и на serverless-платформах.

### Для чего Upstash в Next.js?
Для кэша, сессий, ограничения запросов к API и очередей фоновых задач через QStash.
