## Описание

UptimeRobot — сервис мониторинга доступности сайтов, API и серверов. Он проверяет адрес по расписанию и присылает уведомление, если сайт упал или SSL-сертификат скоро истечёт.

Главное отличие — щедрый бесплатный план: 50 мониторов, в том числе для коммерческих проектов.

### Возможности
- **Типы проверок:** HTTP(S), ключевое слово на странице, ping, порт, heartbeat для cron-задач.
- **Сроки SSL и домена:** предупреждение до истечения.
- **Уведомления** на почту, в SMS, [[Telegram (инструмент)|Telegram]], [[Slack]], через вебхуки.
- **Публичные страницы статуса** для клиентов.
- **API** для управления мониторами из кода.

### Кому подходит
Фрилансерам и студиям, которые ведут сайты клиентов, владельцам интернет-магазинов и небольшим SaaS.

### Как начать
Зарегистрируйтесь, добавьте монитор HTTP(S) с адресом сайта, подключите уведомления в [[Telegram (инструмент)|Telegram]]. Для важных страниц добавьте проверку ключевого слова: так вы узнаете о белом экране вместо сайта.

### Совет
Заведите отдельный монитор на форму заявки или API оплаты: главная может открываться, а заказы — не проходить. Для клиентов сделайте страницу статуса на своём поддомене.

### Ограничения
На бесплатном плане интервал — 5 минут, короткие падения можно пропустить. Глубокой диагностики ошибок нет: для неё нужен [[Sentry]] или [[Better Stack]].

## Частые вопросы
### UptimeRobot бесплатный?
Да, бесплатный план включает 50 мониторов с интервалом 5 минут и подходит для коммерческих проектов.

### Работает ли UptimeRobot в России?
Да, сервис открывается без VPN и проверяет российские сайты. Платные тарифы оплачиваются только зарубежной картой.

### Чем заменить UptimeRobot?
Российский аналог — [[Host-tracker]]. Для мониторинга с логами и инцидентами подойдёт [[Better Stack]].

### Как получать уведомления UptimeRobot в Telegram?
В разделе Integrations добавьте Telegram, запустите бота и привяжите его к нужным мониторам.
