## Описание

UserTesting — платформа для удалённых юзабилити-тестов и интервью с пользователями. Вы задаёте сценарий, а участники из панели сервиса выполняют задания и записывают экран и голос.

Главное отличие — собственная большая панель респондентов: результаты приходят за часы, без самостоятельного рекрутинга.

### Возможности
- **Неуправляемые тесты:** участники проходят сценарий и комментируют вслух.
- **Интервью** в реальном времени с записью.
- **Тесты прототипов** из [[Figma]], сайтов и мобильных приложений.
- **Таргетинг** по демографии, профессии и другим критериям.
- **AI-анализ:** выделение тем, саммари и хайлайты видео.

### Кому подходит
Крупным продуктовым и UX-командам, которые постоянно тестируют решения на западной аудитории.

### Как пользоваться
Сформулируйте 3–5 задач, выберите аудиторию, запустите тест на 5–8 участников. Смотрите записи и отмечайте проблемы, которые повторяются.

### Совет
Пишите задачи как жизненную ситуацию, а не инструкцию: «Найдите тариф для команды из пяти человек», а не «Нажмите „Цены“». Перед запуском пройдите тест сами и проверьте, что задачи понятны без подсказок.

### Ограничения
Дорого для малого бизнеса и почти недоступно из России. Для русскоязычной аудитории дешевле провести интервью самим, а для быстрых тестов прототипов взять [[Maze]]. Результаты удобно хранить в [[Dovetail]].

## Вердикт
- Кому подходит: Крупным UX-командам с бюджетом и западной аудиторией.
- Кому не подходит: Фрилансерам, малому бизнесу и проектам для русскоязычных пользователей.
- Итог: Лидер рынка удалённых юзабилити-тестов с большой панелью, но дорогой и закрытый для России.

## Плюсы

- Тесты сайтов, приложений и прототипов
- AI-анализ записей

## Частые вопросы
### Сколько стоит UserTesting?
Цены не публикуются, их называют после демо. Годовые контракты обычно стоят десятки тысяч долларов.

### Работает ли UserTesting в России?
Напрямую нет: нужен договор через зарубежную компанию, а участников из России в панели почти нет.

### Чем заменить UserTesting?
Для тестов прототипов подойдёт [[Maze]], для анализа интервью — [[Dovetail]]. Для российской аудитории проще набрать участников самостоятельно.

### Сколько участников нужно для юзабилити-теста?
Для поиска основных проблем обычно хватает 5–8 человек на один сегмент аудитории.
