# Utopia

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Шрифты и типографика · Global
Буква: U · Страница на сайте: `/tools/utopia`

## Описание

Utopia — это бесплатный набор калькуляторов для fluid-типографики и отступов: он генерирует CSS с clamp(), чтобы размеры плавно менялись между мобильным и десктопом.

Главное отличие — метод вместо брейкпоинтов. Вы задаёте шкалу для минимальной и максимальной ширины экрана, а Utopia считает промежуточные значения сама.

### Возможности
- **Калькулятор шрифтовой шкалы**: базовый размер и коэффициент для двух крайних ширин экрана.
- **Калькулятор отступов**: шаги от 3XS до 3XL и пары вроде «S → L» для адаптивных отступов.
- **Калькулятор clamp()** для любого отдельного значения.
- **Готовый CSS** с кастомными свойствами, который можно вставить в проект или перенести в [[Tailwind CSS]].
- **Плагины для Figma**, чтобы дизайн и код жили на одной шкале.

### Кому подходит
Дизайнерам и фронтенд-разработчикам, которые собирают дизайн-систему и устали от наборов размеров под каждый брейкпоинт.

### Как начать
Задайте минимальную ширину 360 px и максимальную 1240 px, выберите базовый кегль и коэффициент шкалы, скопируйте CSS в глобальные стили.

### Совет
Держите шкалу шрифтов и шкалу отступов на одних и тех же крайних ширинах. Тогда типографика и сетка растягиваются синхронно, и макет не разваливается на промежуточных экранах.

### Ограничения
Utopia не подбирает шрифты и пары. Для этого есть [[Fontjoy]] и [[Google Fonts]], а простую статичную шкалу удобнее считать в [[Type Scale]].

## Частые вопросы
### Utopia бесплатный?
Да, все калькуляторы бесплатные и не требуют регистрации. Код открыт на GitHub.

### Работает ли Utopia в России?
Да, сайт открывается без VPN, оплата не нужна.

### Utopia или Type Scale?
[[Type Scale]] считает одну статичную шкалу, Utopia — две шкалы для узкого и широкого экрана и плавный переход между ними через clamp().

### Как подключить шкалу Utopia к Tailwind?
Скопируйте сгенерированные переменные в глобальный CSS и сошлитесь на них в конфиге [[Tailwind CSS]] вместо стандартных размеров.
