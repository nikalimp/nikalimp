## Описание

Visual Studio Code (VS Code) — бесплатный редактор кода от Microsoft. Он лёгкий, работает на Windows, macOS и Linux и расширяется тысячами плагинов под любые языки и задачи.

VS Code вышел в 2015 году и за несколько лет стал самым популярным редактором у разработчиков. На его основе сделаны AI-редакторы вроде Cursor и Windsurf.

### Возможности
- **Подсветка и автодополнение** для десятков языков.
- **Встроенный терминал** и Git.
- **Отладчик** для JavaScript, Python и других языков.
- **Маркетплейс расширений:** линтеры, форматтеры, темы, интеграции.
- **Удалённая разработка** на сервере, в контейнере или в WSL.
- **AI-помощники:** GitHub Copilot и другие.
- **Синхронизация настроек** между устройствами.

### Кому подходит
Разработчикам любого уровня, верстальщикам, аналитикам данных, а также дизайнерам и маркетологам, которые правят код сайтов, Markdown-файлы и конфиги.

### Полезные расширения
- Prettier — автоформатирование кода.
- ESLint — поиск ошибок в JavaScript и TypeScript.
- Tailwind CSS IntelliSense — подсказки классов.
- GitLens — история изменений строк.
- Markdown-превью для документации.

### Как начать
Установите редактор, откройте папку проекта и поставьте расширения для вашего стека. Включите форматирование при сохранении — это избавит от споров о стиле кода.

### Совет
Выучите командную палитру (Cmd/Ctrl + Shift + P) и быстрый переход к файлу (Cmd/Ctrl + P). Эти два сочетания экономят больше времени, чем любые плагины.

### Частый вопрос
**VS Code или Cursor?** [[Cursor]] — это VS Code с глубоко встроенным AI-агентом. Если AI нужен как помощник, хватит VS Code с [[GitHub Copilot]]. Если хотите поручать агенту целые задачи — попробуйте Cursor. Код храните на [[GitHub]].

## Частые вопросы
### VS Code бесплатный?
Да, редактор Visual Studio Code бесплатный, в том числе для коммерческой работы. Платными бывают только отдельные расширения, например AI-помощники.

### Работает ли VS Code в России?
Подтвердить доступ из России официальным источником не удалось. Редактор ставится как обычная программа, а расширения подгружаются из каталога расширений Microsoft.

### Что лучше: VS Code или WebStorm?
VS Code бесплатный и гибкий за счёт расширений, [[WebStorm]] платный, зато из коробки умнее работает с JavaScript и рефакторингом. Для большинства задач хватает VS Code.

### Можно ли использовать VS Code с AI?
Да, через расширения вроде [[GitHub Copilot]], [[Cline]] и [[Continue]]. Есть и отдельные форки редактора с AI, например [[Cursor]].
