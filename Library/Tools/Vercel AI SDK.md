# Vercel AI SDK

Буква: V · Страница на сайте: `/tools/vercel-ai-sdk`

## Описание

Vercel AI SDK — открытая TypeScript-библиотека для работы с языковыми моделями в веб-приложениях. Через один API она подключает OpenAI, Anthropic, Google и других провайдеров, стримит ответы и вызывает инструменты.

Главное отличие — единый интерфейс и готовые хуки для фронтенда: смена модели — это одна строка, а чат на [[React]] собирается за час.

### Возможности
- **Единый API** для десятков провайдеров: [[OpenAI API]], [[Anthropic API]], Google, Mistral, локальные модели.
- **Стриминг** текста и структурированных объектов по схеме.
- **Вызов инструментов** и многошаговые агенты.
- **UI-хуки** для React, Vue и Svelte: чат, автодополнение.
- **Работа на сервере и в edge-функциях**, интеграция с [[Next.js]].

### Кому подходит
Фронтенд- и фулстек-разработчикам на TypeScript, которые встраивают AI-чат, генерацию или агентов в свой продукт.

### Как начать
Установите пакет `ai` и провайдера, например `@ai-sdk/openai`. Вызовите `generateText` или `streamText` на сервере, а на клиенте подключите хук `useChat`.

### Совет
Из России подключайте модели через [[OpenRouter]] или российские API по OpenAI-совместимому протоколу: так код не зависит от VPN на сервере.

### Ограничения
Только TypeScript и JavaScript. Сложные графы агентов с памятью удобнее строить в [[LangChain]]. Библиотека часто меняет API между мажорными версиями.

## Частые вопросы
### Vercel AI SDK бесплатный?
Да, библиотека открытая и бесплатная. Платить нужно только за токены у провайдера моделей.

### Работает ли Vercel AI SDK в России?
Сама библиотека — да. Но зарубежные модели из России доступны через VPN, прокси или агрегаторы вроде [[OpenRouter]].

### Vercel AI SDK или LangChain?
AI SDK проще и лучше для фронтенда на TypeScript. [[LangChain]] богаче для сложных цепочек, RAG и Python.

### Нужен ли Vercel для AI SDK?
Нет, библиотека работает на любом хостинге с Node.js, Bun или edge-функциями.
