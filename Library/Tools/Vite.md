## Описание

Vite — инструмент сборки и сервер разработки для фронтенд-проектов. Он запускает проект мгновенно и обновляет страницу при изменениях за доли секунды, а для продакшена собирает оптимизированные файлы.

Vite создал Эван Ю, автор Vue.js, в 2020 году. Сегодня Vite стал стандартом сборки для React, Vue, Svelte и других фреймворков, а также основой многих AI-генераторов приложений.

### Возможности
- **Мгновенный запуск** сервера разработки.
- **Горячая перезагрузка модулей** без потери состояния.
- **Поддержка TypeScript, JSX, CSS-модулей** из коробки.
- **Оптимизированная сборка** для продакшена.
- **Плагины** для фреймворков и инструментов.
- **Шаблоны** проектов для React, Vue, Svelte, Solid и других.

### Кому подходит
Фронтенд-разработчикам, которые создают одностраничные приложения, библиотеки и интерактивные интерфейсы.

### Как начать
Создайте проект командой `npm create vite@latest`, выберите фреймворк и запустите сервер разработки.

### Как использовать в работе
Используйте Vite для внутренних инструментов и прототипов: настройка занимает минуты, а сборка — статические файлы для любого хостинга.

### Где особенно полезен
В одностраничных приложениях и дашбордах, где не нужен серверный рендеринг.

### Совет
Для публичных сайтов с SEO выбирайте фреймворки с генерацией страниц — Next.js, Nuxt, Astro, — они тоже работают на основе современных сборщиков.

### Ограничения
Vite — сборщик, а не фреймворк: маршрутизацию, рендеринг на сервере и данные нужно добавлять отдельно.

### Кому не подойдёт
Контентным сайтам, которым важно SEO и быстрая индексация: им нужен фреймворк с готовыми HTML-страницами.

### Частый вопрос
**Vite или Next.js?** [[Next.js]] — полноценный фреймворк для сайтов с SEO, Vite — быстрый сборщик для приложений. Код на Vite генерируют [[Lovable]] и [[Bolt.new]], разрабатывают в [[VS Code]].

## Вердикт
- Кому подходит: Фронтенд-разработчикам, которым нужен быстрый сборщик и сервер разработки для сайтов на React, Vue, Svelte.
- Кому не подходит: Тем, кто делает сайты на конструкторах вроде Tilda: сборщик им не нужен.
- Итог: Vite запускает проект за секунды и собирает его для продакшена; это сейчас стандартный выбор для новых проектов.

## Частые вопросы
### Vite бесплатный?
Да, Vite бесплатный и с открытым кодом по лицензии MIT.

### Работает ли Vite в России?
Да, он ставится из npm и работает локально, без регистрации.

### Что лучше: Vite или Next.js?
Это разные задачи. [[Next.js]] — полноценный фреймворк с сервером, Vite — сборщик, на нём строят свои проекты.

### Какая версия Node.js нужна для Vite?
Нужна Node.js 20.19+ или 22.12+, некоторые шаблоны требуют более новую версию.
