## Описание

Vue.js — прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов. Его можно подключить к одной странице, как библиотеку, или использовать для полноценного одностраничного приложения.

Vue создал Эван Ю, бывший разработчик Google, в 2014 году. Фреймворк популярен благодаря понятному синтаксису и мягкому порогу входа, особенно в Азии и Европе.

### Ключевые идеи
- **Однофайловые компоненты:** шаблон, логика и стили в одном файле.
- **Реактивность:** интерфейс обновляется при изменении данных.
- **Composition API** для организации логики.
- **Директивы** в шаблонах: условия, циклы, события.

### Экосистема
- **Nuxt** — фреймворк для сайтов и приложений с серверным рендерингом.
- **Pinia** — управление состоянием.
- **Vue Router** — маршрутизация.
- **Vite** — сборщик от того же автора.

### Кому подходит
Фронтенд-разработчикам, командам, которые ценят простоту и читаемость кода, и проектам, где фреймворк внедряется постепенно в существующий сайт.

### Как начать
Создайте проект командой `npm create vue@latest`, изучите официальный учебник и соберите простое приложение со списком и формой.

### Как использовать в работе
Подключите Vue к отдельным виджетам существующего сайта — калькулятору, фильтру каталога, — не переписывая весь проект.

### Где особенно полезен
В админках и внутренних интерфейсах, где важны скорость разработки и понятный код.

### Совет
Для публичных сайтов используйте Nuxt с серверным рендерингом: страницы, которые рендерятся только в браузере, хуже индексируются.

### Ограничения
Экосистема и рынок вакансий меньше, чем у React.

### Кому не подойдёт
Проектам, где команда уже работает на React.

### Частый вопрос
**Vue или React?** [[React]] популярнее и у него больше библиотек, Vue проще для старта. Сборщик для обоих — [[Vite]]. Визуальный конструктор на Vue — [[WeWeb]].

## Частые вопросы
### Vue.js бесплатный?
Да, Vue.js бесплатный и распространяется с открытым кодом по лицензии MIT. Платить нужно только за хостинг готового проекта.

### Работает ли Vue.js в России?
Да, фреймворк ставится через npm без ограничений. Документация доступна и на русском.

### Что лучше: Vue или React?
[[React]] популярнее и даёт больше вакансий, Vue проще на старте и приходит с официальными библиотеками для роутинга и состояния. Для небольших команд и быстрых проектов часто хватает Vue.

### Что такое Nuxt и нужен ли он для Vue?
[[Nuxt]] — надстройка над Vue для сайтов с серверным рендерингом и маршрутами. Для SEO-страниц его обычно берут, для небольшого виджета хватит чистого Vue.
