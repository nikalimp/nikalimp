# WAVE

[[Инструменты — UI UX дизайн|UI/UX дизайн]] · Доступность (a11y) · Global
Буква: W · Страница на сайте: `/tools/wave`

## Описание

WAVE — бесплатный инструмент автоматической проверки доступности веб-страниц от некоммерческой организации WebAIM. Он показывает ошибки прямо поверх страницы: значками рядом с проблемными элементами.

Главное отличие — наглядность: видно не только список ошибок, но и где именно на странице они находятся.

### Возможности
- **Ошибки доступности:** нет alt-текста, пустые ссылки и кнопки, формы без подписей.
- **Контраст** текста по требованиям WCAG.
- **Структура:** заголовки, ориентиры, порядок чтения.
- **ARIA-разметка** и её проверка.
- **Расширения** для Chrome, Firefox и Edge для закрытых и локальных страниц.

### Кому подходит
Дизайнерам, фронтенд-разработчикам и SEO-специалистам, которые хотят быстро найти очевидные проблемы доступности.

### Как пользоваться
Установите расширение, откройте страницу и нажмите на значок WAVE. Сначала исправьте красные ошибки, затем проверьте вкладку контраста и структуру заголовков.

### Совет
Прогоняйте WAVE на шаблонах, а не на каждой странице: главная, карточка, статья, форма. Ошибки обычно повторяются по шаблону, и одно исправление в компоненте закрывает их на сотнях страниц.

### Ограничения
Автоматика находит только часть проблем. Клавиатурную навигацию и работу программ экранного доступа проверяйте вручную в [[VoiceOver]] или [[NVDA]]. Для проверки в CI удобнее [[axe DevTools]].

## Карточка
- Россия: работает
- Русский язык: нет
- Бесплатный план: есть
- Платформы: Веб, Расширение браузера, API

## Вердикт
- Кому подходит: Всем, кто делает сайты и хочет бесплатно проверить базовую доступность.
- Кому не подходит: Тем, кому нужен полный аудит доступности без ручной проверки.
- Итог: Лучший бесплатный старт для проверки доступности: наглядно и без настройки.

## Плюсы
- Бесплатно, без регистрации
- Ошибки видны прямо на странице
- Работает на локальных и закрытых страницах через расширение
- Проверяет контраст и структуру

## Минусы
- Находит только автоматически определяемые ошибки
- Интерфейс только на английском
- API платное

## Частые вопросы
### WAVE бесплатный?
Да, веб-версия и расширения бесплатны. Платное только API для пакетных проверок.

### Работает ли WAVE в России?
Да, сайт и расширения работают без VPN.

### WAVE или axe DevTools?
WAVE нагляднее для дизайнеров, [[axe DevTools]] — для разработчиков и автоматических тестов. Лучше использовать оба.

### Достаточно ли WAVE для соответствия WCAG?
Нет. WAVE находит часть ошибок, остальное проверяется вручную с клавиатурой и программой экранного доступа.
