# Wagtail

Буква: W · Страница на сайте: `/tools/wagtail`

## Описание

Wagtail — это бесплатная CMS с открытым кодом на Python и [[Django]]: разработчик описывает типы страниц в коде, а редакторы получают удобную админку для контента.

Главное отличие — StreamField. Редактор собирает страницу из блоков, которые заранее определил разработчик: текст, цитата, галерея, видео, карточки.

### Возможности
- **Типы страниц как модели Django** с любыми полями.
- **StreamField** — гибкие блоки контента без визуального хаоса.
- **Изображения с фокусной точкой** и автоматические рендишены.
- **Ревизии, черновики и модерация** публикаций.
- **Мультисайт, локализация** и REST API для headless-режима.

### Кому подходит
Командам на Python, которым нужен сайт с контентом и собственной бизнес-логикой: медиа, университеты, госорганизации, корпоративные порталы.

### Как начать
Установите пакет wagtail, выполните wagtail start, опишите первую модель страницы и откройте админку на /admin.

### Совет
Не делайте один «универсальный» тип страницы со всеми блоками. Заведите отдельные модели под разные задачи: так редакторы не ломают дизайн, а шаблоны остаются простыми.

### Ограничения
Нужен Python-разработчик и сервер, конструктора сайтов здесь нет. Для блога без разработки проще [[Ghost]] или [[WordPress (инструмент)|WordPress]], для headless на JavaScript — [[Strapi]] или [[Payload CMS]].

## Частые вопросы
### Wagtail бесплатный?
Да, это проект с открытым кодом под BSD. Платить нужно только за сервер и разработку.

### Работает ли Wagtail в России?
Да, пакеты ставятся из PyPI, а сайт можно развернуть на российском хостинге без ограничений.

### Wagtail или WordPress?
[[WordPress (инструмент)|WordPress]] проще для типового сайта с темами и плагинами. Wagtail выбирают, когда нужна своя логика на Django и аккуратная структура контента.

### Можно ли использовать Wagtail как headless CMS?
Да, у Wagtail есть встроенный API, и фронтенд можно сделать на [[Next.js]] или другом фреймворке.
