# Wakamai Fondue

Буква: W · Страница на сайте: `/tools/wakamai-fondue`

## Описание

Wakamai Fondue — это бесплатный сервис, который показывает, что умеет шрифт: перетащите файл в браузер и увидите OpenType-функции, набор символов, языки и оси вариативности.

Название читается как «What can my font do?». Автор — нидерландский разработчик Роэл Ниускенс, код открыт.

### Возможности
- **OpenType-функции**: лигатуры, альтернативы, табличные цифры, капитель с живым превью.
- **Набор символов** и поддерживаемые языки, включая кириллицу.
- **Вариативные оси** с ползунками для каждой оси.
- **Готовый CSS** для включения нужных функций через font-feature-settings и font-variation-settings.
- **Метаданные**: формат, число глифов, размер файла.

### Кому подходит
Дизайнерам и верстальщикам, которые подключают шрифт на сайт и хотят использовать его возможности, а не только начертания.

### Как начать
Откройте сайт, перетащите файл TTF, OTF, WOFF или WOFF2 и пролистайте отчёт. Нужные функции скопируйте в CSS.

### Совет
Перед покупкой шрифта для русскоязычного сайта проверьте в Wakamai Fondue кириллицу и табличные цифры. Это сэкономит время на поиске замены после запуска.

### Ограничения
Сервис не подбирает и не распознаёт шрифты. Для поиска по картинке нужен [[WhatTheFont]], для подбора пар — [[Fontjoy]], для каталога бесплатных шрифтов — [[Google Fonts]].

## Частые вопросы
### Wakamai Fondue бесплатный?
Да, полностью бесплатный и с открытым кодом. Регистрация не нужна.

### Работает ли Wakamai Fondue в России?
Да, сайт открывается без VPN, а шрифт обрабатывается локально в браузере.

### Чем Wakamai Fondue отличается от WhatTheFont?
[[WhatTheFont]] определяет шрифт по изображению. Wakamai Fondue анализирует уже имеющийся файл шрифта и показывает его возможности.

### Безопасно ли загружать платный шрифт?
Да, файл не покидает ваш компьютер: анализ выполняется в браузере.
