# Wayback Machine

Буква: W · Страница на сайте: `/tools/wayback-machine`

## Описание

Wayback Machine — бесплатный веб-архив Internet Archive, где хранятся сохранённые копии сайтов с 1996 года: можно открыть страницу такой, какой она была в нужную дату.

Главное отличие — масштаб и глубина истории. Архив содержит сотни миллиардов страниц, и любой может сохранить страницу вручную.

### Возможности
- **Календарь снимков:** все сохранённые версии страницы по датам.
- **Save Page Now:** ручное сохранение страницы в архив.
- **Changes:** сравнение двух версий страницы и подсветка изменений.
- **Поиск по сайту:** список всех сохранённых адресов домена.
- **API** для массовой проверки снимков.

### Кому подходит
SEO-специалистам при покупке дроп-доменов и аудите, маркетологам для изучения истории конкурентов, юристам и журналистам для фиксации содержимого страниц.

### Как пользоваться
Введите адрес на web.archive.org и выберите год и дату в календаре. Для сравнения версий откройте вкладку Changes.

### Совет
Перед покупкой старого домена посмотрите его историю: если там были казино или дорвеи, поисковики могут относиться к нему с недоверием. Технологии старой версии сайта проверьте в [[BuiltWith]] или [[Wappalyzer]].

### Ограничения
Сохраняются не все страницы, картинки и скрипты часто не грузятся. Владелец сайта может закрыть архив через robots.txt или запрос. Данных о трафике нет, для этого нужен [[Similarweb]].

## Частые вопросы
### Wayback Machine бесплатный?
Да, просмотр архива и сохранение страниц бесплатны. Internet Archive существует на пожертвования.

### Работает ли Wayback Machine в России?
Обычно сайт открывается без VPN, но доступ бывает нестабильным. При ошибках попробуйте VPN.

### Чем заменить Wayback Machine?
Для отдельных страниц подходит archive.today. Для текущего стека сайта — [[BuiltWith]], для трафика — [[Similarweb]].

### Как удалить сайт из Wayback Machine?
Владелец домена может написать в Internet Archive с запросом на исключение. Новые снимки также блокируются правилами в robots.txt, но не всегда.
