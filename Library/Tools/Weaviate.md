## Описание

Weaviate — это векторная база данных с открытым кодом для семантического и гибридного поиска, RAG-систем и рекомендаций на основе эмбеддингов.

Главное отличие — гибридный поиск и модули векторизации из коробки. Weaviate сам отправляет текст в модель эмбеддингов, совмещает векторный поиск с ключевым (BM25) и может сразу генерировать ответ через LLM.

### Возможности
- **Векторный, ключевой и гибридный поиск** в одном запросе.
- **Модули векторизации** для OpenAI, Cohere, Hugging Face и локальных моделей.
- **Генеративный поиск (RAG)**: найденные объекты передаются в LLM.
- **Мультитенантность** для SaaS с тысячами клиентов.
- **Клиенты** для Python, TypeScript, Go и Java, API на REST, GraphQL и gRPC.

### Кому подходит
Разработчикам AI-продуктов: поиск по базе знаний, чат-боты по документации, рекомендации, поиск по каталогу товаров.

### Как начать
Запустите Weaviate локально в контейнере или создайте песочницу в облаке, подключите модуль векторизации и загрузите первую коллекцию документов через клиент Python.

### Совет
Включайте гибридный поиск для русскоязычного контента: чистый векторный поиск часто промахивается на артикулах, названиях и редких терминах, а BM25 их ловит.

### Ограничения
Self-hosted требует администрирования и памяти под индекс. Для простого старта без сервера есть управляемый [[Pinecone]], для лёгкого локального прототипа — [[Chroma]].

## Частые вопросы
### Weaviate бесплатный?
Да, open-source версию можно бесплатно развернуть на своём сервере. Облако платное, для теста есть песочница на 14 дней.

### Работает ли Weaviate в России?
Self-hosted версия работает на любом сервере, в том числе российском. Облачную версию оплачивают зарубежной картой.

### Weaviate или Qdrant?
[[Qdrant]] быстрее и проще в эксплуатации. Weaviate выигрывает встроенными модулями векторизации и генеративным поиском.

### Поддерживает ли Weaviate русский язык?
Да, если выбрать многоязычную модель эмбеддингов. Для ключевого поиска по русскому тексту стоит настроить токенизацию.
