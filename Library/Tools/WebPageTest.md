## Описание

WebPageTest — бесплатный сервис для подробной проверки скорости загрузки сайта из разных городов, браузеров и типов соединения. Сейчас его развивает компания Catchpoint.

Главное отличие — глубина: водопад запросов, кадры загрузки и сравнение нескольких прогонов. Это точнее, чем общая оценка в [[Google PageSpeed Insights]].

### Возможности
- **Водопад запросов:** время каждого файла, блокирующие ресурсы, сторонние скрипты.
- **Core Web Vitals:** LCP, CLS, TBT с указанием элементов, которые их портят.
- **Видео и кадры загрузки** для сравнения версий страницы.
- **Выбор условий:** город, браузер, мобильное устройство, скорость сети.
- **Сценарии:** вход в аккаунт, несколько шагов, блокировка отдельных доменов.

### Кому подходит
Разработчикам и SEO-специалистам, которые ищут конкретную причину медленной загрузки, а не только общий балл.

### Как пользоваться
Введите адрес, выберите место проверки ближе к вашей аудитории и мобильный профиль. Запустите три прогона и смотрите медианный результат.

### Совет
Включите блокировку доменов счётчиков и чатов и сравните результат. Так вы увидите, сколько времени съедают сторонние скрипты.

### Ограничения
Интерфейс перегружен для новичков. Точек проверки в России мало, поэтому для общей картины сравнивайте с [[GTmetrix]] и данными [[Яндекс Метрика]].

## Частые вопросы
### WebPageTest бесплатный?
Да, базовые тесты бесплатны после регистрации. Платный Pro нужен для API и большого объёма проверок.

### Работает ли WebPageTest в России?
Сайт открывается без VPN, бесплатные тесты доступны. Оплатить Pro можно только зарубежной картой.

### WebPageTest или PageSpeed Insights?
[[Google PageSpeed Insights]] быстро даёт оценку и данные реальных пользователей. WebPageTest показывает, какой именно файл тормозит загрузку.

### Сколько прогонов делать?
Минимум три. Один прогон бывает случайно медленным, а медиана даёт устойчивую картину.
