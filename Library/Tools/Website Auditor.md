## Описание

Website Auditor (WebSite Auditor) — десктопная программа для технического SEO-аудита сайта из пакета [[SEO PowerSuite]]. Она обходит сайт как поисковый робот, находит ошибки и даёт рекомендации по оптимизации страниц.

Главное отличие — аудит и оптимизация контента в одной программе: кроме технических ошибок она анализирует тексты конкурентов и предлагает ключевые слова.

### Возможности
- **Краулинг сайта:** битые ссылки, редиректы, дубли, ошибки индексации.
- **Аудит страниц:** title, description, заголовки, изображения, скорость.
- **Анализ контента** по TF-IDF в сравнении с конкурентами из выдачи.
- **Карта сайта и robots.txt:** генерация и проверка.
- **Отчёты для клиентов** с вашим брендингом на платных версиях.

### Кому подходит
SEO-специалистам, фрилансерам и студиям, которые проводят аудиты сайтов клиентов и хотят разовую годовую лицензию вместо подписки на облачный сервис.

### Как начать
Скачайте программу для Windows, macOS или Linux, создайте проект с адресом сайта и запустите обход. Начните с раздела Site Audit: там ошибки сгруппированы по важности.

### Совет
Сравнивайте результат с [[Google Search Console]] и [[Яндекс Вебмастер|Яндекс Вебмастером]]: программа видит сайт как робот, а панели — как реальный поиск.

### Ограничения
Бесплатная версия ограничена 500 URL и не подходит для больших сайтов. Интерфейс тяжеловат, а для массового краулинга привычнее [[Screaming Frog SEO Spider]] или [[Netpeak Spider]].

### Website Auditor бесплатный?

### Работает ли Website Auditor в России?

### Website Auditor или Screaming Frog?
[[Screaming Frog SEO Spider]] быстрее и гибче в краулинге больших сайтов. Website Auditor сильнее в оптимизации контента и отчётах для клиентов.

Для краулинга — [[Netpeak Spider]], для онлайн-аудита — [[Labrika]] и [[Сайт-аудитор]].
