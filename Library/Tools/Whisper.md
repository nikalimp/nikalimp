## Описание

Whisper — это модель OpenAI с открытым кодом для распознавания речи: она переводит аудио и видео в текст на десятках языков, включая русский, и умеет сразу переводить речь на английский.

Главное отличие — бесплатный локальный запуск. Модель работает на вашем компьютере без интернета, поэтому подходит для конфиденциальных записей.

### Возможности
- **Распознавание речи** на 90+ языках с автоматическим определением языка.
- **Перевод на английский** прямо из аудио.
- **Субтитры** в форматах SRT и VTT с таймкодами.
- **Модели разного размера:** от tiny до large-v3 и быстрой large-v3-turbo.
- **API OpenAI** для тех, кто не хочет держать модель у себя.

### Кому подходит
Журналистам, исследователям, авторам видео и подкастов, разработчикам, которым нужна расшифровка без платных подписок.

### Как начать
Без кода Whisper удобно запускать через готовые приложения с графическим интерфейсом, например MacWhisper на Mac. Разработчики ставят пакет через pip и запускают одной командой.

### Совет
Для русской речи берите модель large-v3 или large-v3-turbo: маленькие модели заметно чаще ошибаются в именах и терминах. Готовый текст удобно чистить в [[ChatGPT]] или [[GigaChat]].

### Ограничения
Whisper не разделяет говорящих — для этого нужны дополнения. На слабом компьютере большие модели работают медленно. Готовые сервисы с разметкой спикеров — [[Otter.ai]] и [[Fireflies.ai]].

## Частые вопросы
### Whisper бесплатный?
Да, модель распространяется с открытым кодом и бесплатна для локального запуска. Платно только распознавание через API OpenAI.

### Работает ли Whisper в России?
Локально — да, без VPN и без интернета. API OpenAI из России недоступен.

### Чем заменить Whisper?
Готовые облачные сервисы с протоколами встреч — [[Otter.ai]] и [[Fireflies.ai]]. Для монтажа по тексту есть [[Descript]].

### Как пользоваться Whisper без программирования?
Установите приложение с графическим интерфейсом на основе Whisper, например MacWhisper для Mac. Перетащите файл, выберите модель и язык.

## Доступность из России

Локально Whisper работает в России без ограничений. API OpenAI из России недоступен, нужны VPN и зарубежная карта; российская альтернатива — Yandex SpeechKit.
