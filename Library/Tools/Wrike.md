# Wrike

Буква: W · Страница на сайте: `/tools/wrike`

## Описание

Wrike — это система управления проектами для команд и компаний: задачи, диаграммы Ганта, загрузка ресурсов, отчёты и согласования в одном сервисе.

Главное отличие от лёгких трекеров вроде [[Asana]] — глубина для крупных команд: настраиваемые процессы, ресурсное планирование, бюджеты и контроль доступа.

### Возможности
- **Виды:** список, доска, таблица, диаграмма Ганта, календарь.
- **Пользовательские поля и процессы** со своими статусами для каждого отдела.
- **Загрузка ресурсов:** видно, кто перегружен, а у кого есть время.
- **Согласования:** проверка макетов и документов с пометками прямо на файле.
- **Дашборды и отчёты** по срокам, статусам и времени.
- **AI-функции:** резюме задач, генерация подзадач, оценка рисков.

### Кому подходит
Маркетинговым и креативным отделам, агентствам и PMO от 10–15 человек, которым нужны сложные процессы и отчётность. Небольшой студии хватит [[Weeek]] или [[YouGile]].

### Как начать
Создайте пространство для команды, настройте статусы под ваш процесс и импортируйте задачи из таблицы. Начните с одного проекта, затем подключайте остальные.

### Совет
Сразу договоритесь о правилах: кто ставит задачи, где обсуждения, какие поля обязательны. Без регламента гибкость Wrike превращается в хаос.

### Ограничения
Порог входа высокий, интерфейс перегружен для маленьких команд. Ресурсное планирование и бюджеты — только на дорогих тарифах. Из России сервис работает с ограничениями.

## Частые вопросы
### Сколько стоит Wrike?
Есть бесплатный план. Платные — от $10 за пользователя в месяц при оплате за год, корпоративные — по запросу.

### Работает ли Wrike в России?
Wrike прекратил продажи в России. Для работы обычно нужен VPN, оплата — только зарубежной картой.

### Чем заменить Wrike?
Из российских сервисов — [[Kaiten]], [[Яндекс Трекер]], [[YouGile]] и [[Битрикс24]]. Из зарубежных похожие по уровню — [[ClickUp]] и [[Monday.com]].

### Подходит ли Wrike для агентства?
Да, если в агентстве десятки сотрудников и много согласований. Небольшой студии хватит более простого трекера.
