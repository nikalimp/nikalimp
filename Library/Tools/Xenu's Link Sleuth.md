# Xenu's Link Sleuth

Буква: X · Страница на сайте: `/tools/xenus-link-sleuth`

## Описание

Xenu's Link Sleuth — это бесплатная программа для Windows, которая обходит сайт и находит битые ссылки, картинки, скрипты и редиректы.

Главное отличие от [[Screaming Frog SEO Spider]] — Xenu полностью бесплатна и без лимита страниц, но не обновлялась с 2010 года и умеет только базовую проверку.

### Возможности
- **Поиск битых ссылок:** страницы, изображения, CSS, скрипты, фреймы.
- **Редиректы:** показывает, какие URL перенаправляют и куда.
- **Повторная проверка ошибок,** чтобы отсеять временные сбои.
- **Отчёт и карта сайта** в HTML, сортируемый список URL.
- **Настройки обхода:** число потоков, исключения, cookies.

### Кому подходит
Вебмастерам и SEO-специалистам, которым нужно быстро проверить небольшой или средний сайт на 404 без покупки краулера.

### Как пользоваться
Скачайте программу, выберите File → Check URL, введите адрес сайта и запустите проверку. Ошибки подсветятся красным.

### Совет
Используйте Xenu как быструю первую проверку, а мета-теги, дубли и canonical смотрите в [[Netpeak Spider]] или бесплатной версии [[Screaming Frog SEO Spider]] до 500 URL.

### Ограничения
Последняя версия вышла в 2010 году. Программа не рендерит JavaScript, не проверяет мета-теги и canonical. На macOS и Linux работает только через Wine.

## Частые вопросы
### Xenu's Link Sleuth бесплатная?
Да, программа полностью бесплатна и без ограничений на число страниц. Автор принимает добровольные пожертвования.

### Работает ли Xenu's Link Sleuth в России?
Да, программа скачивается и работает без VPN и регистрации.

### Xenu или Screaming Frog?
[[Screaming Frog SEO Spider]] умеет намного больше: мета-теги, canonical, рендеринг JavaScript, интеграции. Xenu выигрывает только ценой и отсутствием лимита.

### Работает ли Xenu на Mac?
Официально нет, только на Windows. На macOS и Linux программа запускается через Wine или CrossOver.
