# Yandex Object Storage

[[Инструменты — Хостинг, домены, инфраструктура|Хостинг, домены, инфраструктура]] · Хранение файлов и облака · Россия и СНГ
Буква: Y · Страница на сайте: `/tools/yandex-object-storage`

## Описание

Yandex Object Storage — это S3-совместимое объектное хранилище Yandex Cloud: файлы, бэкапы, картинки и статика сайта хранятся в «бакетах» и отдаются по ссылке или через API.

Главное отличие от [[Amazon S3]] — сервис работает в России, принимает рубли и хранит данные в российских дата-центрах, что важно для закона о персональных данных.

### Возможности
- **S3-совместимый API:** подходят AWS SDK, [[Cyberduck]] и любые S3-клиенты.
- **Классы хранения:** стандартное, холодное и ледяное для архивов.
- **Хостинг статического сайта** прямо из бакета, с HTTPS и своим доменом.
- **Жизненный цикл объектов:** автоудаление и перенос в холодное хранилище.
- **Интеграция с CDN** Yandex Cloud для быстрой раздачи файлов.

### Кому подходит
Разработчикам сайтов и сервисов для российского рынка: хранение загрузок пользователей, медиа, бэкапов и статики фронтенда.

### Как начать
Создайте платёжный аккаунт в Yandex Cloud, откройте Object Storage и создайте бакет. Получите статический ключ доступа и подключите его в коде или S3-клиенте.

### Совет
Включите правила жизненного цикла для бэкапов: старые копии сами уйдут в холодное хранилище и обойдутся дешевле. Для статики добавьте CDN, чтобы не платить за лишний исходящий трафик.

### Ограничения
Тарификация сложнее, чем у дисков: отдельно считаются хранение, запросы и трафик. Консоль Yandex Cloud требует времени на освоение. Для простой передачи файлов клиенту удобнее [[Яндекс Диск]].

## Частые вопросы
### Сколько стоит Yandex Object Storage?
Оплата по факту: за гигабайты хранения, количество запросов и исходящий трафик. Небольшой объём в месяц бесплатный, точные цены — в калькуляторе Yandex Cloud.

### Работает ли Yandex Object Storage в России?
Да, это российский сервис. Он работает без VPN, принимает рублёвые карты и оплату по счёту.

### Yandex Object Storage или Selectel S3?
Оба S3-совместимые и работают в рублях. [[Selectel S3]] проще по тарифам, Yandex Object Storage удобнее, если остальная инфраструктура уже в [[Yandex Cloud]].

### Можно ли разместить сайт в Yandex Object Storage?
Да, статический сайт на HTML, CSS и JS можно отдавать прямо из бакета со своим доменом и HTTPS.
