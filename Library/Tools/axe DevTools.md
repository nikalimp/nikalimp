## Описание

axe DevTools — это набор инструментов Deque для проверки доступности сайтов по WCAG: расширение для браузера, интеграции с тестами и CI.

Главное отличие — движок axe-core: он лежит в основе многих проверок доступности, включая Lighthouse, и почти не даёт ложных срабатываний.

### Возможности
- **Автоматическая проверка страницы** в DevTools браузера с привязкой к элементу и правилу WCAG.
- **Пояснения и рекомендации** по исправлению каждой ошибки.
- **Guided testing в Pro:** пошаговые ручные проверки клавиатуры, форм, заголовков и изображений.
- **Проверка пользовательских сценариев** и экспорт отчётов в Pro.
- **Интеграции** с [[Playwright]], [[Cypress]], Jest и CI для тестов в коде.

### Кому подходит
Фронтенд-разработчикам и QA, которые проверяют доступность на этапе вёрстки, и командам, которые обязаны соответствовать WCAG.

### Как начать
Установите расширение, откройте DevTools на нужной странице и запустите сканирование во вкладке axe DevTools. Исправляйте ошибки по степени критичности.

### Совет
Проверяйте страницу во всех состояниях: открытое меню, модальное окно, ошибки формы. Автоматический скан видит только то, что сейчас в DOM.

### Ограничения
Автоматика находит лишь часть проблем, остальное проверяют вручную и экранными читалками вроде [[NVDA]] и [[VoiceOver]]. Платные функции стоят дорого и продаются через отдел продаж. Простая альтернатива для визуальной проверки — [[WAVE]].

## Частые вопросы
### axe DevTools бесплатный?
Базовое расширение бесплатно и закрывает автоматическую проверку страниц. Pro и интеграции для команд продаются по подписке, цена по запросу.

### Работает ли axe DevTools в России?
Да, бесплатное расширение устанавливается из Chrome Web Store и работает без VPN.

### axe DevTools или WAVE?
axe показывает ошибки списком в DevTools и подходит разработчикам. [[WAVE]] размечает проблемы прямо на странице, это нагляднее для дизайнеров и контент-менеджеров.

### Достаточно ли axe для соответствия WCAG?
Нет. Автоматическая проверка находит часть ошибок, остальное требует ручного теста с клавиатуры и экранной читалки.
