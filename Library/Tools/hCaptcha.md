## Описание

hCaptcha — это капча для защиты форм и сайтов от ботов, которая делает упор на приватность и не передаёт данные посетителей в рекламные системы.

Главное отличие от [[reCAPTCHA]] — модель приватности. hCaptcha собирает минимум данных, соответствует GDPR и не связана с рекламной экосистемой Google.

### Возможности
- **Виджет капчи** для форм регистрации, входа и заявок.
- **Невидимый режим:** проверка без лишних действий для большинства людей.
- **Пассивный режим и оценка риска** в платных тарифах.
- **Совместимость с API reCAPTCHA** для быстрой замены.
- **Поддержка многих языков**, включая русский.

### Кому подходит
Владельцам сайтов, которым нужна защита форм от спама без передачи данных Google.

### Как начать
Зарегистрируйтесь, добавьте сайт и получите ключи. Вставьте виджет в форму и проверяйте токен на сервере при отправке.

### Совет
Не ставьте капчу на каждую форму. Начните с поля-ловушки и ограничения частоты отправок, а hCaptcha включайте там, где спам всё равно проходит.

### Ограничения
Задания с картинками иногда раздражают пользователей. Пассивный режим только в платных тарифах. Невидимую проверку бесплатно даёт и [[Cloudflare Turnstile]], для российских сайтов с хранением данных в России подойдёт [[Яндекс SmartCaptcha]].

## Частые вопросы
### hCaptcha бесплатная?
Да, базовый план бесплатный. Пассивный режим и аналитика — в платных тарифах.

### Работает ли hCaptcha в России?
Да, бесплатный план подключается без оплаты, а виджет показывается российским посетителям на русском.

### hCaptcha или Cloudflare Turnstile?
[[Cloudflare Turnstile]] бесплатно проверяет посетителей без заданий с картинками. hCaptcha чаще показывает задания, зато даёт больше настроек защиты.

### Как заменить reCAPTCHA на hCaptcha?
API совместимы: замените скрипт, ключи и адрес серверной проверки — остальной код формы обычно менять не нужно.
