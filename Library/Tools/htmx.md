## Описание

htmx — это небольшая JavaScript-библиотека, которая добавляет в обычный HTML запросы к серверу и обновление частей страницы через атрибуты вроде `hx-get` и `hx-swap`.

Главное отличие — интерактивность без SPA-фреймворка. Сервер возвращает готовые куски HTML, а htmx вставляет их на страницу. Не нужны [[React]], сборка и отдельный API.

### Возможности
- **AJAX через атрибуты:** `hx-get`, `hx-post`, `hx-put`, `hx-delete` на любом элементе.
- **Гибкая подмена** контента через `hx-swap` и `hx-target`.
- **Триггеры** по клику, вводу, прокрутке или таймеру.
- **История и ссылки** через `hx-push-url` без перезагрузки.
- **WebSocket и SSE** через расширения.

### Кому подходит
Бэкенд-разработчикам на [[Django]], [[Laravel]], [[Ruby on Rails]] и [[FastAPI]], которые хотят живой интерфейс без отдельного фронтенда.

### Как начать
Подключите скрипт в `<head>`, добавьте кнопке `hx-post="/like"` и `hx-target="#counter"`. На сервере верните фрагмент HTML со счётчиком.

### Совет
Сочетайте htmx с [[Alpine.js]]: htmx отвечает за обмен с сервером, Alpine — за локальное состояние вроде открытых меню и вкладок.

### Ограничения
Сложные клиентские интерфейсы — редакторы, офлайн-режим, богатая анимация — проще делать на [[React]] или [[Vue.js]]. Логика размазывается по шаблонам. Вышел htmx 4, но в npm основной пока остаётся ветка 2.x.

## Частые вопросы
### htmx бесплатный?
Да, библиотека распространяется с открытым кодом под лицензией BSD. Платных версий нет.

### Работает ли htmx в России?
Да, библиотеку можно подключить из npm или CDN без VPN. Для продакшена лучше положить файл на свой сервер.

### htmx или React?
[[React]] нужен, когда большая часть логики живёт в браузере. htmx лучше, когда логика на сервере, а странице нужно лишь обновлять куски HTML. Для маленьких интерактивных деталей добавьте [[Alpine.js]].

### Нужен ли для htmx особый бэкенд?
Нет, подходит любой сервер, который умеет возвращать HTML: Django, Laravel, Rails, FastAPI, Go или PHP.
