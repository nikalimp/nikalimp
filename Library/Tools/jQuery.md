## Описание

jQuery — бесплатная JavaScript-библиотека для работы с DOM, событиями, анимацией и AJAX-запросами через короткий и удобный синтаксис.

Главное отличие: jQuery до сих пор работает на огромной доле сайтов, особенно на WordPress и старых CMS. В январе 2026 года вышла версия 4.0 — первое крупное обновление с 2016 года.

### Возможности
- **Селекторы** в стиле CSS для поиска элементов на странице.
- **Обработка событий:** клики, ввод, прокрутка, делегирование.
- **AJAX:** запросы к серверу в одну строку.
- **Анимации** и эффекты показа и скрытия.
- **Плагины:** слайдеры, маски ввода, валидация форм.
- **Версия 4.0:** без поддержки старых IE, с ES-модулями и удалёнными устаревшими методами.

### Кому подходит
Разработчикам, которые поддерживают старые проекты, темы WordPress и сайты на конструкторах. Тем, кому нужно быстро добавить интерактив без сборщика.

### Как пользоваться
Подключите jQuery через CDN перед своим скриптом и пишите код внутри `$(function(){ ... })`. Для новых проектов используйте версию 4.x.

### Совет
Перед переходом на jQuery 4 подключите jQuery Migrate: он покажет в консоли, какие устаревшие методы использует ваш код и плагины.

### Ограничения
Для новых приложений jQuery почти не нужен: современный JavaScript делает то же самое нативно, а интерфейсы собирают на [[React]] или [[Vue.js]]. Многие старые плагины не обновлены под версию 4.

## Частые вопросы
### jQuery бесплатный?
Да, библиотека распространяется бесплатно под лицензией MIT.

### Работает ли jQuery в России?
Да, jQuery подключается через npm, CDN или скачивается с официального сайта без VPN.

### Нужен ли jQuery в 2026 году?
Для поддержки старых проектов и WordPress — да. Для новых приложений лучше чистый JavaScript или фреймворки вроде [[React]] и [[Vue.js]].

### Что изменилось в jQuery 4.0?
Убрана поддержка IE10 и старше, удалены устаревшие методы, появилась поставка в виде ES-модулей. Перед обновлением проверьте код через jQuery Migrate.
