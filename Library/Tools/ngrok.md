## Описание

ngrok — это сервис туннелей, который за одну команду открывает доступ из интернета к локальному серверу: сайт, API или вебхук на вашем компьютере получает публичный HTTPS-адрес.

Главное отличие — скорость старта: не нужен белый IP, настройка роутера и сертификаты, достаточно команды `ngrok http 3000`.

### Возможности
- **Публичный HTTPS-адрес** для локального сервера за секунды.
- **Инспектор трафика:** просмотр и повтор запросов в веб-интерфейсе.
- **Тестирование вебхуков** платёжек, ботов и CRM на локальной машине.
- **Авторизация и ограничения** на входе: OAuth, IP-фильтры, mTLS.
- **TCP-туннели** для SSH и баз данных.

### Кому подходит
Разработчикам ботов, интеграций и API, которым нужно принять вебхук на локальной машине или быстро показать работу клиенту.

### Как начать
Установите агент, добавьте токен из кабинета и выполните `ngrok http 3000`. Полученный адрес укажите в настройках вебхука, например в [[BotFather]] для Telegram-бота.

### Совет
Включите инспектор на localhost:4040 и повторяйте вебхуки кнопкой replay: не нужно каждый раз заново оплачивать тестовый заказ или писать боту.

### Ограничения
На бесплатном плане есть промежуточная страница-предупреждение и жёсткие лимиты трафика. Из России без VPN не работает.

## Вердикт
- Кому подходит: Разработчикам за рубежом, которым нужно быстро открыть локальный сервер и тестировать вебхуки.
- Кому не подходит: Разработчикам из России без VPN и тем, кому нужен постоянный продакшн-хостинг.
- Итог: Самый быстрый способ открыть локальный сервер в интернет, но из России он заблокирован.

## Частые вопросы
### ngrok бесплатный?
Да, есть бесплатный план для тестов с лимитом 1 ГБ трафика и 20 тыс. запросов в месяц. Платные тарифы — от $10 в месяц.

### Работает ли ngrok в России?
Нет, с апреля 2025 года ngrok блокирует российские IP-адреса. Работать с ним можно только через VPN или зарубежный сервер.

### Чем заменить ngrok?
[[Cloudflare Tunnel]] бесплатен и подходит для постоянных туннелей. Для разработчиков из России есть отечественные сервисы туннелей, например tuna.am.

### Зачем ngrok разработчику ботов?
Чтобы принимать вебхуки от Telegram или платёжных систем на локальной машине без деплоя на сервер.
