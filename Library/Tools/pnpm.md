## Описание

pnpm — менеджер пакетов для JavaScript и Node.js, замена npm и [[Yarn]]. Хранит каждую версию пакета на диске один раз и подключает её в проекты через ссылки.

Главное отличие: установка в 2–3 раза быстрее, чем у npm, и экономия гигабайтов на диске, если у вас много проектов с одинаковыми зависимостями.

### Возможности
- **Общее хранилище пакетов:** одна копия версии на весь компьютер.
- **Строгий node_modules:** проект видит только объявленные зависимости, без «фантомных» пакетов.
- **Монорепозитории:** workspaces, фильтры `--filter`, каталоги версий.
- **Безопасность:** с версии 10 скрипты установки зависимостей по умолчанию не запускаются.
- **pnpm dlx** — запуск пакета без установки, аналог npx.

### Кому подходит
Разработчикам на [[Next.js]], [[Vite]] и других JS-стеках, особенно в монорепозиториях и на CI, где важна скорость установки.

### Как начать
Включите pnpm через `corepack enable` или поставьте `npm i -g pnpm`. В проекте удалите `package-lock.json` и выполните `pnpm import`, затем `pnpm install`.

### Совет
Зафиксируйте версию в поле `packageManager` в `package.json`: тогда на CI и у коллег будет та же версия. В [[GitHub Actions]] используйте кэш хранилища pnpm.

### Ограничения
Редкие старые пакеты ломаются из-за строгого node_modules: для них есть настройки `public-hoist-pattern` и `node-linker=hoisted`. Конкуренты по скорости — [[Bun]] и новые версии [[Yarn]].

## Вердикт
- Кому подходит: JS-разработчикам с несколькими проектами, монорепозиториями и CI.
- Кому не подходит: Командам на старых проектах, где пакеты рассчитаны на плоский node_modules и нет времени на настройку.
- Итог: Быстрый и экономный менеджер пакетов, который стоит сделать стандартом для новых проектов.

## Плюсы
- Установка быстрее npm, экономия места на диске
- Строгие зависимости без «фантомных» пакетов
- Сильная поддержка монорепозиториев
- Безопасные настройки по умолчанию для скриптов установки

## Минусы
- Отдельные старые пакеты требуют настройки
- Нужно, чтобы вся команда перешла на pnpm

## Частые вопросы
### pnpm бесплатный?
Да, pnpm распространяется бесплатно с открытым кодом под лицензией MIT.

### Работает ли pnpm в России?
Да, pnpm и реестр npm работают без VPN.

### pnpm или npm?
npm идёт вместе с Node.js и не требует установки. pnpm быстрее, экономит место и строже следит за зависимостями, поэтому лучше подходит для новых проектов и монорепозиториев.

### Как перевести проект с npm на pnpm?
Выполните `pnpm import`, чтобы создать `pnpm-lock.yaml` из старого lock-файла, удалите `node_modules` и `package-lock.json`, затем запустите `pnpm install`.
