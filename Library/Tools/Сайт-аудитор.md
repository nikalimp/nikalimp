# Сайт-аудитор

[[Инструменты — SEO|SEO]] · SEO-сервисы Рунета · Россия и СНГ
Буква: С · Страница на сайте: `/tools/sayt-auditor`

## Описание

Сайт-аудитор — это бесплатная программа для Windows, которая показывает основные SEO-показатели сайта: позиции по запросам, индексацию и данные счётчиков посещаемости.

Главное отличие от онлайн-сервисов вроде [[PR-CY]] — программа хранит историю проверок у вас на компьютере и сравнивает позиции с прошлыми замерами.

### Возможности
- **Экспресс-анализ** основных показателей сайта.
- **Проверка позиций** по своему списку запросов в Яндексе и Google с учётом региона.
- **Динамика позиций** относительно прошлых проверок.
- **Поиск счётчиков** посещаемости на сайте.
- **Локальное хранение** результатов.

### Кому подходит
Владельцам небольших сайтов и начинающим SEO-специалистам, которым нужна бесплатная базовая проверка без подписки.

### Как пользоваться
Скачайте программу с официального сайта, установите и введите адрес сайта. Добавьте список запросов и запустите проверку позиций.

### Совет
Используйте программу для быстрого обзора, а точные данные по индексации и запросам берите в [[Яндекс Вебмастер]] и [[Google Search Console]]: они показывают данные самих поисковиков.

### Ограничения
Программа давно не развивается, часть метрик устарела: например, тИЦ Яндекс отменил ещё в 2018 году. Проверка позиций без прокси может упираться в капчу. Только Windows. Технический аудит — битые ссылки, мета-теги, дубли — программа не проводит.

## Частые вопросы
### Сайт-аудитор бесплатный?
Да, программа бесплатная и не требует регистрации.

### Работает ли Сайт-аудитор в России?
Да, это российская программа. Она работает без VPN.

### Чем заменить Сайт-аудитор?
Для быстрой проверки сайта онлайн — [[PR-CY]] или [[Be1.ru]], для позиций — [[AllPositions]] или [[Rush Analytics]], для технического аудита — [[Netpeak Spider]].

### Показывает ли Сайт-аудитор точные позиции?
Приблизительные: программа проверяет выдачу со своего компьютера, и результат зависит от региона, IP и персонализации. Для регулярного съёма позиций и отчётов клиентам используйте специализированные сервисы с историей и выгрузкой.
