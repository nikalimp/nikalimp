# Яндекс XML

Буква: Я · Страница на сайте: `/tools/yandeks-xml`

## Описание

Яндекс XML — программный доступ к результатам поиска Яндекса: сервис возвращает выдачу по запросу в XML или HTML. Сейчас он работает как Yandex Search API в облаке Яндекса.

Главное отличие — официальный источник выдачи. Данные приходят от самого Яндекса, без парсинга и капчи, с учётом региона поиска.

### Возможности
- **Выдача по запросу** с учётом региона, языка и устройства.
- **Отложенный режим** — дешёвые пакетные запросы с ответом через время.
- **Синхронный режим** — ответ сразу, но дороже.
- **Поиск по изображениям** и генеративные ответы.
- **Методы Wordstat** — частотность и динамика запросов.

### Кому подходит
SEO-специалистам и разработчикам сервисов, которые снимают позиции, собирают топ для кластеризации и анализируют конкурентов.

### Как начать
Создайте аккаунт в Yandex Cloud, включите Search API и получите ключ. Подключите его в [[Key Collector]], [[Топвизор]] или свой скрипт.

### Совет
Для съёма позиций и кластеризации используйте отложенный режим ночью: он в разы дешевле синхронного, а свежесть данных для SEO-задач не страдает.

### Ограничения
Синхронные запросы стоят дорого, есть квоты. Переход с классического Яндекс XML в облако потребовал перенастройки инструментов. Дешевле выходит через посредников вроде [[XMLRiver]].

## Частые вопросы
### Яндекс XML бесплатный?
Нет, сейчас это платный Yandex Search API: отложенные запросы стоят от 25 ₽ за 1000, синхронные — от 366 ₽.

### Работает ли Яндекс XML в России?
Да, это сервис Яндекса: работает без ограничений, оплата в рублях.

### Яндекс XML или XMLRiver?
Яндекс XML — официальный источник с ценами Яндекса. [[XMLRiver]] — посредник, который отдаёт выдачу Яндекса и Google и часто выходит дешевле.

### Где использовать ключ Яндекс XML?
В программах для SEO: [[Key Collector]], [[Топвизор]], [[Rush Analytics]] и своих скриптах для съёма позиций и кластеризации.
